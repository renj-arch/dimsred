Algebra: The Backbone of JEE Mathematics

Algebra is the language of patterns and relationships, serving as the foundation for advanced calculus and physics in engineering. This comprehensive lesson covers Complex Numbers, Quadratic Equations, Sequences and Series, Permutations and Combinations, Binomial Theorem, and Matrices. Mastery of these topics is essential not only for JEE Main but also for competitive exams and CAT, where speed and conceptual clarity are paramount.

Complex Numbers

A complex number is a number of the form z = x + iy, where x and y are real numbers and i is the imaginary unit defined by i2 = -1. The set of complex numbers forms a field, allowing for addition, subtraction, multiplication, and division. In the Argand plane, a complex number corresponds to a point $(x, y)$ or a vector from the origin.

The modulus of a complex number z, denoted |z|, represents its distance from the origin in the Argand plane and is calculated as √(x2 + y2). The conjugate of z = x+iy is \bar{z} = x-iy, which is useful for simplifying division operations. A fundamental property is that |z|2 = zz.

Examiners typically ask questions involving finding the modulus and argument, solving quadratic equations with complex roots (where roots occur in conjugate pairs if coefficients are real), or determining the locus of points satisfying a condition like |z-z1|=|z-z2|.

Quadratic Equations

A quadratic equation is a polynomial equation of degree two, generally written as ax2 + bx + c = 0, where a ≠ 0. The nature of the roots depends entirely on the discriminant Δ = b2 - 4ac. If Δ > 0, there are two distinct real roots; if Δ = 0, there is one repeated real root; and if Δ < 0, the roots are complex conjugates.

The quadratic formula x = (-b ± √(b2 - 4ac))/(2a) provides the exact values of the roots. Vieta's formulas relate the coefficients to the roots: the sum of roots α + β = -(b)/(a) and the product of roots αβ = (c)/(a). These relations allow solving problems without finding the actual roots, such as forming a new quadratic equation given the sum and product of its roots.

Sequences and Series

A sequence is an ordered list of numbers, while a series is the sum of the terms of that sequence. An Arithmetic Progression (AP) has a constant difference d between consecutive terms. The n-th term is given by a_n = a + (n-1)d, and the sum of the first n terms is S_n = (n)/(2)[2a + (n-1)d]. A Geometric Progression (GP) has a constant ratio r between consecutive terms. The n-th term is a_n = arn-1, and the sum of an infinite GP converges to (a)/(1-r) only if |r| < 1.

Harmonic Progression (HP) is defined as the reciprocals of terms in an AP. If a1, a2, … are in HP, then (1)/(a1), (1)/(a2), … are in AP. This concept often appears in problems involving resistors in parallel or lenses.

Permutations and Combinations

Permutation refers to the arrangement of objects where order matters, calculated as ^nP_r = (n!)/((n-r)!). Combination refers to selection of objects where order does not matter, calculated as ^nC_r = (n!)/(r!(n-r)!). The factorial function n! represents the product of all positive integers up to n, with 0! = 1 by definition.

The total number of ways to arrange n distinct objects is n!. If there are repetitions, such as arranging letters in a word like "MATHS" (all unique) versus "MISSISSIPPI" (repeated letters), the formula adjusts to (n!)/(p!q!r!…). The Binomial Coefficient identity Σk=0^n ^nC_k = 2^n is a direct application of this concept.

Binomial Theorem

The Binomial Theorem provides an expansion for (x+y)^n where n is a non-negative integer. It states that (x+y)^n = Σk=0^n ^nC_k xn-k y^k. The term independent of x (or y) in the expansion of (1+x)^n or similar expressions is found by setting the power of the variable to zero. The general term Tr+1 is given by nC_r xn-r y^r.

Matrices

A matrix is a rectangular array of numbers arranged in rows and columns, denoted as A = [aij]. The order of a matrix is defined by the number of rows multiplied by the number of columns (e.g., 2 × 3). Operations include addition, subtraction, scalar multiplication, and matrix multiplication. Note that matrix multiplication is not commutative (AB ≠ BA generally) but is associative.

The determinant of a square matrix is a scalar value calculated from its elements. For a 2 × 2 matrix begin{pmatrix} a & b \ c & d end{pmatrix}, the determinant is ad - bc. The inverse of a non-singular matrix A, denoted A-1, satisfies AA-1 = I, where I is the identity matrix. Cramer's rule uses determinants to solve systems of linear equations.

Solved Examples

Example 1: Quadratic Roots and Symmetry
If α and β are the roots of ax2 + bx + c = 0, find the value of (1)/(α) + (1)/(β) in terms of $a, b, c$.
Options: A) (b)/(c) B) (-b)/(c) C) (a)/(c) D) (-a)/(c)
Solution: B) (-b)/(c).
Technique: Use Vieta's formulas. They are derived directly from the factorization a(x-α)(x-β) = ax2 - a(α+β)x + aαβ. Comparing coefficients gives α+β = -b/a and αβ = c/a.
Step-by-step: We need to evaluate (1)/(α) + (1)/(β). Find the common denominator: (β + α)/(αβ). Substitute the values from Vieta's formulas: (-b/a)/(c/a). Simplify the complex fraction by multiplying numerator and denominator by a: (-b)/(c).
Key Insight: Always simplify expressions involving roots using sum and product relations rather than solving for individual roots, which introduces unnecessary square roots.
Example 2: Complex Numbers and Modulus
If z is a complex number such that |z| = 1, find the value of (z2)/(z).
Options: A) z3 B) -z3 C) z4 D) -z4
Solution: A) z3.
Technique: Utilize the property of modulus for unit circle numbers. If |z|=1, then zz = |z|2 = 1, which implies z = (1)/(z).
Step-by-step: Substitute z in the expression: (z2)/((1/z)). This simplifies to z2 · z = z3.
Key Insight: Recognizing that a number on the unit circle is its own reciprocal's conjugate is a powerful shortcut for JEE Main problems involving complex fractions.

Common Traps

Students frequently fall into specific traps that cost valuable marks. First, confusing Permutation and Combination: remember "Permutation" has an 'm' (like arrangement) while "Combination" has a 'b' (like selection/basket). Second, the sign error in Vieta's formulas: sum of roots is -b/a, not b/a. Third, forgetting that matrix multiplication order matters; (AB)^T = B^T A^T, not A^T B^T. Fourth, assuming √(x2) = x always; it is actually |x|. Fifth, in Binomial Theorem expansions, misidentifying the general term index (r+1 vs r).

Memory Tricks

To retain these concepts effectively, use these mnemonics. For quadratic roots: "BAD" stands for B (sum) is negative of b over a, A (product) is c over a, D (discriminant) determines nature. For AP and GP sums: AP sum involves an arithmetic mean concept (n/2), while GP sum involves the geometric ratio (r^n-1)/(r-1). For matrices: Think of them as "tables" where you multiply rows by columns, but never swap order like numbers. For complex numbers: "Conjugate is the flip", meaning change the sign of i to get \bar{z}

Exam Day Strategy
When facing an Algebra question in JEE Main, first identify the topic instantly: Is it roots? Then check the discriminant. Is it sequences? Check for AP or GP keywords like "constant difference" or "ratio". If you see matrices, verify dimensions before multiplying to avoid impossible operations. Always substitute x=0 or y=0 in polynomial expansions to find constant terms quickly. If a question seems too long, look for symmetry or identities (like (a+b)2) that can simplify the algebra instantly. Time management: spend no more than 3 minutes on a single matrix determinant calculation; if stuck, move on and return later.

De Moivre’s Theorem and Roots of Unity

De Moivre’s theorem states that for any real number θ and integer n, (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ. This identity bridges trigonometry and complex algebra, turning powers of complex numbers on the unit circle into simple angle multiplication. The theorem extends to rational exponents, giving the n distinct nth roots of unity: the solutions of zⁿ = 1 are zₖ = cos(2πk/n) + i sin(2πk/n) for k = 0,1,…,n−1. These roots lie at the vertices of a regular n‑gon inscribed in the unit circle, symmetric about the real axis. Their sum is zero, and the product of all non‑trivial roots equals (−1)ⁿ⁻¹. The primitive nth roots — those with gcd(k,n)=1 — generate the full cyclic group of order n under multiplication. In problems, De Moivre’s theorem is used to evaluate expressions like (1+i)¹⁰⁰, to derive trigonometric identities (e.g., cos 3θ = 4 cos³θ − 3 cos θ), and to factor polynomials such as xⁿ−1 over the reals by pairing conjugate roots. A common examiner twist asks for the value of Σ cos(2πk/n) or Σ sin(2πk/n) over a subset of k; the geometric symmetry often reduces the sum to a simple closed form without heavy computation.

Discriminant Geometry and Nature of Roots

The discriminant Δ = b² − 4ac of a quadratic ax² + bx + c = 0 determines not only the reality of roots but also their geometric relationship to the parabola y = ax² + bx + c. When Δ > 0, the parabola cuts the x‑axis at two distinct points; the distance between the roots is √Δ/|a|. When Δ = 0, the vertex touches the axis, giving a double root at x = −b/(2a). When Δ < 0, the parabola lies entirely above (a>0) or below (a<0) the axis, and the roots are a complex conjugate pair with real part −b/(2a) and imaginary part ±√|Δ|/(2a). The sign of a together with Δ also decides the sign of the quadratic for all x: if a>0 and Δ<0, the expression is positive for every real x; if a<0 and Δ<0, it is negative everywhere. In optimisation problems, the minimum (or maximum) value of the quadratic is (4ac−b²)/(4a) = −Δ/(4a). Examiners frequently combine discriminant conditions with inequalities on the roots — for instance, “both roots lie in (1,3)” translates to three simultaneous constraints: Δ ≥ 0, f(1) and f(3) have the same sign as a, and the vertex x‑coordinate lies between 1 and 3. Mastering this translation from algebraic conditions to geometric picture is essential for rapid, error‑free solving.

Technique: Using Roots of Unity to Evaluate Sums
Find the value of Σₖ₌₁ⁿ⁻¹ cos(2πk/n) for integer n ≥ 2.
The nth roots of unity are zₖ = cos(2πk/n) + i sin(2πk/n) for k = 0,…,n−1. Their sum is Σₖ₌₀ⁿ⁻¹ zₖ = 0. Separating real and imaginary parts gives Σₖ₌₀ⁿ⁻¹ cos(2πk/n) = 0 and Σₖ₌₀ⁿ⁻¹ sin(2πk/n) = 0. The term for k = 0 is cos 0 = 1, sin 0 = 0. Therefore Σₖ₌₁ⁿ⁻¹ cos(2πk/n) = −1. The answer is −1 for every n ≥ 2.
Exam‑Day Strategy
When a problem asks for a symmetric sum of trigonometric terms with equally spaced angles, immediately check whether the angles correspond to roots of unity. Writing the sum as the real part of a geometric series of complex exponentials often collapses the computation to a single line. Keep the identity Σₖ₌₀ⁿ⁻¹ ei2πk/n = 0 at the front of your mental toolkit.

Generating Functions for Sequences and Series

A generating function encodes an infinite sequence {aₙ} as the coefficients of a formal power series G(x) = Σₙ₌₀^∞ aₙ xⁿ. Ordinary generating functions (OGF) suit combinatorial sequences where order matters; exponential generating functions (EGF) Σ aₙ xⁿ/n! are natural for labelled structures. The OGF of the constant sequence 1,1,1,… is 1/(1−x); the OGF of the natural numbers 0,1,2,… is x/(1−x)². Operations on sequences translate into algebraic operations on generating functions: addition corresponds to termwise sum, convolution (Cauchy product) corresponds to multiplication, and shifting the index corresponds to multiplication by x or division by x. The binomial theorem gives (1−x)−k = Σₙ₌₀^∞ C(n+k−1, k−1) xⁿ, which yields the formula for combinations with repetitions. For linear recurrences with constant coefficients, the generating function is rational; partial‑fraction decomposition then provides a closed form for aₙ. A classic example is the Fibonacci recurrence Fₙ = Fₙ₋₁ + Fₙ₋₂ with F₀=0, F₁=1. Its OGF is x/(1−x−x²); factoring the denominator gives the Binet formula Fₙ = (φⁿ − ψⁿ)/√5 where φ,ψ = (1±√5)/2. Examiners often ask for the coefficient of xⁿ in a rational function, which reduces to finding the partial‑fraction expansion and reading off the geometric‑series coefficients.

Permutation Groups and Cycle Decomposition

Every permutation of a finite set can be written uniquely (up to order of cycles) as a product of disjoint cycles. A cycle of length k contributes (k−1) transpositions to the parity of the permutation; thus a permutation is even iff the number of even‑length cycles in its decomposition is even. The sign of a permutation, sgn(σ) = (−1)n−c(σ) where c(σ) is the number of cycles (including 1‑cycles), determines whether the permutation belongs to the alternating group Aₙ. The order of a permutation is the least common multiple of its cycle lengths. Conjugacy classes in Sₙ are exactly the sets of permutations with the same cycle‑type (multiset of cycle lengths). This classification underpins counting problems: the number of permutations with a given cycle‑type is n! divided by the product over each cycle length ℓ of ℓm_ℓ m_ℓ! where m_ℓ is the number of cycles of length ℓ. Burnside’s lemma (the Cauchy‑Frobenius orbit‑counting theorem) uses the cycle structure of group actions to count distinct colourings or arrangements up to symmetry. In competitive problems, recognising that a permutation’s cycle decomposition directly yields its order, parity, and centraliser size allows rapid answers to questions like “How many permutations of {1,…,7} have order exactly 6?” — one enumerates cycle‑types whose LCM is 6 (e.g., a 6‑cycle, a 3‑cycle plus a 2‑cycle, etc.) and applies the formula above.

Matrix Rank, Nullity, and Linear Transformations

The rank of a matrix A (denoted ρ(A)) is the dimension of its column space, equal to the dimension of its row space. The nullity ν(A) is the dimension of the solution space of Ax = 0. The rank‑nullity theorem states ρ(A) + ν(A) = n, where n is the number of columns. For a linear transformation T: V → W represented by A relative to chosen bases, ρ(A) = dim Im(T) and ν(A) = dim Ker(T). Elementary row operations preserve the row space and the nullspace, so Gaussian elimination to row‑echelon form reveals both rank (number of pivots) and a basis for the nullspace (free variables). The determinant of a square matrix is non‑zero iff the matrix has full rank (ρ = n). For rectangular matrices, the rank determines the consistency of linear systems: Ax = b has a solution iff rank(A) = rank([A|b]). If a solution exists, the solution set is an affine subspace of dimension ν(A). In problems involving parameterised families of matrices, the rank can drop at special parameter values; tracking these values via minors or determinant conditions is a standard technique. The singular value decomposition (SVD) and the concept of matrix norm are beyond the core syllabus but the rank‑nullity relationship remains the backbone of all linear‑algebra questions in the examination.

  • Assuming that the sum of all nth roots of unity is zero for every n, forgetting that the root 1 is included and the required sum may exclude it.
  • Misapplying the discriminant sign test for root location without checking the vertex condition when both roots must lie in a given interval.
  • Confusing ordinary and exponential generating functions, leading to incorrect coefficient extraction for labelled versus unlabelled structures.
  • Overlooking that disjoint cycles commute, so the order of a permutation is the LCM of cycle lengths, not the sum.
  • Treating rank as the number of non‑zero rows in any echelon form, ignoring that row‑echelon form must be reduced to identify pivots correctly.
  • Forgetting that the nullity of a non‑square matrix is defined with respect to the number of columns, not rows.
  • Neglecting to verify that a parameter value making a determinant zero actually reduces the rank, rather than merely making a minor vanish while the rank stays full.

Loci and Transformations in the Complex Plane

The geometric interpretation of complex numbers turns algebraic conditions into familiar curves. The equation |z − z₀| = r describes a circle centred at z₀ with radius r. The equation |z − z₁| = |z − z₂| is the perpendicular bisector of the segment joining z₁ and z₂. More generally, |z − z₁| = k|z − z₂| with k > 0, k ≠ 1 yields an Apollonius circle. Arguments give half‑lines: arg(z − z₀) = θ is a ray from z₀ making angle θ with the positive real axis. Inequalities such as |z − z₁| < |z − z₂| define open half‑planes.

Transformations of the form w = (az + b)/(cz + d) with ad − bc ≠ 0 are Möbius (linear fractional) maps. They send circles and lines to circles and lines, preserve angles (conformal), and map the extended complex plane onto itself. Special cases: translation w = z + b, rotation and scaling w = az (a ≠ 0), inversion w = 1/z. The image of a line not passing through the origin under inversion is a circle through the origin; a circle through the origin becomes a line. Composition of Möbius maps corresponds to matrix multiplication of the associated 2×2 matrices [[a, b], [c, d]] up to a non‑zero scalar factor.

Problems often ask for the locus of z satisfying |z − 1| = 2|z + 1| or the image of the line Re(z) = 1 under w = (z − i)/(z + i). The standard technique: substitute z = x + iy, simplify to a Cartesian equation, identify the curve, then apply the transformation algebraically or geometrically. For Möbius maps, find images of three points (e.g., intersections with axes and the point at infinity) to determine the image circle or line uniquely.

Key Results

  • The cross‑ratio (z₁, z₂; z₃, z₄) = (z₁−z₃)(z₂−z₄)/((z₁−z₄)(z₂−z₃)) is invariant under Möbius transformations.
  • A Möbius map is uniquely determined by the images of three distinct points.
  • The unit circle |z| = 1 is mapped to itself by maps of the form w = eiθ(z − α)/(1 − αz) with |α| < 1 (Blaschke factors).

Parameter Dependent Quadratics and Root Location

When a quadratic f(x) = ax² + bx + c contains a parameter k, the nature and position of its roots change with k. The discriminant Δ(k) = b² − 4ac is a polynomial in k; solving Δ(k) ≥ 0 gives the parameter range for real roots. For both roots to lie in an interval (α, β), three conditions must hold simultaneously: (i) Δ ≥ 0, (ii) the vertex x_v = −b/(2a) satisfies α < x_v < β, (iii) f(α) and f(β) have the same sign as a (i.e., a·f(α) > 0 and a·f(β) > 0). If the interval is unbounded, the corresponding endpoint condition is dropped.

Vieta’s relations x₁ + x₂ = −b/a, x₁x₂ = c/a translate root‑location problems into inequalities on the coefficients. For example, both roots positive ⇔ −b/a > 0 and c/a > 0 together with Δ ≥ 0. When the parameter appears linearly in the coefficients, the feasible set for k is typically an interval or union of intervals obtained by intersecting the solution sets of the individual inequalities.

A common twist: the quadratic is the denominator of a rational function, and the problem asks for the range of the function. Setting y = (px²+qx+r)/(ax²+bx+c) and cross‑multiplying yields a quadratic in x whose discriminant must be non‑negative for real x. This gives a quadratic inequality in y whose solution is the required range. The same discriminant method works for finding the range of expressions like (x²+2x+3)/(x²+4x+5).

Systematic Checklist

  1. Write the quadratic in standard form with parameter isolated.
  2. Compute the discriminant as a function of the parameter.
  3. Apply vertex condition if both roots must lie in a finite interval.
  4. Evaluate the quadratic at the interval endpoints.
  5. Intersect all parameter intervals; watch for strict vs. non‑strict inequalities when roots coincide with endpoints.
Worked Example: Parameter Range for Roots in (1, 3)
Find all real values of k for which the quadratic f(x) = x² − (k+2)x + (k+1) has both roots strictly between 1 and 3.

Step 1: Discriminant Δ = (k+2)² − 4(k+1) = k² + 4k + 4 − 4k − 4 = k² ≥ 0 for all real k. So real roots exist for every k.

Step 2: Vertex x_v = (k+2)/2. Condition 1 < x_v < 3 gives 1 < (k+2)/2 < 3 ⇒ 2 < k+2 < 6 ⇒ 0 < k < 4.

Step 3: f(1) = 1 − (k+2) + (k+1) = 0. Since we need roots strictly between 1 and 3, f(1) must have the same sign as a (=1) and be non‑zero. Here f(1)=0 means 1 is a root for all k, violating strict inequality. Therefore no value of k satisfies the condition.

Answer: Empty set.

Exam‑Day Strategy
When a parameter appears in a quadratic, always compute the discriminant first; it often factors nicely. Then write down the vertex and endpoint conditions mechanically — missing the vertex condition is the most frequent error. If f(endpoint) = 0, the root lies exactly on the boundary, so strict inequality fails. Keep a mental checklist: Δ, vertex, f(α), f(β).

Convergence Tests and Summation of Infinite Series

An infinite series Σ aₙ converges if its sequence of partial sums approaches a finite limit. The nth‑term test: if lim aₙ ≠ 0, the series diverges. For positive series, the comparison test compares with a known p‑series Σ 1/n^p (converges iff p > 1). The limit comparison test uses lim aₙ/bₙ = L with 0 < L < ∞ to transfer convergence. The ratio test examines lim |aₙ₊₁/aₙ| = ρ; convergence for ρ < 1, divergence for ρ > 1, inconclusive for ρ = 1. The root test uses lim |aₙ|1/n with the same criteria.

Alternating series Σ (−1)ⁿ bₙ with bₙ ≥ 0 converge if bₙ decreases to zero (Leibniz test). Absolute convergence (Σ |aₙ| converges) implies convergence; conditional convergence occurs when the series converges but not absolutely. Power series Σ cₙ (x−x₀)ⁿ have a radius of convergence R = 1/limsup |cₙ|1/n (Cauchy–Hadamard). Within |x−x₀| < R the series converges absolutely; on the boundary each point must be checked separately.

Summation of known series: geometric Σ rⁿ = 1/(1−r) for |r| < 1; telescoping series where terms cancel pairwise; series derived from Taylor expansions such as e^x = Σ xⁿ/n!, ln(1+x) = Σ (−1)ⁿ⁺¹ xⁿ/n for −1 < x ≤ 1, arctan x = Σ (−1)ⁿ x2n+1/(2n+1). Differentiation or integration of a power series term‑by‑term within its radius of convergence yields new sums. For example, integrating the geometric series gives −ln(1−x) = Σ xⁿ/n.

Typical Problem Patterns

  • Find the radius and interval of convergence of Σ (n! xⁿ)/nⁿ using ratio test.
  • Determine whether Σ (−1)ⁿ (ln n)/n converges absolutely, conditionally, or diverges.
  • Evaluate Σ n/2ⁿ by differentiating the geometric series Σ xⁿ = 1/(1−x) and setting x = 1/2.

Multinomial Theorem and Generalised Binomial Coefficients

The multinomial theorem expands (x₁ + x₂ + … + x_m)^n as a sum over all m‑tuples of non‑negative integers (k₁,…,k_m) with k₁+…+k_m = n: Σ (n!/(k₁! k₂! … k_m!)) x₁k₁ x₂k₂ … x_mk_m. The coefficient n!/(k₁! … k_m!) is the multinomial coefficient, counting the number of ways to arrange n objects with k_i of type i. It generalises the binomial coefficient C(n, k) = n!/(k!(n−k)!).

For real exponent α (not necessarily a non‑negative integer), the binomial series (1+x)^α = Σk=0^∞ C(α, k) x^k converges for |x| < 1, where the generalised binomial coefficient is C(α, k) = α(α−1)…(α−k+1)/k!. This yields expansions such as (1−x)−1/2 = Σ C(2k, k) x^k / 4^k and (1+x)−2 = Σ (−1)^k (k+1) x^k. The series terminates when α is a non‑negative integer, reproducing the finite binomial theorem.

Applications: coefficient extraction in generating functions, probability (multinomial distribution), and combinatorial identities. For instance, the coefficient of x^r in (1+x+x²)^n equals the number of ways to write r as a sum of n numbers each 0, 1, or 2, which is Σj C(n, j) C(n−j, r−2j). The generalised binomial theorem also provides the expansion of (a+b)^α for non‑integer α by factoring out the larger term.

Useful Identities

  • C(−n, k) = (−1)^k C(n+k−1, k) (negative integer upper index).
  • C(1/2, k) = (−1)k−1 (2k−3)!! / (2^k k!) for k ≥ 1.
  • Vandermonde’s convolution: Σ C(r, k) C(s, n−k) = C(r+s, n).

Eigenvalues, Eigenvectors and Diagonalisation of Matrices

For a square matrix A, a scalar λ is an eigenvalue if there exists a non‑zero vector v such that Av = λv. The eigenvalues are the roots of the characteristic polynomial p(λ) = det(A − λI). The set of all eigenvectors for a given λ together with the zero vector forms the eigenspace E_λ = Ker(A − λI); its dimension is the geometric multiplicity of λ. The algebraic multiplicity is the multiplicity of λ as a root of p(λ). Always geometric ≤ algebraic.

A matrix is diagonalisable iff there exists a basis of eigenvectors, equivalently iff the sum of geometric multiplicities equals the matrix size n. A sufficient condition: A has n distinct eigenvalues. For real symmetric (or complex Hermitian) matrices, the spectral theorem guarantees orthogonal diagonalisation: A = QΛQ^T with Q orthogonal and Λ diagonal containing the real eigenvalues. The Cayley‑Hamilton theorem states that every matrix satisfies its own characteristic equation: p(A) = 0. This allows expressing high powers A^k as a linear combination of I, A, …, An−1.

Applications: solving systems of linear differential equations dx/dt = Ax via x(t) = eAtx(0); computing matrix functions; quadratic forms x^T A x where diagonalisation removes cross terms. The matrix exponential eAt can be evaluated using diagonalisation or the Jordan form when A is not diagonalisable.

Step‑by‑Step Diagonalisation

  1. Compute the characteristic polynomial det(A − λI).
  2. Find all eigenvalues (roots).
  3. For each eigenvalue, solve (A − λI)v = 0 to obtain a basis of the eigenspace.
  4. If total number of independent eigenvectors = n, form P with eigenvectors as columns; then P−1AP = diag(λ₁,…,λ_n).
  5. If not, the matrix is defective; proceed to Jordan canonical form (beyond core syllabus but useful for theory).
  • Assuming that a quadratic with parameter always has real roots for all parameter values without checking the discriminant sign.
  • Forgetting the vertex condition when both roots must lie in a finite interval, leading to an over‑estimated parameter range.
  • Applying the ratio test to a series with factorial terms but mis‑simplifying the ratio, especially when n! appears in both numerator and denominator.
  • Confusing the multinomial coefficient with the product of binomial coefficients; the correct coefficient is n!/(k₁!…k_m!).
  • Treating the generalised binomial series (1+x)^α as valid for all x when α is not a non‑negative integer; the radius of convergence is 1.
  • Assuming a matrix with repeated eigenvalues is automatically non‑diagonalisable; it may still be diagonalisable if geometric multiplicity equals algebraic multiplicity.
  • Neglecting to verify that the eigenvectors obtained are linearly independent before forming the diagonalising matrix P.
  • Review these traps before the exam to avoid common mistakes.

Complex Numbers in Plane Geometry: Rotation, Translation, and Inversion

Complex numbers provide a compact algebraic model for Euclidean plane geometry. A point (x, y) corresponds to z = x + iy. Addition of a constant w translates the plane by the vector w. Multiplication by a unit complex number eiθ rotates the plane about the origin through angle θ. The composition of a rotation and a translation is a direct similarity: z ↦ a z + b with a ≠ 0. If |a| = 1 the map is an isometry (rotation + translation); if a is real and positive it is a homothety (scaling) combined with translation. Inversion in the unit circle is expressed by z ↦ 1/ z (or z ↦ 1/z for points on the circle). More generally, a Möbius transformation z ↦ (α z + β)/(γ z + δ) with αδ − βγ ≠ 0 maps generalized circles (lines and circles) to generalized circles and preserves angles. The cross‑ratio (z₁, z₂; z₃, z₄) = (z₁−z₃)(z₂−z₄)/((z₁−z₄)(z₂−z₃)) is invariant under Möbius maps. These facts turn many geometric locus problems into algebraic equations. For instance, the condition that z lies on a circle with centre c and radius r is |z − c| = r, which expands to z z − c z − c z + |c|² − r² = 0. The equation of a line through points a and b is (z−a)/(z−a) = (b−a)/(b−a) (real ratio). Using these forms, one can derive the equation of the perpendicular bisector, the angle bisector, or the Apollonius circle without coordinate bashing. A classic application: the locus of z such that arg((z−z₁)/(z−z₂)) = θ is an arc of a circle through z₁ and z₂ subtending angle θ. The full circle (excluding the chord) corresponds to the two possible orientations. This technique is indispensable for problems that ask for the region defined by inequalities like |z−z₁|/|z−z₂| = k (Apollonius circle) or Re((z−a)/(z−b)) > 0 (half‑plane). Mastery of these transformations allows a student to convert a geometric description into a simple algebraic condition and vice‑versa, often reducing a multi‑step coordinate geometry problem to a few lines of complex algebra.

Advanced Inequalities: Cauchy‑Schwarz, AM‑GM, Jensen, and Rearrangement

Inequalities form the backbone of optimisation and estimation in algebra. The Cauchy‑Schwarz inequality in its simplest form states (∑ a_i b_i)² ≤ (∑ a_i²)(∑ b_i²) for real sequences, with equality iff the vectors are linearly dependent. Its integral analogue and the Engel form ∑ (x_i² / a_i) ≥ (∑ x_i)² / (∑ a_i) (a_i > 0) are frequent tools for summing fractions. The AM‑GM inequality (arithmetic mean ≥ geometric mean) for non‑negative numbers x₁,…,x_n reads (x₁+…+x_n)/n ≥ (x₁⋯x_n)1/n, equality when all x_i are equal. Weighted AM‑GM extends this to ∑ w_i x_i ≥ ∏ x_iw_i for weights w_i > 0, ∑ w_i = 1. Jensen’s inequality applies to convex functions: f(∑ w_i x_i) ≤ ∑ w_i f(x_i) for convex f, reversed for concave f. Since x ↦ x^p is convex for p ≥ 1 or p ≤ 0 and concave for 0 ≤ p ≤ 1, Jensen yields power‑mean inequalities. The Rearrangement inequality states that for similarly sorted sequences a₁ ≤ … ≤ a_n and b₁ ≤ … ≤ b_n, the sum ∑ a_i b_i is maximal, while the oppositely sorted sum is minimal. Chebyshev’s inequality (a consequence of Rearrangement) gives (1/n)∑ a_i b_i ≥ ((1/n)∑ a_i)((1/n)∑ b_i) when both sequences are similarly sorted. Hölder’s inequality generalises Cauchy‑Schwarz: ∑ |x_i y_i| ≤ (∑ |x_i|^p)1/p (∑ |y_i|^q)1/q with 1/p + 1/q = 1. Minkowski’s inequality is the triangle inequality for ℓ^p norms. These inequalities are not isolated; they interconnect. For example, Cauchy‑Schwarz follows from AM‑GM applied to (a_i²/∑ a_j²) + (b_i²/∑ b_j²) ≥ 2|a_i b_i|/√(∑ a_j² ∑ b_j²). In contest problems, a typical strategy is to homogenise the inequality, then apply a known inequality after a clever substitution (e.g., let a = x/y, b = y/z, c = z/x). The method of Lagrange multipliers provides a calculus backup, but algebraic proofs using the above inequalities are preferred for their elegance and because they avoid differentiability assumptions. A common trap is to apply AM‑GM to terms that are not guaranteed non‑negative, or to forget the equality condition when the problem asks for the maximum or minimum value. Another subtlety: Jensen requires the function to be convex on the entire interval containing all x_i; if the domain is split, one must use Karamata’s inequality or majorisation theory.

Technique: Homogenisation and Cauchy‑Schwarz
Let a, b, c be positive real numbers. Prove that (a/(b+c)) + (b/(c+a)) + (c/(a+b)) ≥ 3/2.
The inequality is homogeneous of degree 0. Multiply each term by (a+b+c)/(a+b+c) to obtain ∑ a(a+b+c)/((b+c)(a+b+c)). By Cauchy‑Schwarz in Engel form: ∑ a²/(a(b+c)) ≥ (a+b+c)² / ∑ a(b+c). The denominator ∑ a(b+c) = 2(ab+bc+ca). So the left side ≥ (a+b+c)² / (2(ab+bc+ca)). It remains to show (a+b+c)² ≥ 3(ab+bc+ca), which is equivalent to a²+b²+c² ≥ ab+bc+ca, true by rearrangement or by ½∑(a−b)² ≥ 0. Equality holds when a = b = c.
Exam‑Day Strategy
When faced with a symmetric inequality in positive variables, first check homogeneity. If it is homogeneous, you may normalise (e.g., set a+b+c = 1 or abc = 1) to simplify algebra. Then scan for a direct application of Cauchy‑Schwarz (Engel form), AM‑GM, or Jensen. If the expression contains fractions with sums in denominators, Engel form is often the quickest route. Write down the equality condition early; it guides the choice of weights or the substitution that makes terms equal.

Polynomial Equations: Vieta’s Relations, Newton’s Sums, and Discriminants of Higher Degree

For a monic polynomial P(x) = x^n + an-1 xn-1 + … + a1 x + a0 with roots r1,…,r_n (counted with multiplicity), Vieta’s formulas give elementary symmetric sums: e1 = ∑ r_i = −an-1, e2 = ∑i<j</sub> r_i r_j = an-2, …, e_n = (−1)^n a0. These relations allow one to express any symmetric polynomial in the roots as a polynomial in the coefficients. Newton’s sums S_k = ∑i=1^n r_i^k satisfy the recurrence S_k + an-1 Sk-1 + … + an-k+1 S1 + k an-k = 0 for 1 ≤ k ≤ n, and for k > n, S_k + an-1 Sk-1 + … + a0 Sk-n = 0. This recurrence computes power sums efficiently without finding the roots. The discriminant Δ = ∏i<j</sub> (r_i − r_j)² is a polynomial in the coefficients; for a quadratic Δ = b² − 4ac, for a cubic Δ = 18abcd − 4b³d + b²c² − 4ac³ − 27a²d² (with a=1 for monic). Δ > 0 implies all roots real and distinct (for real coefficients); Δ < 0 implies one real and two non‑real complex conjugates for cubic; Δ = 0 indicates a repeated root. For quartics and higher, the sign of Δ still distinguishes between distinct and repeated roots, but the real/complex classification requires Sturm’s theorem or Descartes’ rule of signs. The resultant of two polynomials eliminates a variable and detects common roots; it is the determinant of the Sylvester matrix. These tools are essential for problems that ask: “Find all values of k for which the polynomial has a double root” or “Express ∑ 1/(r_i − r_j) in terms of coefficients”. A typical approach: set P(x) and P'(x) have a common root ⇒ resultant = 0 ⇒ condition on parameters. Newton’s sums also help evaluate ∑ 1/r_i^k by considering the reciprocal polynomial. Mastery of these algebraic identities turns root‑location problems into coefficient manipulations, avoiding numerical approximation.

Linear Recurrences and Characteristic Equations: Solving Homogeneous and Non‑Homogeneous Recurrences

A linear recurrence of order d with constant coefficients has the form a_n = c1 an-1 + c2 an-2 + … + c_d an-d for n ≥ d. The characteristic polynomial is λ^d − c1 λd-1 − … − c_d = 0. If the roots λ1,…,λ_d are distinct, the general solution is a_n = ∑i=1^d A_i λ_i^n, where constants A_i are determined by initial conditions. If a root λ has multiplicity m, the corresponding terms are (A0 + A1 n + … + Am-1 nm-1) λ^n. For non‑homogeneous recurrences a_n = c1 an-1 + … + c_d an-d + f(n), the general solution is the sum of the homogeneous solution and a particular solution. The method of undetermined coefficients works when f(n) is a polynomial, exponential, or product thereof: guess a form similar to f(n) multiplied by n^s where s is the multiplicity of the characteristic root matching the exponential base. For example, if f(n) = n2 3^n and 3 is a root of multiplicity 1, try (An2 + Bn + C) n 3^n. The annihilator method (applying the characteristic operator to f(n)) systematises this guess. Generating functions provide an alternative: let A(x) = ∑ a_n x^n; multiply the recurrence by x^n and sum to obtain an algebraic equation for A(x), then expand by partial fractions. This method automatically handles initial conditions and works even when the characteristic polynomial has complex roots. A classic example is the Fibonacci recurrence F_n = Fn-1 + Fn-2 with F0 = 0, F1 = 1. The characteristic equation λ² − λ − 1 = 0 gives λ = (1 ± √5)/2, leading to Binet’s formula F_n = (φ^n − ψ^n)/√5. For non‑homogeneous terms like n 2^n, the generating function denominator acquires a factor (1−2x)², and partial fractions yield the particular solution. Understanding the interplay between characteristic roots and the form of f(n) is crucial for deriving closed forms quickly in examinations.

Matrix Decompositions: LU, QR, and Singular Value Decomposition

Matrix factorisations reveal structural properties and enable efficient computation. LU decomposition writes a square matrix A as A = LU where L is lower triangular with unit diagonal and U is upper triangular. It exists if all leading principal minors are non‑zero (or with partial pivoting PA = LU). LU is the workhorse for solving linear systems: solve Ly = b then Ux = y. QR decomposition expresses A (m×n, m ≥ n) as A = QR with Q orthogonal (Q^T Q = I) and R upper triangular. It is obtained via Gram‑Schmidt orthogonalisation or Householder reflections. QR is numerically stable and underlies the QR algorithm for eigenvalues. The singular value decomposition (SVD) factorises any real m×n matrix as A = U Σ V^T, where U (m×m) and V (n×n) are orthogonal, and Σ is diagonal with non‑negative singular values σ1 ≥ … ≥ σ_r > 0 (r = rank). The columns of U are eigenvectors of AA^T, columns of V are eigenvectors of A^T A, and σ_i² are the non‑zero eigenvalues of both. SVD provides the best low‑rank approximation (Eckart‑Young theorem): the rank‑k approximation A_k = ∑i=1^k σ_i u_i v_i^T minimises ‖A − B‖_F over rank‑k matrices B. The condition number κ(A) = σ1/σ_r measures sensitivity of linear systems. For symmetric positive definite matrices, Cholesky decomposition A = LL^T (L lower triangular) is more efficient than LU. The polar decomposition A = UP (U orthogonal, P symmetric positive semidefinite) separates rotation from stretching. These decompositions are not merely theoretical; they are the foundation of numerical linear algebra libraries (LAPACK, NumPy). In an exam context, you may be asked to compute the LU factors of a 3×3 matrix by hand, to find the QR factorisation of a 2×2 matrix using Gram‑Schmidt, or to interpret the singular values of a given matrix in terms of its action on the unit sphere. Knowing the algorithmic steps and the existence conditions (e.g., LU without pivoting requires non‑zero leading minors) prevents common errors such as dividing by zero during elimination.

  • Assuming that a symmetric matrix is always diagonalisable by an orthogonal matrix without verifying that it is real (complex Hermitian matrices require unitary diagonalisation).
  • Applying AM‑GM to terms that can be negative; the inequality only holds for non‑negative numbers.
  • Forgetting to multiply the particular solution guess by n^s when the forcing term matches a characteristic root of multiplicity s.
  • Using LU decomposition without pivoting on a matrix that has a zero leading principal minor, leading to division by zero.
  • Confusing the discriminant of a cubic with that of a quadratic; the cubic discriminant formula is more involved and its sign interpretation differs.
  • Treating the cross‑ratio as invariant under all complex functions; it is invariant only under Möbius transformations.
  • Neglecting to check the equality condition when an inequality problem asks for the maximum or minimum value.

Resultants and Discriminants: Elimination of Variables

The resultant of two polynomials f(x) and g(x) is a single polynomial in the coefficients that vanishes exactly when f and g share a common root. For f(x)=anxn+…+a0 and g(x)=bmxm+…+b0, the resultant Res(f,g) is the determinant of the (n+m)×(n+m) Sylvester matrix formed by the coefficients of f and g. This determinant is homogeneous of degree m in the ai and degree n in the bj. A fundamental property: Res(f,g)=anm∏ig(αi)= (−1)nmbmn∏jf(βj), where αi and βj are the roots of f and g. The discriminant Δ(f) is (up to sign) the resultant of f and its derivative f′; it vanishes iff f has a multiple root. For a quadratic ax2+bx+c, Δ=b2−4ac. For a cubic x3+px+q, Δ=−4p3−27q2. Resultants enable elimination: given two equations in x and y, treat them as polynomials in y with coefficients in x; the resultant in y yields a single polynomial in x whose roots are the x‑coordinates of the common solutions. This technique underlies Gröbner basis computations and is a standard tool for solving systems of polynomial equations in competitive problems.

Key Computational Steps

  1. Write both polynomials in the same variable with symbolic coefficients.
  2. Construct the Sylvester matrix: first m rows contain shifted coefficients of f, next n rows contain shifted coefficients of g.
  3. Compute the determinant (use block‑matrix tricks or expansion by minors for small degrees).
  4. Factor the resultant to read off conditions for common roots.

When the coefficients are integers, the resultant is an integer; its prime factors give information about common roots modulo primes. In examinations, a typical question asks for the condition on parameters a, b, c such that two given quadratics have a common root — compute Res and set it to zero.

Jordan Canonical Form and Generalised Eigenvectors

Not every square matrix is diagonalisable. The Jordan canonical form (JCF) provides a nearly diagonal representation that exists for every matrix over an algebraically closed field. For a matrix A, let λ be an eigenvalue with algebraic multiplicity m and geometric multiplicity g (dimension of the eigenspace). The JCF consists of g Jordan blocks Jk(λ) of sizes k1≥k2≥…≥kg with Σki=m. Each block is a k×k matrix with λ on the diagonal, 1 on the super‑diagonal, and 0 elsewhere. The columns of the similarity matrix P are generalised eigenvectors: vectors v satisfying (A−λI)kv=0 but (A−λI)k−1v≠0. To construct P, start with a basis of the eigenspace (k=1). For each eigenvector v, extend a chain by solving (A−λI)w=v, (A−λI)u=w, etc., until the chain length equals the block size. The number of blocks of size at least s equals rank((A−λI)s−1)−rank((A−λI)s). This rank‑difference formula is a quick way to determine the block structure without solving linear systems repeatedly. JCF is unique up to permutation of blocks. Applications include computing matrix functions (exponential, powers) and solving systems of linear differential equations x′=Ax: the solution is eAtx(0), and eAt = P eJt P−1, where eJt is block‑diagonal with each block eλt times a polynomial in t.

Algorithm for JCF of a 3×3 Matrix

  1. Find the characteristic polynomial and its roots (eigenvalues).
  2. For each eigenvalue λ, compute ranks of (A−λI), (A−λI)2, … until the rank stabilises.
  3. Deduce block sizes from rank differences.
  4. Build chains of generalised eigenvectors by back‑substitution.
  5. Assemble P and verify P−1AP = J.

In exam problems, you may be given a matrix with a repeated eigenvalue and asked to decide whether it is diagonalisable; compute the dimension of the eigenspace. If it is less than the algebraic multiplicity, write down the JCF and a suitable P.

Worked Example: Jordan Form of a Defective Matrix
Let A = [[2,1,0],[0,2,1],[0,0,2]]. Find its Jordan canonical form and a matrix P such that P−1AP = J.
The characteristic polynomial is (2−λ)3, so λ=2 with algebraic multiplicity 3. Compute A−2I = [[0,1,0],[0,0,1],[0,0,0]]. Rank(A−2I)=2, so nullity = 1 → geometric multiplicity 1. Hence there is a single Jordan block of size 3. J = [[2,1,0],[0,2,1],[0,0,2]]. To build P, we need a chain v1, v2, v3 with (A−2I)v3=v2, (A−2I)v2=v1, (A−2I)v1=0. Choose v1 = e1 = (1,0,0)T. Solve (A−2I)v2=v1 → [[0,1,0],[0,0,1],[0,0,0]] (x,y,z)T = (1,0,0)T gives y=1, z=0, x free; take v2 = (0,1,0)T. Solve (A−2I)v3=v2 → y=0, z=1, x free; take v3 = (0,0,1)T. Then P = [v1 v2 v3] = I3. Indeed P−1AP = A = J. (Any invertible P formed by a valid chain works.)
Exam‑Day Strategy
When a matrix has a repeated eigenvalue, first check the rank of (A−λI). If rank = n−1, the matrix is diagonalisable; if rank ≤ n−2, it is defective and you must construct Jordan chains. Use the rank‑difference table to write down block sizes instantly, then pick the simplest chain (often standard basis vectors) to form P. This avoids solving large linear systems under time pressure.

Quadratic Forms, Sylvester’s Law of Inertia, and Definiteness

A quadratic form in n variables is a homogeneous polynomial of degree two: Q(x)=xTA x where A is a symmetric n×n matrix. Over ℝ, Sylvester’s law of inertia states that by a non‑singular linear change of variables x = P y, Q can be transformed to a diagonal form y12+…+yp2−yp+12−…−yp+q2 where p (positive index) and q (negative index) are invariants; the number of zero coefficients is the nullity r = n−p−q. The triple (p,q,r) is the signature of Q. Definiteness: Q is positive definite iff p=n (all eigenvalues of A > 0); negative definite iff q=n; indefinite iff p>0 and q>0; positive semidefinite iff q=0 and r>0. Principal minor criteria (Sylvester’s criterion): A is positive definite iff all leading principal minors are positive. For negative definiteness, the leading principal minors alternate in sign starting with negative. These tests are purely algebraic and avoid eigenvalue computation. Quadratic forms appear in optimisation (Hessian matrix), conic classification, and the second derivative test for multivariable functions. Over ℂ, every non‑degenerate quadratic form is equivalent to the sum of squares (signature (n,0,0)). Over finite fields, the classification involves the discriminant and the Hasse invariant.

Practical Checklist for a Given Symmetric Matrix

  1. Compute the leading principal minors Δ1, Δ2, …, Δn.
  2. If all Δk>0 → positive definite.
  3. If (−1)kΔk>0 for all k → negative definite.
  4. If neither holds but Δn≠0 → indefinite.
  5. If Δn=0 → semidefinite or degenerate; examine eigenvalues or complete the square.

Completing the square (Lagrange’s method) provides an explicit diagonalisation: repeatedly isolate a square term by grouping variables. This yields the transformation matrix P directly and is often faster than eigenvalue computation for hand calculations.

Advanced Combinatorial Identities: Stirling Numbers, Bell Numbers, and Inclusion–Exclusion

Stirling numbers of the first kind s(n,k) count permutations of n elements with exactly k cycles (signed version) or the unsigned version c(n,k)=|s(n,k)|. They satisfy the recurrence c(n,k)=c(n−1,k−1)+(n−1)c(n−1,k) with c(0,0)=1. Stirling numbers of the second kind S(n,k) count partitions of an n‑set into k non‑empty blocks, with recurrence S(n,k)=S(n−1,k−1)+k S(n−1,k). Bell numbers Bn=∑k=0n S(n,k) count all partitions of an n‑set. They obey Dobinski’s formula Bn = (1/e)∑k=0∞ kn/k! and the recurrence Bn+1=∑k=0n C(n,k) Bk. Inclusion–exclusion principle: for finite sets A1,…,Am, |⋃ Ai| = ∑|Ai| − ∑|Ai∩Aj| + ∑|Ai∩Aj∩Ak| − … + (−1)m−1|⋂ Ai|. A classic application is derangements: Dn = n! ∑k=0n (−1)k/k!. The principle also yields formulas for Stirling numbers: S(n,k) = (1/k!)∑j=0k (−1)k−j C(k,j) jn. In examinations, problems often ask for the number of onto functions from an m‑set to an n‑set (n! S(m,n)), or the coefficient of xk in (ex−1)n/n! (which is S(k,n)/n!). Mastery of these identities allows rapid conversion between sums, generating functions, and closed forms.

Useful Generating Functions

  • ∑n≥k S(n,k) xn/n! = (ex−1)k/k!.
  • ∑n≥k c(n,k) xn/n! = (−ln(1−x))k/k!.
  • Exponential generating function for Bell numbers: ∑ Bn xn/n! = eex−1.

When a problem involves sums of the form ∑ (−1)k C(n,k) (n−k)m, recognise it as n! S(m,n) (or zero if m<n). This recognition turns a lengthy computation into a one‑line answer.</p>

Matrix Functions: Exponential, Logarithm, and Applications to Differential Equations

For a square matrix A, the matrix exponential is defined by the convergent series eA = ∑k=0∞ Ak/k!. If A = P J P−1 is the Jordan decomposition, then eA = P eJ P−1, where eJ is block‑diagonal with each Jordan block Jk(λ) exponentiated to eλ times a polynomial in the nilpotent part: eJk(λ) = eλ [[1,1,1/2!,…,1/(k−1)!],[0,1,1,…,1/(k−2)!],…,[0,…,0,1]]. The matrix logarithm log(I+N) for nilpotent N (Nm=0) is the finite series N − N2/2 + N3/3 − … + (−1)m−1 Nm−1/(m−1). For a diagonalisable matrix with positive eigenvalues, log A = P diag(log λi) P−1. These functions solve linear systems x′ = A x: the fundamental matrix is eAt, and the solution with initial condition x(0)=x0 is x(t)=eAt x0. For non‑homogeneous systems x′ = A x + f(t), variation of parameters gives x(t)=eAt( x0 + ∫0t e−As f(s) ds ). In discrete time, powers An are obtained via the same Jordan form: An = P Jn P−1, where Jn has blocks λn times binomial coefficients. The Cayley‑Hamilton theorem allows reduction of any polynomial in A to degree < n, which is useful for computing eA without full Jordan form when n is small (e.g., 2×2 or 3×3). For a 2×2 matrix with distinct eigenvalues λ1, λ2, eA = (eλ1−eλ2)/(λ1−λ2) A + (λ1eλ2−λ2eλ1)/(λ1−λ2) I. This closed form is a favourite in time‑limited tests.

Checklist for Computing eA in Exams

  1. Find eigenvalues and their multiplicities.
  2. If diagonalisable, use spectral decomposition.
  3. If defective, write Jordan form and exponentiate each block.
  4. For 2×2 with repeated eigenvalue λ, use eA = eλ( I + (A−λI) ).
  5. Verify by checking that d/dt eAt = A eAt at t=0.

These techniques also apply to matrix trigonometric functions (sin A, cos A) via Euler’s formula, and to the matrix square root when A has no eigenvalues on the negative real axis.

  • Confusing the signed and unsigned Stirling numbers of the first kind; the sign alternates with n−k.
  • Applying Sylvester’s criterion to a non‑symmetric matrix; the test requires symmetry (or Hermitian).
  • Assuming a matrix with repeated eigenvalues is automatically non‑diagonalisable; check the eigenspace dimension first.
  • Forgetting that the matrix exponential of a nilpotent matrix terminates after finitely many terms.
  • Using the resultant of two polynomials without clearing common factors; a common factor makes the resultant zero identically.
  • Misapplying inclusion–exclusion by omitting the alternating signs or by double‑counting intersections of different sizes.
  • Treating the matrix logarithm as globally defined; it requires a branch cut and fails for matrices with eigenvalues on the negative real axis unless a specific branch is chosen.
