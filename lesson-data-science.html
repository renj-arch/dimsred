Mathematical Data Science — Dimensionality Reduction, Manifold Learning & the Kernel Method

Mathematical data science sits at the intersection of linear algebra, probability, optimization, and geometry. A central observation — the curse of dimensionality — says that volume grows exponentially with dimension, making naive estimation impossible in high p. Yet real data often clusters near a low-dimensional structure. The manifold hypothesis asserts that high-dimensional data (e.g., images, text, gene expression) lies on or near a low-dimensional manifold M ⊂ ℝ^p with intrinsic dimension d ≪ p. This insight drives methods like PCA (finding the best linear subspace), the kernel trick (implicitly mapping to a high-dimensional feature space via a positive-definite kernel), and nonlinear manifold learning (ISOMAP, LLE, Laplacian eigenmaps, t-SNE, UMAP). In compressed sensing, we recover a sparse signal from far fewer measurements than the ambient dimension using ℓ₁-minimization — the restricted isometry property guarantees exact recovery. Finally, the theory of neural networks provides universal approximation guarantees and the Barron space view shows that certain functions can be learned without the curse of dimensionality.

Part 1

📏 Dimensionality Reduction and PCA

Linear Dimension Reduction
The Data Matrix, Sample Covariance, and the Spectral Theorem
Let X ∈ ℝ^{n×p} be the data matrix with n observations and p features (typically n ≪ p or n ≈ p). The sample covariance matrix is Σ̂ = (1/n) X^T X (assuming centered data). Principal Component Analysis (PCA) seeks the first k eigenvectors of Σ̂ corresponding to the k largest eigenvalues. The optimization problem: max_{||v||=1} Var(Xv) = v^T Σ̂ v — the variance captured by projecting onto direction v. By the spectral theorem, Σ̂ = Σ λ_i u_i u_i^T with λ₁ ≥ λ₂ ≥ … ≥ λ_p ≥ 0, and the proportion of variance explained by the first k components is (Σ_{i=1}^k λ_i) / (Σ_{i=1}^p λ_i). The Eckart-Young theorem: PCA gives the optimal rank-k approximation to X in Frobenius norm — the truncated SVD X ≈ U_k Σ_k V_k^T solves min_{rank(A)=k} ||X − A||_F. Kernel PCA extends this: map data to a feature space via φ(x) so that ⟨φ(x_i), φ(x_j)⟩ = K(x_i, x_j) for a positive-definite kernel K (e.g., Gaussian RBF, polynomial). The kernel trick avoids explicitly computing φ by working directly with the Gram matrix K_{ij} = K(x_i, x_j). PCA is performed on the centered Gram matrix in feature space, enabling nonlinear dimensionality reduction.
PCA is the optimal linear dimensionality reduction method via the spectral decomposition of the covariance; the kernel trick generalizes PCA to nonlinear features without explicit computation.
Part 2

🌍 Manifold Learning

Nonlinear Dimension Reduction
ISOMAP, LLE, Laplacian Eigenmaps, t-SNE, and UMAP
The manifold hypothesis: data lies on or near a d-dimensional manifold M embedded in ℝ^p with d ≪ p. ISOMAP (Tenenbaum, de Silva, Langford 2000): construct a k-nearest-neighbor graph on the data, approximate geodesic distances by shortest paths via Dijkstra or Floyd-Warshall, then apply classical MDS (multidimensional scaling) to the geodesic distance matrix to find low-dimensional coordinates. Locally Linear Embedding (LLE) (Roweis-Saul 2000): reconstruct each point x_i as a linear combination of its neighbors, minimize ||x_i − Σ_j w_{ij} x_j||^2 subject to Σ_j w_{ij} = 1 (sparsity: w_{ij} = 0 if j not a neighbor), then find low-dimensional embeddings y_i preserving the reconstruction weights: min Σ_i ||y_i − Σ_j w_{ij} y_j||^2. Laplacian eigenmaps (Belkin-Niyogi 2003): construct the graph Laplacian L = D − W where W is the adjacency matrix, solve the generalized eigenvalue problem Lf = λ D f; the low-dimensional embedding is given by the eigenvectors corresponding to the smallest nonzero eigenvalues. t-SNE (van der Maaten-Hinton 2008): define pairwise similarities in high dimension as p_{j|i} ∝ exp(−||x_i − x_j||^2 / 2σ_i²), symmetrize to p_{ij}, and in low dimension define q_{ij} ∝ (1 + ||y_i − y_j||²)^{-1} (the heavy-tailed t-distribution avoids the crowding problem); minimize the Kullback-Leibler divergence KL(P||Q) = Σ_{i≠j} p_{ij} log(p_{ij}/q_{ij}). UMAP (McInnes-Healy 2018): constructs a fuzzy simplicial set representation of the data, then optimizes the cross-entropy between the high- and low-dimensional fuzzy topological representations, resulting in a faster and more scalable embedding than t-SNE.
Manifold learning methods exploit local geometry to recover global low-dimensional structure; each method balances local versus global fidelity differently.
Part 3

🧮 Compressed Sensing and the Restricted Isometry Property

Sparse Recovery
ℓ₁-Minimization, RIP, and the Donoho-Tanner Phase Transition
The compressed sensing problem: recover a signal x ∈ ℝⁿ from m ≪ n linear measurements y = Ax where A ∈ ℝ^{m×n} is the measurement matrix. When x is k-sparse (only k non-zero entries), we can hope to recover it exactly. The naive ℓ₀-minimization (min ||x||₀ subject to Ax = y) is NP-hard. The basis pursuit replaces ℓ₀ with ℓ₁: min ||x||₁ subject to Ax = y — a convex optimization problem solvable via linear programming. The restricted isometry property (RIP): a matrix A satisfies RIP of order k with constant δ ∈ (0,1) if for all k-sparse vectors v, (1−δ)||v||₂² ≤ ||Av||₂² ≤ (1+δ)||v||₂². The Candès-Romberg-Tao theorem: if A satisfies the RIP with δ < √2−1 (≈0.414), then ℓ₁-minimization recovers any k-sparse x exactly. For the noisy case y = Ax + e with ||e||₂ ≤ ε, the recovered x̂ satisfies ||x̂ − x||₂ ≤ C·ε. Random Gaussian matrices (each entry i.i.d. N(0,1/m)) satisfy RIP with high probability when m ≥ C·k·log(n/k). More generally, sub-Gaussian and certain structured random matrices (partial Fourier, random rows of orthogonal matrices) also satisfy RIP. The Donoho-Tanner phase transition: for Gaussian random matrices and ℓ₁-minimization, there is a sharp boundary in the (δ = m/n, ρ = k/m) plane separating successful recovery (below the curve) from failure (above it), given by the function ρ(δ) = max{ρ : 1 − (δ/ρ) · ((1+ρ)/ρ · log(1+ρ) − (1−ρ)/ρ · log(1−ρ) − 1) > 0} — derived from the asymptotic analysis of the LASSO and linear programming.
Compressed sensing shows that sparse signals can be recovered from few linear measurements via ℓ₁-minimization, provided the measurement matrix satisfies the restricted isometry property.
Part 4

🔥 Neural Networks and Statistical Learning Theory

Deep Learning Theory
Universal Approximation, Barron Space, VC Dimension, and the Minimax Rate
A feed-forward neural network with L layers computes f(x) = W_L·σ(W_{L−1}·...·σ(W_1 x + b_1)...+ b_L), where σ is a nonlinear activation (e.g., ReLU, sigmoid). The universal approximation theorem (Cybenko 1989, Hornik 1991, Leshno 1993): a single hidden layer with enough units can approximate any continuous function on a compact set arbitrarily well, provided σ is non-polynomial. The Barron space (Barron 1993): functions f: ℝ^d → ℝ with finite Barron norm ||f||_B = ∫ ||ω||₁ |f̂(ω)| dω (where f̂ is the Fourier transform) can be approximated by a two-layer ReLU network with N units at rate O(1/√N) independent of dimension d — thus avoiding the curse of dimensionality. Klusowski and Barron (2018) refined this: the approximation error is O(1/N + (d/N)log N) for certain smooth functions. The bias-variance tradeoff: as model complexity increases, bias decreases but variance increases; the optimal model minimizes test error at the intersection. The Vapnik-Chervonenkis (VC) dimension measures the capacity of a hypothesis class H — the largest set of points that can be shattered by H. For linear classifiers in ℝ^d, VC(H) = d+1; for neural networks, VC-dimension grows with the number of parameters. The Rademacher complexity R_n(H) = E[sup_{h∈H} (1/n) Σ_{i=1}^n ε_i h(z_i)] gives sharper, distribution-dependent concentration bounds. The minimax rate is the optimal achievable error over a function class F: inf_{f̂} sup_{f∈F} E[||f̂ − f||²] ≍ n^{−2β/(2β+d)} for β-smooth functions in d dimensions — the curse of dimensionality is unavoidable without additional structure (like manifold structure, sparsity, or Barron-type smoothness). Lower bounds are proved via Fano's inequality (reducing estimation to hypothesis testing on a packing set), Le Cam's method (two-point testing), and Assouad's lemma (multiple binary testing).
Neural networks can approximate high-dimensional functions without curse of dimensionality under the Barron norm; the minimax rate formalizes the fundamental statistical limits of estimation.
