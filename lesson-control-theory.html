Control Theory — Shaping Dynamics Through Feedback

Control theory studies how to make dynamical systems behave as desired through feedback. It spans state-space models, controllability/observability, Lyapunov stability theory, optimal control (LQR, Pontryagin), estimation (Kalman filter), robust control (H∞), and nonlinear control (sliding mode, backstepping). It's the mathematics behind autonomous vehicles, robots, aircraft autopilots, and industrial process control.

"Control theory is the art of making systems behave — even when you don't have a perfect model."
— Karl Johan Åström
Part 1

⚙️ State-Space Models and Fundamental Properties

Representation
State-Space Realizations — Controllability and Observability
A linear system is dx/dt = Ax + Bu, y = Cx + Du, with state x ∈ ℝⁿ, input u ∈ ℝ^m, output y ∈ ℝ^p. The transfer function G(s) = C(sI−A)^{-1}B + D connects Laplace transforms. A system is controllable if there exists u(t) steering any initial state to any final state in finite time — the controllability matrix [B AB A²B ... A^{n−1}B] must have full row rank n (Kalman's criterion). Observability means the initial state can be determined from inputs and outputs — the observability matrix [C; CA; ...; CA^{n−1}] has full column rank. The Hautus test: rank[A−λI B] = n for all eigenvalues λ (controllability), rank[A−λI; C] = n (observability). The Kalman decomposition splits the state space into controllable/observable, controllable/unobservable, uncontrollable/observable, and uncontrollable/unobservable subspaces.
Controllability tells you if you can steer the system; observability tells you if you can see what's happening inside.
Part 2

📊 Lyapunov Stability and Feedback Design

Stability
Lyapunov's Method — Proving Stability Without Solving
For dx/dt = f(x), an equilibrium x* is stable if nearby solutions stay nearby; asymptotically stable if they converge to x*. Lyapunov's second method: if there exists V(x) > 0 (positive definite) with dV/dt = ∇V·f ≤ 0 (negative semidefinite), then x* is stable. If dV/dt < 0 (negative definite), it's asymptotically stable. For linear systems dx/dt = Ax, stability is equivalent to all eigenvalues of A having negative real parts. The Lyapunov equation AᵀP + PA = −Q with P,Q > 0 gives a quadratic Lyapunov function V(x) = xᵀPx. State feedback u = −Kx places the closed-loop eigenvalues (pole placement) if (A,B) is controllable. The LQR (linear quadratic regulator) minimizes J = ∫(xᵀQx + uᵀRu) dt → u = −R^{-1}BᵀPx where P solves the algebraic Riccati equation AᵀP + PA − PBR^{-1}BᵀP + Q = 0.
Lyapunov functions are the energy of the system — if energy always decreases, the system is stable. LQR gives the optimal feedback.
Part 3

🔬 Estimation, Optimal Control, and the Kalman Filter

Estimation
The Kalman Filter — Optimal State Estimation from Noisy Measurements
The stochastic system dx = Ax dt + Bu dt + dw (process noise), dy = Cx dt + dv (measurement noise), with w,v Brownian motions with covariances Q_c and R. The Kalman-Bucy filter gives the optimal state estimate x̂: d x̂/dt = A x̂ + Bu + L(y − C x̂), where L = PCᵀR^{-1} and P solves the Riccati equation dP/dt = AP + PAᵀ − PCᵀR^{-1}CP + Q_c. The discrete Kalman filter alternates between prediction (time update) and correction (measurement update). The separation principle: for LQG (linear quadratic Gaussian) control, the optimal policy is to estimate with the Kalman filter then apply the LQR gain using the estimate — estimation and control separate. Pontryagin's maximum principle (PMP) gives necessary conditions for optimal control: the Hamiltonian H = L + λᵀf, with costate λ satisfying dλ/dt = −∂H/∂x and optimal u minimizing H pointwise.
The Kalman filter is the optimal way to combine noisy measurements with a model — it's why GPS works, rockets land, and robots navigate.
Part 4

⚡ Robust and Nonlinear Control

Uncertainty
Robust Control — Handling Model Uncertainty and Nonlinear Dynamics
Real systems have model uncertainty. The small-gain theorem: if the loop gain ∥G∥·∥K∥ < 1, the feedback system is stable. H∞ control minimizes the worst-case gain from disturbance to output — the ∞-norm ∥G∥_∞ = sup_ω σ̄(G(jω)). The structured singular value μ (D-K iteration) handles structured uncertainty. Sliding mode control drives the state to a surface s(x)=0 and keeps it there using discontinuous control — it's robust to matched uncertainties but causes chattering. Backstepping recursively designs controllers for strict-feedback systems using virtual controls. Adaptive control estimates unknown parameters online (MIT rule, Lyapunov-based MRAC). Model predictive control (MPC) solves a finite-horizon optimal control problem at each step, applying only the first control input — it handles constraints naturally. Reinforcement learning (RL) learns optimal policies from data — Q-learning (value-based) and policy gradient (actor-critic) extend control to unknown environments.
Robust control handles the gap between model and reality; nonlinear methods like sliding mode and backstepping tame complex dynamics.
