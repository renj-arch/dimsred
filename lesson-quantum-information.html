Quantum Information — Qubits, Entanglement, Teleportation, Quantum Gates & Error Correction

Part 1

🔄 Qubits and the Bloch Sphere

Qubits
The Qubit, the Bloch Sphere, and the Density Matrix
A qubit is a two-level quantum system |ψ⟩ = α|0⟩ + β|1⟩ where α, β ∈ ℂ and |α|² + |β|² = 1. The Bloch sphere representation: |ψ⟩ = cos(θ/2)|0⟩ + e^{iφ} sin(θ/2)|1⟩, where θ ∈ [0, π] is the polar angle and φ ∈ [0, 2π) is the azimuthal angle. Every pure state corresponds to a point on the Bloch sphere surface. The computational basis |0⟩ (north pole) and |1⟩ (south pole) are eigenstates of σ_z. The states |+⟩ = (|0⟩ + |1⟩)/√2 and |−⟩ = (|0⟩ − |1⟩)/√2 lie on the equator and are eigenstates of σ_x. The density matrix ρ = |ψ⟩⟨ψ| for a pure state and ρ = Σ pᵢ |ψᵢ⟩⟨ψᵢ| for a mixed state. The von Neumann entropy S(ρ) = −Tr(ρ log ρ) quantifies mixedness — zero for pure states, log d for maximally mixed d-dimensional states. The Pauli matrices σₓ, σ_y, σ_z form a basis for 2×2 Hermitian operators: ρ = ½(I + r · σ) where r is the Bloch vector (|r| ≤ 1). The measurement postulate: a projective measurement in the basis {|eᵢ⟩} yields outcome i with probability pᵢ = ⟨eᵢ|ρ|eᵢ⟩, and the post-measurement state is |eᵢ⟩. The no-cloning theorem: there is no unitary operation that copies an unknown quantum state; formally, no unitary U exists such that U(|ψ⟩|0⟩) = |ψ⟩|ψ⟩ for all |ψ⟩.
A qubit is not merely a bit with two values — it is a vector in a two-dimensional Hilbert space whose continuous parameters (θ, φ) enable superposition and interference, the fundamental resources of quantum computing.
Part 2

🔗 Entanglement and Bell's Theorem

Entanglement
Bell States, Bell Inequalities, the CHSH Game, and Nonlocality
Entanglement is a quantum correlation between subsystems that cannot be described by product states. The four Bell states (maximally entangled two-qubit states): |Φ⁺⟩ = (|00⟩ + |11⟩)/√2, |Φ⁻⟩ = (|00⟩ − |11⟩)/√2, |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2, |Ψ⁻⟩ = (|01⟩ − |10⟩)/√2. A state is separable if it can be written as ρ = Σ pᵢ ρᵢ^A ⊗ ρᵢ^B; otherwise it is entangled. The Schmidt decomposition: any pure state |ψ⟩_{AB} = Σᵢ √λᵢ |i⟩_A|i⟩_B with λᵢ ≥ 0, Σ λᵢ = 1. The number of non-zero λᵢ is the Schmidt rank; a state is entangled iff Schmidt rank > 1. Bell's theorem: local hidden variable theories cannot reproduce all quantum mechanical predictions. The CHSH inequality: ⟨A₁B₁⟩ + ⟨A₁B₂⟩ + ⟨A₂B₁⟩ − ⟨A₂B₂⟩ ≤ 2 for local realistic theories. Quantum mechanics violates this bound — the Tsirelson bound is 2√2 ≈ 2.828, achieved by measuring the Bell state |Φ⁺⟩ with appropriate observables. The CHSH game: Alice and Bob each receive a random bit x, y and must output bits a, b satisfying a ⊕ b = x ∧ y. Classical strategies win with probability ≤ 75%; quantum strategies using a shared Bell state win with probability cos²(π/8) ≈ 85.4%. The monogamy of entanglement: a qubit cannot be maximally entangled with more than one other qubit.
Entanglement is a non-classical correlation that enables tasks impossible in classical physics; Bell's theorem proves that no local hidden variable theory can replicate quantum correlations.
Part 3

📡 Teleportation and Quantum Gates

Teleportation
Quantum Teleportation, Superdense Coding, and Universal Gate Sets
Quantum teleportation transfers an unknown qubit state |ψ⟩ from Alice to Bob using a shared Bell state and two classical bits. Protocol: (1) Alice performs a Bell-state measurement on |ψ⟩ and her half of the Bell pair; (2) she sends the 2-bit outcome to Bob; (3) Bob applies the corresponding Pauli correction {I, σₓ, σ_z, σₓσ_z} to recover |ψ⟩. The no-cloning theorem is preserved — the original state is destroyed by measurement. Superdense coding: Alice sends two classical bits by transmitting a single qubit — she applies one of {I, σₓ, σ_z, σₓσ_z} to her half of a Bell pair then sends it; Bob performs a Bell measurement to decode the 2-bit message. Quantum gates: single-qubit gates include the Hadamard H, phase S = √Z, π/8 gate T = √S, and rotations R_n(θ) = exp(−iθ/2 n·σ). The CNOT (controlled-NOT) gate flips the target qubit iff the control qubit is |1⟩: CNOT = |0⟩⟨0| ⊗ I + |1⟩⟨1| ⊗ σₓ. The universal gate set for quantum computing: {H, S, T, CNOT} or any set that generates a dense subgroup of SU(2ⁿ). The Solovay-Kitaev theorem: any single-qubit gate can be approximated to accuracy ε using O(log^{c}(1/ε)) gates from a finite universal set. The Toffoli (CCNOT) gate is universal for reversible classical computing. The Deutsch-Jozsa algorithm and Grover's search and Shor's factoring algorithms demonstrate quantum speedup.
Quantum teleportation uses entanglement and classical communication to transfer quantum states; universal quantum gate sets enable arbitrary quantum computations with efficient approximation.

🛡️ Quantum Error Correction

Error Correction
The Shor Code, Stabilizer Codes, the Surface Code, and the Threshold Theorem
Quantum error correction protects quantum information against decoherence and operational errors. The Shor 9-qubit code protects one logical qubit against arbitrary single-qubit errors by concatenating the phase-flip code (|0⟩ → |+++⟩, |1⟩ → |−−−⟩) with the bit-flip code (|+⟩ → (|000⟩+|111⟩)/√2). The stabilizer formalism (Gottesman 1996): an [[n, k, d]] quantum code is defined by an Abelian subgroup S of the Pauli group G_n (stabilizer generators) such that −I ∉ S. The logical codespace is the +1 eigenspace of all stabilizer elements, encoding k logical qubits in n physical qubits with distance d (the minimum weight of a Pauli operator that maps a codeword to another without being detected by syndrome measurement). Syndrome measurement uses ancilla qubits to measure the stabilizer generators without disturbing the logical state. The surface code (Kitaev 1997) is a topological stabilizer code on a 2D lattice where stabilizers are plaquette (star) operators measuring ZZZZ (XXXX) around each face (vertex). The logical qubit is encoded non-locally, giving high error thresholds ≈ 1%. The threshold theorem: if the physical error rate is below a threshold p_th, arbitrarily long quantum computation is possible using concatenated coding, with overhead scaling as O(poly(log(1/ε))). The fault-tolerant threshold for the surface code is approximately 0.6–1.1% for the standard circuit model. The magic state distillation provides a fault-tolerant method for implementing non-Clifford gates (T gates) which are required for universal quantum computing.
Quantum error correction overcomes decoherence by encoding logical qubits into entangled states of many physical qubits; the threshold theorem proves that arbitrarily long quantum computations are possible with realistic error rates.
