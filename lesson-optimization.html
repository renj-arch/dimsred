Optimization Theory — The Science of Best Choices

Optimization is the mathematics of making the best possible choice under constraints. It spans linear programming (simplex method), convex optimization (gradient descent, Newton), nonlinear programming (KKT conditions), integer programming (branch-and-bound), and stochastic optimization (simulated annealing, evolutionary algorithms). The subject is the foundation of operations research, machine learning, engineering design, and economics.

"Optimization theory is the mathematical art of making the best of things."
— George Dantzig
Part 1

📐 Linear Programming — The Simplex Method and Duality

Optimal Allocation
Linear Programming — Maximizing Under Linear Constraints
A linear program (LP) minimizes cᵀx subject to Ax = b, x ≥ 0. The feasible region is a convex polytope. The simplex method (Dantzig, 1947) walks along edges of the polytope from vertex to vertex, decreasing the objective at each step — exponential worst-case but polynomial in practice. Strong duality: if the primal (min cᵀx) has an optimal solution x*, then the dual (max bᵀy) has an optimal y* with cᵀx* = bᵀy*. Complementary slackness gives optimality conditions. Interior point methods (Karmarkar, 1984) traverse the interior of the feasible region using barrier functions — polynomial time O(n³L). Integer linear programming (ILP) adds integrality constraints — much harder (NP-complete). The branch-and-bound algorithm solves ILPs by recursively partitioning the feasible region and bounding the objective.
Linear programming duality is the deepest idea — every maximization problem has a matching minimization problem with the same optimal value.
Part 2

🔄 Convex Optimization — Gradient Descent and Newton's Method

Descent Direction
Convex Optimization — When Local Minima Are Global
A set is convex if the line between any two points lies in it. A function f is convex if f(θx+(1−θ)y) ≤ θf(x)+(1−θ)f(y) — a convex function on a convex set has every local minimum be global. Gradient descent x_{k+1} = x_k − α∇f(x_k) converges to optimum for convex f with Lipschitz gradient — O(1/k) rate. Stochastic gradient descent (SGD) uses noisy gradient estimates ∇f_i(x_k) instead of full gradient — the workhorse of machine learning. Newton's method x_{k+1} = x_k − [∇²f(x_k)]^{-1}∇f(x_k) converges quadratically near optimum but costs O(n³) per step. BFGS and Limited-memory BFGS (L-BFGS) approximate the Hessian with gradient differences — quasi-Newton methods balance cost and convergence speed. Nesterov accelerated gradient achieves O(1/k²) convergence for smooth convex functions — optimal first-order method.
Convex optimization is the golden land — every local minimum is global, and gradient methods find it reliably.
Part 3

⚡ KKT Conditions and Constrained Nonlinear Optimization

Optimization Under Constraints
KKT Conditions — The First-Order Necessary Conditions for Optimality
For minimize f(x) subject to g_i(x) ≤ 0, h_j(x) = 0, the Karush-Kuhn-Tucker (KKT) conditions are: (1) Stationarity: ∇f + Σ μ_i∇g_i + Σ λ_j∇h_j = 0, (2) Primal feasibility: g_i(x) ≤ 0, h_j(x) = 0, (3) Dual feasibility: μ_i ≥ 0, (4) Complementary slackness: μ_i g_i(x) = 0. For convex problems, KKT is both necessary and sufficient. The Lagrangian L(x,μ,λ) = f(x) + Σ μ_i g_i(x) + Σ λ_j h_j(x). The penalty method adds a penalty term for constraint violations. The augmented Lagrangian (method of multipliers) adds a quadratic penalty to improve convergence. Sequential quadratic programming (SQP) solves constrained nonlinear problems by approximating them as QP subproblems at each iteration.
The KKT conditions are the ultimate check for whether you've found the best possible point under constraints.
Part 4

🎲 Stochastic Optimization and Metaheuristics

Randomness as a Tool
When Deterministic Methods Fail — Stochastic and Global Optimization
Non-convex optimization has multiple local minima — deterministic gradient methods get trapped. Simulated annealing accepts worse solutions with decreasing probability (controlled by temperature) to escape local minima — inspired by metallurgy. Genetic algorithms evolve a population of solutions through selection, crossover, and mutation — they explore the search space broadly. Particle swarm optimization (PSO) models a swarm of particles moving toward personal and global best positions. Bayesian optimization builds a probabilistic surrogate model (Gaussian process) of the objective function and uses an acquisition function (expected improvement, upper confidence bound) to choose the next evaluation point — ideal for expensive black-box functions. Evolutionary strategies (CMA-ES) adapt the covariance matrix of the search distribution for efficient exploration. For convex nondifferentiable problems, subgradient methods replace gradients with subgradients — they converge slowly but reliably.
When the landscape is rugged, randomness helps — simulated annealing, genetic algorithms, and Bayesian optimization explore in different ways.

Conic Programming and Semidefinite Programming

Conic programming generalizes linear programming by replacing the nonnegative orthant with an arbitrary closed convex cone K. A conic program minimizes cᵀx subject to Ax = b, x ∈ K. The most important cones are the nonnegative orthant (recovering LP), the second‑order cone (SOCP), and the positive semidefinite cone (SDP). In SDP the variable X is a symmetric matrix constrained to be positive semidefinite, written X ⪰ 0. Many combinatorial problems — max‑cut, graph coloring, and quadratic assignment — admit SDP relaxations that are often tight in practice. The dual of a conic program is another conic program over the dual cone K*; strong duality holds under Slater’s condition (strict feasibility). Interior‑point methods for SDP use a logarithmic barrier for the semidefinite cone, yielding polynomial‑time algorithms with complexity O(n³) per iteration where n is the matrix dimension. Practical solvers (e.g., MOSEK, SDPT3, SeDuMi) exploit sparsity and low‑rank structure to handle problems with thousands of variables.

Semidefinite programming also provides a unified framework for eigenvalue optimization, robust control, and polynomial optimization via sum‑of‑squares (SOS) relaxations. The SOS hierarchy (Lasserre, 2001) produces a sequence of SDPs whose optimal values converge to the global optimum of a polynomial optimization problem. Each level of the hierarchy increases the size of the SDP but yields tighter bounds. For many problems the first or second level already gives the exact optimum. Understanding the geometry of the PSD cone — its facial structure, the role of rank‑one matrices, and the complementarity conditions — is essential for formulating tight relaxations and for interpreting dual certificates of optimality.

Robust and Distributionally Robust Optimization

Robust optimization (RO) addresses data uncertainty by requiring feasibility for all realizations in an uncertainty set U. The classic model minimizes cᵀx subject to A(u)x ≤ b(u) for all u ∈ U. When U is a polyhedron or an ellipsoid, the robust counterpart often reduces to a tractable conic program (LP, SOCP, or SDP). Ben‑Tal and Nemirovski (1998) showed that ellipsoidal uncertainty leads to second‑order cone constraints, while polyhedral uncertainty preserves linearity. The price of robustness is a more conservative solution; the size and shape of U control the trade‑off between performance and reliability.

Distributionally robust optimization (DRO) goes a step further by assuming the uncertain parameters follow an unknown distribution belonging to an ambiguity set 𝒫. The objective becomes minx supP∈𝒫 EP[f(x, ξ)]. Common ambiguity sets are moment‑based (mean and covariance known) or Wasserstein balls around an empirical distribution. For convex loss functions, the worst‑case expectation over a moment‑based set can be expressed as a semidefinite program. Wasserstein DRO yields a regularized empirical risk minimization problem where the regularization parameter equals the radius of the Wasserstein ball. Recent work (Esfahani & Kuhn, 2018) establishes finite‑sample guarantees: with high probability the DRO solution outperforms the true expected loss. Both RO and DRO are now standard tools in finance, energy systems, and machine learning where data are noisy or scarce.

Worked Example
Consider the robust linear program: minimize cᵀx subject to a(u)ᵀx ≤ b for all u ∈ U = {u : ‖u‖₂ ≤ ρ}. Show that the robust counterpart is a second‑order cone constraint.
Write a(u) = a₀ + Σi uᵢ aᵢ. The constraint must hold for the worst‑case u. The left‑hand side is a₀ᵀx + Σi uᵢ aᵢᵀx. Maximizing over ‖u‖₂ ≤ ρ gives a₀ᵀx + ρ √(Σi (aᵢᵀx)²) ≤ b. This is exactly a second‑order cone constraint: ‖Aᵀx‖₂ ≤ (b − a₀ᵀx)/ρ, where A has columns aᵢ. Hence the robust counterpart is an SOCP.
Exam‑Day Strategy
When a question asks for the robust counterpart of a linear constraint with ellipsoidal uncertainty, immediately write the SOC form: nominal term plus radius times the Euclidean norm of the coefficient matrix times the decision vector. Memorize the derivation steps — they are short and earn full marks.

Decomposition Methods for Large‑Scale Optimization

Large‑scale linear and integer programs often exhibit a block‑angular structure that can be exploited by decomposition. Dantzig‑Wolfe decomposition (1960) applies to problems with linking constraints coupling independent subproblems. The master problem selects convex combinations of extreme points of each subproblem’s feasible region; column generation solves the pricing subproblem to find columns with negative reduced cost. This is the foundation of branch‑and‑price algorithms for vehicle routing, crew scheduling, and cutting stock. Benders decomposition (1962) takes the dual view: the master problem contains the complicating variables, while the subproblem generates feasibility and optimality cuts (Benders cuts) from its dual solution. Benders is especially effective for two‑stage stochastic programs where the first‑stage decisions are the master variables and the second‑stage recourse problems are the subproblems.

Lagrangian relaxation dualizes a subset of constraints, moving them into the objective with multipliers. The resulting Lagrangian dual provides a lower bound (for minimization) that can be tightened by subgradient or bundle methods. When the relaxed problem decomposes into independent subproblems, each can be solved efficiently, yielding a practical heuristic: solve the Lagrangian dual, then construct a feasible primal solution via a repair heuristic. Column generation, Benders, and Lagrangian relaxation are not mutually exclusive; modern solvers combine them (e.g., branch‑and‑cut‑and‑price). Understanding the interplay between primal and dual bounds, the role of reduced costs, and the convergence properties of cut generation is essential for designing scalable algorithms.

Advanced First‑Order Methods: Proximal, Mirror Descent, and ADMM

First‑order methods avoid Hessian computations and are the workhorses of high‑dimensional optimization. The proximal gradient method handles composite objectives f(x) = g(x) + h(x) where g is smooth and h is simple (e.g., ℓ₁ norm). The update is xk+1 = proxαh(xk − α∇g(xk)), where the proximal operator proxαh(v) = argminx { h(x) + (1/(2α))‖x − v‖² }. For h = λ‖·‖₁ this is soft‑thresholding. Nesterov acceleration applied to proximal gradient yields O(1/k²) convergence for convex composite problems.

Mirror descent generalizes gradient descent by replacing the Euclidean distance with a Bregman divergence generated by a strongly convex function ψ. The update is xk+1 = argminx∈X { ⟨∇f(xk), x⟩ + (1/α) Dψ(x, xk) }. Choosing ψ(x) = Σ xᵢ log xᵢ over the simplex yields the exponentiated gradient algorithm, which is well‑suited for sparse problems. The Frank‑Wolfe (conditional gradient) method avoids projections by solving a linear minimization oracle over the feasible set; it maintains iterates as convex combinations of vertices, giving sparse solutions and a O(1/k) rate for smooth convex objectives. ADMM (alternating direction method of multipliers) solves problems with separable objectives and linear constraints by alternating minimization of the augmented Lagrangian with respect to each block, followed by a dual update. ADMM converges for convex problems and is highly parallelizable, making it popular for distributed optimization and statistical learning (e.g., graphical lasso, consensus optimization).

Two‑Stage Stochastic Programming and Sample Average Approximation

Two‑stage stochastic programming models decisions made before (x) and after (y(ξ)) the realization of random data ξ. The problem is minx∈X { cᵀx + Eξ[ Q(x, ξ) ] } where Q(x, ξ) = miny { qᵀy : T(ξ)x + W(ξ)y = h(ξ), y ≥ 0 }. The expected recourse function is convex but typically non‑differentiable. Sample average approximation (SAA) replaces the expectation with an average over N independent scenarios ξ¹,…,ξᴺ, yielding a large deterministic equivalent program. Under mild conditions, the SAA optimal value converges to the true optimum almost surely as N → ∞, and the rate is Op(1/√N). Confidence intervals for the optimal value can be constructed via batching or the bootstrap.

Scenario reduction techniques (e.g., fast forward selection) compress a large scenario set while preserving the distribution’s key moments, reducing the deterministic equivalent size. For multi‑stage problems, scenario trees represent the filtration of information; the number of nodes grows exponentially with stages, motivating decomposition (e.g., stochastic dual dynamic programming, SDDP). SDDP builds piecewise‑linear approximations of the cost‑to‑go functions by sampling forward and solving backward subproblems, generating Benders‑type cuts. It has become a widely used algorithm for long‑term hydro‑thermal scheduling and capacity expansion. Understanding the interplay between scenario generation, statistical guarantees, and algorithmic decomposition is crucial for solving real‑world stochastic optimization problems.

  • Confusing the dual cone in conic programming with the polar cone — the polar cone is the negative of the dual cone; they coincide only when the dual cone is a linear subspace.
  • Assuming ellipsoidal uncertainty always yields an SOCP; the robust counterpart is an SOCP only when the uncertainty enters linearly in the constraints.
  • Treating Benders cuts as valid for the original integer program without integer‑compatible cut generation (e.g., combinatorial Benders).
  • Using the proximal operator of a non‑convex regularizer and expecting convergence guarantees that hold only for convex h.
  • Believing SAA provides exact confidence intervals without accounting for the optimization error in solving the deterministic equivalent.
  • Applying Frank‑Wolfe to problems where the linear minimization oracle is NP‑hard, negating the method’s projection‑free advantage.
  • Mastering these advanced topics will strengthen your optimization toolkit.

Integer Programming — Branch‑and‑Bound, Cutting Planes, and Branch‑and‑Cut

Integer programming (IP) models decisions that must take discrete values, typically binary or general integers. The standard formulation is min cᵀx subject to Ax ≤ b, x ∈ ℤⁿ₊. Because the integrality constraint destroys convexity, the linear programming relaxation (LP‑relaxation) provides a lower bound for minimization problems. Branch‑and‑bound systematically partitions the feasible region by fixing fractional variables to integer values, creating a search tree. At each node the LP‑relaxation is solved; if the solution is integral it updates the incumbent, otherwise the node is branched. Effective branching rules — such as strong branching, pseudocost branching, or reliability branching — dramatically reduce tree size.

Cutting planes tighten the LP‑relaxation by adding valid inequalities that cut off fractional extreme points without removing any integer feasible point. Classical families include Gomory mixed‑integer cuts derived from the simplex tableau, knapsack cover cuts, and flow cover cuts for network structures. Modern solvers generate cuts dynamically (cut generation) and manage a cut pool to avoid numerical instability. The combination of branch‑and‑bound with cutting planes yields branch‑and‑cut, the algorithmic backbone of commercial MIP solvers. Branch‑and‑cut also incorporates heuristics (e.g., feasibility pump, local branching) to find high‑quality incumbents early, which improves pruning.

Preprocessing and presolve play a crucial role: bound tightening, coefficient reduction, probing, and detection of implied integer variables shrink the model before the tree search begins. Symmetry breaking constraints can be added when the model contains interchangeable components, preventing the solver from exploring equivalent subtrees. Parallel tree search distributes nodes across cores, while deterministic parallelism ensures reproducibility. Understanding the interplay between node selection (best‑bound vs. depth‑first), cut aggressiveness, and heuristic effort is essential for tuning solver performance on large‑scale instances.

Decomposition techniques such as Dantzig‑Wolfe (column generation) and Benders reformulate the IP into a master problem and subproblems, enabling the solution of problems with block‑angular structure. In branch‑and‑price, columns are generated at each node of the branch‑and‑bound tree, combining pricing with branching. Branch‑and‑cut‑and‑price integrates cutting planes, column generation, and branching in a single framework, representing the state of the art for many combinatorial optimization problems like vehicle routing and crew scheduling.

From an examination perspective, candidates must be able to formulate a problem as an IP, write its LP‑relaxation, identify a valid cutting plane for a given fractional solution, and explain how branching decisions affect the dual bound. Typical questions ask to derive a Gomory cut from a simplex row, to describe the effect of a cover inequality on a knapsack constraint, or to compare the theoretical worst‑case complexity of branch‑and‑bound versus branch‑and‑cut.

Nonconvex Global Optimization — Spatial Branch‑and‑Bound and DC Programming

Nonconvex optimization problems arise when the objective or constraints are nonconvex, leading to multiple local minima. Global optimization seeks a guaranteed ε‑optimal solution. Spatial branch‑and‑bound (sBB) extends branch‑and‑bound to continuous nonconvex problems by recursively partitioning the domain (usually a box) and computing convex relaxations on each subregion. The most common relaxation is the McCormick envelope for bilinear terms x·y, which provides the tightest convex/concave under/over‑estimators on a rectangle. For general factorable functions, the αBB method adds a quadratic term α‖x‖² to the objective, where α is chosen from interval Hessian eigenvalue bounds to ensure convexity.

Convergence of sBB relies on the consistency of the relaxation (the relaxation value converges to the true function value as the box diameter shrinks) and the bounding operation (the lower bound is non‑decreasing along the tree). Practical implementations use a combination of variable selection rules (e.g., longest edge, maximum violation) and bounding strategies (e.g., solving the convex relaxation with an interior‑point method). The algorithm terminates when the gap between the best feasible upper bound (incumbent) and the global lower bound falls below a prescribed tolerance.

Difference‑of‑convex (DC) programming exploits the structure f(x) = g(x) − h(x) where g and h are convex. The DC algorithm (DCA) linearizes the concave part −h(x) at the current iterate, yielding a convex subproblem min g(x) − ⟨∇h(xᵏ), x⟩. DCA generates a sequence of decreasing objective values and converges to a critical point under mild conditions. For global optimality, DC decomposition can be combined with branch‑and‑bound: each node solves a convex relaxation obtained by underestimating g and overestimating h. This hybrid approach is effective for problems such as sparse regression with ℓ₀ regularization and certain quadratic programming instances with indefinite matrices.

Interval arithmetic and automatic differentiation provide rigorous bounds on function ranges and gradients, enabling certified global optimization. Software packages such as BARON, Couenne, and SCIP implement sBB with sophisticated cut generation (e.g., edge‑concave cuts, lifted McCormick cuts) and primal heuristics (e.g., local NLP solves from relaxation solutions). Understanding the theoretical guarantees — finite ε‑convergence for Lipschitz functions, the role of the relaxation tightness, and the impact of branching variable selection — is essential for both algorithm design and for answering exam questions that ask to construct a McCormick envelope for a given bilinear term or to outline the steps of DCA on a simple DC program.

Examiners often test the ability to distinguish between local and global optimality conditions, to write the convex/concave envelopes of elementary nonconvex functions (e.g., x² on [−1,1] is convex, but x³ requires a piecewise envelope), and to explain why a pure gradient‑based method cannot guarantee global optimality in nonconvex settings. A typical trap is to claim that KKT conditions are sufficient for global optimality; they are only necessary under constraint qualifications and sufficient only for convex problems.

Worked Example: McCormick Envelope for a Bilinear Term
Given the bilinear term w = x·y with x ∈ [0, 2] and y ∈ [1, 3], write the four linear inequalities that form the McCormick convex/concave envelope of w over this rectangle.
The McCormick envelope for w = x·y on x ∈ [xL, xU], y ∈ [yL, yU] consists of: w ≥ xL·y + yL·x − xL·yL, w ≥ xU·y + yU·x − xU·yU, w ≤ xU·y + yL·x − xU·yL, w ≤ xL·y + yU·x − xL·yU. Substituting xL = 0, xU = 2, yL = 1, yU = 3 gives: w ≥ 0·y + 1·x − 0·1 = x, w ≥ 2·y + 3·x − 2·3 = 2y + 3x − 6, w ≤ 2·y + 1·x − 2·1 = 2y + x − 2, w ≤ 0·y + 3·x − 0·3 = 3x. These four inequalities define the tightest convex relaxation of w on the given box.
Exam‑Day Strategy
When a question asks for a relaxation, first identify the nonconvex term (bilinear, fractional, trigonometric). Write the variable bounds explicitly, then apply the standard envelope formulas. For DC programming, clearly separate the convex and concave parts before linearizing. Show the linearized subproblem; examiners award marks for the correct convex subproblem formulation even if the final numeric answer is not required.

Bilevel Optimization — Hierarchical Decision Making and KKT Reformulation

Bilevel optimization models a hierarchical decision process where a leader (upper level) chooses variables x, anticipating the reaction of a follower (lower level) who solves a parametric optimization problem in variables y. The generic form is minₓ F(x, y) subject to G(x, y) ≤ 0, where y ∈ argminᵧ { f(x, y) : g(x, y) ≤ 0 }. The lower‑level problem is assumed to be convex in y for each fixed x, ensuring a unique optimal response or a well‑defined solution set. The leader’s feasible region is the set of (x, y) such that y solves the lower‑level problem; this region is generally nonconvex and non‑connected.

A standard approach to obtain a single‑level reformulation replaces the lower‑level problem by its Karush‑Kuhn‑Tucker (KKT) conditions, provided a constraint qualification (e.g., Mangasarian‑Fromovitz) holds for all relevant x. The KKT system introduces primal feasibility, dual feasibility, complementary slackness, and stationarity. Complementary slackness yields complementarity constraints λᵢ·gᵢ(x, y) = 0, λᵢ ≥ 0, gᵢ(x, y) ≤ 0, which are nonconvex and difficult for standard NLP solvers. These can be handled by mixed‑integer linear programming (MILP) reformulations using big‑M or indicator constraints, or by specialized algorithms such as the branch‑and‑bound on the complementarity conditions.

When the lower‑level problem is linear in y (i.e., a linear program parameterized by x), the KKT conditions become linear except for complementarity. The resulting Mathematical Program with Equilibrium Constraints (MPEC) can be tackled by the Fortuny‑Amat and McCarl linearization, which introduces binary variables to model the either‑or nature of complementarity. For nonlinear lower‑level problems, the KKT reformulation leads to a Mathematical Program with Complementarity Constraints (MPCC). MPCCs violate standard constraint qualifications (e.g., MFCQ fails at any feasible point), so classical NLP theory does not apply directly; specialized stationarity concepts (C‑stationarity, M‑stationarity, S‑stationarity) are used to characterize local optima.

Algorithmic strategies include: (1) the penalty method, which adds a penalty term for complementarity violation to the objective and solves a sequence of NLPs; (2) the smoothing method, which replaces the complementarity condition by a smooth approximation (e.g., Fischer‑Burmeister function); (3) the branch‑and‑bound on the binary variables from the MILP reformulation; and (4) the value‑function approach, which replaces the lower‑level problem by its optimal value function and uses subgradient information. Each method has trade‑offs in terms of global optimality guarantees, computational effort, and sensitivity to problem scaling.

Examination questions often ask to write the KKT conditions for a given lower‑level quadratic program, to formulate the resulting MPEC, and to discuss why standard NLP solvers may fail. Another common task is to linearize a simple bilevel linear program using binary variables and big‑M constants, and to comment on the choice of M. Candidates should also be aware of the optimistic vs. pessimistic bilevel formulations: the optimistic version assumes the follower selects a solution favorable to the leader when multiple optimal responses exist, while the pessimistic version assumes the worst‑case follower response.

Multi‑Objective Optimization — Pareto Optimality, Scalarization, and Evolutionary Algorithms

Multi‑objective optimization (MOO) deals with problems having several conflicting objectives f₁(x), …, fₖ(x) to be minimized simultaneously over a feasible set X. A solution x* is Pareto optimal if there is no other x ∈ X such that fᵢ(x) ≤ fᵢ(x*) for all i and fⱼ(x) < fⱼ(x*) for at least one j. The set of all Pareto optimal points in the decision space is the Pareto set; its image in objective space is the Pareto front. In convex problems the Pareto front is a continuous (k−1)‑dimensional manifold; in nonconvex or discrete problems it can be disconnected.

Scalarization converts the vector problem into a family of single‑objective problems. The weighted‑sum method minimizes Σ wᵢ fᵢ(x) with wᵢ > 0, Σ wᵢ = 1. It can generate any Pareto optimal point on the convex hull of the Pareto front but fails for nonconvex regions. The ε‑constraint method minimizes one objective while constraining the others: min f₁(x) s.t. fᵢ(x) ≤ εᵢ, i = 2..k. By varying ε, the entire Pareto front (including nonconvex parts) can be traced. The achievement scalarizing function (ASF) min maxᵢ (fᵢ(x) − zᵢʳᵉᶠ)/wᵢ + ρ Σ (fᵢ(x) − zᵢʳᵉᶠ) provides a reference‑point based approach that can reach any Pareto optimal solution for appropriate reference points zʳᵉᶠ and augmentation parameter ρ > 0.

Evolutionary multi‑objective algorithms (EMOAs) such as NSGA‑II, SPEA2, and MOEA/D approximate the Pareto front without requiring gradient information. NSGA‑II uses non‑dominated sorting and crowding distance to maintain diversity; SPEA2 maintains an external archive of non‑dominated solutions and uses a fitness assignment based on strength; MOEA/D decomposes the MOO problem into a set of scalar subproblems (often using Tchebycheff or weighted‑sum) and optimizes them collaboratively. These algorithms are population‑based, stochastic, and well‑suited for black‑box, discontinuous, or expensive objectives. Performance metrics include the hypervolume indicator, inverted generational distance (IGD), and spacing metric.

Decision‑making after obtaining an approximation of the Pareto front involves selecting a preferred solution. Techniques include interactive methods (e.g., NIMBUS, reference point method), value‑function based approaches, and outranking methods (e.g., ELECTRE, PROMETHEE). In many practical settings, the decision maker provides aspiration levels or trade‑off information that guides the final choice. Understanding the relationship between scalarization parameters and the resulting Pareto points, and the limitations of each scalarization, is crucial for both algorithm design and for answering exam questions that ask to derive the weighted‑sum scalarization for a bi‑objective quadratic program or to explain why NSGA‑II may lose diversity on a highly degenerate front.

Typical exam traps: confusing weak Pareto optimality (no other solution strictly improves all objectives) with strong Pareto optimality; assuming the weighted‑sum method can generate the entire front for nonconvex problems; neglecting the need for constraint qualifications in the ε‑constraint method; and misinterpreting the hypervolume indicator as a measure of convergence only (it also reflects diversity). Candidates should be able to sketch the Pareto front of a simple bi‑objective problem, write the ε‑constraint formulation, and describe the main steps of NSGA‑II.

Online Convex Optimization — Regret Minimization, Mirror Descent, and Adaptive Methods

Online convex optimization (OCO) models sequential decision making where at each round t = 1,…,T the learner chooses xₜ ∈ X (a convex set), then observes a convex loss function fₜ(x) and incurs loss fₜ(xₜ). The performance metric is regret R_T = Σₜ₌₁ᵀ fₜ(xₜ) − minₓ∈X Σₜ₌₁ᵀ fₜ(x). The goal is to design algorithms with sublinear regret, i.e., R_T = o(T), guaranteeing that the average loss approaches the best fixed decision in hindsight. The classic online gradient descent (OGD) update is xₜ₊₁ = Π_X (xₜ − ηₜ ∇fₜ(xₜ)), where Π_X denotes Euclidean projection onto X. With a fixed step size η = O(1/√T), OGD achieves O(√T) regret for Lipschitz losses.

Mirror descent generalizes OGD by replacing the Euclidean distance with a Bregman divergence D_ψ(x, y) = ψ(x) − ψ(y) − ⟨∇ψ(y), x − y⟩ generated by a strongly convex function ψ. The update is xₜ₊₁ = argminₓ∈X { ηₜ ⟨∇fₜ(xₜ), x⟩ + D_ψ(x, xₜ) }. Choosing ψ(x) = ½‖x‖₂² recovers OGD. For the probability simplex, ψ(x) = Σ xᵢ log xᵢ yields the exponentiated gradient algorithm, which maintains iterates in the simplex without projection and achieves O(√T log n) regret for n‑dimensional simplex. Mirror descent adapts to the geometry of X via the choice of ψ, leading to dimension‑dependent improvements.

Adaptive step‑size methods such as AdaGrad, RMSprop, and Adam have been analyzed in the OCO framework. AdaGrad uses per‑coordinate learning rates ηₜ,ᵢ = η / √(Σₛ₌₁ᵗ gₛ,ᵢ²) where gₛ,ᵢ is the i‑th component of the gradient at round s. It achieves regret bounds that depend on the ℓ₂ norm of the gradient sequence, often improving over OGD when gradients are sparse. The Follow‑the‑Regularized‑Leader (FTRL) framework unifies many adaptive algorithms: xₜ₊₁ = argminₓ∈X { Σₛ₌₁ᵗ ⟨gₛ, x⟩ + Rₜ(x) } where Rₜ is a time‑varying regularizer. With Rₜ(x) = ½ Σᵢ (√(Σₛ₌₁ᵗ gₛ,ᵢ²)) xᵢ², FTRL recovers AdaGrad. These methods are central to large‑scale machine learning (e.g., training deep networks) where the loss functions are stochastic gradients of a population risk.

Lower bounds show that for convex Lipschitz losses over a bounded domain, any algorithm must incur Ω(√T) regret, making OGD and mirror descent minimax optimal up to constants. For strongly convex losses, the optimal regret is O(log T), achieved by online Newton step or by using a time‑varying step size ηₜ = 1/(λ t) where λ is the strong convexity parameter. In the bandit setting, where only the function value fₜ(xₜ) is observed (not the gradient), algorithms such as the one‑point gradient estimator achieve O(T3/4) regret for convex losses and O(√T) for strongly convex losses.

Examination questions often ask to derive the regret bound for OGD with a given step‑size schedule, to write the mirror descent update for a specific ψ (e.g., ψ(x) = Σ xᵢ log xᵢ), or to explain why AdaGrad’s per‑coordinate learning rates help with sparse gradients. A common trap is to confuse static regret (comparison to best fixed decision) with dynamic regret (comparison to a sequence of changing comparators) and to apply static regret bounds in non‑stationary environments. Another trap is to assume that the Bregman divergence is symmetric; it is not, and the direction matters in the mirror descent update.

  • Assuming that branch‑and‑bound alone solves large integer programs without cutting planes or heuristics.
  • Confusing the McCormick envelope with the convex hull of a bilinear term; the envelope is a relaxation, not the exact hull unless the variable bounds are tight.
  • Treating KKT conditions of the lower‑level problem as sufficient for global optimality in bilevel optimization; they are only necessary under constraint qualifications.
  • Believing the weighted‑sum scalarization can generate every Pareto optimal point for nonconvex multi‑objective problems.
  • Applying online gradient descent with a fixed step size in a non‑stationary environment and expecting sublinear dynamic regret.
  • Using the proximal operator of a non‑convex regularizer and expecting convergence guarantees that hold only for convex functions.
  • Neglecting to verify constraint qualifications before reformulating a bilevel program via KKT conditions.

Distributed Optimization and Consensus ADMM

Distributed optimization addresses problems where the objective or constraints are split across agents communicating over a network. The canonical formulation minimizes Σᵢ fᵢ(xᵢ) subject to xᵢ = z for all i, where each agent i holds a local convex function fᵢ and a local copy xᵢ of the global variable z. The Alternating Direction Method of Multipliers (ADMM) introduces dual variables yᵢ for the consensus constraints and performs the updates: xᵢk+1 = argmin fᵢ(xᵢ) + (ρ/2)‖xᵢ - z^k + yᵢ^k‖², zk+1 = (1/N) Σᵢ (xᵢk+1 + yᵢ^k), yᵢk+1 = yᵢ^k + xᵢk+1 - zk+1. Convergence holds for closed, proper, convex fᵢ and any ρ > 0 at an ergodic O(1/k) rate. The penalty parameter ρ strongly affects practical speed; adaptive schemes that increase ρ when the primal residual dominates the dual residual, and decrease it otherwise, are standard. Communication topology matters: the above assumes a star network with a central coordinator. For decentralized graphs, consensus ADMM replaces the averaging step with a weighted mixing matrix W respecting the graph, giving zk+1 = W (xk+1 + y^k). Convergence then requires W to be doubly stochastic and the graph connected. Applications include distributed statistical learning (e.g., logistic regression across data silos), power system state estimation, and federated learning where privacy constraints forbid raw data exchange. A key practical trade‑off is between communication rounds and local computation; inexact local solves (e.g., a few gradient steps) can reduce per‑iteration cost while preserving overall convergence if errors are summable.

Chance‑Constrained Programming and Risk Measures

Chance‑constrained programming (CCP) models optimization under uncertainty by requiring constraints to hold with a prescribed probability. For a random vector ξ and decision x, a typical chance constraint is ℙ(g(x, ξ) ≤ 0) ≥ 1 - ε, where ε ∈ (0,1) is a small risk tolerance. When g is linear in ξ and ξ follows a known distribution (e.g., Gaussian), the constraint reformulates as a deterministic convex constraint: aᵀx + Φ-1(1-ε)‖Σ1/2a‖ ≤ b, where Φ-1 is the Gaussian quantile function. For general distributions, the constraint is nonconvex and often intractable. Two major approximation routes are scenario approximation and convex safe approximations. Scenario approximation draws N independent samples ξ¹,…,ξᴺ and enforces g(x, ξʲ) ≤ 0 for all j; by the scenario theorem, if N ≥ (2/ε)(ln(1/β) + d) where d is the VC‑dimension of the constraint set, the solution satisfies the original chance constraint with confidence 1-β. Convex safe approximations replace the chance constraint with a tighter deterministic constraint guaranteeing feasibility; for example, using Conditional Value‑at‑Risk (CVaR) yields the convex constraint CVaR_ε(g(x, ξ)) ≤ 0, which is exact when g is convex in ξ and the distribution is known. CVaR_α(Z) = min_t { t + (1/(1-α)) 𝔼[(Z - t)_+] } provides a coherent risk measure capturing tail behavior better than Value‑at‑Risk. In distributionally robust CCP, the distribution of ξ is only known to belong to an ambiguity set (e.g., moment‑based or Wasserstein ball); the worst‑case probability over the set is then constrained, leading to tractable conic reformulations for suitably chosen ambiguity sets. Examiners often test the ability to derive the Gaussian deterministic equivalent, state the scenario sample‑size bound, and distinguish between VaR (non‑convex, not coherent) and CVaR (convex, coherent). A common trap is applying the Gaussian reformulation when the uncertainty is not elliptically symmetric, which can produce severely infeasible solutions.

Worked Example: Gaussian Chance Constraint Reformulation
Consider the constraint ℙ(aᵀx + ξ ≤ b) ≥ 0.95 where ξ ~ N(0, σ²) is scalar. Derive the deterministic equivalent and compute the required safety margin for σ = 2, a = 3, b = 10.
The constraint is ℙ(ξ ≤ b - aᵀx) ≥ 0.95. Since ξ is Gaussian with mean 0 and variance σ², this is equivalent to Φ((b - aᵀx)/σ) ≥ 0.95, where Φ is the standard normal CDF. Hence (b - aᵀx)/σ ≥ Φ-1(0.95) ≈ 1.645. Rearranging gives aᵀx ≤ b - 1.645σ. With σ = 2, a = 3, b = 10, the safety margin is 1.645 × 2 = 3.29, so the deterministic constraint is 3x ≤ 10 - 3.29 = 6.71, i.e., x ≤ 2.2367.
Exam‑Day Strategy
When a chance‑constrained question appears, first identify the distribution of the uncertain parameter. If it is Gaussian (or elliptically symmetric), write the deterministic equivalent using the appropriate quantile. If the distribution is unspecified, check whether the question asks for a scenario‑based bound (cite the sample‑size formula) or a CVaR reformulation (write the epigraph form). Never confuse VaR with CVaR; VaR is a quantile, CVaR is an expectation over the tail. Memorize the Gaussian quantile Φ-1(0.95) ≈ 1.645 and Φ-1(0.99) ≈ 2.33 for quick calculations.

Variance‑Reduced Stochastic Gradient Methods

Standard stochastic gradient descent (SGD) uses a single sample gradient ∇f_i(x) per iteration, yielding variance that does not vanish near the optimum, forcing diminishing step sizes and slowing convergence to O(1/√k) for convex objectives. Variance‑reduced methods construct gradient estimators with decreasing variance, enabling constant step sizes and faster rates. The Stochastic Variance Reduced Gradient (SVRG) algorithm maintains a snapshot point tilde{x} updated every m iterations. At the start of each epoch, the full gradient ∇f(tilde{x}) = (1/n) Σ_i ∇f_i(tilde{x}) is computed. Inner iterations then use the estimator v = ∇f_i(x) - ∇f_i(tilde{x}) + ∇f(tilde{x}), which is unbiased and has variance shrinking as x approaches tilde{x}. With a constant step size η = O(1/L) and epoch length m = O(n), SVRG achieves a linear convergence rate (1 - μ/L)^k for μ‑strongly convex finite‑sum problems, dramatically outperforming SGD. SAGA maintains a table of past gradients φ_i for each component, updating one entry per iteration and using the estimator v = ∇f_i(x) - φ_i + (1/n) Σ_j φ_j. SAGA avoids the full‑gradient computation of SVRG but requires O(n) memory. Both methods extend to non‑convex finite‑sum problems, converging to stationary points at rate O(1/k). For problems with many components, the Stochastic Average Gradient (SAG) method uses a similar table with a different averaging scheme. In empirical risk minimization, variance reduction is key to achieving the optimal oracle complexity O((n + L/μ) log(1/ε)) for strongly convex losses. Examiners may ask to write the SVRG update, explain why the estimator variance vanishes at the optimum, or compare memory and computation trade‑offs between SVRG and SAGA. A frequent trap is claiming that variance reduction eliminates the need for any step‑size schedule; in practice, a constant step size works only when the condition number L/μ is moderate, otherwise a modest decay remains beneficial.

Derivative‑Free Optimization and Bayesian Optimization

Derivative‑free optimization (DFO) addresses problems where gradients are unavailable, unreliable, or too expensive. Model‑based DFO builds a local surrogate model (typically quadratic) from function evaluations and minimizes it within a trust region. The classic algorithm is Powell’s BOBYQA, which constructs an interpolation model using 2n+1 points and updates the trust‑region radius based on the ratio of actual to predicted reduction. Convergence to first‑order stationary points is guaranteed under mild smoothness assumptions, with worst‑case evaluation complexity O(n² ε-2) for nonconvex problems. Direct‑search methods, such as Mesh Adaptive Direct Search (MADS), explore a set of polling directions on a mesh that refines as the algorithm progresses; they require only function values and can handle general constraints via a progressive barrier. Bayesian optimization (BO) takes a global perspective: it places a Gaussian process (GP) prior on the unknown objective f, updates the posterior with each evaluation, and selects the next point by maximizing an acquisition function. The Expected Improvement (EI) acquisition is EI(x) = 𝔼[max(0, f_min - f(x))], where f_min is the best observed value; it balances exploration (high posterior variance) and exploitation (low posterior mean). The GP kernel (e.g., Matérn 5/2) encodes smoothness assumptions; misspecification can degrade performance. BO is the de facto standard for hyperparameter tuning of machine learning models, where each evaluation is a costly training run. Theoretical guarantees include cumulative regret bounds of O(√(T γ_T)) where γ_T is the maximum information gain, which is sublinear for common kernels. In exams, candidates should be able to write the EI formula, explain the role of the trust‑region radius in model‑based DFO, and distinguish between local convergence guarantees of BOBYQA and global regret bounds of BO. A common mistake is treating the GP posterior mean as the true function and ignoring the acquisition function’s exploration term.

Complementarity Problems and Variational Inequalities

The Nonlinear Complementarity Problem (NCP) seeks a vector x ∈ ℝⁿ such that x ≥ 0, F(x) ≥ 0, and xᵀF(x) = 0, where F: ℝⁿ → ℝⁿ is a continuous mapping. This captures equilibrium conditions in economics (Walrasian equilibrium), engineering (contact mechanics), and game theory (Nash equilibria of bimatrix games). The NCP is equivalent to the Variational Inequality VI(F, X): find x* ∈ X such that ⟨F(x*), x - x*⟩ ≥ 0 for all x ∈ X, with X = ℝⁿ₊. When F is the gradient of a convex function, VI reduces to a convex optimization problem. For monotone operators (⟨F(x) - F(y), x - y⟩ ≥ 0), the solution set is convex and projection‑type algorithms converge. The classic projection method xk+1 = Π_X(x^k - α F(x^k)) converges for Lipschitz monotone F with step size α ∈ (0, 2/L). The extragradient method of Korpelevich uses two projections per iteration to allow larger steps and achieves O(1/k) ergodic convergence for monotone VIs. For strongly monotone F (⟨F(x) - F(y), x - y⟩ ≥ μ‖x - y‖²), linear convergence is possible. The NCP can be reformulated as a nonsmooth equation using the Fischer‑Burmeister function φ(a,b) = √(a²+b²) - a - b, leading to semismooth Newton methods with superlinear local convergence. In mixed complementarity problems (MCP), variables have lower and upper bounds, and complementarity conditions apply only at active bounds; this is the standard format for computable general equilibrium models. Examiners often test the equivalence between NCP and VI, the monotonicity condition for convergence of the projection method, and the Fischer‑Burmeister reformulation. A typical trap is assuming that any VI with a continuous mapping has a solution; existence requires compactness of X or coercivity of F. Another trap is applying the projection method to a non‑monotone VI and expecting convergence; counterexamples show cycling.

  • Assuming that a chance constraint with Gaussian uncertainty remains convex after a nonlinear transformation of the random variable.
  • Using a constant step size in SVRG without verifying the condition number bound, leading to divergence in ill‑conditioned problems.
  • Confusing the Expected Improvement acquisition function with the Probability of Improvement; EI integrates over the improvement magnitude, PI only measures its probability.
  • Applying the projection method to a variational inequality with a non‑monotone operator and expecting global convergence.
  • Treating the Fischer‑Burmeister function as globally Lipschitz; it is only semismooth, and Newton steps require a regularization safeguard.
  • Believing that Bayesian optimization’s regret bounds hold for any kernel; they require the kernel to have bounded information gain (e.g., Matérn, squared exponential).
  • Forgetting that the scenario approximation sample‑size bound depends on the VC‑dimension of the constraint set, not merely on the number of decision variables.

Mathematical Programs with Equilibrium Constraints and M‑Stationarity

A Mathematical Program with Equilibrium Constraints (MPEC) takes the form

minimize f(x, y) subject to g(x, y) ≤ 0, h(x, y) = 0, and y ∈ SOL(x)

where SOL(x) = {y | 0 ≤ y ⊥ F(x, y) ≥ 0} is the solution set of a parametric complementarity problem or variational inequality. This structure arises in bilevel optimization (when the lower level satisfies strong duality and is replaced by its KKT conditions), Stackelberg games, and equilibrium-constrained design (e.g., traffic networks, electricity markets). Standard CQs (LICQ, MFCQ) fail at every feasible MPEC point: the complementarity conditions y_i F_i = 0, y_i ≥ 0, F_i ≥ 0 create a non‑regular feasible set where active constraint gradients are linearly dependent. Consequently, classical KKT conditions are not necessary for local optimality. Instead, tailored stationarity concepts are used: C‑stationarity (Clarke), M‑stationarity (Mordukhovich), and S‑stationarity (Strong). For MPECs with F = ∇_y φ (φ convex in y), local minimizers satisfy M‑stationarity: ∃ λ ≥ 0, μ, ν with ∇_x L = 0, ∇_y L = 0, λ_i g_i = 0, and for each pair (y_i, F_i) either (ν_i, μ_i) = (0,0), (ν_i, μ_i) > 0, (ν_i > 0, μ_i = 0, y_i = 0), or (ν_i = 0, μ_i > 0, F_i = 0). S‑stationarity requires ν_i μ_i = 0 ∀i, which holds under MPEC‑LICQ (linear independence of equality, active inequality, and one constraint per complementarity pair). M‑stationarity is necessary under the weaker MPEC‑MFCQ. Algorithms include Scholtes relaxation (y_i F_i ≤ t, t → 0), exact penalty methods, and piecewise SQP. In exams, candidates must distinguish the three stationarity types, write the M‑stationarity conditions for a given MPEC, and explain why standard NLP solvers fail without reformulation. Traps: applying standard KKT and claiming necessity; assuming MPEC‑LICQ holds if upper-level LICQ holds (it also needs strict complementarity or active-set identification at the lower level).

Riemannian Optimization on Matrix Manifolds

Riemannian optimization solves minX∈M f(X) for a smooth embedded manifold M (typically a matrix manifold with inherited metric). Key examples: the Stiefel manifold St(p, n) = {X ∈ ℝn×p | XᵀX = I_p} (orthonormal columns), the Grassmann manifold Gr(p, n) (p‑dimensional subspaces in ℝⁿ), the fixed‑rank manifold M_r = {X ∈ ℝm×n | rank(X) = r}, and the symmetric positive definite cone S++n with the affine‑invariant metric. The template: compute Riemannian gradient grad f(X) = ΠT_X M(∇f(X)); choose step α; retract via R_X(-α grad f(X)); optionally vector-transport gradients for momentum/CG. Common retractions: on St(p, n), QR retraction R_X(ξ) = qf(X + ξ) (Q factor) or polar retraction R_X(ξ) = (X + ξ)(I + ξᵀξ)-1/2; on S++n, exponential map Exp_X(ξ) = X1/2 exp(X-1/2 ξ X-1/2) X1/2. RTR builds a quadratic model on T_X M, solves it within radius Δ; guarantees global convergence to first-order and local superlinear convergence to non-degenerate second-order critical points. RCG uses vector transport (parallel transport or differentiated retraction) for β_k via Polak‑Ribière or Fletcher‑Reeves. Applications: low‑rank matrix completion (M_r), ICA (St(p, n) or Gr(p, n)), covariance estimation (S++n), dictionary learning. In exams, candidates should derive the tangent space projection for St(p, n) (Π_X(Z) = Z - X sym(XᵀZ)), write the QR retraction, and explain why the Euclidean gradient ∇f(X) is not a valid search direction. A common mistake: Euclidean line search X + α∇f(X) followed by projection — this leaves the manifold and breaks convergence. Another trap: confusing the affine-invariant metric ⟨ξ,η⟩_X = tr(X-1ξ X-1η) with the Euclidean metric; the Riemannian gradient is X ∇f(X) X, not ∇f(X).

Worked Example: Riemannian Gradient on the Stiefel Manifold
Let f(X) = ½ ‖X - A‖_F² where A ∈ ℝn×p is given and X ∈ St(p, n). Compute the Riemannian gradient grad f(X) at a point X ∈ St(p, n).
The Euclidean gradient is ∇f(X) = X - A. The tangent space at X is T_X St(p, n) = {ξ ∈ ℝn×p | Xᵀξ + ξᵀX = 0} = {ξ | Xᵀξ is skew‑symmetric}. The orthogonal projection onto T_X St(p, n) is Π_X(Z) = Z - X sym(XᵀZ) where sym(M) = ½(M + Mᵀ). Applying this to Z = X - A: Π_X(X - A) = (X - A) - X sym(Xᵀ(X - A)) = (X - A) - X sym(I - XᵀA) = (X - A) - X (I - ½(XᵀA + AᵀX)) = -A + ½ X (XᵀA + AᵀX). Thus grad f(X) = -A + ½ X (XᵀA + AᵀX). This is the steepest ascent direction on the manifold; the descent direction is -grad f(X).
Exam‑Day Strategy
When a problem involves orthogonality constraints (XᵀX = I), positive definiteness (X ≻ 0), or fixed rank, immediately recognize the manifold structure. Write down the tangent space projection and a valid retraction (QR for Stiefel, exponential for SPD). Do not attempt Euclidean projected gradient — it is a standard trap. For MPECs, identify the complementarity structure and state which stationarity concept (C, M, S) applies under which constraint qualification (MPEC‑LICQ, MPEC‑MFCQ). Memorize the M‑stationarity sign conditions for complementarity pairs: (ν_i > 0, μ_i > 0) or (ν_i > 0, μ_i = 0, y_i = 0) or (ν_i = 0, μ_i > 0, F_i = 0).

Stochastic Dual Dynamic Programming for Multi‑Stage Stochastic Programming

Stochastic Dual Dynamic Programming (SDDP) solves multi‑stage stochastic linear programs of the form

minx1 c1ᵀx1 + 𝔼[Q2(x1, ξ2)] s.t. A1 x1 = b1, x1 ≥ 0

where Q_t(xt-1, ξ_t) = minx_t c_tᵀx_t + 𝔼[Qt+1(x_t, ξt+1)] s.t. A_t x_t = b_t - B_t xt-1, x_t ≥ 0, and QT+1 ≡ 0. The uncertainty ξ_t is stagewise independent with finite support. SDDP builds a piecewise-linear convex approximation of Q_t(·) by adding Benders cuts from subproblem duals. Forward pass: draw sample path ξ2,…,ξ_T; solve approximate problems sequentially for trial decisions x_t^k. Backward pass: from stage T, solve exact subproblems for realized ξ_t and trial state xt-1^k, obtaining dual multipliers π_t. The cut Q_t(xt-1) ≥ α_t + β_tᵀ xt-1 with α_t = -π_tᵀ B_t xt-1^k + π_tᵀ b_t, β_t = -π_tᵀ B_t is added to the approximation of Q_t. Because subproblems are LPs, strong duality holds and cuts are globally valid lower bounds. Termination: when gap between forward-pass lower bound (average approximate cost) and statistical upper bound (Monte Carlo policy simulation) is small. Convergence is almost sure under stagewise independence and relatively complete recourse. Enhancements: cut selection, proximal regularization, risk-averse extensions (e.g., CVaR) with risk-adjusted duals, and SDDiP for mixed-integer stages using strengthened cuts. In exams, candidates must describe the forward/backward pass, write the Benders cut formula, explain why stagewise independence is required (cost-to-go depends only on current state), and distinguish SDDP from SAA (SAA solves a large deterministic equivalent; SDDP builds an adaptive approximation). Traps: applying SDDP without relatively complete recourse (needs feasibility cuts); assuming cuts are supporting hyperplanes at trial points (they are global lower bounds, tight only at xt-1^k if dual is unique).

Frank‑Wolfe and Conditional Gradient Methods for Projection‑Free Optimization

Frank-Wolfe (Conditional Gradient) solves minx∈C f(x) for compact convex C, smooth convex f, without projections. Each iteration solves a linear minimization oracle (LMO): s_k = argmins∈C ⟨∇f(x_k), s⟩, then updates xk+1 = x_k + γ_k (s_k - x_k) with γ_k ∈ [0, 1] (e.g., γ_k = 2/(k+2) or line search). The iterate remains in C by convexity. The method achieves primal gap f(x_k) - f(x*) ≤ 2L D² / (k+2) where L is the Lipschitz constant of ∇f and D is the diameter of C. For strongly convex f, the rate improves to O(1/k) but not linear unless the optimum lies in the relative interior of C. The curvature constant C_f = supx,s∈C, γ∈[0,1] 2/γ² (f(x + γ(s-x)) - f(x) - γ⟨∇f(x), s-x⟩) governs the convergence bound. Variants address slow tail convergence: Away-step FW (AFW) chooses between FW steps and away steps v_a = argmaxv∈S_k ⟨∇f(x_k), v⟩ from the active set; AFW achieves linear convergence for strongly convex f over polytopes. Pairwise FW (PFW) combines a FW vertex and an away vertex in a single step. Fully-Corrective FW (FCFW) re-optimizes over the convex hull of visited vertices (solving a small QP), achieving finite convergence for polyhedral C. LMO complexity depends on C: nuclear norm ball {X | ‖X‖_* ≤ τ} → leading singular vector (O(mn) via power iteration); ℓ₁-ball → signed coordinate selection; Birkhoff polytope → linear assignment (Hungarian, O(n³)); flow polytope → shortest path. In exams, candidates must write the FW update, derive the O(1/k) gap bound using the curvature constant, explain why FW is projection-free and when advantageous (e.g., nuclear norm ball: projection needs full SVD, LMO needs only top singular vector), and contrast AFW with standard FW. Trap: claiming linear convergence for vanilla FW on strongly convex functions (only holds if solution is strictly interior). Another trap: using FW for non-convex f without modification; non-convex FW uses ‖x_k - s_k‖ as stationarity measure, achieving O(1/√k) FW gap.

Mixed‑Integer Nonlinear Programming: Outer Approximation and Generalized Benders Decomposition

Mixed‑Integer Nonlinear Programming (MINLP) problems combine integer variables with nonlinear constraints: min f(x, y) s.t. g(x, y) ≤ 0, h(x, y) = 0, x ∈ X ⊆ ℝⁿ, y ∈ Y ⊆ ℤ^p. When f, g, h are convex in (x, y) for fixed y, the problem is a convex MINLP. Two classical decomposition algorithms are Outer Approximation (OA) and Generalized Benders Decomposition (GBD). OA (Duran & Grossmann, 1986) alternates between solving a MILP master problem and an NLP subproblem. The master minimizes a linear approximation: min η s.t. η ≥ f(x^k, y^k) + ∇f(x^k, y^k)ᵀ (x - x^k, y - y^k), 0 ≥ g(x^k, y^k) + ∇g(x^k, y^k)ᵀ (x - x^k, y - y^k), h(x^k, y^k) + ∇h(x^k, y^k)ᵀ (x - x^k, y - y^k) = 0, x ∈ X, y ∈ Y, where (x^k, y^k) are previous NLP solutions. The NLP subproblem fixes y = ŷ from the master; if feasible, it provides a new linearization point and an upper bound; if infeasible, a feasibility NLP (min ‖slack‖) generates a feasibility cut. OA converges finitely for convex MINLPs because the master’s feasible region is a polyhedral outer approximation that tightens with each cut. GBD (Geoffrion, 1972) projects onto the integer space: master is miny∈Y η s.t. η ≥ L(y, λ^k, μ^k) for all previous dual multipliers, where L is the NLP Lagrangian. The subproblem for fixed y = ŷ is the primal NLP; its dual provides the Benders cut. GBD requires a constraint qualification for strong duality. For nonconvex MINLPs, neither OA nor GBD guarantees global optimality; spatial branch-and-bound or extended cutting plane methods are used. ECP (Westerlund & Pettersson, 1995) solves MILP master problems with linearizations at integer points, avoiding NLP subproblems. In exams, candidates must formulate the OA master for a given convex MINLP, write optimality and feasibility cuts, explain the difference between OA (primal decomposition, requires NLP solves) and GBD (dual decomposition, requires dual solutions), and identify when each is preferred (OA when NLP subproblems are easy; GBD when integer space is small and duals are readily available). Trap: applying OA to nonconvex MINLPs claiming global convergence (linearizations aren't global underestimators). Another trap: forgetting OA needs feasible NLP subproblems; if infeasible, a feasibility NLP generates a cut.

  • Assuming standard KKT conditions are necessary for MPECs — they fail at every feasible point; use M‑stationarity or S‑stationarity instead.
  • Using Euclidean gradient descent with projection on matrix manifolds (Stiefel, SPD) — this leaves the manifold; use Riemannian gradient and retractions (QR, polar, exponential).
  • Applying SDDP without stagewise independence — the cost‑to‑go function then depends on the entire history, breaking the dynamic programming structure.
  • Claiming linear convergence for vanilla Frank‑Wolfe on strongly convex objectives — linear convergence requires the optimum to be in the relative interior or the use of away‑step variants.
  • Using Outer Approximation on nonconvex MINLPs and expecting global optimality — OA cuts are supporting hyperplanes only for convex functions; for nonconvex problems they cut off feasible regions.
  • Confusing the Benders cuts in GBD (derived from dual of NLP subproblem) with OA cuts (derived from primal NLP solution gradients) — GBD requires strong duality, OA does not.
  • Treating the Riemannian gradient on S++n with the affine‑invariant metric as ∇f(X) — it is X ∇f(X) X; the Euclidean gradient is not tangent to the manifold under this metric.

Polynomial Optimization and Sum‑of‑Squares Relaxations

Polynomial optimization minimizes a multivariate polynomial f(x) over a basic semialgebraic set {x ∈ ℝⁿ | gᵢ(x) ≥ 0, hⱼ(x) = 0}. The problem is NP‑hard because it subsumes integer and nonconvex quadratic programming. A convex relaxation hierarchy (Lasserre 2001; Parrilo 2000) replaces the feasible set with a sequence of semidefinite programs built from moment and localizing matrices. At order d, a moment vector y indexed by monomials up to degree 2d is introduced, requiring Md(y) ⪰ 0 and Md‑deg(gᵢ)/2(gᵢ y) ⪰ 0. The SDP yields a lower bound; bounds converge to the global optimum under Archimedean conditions (Putinar’s Positivstellensatz). Low‑order relaxations (d = 1,2,3) often give exact solutions for problems up to a few dozen variables. The dual is an SOS program: maximize λ such that f(x) − λ = σ₀(x) + Σ σᵢ(x)gᵢ(x) + Σ τⱼ(x)hⱼ(x) with σ, τ SOS of bounded degree. Solvers (MOSEK, SeDuMi) compute the same bound. Examiners test writing moment matrices, stating Putinar’s condition, and explaining finite convergence for zero‑dimensional varieties. A common trap: claiming the first‑order relaxation (d = 1) is always exact for quadratic programs; it is exact only for convex feasible sets or when the Shor relaxation is tight.

Interior‑Point Methods for Convex Optimization: Primal‑Dual Path‑Following

Primal‑dual interior‑point methods solve min cᵀx s.t. Ax = b, x ∈ K with K a symmetric cone (nonnegative orthant, second‑order cone, or positive semidefinite cone). The algorithm follows the central path: Ax = b, Aᵀy + s = c, x ∘ s = μ e, with x, s ∈ int(K), μ > 0. Here ∘ is the Jordan product and e the identity. Each iteration computes a Newton step for the linearized system, giving directions (Δx, Δy, Δs). A line search maintains strict feasibility and reduces μ by (1 − θ/√ν), where ν is the barrier parameter (ν = n for ℝ₊ⁿ, ν = n+1 for the second‑order cone of dimension n, ν = n for S₊ⁿ). Iteration complexity is O(√ν log(1/ε)). For LP (K = ℝ₊ⁿ) this reduces to Mehrotra’s predictor‑corrector; for SDP the search direction requires solving an m × m Schur complement system. Examiners expect the perturbed KKT system for a given cone, derivation of Newton equations, and the role of ν in the complexity bound. A frequent mistake: confusing Nesterov‑Todd scaling for SDP with diagonal scaling for LP; the former preserves the Jordan algebra structure and is essential for polynomial‑time guarantees.

Worked Example: First‑Order SOS Relaxation
Consider min x₁⁴ + x₂⁴ − 2x₁²x₂² s.t. x₁² + x₂² ≥ 1. Formulate the degree‑2 (d = 1) SOS relaxation and state the resulting SDP.
The objective is f(x) = (x₁² − x₂²)². The constraint is g(x) = x₁² + x₂² − 1 ≥ 0. For d = 1 the monomial basis up to degree 2 is [1, x₁, x₂, x₁², x₁x₂, x₂²]. The moment matrix M₁(y) is a 6×6 symmetric matrix with entries yα+β. The localizing matrix for g is M₀(g y) = y00 + y20 + y02 − y00 = y20 + y02 − 1 (since y00 = 1). The SDP: minimize y40 + y04 − 2y22 subject to M₁(y) ⪰ 0, y20 + y02 ≥ 1, y00 = 1. This SDP yields the exact optimum 0 attained at (±1,0) and (0,±1).
Exam‑Day Strategy
When a question asks for an SOS relaxation, first list the monomial basis up to the required degree, then write the moment matrix symbolically. Do not expand the full matrix unless explicitly required; stating its block structure and the localizing constraints earns most marks. For interior‑point questions, remember the three ingredients: barrier function, central path equations, and Newton step. Write the perturbed complementarity condition x ∘ s = μ e for the specific cone; this distinguishes LP, SOCP, and SDP instantly.

Sequential Quadratic Programming and Trust‑Region Methods for Nonlinear Optimization

Sequential Quadratic Programming (SQP) solves smooth nonlinear programs min f(x) s.t. cE(x) = 0, cI(x) ≤ 0 by generating quadratic subproblems approximating the Lagrangian. At iteration k, with iterate xk and multiplier estimates λk, μk, the subproblem is min ∇fkᵀd + ½ dᵀBkd s.t. ∇cE,kᵀd + cE,k = 0, ∇cI,kᵀd + cI,k ≤ 0, where Bk approximates the Lagrangian Hessian (exact or BFGS). The solution dk gives a trial step xk + dk. Global convergence uses a merit function (ℓ₁ penalty or augmented Lagrangian) with line search, or a trust‑region framework. Trust‑region SQP solves min ∇fkᵀd + ½ dᵀBkd s.t. linearized constraints, ‖d‖ ≤ Δk. The radius Δk is adjusted by the ratio of actual to predicted reduction: high ratio accepts the step and may increase Δk; low ratio rejects and shrinks Δk. This avoids merit functions and handles inconsistent linearizations. Examiners test the QP subproblem KKT conditions, Hessian approximation roles (exact, BFGS, limited‑memory), and the trust‑region update rule. A classic trap: claiming SQP with exact Hessian always converges quadratically; quadratic convergence requires the strong second‑order sufficient condition and a sufficiently accurate Hessian, otherwise the method may stall or converge to a non‑stationary point.

Coordinate Descent and Randomized Block Coordinate Methods for Large‑Scale Problems

Coordinate descent (CD) minimizes f(x) = g(x) + Σ hᵢ(xᵢ) by cyclically or randomly updating one coordinate (or block) while fixing others. For convex f with Lipschitz gradient, cyclic CD achieves O(1/k); randomized CD (RCD) with uniform sampling gives the same expectation bound with a simpler proof. Accelerated variants attain O(1/k²) for smooth convex problems. With strong convexity (modulus μ) and coordinate‑wise Lipschitz constants Lᵢ, linear convergence factors are 1 − μ/(n Lmax) for cyclic CD and 1 − μ/(Σ Lᵢ) for RCD with importance sampling proportional to Lᵢ. Block CD extends this to variable groups, crucial for structured sparsity (group Lasso, matrix factorization). Per‑iteration cost is solving a low‑dimensional subproblem, often a proximal mapping. In distributed settings, workers update local blocks and communicate changed coordinates, yielding asynchronous parallel CD (e.g., Hogwild!). Examiners expect the proximal coordinate update: xᵢ ← proxα hᵢ(xᵢ − α ∇ᵢ g(x)), the RCD convergence theorem with importance sampling, and why asynchronous updates tolerate stale gradients under bounded delay. A common error: applying CD to non‑separable nonconvex objectives expecting global convergence; only convergence to a stationary point is guaranteed under the Kurdyka‑Łojasiewicz property.

Low‑Rank Matrix Recovery via Nuclear Norm Minimization and Nonconvex Factorization

Recovering a low‑rank matrix X ∈ ℝm×n from linear measurements y = A(X) + noise arises in collaborative filtering, system identification, and quantum tomography. The convex relaxation replaces rank(X) with the nuclear norm ‖X‖* = Σ σᵢ(X), giving min ‖X‖* s.t. A(X) = y (or with data‑fidelity). This SDP is solved by proximal gradient (singular value thresholding) or ADMM. Exact recovery requires the restricted isometry property (RIP) for A or incoherence of the true matrix. A nonconvex alternative factorizes X = UVᵀ (U ∈ ℝm×r, V ∈ ℝn×r) and solves min ½‖A(UVᵀ) − y‖² + (λ/2)(‖U‖F² + ‖V‖F²). The regularization balances U, V scales and removes scaling ambiguity. Gradient descent on the factorized problem converges globally under RIP and proper initialization (e.g., spectral initialization from top‑r singular vectors of A*(y)). Per‑iteration cost is O(r(m+n)) versus O(min(m,n)² max(m,n)) for full SVD in the nuclear‑norm proximal step, making factorization attractive for large problems. Examiners test the nuclear‑norm proximal operator (singular value thresholding), the RIP condition for exact recovery, and gradients of the factorized objective w.r.t. U and V. A frequent trap: claiming nuclear‑norm minimization always yields the minimum‑rank solution; it does so only under RIP or incoherence, otherwise it may return a higher‑rank matrix satisfying the measurements.

  • Assuming the first‑order SOS relaxation is exact for all polynomial programs — it is exact only under specific algebraic conditions (e.g., zero‑dimensional variety, Archimedean quadratic module).
  • Confusing the barrier parameter ν for different symmetric cones — ν = n for the nonnegative orthant, ν = n+1 for the second‑order cone, ν = n for the semidefinite cone of size n.
  • Claiming SQP with BFGS Hessian achieves superlinear convergence without the Dennis‑Moré condition — the quasi‑Newton update must satisfy the secant equation asymptotically.
  • Using a fixed trust‑region radius in SQP — the radius must be updated based on the agreement ratio; a fixed radius can cause stagnation.
  • Applying cyclic coordinate descent to a non‑separable nonconvex function and expecting global convergence — only convergence to a stationary point can be guaranteed under the Kurdyka‑Łojasiewicz property.
  • Believing nuclear‑norm minimization always recovers the true rank — exact recovery requires RIP or incoherence; without them the solution may be higher rank.
  • Ignoring the scaling ambiguity in matrix factorization — without balanced regularization (‖U‖F² + ‖V‖F²) the problem is ill‑posed and gradient descent may diverge.

These advanced topics complete the optimization toolkit required for high‑level competitive examinations.

Column Generation and Branch‑and‑Price for Large‑Scale Integer Programming

Column generation solves linear programs with exponentially many variables by iteratively adding only columns that improve the objective. The master problem is a restricted LP with a subset of columns; the pricing problem (often a shortest‑path, knapsack, or resource‑constrained shortest‑path subproblem) searches for a column with negative reduced cost. Dantzig‑Wolfe decomposition provides the theoretical foundation: the original integer program is reformulated as a convex combination of extreme points of a sub‑polyhedron, yielding a set‑partitioning or set‑covering master. In branch‑and‑price, column generation runs at each node of a branch‑and‑bound tree; branching decisions must preserve the pricing problem’s structure. Ryan‑Foster branching on variable pairs is a classic choice for set‑partitioning masters because it keeps the pricing problem a standard shortest‑path problem. Column management (adding, removing, stabilizing) is critical: excessive columns degrade LP solve time, while premature removal discards columns needed later. Stabilization techniques such as dual‑optimal inequalities, interior‑point stabilization, or weighted Dantzig‑Wolfe reduce dual oscillations and accelerate convergence. Applications include cutting‑stock, vehicle routing with time windows, crew scheduling, and large‑scale network design. Examiners expect the reduced‑cost formula c̄ⱼ = cⱼ − πᵀAⱼ, the distinction between restricted and full master, and the impact of branching on pricing feasibility. A common trap is assuming column generation alone yields an integer solution; it only solves the LP relaxation, and integrality requires branching or cutting planes.

Operator Splitting Methods: Douglas‑Rachford, Peaceman‑Rachford, and ADMM Variants

Operator splitting solves monotone inclusion problems 0 ∈ A(x) + B(x) where A and B are maximal monotone operators. The Douglas‑Rachford (DR) iteration uses the resolvents JA = (I + A)⁻¹ and JB = (I + B)⁻¹:

xk+1 = JA(2JB(xk) − xk) + xk − JB(xk).

Convergence to a zero of A+B is guaranteed from any starting point; the ergodic average yields an O(1/k) rate in the primal‑dual gap. The Peaceman‑Rachford (PR) method uses xk+1 = (2JA−I)(2JB−I)xk. PR converges for linear operators (e.g., saddle‑point problems) but may diverge for general nonlinear monotone operators. ADMM is precisely DR applied to the dual of a separable convex problem min f(x) + g(z) s.t. Ax + Bz = c. The standard ADMM updates are:

xk+1 = argmin f(x) + (ρ/2)‖Ax + Bzk − c + uk‖²,
zk+1 = argmin g(z) + (ρ/2)‖Axk+1 + Bz − c + uk‖²,
uk+1 = uk + Axk+1 + Bzk+1 − c.

Variants include linearized ADMM (proximal linearization of the quadratic term), proximal ADMM (adding proximal terms to x‑ and z‑updates), and over‑relaxed ADMM (using α ∈ (0,2) in the dual update). Under strong convexity of f or g, ADMM achieves linear convergence; otherwise the ergodic O(1/k) rate is tight. The DR framework also yields the primal‑dual hybrid gradient (PDHG) / Chambolle‑Pock algorithm for saddle‑point problems. Examiners test the ADMM–DR equivalence, the role of the penalty parameter ρ, and the distinction between ergodic and non‑ergodic convergence guarantees.

Worked Example: Consensus ADMM for Distributed Averaging
Consider N agents each holding a scalar xᵢ. They wish to compute the average (1/N)∑xᵢ via consensus ADMM on a connected graph. Write the local variable zᵢ and global consensus variable y. The problem is min ∑ (1/2)(zᵢ − xᵢ)² s.t. zᵢ = y ∀i. Derive the ADMM updates and show that the y‑update reduces to the average of the current zᵢ plus dual variables.
The augmented Lagrangian is Lρ = ∑[(1/2)(zᵢ−xᵢ)² + uᵢ(zᵢ−y) + (ρ/2)(zᵢ−y)²]. The zᵢ‑update: zᵢ ← (xᵢ + ρy − uᵢ)/(1+ρ). The y‑update minimizes ∑[−uᵢy + (ρ/2)(zᵢ−y)²] giving y ← (∑(ρzᵢ + uᵢ))/(Nρ) = (1/N)∑zᵢ + (1/(Nρ))∑uᵢ. The dual update: uᵢ ← uᵢ + ρ(zᵢ − y). This matches the standard consensus ADMM form.
Exam‑Day Strategy
Memorize the DR iteration formula and the ADMM update order (x, then z, then dual). When asked for convergence rates, state ergodic O(1/k) for general convex, linear under strong convexity, and note that PR is only safe for linear operators. For ADMM variants, recall that linearized ADMM replaces the quadratic term with a proximal linearization, useful when the x‑ or z‑subproblem lacks a closed form.

Federated Optimization Algorithms: FedAvg, SCAFFOLD, and Convergence Analysis

Federated learning minimizes a global objective F(w) = ∑i=1N pᵢ Fᵢ(w) where each client i holds a local loss Fᵢ and pᵢ are participation weights. The seminal FedAvg algorithm performs E local SGD steps on each selected client before averaging models on the server. With heterogeneous data (non‑IID), client drift causes local models to diverge, slowing convergence. The convergence bound for FedAvg on smooth non‑convex losses with partial participation (fraction C) and K selected clients per round is O(1/√(KT)) + O(E²σ²/K), where σ² bounds gradient variance. SCAFFOLD (Stochastic Controlled Averaging for Federated Learning) introduces control variates cᵢ on each client and a global control variate c on the server to correct drift. The local update becomes wᵢ ← wᵢ − η(∇Fᵢ(wᵢ) − cᵢ + c), and after local steps the server updates c ← c + (1/N)∑(cᵢ⁺ − cᵢ). SCAFFOLD achieves the same O(1/√(KT)) rate as centralized SGD without the E² penalty, provided control variates are updated exactly. Communication compression (random sparsification, quantization) combined with error‑feedback maintains convergence. Partial participation and straggler tolerance are modeled by random client sampling each round; convergence proofs typically assume bounded dissimilarity ‖∇Fᵢ(w) − ∇F(w)‖ ≤ ζ. Examiners focus on the drift term in FedAvg, the control‑variate mechanism in SCAFFOLD, and the distinction between client‑level and server‑level learning rates.

Adaptive Regularization with Cubics (ARC) and High‑Order Methods for Nonconvex Optimization

ARC minimizes a nonconvex twice‑differentiable function f by building a cubic model at the current iterate xk:

mk(s) = f(xk) + ∇f(xk)ᵀs + (1/2)sᵀ∇²f(xk)s + (σk/3)‖s‖³.

The step sk is computed (approximately) by solving min mk(s), typically via a truncated Lanczos method that finds a direction of negative curvature when the Hessian is indefinite. The regularization parameter σk is adapted via the agreement ratio ρk = (f(xk) − f(xk+sk)) / (mk(0) − mk(sk)): if ρk ≥ η₁ accept the step and possibly decrease σ; otherwise reject and increase σ. Under standard assumptions (Lipschitz gradient and Hessian), ARC converges to a second‑order stationary point (‖∇f‖ ≤ ε, λmin(∇²f) ≥ −√ε) in at most O(ε−3/2) iterations, optimal for second‑order methods. High‑order generalizations replace the cubic term with a p‑th order tensor term (σk/p)‖s‖p and achieve O(ε−(p+1)/p) complexity. Practical implementations use adaptive tensor methods (e.g., AR

) with inexact subproblem solves. Unlike trust‑region methods, ARC does not require solving a constrained subproblem; the cubic regularization naturally handles negative curvature. Examiners test the cubic model formulation, the role of σk, the agreement ratio, and the O(ε−3/2) complexity bound. A frequent error is confusing ARC with cubic regularization of Newton’s method (which uses a fixed σ) or assuming the cubic subproblem is convex (it is not when the Hessian has negative eigenvalues).

Submodular Function Minimization and Maximization: Continuous and Discrete Algorithms

A set function F: 2V → ℝ is submodular if F(A) + F(B) ≥ F(A∪B) + F(A∩B) for all A,B ⊆ V. Minimization can be done in polynomial time via the ellipsoid method on the Lovász extension f̂: [0,1]n → ℝ, defined as f̂(x) = 𝔼[F({i : xᵢ ≥ θ})] for θ ∼ Uniform[0,1]. The Lovász extension is convex, and its subgradients correspond to bases of the submodular polyhedron. Combinatorial strongly polynomial algorithms (Iwata‑Fleischer‑Fujishige, Orlin) achieve O(n⁵) or O(n⁶) time. For maximization, the greedy algorithm that iteratively adds the element with largest marginal gain yields a (1−1/e) approximation for monotone submodular functions under a cardinality constraint. The continuous greedy algorithm optimizes the multilinear extension F̃(x) = ∑S⊆V F(S) ∏i∈S xᵢ ∏j∉S (1−xⱼ) over the matroid polytope, followed by pipage rounding or swap rounding to obtain an integral solution with the same guarantee. For non‑monotone submodular maximization, the double‑greedy algorithm achieves a 1/2 approximation. Stochastic gradient methods on the multilinear extension (e.g., measured continuous greedy) provide O(1/ε²) convergence to a stationary point. Examiners expect the definition of the Lovász extension, the greedy (1−1/e) bound, the continuous greedy + rounding pipeline, and the distinction between minimization (exact polynomial) and maximization (approximation). A common trap is applying the greedy guarantee to non‑monotone functions or ignoring the matroid constraint in continuous greedy.

  • Assuming column generation alone yields integer optimal solutions — it only solves the LP relaxation; integrality requires branching or cutting planes.
  • Confusing Peaceman‑Rachford with Douglas‑Rachford — PR diverges for general nonlinear monotone operators; only DR guarantees convergence.
  • Neglecting the drift term in FedAvg convergence analysis — the E² factor appears precisely because of client heterogeneity.
  • Treating the ARC cubic subproblem as convex — it is nonconvex when the Hessian has negative eigenvalues; the algorithm exploits negative curvature.
  • Applying the greedy (1−1/e) guarantee to non‑monotone submodular maximization — the guarantee holds only for monotone functions under a cardinality or matroid constraint.
  • Overlooking the need for control‑variate synchronization in SCAFFOLD — stale control variates reintroduce drift and degrade the rate to FedAvg’s.
  • Believing the multilinear extension is convex — it is neither convex nor concave; continuous greedy works on a convex relaxation (the matroid polytope) but the extension itself is nonconvex.

Nesterov's Accelerated Gradient Methods and Momentum Techniques

Nesterov's accelerated gradient method achieves the optimal convergence rate O(1/k²) for smooth convex functions, improving on the O(1/k) rate of standard gradient descent. The method introduces a momentum term that extrapolates the current iterate using a weighted combination of the previous two iterates. The classic scheme maintains two sequences: the primary iterate x_k and an auxiliary sequence y_k. At each step, y_k = x_k + β_k (x_k − xk−1) where β_k = (k−1)/(k+2) for the constant step‑size version. The gradient is evaluated at y_k, and xk+1 = y_k − α ∇f(y_k). This extrapolation exploits the curvature of the objective to accelerate convergence without requiring higher‑order derivatives.

For strongly convex functions with condition number κ, the accelerated rate becomes O((√κ−1)/(√κ+1))^k, which matches the information‑theoretic lower bound for first‑order methods. The momentum parameter β_k can be adapted via line‑search or by estimating the local Lipschitz constant, leading to practical variants such as Nesterov's universal gradient method. A common pitfall is applying the standard momentum schedule to non‑convex problems; without convexity the extrapolation may diverge. In practice, restarted versions (e.g., gradient restart, function‑value restart) restore stability and retain acceleration on locally convex regions.

Heavy‑ball momentum, proposed by Polyak, uses a constant β and updates xk+1 = x_k − α ∇f(x_k) + β (x_k − xk−1). While it often accelerates empirically, its theoretical guarantees are weaker: for convex quadratics it achieves linear convergence with optimal β, but for general convex functions it does not improve the worst‑case O(1/k) rate. Nesterov's method can be interpreted as a discretization of a second‑order ODE (the Bregman Lagrangian framework), which explains the optimal rate and suggests continuous‑time analysis for designing new algorithms.

Extensions include accelerated proximal gradient for composite objectives f(x) = g(x) + h(x) where h is non‑smooth but proximable. The update becomes y_k = x_k + β_k (x_k − xk−1), xk+1 = proxα h(y_k − α ∇g(y_k)). This retains O(1/k²) for the smooth part. Accelerated coordinate descent and accelerated stochastic variance‑reduced methods (e.g., Katyusha) combine momentum with variance reduction to achieve near‑optimal rates for finite‑sum problems.

Primal‑Dual Hybrid Gradient (Chambolle‑Pock) for Saddle‑Point Problems

The Chambolle‑Pock algorithm solves convex‑concave saddle‑point problems of the form min_x max_y ⟨Kx, y⟩ + g(x) − h*(y), where g and h* are proper closed convex functions and K is a linear operator. It is a primal‑dual method that updates the primal variable x and dual variable y simultaneously using proximal operators. The iterations are: yk+1 = proxσ h*(y_k + σ K x̄_k), xk+1 = proxτ g(x_k − τ K^T yk+1), x̄k+1 = xk+1 + θ (xk+1 − x_k). The step‑sizes τ, σ must satisfy τ σ ‖K‖² < 1 for convergence; θ ∈ [0,1] controls over‑relaxation (θ = 1 gives the original scheme).

The algorithm achieves an ergodic O(1/k) convergence rate in terms of the primal‑dual gap. If either g or h* is strongly convex, a linear rate can be obtained by adapting τ, σ, and θ. The method is particularly effective for total variation denoising, image reconstruction, and optimal transport where K is a gradient or divergence operator. Its projection‑free nature (only proximal maps of g and h* are needed) makes it attractive when projections onto constraint sets are expensive.

Compared to ADMM, Chambolle‑Pock does not require solving a linear system at each iteration; it only needs matrix‑vector multiplications with K and K^T. However, ADMM can handle non‑separable quadratic terms more naturally. The primal‑dual hybrid gradient is also known as the Primal‑Dual Hybrid Gradient (PDHG) method. Variants include the preconditioned PDHG, where diagonal preconditioners adapt τ and σ per coordinate, and the stochastic PDHG for large‑scale problems where K is accessed via random sampling.

Convergence analysis relies on the monotone operator framework: the optimality conditions are a monotone inclusion 0 ∈ (∂g × ∂h*) + (0, K; −K^T, 0)(x, y). The algorithm is a forward‑backward splitting on this operator with a skew‑symmetric forward step. The step‑size condition ensures the forward step is cocoercive. Practical implementations sometimes use adaptive rules such as τ_k = τ0 / √k, σ_k = σ0 / √k to handle unknown operator norms, though constant step‑sizes are standard when ‖K‖ is known.

Worked Example: Total Variation Denoising
Consider the 1‑D total variation denoising problem min_x (1/2)‖x − b‖² + λ ‖Dx‖₁ where D is the first‑difference matrix. Formulate as a saddle‑point problem and write the Chambolle‑Pock updates explicitly.
Set g(x) = (1/2)‖x − b‖², h*(y) = ι‖y‖∞ ≤ λ(y) (indicator of the ℓ∞ ball), and K = D. Then proxτ g(v) = (v + τ b)/(1+τ). The dual proximal operator is projection onto the ℓ∞ ball: proxσ h*(u) = clip(u, −λ, λ). The updates become: yk+1 = clip(y_k + σ D x̄_k, −λ, λ); xk+1 = (x_k − τ D^T yk+1 + τ b)/(1+τ); x̄k+1 = xk+1 + θ (xk+1 − x_k). Choose τ, σ such that τ σ ‖D‖² < 1 (‖D‖² = 4 for 1‑D with Neumann boundary). This yields a simple, fully explicit algorithm.
Exam‑Day Strategy
When asked to derive a primal‑dual algorithm, first identify the saddle‑point structure: write the problem as min_x max_y ⟨Kx, y⟩ + g(x) − h*(y). Then state the step‑size condition τσ‖K‖² < 1 and the update formulas. For convergence rate questions, distinguish between ergodic O(1/k) for general convex and linear rates under strong convexity. Memorize the proximal operators of common functions (ℓ₁ norm, indicator of ℓ∞ ball, quadratic) to avoid re‑deriving them under time pressure.

Stochastic Gradient Descent with Adaptive Learning Rates: Adam, RMSProp, and Convergence Guarantees

Adaptive gradient methods adjust the learning rate per coordinate based on historical gradient magnitudes. RMSProp maintains an exponential moving average of squared gradients: v_k = β vk−1 + (1−β) g_k², and updates xk+1 = x_k − α g_k / (√v_k + ε). Adam combines RMSProp with momentum: m_k = β₁ mk−1 + (1−β₁) g_k, v_k = β₂ vk−1 + (1−β₂) g_k², followed by bias correction m̂_k = m_k/(1−β₁^k), v̂_k = v_k/(1−β₂^k), and update xk+1 = x_k − α m̂_k / (√v̂_k + ε). Typical defaults are β₁=0.9, β₂=0.999, ε=10⁻⁸.

Despite widespread empirical success, the original Adam algorithm can fail to converge even on simple convex problems due to the interaction between momentum and adaptive scaling. A counterexample shows that the effective step‑size can increase when gradients are sparse, violating the diminishing step‑size condition required for convergence. AMSGrad fixes this by using the maximum of past v̂_k: v̂_k^max = max(v̂k−1^max, v̂_k), ensuring the denominator is non‑decreasing. With this modification, convergence to a stationary point for non‑convex objectives and O(√T) regret for online convex optimization can be proved under bounded gradients.

Recent analyses have established tighter bounds: for convex Lipschitz functions, Adam‑type methods achieve O(log T / √T) regret with appropriate step‑size schedules. In the stochastic non‑convex setting, convergence to an ε‑stationary point requires O(ε⁻⁴) iterations under standard assumptions, matching SGD up to logarithmic factors. However, the constants depend on the condition number of the diagonal preconditioner. Practical recommendations include using a warm‑up phase for the learning rate, clipping gradients, and decaying α as α₀ / √k to guarantee convergence.

Other adaptive methods include AdaGrad (accumulates all past squared gradients, leading to vanishing step‑sizes), AdaDelta (uses RMS of updates instead of learning rate), and Nadam (Nesterov‑accelerated Adam). The choice among them often hinges on the sparsity of gradients and the presence of noisy curvature. For deep learning, Adam with weight decay (AdamW) decouples weight decay from the adaptive learning rate, improving generalization.

Nonconvex Optimization under the Polyak‑Łojasiewicz Condition

The Polyak‑Łojasiewicz (PL) condition is a relaxation of strong convexity that still guarantees linear convergence of gradient descent. A differentiable function f satisfies the PL condition with constant μ > 0 if ½‖∇f(x)‖² ≥ μ (f(x) − f*) for all x, where f* is the global minimum value. This inequality implies that any stationary point is a global minimizer, but the function need not be convex. Many over‑parameterized models (e.g., wide neural networks, linear regression with redundant features) satisfy the PL condition locally or globally.

Under the PL condition, gradient descent with fixed step‑size α ≤ 1/L (L is the Lipschitz constant of ∇f) converges linearly: f(x_k) − f* ≤ (1 − αμ)^k (f(x0) − f*). The rate depends only on the condition number L/μ, not on the dimension. Stochastic gradient descent with diminishing step‑sizes α_k = Θ(1/k) achieves O(1/k) convergence in expectation; with constant step‑size and variance reduction (SVRG, SARAH), linear convergence up to a noise floor is possible. The PL condition also enables fast convergence of coordinate descent, proximal gradient, and accelerated methods.

A related concept is the error bound condition: dist(x, X*) ≤ c ‖∇f(x)‖ for some c > 0, where X* is the set of minimizers. The PL condition implies an error bound, but the converse is not true. The Kurdyka‑Łojasiewicz (KL) property generalizes PL to non‑smooth and non‑convex functions using a desingularizing function φ. For semi‑algebraic functions, the KL property holds with φ(s) = c s1−θ, θ ∈ [0,1). The exponent θ determines the convergence rate: θ = 1/2 yields linear, θ ∈ (1/2,1) yields sublinear polynomial, θ = 0 yields finite‑time convergence.

In practice, verifying the PL condition is difficult. However, for specific problem classes (e.g., phase retrieval, low‑rank matrix recovery, certain neural network training objectives), the PL condition can be proved under restricted isometry or over‑parameterization assumptions. Algorithms that exploit PL include gradient descent with Polyak step‑size α_k = (f(x_k) − f*)/‖∇f(x_k)‖², which achieves finite‑time convergence if f* is known. Adaptive methods like Adam can also benefit from PL geometry, though theoretical guarantees are less developed.

Distributionally Robust Optimization with Wasserstein Ambiguity Sets

Distributionally robust optimization (DRO) hedges against distributional ambiguity by optimizing the worst‑case expected cost over a family of probability distributions (an ambiguity set). The Wasserstein ambiguity set centers on an empirical distribution P̂_N from N samples and includes all distributions within Wasserstein distance ρ: 𝒫_ρ = {P : W_c(P, P̂_N) ≤ ρ}, where W_c is the optimal transport cost with metric c. This set captures both statistical confidence (via ρ) and geometric structure of the underlying space.

For a loss function ℓ(x, ξ) that is convex in x and Lipschitz in ξ, the worst‑case expectation supP∈𝒫_ρ 𝔼_P[ℓ(x, ξ)] admits a tractable dual reformulation: infλ≥0 { λ ρ + (1/N) ∑i=1^N supξ [ℓ(x, ξ) − λ c(ξ, ξ_i)] }. If ℓ is piecewise linear or quadratic in ξ, the inner supremum reduces to a convex program. For linear losses ℓ(x, ξ) = a(x)^T ξ + b(x), the DRO problem becomes a regularized empirical risk minimization: (1/N) ∑ ℓ(x, ξ_i) + ρ ‖a(x)‖_*, where ‖·‖_* is the dual norm of the transport cost. This reveals a direct link between Wasserstein DRO and regularization.

The radius ρ controls the trade‑off between robustness and performance. Statistical guarantees show that with probability 1−β, the true distribution lies in 𝒫_ρ if ρ ≥ C (log(1/β)/N)1/d for dimension d, assuming light‑tailed data. This finite‑sample guarantee is dimension‑dependent, which can be conservative in high dimensions. Recent work uses sliced Wasserstein or maximum mean discrepancy to mitigate the curse of dimensionality.

Computationally, Wasserstein DRO can be solved via cutting‑plane methods, dual gradient ascent, or by reformulating as a conic program when the support is finite. For continuous supports, scenario‑based approximations or sample average approximation of the dual are used. The method has been applied to portfolio optimization, queueing control, and robust machine learning (e.g., adversarial training). A key advantage over moment‑based ambiguity sets is that Wasserstein sets preserve the support structure and do not require moment estimation.

Adjustable Robust Optimization with Affine Decision Rules

Adjustable robust optimization (ARO) extends static robust optimization by allowing second‑stage decisions to adapt to the realized uncertainty. In a two‑stage formulation the first‑stage variables x are chosen before the uncertainty ξ is revealed, while the second‑stage variables y(ξ) are functions of the observation. The problem reads

minx∈X maxξ∈𝒰 miny∈Y(x,ξ) cTx + dTy(ξ)

where 𝒰 is an uncertainty set. Because optimizing over all measurable functions y(·) is intractable, a common approximation restricts y(ξ) to an affine form y(ξ) = Y₀ + Y₁ξ. This affine decision rule (ADR) transforms the infinite‑dimensional problem into a finite‑dimensional robust counterpart that can often be reformulated as a conic program. When 𝒰 is polyhedral or ellipsoidal, the resulting model is a linear or second‑order cone program respectively.

The quality of ADR depends on the geometry of 𝒰 and the structure of the recourse constraints. For problems with fixed recourse (the matrix multiplying y does not depend on ξ) and a simplex or box uncertainty set, ADR can be provably optimal. In general, ADR can be conservative; tighter approximations include piecewise‑affine rules, polynomial decision rules, or the use of lift‑and‑project hierarchies. A practical trade‑off is to start with ADR, evaluate the optimality gap via simulation, and enrich the rule class only if the gap is unacceptable.

Applications include multi‑period inventory control where replenishment orders adjust to observed demand, unit commitment in power systems where generation dispatch reacts to renewable output, and adjustable portfolio optimization where rebalancing follows market shocks. In each case the affine rule yields a tractable model that captures the most important adaptive behavior while remaining solvable by off‑the‑shelf conic solvers.

Key theoretical results: (1) Ben‑Tal, Goryashvili, Guslitzer, and Nemirovski (2004) showed that for constraint‑wise uncertainty the ADR counterpart is exact when the uncertainty set is a Cartesian product of intervals. (2) Bertsimas and Goyal (2012) established that for a budgeted uncertainty set the optimal value of the ADR approximation converges to the true adjustable optimum as the budget parameter grows. (3) The dual of the ADR problem provides a certificate of robustness and can be used to derive cutting planes for a column‑and‑constraint generation algorithm that iteratively refines the decision rule.

Distributionally Robust Optimization with Phi‑Divergence Ambiguity Sets

Phi‑divergence ambiguity sets generalize the Kullback‑Leibler, χ², and Hellinger distances. Given an empirical distribution P̂N = (1/N)∑i=1N δξi, the ambiguity set is

𝒫ρ = { P ≪ P̂N : Dφ(P || P̂N) ≤ ρ }

where Dφ(P||Q) = ∑ φ(dP/dQ) dQ for a convex function φ with φ(1)=0. Common choices: φ(t)=t log t (KL), φ(t)=(t−1)² (χ²), φ(t)=(√t−1)² (Hellinger). The worst‑case expectation supP∈𝒫ρ 𝔼P[ℓ(x,ξ)] admits a convex dual

infλ≥0, η { λρ + η + (1/N)∑i=1N φ* ( ℓ(x,ξi) − η / λ ) }

where φ* is the convex conjugate of φ. For KL divergence φ*(s)=es−1, yielding the familiar log‑sum‑exp reformulation; for χ², φ*(s)=s²/4 + s, giving a quadratic program. This dual is a finite‑dimensional convex program that can be solved with interior‑point methods.

Statistical guarantees: if the true distribution P* satisfies Dφ(P*||P̂N) ≤ ρ with probability 1−β, then ρ can be calibrated via Sanov’s theorem or concentration inequalities. For KL divergence, ρ scales approximately as (1/N)(log(1/β) + d) where d is the support size; for χ², ρ scales approximately as (1/N)χ²1−β(d). These radii are typically smaller than Wasserstein radii in low dimensions but suffer from the curse of dimensionality when the support is large.

Comparison with Wasserstein DRO: phi‑divergence sets only reweight the empirical atoms, preserving the support exactly, whereas Wasserstein sets allow mass transport to new points. Consequently, phi‑divergence DRO is more suitable when the support is known and fixed (e.g., discrete demand scenarios), while Wasserstein DRO is preferable for continuous distributions or when out‑of‑sample points are plausible. Both frameworks yield regularization effects: KL DRO adds an entropic penalty, χ² DRO adds a variance‑type penalty.

Applications: portfolio optimization with KL ambiguity leads to a risk‑sensitive objective that penalizes the exponential moment of losses; queueing control with χ² ambiguity yields a robust staffing rule that hedges against arrival‑rate misspecification; hypothesis testing with Hellinger ambiguity provides minimax optimal tests. In all cases the dual reformulation enables scalable computation.

Stochastic Approximation: Robbins‑Monro and Kiefer‑Wolfowitz Algorithms

Stochastic approximation (SA) solves root‑finding or optimization problems when only noisy observations are available. The Robbins‑Monro (RM) algorithm targets a zero of h(θ)=𝔼[H(θ,ξ)] by iterating θk+1 = θk − αk H(θk, ξk). Classic step‑size conditions are ∑αk=∞ and ∑αk²<∞ (e.g., αk=a/(k+b)). Under Lipschitz continuity of h and bounded noise variance, θk converges almost surely to a root θ* provided the ODE dθ/dt = −h(θ) has a globally asymptotically stable equilibrium.

The Kiefer‑Wolfowitz (KW) algorithm addresses derivative‑free optimization: minimize f(θ)=𝔼[F(θ,ξ)] by approximating the gradient via finite differences. The symmetric KW update is θk+1 = θk − αk ( F(θk+ckei, ξk⁺) − F(θk−ckei, ξk⁻) ) / (2ck) for each coordinate i. The perturbation sequence ck must satisfy ck→0, ∑αkck−1<∞, and ∑αk²ck−2<∞. A practical variant is Simultaneous Perturbation Stochastic Approximation (SPSA), which uses a single random direction Δk with i.i.d. symmetric Bernoulli entries, requiring only two function evaluations per iteration regardless of dimension.

Asymptotic normality: under regularity, √k (θk−θ*) converges in distribution to N(0, Σ) where Σ solves a Lyapunov equation involving the Jacobian ∇h(θ*) and the noise covariance. Polyak‑Ruppert averaging θ̄k = (1/k)∑i=1k θi achieves the optimal asymptotic covariance (the Cramér‑Rao bound) without needing to estimate ∇h(θ*). This makes averaged SA the method of choice for statistical estimation problems such as stochastic gradient descent for M‑estimators.

Applications: adaptive signal processing (LMS algorithm is RM with linear h), reinforcement learning (TD(0) is RM for the Bellman equation), simulation‑based optimization (KW/SPSA for black‑box objectives), and online parameter estimation in econometrics. Modern variants incorporate momentum, adaptive step‑sizes (AdaGrad, Adam), and variance reduction while preserving the SA convergence framework.

Nonconvex Minimax Optimization: Gradient Descent‑Ascent, Extragradient, and Optimistic Methods

Nonconvex‑nonconcave minimax problems minx maxy f(x,y) arise in generative adversarial networks (GANs), adversarial training, and robust optimization. The standard Gradient Descent‑Ascent (GDA) updates xk+1 = xk − α∇xf(xk,yk), yk+1 = yk + α∇yf(xk,yk) can diverge or cycle even for simple bilinear games because the Jacobian of the game vector field has eigenvalues with positive real parts.

The Extragradient (EG) method, introduced by Korpelevich (1976), adds a look‑ahead step: compute an intermediate point (x̃,ỹ) via GDA, then update using gradients at (x̃,ỹ). For monotone operators (which include convex‑concave games) EG converges with step‑size α < 1/L where L is the Lipschitz constant of ∇f. In nonconvex‑nonconcave settings, EG converges to a first‑order stationary point of the gradient norm ‖∇f‖ under the Minty variational inequality (MVI) condition, which is weaker than monotonicity and holds for many GAN objectives.

Optimistic Gradient (OG) / Optimistic Mirror Descent uses the previous gradient as a prediction: xk+1 = xk − α(2∇xf(xk,yk) − ∇xf(xk−1,yk−1)). OG achieves the same convergence guarantees as EG with only one gradient evaluation per iteration (after the first step). Both EG and OG enjoy last‑iterate convergence to a stationary point under MVI, whereas GDA may only guarantee convergence of the averaged iterates.

Two‑time‑scale methods (e.g., TTUR — Two Time‑Scale Update Rule) use different step‑sizes αx ≪ αy so that the y‑player approximates the best response to the slowly moving x. This mimics the Stackelberg equilibrium and can converge to local minimax points under suitable curvature assumptions. Recent theory shows that for nonconvex‑PL (Polyak‑Łojasiewicz) objectives in y, GDA with two time scales finds an ε‑stationary point in O(ε−2) iterations.

Practical considerations: (1) Gradient penalty or spectral normalization stabilizes GAN training by enforcing Lipschitz continuity. (2) Consensus optimization adds a proximal term ‖∇f‖² to the objective, turning the game into a potential game. (3) Hamiltonian‑based methods exploit the symplectic structure of the gradient field to design volume‑preserving integrators that avoid limit cycles. In examinations, expect questions on the distinction between simultaneous and alternating updates, the role of the MVI condition, and the step‑size bounds for EG/OG.

Progressive Hedging Algorithm for Multi‑Stage Stochastic Programming

Progressive Hedging (PH), introduced by Rockafellar and Wets (1991), solves multi‑stage stochastic programs by scenario decomposition. The extensive form of a T‑stage problem with scenario tree 𝒯 has non‑anticipativity constraints requiring that decisions at stage t be identical for all scenarios sharing the same history. PH relaxes these constraints via an augmented Lagrangian: for each scenario s, solve a deterministic subproblem with a quadratic penalty ρ/2 ‖xs − x̄‖² plus a linear term from the Lagrange multipliers. The subproblems are independent and can be solved in parallel.

The algorithm iterates: (1) given current averages x̄k and multipliers λk, solve each scenario subproblem to obtain xsk+1; (2) update the averages x̄k+1 = ∑s ps xsk+1; (3) update multipliers λsk+1 = λsk + ρ (xsk+1 − x̄k+1). For convex problems, PH converges to the global optimum for any ρ>0. The penalty parameter ρ influences speed: too small yields slow consensus, too large causes ill‑conditioning. Adaptive schemes (e.g., residual balancing) adjust ρ dynamically.

For mixed‑integer stochastic programs, PH is a heuristic: the subproblems become MIPs, and the quadratic penalty is often linearized using big‑M or perspective reformulations. Convergence to a feasible integer solution is not guaranteed, but in practice PH combined with branch‑and‑bound (PH‑BB) or with a rounding heuristic produces high‑quality solutions for unit commitment, hydro‑thermal scheduling, and capacity expansion problems.

Comparison with Stochastic Dual Dynamic Programming (SDDP): SDDP builds Benders cuts on the value function and is tailored for stagewise independent noise with convex cost‑to‑go functions. PH makes no stagewise independence assumption and handles general scenario trees, but its convergence rate can be slower for problems with many stages because the augmented Lagrangian couples all stages simultaneously. Hybrid approaches use SDDP cuts within PH subproblems to accelerate convergence.

Implementation details: (1) Scenario subproblems are solved with a warm start from the previous iteration. (2) The non‑anticipativity constraints are enforced only at the nodes of the scenario tree, reducing the number of consensus variables. (3) Parallel computing frameworks (MPI, Spark) distribute subproblems across cores. (4) Stopping criteria include primal residual ‖xs − x̄‖ and dual residual ρ‖x̄k − x̄k−1‖. PH is the method of choice when the scenario tree is large but each scenario subproblem is tractable, and when parallel resources are available.

Stochastic Compositional Optimization: Gradient Estimation and Variance‑Reduced Methods

Stochastic compositional optimization addresses problems of the form

minx∈ℝd  F(x) ≔ 𝔼ζ[ f( 𝔼ξ[ g(x, ξ) ], ζ ) ]

where the outer function f depends on an inner expectation. Classical stochastic gradient descent cannot be applied directly because the gradient ∇F(x) = 𝔼ζ[ ∇yf(y, ζ) |y=𝔼[g(x,ξ)] · 𝔼ξ[ ∇g(x, ξ) ] ] contains a product of two expectations. A naïve Monte‑Carlo estimator using independent samples for the two expectations introduces a persistent bias that does not vanish with a constant step‑size.

Modern algorithms construct asymptotically unbiased gradient estimators by maintaining running averages of the inner function and its Jacobian. The Stochastic Compositional Gradient Descent (SCGD) method keeps a sequence yk ≈ 𝔼[g(xk, ξ)] updated with a small step‑size βk and uses the estimator

vk = ∇yf(yk, ζk) · ∇g(xk, ξk)

to perform the outer update xk+1 = xk − αk vk. Under smoothness and bounded variance assumptions, SCGD achieves an O(ε−2) sample complexity for finding an ε‑stationary point.

Variance‑reduced variants such as ASCVR (Accelerated Stochastic Compositional Variance Reduction) and STORM‑COMP (Stochastic Recursive Momentum for Compositional problems) employ control‑variate techniques analogous to SVRG and SARAH. They periodically compute a full‑batch snapshot of the inner expectation and its Jacobian, then correct the stochastic estimator with the difference between current and snapshot values. This yields a convergence rate of O(ε−3/2) for nonconvex objectives and O(ε−1) for convex ones, matching the optimal rates for single‑level stochastic optimization.

Key practical considerations: (1) The inner step‑size βk must decay slower than the outer step‑size αk to ensure the bias vanishes. (2) Mini‑batch sizes for the inner and outer samples can be chosen independently; larger inner batches reduce the variance of the Jacobian estimate. (3) In deep learning, compositional structure appears in meta‑learning and reinforcement learning (e.g., policy gradient with a value‑function baseline), where these methods provide measurable speed‑ups over naïve estimators.

Optimization with Differential Privacy: Objective Perturbation, Output Perturbation, and Convergence Guarantees

Differential privacy (DP) requires that the output of an algorithm changes only slightly when a single data point is replaced. In empirical risk minimization (ERM) we solve

minx∈𝒳  (1/n) ∑i=1n ℓ(x; zi) + R(x)

where ℓ is a loss and R a regularizer. Three canonical DP mechanisms are used:

  • Objective perturbation: add a random linear term bᵀx to the objective, where b ∼ 𝒩(0, σ²I) or Laplace(Δ/ε). The perturbed problem remains strongly convex if R is strongly convex, and the solution x̂ satisfies (ε,δ)‑DP with σ calibrated to the sensitivity Δ = supz,z' ‖∇ℓ(x;z) − ∇ℓ(x;z')‖. Excess risk bound: 𝔼[F(x̂)] − F(x*) = O( (d log(1/δ)) / (n²ε²) + 1/√n ) for Lipschitz losses with strong convexity.
  • Output perturbation: compute the exact ERM solution x* (or an approximate one) and release x̂ = x* + η, η ∼ 𝒩(0, σ²I). Sensitivity of the ERM solution is bounded by Δout = (2L) / (λ n) for λ‑strongly convex regularizer and L‑Lipschitz loss. The excess risk becomes O( (d L²) / (λ² n² ε²) + 1/√n ). This method is simple but requires solving the non‑private problem exactly, which may be costly.
  • Gradient perturbation (DP‑SGD): at each iteration add Gaussian noise to the mini‑batch gradient. Using the moments accountant or Rényi DP composition, the total privacy budget after T steps is (ε,δ) with ε ≈ (q√(T log(1/δ))) / σ where q is the sampling ratio. Convergence analysis shows that for convex losses the excess empirical risk is O( (L√d) / (nε) + 1/√n ). For nonconvex losses, DP‑SGD finds an ε‑stationary point with sample complexity O( (d log(1/δ)) / (n ε²) ).

Advanced composition theorems (e.g., advanced composition, zero‑concentrated DP) allow tighter privacy accounting when many iterations are performed. Recent work on private Frank‑Wolfe and private mirror descent extends these guarantees to constrained and non‑Euclidean geometries.

Distributionally Robust Optimization with Sinkhorn Divergence Ambiguity Sets

The Sinkhorn divergence Sε(P, Q) is an entropically regularized optimal transport cost between probability measures P and Q. For a reference empirical distribution P̂n = (1/n) ∑i=1n δξi, a Sinkhorn ambiguity set is defined as

𝒰ρ = { Q ∈ 𝒫(Ξ) : Sε(Q, P̂n) ≤ ρ }

where ρ ≥ 0 controls the size of the set. The distributionally robust optimization (DRO) problem

minx∈𝒳 supQ∈𝒰ρ 𝔼ξ∼Q[ ℓ(x; ξ) ]

admits a tractable dual reformulation. Using the convex conjugate of the Sinkhorn divergence, the inner supremum becomes

infλ≥0 { λ ρ + λ ε log( (1/n) ∑i=1n exp( ℓ(x; ξi) / (λ ε) ) ) }

which is a convex optimization problem in (x, λ). The parameter ε > 0 provides a smoothing effect: as ε → 0 the Sinkhorn divergence converges to the Wasserstein distance, and the dual reduces to the classic Wasserstein DRO formulation with a Lipschitz regularization term. For ε > 0 the problem is strictly convex in λ and can be solved efficiently by a one‑dimensional line search combined with a gradient step on x.

Statistical guarantees: with probability at least 1−β, the true distribution P* lies in 𝒰ρ for ρ = O( (log(1/β) / n)1/2 ) when the support is bounded. This yields an out‑of‑sample performance bound of order O( √(log(1/β)/n) ). Compared to Wasserstein DRO, the Sinkhorn set is computationally cheaper because the dual involves only a log‑sum‑exp term rather than a supremum over a Lipschitz constant. Recent algorithms exploit the Sinkhorn iteration (matrix scaling) to compute the divergence and its gradient in O(n²) time, enabling DRO on datasets with thousands of samples.

Nonconvex Optimization under the Kurdyka‑Łojasiewicz Property: Descent Lemmas and Convergence Rates

The Kurdyka‑Łojasiewicz (KL) property generalizes the Polyak‑Łojasiewicz condition to a broad class of nonconvex, possibly nonsmooth functions. A proper lower‑semicontinuous function f satisfies the KL property at a point x̄ ∈ dom ∂f if there exist η > 0, a neighborhood U of x̄, and a continuous concave function φ: [0, η) → ℝ+ with φ(0)=0, φ′>0 on (0, η), such that for all x ∈ U with f(x̄) < f(x) < f(x̄)+η,

φ′( f(x) − f(x̄) ) · dist(0, ∂f(x)) ≥ 1.

Typical desingularizing functions are φ(s) = c s1−θ with θ ∈ [0,1). The exponent θ determines the convergence speed of descent algorithms:

  • θ = 0 (sharp growth): finite‑length property, implying finite convergence in some cases.
  • θ ∈ (0, 1/2]: linear (geometric) convergence of the iterates.
  • θ ∈ (1/2, 1): sublinear convergence of order O(k−(1−θ)/(2θ−1)).

For the proximal gradient method xk+1 = proxα g( xk − α ∇f(xk) ) applied to f+g with f smooth and g convex, the KL property of the composite objective ensures that the whole sequence {xk} converges to a critical point. The proof uses a uniformized KL inequality on a compact sublevel set and a sufficient decrease condition f(xk+1) + (1/(2α) − L/2)‖xk+1−xk‖² ≤ f(xk).

In alternating minimization for problems like matrix factorization minU,V ‖M − UVᵀ‖F² + R(U,V), each block subproblem is strongly convex, so the block updates satisfy a KL inequality with θ = 1/2, yielding linear convergence. For sparse coding with ℓ1 regularization, the objective is semi‑algebraic and thus satisfies the KL property with some θ ∈ (0,1); empirical rates often match the theoretical sublinear bound.

Practical implication: when designing step‑size rules for nonconvex problems, one can monitor the quantity dist(0, ∂f(xk)) and adapt αk to maintain sufficient decrease; the KL exponent then predicts the eventual convergence regime.

Second‑Order Stochastic Methods: Subsampled Newton, Cubic Regularization, and Hessian‑Free Approaches

Second‑order methods accelerate convergence by incorporating curvature information. In the stochastic setting the full Hessian ∇²f(x) = (1/n) ∑i=1n ∇²fi(x) is approximated by a mini‑batch Hessian Hk = (1/|ℬ|) ∑i∈ℬ ∇²fi(xk). The subsampled Newton step solves (Hk + λkI) pk = −∇f(xk) with a regularization λk > 0 to ensure positive definiteness. Under standard assumptions (L‑Lipschitz Hessian, bounded variance of Hessian samples), a batch size |ℬ| = O(ε−1) yields an ε‑approximate Newton direction, leading to an overall iteration complexity of O(ε−3/2) for nonconvex problems.

Adaptive Cubic Regularization (ARC) replaces the quadratic model by a cubic model mk(p) = f(xk) + ∇f(xk)ᵀp + ½ pᵀHkp + (σk/3)‖p‖³. The subproblem is solved approximately (e.g., by Lanczos) to obtain a step satisfying the Cauchy decrease condition. With stochastic Hessian estimates, the regularization parameter σk is increased until the ratio of actual to predicted reduction exceeds a threshold. Recent analysis shows that stochastic ARC achieves O(ε−3/2) gradient evaluations and O(ε−3/2) Hessian‑vector products, matching the deterministic rate.

Hessian‑free methods avoid forming Hk explicitly. They compute Hessian‑vector products Hv via automatic differentiation (Pearlmutter’s trick) and run a truncated conjugate‑gradient (CG) iteration to approximately solve the Newton system. The CG tolerance is relaxed proportionally to ‖∇f(xk)‖, yielding an inexact Newton direction. For deep neural networks, the stochastic Hessian‑free method (also known as the “Hessian‑free optimizer”) uses a mini‑batch for both gradient and Hessian‑vector products, and a damping term λI is added to the CG system. Empirically it converges in fewer iterations than first‑order methods, though each iteration is more expensive.

Key trade‑offs: (1) Subsampled Newton requires a batch size growing as ε−1; for very high accuracy the cost approaches full‑batch Newton. (2) Cubic regularization is more robust to non‑convexity because the cubic term controls step length globally. (3) Hessian‑free CG exploits the fact that only a few eigen‑directions of the Hessian are needed for a good step, making it attractive for problems with millions of parameters where storing the Hessian is impossible.
