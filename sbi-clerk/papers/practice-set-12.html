Q14. Reasoning Ability
Statements: Some Pens are Pencils. All Pencils are Erasers. No Eraser is a Sharpener. Conclusions: I. Some Pens are not Sharpeners. II. All Pencils can never be Sharpeners.
A. Only Conclusion II follows
B. Neither Conclusion I nor II follows
C. Only Conclusion I follows
D. Both Conclusions I and II follow
Correct Answer: D
Shortcut: Apply chain rules: Some + All = Some; Some + No = Some Not; All + No = No. Full: Some Pens are Pencils + All Pencils are Erasers ⇒ Some Pens are Erasers. This + No Eraser is Sharpener ⇒ Some Pens are not Sharpeners (I follows). All Pencils are Erasers + No Eraser is Sharpener ⇒ No Pencil is Sharpener ⇒ All Pencils can never be Sharpeners (II follows).
