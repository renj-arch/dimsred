01 / EDIT
The cut is the argument

13 shots became 50.

The first cut held each plate for ten seconds and explained it. The new cut makes the plate carry a beat, then moves. The figures land as full-frame cards. The silence before the firing is a cut, not a gap.

02 / MOTION
Transitions are cuts with intent

The edit has a grammar.

Hard cuts are not the default. The film uses whips across connected spaces, match cuts on the same object, mask wipes on evidence, dips for silence and flash frames for the figures. Each family has a job.

03 / SETS
What the camera actually saw

First-cut frame studies.

These are frames from the rejected 13-shot cut, kept as production evidence. The new cut uses the same procedural sets with tighter framing and more inserts. No stock footage. No generated faces. No bodies.

04 / EVIDENCE
No invented facts

Every line has a source.

The storyboard is validated before rendering. Each narration line carries a source id, and the render fails if the line, shot or source is missing. The page below is generated from that same file.

05 / TRANSPARENCY
Freedom of expression, protected by evidence

Every claim is sourced; no claim is invented.

Every narration line carries a source identifier, and the render refuses a line whose source is missing. Every host line either restates a sourced fact or expresses an attitude toward it. The film does not invent facts; the argument lives in the evidence, not in commentary. The storyboard, the debate map and the source ledger are public and verifiable. A government that calls this film a risk to public order must answer the record it cites. It cannot suppress the record by naming the record dangerous.

06 / PIPELINE
Free CI, no paid keys

Every frame is assembled on GitHub.

Blender, Piper, Chromium and ffmpeg run on a free Ubuntu CPU runner. The owner's machine writes the code; it does not render the film. The pipeline is public, repeatable and allowed to fail loudly.
