What are Numerical Methods?

Numerical methods provide techniques for solving mathematical problems using numerical approximation. GATE covers root-finding methods, interpolation, numerical differentiation and integration, and numerical solutions of ODEs. Weightage is typically 3-5% in GATE.

Key Concepts

1. Root Finding: Bisection method — repeatedly halve the interval [a,b] where f(a)f(b)<0. Convergence is linear, slow but guaranteed. Newton-Raphson method: x_{n+1} = x_n - f(x_n)/f'(x_n). Convergence is quadratic if initial guess is close. Secant method: x_{n+1} = x_n - f(x_n)(x_n-x_{n-1})/(f(x_n)-f(x_{n-1})) — no derivative needed.

2. Interpolation: Lagrange interpolation: polynomial passing through n+1 points. Newton's forward/backward difference formulas for equally spaced data. Error in interpolation depends on the (n+1)th derivative of the function.

3. Numerical Integration: Trapezoidal rule: ∫(a to b) f(x)dx ≈ h/2[f₀ + 2(f₁+...+f_{n-1}) + f_n], error ~ O(h²). Simpson's 1/3 rule: ∫(a to b) f(x)dx ≈ h/3[f₀ + 4(f₁+f₃+...) + 2(f₂+f₄+...) + f_n], requires even number of intervals, error ~ O(h⁴). Simpson's 3/8 rule for 3-interval blocks.

4. Numerical Solution of ODEs: Euler's method: y_{n+1} = y_n + hf(x_n,y_n) — first order accuracy. Modified Euler (Heun): predictor-corrector method. Runge-Kutta 4th order: y_{n+1} = y_n + (h/6)(k₁+2k₂+2k₃+k₄) where k₁ = f(x_n,y_n), k₂ = f(x_n+h/2, y_n+hk₁/2), k₃ = f(x_n+h/2, y_n+hk₂/2), k₄ = f(x_n+h, y_n+hk₃). RK4 is widely used due to its high accuracy.

Solved Examples

Example 1 (Newton-Raphson Method)
Find the root of f(x) = x² - 5 near x₀ = 2, correct to 3 decimal places using Newton-Raphson method.

a) 2.236 b) 2.238 c) 2.234 d) 2.230
Solution: a) 2.236. f(x)=x²-5, f'(x)=2x. Newton-Raphson: x₁ = x₀ - f(x₀)/f'(x₀) = 2 - (4-5)/4 = 2 - (-1/4) = 2.25. x₂ = 2.25 - (5.0625-5)/(4.5) = 2.25 - 0.0625/4.5 = 2.25 - 0.01389 = 2.23611. x₃ = 2.23611 - (5.00017-5)/(4.47222) ≈ 2.23607. So root ≈ 2.236 (which is √5).
Example 2 (Simpson's 1/3 Rule)
Using Simpson's 1/3 rule with n=4, approximate ∫(0 to 4) x² dx.

a) 21.33 b) 21.00 c) 22.67 d) 20.00
Solution: a) 21.33. n=4, h=1. x: 0,1,2,3,4. f(x)=x²: f₀=0, f₁=1, f₂=4, f₃=9, f₄=16. Simpson: ∫ ≈ h/3[f₀+4(f₁+f₃)+2f₂+f₄] = 1/3[0+4(1+9)+2(4)+16] = 1/3[0+40+8+16] = 64/3 = 21.333. Exact = x³/3|₀⁴ = 64/3 = 21.333 — since f(x)=x² is quadratic, Simpson's gives exact result (error ~ O(h⁴)f⁴(ξ), f⁴(x) = 0).
Example 3 (Euler's Method)
Use Euler's method with h=0.1 to find y(0.2) for dy/dx = x + y, y(0)=1.

a) 1.22 b) 1.23 c) 1.21 d) 1.24
Solution: a) 1.22. Euler: y_{n+1} = y_n + h·f(x_n,y_n). f(x,y)=x+y. At x₀=0, y₀=1: y₁ = 1+0.1(0+1)=1+0.1=1.1 (at x=0.1). At x₁=0.1, y₁=1.1: y₂ = 1.1+0.1(0.1+1.1)=1.1+0.12=1.22 (at x=0.2). Exact solution: dy/dx - y = x. Linear DE: IF=e^(-x), y·e^(-x)=∫xe^(-x)dx = -xe^(-x)-e^(-x)+C, y = -x-1+Ce^x. y(0)=1 → 1=-1+C → C=2. y = 2e^x - x - 1. y(0.2) = 2×1.2214 - 0.2 - 1 = 2.4428-1.2=1.2428. Euler gives 1.22, error ≈ 0.0228.

Shortcut Techniques

  • For Newton-Raphson, choose initial guess close to the root — divergence can occur if f'(x) is small near the guess.
  • Trapezoidal rule is exact for linear functions. Simpson's 1/3 rule is exact for quadratic and cubic functions.
  • Bisection method is guaranteed to converge but slow — use it for initial bracketing then switch to Newton-Raphson for faster convergence.
  • For Euler's method, halving the step size roughly halves the error (first order). RK4 has fourth order accuracy — error reduces by factor 16 when step size is halved.
  • Lagrange interpolation for n+1 points gives a unique polynomial of degree ≤ n. For evenly spaced data, Newton's forward/backward formulas are more efficient.

Convergence Analysis and Error Bounds for Root‑Finding Methods

The speed at which an iterative root‑finder approaches a solution is quantified by its order of convergence. For a sequence {xₙ} converging to a root α, the method has order p ≥ 1 if there exists a constant C > 0 such that |xₙ₊₁ − α| ≤ C·|xₙ − α|ᵖ for sufficiently large n. The bisection method is linearly convergent with p = 1 and C = ½, guaranteeing a reduction of the interval width by half each iteration. The secant method achieves super‑linear convergence with order p = (1+√5)/2 ≈ 1.618, while Newton‑Raphson attains quadratic convergence (p = 2) provided f′(α) ≠ 0 and the initial guess is sufficiently close. When f′(α) = 0 (multiple root), Newton’s order drops to linear; a modified iteration xₙ₊₁ = xₙ − m·f(xₙ)/f′(xₙ) with known multiplicity m restores quadratic convergence.

Error bounds are derived from Taylor expansions. For Newton’s method, if f ∈ C² near α and f′(α) ≠ 0, the error satisfies eₙ₊₁ = (f″(α)/(2f′(α)))·eₙ² + O(eₙ³). This constant determines the asymptotic error constant and explains why a poor initial guess can cause divergence or convergence to a different root. The Kantorovich theorem gives a rigorous sufficient condition: if ‖f′(x₀)⁻¹‖·‖f(x₀)‖·L ≤ ½ where L is a Lipschitz constant for f′, then Newton converges and the error after k steps is bounded by (2⁻²ᵏ⁺¹)·‖f′(x₀)⁻¹‖·‖f(x₀)‖. In practice, a stopping criterion based on |f(xₙ)| < tol or |xₙ₊₁ − xₙ| < tol is used, but one must guard against stagnation when f′ is very small.

Hybrid strategies combine the guaranteed bracketing of bisection with the rapid local convergence of Newton or secant. Brent’s method, for example, maintains a bracket [a,b] where f(a)f(b) < 0 and attempts inverse quadratic interpolation; if the interpolated point falls outside the bracket or does not reduce the interval sufficiently, it falls back to bisection. This yields a method that is both robust and super‑linear in practice, with a worst‑case guarantee of linear convergence. Understanding these theoretical guarantees allows an examinee to select the appropriate algorithm when a problem statement specifies “guaranteed convergence” versus “fast convergence near the root”.

Higher‑Order Interpolation: Spline Methods and Runge Phenomenon

Polynomial interpolation through n+1 equally spaced nodes suffers from the Runge phenomenon: as n grows, the interpolant oscillates wildly near the interval ends, even for smooth functions such as f(x)=1/(1+25x²) on [−1,1]. The error formula f(x)−Pₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·∏(x−xᵢ) shows that the product term grows large near the boundaries for equidistant nodes. Chebyshev nodes xᵢ = cos((2i+1)π/(2n+2)) minimise the maximum of this product, yielding near‑optimal uniform convergence for analytic functions. However, constructing the interpolant at Chebyshev points requires either a change of basis or the use of the barycentric Lagrange formula, which evaluates the interpolant in O(n) time with excellent numerical stability.

Spline interpolation circumvent high‑degree polynomials by piecing together low‑degree polynomials on subintervals. A cubic spline S(x) is a C² function composed of cubic polynomials on each subinterval [xᵢ, xᵢ₊₁] that matches function values and first/second derivatives at the knots. The natural spline imposes S″(x₀)=S″(xₙ)=0, while the clamped spline prescribes S′(x₀)=f′(x₀) and S′(xₙ)=f′(xₙ). The spline coefficients are obtained by solving a tridiagonal linear system for the second derivatives Mᵢ = S″(xᵢ): hᵢ₋₁Mᵢ₋₁ + 2(hᵢ₋₁+hᵢ)Mᵢ + hᵢMᵢ₊₁ = 6[(yᵢ₊₁−yᵢ)/hᵢ − (yᵢ−yᵢ₋₁)/hᵢ₋₁]. This system is strictly diagonally dominant and solved in O(n) operations via the Thomas algorithm. The error of a cubic spline for f ∈ C⁴ satisfies ‖f−S‖∞ ≤ (5/384)·h⁴·‖f⁽⁴⁾‖∞, where h = max hᵢ, giving fourth‑order accuracy with a modest constant.

In examinations, a typical twist is to ask for the spline value at a point not coinciding with a knot, requiring evaluation of the cubic polynomial on the relevant subinterval. Another common question compares the condition number of the Vandermonde matrix for equidistant nodes (which grows exponentially) with the well‑conditioned tridiagonal system for splines. Recognising that spline interpolation is preferred for large data sets and that Chebyshev nodes are the remedy for polynomial interpolation on a fixed grid demonstrates depth beyond the basic Lagrange formula.

Worked Example: Natural Cubic Spline Construction
Given data points (0,0), (1,1), (2,0), construct the natural cubic spline and evaluate S(1.5).

Step 1: intervals h₀ = h₁ = 1. Step 2: set up tridiagonal system for M₀, M₁, M₂ with natural conditions M₀ = M₂ = 0. The single interior equation for i=1: h₀M₀ + 2(h₀+h₁)M₁ + h₁M₂ = 6[(y₂−y₁)/h₁ − (y₁−y₀)/h₀] → 0 + 4M₁ + 0 = 6[(0−1)/1 − (1−0)/1] = 6[−1−1] = −12 → M₁ = −3.

Step 3: on [1,2] the cubic is S(x) = a + b(x−1) + c(x−1)² + d(x−1)³. Using S(1)=1, S(2)=0, S″(1)=M₁=−3, S″(2)=M₂=0. S″(x) = 2c + 6d(x−1). At x=1: 2c = −3 → c = −1.5. At x=2: 2c+6d = 0 → −3+6d=0 → d = 0.5. S(1)=a = 1. S(2)=a+b+c+d = 1+b−1.5+0.5 = b = 0 → b = 0. Thus S(x) = 1 −1.5(x−1)² + 0.5(x−1)³ on [1,2]. Evaluate at 1.5: (x−1)=0.5 → S(1.5)=1 −1.5·0.25 + 0.5·0.125 = 1 −0.375 + 0.0625 = 0.6875.

Exam‑Day Strategy
When a spline question appears, write the tridiagonal system immediately; the Thomas algorithm is a guaranteed 3‑step process (forward elimination, back substitution). Memorise the natural spline end conditions (M₀=Mₙ=0) and the clamped formulas (M₀, Mₙ expressed via first derivatives). For Chebyshev nodes, recall the cosine formula and the error bound factor 1/2ⁿ. These patterns repeat across papers.

Adaptive Quadrature and Error Estimation in Numerical Integration

Fixed‑step composite rules (trapezoidal, Simpson) allocate the same subinterval width everywhere, which is inefficient when the integrand has localized features such as sharp peaks or boundary layers. Adaptive quadrature recursively subdivides intervals until a local error estimate falls below a user‑specified tolerance. The classic adaptive Simpson algorithm computes the composite Simpson approximation S(a,b) on [a,b] and the two‑half‑interval approximations S(a,m)+S(m,b) where m=(a+b)/2. The error estimate is E = (S(a,m)+S(m,b) − S(a,b))/15, derived from the fact that Simpson’s rule has error term −(b−a)⁵/2880·f⁽⁴⁾(ξ). If |E| < ε, the corrected value S(a,m)+S(m,b)+E is accepted; otherwise the interval is bisected and the process repeats. This yields a guaranteed absolute error bound proportional to the prescribed tolerance.

Gauss‑Kronrod rules embed a higher‑order Gauss rule within a lower‑order one by adding nodes, providing an error estimate without extra function evaluations beyond the higher‑order rule. For example, the 7‑point Gauss rule is embedded in a 15‑point Kronrod rule; the difference between the two approximations serves as the error indicator. Modern libraries (e.g., QUADPACK) use such pairs to achieve high efficiency for smooth and moderately singular integrands. When the integrand has an algebraic singularity at an endpoint, a change of variable x = tᵖ or a weighted Gauss‑Jacobi rule removes the singularity and restores rapid convergence.

In examination problems, adaptive quadrature is often tested conceptually: “Explain why the error estimate for adaptive Simpson uses the factor 1/15” or “Given a tolerance ε, how many recursive levels are needed for a function with bounded fourth derivative?”. The answer hinges on the error scaling h⁵ for Simpson; halving h reduces the local error by 2⁵ = 32, so the recursion depth grows logarithmically with 1/ε. Knowing the derivation of the 1/15 factor (Richardson extrapolation) and the role of the fourth derivative in the error term distinguishes a superficial answer from a rigorous one.

Stability and Stiffness in ODE Solvers: Implicit Methods and A‑Stability

Stiff differential equations contain components that decay on vastly different time scales, e.g., y′ = −1000y + 3000−2000e⁻ᵗ with solution y = 3−0.998e⁻¹⁰⁰⁰ᵗ + 2e⁻ᵗ. Explicit methods such as Euler or RK4 require step sizes h ≪ 1/1000 to remain stable, making them impractical. The linear test equation y′ = λy (Re λ < 0) defines the stability region of a method: the set of complex z = hλ for which the numerical solution remains bounded. For explicit Euler, the region is the disk |1+z| ≤ 1; for RK4 it is a larger but still bounded region. A method is A‑stable if its stability region contains the entire left half‑plane {Re z ≤ 0}. The backward (implicit) Euler method yₙ₊₁ = yₙ + h f(tₙ₊₁, yₙ₊₁) is A‑stable, as is the trapezoidal rule (Crank–Nicolson) yₙ₊₁ = yₙ + h/2[f(tₙ,yₙ)+f(tₙ₊₁,yₙ₊₁)]. However, the trapezoidal rule is only A‑stable, not L‑stable; its amplification factor tends to −1 as Re z → −∞, causing mild oscillations for very stiff components.

Implicit Runge‑Kutta methods, notably the Gauss–Legendre family, achieve high order with A‑stability. The two‑stage Gauss method (order 4) has Butcher tableau with c = (1/2 ∓ √3/6) and is symplectic, preserving geometric properties of Hamiltonian systems. For large‑scale stiff problems, linearly implicit methods such as Rosenbrock or BDF (backward differentiation formulas) are preferred. BDF methods of order ≤ 2 are A‑stable; orders 3–6 are only stiffly stable (stable in a wedge). The popular variable‑order, variable‑step BDF implementation (e.g., LSODE, CVODE) automatically selects the order based on local error estimates and stiffness detection.

Exam questions often ask: “Why does explicit Euler fail for stiff problems?” or “State the definition of A‑stability and give an example of an A‑stable method.” A concise answer: explicit Euler’s stability region is bounded, so for λ with large negative real part the product hλ falls outside the region unless h is impractically small. Backward Euler is A‑stable because its amplification factor 1/(1−z) satisfies |1/(1−z)| ≤ 1 for all Re z ≤ 0. Recognising the distinction between A‑stability and L‑stability, and knowing that BDF2 is the highest‑order A‑stable BDF, are typical discriminators.

Practical Implementation Issues: Round‑off Error, Conditioning, and Algorithm Selection

Finite‑precision arithmetic introduces round‑off errors that can dominate truncation errors when step sizes become very small. In root finding, the Newton update xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) suffers from catastrophic cancellation when f(xₙ) and f′(xₙ) are both small; using a compensated evaluation or switching to a higher‑precision accumulator mitigates this. For interpolation, the barycentric Lagrange formula evaluates the interpolant as Σ wᵢ fᵢ/(x−xᵢ) / Σ wᵢ/(x−xᵢ) with pre‑computed weights wᵢ = 1/∏ⱼ≠ᵢ (xᵢ−xⱼ). This formulation is numerically stable even for high‑degree polynomials at Chebyshev nodes, whereas the standard Lagrange basis suffers from O(ε·n²) error growth.

Condition numbers quantify sensitivity of the output to input perturbations. For a linear system Ax = b, the condition number κ(A) = ‖A‖·‖A⁻¹‖ bounds the relative error: ‖δx‖/‖x‖ ≤ κ(A)·(‖δA‖/‖A‖ + ‖δb‖/‖b‖). The Vandermonde matrix for equidistant nodes has κ growing exponentially with n, explaining the instability of high‑degree polynomial interpolation. In contrast, the tridiagonal matrix for cubic splines has κ = O(n²), making splines far more robust. When solving ODEs, the stiffness ratio (largest |λ|/smallest |λ|) acts as a condition number for the time‑integration problem; implicit methods effectively reduce this ratio by damping the fast modes.

Algorithm selection guidelines: (1) For a single root with a good initial guess and available derivative, use Newton with a safeguard (e.g., fall back to bisection if the iterate leaves the bracket). (2) For tabulated data with many points, prefer cubic splines or piecewise cubic Hermite interpolation (PCHIP) to avoid overshoot. (3) For smooth integrals, Gauss‑Legendre quadrature with 5–10 points per subinterval is optimal; for singular endpoints, apply a transformation or use Gauss‑Jacobi weights. (4) For non‑stiff ODEs, RK4 with step‑size control (e.g., RK45) balances efficiency and ease of implementation; for stiff systems, use an implicit BDF or Rosenbrock method with automatic order selection. These heuristics are frequently tested in scenario‑based questions where the examinee must justify the choice.

  • Assuming Newton‑Raphson always converges quadratically; it requires f′(α) ≠ 0 and a sufficiently close start.
  • Using equidistant nodes for high‑degree polynomial interpolation and ignoring the Runge phenomenon.
  • Applying a fixed‑step Simpson rule to an integrand with a sharp interior peak without adaptive refinement.
  • Choosing explicit RK4 for a stiff ODE and not recognising the step‑size restriction from the stability region.
  • Neglecting round‑off error when h becomes very small in finite‑difference formulas, leading to loss of significant digits.
  • Confusing A‑stability with L‑stability and selecting the trapezoidal rule for heavily damped stiff components.
  • Treating the condition number of the Vandermonde matrix as moderate, resulting in unstable interpolation for large data sets.

Multivariate Root Finding and Newton‑Krylov Methods

When a system of nonlinear equations F(x) = 0 with F : ℝⁿ → ℝⁿ must be solved, the scalar Newton iteration generalises to xk+1 = x_k − J(x_k)-1 F(x_k), where J is the Jacobian matrix. Forming and factorising J explicitly costs O(n³) operations and O(n²) storage, which becomes prohibitive for large‑scale problems arising from discretised PDEs or optimisation. Newton‑Krylov methods avoid the explicit Jacobian by solving the linear Newton step J(x_k) s_k = −F(x_k) with a Krylov subspace solver such as GMRES or BiCGSTAB, using only matrix‑vector products J(x_k) v. These products are approximated by a finite‑difference directional derivative (F(x_k + ε v) − F(x_k))/ε or supplied analytically via algorithmic differentiation. The overall algorithm therefore requires only O(n) storage and O(n·m) work per iteration, where m is the number of Krylov iterations, typically far smaller than n.

Convergence of Newton‑Krylov inherits the local quadratic convergence of Newton’s method provided the linear solves are performed to a tolerance that decreases proportionally to ‖F(x_k)‖. In practice a forcing term η_k = min(0.5, √‖F(x_k)‖) is used to balance accuracy and cost. Preconditioning is essential: a good preconditioner P ≈ J clusters the eigenvalues of P-1J and dramatically reduces m. Common choices include incomplete LU factorisation of an approximate Jacobian, physics‑based block preconditioners, or multigrid cycles when the problem originates from a PDE. Globalisation strategies such as line search or trust‑region methods are added to guarantee convergence from remote starting points; the merit function φ(x) = ½‖F(x)‖² is standard.

Exam questions often ask for the definition of a matrix‑free Newton step, the role of the forcing term, or the distinction between a Jacobian‑free Newton‑Krylov (JFNK) method and a classical Newton method with an explicit Jacobian. A concise answer: JFNK replaces the exact Jacobian solve by an iterative Krylov solve that only needs Jacobian‑vector products, which are obtained by finite differences or automatic differentiation, and it uses a forcing term to control linear‑solve accuracy.

Rational Interpolation and Barycentric Representations

Polynomial interpolation suffers from the Runge phenomenon and ill‑conditioned Vandermonde systems for high degree. Rational interpolation seeks a function R(x) = P(x)/Q(x) where P and Q are polynomials of prescribed degrees m and n. The interpolant satisfies R(x_i) = f_i for given nodes x_i and data f_i. The linearised formulation P(x_i) − f_i Q(x_i) = 0 yields a homogeneous linear system for the coefficients of P and Q. Because the system is homogeneous, a non‑trivial solution exists only when the number of unknowns exceeds the number of equations by at least one; the extra degree of freedom is fixed by a normalisation such as Q(x0)=1 or ‖Q‖=1.

The barycentric representation provides a numerically stable evaluation formula for both polynomial and rational interpolants. For a rational interpolant with nodes x_i and weights w_i, the value at x is R(x) = (∑ w_i f_i/(x−x_i)) / (∑ w_i/(x−x_i)). The weights are computed once from the nodes, e.g. w_i = 1/∏j≠i(x_i−x_j) for polynomial interpolation, or from a linear system for rational weights. This formulation avoids catastrophic cancellation near nodes and remains stable for degrees up to several hundred when nodes are chosen as Chebyshev points. The barycentric form also enables fast updating when nodes are added or removed, a property exploited in adaptive interpolation algorithms.

Key exam topics include the construction of the linear system for rational interpolation, the derivation of barycentric weights for Chebyshev nodes, and the proof that the barycentric formula evaluates the interpolant exactly in exact arithmetic. A typical question: “Explain why the barycentric Lagrange formula is preferred over the classical Lagrange basis for high‑degree polynomial interpolation.” The answer highlights O(n) evaluation cost, numerical stability, and the absence of explicit polynomial coefficient computation.

Newton‑Krylov for a Nonlinear System
Consider the system F(x) = [x₁² + x₂ − 11, x₁ + x₂² − 7]ᵀ. Starting from x⁰ = [2, 2]ᵀ, perform one Newton‑Krylov iteration using GMRES(2) with a finite‑difference Jacobian‑vector product (ε = 10⁻⁶) and no preconditioner. Show the linear system solved, the approximate Jacobian‑vector products, and the updated iterate.

1. Compute F(x⁰) = [2²+2−11, 2+2²−7]ᵀ = [−5, −1]ᵀ.

2. For a direction v = [v₁, v₂]ᵀ, the Jacobian‑vector product Jv ≈ (F(x⁰+εv)−F(x⁰))/ε.

Choose v¹ = [1,0]ᵀ: F([2+ε,2]) ≈ [ (2+ε)²+2−11, (2+ε)+4−7 ] = [−5+4ε+ε², −1+ε]. Jv¹ ≈ [4, 1]ᵀ.

Choose v² = [0,1]ᵀ: F([2,2+ε]) ≈ [ 4+(2+ε)−11, 2+(2+ε)²−7 ] = [−5+ε, −1+4ε+ε²]. Jv² ≈ [1, 4]ᵀ.

3. The approximate Jacobian is J ≈ [[4,1],[1,4]]. Solve J s = −F = [5,1]ᵀ. The exact solution is s = [19/15, −1/15]ᵀ ≈ [1.267, −0.067]ᵀ. GMRES(2) with this 2×2 system converges in at most two iterations, yielding this solution.

4. Update x¹ = x⁰ + s = [49/15, 29/15]ᵀ ≈ [3.267, 1.933]ᵀ.

Exam‑Day Strategy
When a question asks for a matrix‑free Newton step, write the finite‑difference formula for Jv explicitly and state the forcing term rule η_k = min(0.5, √‖F_k‖). For rational interpolation, remember the homogeneous linear system and the normalisation condition; the barycentric weights for Chebyshev nodes of the first kind (roots of T_n) are w_i = (−1)^i sin(θ_i) with θ_i = (2i+1)π/(2n). These compact facts earn full marks quickly.

Gaussian Quadrature with Weight Functions and Orthogonal Polynomials

Gaussian quadrature constructs an n‑point rule ∫_a^b w(x) f(x) dx ≈ ∑i=1^n ω_i f(x_i) that is exact for all polynomials of degree ≤ 2n−1. The nodes x_i are the zeros of the orthogonal polynomial p_n associated with the weight function w(x) on [a,b], and the weights ω_i are given by ω_i = ∫_a^b w(x) ℓ_i(x) dx where ℓ_i are the Lagrange basis polynomials. Classical families include Legendre (w=1 on [−1,1]), Chebyshev (w=1/√(1−x²)), Laguerre (w=e−x on [0,∞)), and Hermite (w=e−x² on (−∞,∞)). The three‑term recurrence pk+1(x) = (x−α_k) p_k(x) − β_k pk-1(x) generates the orthogonal polynomials and provides the coefficients for the symmetric tridiagonal Jacobi matrix whose eigenvalues are the quadrature nodes and whose first components of the normalized eigenvectors give the weights (Golub‑Welsch algorithm).

When the weight function is non‑standard, one can compute the recurrence coefficients α_k, β_k by the modified Chebyshev algorithm using moments μ_k = ∫ w(x) x^k dx or by discretising the Stieltjes procedure. The resulting quadrature rule remains optimal in the sense of maximal algebraic degree. For integrals with endpoint singularities, Gauss‑Jacobi quadrature with weight (1−x)^α (1+x)^β handles algebraic singularities directly. For oscillatory integrals, Gauss‑Laguerre or Gauss‑Hermite rules are appropriate after a suitable change of variables.

Exam questions frequently ask to derive the Jacobi matrix for Legendre polynomials (α_k=0, β_k = k²/(4k²−1) for the monic recurrence), to state the Golub‑Welsch eigenvalue formulation, or to explain why Gaussian quadrature with a weight function is exact for polynomials up to degree 2n−1. A concise answer: the orthogonality of p_n to all lower‑degree polynomials forces the error functional to vanish on that space, yielding the maximal degree.

Multistep Methods for ODEs: Adams‑Bashforth, Adams‑Moulton, and Predictor‑Corrector Schemes

Linear multistep methods approximate the solution of y′ = f(t,y) by a linear combination of past solution values and derivative evaluations. The general k‑step formula is ∑j=0^k α_j yn+j = h ∑j=0^k β_j fn+j with α_k = 1. Explicit Adams‑Bashforth methods have β_k = 0; implicit Adams‑Moulton methods have β_k ≠ 0. The coefficients are derived by integrating the polynomial that interpolates f at the past k points (Adams‑Bashforth) or at the past k points plus the future point (Adams‑Moulton). For example, the two‑step Adams‑Bashforth method is yn+2 = yn+1 + h(3/2 fn+1 − 1/2 f_n) (order 2), while the two‑step Adams‑Moulton (trapezoidal) method is yn+2 = yn+1 + h/2 (fn+2 + fn+1) (order 3).

Zero‑stability requires that the roots of the characteristic polynomial ρ(ζ) = ∑ α_j ζ^j satisfy the root condition: all roots lie in |ζ| ≤ 1 and any root on the unit circle is simple. For Adams methods, ρ(ζ) = ζ^k − ζk-1, giving a simple root at ζ=1 and k−1 roots at ζ=0, so zero‑stability holds for all k. Consistency (order ≥ 1) together with zero‑stability implies convergence by the Dahlquist equivalence theorem. The region of absolute stability for explicit Adams‑Bashforth methods shrinks as k increases; for k=3 the stability interval on the negative real axis is a small interval near the origin. Implicit Adams‑Moulton methods have larger stability regions; the trapezoidal rule is A‑stable.

In practice a predictor‑corrector pair is used: an explicit Adams‑Bashforth step predicts yn+1(0), then one or more implicit Adams‑Moulton corrections refine it. The local truncation error of the corrector can be estimated by the difference between predictor and corrector, enabling step‑size control. Variable‑step, variable‑order Adams codes (e.g., DEABM, LSODE’s non‑stiff option) adjust k and h to maintain a user‑specified tolerance while minimising function evaluations.

Typical exam items: write the third‑order Adams‑Bashforth formula, derive the coefficients of the two‑step Adams‑Moulton method, state the root condition for zero‑stability, or explain why a predictor‑corrector scheme is more efficient than a fully implicit iteration. The key points are the interpolation‑based derivation, the root condition, and the error estimate from the predictor‑corrector difference.

Spectral Methods and Pseudospectral Differentiation

Spectral methods approximate the solution of differential equations by a global expansion in smooth basis functions, typically Fourier series for periodic problems or orthogonal polynomials (Chebyshev, Legendre) for non‑periodic domains. The unknown solution u(x) is represented as u_N(x) = ∑k=0^N a_k φ_k(x). In a Galerkin formulation the residual is orthogonalised against the basis, leading to a system for the coefficients a_k. In a collocation (pseudospectral) formulation the differential equation is enforced at a set of quadrature nodes, usually the Gauss‑Lobatto points for Chebyshev or equispaced points for Fourier. The derivative of the interpolant at the nodes is computed by a differentiation matrix D, where (Du)_i = u′(x_i). For Chebyshev‑Gauss‑Lobatto nodes x_i = cos(iπ/N), the entries of D are known analytically: Dij = c_i/(c_j) (−1)i+j/(x_i−x_j) for i≠j, and Dii = −x_i/(2(1−x_i²)) for interior points, with c0 = c_N = 2, c_i = 1 otherwise.

The spectral accuracy property states that for analytic solutions the error decays faster than any algebraic power of N (exponential convergence). For solutions with finite regularity (e.g., a discontinuity in a derivative) the convergence is algebraic, with rate determined by the Sobolev regularity. Aliasing errors arise when nonlinear terms are evaluated pointwise; they are mitigated by the 3/2‑rule padding in Fourier methods or by modal filtering in polynomial methods. Time integration of the resulting semi‑discrete system is usually performed with implicit‑explicit (IMEX) Runge‑Kutta or exponential integrators to handle the stiff eigenvalues that scale like O(N²) for second‑order operators.

Exam questions often ask for the construction of the Chebyshev differentiation matrix, the statement of the spectral convergence theorem, or the explanation of the 3/2‑rule for dealiasing. A concise answer: the differentiation matrix is derived from the Lagrange interpolant at Chebyshev‑Gauss‑Lobatto nodes; spectral convergence follows from the exponential decay of Chebyshev coefficients for analytic functions; the 3/2‑rule zero‑pads the high‑frequency modes before transforming back to physical space to avoid aliasing in quadratic nonlinearities.

  • Assuming Newton‑Krylov converges without a forcing term; the linear solve tolerance must shrink with the nonlinear residual.
  • Using equidistant nodes for rational interpolation and ignoring the pole‑placement problem that can cause spurious poles near the interval.
  • Applying Gaussian quadrature with a weight function that does not match the integrand’s singular behaviour, leading to loss of the 2n−1 exactness.
  • Choosing a high‑order explicit Adams‑Bashforth method for a stiff problem and not recognising the severe step‑size restriction from the stability interval.
  • Neglecting the root condition when analysing a new multistep scheme, resulting in a zero‑unstable method that diverges even for consistent formulas.
  • Treating the Chebyshev differentiation matrix as dense without exploiting its structure, causing O(N³) cost instead of O(N log N) via FFT‑based transforms.
  • Forgetting to dealias nonlinear terms in a Fourier spectral code, which produces spurious energy transfer to high modes and corrupts the solution.
