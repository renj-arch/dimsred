What are Differential Equations?

Differential equations (DEs) describe relationships involving rates of change and are fundamental to engineering analysis. GATE covers first and second order ordinary differential equations (ODEs), methods of solution, and Laplace transforms. Weightage is typically 4-6% in GATE.

Key Concepts

1. First Order ODE: Variable separable: dy/dx = f(x)g(y) → ∫dy/g(y) = ∫f(x)dx. Homogeneous: dy/dx = f(y/x) → substitute y = vx. Linear: dy/dx + P(x)y = Q(x) → integrating factor IF = e^(∫P dx) → solution: y(IF) = ∫Q(IF) dx. Bernoulli: dy/dx + Py = Qyⁿ → substitute v = y^(1-n).

2. Exact Differential Equations: M dx + N dy = 0 is exact if ∂M/∂y = ∂N/∂x. Solution: ∫M dx + ∫(terms in N not containing x) dy = C. If not exact, find integrating factor.

3. Second Order Linear ODE: a d²y/dx² + b dy/dx + cy = f(x). Homogeneous (f=0): auxiliary equation ar² + br + c = 0. Roots: real distinct → y = C₁e^(r₁x) + C₂e^(r₂x). Real equal → y = (C₁ + C₂x)e^(rx). Complex → y = e^(αx)(C₁cosβx + C₂sinβx). Particular integral for f(x) using method of undetermined coefficients or variation of parameters.

4. Laplace Transforms: L{f(t)} = ∫(0 to ∞) e⁻ˢᵗ f(t) dt. Standard transforms: L{1} = 1/s, L{tⁿ} = n!/sⁿ⁺¹, L{e^(at)} = 1/(s-a), L{sinωt} = ω/(s²+ω²), L{cosωt} = s/(s²+ω²). Properties: linearity, first shifting theorem L{e^(at)f(t)} = F(s-a), second shifting theorem L{f(t-a)H(t-a)} = e⁻ᵃˢF(s). Inverse Laplace: partial fractions + standard forms.

Solved Examples

Example 1 (First Order Linear ODE)
Solve: dy/dx + 2xy = 2x, given y(0) = 1.

a) y = 1 b) y = 1 + e^(-x²) c) y = 1 - e^(-x²) d) y = e^(-x²)
Solution: a) y = 1. P(x) = 2x, Q(x) = 2x. IF = e^(∫2x dx) = e^(x²). Solution: y·e^(x²) = ∫2x·e^(x²) dx = e^(x²) + C. So y = 1 + Ce^(-x²). Using y(0)=1: 1 = 1 + C → C=0. Therefore y = 1.
Example 2 (Second Order ODE)
Solve: d²y/dx² + 4y = 0, y(0)=1, y'(0)=2.

a) y = cos2x + sin2x b) y = cos2x + 2sin2x c) y = 2cos2x + sin2x d) y = cos2x + 3sin2x
Solution: a) y = cos2x + sin2x. AE: r² + 4 = 0 → r = ±2i. Solution: y = C₁cos2x + C₂sin2x. y(0)=1: C₁=1. y' = -2C₁sin2x + 2C₂cos2x. y'(0)=2: 2C₂=2 → C₂=1. So y = cos2x + sin2x.
Example 3 (Laplace Transform)
Find the Laplace transform of f(t) = 3 + 2t - e^(-3t).

a) 3/s + 2/s² - 1/(s+3) b) 3/s + 2/s² + 1/(s+3) c) 3/s - 2/s² - 1/(s-3) d) 1/s + 2/s² - 3/(s+3)
Solution: a) 3/s + 2/s² - 1/(s+3). L{3} = 3/s. L{2t} = 2·1/s² = 2/s². L{e^(-3t)} = 1/(s+3). By linearity: L{f(t)} = 3/s + 2/s² - 1/(s+3).

Shortcut Techniques

  • For variable separable, integrate both sides directly — no special method needed. For linear DE, always find IF first.
  • In second order ODE with constant coefficients, memorise the three cases of auxiliary equation roots.
  • For Laplace transforms, memorise the standard transform pairs and use partial fractions for inverse transforms.
  • Unit step function H(t-a) shifts the function: L{f(t-a)H(t-a)} = e^(-as)F(s).
  • Initial and final value theorems: lim(t→0) f(t) = lim(s→∞) sF(s), lim(t→∞) f(t) = lim(s→0) sF(s).

Higher-Order Linear ODEs with Variable Coefficients

When the coefficients of a linear ordinary differential equation are functions of the independent variable, the constant‑coefficient auxiliary‑equation method no longer applies. Two classical families admit closed‑form solutions: Cauchy‑Euler (equidimensional) equations and equations reducible to constant coefficients by a change of variable. A Cauchy‑Euler equation has the form aₙxⁿy⁽ⁿ⁾ + aₙ₋₁xⁿ⁻¹y⁽ⁿ⁻¹⁾ + … + a₁xy′ + a₀y = 0. Substituting y = xʳ converts it into an algebraic indicial equation aₙr(r‑1)…(r‑n+1) + aₙ₋₁r(r‑1)…(r‑n+2) + … + a₁r + a₀ = 0. Distinct real roots r₁,…,rₙ give the fundamental set {xʳ¹,…,xʳⁿ}. A repeated root r of multiplicity m contributes {xʳ, xʳln x, …, xʳ(ln x)ᵐ⁻¹}. Complex roots α ± iβ yield x^α cos(β ln x) and x^α sin(β ln x). For non‑homogeneous Cauchy‑Euler equations, variation of parameters or the method of undetermined coefficients (with trial functions expressed in powers of x and ln x) provides a particular integral.

Reduction of order is a general technique when one solution y₁(x) of a second‑order linear homogeneous ODE y″ + P(x)y′ + Q(x)y = 0 is known. Setting y = v(x)y₁(x) leads to a first‑order linear equation for v′: v″y₁ + 2v′y₁′ + v(y₁″ + Py₁′ + Qy₁) = 0. Since y₁ satisfies the original ODE, the term in v vanishes, leaving v″y₁ + 2v′y₁′ = 0. Dividing by y₁ and integrating gives v′ = C exp(‑∫2y₁′/y₁ dx) = C/y₁². A second independent solution is y₂ = y₁∫(dx/y₁²). This formula is indispensable for equations such as Bessel’s equation of order zero, where y₁ = J₀(x) is known from series methods.

Another important class arises from the substitution x = eᵗ (or t = ln x) which transforms a Cauchy‑Euler equation into a constant‑coefficient ODE in t. The derivatives transform as dy/dx = (1/x) dy/dt, d²y/dx² = (1/x²)(d²y/dt² – dy/dt), and similarly for higher orders. This mapping is frequently used in examinations to test whether the candidate recognises the hidden constant‑coefficient structure.

Key Points for Quick Identification

  • Equation contains terms xᵏy⁽ᵏ⁾ with the same power of x as the derivative order → Cauchy‑Euler.
  • One known solution is given or can be guessed (e.g., y = x, y = eˣ) → reduction of order.
  • Presence of ln x in the non‑homogeneous term suggests a repeated root in the indicial equation.

Systems of First Order Linear ODEs and Matrix Exponential

A system of n first‑order linear ODEs can be written compactly as d𝐱/dt = A𝐱 + 𝐟(t), where 𝐱(t) is an n‑vector, A is an n×n constant matrix, and 𝐟(t) is a forcing vector. The homogeneous system d𝐱/dt = A𝐱 has the fundamental matrix solution Φ(t) = eᴬᵗ, defined by the convergent series eᴬᵗ = I + At + A²t²/2! + … . If A is diagonalizable, A = PDP⁻¹ with D = diag(λ₁,…,λₙ), then eᴬᵗ = P eᴰᵗ P⁻¹ where eᴰᵗ = diag(eλ₁t,…,eλₙt). The general homogeneous solution is 𝐱ₕ(t) = eᴬᵗ𝐜, 𝐜 constant vector.

For non‑homogeneous systems, the variation‑of‑parameters formula gives a particular solution 𝐱ₚ(t) = eᴬᵗ∫e‑Aτ𝐟(τ)dτ. When 𝐟(t) = 𝐛 eμt with constant vector 𝐛, a trial particular solution of the form 𝐱ₚ = 𝐯 eμt leads to (μI – A)𝐯 = 𝐛, provided μ is not an eigenvalue of A. If μ coincides with an eigenvalue, the trial must be multiplied by t (or higher powers) exactly as in the scalar method of undetermined coefficients.

Phase‑plane analysis for n = 2 classifies equilibrium at the origin according to the eigenvalues of A: real distinct same sign → node (stable if negative, unstable if positive); real opposite signs → saddle; complex with non‑zero real part → spiral (stable/unstable); pure imaginary → centre. The trace τ = tr(A) and determinant Δ = det(A) give a quick discriminant: τ² – 4Δ > 0 → real eigenvalues; τ² – 4Δ < 0 → complex. This classification is a favourite in multiple‑choice questions because it requires only τ and Δ, not the full eigen‑decomposition.

When A is not diagonalizable (defective), the Jordan form introduces terms t eλt in the matrix exponential. For a 2×2 defective matrix with eigenvalue λ of algebraic multiplicity 2 and geometric multiplicity 1, eᴬᵗ = eλt(I + t(A‑λI)). The presence of the polynomial factor t is a hallmark that examiners test by asking for the explicit form of the fundamental matrix.

Worked Example: Matrix Exponential for a Defective System
Consider the system d𝐱/dt = A𝐱 with A = [[2,1],[0,2]]. Find the fundamental matrix Φ(t) = eᴬᵗ and the solution satisfying 𝐱(0) = [1,‑1]ᵀ.
The matrix A has eigenvalue λ = 2 with algebraic multiplicity 2. It is defective because A‑2I = [[0,1],[0,0]] has rank 1. Using the Jordan‑form formula for a 2×2 defective matrix: eᴬᵗ = e2t(I + t(A‑2I)). Compute A‑2I = [[0,1],[0,0]]. Then I + t(A‑2I) = [[1, t],[0,1]]. Hence Φ(t) = e2t[[1, t],[0,1]]. The solution is 𝐱(t) = Φ(t)𝐱(0) = e2t[[1, t],[0,1]] [1,‑1]ᵀ = e2t[1‑t, ‑1]ᵀ. Therefore x₁(t) = e2t(1‑t), x₂(t) = ‑e2t.
Exam‑Day Strategy for Matrix Exponential
When a 2×2 constant‑coefficient system appears, first compute trace τ and determinant Δ. If τ²‑4Δ ≥ 0, eigenvalues are real; write the general solution using exponentials. If τ²‑4Δ < 0, eigenvalues are complex; write the solution in terms of eαtcos βt and eαtsin βt. For defective cases, remember the extra factor t multiplying the eigenvector term. Sketching the phase portrait from τ and Δ alone can earn partial marks even if the full matrix exponential is not required.

Laplace Transform of Periodic Functions and Convolution Theorem

The Laplace transform of a periodic function f(t) with period T > 0 is given by L{f(t)} = (1/(1‑e‑sT)) ∫₀ᵀ e‑st f(t) dt, provided the integral converges. This formula follows from splitting the infinite integral into a sum over periods and recognising a geometric series in e‑sT. It is particularly useful for square waves, sawtooth waves, and rectified sinusoids that appear in electrical‑engineering problems. For a square wave of amplitude A and period 2π defined by f(t)=A for 0<t<π and f(t)=‑A for π<t<2π, the transform reduces to (A/s) tanh(πs/2).</p>

The convolution theorem states that L{(f * g)(t)} = F(s)G(s), where (f * g)(t) = ∫₀ᵗ f(τ)g(t‑τ)dτ. Conversely, the inverse transform of a product F(s)G(s) is the convolution of the individual inverse transforms. This property converts difficult inverse transforms involving rational functions into integrals of known functions. For example, L⁻¹{1/(s(s²+ω²))} = ∫₀ᵗ 1·sin ωτ dτ = (1‑cos ωt)/ω².

Convolution also provides a systematic way to solve linear ODEs with arbitrary forcing: if the ODE is aₙy⁽ⁿ⁾+…+a₀y = f(t) with zero initial conditions, taking Laplace transforms gives Y(s) = F(s)/P(s) where P(s) is the characteristic polynomial. The inverse transform is the convolution of f(t) with the impulse response h(t) = L⁻¹{1/P(s)}. The impulse response is precisely the solution of the homogeneous ODE with initial conditions y(0)=…=y⁽ⁿ⁻²⁾(0)=0, y⁽ⁿ⁻¹⁾(0)=1/aₙ.

An important corollary is the differentiation of transforms: L{t f(t)} = ‑dF/ds. Combined with convolution, this yields formulas for transforms of integrals and derivatives of periodic functions. Examiners often ask for the Laplace transform of t·f(t) where f is a standard periodic waveform, testing both the periodic‑function formula and the derivative property.

Typical Examination Patterns

  • Given a piecewise‑defined periodic function, write its Laplace transform using the period formula.
  • Compute the inverse transform of a product like (s/(s²+ω²))·(1/(s²+α²)) by identifying the factors as transforms of cos ωt and (1/α) sin αt and writing the convolution integral.
  • Use the convolution theorem to solve an initial‑value problem with a non‑standard forcing term (e.g., f(t)=t²e‑t).

Partial Differential Equations: Separation of Variables for Heat and Wave Equations

The one‑dimensional heat equation ∂u/∂t = α ∂²u/∂x² on a finite rod 0<x<L with homogeneous Dirichlet boundary conditions u(0,t)=u(L,t)=0 and initial temperature u(x,0)=f(x) is solved by assuming u(x,t)=X(x)T(t). Substitution yields X T′ = α X″ T, or T′/(αT) = X″/X = ‑λ (separation constant). The spatial problem X″+λX=0, X(0)=X(L)=0 gives eigenvalues λₙ = (nπ/L)² and eigenfunctions Xₙ(x)=sin(nπx/L), n=1,2,…. The temporal problem T′+αλₙT=0 gives Tₙ(t)=e<sup>‑αλₙt. Superposition yields u(x,t)=∑n=1^∞ Bₙ sin(nπx/L) e‑α(nπ/L)²t, where Bₙ = (2/L)∫₀ᴸ f(x) sin(nπx/L) dx are the Fourier sine coefficients of the initial data.

For the wave equation ∂²u/∂t² = c² ∂²u/∂x² with the same boundary conditions and initial displacement u(x,0)=f(x), initial velocity ∂u/∂t(x,0)=g(x), separation gives X″+λX=0 as before, but the temporal equation becomes T″+c²λT=0. The solution is Tₙ(t)=Aₙ cos(c nπ t/L)+Bₙ sin(c nπ t/L). The full series is u(x,t)=∑n=1^∞ sin(nπx/L)[Aₙ cos(c nπ t/L)+Bₙ sin(c nπ t/L)], with Aₙ = (2/L)∫₀ᴸ f(x) sin(nπx/L) dx and Bₙ = (2/(c nπ/L))∫₀ᴸ g(x) sin(nπx/L) dx.

Neumann (insulated) boundary conditions ∂u/∂x(0,t)=∂u/∂x(L,t)=0 lead to cosine eigenfunctions Xₙ(x)=cos(nπx/L) with n=0,1,2,… and λₙ = (nπ/L)². The n=0 mode gives a constant spatial eigenfunction, which for the heat equation yields a steady‑state term that does not decay. For the wave equation, the n=0 temporal solution is A₀+B₀t, representing a rigid translation of the string.

Non‑homogeneous boundary conditions are handled by splitting u = v + w, where w(x,t) satisfies the boundary conditions (often a linear function in x for Dirichlet data) and v satisfies homogeneous boundary conditions with a modified forcing term. This technique is a standard examination question because it tests both the method of separation and the ability to construct a suitable auxiliary function.

Key Formulas to Memorise

  • Heat equation Fourier sine coefficients: Bₙ = (2/L)∫₀ᴸ f(x) sin(nπx/L) dx.
  • Wave equation coefficients: Aₙ = (2/L)∫₀ᴸ f(x) sin(nπx/L) dx, Bₙ = (2L/(c nπ))∫₀ᴸ g(x) sin(nπx/L) dx.
  • Eigenvalues for Dirichlet: λₙ = (nπ/L)²; for Neumann: λₙ = (nπ/L)² with n≥0.

Numerical Methods for ODEs: Runge‑Kutta and Stability Analysis

When analytical solutions are unavailable, numerical integration of initial‑value problems dy/dt = f(t,y), y(t₀)=y₀ is essential. The classical fourth‑order Runge‑Kutta (RK4) method advances the solution by a step h using four slope evaluations: k₁ = f(tₙ, yₙ); k₂ = f(tₙ+h/2, yₙ+h k₁/2); k₃ = f(tₙ+h/2, yₙ+h k₂/2); k₄ = f(tₙ+h, yₙ+h k₃); yₙ₊₁ = yₙ + (h/6)(k₁+2k₂+2k₃+k₄). The local truncation error is O(h⁵), giving a global error O(h⁴). RK4 is the workhorse for non‑stiff problems because it balances accuracy and computational cost.

Stiff equations, characterised by eigenvalues of the Jacobian ∂f/∂y with large negative real parts, require implicit methods to avoid prohibitively small step sizes. The backward Euler method yₙ₊₁ = yₙ + h f(tₙ₊₁, yₙ₊₁) is A‑stable: its region of absolute stability contains the entire left half‑plane. The trapezoidal rule (Crank‑Nicolson) yₙ₊₁ = yₙ + (h/2)[f(tₙ,yₙ)+f(tₙ₊₁,yₙ₊₁)] is also A‑stable and second‑order accurate. For linear test equation y′ = λy, the amplification factor of a one‑step method is a rational function R(z) with z = λh. The method is stable if |R(z)| ≤ 1. Plotting the stability region in the complex z‑plane is a standard examination task.

Adaptive step‑size control uses embedded Runge‑Kutta pairs (e.g., RK4(5) Dormand‑Prince) that produce two estimates of different orders; their difference estimates the local error. The step is accepted if the error is below a tolerance, and h is adjusted by a factor (tolerance/error)1/(p+1) where p is the lower order. This strategy is implemented in most scientific computing libraries and is occasionally tested conceptually.

For systems, the same formulas apply component‑wise. The Jacobian matrix J = ∂f/∂y determines stiffness. If the eigenvalues of J are widely separated in magnitude, explicit methods require h < 2/|λ_max| for stability, while implicit methods allow much larger h. Examination questions may ask to identify stiffness from a given Jacobian or to choose an appropriate method (explicit vs implicit) for a described problem.

Practical Checklist for Numerical Questions

  • Write the RK4 update formulas explicitly; do not just name the method.
  • For stability analysis, compute the amplification factor R(z) for the given method applied to y′ = λy.
  • State the order of the method and the expected global error behaviour.
  • When asked about adaptive step size, mention error estimation via embedded pairs and the step‑size adjustment formula.
  • Confusing the indicial equation of a Cauchy‑Euler ODE with the auxiliary equation of a constant‑coefficient ODE.
  • Forgetting the factor t in the second solution when the indicial equation has a repeated root.
  • Applying the matrix exponential formula eᴬᵗ = P eᴰᵗ P⁻¹ without verifying that A is diagonalizable.
  • Misusing the convolution theorem by convolving the wrong pair of inverse transforms.
  • Neglecting the n=0 cosine mode in Neumann problems, leading to missing steady‑state terms.
  • Using an explicit Runge‑Kutta method on a stiff problem without checking the stability restriction.
  • Omitting the factor 2/L in Fourier coefficient formulas for heat and wave equations on [0,L].

Exact Differential Equations and Integrating Factors

A first‑order differential equation written in the form M(x,y) dx + N(x,y) dy = 0 is exact when ∂M/∂y = ∂N/∂x throughout a simply connected region. In that case there exists a potential function ψ(x,y) such that dψ = M dx + N dy, and the general solution is ψ(x,y) = C. The test for exactness is purely algebraic; if it fails, an integrating factor μ(x,y) may be sought to render the equation exact. When μ depends only on x, the condition (∂M/∂y − ∂N/∂x)/N = f(x) yields μ = exp(∫ f(x) dx). When μ depends only on y, the condition (∂N/∂x − ∂M/∂y)/M = g(y) gives μ = exp(∫ g(y) dy). More general integrating factors can be found by assuming a product form μ = x^a y^b or by exploiting symmetries of the equation. A classic example is (2xy + y2) dx + (x2 + 2xy) dy = 0. Here ∂M/∂y = 2x + 2y = ∂N/∂x, so the equation is exact; the potential function is ψ = x2 y + x y2 = C. For a non‑exact homogeneous equation such as (y2) dx + (x2 + xy) dy = 0, an integrating factor can sometimes be guessed from homogeneity (e.g., μ = 1/(xM + yN) when the denominator is non‑zero). The method of integrating factors appears frequently in examinations, testing the exactness criterion and the ability to recognise patterns suggesting a simple μ. Students should also remember that any integrating factor multiplied by a non‑zero constant remains an integrating factor, and that the product of two integrating factors is not necessarily an integrating factor.

Bernoulli and Riccati Equations

The Bernoulli equation dy/dx + P(x) y = Q(x) y^n, with n ≠ 0,1, is reduced to a linear equation by the substitution v = y^(1−n). Differentiating gives dv/dx = (1−n) y^(−n) dy/dx, and after division by y^n the original equation becomes dv/dx + (1−n) P(x) v = (1−n) Q(x), a first‑order linear ODE in v. The integrating factor method then yields v, and back‑substitution gives y. A typical trap is forgetting the factor (1−n) when forming the linear equation, or mis‑applying the substitution when n = 0 or 1 (the equation is already linear or separable). The Riccati equation dy/dx = P(x) + Q(x) y + R(x) y2 is nonlinear and generally not solvable in closed form unless a particular solution y₁(x) is known. With one particular solution, the substitution y = y₁ + 1/v transforms the Riccati equation into a linear equation for v: dv/dx + (Q + 2R y₁) v = −R. This reduction is a common examination device because it combines the search for a particular solution (often by inspection or by trying simple functions like constants, polynomials, or exponentials) with the linear‑ODE machinery. For example, dy/dx = 1 + 2y + y2 has the particular solution y₁ = −1; the substitution y = −1 + 1/v gives dv/dx = −1, so v = −x + C and y = −1 − 1/(x + C). Students must verify that the denominator never vanishes on the interval of interest. Bernoulli equations arise in models such as population dynamics with harvesting; Riccati equations appear in optimal control problems.

Worked Example: Bernoulli to Linear
Solve dy/dx + (2/x) y = x2 y3.
Identify P(x) = 2/x, Q(x) = x2, n = 3. Set v = y^(1−3) = y^(−2). Then dv/dx = −2 y^(−3) dy/dx. Divide the original equation by y3: y^(−3) dy/dx + (2/x) y^(−2) = x2. Multiply by −2: −2 y^(−3) dy/dx − (4/x) y^(−2) = −2 x2. Substitute dv/dx and v: dv/dx − (4/x) v = −2 x2. This is linear. Integrating factor μ = exp(∫ −4/x dx) = x^(−4). Multiply: d/dx (v x^(−4)) = −2 x^(−2). Integrate: v x^(−4) = 2 x^(−1) + C. Hence v = 2 x3 + C x4. Back‑substitute y^(−2) = 2 x3 + C x4, so y = ± 1/√(2 x3 + C x4). The solution is valid where the radicand is positive.
Exam‑Day Strategy
When a Bernoulli equation appears, write down the substitution v = y^(1−n) immediately; the linear ODE that follows is almost always solvable by the standard integrating factor. For Riccati, scan the coefficients for a constant or simple polynomial particular solution before attempting the substitution. If no particular solution is evident, the question may only ask for the reduction step, not the full solution.

Series Solutions via the Frobenius Method

When a linear ODE has a regular singular point at x = x₀, the Frobenius method seeks a solution of the form y = (x−x₀)^r ∑k=0^∞ a_k (x−x₀)^k with a₀ ≠ 0. Substituting into the ODE yields the indicial equation, a polynomial in r whose roots r₁, r₂ determine the nature of the series. If the roots differ by a non‑integer, two linearly independent Frobenius series exist. If the roots are equal, the second solution contains a logarithmic term: y₂ = y₁ ln(x−x₀) + (x−x₀)^r ∑ b_k (x−x₀)^k. If the roots differ by an integer N, the second solution may involve a logarithm or may be a pure Frobenius series; the method of reduction of order or the recurrence relation with the smaller root often reveals the logarithmic term. Classic equations solved by Frobenius include Bessel's equation x2 y'' + x y' + (x2 − ν2) y = 0, Legendre's equation (1−x2) y'' − 2x y' + λ y = 0, and the hypergeometric equation. The radius of convergence of the series is at least the distance to the nearest other singularity. Examination questions often ask for the indicial equation, the recurrence relation, and the first few non‑zero terms of each series solution. A common error is to forget that a₀ is arbitrary and to set it to 1 without stating the assumption, or to mis‑apply the recurrence when the roots differ by an integer and the smaller root fails to produce a valid series. The Frobenius method also underpins the theory of special functions, which appear in physics and engineering problems such as heat conduction in cylindrical coordinates (Bessel functions) and quantum mechanical angular momentum (Legendre polynomials).

Sturm‑Liouville Theory and Orthogonal Eigenfunctions

A regular Sturm‑Liouville problem has the form d/dx [p(x) dy/dx] + [q(x) + λ w(x)] y = 0 on [a,b] with separated boundary conditions α₁ y(a) + α₂ y'(a) = 0, β₁ y(b) + β₂ y'(b) = 0, where p, q, w are continuous, p > 0, w > 0 on (a,b). The eigenvalues λ are real, simple, and form an infinite increasing sequence λ₁ < λ₂ < … → ∞. The corresponding eigenfunctions y_n are orthogonal with respect to the weight w: ∫_a^b y_m(x) y_n(x) w(x) dx = 0 for m ≠ n. This orthogonality is the foundation for expanding arbitrary functions in series of eigenfunctions (generalised Fourier series). The Rayleigh quotient R[y] = (∫_a^b [p (y')2 − q y2] dx) / (∫_a^b w y2 dx) gives the minimum eigenvalue λ₁ = min R[y] over admissible functions, and λ_n = min R[y] over functions orthogonal to the first n−1 eigenfunctions. Typical examination tasks include verifying that a given ODE can be put into Sturm‑Liouville form, finding the weight function, and using orthogonality to compute expansion coefficients. For example, the Legendre equation (1−x2) y'' − 2x y' + n(n+1) y = 0 on [−1,1] has p(x) = 1−x2, q = 0, w = 1, and eigenfunctions P_n(x) (Legendre polynomials) orthogonal with weight 1. The Bessel equation x2 y'' + x y' + (λ x2 − ν2) y = 0 on [0,1] with boundary condition y(1)=0 yields eigenfunctions J_ν(√λ x) and weight w(x) = x. Students must remember that the orthogonality integral includes the weight, and that the norm ∫ w y_n2 dx is needed for coefficient formulas. A frequent trap is to apply the standard Fourier sine/cosine coefficient formula 2/L ∫ f(x) sin(nπx/L) dx when the weight is not 1, leading to missing factors of w(x).

Phase Plane Analysis of Autonomous Systems

For a two‑dimensional autonomous system dx/dt = f(x,y), dy/dt = g(x,y), the phase plane provides a qualitative picture of trajectories without solving the system explicitly. Equilibrium points (critical points) satisfy f = 0, g = 0. Linearisation about an equilibrium (x₀,y₀) uses the Jacobian J = [[∂f/∂x, ∂f/∂y],[∂g/∂x, ∂g/∂y]] evaluated at the equilibrium. The eigenvalues of J classify the equilibrium: real eigenvalues of same sign → node (stable if negative, unstable if positive); real eigenvalues of opposite sign → saddle (always unstable); complex eigenvalues with non‑zero real part → spiral (stable if real part negative, unstable if positive); pure imaginary eigenvalues → centre (linearisation inconclusive, nonlinear terms decide). The trace τ and determinant Δ of J give a quick classification: τ² − 4Δ > 0 → node/saddle; τ² − 4Δ < 0 → spiral/centre; Δ < 0 → saddle; Δ > 0, τ = 0 → centre. Nullclines (curves where dx/dt = 0 or dy/dt = 0) help sketch the direction field. Limit cycles are isolated closed trajectories; the Poincaré‑Bendixson theorem gives conditions for their existence in planar systems. Examination questions may ask to find all equilibria, classify them, sketch nullclines, and draw a qualitative phase portrait. A typical system is the predator‑prey (Lotka‑Volterra) model dx/dt = x(α − β y), dy/dt = y(−γ + δ x), which has a centre at (γ/δ, α/β) and a saddle at (0,0). Another common example is the damped pendulum d²θ/dt² + b dθ/dt + sin θ = 0, rewritten as a first‑order system. The key is to compute the Jacobian correctly and to interpret the eigenvalue signs in terms of stability. A frequent mistake is to confuse the stability of a linear centre (neutrally stable) with that of a nonlinear centre, which may be stable or unstable depending on higher‑order terms.

  • Assuming an integrating factor exists in a simple form without verifying the exactness condition after multiplication.
  • Forgetting the factor (1−n) when converting a Bernoulli equation to a linear ODE.
  • Assuming the smaller root of the indicial equation always yields a second Frobenius series when roots differ by an integer; it may fail, requiring a logarithmic term.
  • Omitting the weight function w(x) in Sturm‑Liouville orthogonality integrals, leading to incorrect expansion coefficients.
  • Classifying a centre as asymptotically stable based solely on linearisation when the nonlinear terms could produce a spiral.
  • Neglecting to check that the denominator in a Riccati substitution does not vanish on the interval of interest.
  • Misapplying the Poincaré‑Bendixson theorem by not verifying that the trapping region contains no equilibria.

Boundary Value Problems and Green's Functions for Linear ODEs

Boundary value problems (BVPs) prescribe conditions at two or more points, unlike initial value problems. For a linear second‑order operator L[y] = y'' + p(x) y' + q(x) y on [a,b] with homogeneous boundary conditions α₁ y(a) + α₂ y'(a) = 0, β₁ y(b) + β₂ y'(b) = 0, the Green's function G(x,ξ) satisfies L[G] = δ(x‑ξ) with the same homogeneous boundary conditions in x. Once G is known, the solution of L[y] = f(x) is y(x) = ∫_a^b G(x,ξ) f(ξ) dξ. Construction uses two independent solutions u₁, u₂ of the homogeneous equation satisfying the left and right boundary conditions respectively, then G(x,ξ) = (u₁(x) u₂(ξ))/W(ξ) for x < ξ and the symmetric expression for x > ξ, where W is the Wronskian (constant for self‑adjoint form). For the Sturm‑Liouville operator (p y')' + q y = λ w y, the Green's function is symmetric: G(x,ξ) = G(ξ,x). This symmetry underpins the eigenfunction expansion method and ensures real eigenvalues. A typical examination task derives G for y'' = f(x) with y(0)=y(L)=0, yielding G(x,ξ) = x(L‑ξ)/L for x ≤ ξ and ξ(L‑x)/L for x ≥ ξ. Students must verify continuity of G at x=ξ and the jump condition G_x(ξ⁺,ξ)‑G_x(ξ⁻,ξ)=1. A common variation uses a fourth‑order beam operator y'''' = f(x) with clamped or simply supported ends; the same piecewise construction applies but requires four independent homogeneous solutions. Green's functions also provide a direct route to solving integral equations of the second kind, since the resolvent kernel is built from the same Green's function.

Asymptotic Expansions and the WKB Approximation

The Wentzel–Kramers–Brillouin (WKB) method approximates solutions to ε² y'' + Q(x) y = 0 when a small parameter ε multiplies the highest derivative. Writing y = exp(S/ε) and expanding S = S₀ + ε S₁ + ε² S₂ + … gives at leading order (S₀')² + Q = 0, so S₀ = ± i ∫ √Q dx for Q>0 (oscillatory region) and S₀ = ± ∫ √(-Q) dx for Q<0 (exponential region). The first correction yields the amplitude factor Q-1/4, giving the standard WKB ansatz: y ≈ Q-1/4 [C₁ exp(i/ε ∫ √Q dx) + C₂ exp(-i/ε ∫ √Q dx)] in the allowed region, and y ≈ |Q|-1/4 [C₁ exp(1/ε ∫ √(-Q) dx) + C₂ exp(-1/ε ∫ √(-Q) dx)] in the forbidden region. Turning points where Q(x₀)=0 require connection formulas from Airy function matching; a decaying exponential in the forbidden region connects to a sine with a π/4 phase shift in the allowed region. Quantisation conditions for bound states follow from single‑valuedness after a round trip between two turning points, yielding the Bohr–Sommerfeld rule ∫x₁x₂ √Q dx = (n+½)π ε. The Airy equation y'' = x y (ε=1, Q=x) is the canonical test case: WKB reproduces the known asymptotic forms of Ai(x) and Bi(x). The method fails near turning points unless connection formulas are applied, and the expansion is asymptotic, not convergent — truncating after the first term often gives the best practical accuracy. Higher‑order corrections involve derivatives of Q and can be generated systematically, but are rarely required beyond the first amplitude factor in standard tests.

WKB Quantisation for a Linear Potential
Apply the WKB quantisation condition to the Schrödinger‑type equation y'' + (λ - x) y = 0 on [0,∞) with boundary condition y(0)=0 and y→0 as x→∞. Find the approximate eigenvalues λ_n for large n.
Here ε=1, Q(x)=λ - x. The turning point is x₁ = λ (where Q=0). The left boundary at x=0 is a hard wall, giving a phase loss of π/2. The WKB condition for a potential with one turning point and an infinite wall is ∫0λ √(λ - x) dx = (n + 3/4)π. Compute the integral: let u = λ - x, du = -dx, limits u=λ to 0, integral = ∫0λ √u du = (2/3) λ3/2. Hence (2/3) λ3/2 = (n + 3/4)π, so λ_n ≈ [ (3π/2)(n + 3/4) ]2/3. This matches the known asymptotic zeros of the Airy function Ai(-λ).
Exam‑Day Strategy for WKB Questions
Identify the small parameter (often ε² in front of y''). Write down Q(x) and locate turning points. Sketch the regions (oscillatory vs exponential) to decide which connection formula applies. Memorise the two standard connection rules: decaying exponential ↔ sine with +π/4 phase, growing exponential ↔ cosine with -π/4 phase. For quantisation, count phase losses: each smooth turning point contributes π/2, each hard wall contributes π/2. Write the Bohr–Sommerfeld integral with the correct total phase offset. Do not attempt to derive Airy matching from scratch — state the rule and apply it.

Bifurcation Theory for One‑Parameter Families of ODEs

Bifurcation theory studies qualitative changes in the phase portrait of a dynamical system as a parameter μ varies. For dx/dt = f(x,μ), equilibria satisfy f(x,μ)=0. A saddle‑node (fold) bifurcation occurs when f = 0 and ∂f/∂x = 0 simultaneously, with ∂²f/∂x² ≠ 0 and ∂f/∂μ ≠ 0. The normal form is dx/dt = μ - x²; for μ<0 no equilibria, for μ=0 a single semi‑stable equilibrium, for μ>0 two equilibria (one stable, one unstable). A transcritical bifurcation has normal form dx/dt = μ x - x²; equilibria x=0 and x=μ exchange stability at μ=0. A supercritical pitchfork bifurcation appears as dx/dt = μ x - x³; the trivial equilibrium loses stability at μ=0 and two symmetric stable branches emerge. The subcritical pitchfork dx/dt = μ x + x³ creates unstable branches for μ<0. For planar systems, the Hopf bifurcation creates a limit cycle from an equilibrium when a pair of complex conjugate eigenvalues crosses the imaginary axis. The first Lyapunov coefficient determines supercritical (stable cycle) versus subcritical (unstable cycle). Centre‑manifold reduction reduces the analysis to a low‑dimensional normal form. Examination questions often present a specific f(x,μ) and ask to locate bifurcation points, classify them, and sketch the bifurcation diagram (equilibrium branches vs μ). Students must compute the Jacobian, verify non‑degeneracy conditions, and avoid confusing the parameter derivative condition (∂f/∂μ ≠ 0) with the eigenvalue crossing condition. A frequent twist embeds the bifurcation in a higher‑dimensional system where only a centre manifold matters; the answer then requires projecting onto the centre manifold before applying the normal forms.

Delay Differential Equations: Stability and Characteristic Equations

Delay differential equations (DDEs) incorporate past states, e.g. dx/dt = -a x(t) - b x(t-τ) with τ>0. Linear constant‑coefficient DDEs lead to characteristic equations of the form λ + a + b e-λτ = 0. Unlike ODEs, this transcendental equation has infinitely many roots. Stability requires Re(λ) < 0 for all roots. The stability boundary is found by setting λ = iω and separating real and imaginary parts: a + b cos(ωτ) = 0, ω - b sin(ωτ) = 0. Eliminating ω yields the critical delay τ_c = (1/√(b²-a²)) arccos(-a/b) for b>a>0. As τ increases past τ_c, a pair of complex roots crosses the imaginary axis, producing a Hopf bifurcation and sustained oscillations. For dx/dt = -μ x(t-τ), the characteristic equation λ + μ e-λτ=0 gives stability for μτ < π/2. The Lambert W function represents all roots explicitly: λ = (1/τ) W_k(μτ) where k indexes branches. In examinations, a typical problem asks to determine the stability region in the (μ,τ) plane for a given linear DDE, or to compute the critical delay for a specific parameter set. Students must remember that the zero root λ=0 corresponds to a steady‑state bifurcation and that the infinite spectrum makes numerical root‑finding delicate; the argument principle or the D‑subdivision method are standard analytical tools. Nonlinear DDEs inherit the same linear stability criteria, and centre‑manifold theory extends to infinite‑dimensional phase spaces, but the normal form computation is considerably more involved.

Lie Symmetry Methods for Nonlinear ODEs

Lie symmetry analysis seeks continuous transformation groups that leave a differential equation invariant. For a first‑order ODE dy/dx = ω(x,y), a one‑parameter Lie group with infinitesimal generator X = ξ(x,y) ∂/∂x + η(x,y) ∂/∂y yields the invariance condition η_x + (η_y - ξ_x) ω - ξ_y ω² = ξ ω_x + η ω_y. Solving this linear PDE for ξ, η provides the symmetry generators. Once a symmetry is known, the ODE can be reduced to quadrature by introducing canonical coordinates r = r(x,y), s = s(x,y) such that X = ∂/∂s; the equation becomes ds/dr = Ω(r) which integrates directly. For higher‑order ODEs, each symmetry reduces the order by one; a second‑order ODE with a two‑parameter symmetry group is integrable. The classic example is the Riccati equation y' = a(x) + b(x) y + c(x) y², which admits the projective symmetry group SL(2,R). The determining equations for ξ, η are linear and can be solved algorithmically; computer algebra systems often implement the Lie algorithm. In examinations, students may be given a specific nonlinear ODE and asked to find its Lie point symmetries, construct the canonical variables, and integrate. A common trap is to assume that any ODE possesses a nontrivial symmetry; generic nonlinear ODEs have none. Another pitfall is to confuse Lie point symmetries with contact or higher‑order symmetries, which require prolonged generators. The method also underpins the derivation of integrating factors: if X = ξ∂_x + η∂_y is a symmetry of M dx + N dy = 0, then μ = 1/(ξ M + η N) is an integrating factor, providing a direct link between symmetry and exactness.

  • Assuming a Green's function exists without verifying that the homogeneous BVP has only the trivial solution; a nontrivial kernel makes the inverse non‑unique.
  • Applying the WKB connection formulas at a turning point where Q(x) has a higher‑order zero (e.g., Q ∼ (x-x₀)²) without using the appropriate uniform approximation.
  • Misidentifying the bifurcation type by checking only f=0 and f_x=0 but neglecting the transversality condition f_μ ≠ 0.
  • Treating the characteristic equation of a DDE as a polynomial and expecting a finite number of roots; the infinite spectrum must be accounted for in stability diagrams.
  • Using a Lie symmetry generator that does not satisfy the determining equation, leading to an incorrect canonical coordinate transformation.
  • Forgetting that the Lambert W function has multiple branches; the stability boundary is determined by the principal branch only when all other branches lie further left.
  • Confusing the phase loss at a hard wall (π/2) with that at a smooth turning point (π/2) and double‑counting in the Bohr–Sommerfeld quantisation condition.
