What is Linear Algebra?

Linear algebra is a foundational topic in engineering mathematics, covering vector spaces, matrices, determinants, systems of linear equations, eigenvalues, and eigenvectors. In GATE, linear algebra carries 5-8% weightage across all branches.

Key Concepts

1. Matrices: Types: row, column, square, diagonal, scalar, identity, zero, symmetric (Aᵀ = A), skew-symmetric (Aᵀ = -A), orthogonal (AAᵀ = I). Rank of a matrix = number of linearly independent rows/columns. Trace = sum of diagonal elements.

2. Determinants: |A| for square matrix. Properties: |AB| = |A||B|, |Aᵀ| = |A|, |A⁻¹| = 1/|A|, |kA| = kⁿ|A| for n×n matrix. Cramer's rule for solving linear systems using determinants.

3. Systems of Linear Equations: AX = B. If |A| ≠ 0, unique solution exists. If |A| = 0, either no solution or infinite solutions. Consistency: rank(A) = rank([A|B]) for consistency. Homogeneous systems: AX = 0 always has trivial solution X = 0; non-trivial solutions exist if |A| = 0.

4. Eigenvalues & Eigenvectors: Characteristic equation: |A - λI| = 0. Eigenvalues λ satisfy trace(A) = sum(λᵢ) and |A| = product(λᵢ). For symmetric matrices, eigenvectors are orthogonal. Spectral theorem: real symmetric matrices have real eigenvalues.

5. Cayley-Hamilton Theorem: Every square matrix satisfies its own characteristic equation. Useful for finding A⁻¹ and higher powers of A.

Solved Examples

Example 1 (Determinant — Properties)
If A is a 3×3 matrix with |A| = 5, find |3A|.

a) 15 b) 45 c) 135 d) 27
Solution: c) 135. |kA| = kⁿ|A| where n is the order. For 3×3 matrix, n=3. |3A| = 3³×|A| = 27×5 = 135.
Example 2 (System of Equations)
Find the value of k for which the system has infinite solutions: x + 2y + z = 3, 2x + 4y + 2z = 6, 3x + 6y + kz = 9.

a) 1 b) 2 c) 3 d) 4
Solution: c) 3. The second equation is 2 times the first, so it's redundant. The third: 3x+6y+kz=9. For infinite solutions, the third must be 3 times the first: 3(x+2y+z) = 3x+6y+3z = 9. So k = 3.
Example 3 (Eigenvalues)
Find the eigenvalues of the matrix A = [[3, 1], [1, 3]].

a) 2, 4 b) 1, 5 c) 3, 3 d) -2, 8
Solution: a) 2, 4. Characteristic equation: |A - λI| = 0 → |(3-λ) 1; 1 (3-λ)| = (3-λ)² - 1 = 0 → λ² - 6λ + 9 - 1 = 0 → λ² - 6λ + 8 = 0 → (λ-2)(λ-4) = 0 → λ = 2, 4. Verification: trace = 3+3 = 6 = 2+4. Determinant = 9-1 = 8 = 2×4.

Shortcut Techniques

  • For 2×2 matrices, eigenvalues can be found quickly: λ = (trace ± √(trace² - 4det))/2.
  • Check consistency of linear systems by comparing ranks of A and [A|B] — rank = number of non-zero rows in row-echelon form.
  • For orthogonal matrices, columns are unit vectors and mutually perpendicular — Aᵀ = A⁻¹.
  • For finding A⁻¹ of 2×2 matrix: swap diagonal elements, negate off-diagonal, divide by determinant.
  • Cayley-Hamilton theorem provides a quick way to compute A² or A⁻¹ without solving linear systems.

Matrix Decompositions and Their Uses

Matrix decompositions factor a matrix into a product of simpler matrices that reveal structural properties such as rank, conditioning, and invariant subspaces. The most common decompositions in competitive examinations are LU, QR, and Cholesky. LU decomposition writes a square matrix A as A = LU where L is unit lower‑triangular and U is upper‑triangular; it exists for any non‑singular matrix after suitable row permutations (PA = LU). QR decomposition expresses A = QR with Q orthogonal (QᵀQ = I) and R upper‑triangular; it is numerically stable and underlies the Gram‑Schmidt process and the solution of least‑squares problems. Cholesky decomposition applies only to symmetric positive‑definite matrices, giving A = LLᵀ where L is lower‑triangular with positive diagonal entries; it halves the computational cost compared with LU. Each decomposition has a direct algorithmic counterpart: forward‑back substitution for LU, orthogonal transformations for QR, and a simple recurrence for Cholesky. In examinations, questions often ask to identify which decomposition is applicable given matrix properties, or to compute a specific factor when the matrix size is small (2×2 or 3×3). Understanding the existence conditions — non‑singular for LU, full column rank for QR, symmetric positive‑definite for Cholesky — prevents the common error of applying a decomposition to an unsuitable matrix.

Beyond the three classical factorizations, the Schur decomposition A = QTQᵀ (Q orthogonal, T upper‑triangular) guarantees that every real square matrix can be triangularised by an orthogonal similarity. The diagonal entries of T are the eigenvalues of A, and the columns of Q form an orthonormal basis of invariant subspaces. This result underpins the QR algorithm for eigenvalue computation. The spectral theorem for real symmetric matrices is a special case where T becomes diagonal. In practice, examiners may test the relationship between Schur form and the characteristic polynomial, or ask to deduce the eigenvalues of a block‑triangular matrix from its diagonal blocks. Mastery of these decompositions enables rapid solution of problems involving matrix powers, exponentials, and condition numbers without resorting to full diagonalisation.

Generalized Eigenvectors and Jordan Canonical Form

When a matrix does not possess a complete set of linearly independent eigenvectors, the Jordan canonical form provides the next best structural description. For each eigenvalue λ, the algebraic multiplicity is the exponent of (λ−λ) in the characteristic polynomial, while the geometric multiplicity is the dimension of the eigenspace ker(A−λI). If geometric multiplicity is less than algebraic multiplicity, the matrix is defective and generalized eigenvectors are required. A generalized eigenvector of rank k satisfies (A−λI)ᵏv = 0 but (A−λI)ᵏ⁻¹v ≠ 0. Chains of generalized eigenvectors form Jordan blocks Jₖ(λ) = λIₖ + Nₖ where Nₖ is the nilpotent matrix with ones on the super‑diagonal. The Jordan form J = P⁻¹AP is block‑diagonal with these blocks; P contains the eigenvectors and generalized eigenvectors as columns. The number of Jordan blocks for λ equals the geometric multiplicity, and the sizes of the blocks are determined by the sequence of dimensions of ker(A−λI)ʲ. In examinations, typical tasks include constructing the Jordan form of a 3×3 or 4×4 matrix given its characteristic and minimal polynomials, or determining the size of the largest Jordan block from the nilpotency index of (A−λI). A key shortcut: the minimal polynomial is the least common multiple of (λ−λ)ˢ where s is the size of the largest Jordan block for each eigenvalue. This allows rapid verification of whether a matrix is diagonalisable (minimal polynomial has only simple roots) without computing eigenvectors explicitly.

Technique: Building Jordan Chains from Nilpotent Powers
Let A be a 4×4 matrix with a single eigenvalue λ = 2 and characteristic polynomial (λ−2)⁴. Suppose (A−2I)² ≠ 0 but (A−2I)³ = 0. Determine the Jordan canonical form of A.
The nilpotency index of N = A−2I is 3, so the largest Jordan block has size 3. Since the matrix is 4×4, the remaining block must be of size 1. Therefore the Jordan form consists of one 3×3 block J₃(2) and one 1×1 block J₁(2). Explicitly, J = diag(J₃(2), [2]). The geometric multiplicity equals the number of blocks = 2, and the minimal polynomial is (λ−2)³.
Exam‑Day Strategy
When a problem gives only the characteristic polynomial and a condition on powers of (A−λI), first compute the nilpotency index to locate the largest Jordan block. Then use the matrix dimension to fill the remaining blocks. This avoids the longer route of finding explicit generalized eigenvectors.

Singular Value Decomposition and Low‑Rank Approximation

The singular value decomposition (SVD) factorises any real m×n matrix A as A = UΣVᵀ where U (m×m) and V (n×n) are orthogonal and Σ (m×n) is diagonal with non‑negative singular values σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0 (r = rank(A)). The columns of U are left singular vectors (eigenvectors of AAᵀ), columns of V are right singular vectors (eigenvectors of AᵀA), and σᵢ² are the non‑zero eigenvalues of both AAᵀ and AᵀA. SVD exists for every matrix, unlike eigendecomposition which requires square and diagonalizable matrices. A principal application is the best rank‑k approximation in the Frobenius or spectral norm: Aₖ = Σᵢ₌₁ᵏ σᵢ uᵢ vᵢᵀ, which minimises ‖A−B‖ among all matrices B of rank ≤ k (Eckart‑Young theorem). In examinations, questions may ask to compute the singular values of a 2×2 matrix analytically, to relate the condition number κ₂(A) = σ₁/σᵣ to numerical stability, or to determine the rank from the number of non‑zero singular values. A useful shortcut: for a 2×2 matrix A = [[a, b], [c, d]], the singular values are the square roots of the eigenvalues of AᵀA = [[a²+c², ab+cd], [ab+cd, b²+d²]], which can be obtained via the quadratic formula using trace and determinant of AᵀA. The nuclear norm ‖A‖* = Σ σᵢ and the operator norm ‖A‖₂ = σ₁ are also frequently tested. Understanding that the SVD provides an orthonormal basis for the four fundamental subspaces (column space, row space, null space, left null space) helps answer conceptual questions about rank‑deficiency and pseudoinverses.

Matrix Functions and the Matrix Exponential

Functions of a square matrix extend scalar functions via power series, diagonalisation, or the Jordan form. For a diagonalizable matrix A = PDP⁻¹, f(A) = Pf(D)P⁻¹ where f(D) applies f to each diagonal entry. For a defective matrix, the Jordan form yields f(J) where each Jordan block Jₖ(λ) is transformed into an upper‑triangular Toeplitz matrix whose entries are derivatives of f at λ divided by factorials: (f(Jₖ(λ)))ᵢⱼ = f⁽ʲ⁻ⁱ⁾(λ)/(j−i)! for j ≥ i. The matrix exponential eᴬ = Σₖ₌₀^∞ Aᵏ/k! is the most important matrix function; it solves the linear system x′ = Ax with solution x(t) = eᴬᵗ x(0). Properties include eᴬ⁺ᴮ = eᴬeᴮ when A and B commute, det(eᴬ) = etr(A), and (eᴬ)⁻¹ = e−ᴬ. For a 2×2 matrix with distinct eigenvalues λ₁, λ₂, eᴬ can be computed via the Lagrange interpolation formula eᴬ = (eλ₁−eλ₂)/(λ₁−λ₂) A + (λ₁eλ₂−λ₂eλ₁)/(λ₁−λ₂) I. When eigenvalues coincide, the formula involves the derivative: eᴬ = eλ I + eλ (A−λI). Examiners often ask to compute eᴬ for a given 2×2 or 3×3 matrix, or to use the exponential to solve a system of differential equations with constant coefficients. A practical shortcut: if A is nilpotent of index m (Aᵐ = 0), the series terminates at k = m−1, giving a polynomial in A. Recognising nilpotent blocks inside a Jordan form reduces the exponential to a finite sum.

Applications to Linear Differential Equations and Stability Analysis

Linear systems of ordinary differential equations x′ = Ax with constant coefficient matrix A are solved by the matrix exponential x(t) = eᴬᵗ x₀. The long‑term behaviour is governed by the eigenvalues of A. If all eigenvalues have negative real parts, the origin is asymptotically stable and every solution decays to zero exponentially. If any eigenvalue has a positive real part, solutions grow unbounded and the system is unstable. Purely imaginary eigenvalues lead to marginal stability (oscillations) provided the Jordan blocks are of size one; a defective imaginary eigenvalue produces polynomial growth (e.g., t·sin ωt) and instability. The Lyapunov equation AᵀP + PA = −Q with Q positive‑definite has a unique positive‑definite solution P iff A is Hurwitz (all eigenvalues in the open left half‑plane); this provides an algebraic stability test without computing eigenvalues. In examinations, typical problems present a 2×2 or 3×3 matrix and ask to classify the equilibrium, to sketch phase portraits based on eigenvalue type (node, saddle, focus, centre), or to determine the range of a parameter for which the system is stable. The Routh‑Hurwitz criterion applied to the characteristic polynomial gives necessary and sufficient conditions for all roots to have negative real parts without solving the polynomial. For a cubic λ³ + a₁λ² + a₂λ + a₃, stability requires a₁>0, a₃>0, and a₁a₂ > a₃. Mastery of these criteria allows rapid parameter‑range questions that would otherwise require explicit eigenvalue computation.

  • Assuming LU decomposition exists without checking for zero pivots or the need for row permutations.
  • Confusing geometric multiplicity with algebraic multiplicity when deciding diagonalisability.
  • Applying the Eckart‑Young theorem to a matrix that is not real or not using the Frobenius norm as specified.
  • Using the scalar exponential formula eλt for each eigenvalue without accounting for Jordan blocks of size greater than one.
  • Neglecting the commutativity condition when combining matrix exponentials eᴬeᴮ = eA+B.
  • Misapplying the Routh‑Hurwitz array by omitting the first‑column sign‑change test for higher‑order polynomials.
  • Treating the singular values of a rectangular matrix as eigenvalues of the matrix itself rather than of AᵀA or AAᵀ.

Quadratic Forms and Definiteness Criteria

A quadratic form in n variables is a homogeneous polynomial of degree two, written as Q(x) = xᵀ A x where A is a real symmetric n×n matrix and x ∈ ℝⁿ. The classification of Q depends entirely on the eigenvalues of A. If all eigenvalues are positive, Q is positive‑definite; if all are non‑negative, Q is positive‑semidefinite. Negative‑definite and negative‑semidefinite are defined analogously. When eigenvalues have mixed signs the form is indefinite. Sylvester’s criterion provides an algebraic test without computing eigenvalues: a symmetric matrix is positive‑definite iff all its leading principal minors are strictly positive. For positive‑semidefiniteness every principal minor (not only the leading ones) must be non‑negative. The same minors with alternating signs characterise negative‑definiteness. In examinations the criterion is frequently applied to bordered Hessian matrices arising from constrained optimisation, where the sign of the last n‑m leading principal minors determines the nature of a stationary point under m equality constraints. The Cholesky factorisation A = LLᵀ exists exactly for positive‑definite matrices and yields a numerically stable way to solve linear systems and to sample from multivariate normal distributions. For a positive‑semidefinite matrix a pivoted Cholesky or an LDLᵀ factorisation with a diagonal D ≥ 0 can be used. The inertia of a symmetric matrix — the triple (π, ν, δ) counting positive, negative and zero eigenvalues — is invariant under congruence transformations (Sylvester’s law of inertia). This invariance underpins the classification of conic sections and the analysis of saddle points in optimisation.

Kronecker Product, Vectorization, and Matrix Equations

The Kronecker product A ⊗ B of an m×n matrix A and a p×q matrix B is the mp×nq block matrix whose (i,j) block equals aᵢⱼ B. It satisfies (A ⊗ B)(C ⊗ D) = (AC) ⊗ (BD) whenever the ordinary products are defined, and (A ⊗ B)ᵀ = Aᵀ ⊗ Bᵀ. Vectorisation vec(X) stacks the columns of X into a single column vector. The fundamental identity vec(AXB) = (Bᵀ ⊗ A) vec(X) converts matrix equations into standard linear systems. For the Sylvester equation AX + XB = C, vectorisation gives (I ⊗ A + Bᵀ ⊗ I) vec(X) = vec(C). The coefficient matrix is a sum of two Kronecker products; its eigenvalues are λᵢ(A) + λⱼ(B). Hence the Sylvester equation has a unique solution iff λᵢ(A) + λⱼ(B) ≠ 0 for all i,j. The discrete‑time Lyapunov equation X − A X Aᵀ = Q and the continuous‑time Lyapunov equation A X + X Aᵀ = −Q are special cases. In control theory the controllability Gramian solves the Lyapunov equation and its positive‑definiteness is equivalent to controllability. The Kronecker sum A ⊕ B = A ⊗ I + I ⊗ B appears naturally when differentiating matrix exponentials: d/dt eA t = A eA t = eA t A. The vec‑operator also linearises the Riccati equation, enabling Newton‑type iterations that operate on vectorised unknowns. Examiners often ask to rewrite a given matrix equation in vec‑form, to state the solvability condition in terms of eigenvalue sums, or to compute the dimension of the solution space when the coefficient matrix is singular.

Worked Example: Sylvester Equation Solvability
Let A = [[2, 0], [0, -1]] and B = [[-2, 0], [0, 3]]. Determine whether the Sylvester equation AX + XB = C has a unique solution for every 2×2 matrix C.
The eigenvalues of A are 2 and -1. The eigenvalues of B are -2 and 3. The sums λᵢ(A) + λⱼ(B) are: 2+(-2)=0, 2+3=5, -1+(-2)=-3, -1+3=2. Because one sum equals zero, the coefficient matrix I ⊗ A + Bᵀ ⊗ I is singular. Hence the Sylvester equation does not have a unique solution for all C; it is solvable only when vec(C) lies in the column space of that coefficient matrix.
Exam‑Day Strategy
When a matrix equation appears, first identify its type (Sylvester, Lyapunov, Stein, Riccati). Write the vectorised form immediately; the Kronecker‑sum eigenvalue condition is a one‑line check for uniqueness. If the problem asks for a parameter range guaranteeing a unique solution, compute the eigenvalue sums symbolically and enforce non‑zero inequalities.

Perturbation Bounds for Eigenvalues and Eigenvectors

Let A be a diagonalizable matrix with eigenvalue decomposition A = V Λ V⁻¹ and let Ã = A + E be a perturbation. The Bauer–Fike theorem states that for any eigenvalue μ of Ã there exists an eigenvalue λ of A such that |μ − λ| ≤ κ(V) ‖E‖, where κ(V) = ‖V‖ ‖V⁻¹‖ is the condition number of the eigenvector matrix in the chosen norm. For normal matrices (including Hermitian and unitary) κ(V)=1, so eigenvalues are perfectly conditioned: each perturbed eigenvalue lies within ‖E‖ of some original eigenvalue. Weyl’s inequalities sharpen this for Hermitian matrices: if eigenvalues are ordered λ₁ ≤ … ≤ λₙ and μ₁ ≤ … ≤ μₙ, then |μᵢ − λᵢ| ≤ ‖E‖₂ for all i. Eigenvector perturbation is governed by the Davis–Kahan sin Θ theorem: if an invariant subspace of A is separated from the rest of the spectrum by a gap δ > 0, then the sine of the angle between the true and perturbed subspaces is bounded by ‖E‖₂ / δ. For a simple eigenvalue λ with normalised eigenvector x, the first‑order change in the eigenvector is (λI − A)⁺ E x, where ⁺ denotes the Moore–Penrose inverse. In examinations, typical questions give a symmetric matrix with a known eigenvalue gap and ask for a bound on the eigenvector rotation caused by a perturbation of given norm. Recognising that the bound scales inversely with the spectral gap is crucial; clustered eigenvalues are highly sensitive even to tiny perturbations.

Matrix Norms, Condition Numbers, and Numerical Stability

A matrix norm ‖·‖ is a vector norm on ℝm×n satisfying sub‑multiplicativity ‖AB‖ ≤ ‖A‖ ‖B‖ whenever the product is defined. The induced (operator) norm ‖A‖ₚ = maxx≠0 ‖Ax‖ₚ / ‖x‖ₚ equals the largest singular value for p=2, the maximum absolute column sum for p=1, and the maximum absolute row sum for p=∞. The Frobenius norm ‖A‖_F = √(Σ aᵢⱼ²) = √(trace(AᵀA)) is unitarily invariant but not an induced norm. The condition number of a nonsingular matrix A with respect to inversion is κ(A) = ‖A‖ ‖A⁻¹‖. For the 2‑norm κ₂(A) = σ₁/σₙ, the ratio of largest to smallest singular values. A problem is ill‑conditioned when κ is large; the relative error in the solution of Ax = b can be amplified by up to κ(A) times the relative error in the data. Backward stability of an algorithm means the computed solution x̂ satisfies (A+ΔA)x̂ = b with ‖ΔA‖/‖A‖ = O(ε_machine). Gaussian elimination with partial pivoting is backward stable for most matrices, but the growth factor can be exponential for pathological cases (e.g., Wilkinson’s matrix). The QR factorisation via Householder reflections is unconditionally backward stable and yields an orthogonal Q, making it the preferred method for least‑squares problems. In exams, you may be asked to compute κ₁, κ₂, or κ_∞ for a given matrix, to compare the sensitivity of solving linear systems versus computing eigenvalues, or to explain why forming the normal equations AᵀA x = Aᵀb squares the condition number and should be avoided when κ₂(A) is moderate.

Schur Decomposition and the Real Schur Form

Every square complex matrix A admits a Schur decomposition A = Q T Q* where Q is unitary and T is upper triangular with the eigenvalues of A on its diagonal. The columns of Q are a Schur basis; the first k columns span an invariant subspace corresponding to the first k diagonal entries of T. For real matrices a real Schur form exists: A = Q T Qᵀ with Q orthogonal and T block upper triangular where each diagonal block is either a 1×1 real eigenvalue or a 2×2 block [[a, b], [c, d]] with complex conjugate eigenvalues a ± i√(bc−ad). The real Schur form is computed by the QR algorithm with implicit double shifts and is the backbone of modern eigensolvers (e.g., LAPACK’s ?gees). The ordered Schur form allows the eigenvalues to appear in any prescribed order along the diagonal, which is essential for solving Sylvester and Riccati equations via the Bartels–Stewart algorithm. The separation between two invariant subspaces is quantified by sep(T₁₁, T₂₂) = min‖X‖_F=1 ‖T₁₁ X − X T₂₂‖_F; this quantity appears in perturbation bounds for invariant subspaces. In examinations, you may be asked to construct the real Schur form of a 3×3 matrix with one real and a pair of complex eigenvalues, to explain how the QR algorithm converges to the Schur form, or to use the ordered Schur form to decouple a large Sylvester equation into smaller independent subsystems.

  • Confusing the condition number of the eigenvector matrix κ(V) with the eigenvalue condition number; for normal matrices they coincide but for non‑normal matrices κ(V) can be arbitrarily large.
  • Applying Weyl’s inequalities to non‑Hermitian matrices; they hold only for Hermitian (or symmetric) perturbations.
  • Assuming the Kronecker sum eigenvalue condition λᵢ(A)+λⱼ(B)≠0 is sufficient for the Sylvester equation when A or B are defective; the condition remains necessary and sufficient regardless of diagonalizability.
  • Using the Frobenius norm as an induced norm in backward‑error analysis; it is not sub‑multiplicative with respect to the vector 2‑norm.
  • Neglecting the growth factor in Gaussian elimination when arguing numerical stability; partial pivoting bounds the growth factor by 2n−1 but does not eliminate it.
  • Treating the real Schur form as a diagonalisation; the 2×2 blocks cannot be further reduced by orthogonal transformations.
  • Forgetting that the separation sep(T₁₁,T₂₂) governs the sensitivity of invariant subspaces, not the eigenvalue gaps alone.

These advanced topics complete the core toolkit required for high‑level linear algebra problems in competitive examinations.

Tensor Products, Kronecker Structure, and Multilinear Maps

The tensor (Kronecker) product of an m×n matrix A and a p×q matrix B is the mp×nq block matrix A⊗B whose (i,j) block equals aijB. This operation is bilinear, associative, and satisfies (A⊗B)(C⊗D) = (AC)⊗(BD) whenever the products are defined. The eigenvalues of A⊗B are all pairwise products λi(A)λj(B), and the singular values are the pairwise products of the singular values of the factors. The vectorisation operator vec stacks the columns of a matrix; it converts the matrix equation AXB = C into the linear system (BT⊗A) vec(X) = vec(C). This identity is the foundation for solving Sylvester and Lyapunov equations via Kronecker sums: the equation AX + XB = C becomes (I⊗A + BT⊗I) vec(X) = vec(C). The Kronecker sum I⊗A + BT⊗I has eigenvalues λi(A) + λj(B); the Sylvester equation has a unique solution iff no sum vanishes. In multilinear algebra, a tensor of order three can be viewed as a linear map between matrix spaces, and its rank (the minimal number of rank‑one terms) is NP‑hard to compute in general, but the Tucker and CP decompositions provide practical low‑rank approximations. Examination questions often ask to compute the eigenvalues of a Kronecker product given the spectra of the factors, to rewrite a matrix equation in vectorised form, or to determine the solvability condition for a Sylvester equation by inspecting the spectra of the coefficient matrices.

Minimal Polynomial, Rational Canonical Form, and Matrix Functions

The minimal polynomial μA(λ) of a square matrix A is the monic polynomial of least degree such that μA(A) = 0. It divides the characteristic polynomial χA(λ) and shares the same irreducible factors; the exponent of each factor equals the size of the largest Jordan block associated with that eigenvalue. The rational canonical form (also called the Frobenius normal form) decomposes A into a block diagonal matrix whose blocks are companion matrices of the invariant factors — the monic polynomials that divide each other and whose product is χA(λ). Unlike the Jordan form, the rational canonical form exists over any field and does not require eigenvalues to lie in the field. Matrix functions f(A) for analytic f can be defined via the minimal polynomial: if μA(λ) = ∏(λ−λi)mi, then f(A) is the unique polynomial r(A) of degree < deg μA satisfying r(k)(λi) = f(k)(λi) for k = 0,…,mi−1. This Hermite interpolation formula yields closed forms for the matrix exponential, logarithm, and fractional powers without computing eigenvectors. The Cayley‑Hamilton theorem guarantees χA(A) = 0, so any power Ak with k ≥ n can be reduced to a linear combination of I, A, …, An−1. In examinations, typical tasks include finding the minimal polynomial from the Jordan or rational form, computing eAt for a 3×3 matrix with a repeated eigenvalue, and proving that two matrices are similar iff they have identical invariant factors.

Worked Example: Matrix Exponential via Minimal Polynomial
Let A = [[2, 1, 0], [0, 2, 0], [0, 0, 3]]. Compute exp(A).
The eigenvalues are 2 (algebraic multiplicity 2) and 3. The Jordan block for λ=2 is size 2, so the minimal polynomial is μ(λ) = (λ−2)²(λ−3). We seek a polynomial r(λ) = aλ² + bλ + c such that r(2)=e², r′(2)=e², r(3)=e³. Solving the linear system yields a = (e³−e²)/2, b = e²−2a, c = e²−2b−4a. Then exp(A) = aA² + bA + cI. Computing A² = [[4,4,0],[0,4,0],[0,0,9]] and substituting gives the final matrix.
Exam‑Day Strategy
When a matrix has a small minimal polynomial degree, always prefer the polynomial interpolation method over diagonalisation; it avoids eigenvector calculations and works even when the matrix is defective. Write down the interpolation conditions explicitly before solving for coefficients.

Pseudospectra and Non‑Normal Matrix Analysis

For a non‑normal matrix A, the eigenvalue spectrum can be a poor indicator of dynamical behaviour. The ε‑pseudospectrum Λε(A) is the set of complex numbers z such that ‖(zI−A)−1‖ ≥ ε−1 (or equivalently, z is an eigenvalue of A+E for some perturbation ‖E‖ ≤ ε). Pseudospectra reveal transient growth: even if all eigenvalues lie in the left half‑plane, the norm of etA can grow by a factor proportional to the Kreiss constant supRe z>0 Re(z)‖(zI−A)−1‖ before eventual decay. The numerical abscissa ω(A) = max‖x‖=1 Re(x*Ax) = λmax((A+A*)/2) bounds the initial growth rate ‖etA‖ ≤ et ω(A). For Toeplitz or companion matrices arising from discretised differential operators, pseudospectra often extend far into the right half‑plane, explaining why eigenvalue‑based stability criteria fail. Computation of pseudospectra uses the singular value decomposition of (zI−A) on a grid; the smallest singular value σmin(zI−A) gives the resolvent norm. In examinations, you may be asked to sketch the ε‑pseudospectrum of a 2×2 Jordan block, to compute the numerical abscissa of a given matrix, or to explain why a matrix with eigenvalues −1±i can exhibit ‖etA‖ > 100 for moderate t.

Structured Matrices: Toeplitz, Circulant, and Displacement Rank

A Toeplitz matrix T has constant diagonals: tij = ti−j. A circulant matrix C is a Toeplitz matrix whose rows are cyclic shifts of the first row; it is diagonalised by the discrete Fourier transform (DFT) matrix F: C = F* diag(Fc) F, where c is the first column. Consequently, circulant systems can be solved in O(n log n) via FFT. General Toeplitz matrices are not diagonalised by the DFT, but they possess low displacement rank: the Sylvester displacement ∇A,B(T) = T − ATB has rank at most 2 for suitable shift matrices A, B (e.g., the down‑shift and up‑shift). This property underlies the Gohberg‑Semencul formula, which expresses T−1 as a sum of products of lower‑ and upper‑triangular Toeplitz matrices, enabling O(n²) inversion and O(n log n) multiplication via embedding into a circulant matrix of size 2n. Hankel matrices (constant anti‑diagonals) share the same displacement structure. In competitive problems, you may be asked to compute the eigenvalues of a circulant matrix from its first column, to apply the Gohberg‑Semencul formula for a 4×4 Toeplitz inverse, or to estimate the condition number of a Toeplitz matrix using its symbol (the generating function on the unit circle).

Iterative Methods for Large Sparse Linear Systems

Direct factorisations (LU, Cholesky) incur fill‑in that destroys sparsity for large problems. Iterative methods generate a sequence x(k) converging to the solution of Ax = b. Stationary splittings A = M − N yield fixed‑point iterations x(k+1) = M−1N x(k) + M−1b. The Jacobi method uses M = diag(A), Gauss‑Seidel uses the lower triangular part, and SOR introduces a relaxation parameter ω. Convergence is guaranteed if the spectral radius ρ(M−1N) < 1; for symmetric positive definite A, Gauss‑Seidel always converges and SOR with optimal ω can accelerate convergence dramatically. Krylov subspace methods build the approximation in the affine space x(0) + span{r(0), Ar(0), …}. The Conjugate Gradient (CG) method is optimal for symmetric positive definite matrices, minimising the energy norm ‖x−x*‖A at each step. For non‑symmetric systems, GMRES minimises the residual norm over the Krylov subspace but requires storing all basis vectors; restarted GMRES(m) limits memory. BiCGSTAB and TFQMR are short‑recurrence alternatives. Preconditioning replaces Ax = b by M−1Ax = M−1b (left) or AM−1y = b, x = M−1y (right) with a cheaply invertible M approximating A. Incomplete LU (ILU) and algebraic multigrid are standard preconditioners. Examination questions often ask to derive the iteration matrix for SOR, to prove CG convergence in at most n steps, or to explain why preconditioning clusters eigenvalues and reduces the GMRES iteration count.

  • Confusing the minimal polynomial with the characteristic polynomial; the minimal polynomial may have lower degree and determines the size of the largest Jordan block.
  • Assuming that a matrix with all eigenvalues in the left half‑plane is asymptotically stable for the differential equation x′ = Ax without checking non‑normal transient growth.
  • Treating the Kronecker product as commutative; A⊗B ≠ B⊗A in general, though they are similar via a permutation matrix.
  • Using the DFT to diagonalise a general Toeplitz matrix; only circulant matrices are diagonalised by the Fourier matrix.
  • Applying the Conjugate Gradient method to indefinite or non‑symmetric systems; CG may break down or produce meaningless iterates.
  • Neglecting the effect of restart in GMRES(m); the method may stagnate if the restart length is too small relative to the spectral distribution.
  • Assuming that a low displacement rank guarantees a fast direct solver for any Toeplitz matrix; the Gohberg‑Semencul formula requires the matrix to be nonsingular and the displacement generators to be known.

Nonnegative Matrices and the Perron–Frobenius Theory

A matrix A is called nonnegative (written A ≥ 0) if every entry aij ≥ 0. It is positive (A > 0) if all entries are strictly positive. The Perron–Frobenius theorem gives a complete spectral description for these matrices. For a positive matrix, there exists a simple eigenvalue ρ(A) > 0, called the Perron root, such that ρ(A) = max{|λ| : λ ∈ σ(A)}. The corresponding right and left eigenvectors can be chosen strictly positive. Moreover, ρ(A) is the only eigenvalue on the spectral circle |λ| = ρ(A), and it is a simple root of the characteristic polynomial.

For irreducible nonnegative matrices (those that cannot be permuted to block upper‑triangular form with a zero block), the same conclusions hold except that there may be other eigenvalues of modulus ρ(A). These are exactly the h‑th roots of unity times ρ(A), where h is the index of imprimitivity (the period of the associated directed graph). The eigenvectors for ρ(A) remain nonnegative and can be chosen positive if the matrix is primitive (aperiodic). The Collatz–Wielandt formula characterises the Perron root as

ρ(A) = maxx>0 mini (Ax)i / xi = minx>0 maxi (Ax)i / xi.

Applications abound: stochastic matrices (rows sum to 1) have ρ = 1; the stationary distribution of a finite Markov chain is the positive left eigenvector. In economics, input‑output models (Leontief) use (I − A)−1 where A is nonnegative and ρ(A) < 1 guarantees convergence of the Neumann series. The theorem also underpins Google’s PageRank, where the web graph’s adjacency matrix is made stochastic and primitive by a damping factor.

Extensions include the Krein–Rutman theorem for compact positive operators on Banach spaces, and the theory of M‑matrices (A = sI − B with B ≥ 0, s > ρ(B)) whose inverses are nonnegative. In examinations, you may be asked to prove that a primitive stochastic matrix has a unique stationary distribution, to compute the index of imprimitivity from the directed graph, or to apply the Collatz–Wielandt bounds to estimate ρ(A) without full diagonalisation.

Matrix Equations: Sylvester, Lyapunov, and Algebraic Riccati

The Sylvester equation AX + XB = C with given square matrices A (m×m), B (n×n) and C (m×n) has a unique solution X for every C iff σ(A) ∩ σ(−B) = ∅. Using the Kronecker product, the equation vectorises to (I ⊗ A + BT ⊗ I) vec(X) = vec(C). The eigenvalues of the coefficient matrix are λi(A) + λj(B), confirming the spectral separation condition. The Bartels–Stewart algorithm reduces A and B to real Schur form, then solves the resulting triangular system by back‑substitution in O(m3 + n3) operations.

The continuous‑time Lyapunov equation AX + XA* = −Q (with Q = Q* ≥ 0) appears in stability analysis of ẋ = Ax. If A is Hurwitz (all eigenvalues in the open left half‑plane), the unique solution is X = ∫0∞ etA Q etA* dt and is positive definite. Conversely, if there exists Q > 0 such that the solution X > 0, then A is Hurwitz. The discrete‑time Lyapunov (Stein) equation X − A X A* = Q characterises Schur stability (ρ(A) < 1).

The algebraic Riccati equation (ARE) A*X + XA − XBR−1B*X + Q = 0 arises in linear‑quadratic optimal control and H∞ filtering. Here Q = Q* ≥ 0, R = R* > 0. Under stabilisability of (A, B) and detectability of (A, Q1/2), there exists a unique stabilising solution X ≥ 0 such that A − BR−1B*X is Hurwitz. This solution can be obtained from the stable invariant subspace of the Hamiltonian matrix H = [A, −BR−1B*; −Q, −A*]. The discrete‑time ARE X = A*XA − A*XB(R + B*XB)−1B*XA + Q is solved via the symplectic pencil. In competitive problems, you may be asked to derive the Lyapunov equation from the derivative of a quadratic Lyapunov function, to prove that the Sylvester equation has a unique solution when A and −B have disjoint spectra, or to compute the stabilising solution of a 2×2 ARE by Hamiltonian eigen‑decomposition.

Worked Example: Solving a Sylvester Equation
Solve AX + XB = C for A = [[2, 1], [0, 3]], B = [[−1, 0], [0, −2]], C = [[1, 2], [3, 4]].
Step 1: Check spectral separation. Eigenvalues of A are 2, 3. Eigenvalues of −B are 1, 2. Since 2 appears in both sets, the spectra intersect → the Sylvester equation does not have a unique solution for arbitrary C. Step 2: Because the condition fails, we examine consistency. Vectorise: (I ⊗ A + BT ⊗ I) vec(X) = vec(C). The coefficient matrix is singular (determinant zero). Step 3: Compute the rank of the augmented matrix. Exam‑Day Strategy
When a Sylvester or Lyapunov equation appears, first verify the spectral separation condition; it is a quick yes/no that often decides whether a unique solution exists. For Lyapunov, remember that A Hurwitz ⇔ there exists Q > 0 with X > 0. For ARE, the stabilising solution is the one that makes the closed‑loop matrix stable; you can find it by computing the stable invariant subspace of the Hamiltonian (continuous) or symplectic pencil (discrete). In multiple‑choice questions, the correct stabilising solution is often the only positive semidefinite one.

Majorization, Interlacing, and Weyl's Inequalities

Majorization provides a pre‑order on vectors that captures the notion of “more spread out”. For x, y ∈ ℝn with components sorted decreasingly, x majorizes y (written x ≺ y) if ∑i=1k xi ≤ ∑i=1k yi for k = 1,…,n−1 and equality holds for k = n. A fundamental result (Karamata) states that for any convex function φ, ∑ φ(xi) ≤ ∑ φ(yi) whenever x ≺ y. This underpins many matrix inequalities.

Eigenvalue interlacing theorems relate the spectra of a Hermitian matrix and its principal submatrices. Cauchy’s interlacing theorem: if B is an (n−1)×(n−1) principal submatrix of an n×n Hermitian A, then λi(A) ≤ λi(B) ≤ λi+1(A) for i = 1,…,n−1 (eigenvalues sorted increasingly). For a rank‑one perturbation A + uu*, the eigenvalues interlace those of A with a single new eigenvalue inserted. Weyl’s inequalities bound the eigenvalues of a sum: for Hermitian A, B, λi+j−1(A + B) ≤ λi(A) + λj(B) (with appropriate index conventions). In particular, |λi(A + B) − λi(A)| ≤ ‖B‖2.

These tools yield sharp perturbation bounds. The Hoffman–Wielandt theorem states that for normal matrices, there exists a permutation π such that ∑ |λi(A) − λπ(i)(B)|2 ≤ ‖A − B‖F2. For Hermitian matrices, the eigenvalues can be matched in order, giving ∑ (λi(A) − λi(B))2 ≤ ‖A − B‖F2. Majorization also appears in the Schur–Horn theorem: the diagonal entries of a Hermitian matrix are majorized by its eigenvalues. In examinations, you may be asked to prove Cauchy interlacing for a bordered matrix, to apply Weyl’s inequalities to bound the smallest eigenvalue of a perturbed covariance matrix, or to use the Schur–Horn theorem to show that a given vector cannot be the diagonal of a Hermitian matrix with prescribed eigenvalues.

Low‑Rank Updates, Sherman–Morrison–Woodbury, and Matrix Determinant Lemma

Many practical problems require updating the inverse or determinant of a matrix after a low‑rank modification. The Sherman–Morrison formula handles a rank‑one update: if A is invertible and 1 + v*A−1u ≠ 0, then (A + uv*)−1 = A−1 − (A−1uv*A−1) / (1 + v*A−1u). The Woodbury matrix identity generalises to rank‑k: (A + UCV)−1 = A−1 − A−1U (C−1 + V A−1U)−1 V A−1, where U is n×k, C is k×k invertible, V is k×n. This reduces an n×n inversion to a k×k inversion when k ≪ n.

The matrix determinant lemma gives the determinant of a rank‑one update: det(A + uv*) = det(A) (1 + v*A−1u). For rank‑k, det(A + UCV) = det(A) det(C−1 + V A−1U) det(C). These identities are essential in Kalman filtering (updating the covariance matrix), Gaussian process regression (updating the kernel matrix), and statistics (leave‑one‑out cross‑validation). They also appear in the derivation of the block‑wise inversion formula for partitioned matrices.

Numerical stability requires care: if A is ill‑conditioned, the explicit update may amplify errors. A stable approach computes the Cholesky factor of A and updates the factor using rank‑one Cholesky update/downdate algorithms (e.g., Gill–Murray). In competitive problems, you may be asked to derive the Woodbury identity from block Gaussian elimination, to compute the inverse of I + xyT explicitly, or to show that the determinant of a Cauchy matrix Cij = 1/(xi + yj) can be evaluated via the matrix determinant lemma after a suitable factorisation.

Numerical Eigenvalue Algorithms: QR, Hessenberg, and the Implicit Q Theorem

The QR algorithm is the workhorse for computing all eigenvalues of a dense matrix. Starting from A0 = A, iterate Ak = QkRk, Ak+1 = RkQk where Ak = QkRk is a QR factorisation. The sequence Ak converges to an upper triangular (Schur) form, revealing eigenvalues on the diagonal. For real matrices, the real Schur form is quasi‑triangular with 1×1 and 2×2 blocks corresponding to real eigenvalues and complex conjugate pairs.

To reduce cost from O(n3) per iteration to O(n2), the matrix is first reduced to upper Hessenberg form (H = QTAQ with H zero below the first sub‑diagonal) using Householder reflectors. The QR iteration on a Hessenberg matrix preserves the Hessenberg structure, and each step costs O(n2). Shifts accelerate convergence: the single‑shift QR uses Ak − μI = QkRk, Ak+1 = RkQk + μI. The Francis double‑shift (implicit QR) uses a real shift pair (μ, μ̄) to chase a bulge through the matrix, maintaining real arithmetic for complex conjugate eigenvalues. The implicit Q theorem states that if an orthogonal matrix Q transforms a Hessenberg matrix H to another Hessenberg matrix H̃ = QTHQ with positive sub‑diagonal entries, then Q and H̃ are uniquely determined by the first column of Q. This theorem justifies the bulge‑chasing procedure: the implicit step is mathematically equivalent to an explicit QR step with the same shifts.

For symmetric/Hermitian matrices, the Hessenberg reduction yields a tridiagonal matrix. The QR algorithm on a tridiagonal matrix converges cubically with Wilkinson’s shift (the eigenvalue of the bottom 2×2 submatrix closer to the last diagonal entry). The divide‑and‑conquer algorithm and the MRRR (Multiple Relatively Robust Representations) method achieve O(n2) or even O(n) for eigenvalues only. In examinations, you may be asked to perform one step of the QR algorithm on a 3×3 Hessenberg matrix with a given shift, to explain why the implicit Q theorem guarantees that the bulge‑chasing procedure produces the same result as an explicit shifted QR step, or to derive the Wilkinson shift for a 2×2 symmetric matrix.

  • Confusing the Perron root with the spectral radius for non‑irreducible matrices; the Perron–Frobenius theorem guarantees a positive eigenvector only for irreducible (or primitive) matrices.
  • Assuming the Sylvester equation always has a unique solution; the spectral separation condition σ(A) ∩ σ(−B) = ∅ is necessary and sufficient.
  • Applying Weyl’s inequalities to non‑Hermitian matrices; they hold only for Hermitian (or normal) matrices, while the Bauer–Fike theorem gives bounds for diagonalisable non‑normal matrices.
  • Using the Sherman–Morrison formula when 1 + v*A−1u = 0; the updated matrix is singular and the formula breaks down.
  • Believing the QR algorithm converges to a diagonal matrix for non‑normal matrices; it converges to Schur form (upper triangular), not necessarily diagonal.
  • Neglecting the positivity requirement on sub‑diagonal entries in the implicit Q theorem; without it, the orthogonal matrix Q is not uniquely determined.
  • Forgetting that the matrix determinant lemma requires A to be invertible; if A is singular, the determinant of A + uv* cannot be expressed by the simple formula.

Generalized Eigenvalue Problem and the QZ Algorithm

The generalized eigenvalue problem seeks scalars λ and non‑zero vectors x such that A x = λ B x, where A and B are n×n matrices and B may be singular. When B is invertible the problem reduces to the standard eigenvalue problem for B⁻¹A, but the reduction destroys structure and can amplify rounding errors. The QZ algorithm (also called the generalized Schur method) works directly on the pair (A,B) by reducing it to a generalized Schur form (S,T) = (Qᵀ A Z, Qᵀ B Z) where Q and Z are orthogonal (or unitary) and S is quasi‑triangular while T is upper triangular. The eigenvalues are then the ratios of the diagonal blocks of S and T, with infinite eigenvalues appearing when a diagonal entry of T is zero. The reduction to Hessenberg‑triangular form (A Hessenberg, B triangular) costs O(n³) and is performed with orthogonal transformations that preserve the pencil’s eigenvalues exactly in exact arithmetic.

During the QZ iteration a double‑shift strategy analogous to the Francis QR step is used: a pair of shifts (μ, μ̄) derived from the eigenvalues of the trailing 2×2 sub‑pencil is applied, and a bulge is chased through the matrices using orthogonal rotations. The implicit Q theorem for the QZ algorithm guarantees that the orthogonal matrices Q and Z are uniquely determined by the first columns of Q and Z provided the sub‑diagonal entries of S and T are kept positive. This uniqueness underpins the bulge‑chasing procedure and ensures that the implicit step is mathematically equivalent to an explicit shifted QZ step. For real pencils the algorithm stays in real arithmetic, producing 1×1 and 2×2 blocks on the diagonal of S that correspond to real eigenvalues and complex conjugate pairs.

In practice the QZ algorithm is the method of choice for dense generalized eigenvalue problems in control theory (solving the algebraic Riccati equation via the Hamiltonian pencil), vibration analysis (M x = λ K x with mass matrix M and stiffness matrix K), and descriptor systems (E ẋ = A x). When B is symmetric positive definite, a Cholesky factorisation B = L Lᵀ transforms the pencil to a standard symmetric problem L⁻¹ A L⁻ᵀ, which can be solved more cheaply with the symmetric QR algorithm. However, if B is ill‑conditioned or singular, the QZ algorithm remains stable because it never forms B⁻¹ explicitly. Examination questions often ask to perform one QZ iteration on a 3×3 Hessenberg‑triangular pencil with a given shift, to explain why the implicit Q theorem justifies the bulge chase, or to derive the generalized Schur form of a simple pencil such as ( [2 1; 0 1], [1 0; 0 0] ).

Krylov Subspace Methods for Large‑Scale Eigenvalue Computation

For large sparse matrices the dense QZ or QR algorithms are infeasible because they require O(n³) operations and destroy sparsity. Krylov subspace methods build a sequence of subspaces K_m(A, v) = span{ v, A v, A² v, …, Am‑1 v } and extract approximate eigenpairs from the projection of A onto this subspace. The Arnoldi process generates an orthonormal basis V_m of K_m(A, v) and an upper Hessenberg matrix H_m = V_mᵀ A V_m. The Ritz values (eigenvalues of H_m) converge to the eigenvalues of A, typically the extremal ones, as m grows. For Hermitian A the Arnoldi process reduces to the Lanczos algorithm, producing a symmetric tridiagonal T_m = V_mᵀ A V_m with a three‑term recurrence that halves the storage and computational cost.

Restarting is essential because the basis size m cannot grow indefinitely. Implicitly restarted Arnoldi (IRAM) and thick‑restart Lanczos discard unwanted Ritz vectors while preserving the Krylov subspace structure, allowing the computation of a few eigenvalues with O(n) memory and O(n m) work per restart. Shift‑and‑invert spectral transformation (A − σ I)⁻¹ accelerates convergence to eigenvalues near a target σ, at the cost of solving linear systems with the shifted matrix. Preconditioned iterative solvers (e.g., incomplete LU or algebraic multigrid) are used for these inner solves. The Jacobi–Davidson method combines a correction equation with subspace expansion, offering robust convergence for interior eigenvalues without explicit inversion.

In competitive examinations you may be asked to write the three‑term Lanczos recurrence, to explain why loss of orthogonality occurs in finite precision and how selective re‑orthogonalisation restores it, or to derive the Ritz pair residual norm ‖A x − θ x‖ from the Arnoldi relation A V_m = V_m H_m + hm+1,m vm+1 e_mᵀ. A typical trap is to assume that Ritz values always approximate the extreme eigenvalues; for non‑normal matrices they can converge to spurious values, and the pseudospectrum provides a more reliable picture.

Worked Example: One Step of Implicitly Restarted Arnoldi
Given a 5×5 sparse matrix A and a starting vector v₁, perform one Arnoldi iteration to obtain V₂ and H₂, then apply an implicit restart with a single unwanted Ritz value μ to produce a new starting vector v₁⁺ for the next cycle.
1. Arnoldi step: w = A v₁; h₁₁ = v₁ᵀ w; w = w − h₁₁ v₁; h₂₁ = ‖w‖; v₂ = w / h₂₁. Now V₂ = [v₁ v₂] and H₂ = [[h₁₁, h₁₂]; [h₂₁, 0]] where h₁₂ = v₂ᵀ A v₁. 2. Compute Ritz values θ₁, θ₂ as eigenvalues of H₂. 3. Choose unwanted shift μ = θ₂. 4. Implicit QR step on H₂ with shift μ: form H₂ − μ I = Q R, update H₂⁺ = R Q + μ I, and accumulate Q into V₂⁺ = V₂ Q. 5. The new starting vector is the first column of V₂⁺, i.e., v₁⁺ = V₂⁺ e₁. This vector lies in the original Krylov subspace K₂(A, v₁) but has the component along the unwanted Ritz vector removed, so the next Arnoldi cycle builds K₂(A, v₁⁺) effectively of dimension three.

Memorise the three‑term Lanczos recurrence and the Arnoldi relation A V_m = V_m H_m + hm+1,m vm+1 e_mᵀ. When asked about restarting, describe the implicit QR step on the small Hessenberg matrix and the update of the basis vectors. For shift‑and‑invert, state that the transformed matrix is (A − σ I)⁻¹ and that eigenvalues near σ become dominant. Always mention loss of orthogonality and the remedy of selective re‑orthogonalisation for Lanczos.

Matrix Sign Function and Invariant Subspace Computation

The matrix sign function sign(A) is defined for a matrix with no eigenvalues on the imaginary axis as the unique matrix that commutes with A, satisfies sign(A)² = I, and has eigenvalues +1 for eigenvalues of A in the open right half‑plane and −1 for those in the open left half‑plane. It can be computed by the Newton iteration Xk+1 = ½ (X_k + X_k⁻¹) with X₀ = A, which converges quadratically to sign(A) provided A has no pure imaginary eigenvalues. The projectors onto the stable and unstable invariant subspaces are P₊ = ½ (I + sign(A)) and P₋ = ½ (I − sign(A)). These projectors are idempotent and satisfy A P₊ = P₊ A, A P₋ = P₋ A, enabling the decoupling of the system ẋ = A x into stable and unstable parts without explicitly computing eigenvectors.

The sign function is closely related to the matrix sector function and to the solution of the algebraic Riccati equation. For a Hamiltonian matrix H = [A, −G; −Q, −Aᵀ] with G, Q symmetric positive semidefinite, the stable invariant subspace corresponds to the solution of the continuous‑time algebraic Riccati equation Aᵀ X + X A − X G X + Q = 0. Computing sign(H) yields the projector onto the stable subspace, from which the Riccati solution X can be extracted. The iteration is globally convergent and numerically stable when implemented with a scaling factor (e.g., Xk+1 = ½ (c_k X_k + c_k⁻¹ X_k⁻¹) where c_k = ‖X_k⁻¹‖ / ‖X_k‖). In practice the iteration is stopped when ‖X_k² − I‖ is below a tolerance.

Examination problems may ask to prove that sign(A)² = I, to derive the Newton iteration from the scalar sign function, or to show how the projector P₊ isolates the eigenvalues with positive real part. A common mistake is to apply the iteration to a matrix with eigenvalues on the imaginary axis; the iteration then fails to converge or converges to a non‑idempotent matrix. Another trap is to confuse the matrix sign function with the element‑wise sign function, which has none of the spectral properties described above.

Structured Perturbation Theory for Eigenvalues

Classical perturbation bounds such as Bauer–Fike or Weyl’s inequalities treat perturbations as unstructured, i.e., any matrix E with ‖E‖ ≤ ε is allowed. In many applications the perturbation has a prescribed structure: sparsity pattern, symmetry, Toeplitz, Hamiltonian, or a low‑rank update. Structured perturbation theory provides tighter bounds by restricting the admissible perturbations to the same manifold. For a simple eigenvalue λ of a diagonalizable matrix A = X Λ X⁻¹, the structured condition number is κ_struct(λ) = min{ ‖E‖ : E ∈ S, λ ∈ σ(A+E) }⁻¹, where S is the set of structured perturbations. When S is the set of all matrices, κ_struct reduces to the usual condition number ‖x‖ ‖y‖ / |yᵀ x| with right and left eigenvectors x, y. For symmetric matrices with symmetric perturbations, the condition number equals 1, reflecting the perfect conditioning of eigenvalues under symmetric perturbations.

For Hamiltonian or symplectic matrices arising in control theory, the structured condition number can be orders of magnitude smaller than the unstructured one, explaining why eigenvalues of such pencils are often computed accurately despite large unstructured condition numbers. The structured singular value μ provides a framework for robust stability analysis with structured uncertainties. Computing κ_struct exactly is NP‑hard in general, but for common structures (sparsity, symmetry, low rank) efficient algorithms exist based on the solution of a structured eigenvalue problem for the Fréchet derivative of the eigenvalue map. In examinations you may be asked to derive the structured condition number for a symmetric tridiagonal matrix under symmetric tridiagonal perturbations, or to explain why the eigenvalues of a Hamiltonian matrix are perfectly conditioned with respect to Hamiltonian perturbations.

Tensor Eigenvalues and Higher‑Order Singular Value Decomposition

Tensors of order three or higher generalize matrices, and their spectral theory extends the notion of eigenvalues and singular values. For a real symmetric tensor 𝒯 ∈ ℝn×n×n, a Z‑eigenpair (λ, x) satisfies 𝒯 x² = λ x with xᵀ x = 1, where (𝒯 x²)_i = Σj,k 𝒯ijk x_j x_k. An H‑eigenpair replaces the Euclidean norm condition with x[m‑1] = λ x, where x[m‑1] denotes element‑wise power. The number of Z‑eigenvalues can be exponential in n, and computing them is NP‑hard in general. However, for orthogonal tensors (those that can be diagonalised by an orthogonal transformation) the Z‑eigenvalues coincide with the diagonal entries after an orthogonal change of basis, and the higher‑order singular value decomposition (HOSVD) provides a multilinear analogue of the matrix SVD.

The HOSVD of a tensor 𝒜 ∈ ℝn₁×n₂×…×n_d writes 𝒜 = 𝒮 ×₁ U(1) ×₂ U(2) … ×_d U(d), where 𝒮 is the core tensor (all‑orthogonal) and each U(k) is an orthogonal matrix obtained from the SVD of the mode‑k unfolding of 𝒜. The multilinear ranks (r₁,…,r_d) are the ranks of the unfoldings. Truncating the HOSVD by keeping only the leading singular vectors in each mode yields a low‑multilinear‑rank approximation that is quasi‑optimal in the Frobenius norm. This approximation underpins tensor‑train and hierarchical Tucker formats used in high‑dimensional data compression and the solution of parametric PDEs.

In competitive problems you may be asked to compute the mode‑1 unfolding of a 3×3×3 tensor, to perform one step of the higher‑order orthogonal iteration (HOOI) for rank‑(r₁,r₂,r₃) approximation, or to prove that the Z‑eigenvalues of a symmetric orthogonal tensor are exactly the diagonal entries of its diagonalised form. A frequent trap is to treat tensor eigenvalues as if they obey the same interlacing or Weyl inequalities as matrix eigenvalues; no such general inequalities exist for tensors of order ≥ 3.

  • Assuming the QZ algorithm works without first reducing the pencil to Hessenberg‑triangular form; the reduction is essential for O(n³) cost and numerical stability.
  • Confusing the Arnoldi and Lanczos recurrences; Lanczos applies only to Hermitian matrices and uses a three‑term recurrence, while Arnoldi requires full orthogonalisation.
  • Applying the matrix sign iteration to a matrix with eigenvalues on the imaginary axis; the iteration does not converge and the projectors are not defined.
  • Using unstructured perturbation bounds for structured problems such as Hamiltonian or symmetric pencils; structured condition numbers can be dramatically smaller.
  • Treating tensor Z‑eigenvalues as if they satisfy matrix‑type interlacing theorems; no general interlacing holds for order‑3 or higher tensors.
  • Neglecting the scaling factor in the Newton iteration for the matrix sign function; without scaling the iteration can overflow or stagnate for ill‑conditioned matrices.
  • Believing that the HOSVD truncation yields the best low‑rank approximation in the Frobenius norm; it is only quasi‑optimal, and the HOOI algorithm is needed for a locally optimal solution.

Matrix Polynomials and Linearization Techniques

Matrix polynomials arise naturally in vibration analysis, control theory, and structural dynamics. A matrix polynomial of degree m is P(λ) = Amλm + Am−1λm−1 + … + A1λ + A0 where each Ai ∈ ℂn×n. The eigenvalue problem P(λ)x = 0 with x ≠ 0 defines the spectrum σ(P). Unlike the standard eigenvalue problem, matrix polynomials can have infinite eigenvalues when Am is singular, and the number of eigenvalues (counting algebraic multiplicities) is mn if Am is nonsingular. Linearization converts the polynomial problem into a generalized eigenvalue problem of size mn × mn that preserves the finite spectrum. The first companion form (Frobenius companion) constructs a block matrix C1 = [−Am−1Am−1, …, −Am−1A0; I, 0, …, 0; …; 0, …, I, 0] requiring Am invertible. The second companion form C2 = [−A1A0−1, −A2A0−1, …, −AmA0−1; I, 0, …, 0; …; 0, …, I, 0] requires A0 invertible. For singular leading or trailing coefficients, the linearization must be a pencil L(λ) = λX + Y where X, Y ∈ ℂmn×mn and det(L(λ)) = α det(P(λ)) for some nonzero constant α. The vector space of linearizations L(λ) = λ[X1; X2] + [Y1; Y2] with X2 = [I, 0, …, 0]T and Y2 = [0, I, …, 0]T is the space of block Kronecker pencils. The DL(P) (double ansatz) space provides strong linearizations that preserve both finite and infinite eigenstructure. For quadratic eigenvalue problems Q(λ) = λ2M + λC + K with symmetric M, C, K (mass, damping, stiffness), the symmetric linearization L(λ) = λ[M, 0; 0, −K] + [C, K; K, 0] preserves symmetry and is widely used in structural mechanics. The quadratic eigenvalue problem can also be solved directly by the quadratic Arnoldi method or by exploiting the palindromic structure when M = KT. In examinations, you may be asked to construct the first companion form for a cubic matrix polynomial, to verify that a given pencil is a strong linearization, or to explain why the symmetric linearization of a quadratic pencil preserves the definiteness properties of the original problem.

Randomized Numerical Linear Algebra

Randomized algorithms have transformed large-scale matrix computations by replacing deterministic orthogonalization with random sampling and sketching. The core idea: given A ∈ ℝm×n with m ≫ n or n ≫ m, multiply by a random matrix Ω ∈ ℝn×k (k ≈ rank(A) + p oversampling) to form Y = AΩ. The column space of Y approximates the column space of A with high probability. A QR factorization Y = QR yields an orthonormal basis Q ∈ ℝm×k. The approximation A ≈ QQTA has expected Frobenius error bounded by (1 + k/(p−1))1/2 times the optimal rank-k error. For the randomized SVD, compute B = QTA (size k × n), then the deterministic SVD B = ŨΣVT, giving A ≈ (QŨ)ΣVT. Power iterations Y = (AAT)qAΩ accelerate decay of singular values and improve accuracy for matrices with slow spectral decay. The cost is O(mnk + (m+n)k2) versus O(mn min(m,n)) for full SVD. For least squares minx ‖Ax − b‖2, the sketch-and-solve approach forms S = SA, d = Sb with S ∈ ℝr×m a subspace embedding (e.g., CountSketch, SRHT, or Gaussian), then solves min ‖Sx − d‖2. The solution satisfies ‖Ax̃ − b‖2 ≤ (1+ε) min ‖Ax − b‖2 with r = O(n/ε2). Iterative refinement using the sketch as a preconditioner achieves high precision. Leverage scores ℓi = ‖Ui‖22 (rows of left singular vectors) identify important rows for sampling; uniform sampling fails for coherent matrices. The Nyström method approximates a positive semidefinite kernel matrix K by sampling columns: K ≈ CW†CT where C contains sampled columns and W their intersection. In examinations, you may be asked to derive the expected error bound for randomized range finding, to explain why power iterations improve the approximation for matrices with clustered singular values, or to compare the computational complexity of randomized SVD versus deterministic SVD for a 106 × 106 sparse matrix with rank 50.

Worked Example: Randomized Range Finder Error Analysis
Let A ∈ ℝm×n have singular values σ1 ≥ σ2 ≥ … ≥ σr > 0. Let Ω ∈ ℝn×k be a standard Gaussian matrix, Y = AΩ, and Q = orth(Y). Show that the expected approximation error satisfies E[‖A − QQTA‖F] ≤ (1 + k/(p−1))1/2 (∑j>k σj2)1/2 where p = k − rankk(A) is the oversampling parameter.
The randomized range finder projects A onto the column space of Y = AΩ. Let A = UΣVT be the full SVD with U = [U1 U2], Σ = diag(Σ1, Σ2), V = [V1 V2] where Σ1 contains the top k singular values. Then Y = UΣVTΩ = U[Σ1V1TΩ; Σ2V2TΩ]. The key is that VTΩ has the same distribution as Ω because V is orthogonal and Ω is rotationally invariant. Write Ω1 = V1TΩ ∈ ℝk×k, Ω2 = V2TΩ ∈ ℝ(n−k)×k. The error ‖A − QQTA‖F = ‖(I − QQT)U2Σ2V2T‖F = ‖Σ2Ω2T(Ω1Ω1T + Ω2Ω2T)−1/2‖F. Using the expectation of the inverse Wishart matrix and the fact that Ω1 and Ω2 are independent Gaussian matrices, the expected squared error is E[‖Σ2Ω2T(Ω1Ω1T)−1/2‖F2] = ∑j>k σj2 E[tr(Ω2TΩ2(Ω1Ω1T)−1)] = ∑j>k σj2 · k/(p−1) for p > 1. Adding the optimal error ∑j>k σj2 gives the bound. The oversampling parameter p = k − rankk(A) is typically chosen as 5–10 for reliable performance.
Exam Strategy for Randomized Linear Algebra
Questions on randomized algorithms often test understanding of the probability bounds rather than implementation details. Memorize the key error bound: E[‖A − QQTA‖] ≤ (1 + k/(p−1))1/2 σk+1 for spectral norm and the Frobenius version. Know when to use Gaussian vs. SRHT vs. CountSketch embeddings: Gaussian for dense matrices, SRHT for structured matrices (FFT-friendly), CountSketch for sparse matrices. Be ready to explain why power iterations (q ≥ 1) help when singular values decay slowly — they effectively raise the singular value ratio to the (2q+1) power. A common trap is confusing the sketch size r for least squares (r = O(n/ε2)) with the target rank k for low-rank approximation (k ≈ rank + 5).

Optimization on Matrix Manifolds

Many engineering problems constrain optimization variables to matrix manifolds: the Stiefel manifold St(p, n) = {X ∈ ℝn×p : XTX = Ip} for orthonormal columns, the Grassmann manifold Gr(p, n) = St(p, n)/O(p) for p-dimensional subspaces, the fixed-rank manifold ℳr = {X ∈ ℝm×n : rank(X) = r}, the symmetric positive definite cone 𝒮++n, and the orthogonal group O(n) = {Q : QTQ = I}. Riemannian optimization replaces Euclidean gradients with Riemannian gradients and uses retractions instead of line searches. For a cost function f : ℳ → ℝ on an embedded submanifold ℳ ⊂ ℝn, the Riemannian gradient grad f(x) is the orthogonal projection of the Euclidean gradient ∇f(x) onto the tangent space Txℳ. On St(p, n), TXSt = {Z ∈ ℝn×p : XTZ + ZTX = 0} and grad f(X) = ∇f(X) − X∇f(X)TX. A retraction Rx(ξ) maps ξ ∈ Txℳ to ℳ with Rx(0) = x and DRx(0) = id. On St(p, n), the QR retraction RX(ξ) = qf(X + ξ) (Q-factor of QR) and the polar retraction RX(ξ) = (X + ξ)(I + ξTξ)−1/2 are common. The Riemannian trust-region method builds a quadratic model m(ξ) = f(x) + ⟨grad f(x), ξ⟩ + ½⟨ξ, Hess f(x)[ξ]⟩ on the tangent space and solves a trust-region subproblem. For the fixed-rank manifold ℳr, the tangent space at X = UΣVT (compact SVD) is TXℳr = {UMT + NVT : M ∈ ℝn×r, N ∈ ℝm×r, UTN = 0, VTM = 0}. The Riemannian gradient of f(X) = ½‖X − A‖F2 is grad f(X) = PTX(X − A) where PTX is the orthogonal projector. Applications include low-rank matrix completion (minimize ‖PΩ(X − M)‖F over ℳr), independent component analysis (maximize non-Gaussianity over O(n)), and Procrustes problems (minimize ‖AX − B‖F over St(p, n)). In examinations, you may be asked to derive the Riemannian gradient on the Stiefel manifold, to write the QR retraction for O(n), or to explain why the Grassmann manifold is the quotient St(p, n)/O(p) and how horizontal lifts enable optimization on Gr(p, n).

Tensor Decompositions: CP, Tucker, and Tensor Train Formats

Beyond the higher-order SVD (HOSVD), three principal tensor decomposition formats address the curse of dimensionality. The CANDECOMP/PARAFAC (CP) decomposition expresses a tensor 𝒜 ∈ ℝn1×…×nd as a sum of R rank-1 tensors: 𝒜 = ∑r=1R λr ar(1) ∘ ar(2) ∘ … ∘ ar(d) where ∘ denotes the outer product and ar(k) ∈ ℝnk. The minimal R is the tensor rank. Unlike matrices, tensor rank can exceed min(nk), rank determination is NP-hard, and the best rank-R approximation may not exist (the set of rank-≤R tensors is not closed). The CP decomposition is essentially unique under mild conditions (Kruskal's condition: ∑k krank(A(k)) ≥ 2R + d − 1). The Tucker decomposition writes 𝒜 = 𝒢 ×1 U(1) ×2 U(2) … ×d U(d) where 𝒢 ∈ ℝr1×…×rd is the core tensor and U(k) ∈ ℝnk×rk are factor matrices. The multilinear rank is (r1, …, rd). HOSVD computes the Tucker decomposition by taking SVDs of mode-k unfoldings; it is not optimal but provides a good initialization for Higher-Order Orthogonal Iteration (HOOI), which alternates least-squares updates of factor matrices to minimize ‖𝒜 − 𝒢 ×1 U(1) … ×d U(d)‖F. The Tensor Train (TT) format (also Matrix Product States) represents a d-way tensor as 𝒜(i1, …, id) = G1(i1) G2(i2) … Gd(id) where Gk(ik) ∈ ℝrk−1×rk are core matrices with r0 = rd = 1. The TT-ranks (r1, …, rd−1) control the storage: O(d n r2) versus O(nd) for full tensor. The TT-SVD algorithm computes a quasi-optimal TT approximation by sequential SVDs of unfolding matrices. The Hierarchical Tucker (HT) format uses a dimension tree to achieve O(d n r + d r3) storage. For a 3-way tensor, CP with R = 10, Tucker with (r1,r2,r3) = (10,10,10), and TT with (r1,r2) = (10,10) all have similar parameter counts but different expressive power. In examinations, you may be asked to compute the mode-2 unfolding of a 3×4×5 tensor, to write the ALS update for CP factor matrices, to explain why the best rank-R CP approximation may not exist, or to derive the storage complexity of the TT format for a tensor of size nd with uniform TT-rank r.

Matrix Concentration Inequalities and Non-Asymptotic Random Matrix Theory

Classical random matrix theory (Wigner semicircle, Marchenko-Pastur) describes asymptotic spectral distributions as dimensions grow. Non-asymptotic theory provides finite-n bounds on deviations of random matrices from their expectations. The matrix Chernoff bound: let X1, …, Xm be independent random PSD matrices in ℝd×d with 0 ⪯ Xi ⪯ RI and ∑ 𝔼[Xi] = μI. Then ℙ(λmax(∑ Xi) ≥ (1+δ)μ) ≤ d [eδ/(1+δ)1+δ]μ/R for δ > 0. The matrix Bernstein inequality: for independent zero-mean symmetric matrices with ‖Xi‖ ≤ R and variance σ2 = ‖∑ 𝔼[Xi2]‖, ℙ(‖∑ Xi‖ ≥ t) ≤ 2d exp(−t2/(2σ2 + 2Rt/3)). These bounds control the spectral norm of sums of random matrices. For a random matrix A with independent sub-Gaussian rows, the covariance estimation error satisfies ‖ATA/n − Σ‖ ≤ C (‖Σ‖1/2√(d/n) + ‖Σ‖d/n) with high probability. The restricted isometry property (RIP) for random matrices: if A ∈ ℝm×n has i.i.d. sub-Gaussian entries, then with m ≥ C s log(n/s), A satisfies the RIP of order s with constant δs < 1/√2, enabling sparse recovery via ℓ1 minimization. The matrix deviation inequality for sampling without replacement: if X1, …, Xm are sampled without replacement from a finite set of matrices, the same Chernoff/Bernstein bounds hold with a factor of 2 in the exponent. The operator norm of a Gaussian random matrix G ∈ ℝm×n satisfies 𝔼‖G‖ ≤ √m + √n and ℙ(‖G‖ ≥ √m + √n + t) ≤ 2e−t2/2. For a Wishart matrix W = XXT with X ∈ ℝd×n Gaussian, the smallest singular value satisfies ℙ(σmin(X) ≤ √n − √d − t) ≤ e−t2/2. These non-asymptotic bounds are essential for analyzing randomized algorithms, compressed sensing, and high-dimensional statistics. In examinations, you may be asked to state the matrix Bernstein inequality and apply it to bound the error of a sample covariance matrix, to derive the sample complexity for RIP of a Gaussian matrix, or to explain why the dimension factor d appears in matrix concentration bounds but not in scalar Chernoff bounds.

  • Confusing the CP rank with multilinear rank; CP rank is the minimum number of rank-1 terms, multilinear rank is the tuple of mode-k ranks.
  • Assuming the best low-rank CP approximation always exists; the set of tensors with rank ≤ R is not closed for R ≥ 2, so infimum may not be attained.
  • Using the matrix Chernoff bound without the PSD assumption; the bound requires 0 ⪯ Xi ⪯ RI.
  • Forgetting the dimension factor d in matrix concentration inequalities; scalar bounds do not have this factor, but matrix bounds scale with dimension.
  • Treating the QR retraction on the Stiefel manifold as the exponential map; it is a first-order retraction, not the geodesic.
  • Confusing the tensor train format with the Tucker format; TT uses a chain of core matrices, Tucker uses a single core tensor with factor matrices.
  • Applying the standard SVD to a matrix polynomial eigenvalue problem without linearization; the polynomial structure must be preserved or properly linearized.
