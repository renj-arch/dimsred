Key Concepts

What is Logical Reasoning?

Logical Reasoning in GATE General Aptitude tests your ability to identify patterns, analyse relationships, and draw valid conclusions. Topics include analogies, syllogisms, puzzles, blood relations, direction sense, and number/letter series. GATE typically has 2-3 logical reasoning questions in the aptitude section.

Key Concepts

1. Analogies: Relationships include synonym/antonym, cause-effect, part-whole, worker-tool, product-material, animal-young one, degree of intensity. For letter analogies, use positional values (A=1 to Z=26). Number analogies use arithmetic operations.

2. Syllogisms: Statement types: All A are B (circle A inside B), No A is B (separate circles), Some A are B (overlapping circles), Some A are not B (partial overlap). A conclusion follows only if true in ALL possible Venn diagrams.

3. Blood Relations: Build a family tree step by step. Key: 'son of' or 'daughter of' indicates parent-child relationship. 'Brother/sister of' indicates sibling relationship. 'Husband/wife of' indicates marital relationship.

4. Direction Sense: Track movement step by step using a grid. Draw arrows for each movement. Right turn = +90° (clockwise from current direction). Left turn = -90° (anticlockwise). Use Pythagoras for net displacement.

5. Number & Letter Series: Number series: check differences, ratios, squares/cubes, alternating patterns, Fibonacci. Letter series: check positional value differences — often involves consistent addition/subtraction or a pattern of operations.

Solved Examples

Example 1 (Analogy)
Find the missing term: Engineer : Blueprint :: Architect : ?

a) Building b) Design c) Construction d) Site
Solution: b) Design. An engineer creates a blueprint. Similarly, an architect creates a design. This is a worker-product relationship.
Example 2 (Blood Relation)
Pointing to a man, Priya said, 'He is the son of the only daughter of my father.' How is the man related to Priya?

a) Brother b) Son c) Cousin d) Nephew
Solution: b) Son. Priya's father has only one daughter — that must be Priya herself (since Priya is a female name). The man is the son of that only daughter (Priya). Therefore, the man is Priya's son.
Example 3 (Number Series)
Find the next term: 3, 8, 15, 24, 35, ?

a) 42 b) 44 c) 48 d) 49
Solution: c) 48. Pattern: 1×3=3, 2×4=8, 3×5=15, 4×6=24, 5×7=35, 6×8=48. Alternatively, differences: 5,7,9,11,13 — increasing by 2 each time. Next difference = 13, so next term = 35+13 = 48.

Shortcut Techniques

  • For syllogisms in GATE, the Venn diagram method is most reliable. Draw all possible configurations before checking conclusions.
  • In blood relations, carefully track gender-specific terms (only 'mother' and 'sister' indicate female; 'father', 'brother', 'son' indicate male).
  • For series questions, examine differences first — if differences are constant or follow a pattern, you've found it. If not, check ratios or alternate terms.
  • In direction problems, draw a diagram for each movement — mental tracking often leads to errors in multi-step problems.
  • For analogy questions, identify the exact relationship in the first pair before checking options — multiple options may have partial similarity.
Pro Tip
GATE logical reasoning questions are straightforward and test basic aptitude. Do not overthink — if the answer seems too complex, you are likely on the wrong track. Practice 3-5 questions daily to maintain speed. These questions are easy to score if you identify the pattern quickly.
