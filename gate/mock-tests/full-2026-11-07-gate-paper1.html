Q1General Aptitude
If 15 workers can build a wall in 8 days, how many workers are needed to build same wall in 6 days?
Answer: C

MD = MD -> 15x8 = Mx6 -> M = 20.

Q2General Aptitude
If x + y = 10 and xy = 21, then x² + y² is:
Answer: C

x²+y² = (x+y)² - 2xy = 100 - 42 = 58.

Q3General Aptitude
If a train running at 72 km/h crosses a pole in 10 s, the length of train is:
Answer: C

Speed = 72×(5/18) = 20 m/s. Length = 20×10 = 200 m.

Q4General Aptitude
If the radius of a circle is doubled, the area becomes:
Answer: B

A ∝ r². If r → 2r, A → 4A.

Q5General Aptitude
Simplify: 25 + 5 x 2 - 10
Answer: C

Using BODMAS: 5x2=10, 25+10-10=25.

Q6General Aptitude

Answer: C

Speed = 72x(5/18) = 20 m/s. Length = 20x10 = 200 m.

Q7General Aptitude
What is the value of x in the equation 2^x + 2^x = 10?
Answer: B

Given equation is 2^x + 2^x = 10, which can be simplified as 2 * 2^x = 10, then 2^x = 5. Since 2^2 = 4 and 2^3 = 8, the value of x that satisfies the equation is between 2 and 3, but closest to the given options is 2.

Q8General Aptitude
If 5 men can build a wall in 12 days, how many days will 10 men take?
Answer: C

MD = MD -> 5x12 = 10xD -> D = 6 days.

Q9General Aptitude
The ratio of 3 km to 300 m is:
Answer: C

3 km = 3000 m. 3000:300 = 10:1.
