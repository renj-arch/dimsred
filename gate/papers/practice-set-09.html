Q1.
What does the following C expression evaluate to? (Assume i = 5) i++ + ++i
A. 10
B. 11
C. 12
D. Undefined
Correct Answer: C
i++ uses current value (5) then increments to 6. ++i increments to 7 then uses 7. So 5 + 7 = 12.
Q2. General Aptitude
The sum of ages of A and B is 45 years. 5 years from now, the ratio of their ages will be 4:5. Find the current age of A.
A. 15 years
B. 20 years
C. 25 years
D. 30 years
Correct Answer: A
Let A's age = x, B's age = 45-x. After 5 years: (x+5)/(50-x) = 4/5. 5x+25 = 200-4x. 9x = 175. x = 15.
Q3.
Which of the following is a volatile memory?
A. ROM
B. Hard disk
C. RAM
D. Flash drive
Correct Answer: C
RAM (Random Access Memory) is volatile - data is lost when power is turned off.
Q4. General Aptitude
If 3x + 2 = 11, then x = ?
A. 1
B. 3

3x = 9 -> x = 3.
Q5.
Slab spanning in one direction only is called:
A. Two-way slab
B. One-way slab
C. Flat slab
D. Ribbed slab
Correct Answer: B
One-way slab: L/B 2, main reinforcement in shorter span direction.

Q7.
The worst-case time complexity of quicksort is:
A. O(log n)
B. O(n log n)
C. O(n^2)
D. O(n)
Correct Answer: C
Quicksort worst-case O(n^2) when pivot is smallest/largest element (e.g., sorted array with naive pivot).
Q8.
Which of the following problems is undecidable?
A. Checking if a DFA accepts a given string
B. Checking if a CFL is empty
C. The Halting Problem for Turing Machines
D. Checking if an NFA accepts a given string
Correct Answer: C
The Halting Problem is undecidable (proved by Alan Turing). All other options are decidable.
Q9.
The gain of a non-inverting amplifier with Rf=10 k and R1=1 k is:
A. 10
B. 11
C. 9
D. 1
Correct Answer: B
Gain = 1 + Rf/R1 = 1 + 10 = 11.
Q10.
The COP of a refrigerator is 4. If it extracts 200 J from cold reservoir, work input is:
A. 20 J
B. 40 J
C. 50 J
D. 200 J
Correct Answer: C
COP = Q/W -> 4 = 200/W -> W = 50 J.
Q11.
Binary equivalent of decimal 15 is:
A. 1010
B. 1100
C. 1111
D. 1001
Correct Answer: C
15 = 8+4+2+1 = 1111.
Q12.
The cutting speed in a lathe is measured in:
A. RPM
B. m/min
C. mm/rev
D. mm
Correct Answer: B
Cutting speed = piDN/1000 m/min (D in mm, N in RPM).
Q13.
The bandwidth of an ideal bandpass filter is:
A. Zero
B. Equal to center frequency
C. Difference of cut-off frequencies
D. Infinite
Correct Answer: C
BW = fH - fL where fH and fL are upper and lower cut-off frequencies.
Q14.
Which process is used to make threads on a bolt?
A. Milling
B. Drilling
C. Threading
D. Grinding
Correct Answer: C
Threading (using dies) cuts external threads on bolts and rods.
Q15. General Aptitude
A man buys a book for 500 and sells it for 600. Profit percentage is:
A. 10%
B. 20%
C. 15%
D. 25%
Correct Answer: B
Profit = 100, CP = 500. Profit% = 100/500 x 100 = 20%.
