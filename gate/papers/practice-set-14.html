A. 0

Correct Answer: B

A. 0.70
B. 0.80
C. 0.85
D. 0.90
Correct Answer: B
Shortcut: η = (h1 – h2)/(h1 – h2s) = (3400–2600)/(3400–2400) = 800/1000 = 0.80. Full: Isentropic efficiency is actual work output divided by isentropic work output. Actual work = h1 – h2 = 800 kJ/kg; isentropic work = h1 – h2s = 1000 kJ/kg. Ratio = 0.80.

A. 40
B. 50
C. 60
D. 55
Correct Answer: B
Shortcut: For a counterflow heat exchanger, if the temperature difference at the two ends (ΔT₁ and ΔT₂) are equal, LMTD equals that common value. Here ΔT₁ = 120−70 = 50°C and ΔT₂ = 80−30 = 50°C, so LMTD = 50°C directly. Full: LMTD = (ΔT₁−ΔT₂)/ln(ΔT₁/ΔT₂). Since ΔT₁=ΔT₂=50, the formula reduces to 0/0; applying the limit gives LMTD = 50°C.

A. 75

D. 125
Correct Answer: C

Q12. Core Subjectmodel-generated · 2026-11-16
A Carnot heat pump operates between a high temperature reservoir at 300 K and a low temperature reservoir at 250 K. The Coefficient of Performance (COP) of the heat pump is:
A. 6
B. 5
C. 5.5
D. 6.5
Correct Answer: A
Shortcut: COP of Carnot Heat Pump = T_H/(T_H−T_L) (absolute temperatures). COP = 300/(300−250) = 300/50 = 6. Full: For a reversible cycle, Q_H/T_H = Q_L/T_L. Work input W = Q_H−Q_L. COP_HP = Q_H/W = Q_H/(Q_H−Q_L) = 1/(1−T_L/T_H) = T_H/(T_H−T_L) = 300/50 = 6.

A. 15
B. 20
C. 25
D. 30
Correct Answer: B
Shortcut: Total length = 300 m. Opposite direction relative speed = 300/10 = 30 m/s (sum of speeds). Same direction relative speed = 300/30 = 10 m/s (difference of speeds). Faster train speed = (Sum + Difference)/2 = (30 + 10)/2 = 20 m/s. Full Solution: Let speeds be x and y (x > y). x + y = 30 and x - y = 10. Adding equations: 2x = 40 => x = 20 m/s.

The power P required to drive a fan depends on density ρ, dynamic viscosity μ, angular speed ω, diameter D, and discharge Q. Using Buckingham π theorem, the number of independent dimensionless groups required to describe this phenomenon is:
A. 2
B. 4
C. 3
D. 5
Correct Answer: C
Shortcut: Buckingham π Theorem states number of π terms = n - m, where n = number of variables, m = number of fundamental dimensions (M, L, T). Variables: P, ρ, μ, ω, D, Q (n=6). Dimensions: M, L, T (m=3). π terms = 6 - 3 = 3. Full Solution: List the variables and their dimensions: Power P [ML^2T^{-3}], Density ρ [ML^{-3}], Viscosity μ [ML^{-1}T^{-1}], Angular speed ω [T^{-1}], Diameter D [L], Discharge Q [L^3T^{-1}]. Total variables n = 6. Fundamental dimensions involved are Mass (M), Length (L), Time (T), so m = 3. According to Buckingham π theorem, the number of independent dimensionless groups is n - m = 6 - 3 = 3.
