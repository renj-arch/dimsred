Q15. General Aptitude
A bat and a ball together cost $1.10. The bat costs $1.00 more than the ball. How much does the ball cost?
A. $0.05
B. $0.10
C. $0.15
D. $0.20
Correct Answer: A
Let's say the cost of the ball is x. Since the bat costs $1.00 more than the ball, the cost of the bat is x + $1.00. The total cost is $1.10, so we can set up the equation: x + (x + $1.00) = $1.10. Simplifying the equation, we get 2x + $1.00 = $1.10. Subtracting $1.00 from both sides, we get 2x = $0.10. Dividing both sides by 2, we get x = $0.05.
