Fix fix-apostrophes.js: robust apostrophe vs string-terminator detection

Bug: uppercase letters after possessive apostrophe (e.g. 's Gorge)
were treated as part of the word, causing the closing quote to be
consumed as an apostrophe — leaving the string unterminated.

Fix: use the IMMEDIATE next character (no whitespace skipping) to
check for lowercase letter = apostrophe. Also add a snippet-based
end-of-string check (looks ahead for , } ] ) as fallback.
This correctly handles: Bengal's, 1990's, Alappuzha's while still
treating true terminators (followed by comma/brace/bracket) correctly.
