Reasoning Techniques for Competitive Exams

9 min read � Updated June 2026

Logical Reasoning is a unique section in competitive exams because it requires minimal prior knowledge. Unlike Quant or English, you do not need to memorize formulas or vocabulary. What you need is pattern recognition, systematic thinking, and practice with diverse question types. This guide covers the most effective techniques for solving Reasoning questions across SSC CGL, Banking, Railway, and other competitive exams.

1. Understanding the Reasoning Landscape

Reasoning questions in competitive exams fall into three broad categories:

  • Verbal Reasoning: Analogy, classification, coding-decoding, blood relations, direction sense, order and ranking, and syllogisms. These rely on your ability to identify logical relationships between words or concepts.
  • Non-Verbal Reasoning: Figure series, mirror images, embedded figures, paper cutting and folding, and figure completion. These test spatial intelligence and pattern recognition.
  • Analytical Reasoning: Puzzles (seating arrangement, floor-based, scheduling), data sufficiency, input-output, and critical reasoning. These require systematic deduction and a structured approach.

2. Syllogisms: The Venn Diagram Method

Syllogisms test your ability to draw logical conclusions from given statements. The Venn diagram method is the most reliable approach:

  1. Draw overlapping circles representing each category mentioned in the statements.
  2. Shade areas that are confirmed empty by "no" statements.
  3. Mark areas that are confirmed occupied by "some" statements.
  4. Check each conclusion against the diagram. If it is true in all possible diagrams, it follows. If it is false in any possible diagram, it does not follow.
Example:
Statements: All A are B. Some B are C. No C is D.
Conclusion: Some A are not D.
Solution: Draw the Venn diagram. A is inside B. B overlaps with C. C and D do not overlap. Since A and D have no guaranteed relationship (A could be entirely in the B region that does not overlap with C, or it could overlap), "Some A are not D" may or may not be true. Therefore, it does not follow.

3. Coding-Decoding: Pattern Recognition

Coding-decoding questions follow predictable patterns. Check for these in order:

  • Letter shifting: Each letter is shifted by a fixed number of positions (forward or backward). Example: A→D, B→E, C→F (shift +3).
  • Reverse order: The word is reversed, then letters are coded. Or the alphabet positions are reversed (A=26, B=25, etc.).
  • Vowel/consonant substitution: Vowels are replaced by a rule (A→E, E→I) while consonants are replaced differently.
  • Position-based: The code is based on the sum or difference of alphabet positions. A=1, B=2, etc.
  • Mixed operations: A combination of shifting and arithmetic operations on position values.

Start by writing the alphabet with numbered positions (A=1 to Z=26). This visual reference helps identify position-based patterns quickly.

4. Seating Arrangement Puzzles

Seating arrangement puzzles appear in almost every Banking and SSC Tier 2 exam. They are time-consuming but highly scoring. Follow this systematic approach:

  1. Draw a rough diagram: For circular arrangements, draw a circle with marks for each position. For linear arrangements, draw horizontal lines. For rectangular tables, draw the table shape.
  2. Mark definite positions first: Enter facts that give exact positions. Example: "A sits at the extreme left" → place A at position 1.
  3. Use relative positions: "B sits third to the right of A" → count three positions from A and place B.
  4. Handle negative information: "C does not sit adjacent to D" → keep C away from D's neighbors.
  5. Reconcile remaining positions: Use the remaining clues to fill in the last few positions. If you end up with two possible arrangements, note both and check which one is consistent with all clues.
Speed Tip: Do not read all clues at once. Draw the diagram first, then process clues one by one. After each clue, update the diagram. If a clue leads to a contradiction, you have made an assumption � mark it with a pencil (or mental note) and try the alternative.

5. Blood Relations: Family Tree Method

Blood relation questions are about tracing relationships through a family tree. Use these conventions:

  • Draw vertical lines for parent-child relationships.
  • Draw horizontal lines for spouse relationships.
  • Use + for male, − for female (or M/F labels).
  • Place the oldest generation at the top and work downward.

Start with the relationship that has the most connections. If "A is the father of B" and "B is the sister of C," place A, B, and C on the tree before adding other relationships. The tree grows naturally as you add more clues.

6. Direction Sense

Direction sense questions test your ability to track movement on a compass. Follow these steps:

  1. Start at a point marked "Start" at the center of a cross (N-S-E-W).
  2. Trace each movement step by step. Use arrow notation: ↑ for North, → for East, ↓ for South, ← for West.
  3. After all movements, calculate the net displacement using Pythagoras theorem if needed: distance = √(east-west distance� + north-south distance�).
  4. For the direction from start to end, use the angle: tan⁻�(east-west / north-south) and convert to the correct bearing.
Common Trap: "A walks 5 km North, turns right, walks 10 km, turns right, walks 5 km." The right turn from North is East, the next right turn from East is South. Always track both the direction and the distance accurately. Drawing a quick diagram eliminates most errors.

7. Input-Output: Pattern Detection

Input-output questions present a sequence of steps that transform an input into an output. The pattern can involve:

  • Sorting: Numbers sorted in ascending/descending order, one element per step.
  • Shifting: Elements move to new positions based on a rule (largest shifts first, or by position).
  • Arithmetic operations: Each step applies an operation (add, multiply) to selected elements.
  • Alternating patterns: Odd steps follow one rule, even steps follow another.

To solve input-output questions, examine the first step carefully to identify what changed. Then verify the same rule in the second step. Once the rule is confirmed, apply it to the given input to find the required step.

8. Data Sufficiency

Data sufficiency questions ask whether the given statements are sufficient to answer a question. Follow this decision flowchart:

  1. Check Statement 1 alone. Can you answer the question uniquely? If yes, it is sufficient. If you get multiple answers, it is insufficient.
  2. Check Statement 2 alone using the same logic.
  3. If neither is sufficient alone, check both together. If the combination gives a unique answer, it is sufficient.
Key Insight: Do not actually solve the question fully. You only need to determine whether the data is sufficient, not what the answer is. This distinction saves valuable time.
