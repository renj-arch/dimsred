Key Concepts

What is Syllogism?

Syllogism is a logical reasoning topic where you are given two or more statements (premises) and you must determine which conclusions follow logically from them. Each statement involves relationships between categories using words like 'All', 'No', 'Some', and 'Some Not'. SSC CGL typically asks 2-3 syllogism questions in Tier 1.

Types of Statements

1. Universal Affirmative (All A are B): Every member of category A belongs to category B. Venn diagram: circle A inside circle B.

2. Universal Negative (No A is B): No member of A belongs to B. Venn diagram: two non-overlapping circles.

3. Particular Affirmative (Some A are B): At least one member of A belongs to B. Venn diagram: overlapping circles.

4. Particular Negative (Some A are not B): At least one member of A does not belong to B. Venn diagram: part of A outside B.

The Venn Diagram Method

Draw overlapping circles for each category mentioned. For each statement, shade or mark regions that are definitely occupied or empty. A conclusion follows if it is true in ALL possible Venn diagrams that satisfy the given statements. If you can draw one valid diagram where the conclusion is false, the conclusion does not follow.

Solved Examples

Example 1 (Basic)
Statements:
1. All pens are books.
2. No book is a table.

Conclusions:
I. No pen is a table.
II. Some books are pens.

Which conclusion(s) follow(s)?
Solution: Both I and II follow. From the statements: All pens are inside the set of books. No book is a table, so pens (being inside books) cannot be tables either â†’ Conclusion I follows. Conclusion II (Some books are pens) is also true since all pens are books, which implies at least some books are pens.
Example 2 (Either-Or Case)
Statements:
1. Some apples are mangoes.
2. No mango is a banana.

Conclusions:
I. Some apples are not bananas.
II. Some bananas are not apples.

Which conclusion(s) follow(s)?
Solution: Only I follows. From statements: some apples are mangoes, and no mango is banana. So those apples which are mangoes cannot be bananas â†’ Conclusion I follows. However, we cannot say anything definitive about bananas that are not apples â€” there might be some or none. So II does not follow.
Example 3 (Complementary Pair)
Statements:
1. All cats are animals.
2. Some animals are not dogs.

Conclusions:
I. Some cats are dogs.
II. No cat is a dog.

Which conclusion(s) follow(s)?
Solution: Neither I nor II follows individually. But I and II form a complementary pair (Some vs No â€” one affirmative, one negative covering all possibilities). In such cases, 'Either I or II follows' would be the correct answer if both options are available. Here, since we are just checking individually, neither is definitely true.

Shortcut Techniques

  • Use the rules of syllogism: If all A are B and all B are C, then all A are C. If no A is B and all C are A, then no C is B.
  • For 'Some' statements: at least one element of the subject belongs to the predicate.
  • Remember: 'All A are B' does NOT mean 'All B are A' â€” reverse is not always true.
  • In SSC, the either-or case occurs when two conclusions are complementary â€” one positive, one negative, covering all possibilities.
Pro Tip
Always draw at least two possible Venn diagrams if you're unsure. A conclusion follows ONLY if it is true in ALL possible diagrams. If one diagram shows it false, the conclusion does not follow.

Advanced Problem Types

Competitive exams feature advanced variations combining multiple reasoning concepts. Master these to score high.

Multi-Step Problems

Some questions require applying multiple reasoning techniques sequentially. Break problems into clear steps.

Common Traps

  • Assuming a pattern continues without checking all elements
  • Misinterpreting negative statements in syllogisms
  • Forgetting wrapping in alphabet coding (Z to A transition)
  • Confusing directions (East vs West)
  • Overlooking either-or cases in syllogisms
  • Not considering all possible arrangements in puzzles
Pro Tip
For puzzles, start with the most concrete clue and build around it. Draw diagrams for seating arrangements and family trees for blood relations.
