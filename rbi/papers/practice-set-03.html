Q11. [+1, -0.25] Reasoning
In a certain code, 'FLOWER' is written as '649537' and 'WONDER' is written as '539278'. How is 'REFLOW' coded?
A. 729645
B. 785649
C. 789645
D. 789465
Correct Answer: C
By comparing the letters and their corresponding codes in 'FLOWER' and 'WONDER', we can deduce the code for each letter. R=7, E=8, F=6, L=4, O=9, W=5. Therefore, 'REFLOW' would be coded as 789645.
