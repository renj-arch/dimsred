In a certain puzzle, each letter stands for a distinct digit (0‑9) and the following addition is true: SEND + MORE ------ MONEY Which digit does the letter 'O' represent?
A. 0
B. 1
C. 2
D. 3
Correct Answer: A
Shortcut: The only way for a 5‑digit sum to start with a new digit (M) is when there is a carry from the thousands column, so M = 1. Hence O must be 0 because the only remaining digit that can make the tens‑thousands column carry is 0. Full solution: 1) Since SEND + MORE = MONEY has 5 digits, M = 1. 2) Adding the thousands column: S + M (1) gives a carry of 1, so S must be 9 and O must be 0 to satisfy the equation O + carry = 10. Therefore O = 0, which is option A.

A. Paternal Grandfather
B. Maternal Grandfather
C. Maternal Uncle
D. Father
Correct Answer: B
Shortcut (Generation Gap Method): Assign generation values: Father/Mother = +1; Brother/Sister = 0. Starting from K (+1 for '+') to L, then L to M (-1 for '-'), M to N (× = 0), N to O (÷ = 0). Full Solution: K + L → K is father of L. L - M → L is mother of M → K is maternal grandfather of M. M × N → M is brother of N → K is maternal grandfather of N. N ÷ O → N is sister of O → K is maternal grandfather of O.

Correct Answer: D

Cyclicity of 3 is 4 (3, 9, 7, 1). 98 mod 4 = 2 => Unit digit of 3^98 = 9. Sum = 9 + 9 = 18 => Unit digit 8. Full Method: 347^102 -> unit digit of 7^102. 7^1=7, 7^2=49(9), 7^3=343(3), 7^4=2401(1). Cycle 4. 102 = 4×25 + 2 => 2nd position = 9. 653^98 -> unit digit of 3^98. 3^1=3, 3^2=9, 3^3=27(7), 3^4=81(1). Cycle 4. 98 = 4×24 + 2 => 2nd position = 9. 9+9=18, unit digit 8.
