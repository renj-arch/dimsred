Coding Theory — Error-Correcting Codes

Coding theory designs efficient and error-resistant ways to transmit digital information. It spans linear codes (Hamming, Golay), algebraic codes (Reed-Solomon, BCH), cyclic codes, convolutional codes, turbo codes, LDPC (low-density parity-check), polar codes, and capacity-approaching codes. The subject sits at the intersection of information theory, algebra, and combinatorics — enabling everything from CDs and QR codes to deep-space communication.

"Coding theory is the art of adding redundancy to data so that errors can be detected and corrected — making noisy channels reliable."
— Claude Shannon / Richard Hamming
Part 1

🔤 Linear Codes — The Algebra of Error Correction

Repetition
Linear Codes, Generator Matrices, and Hamming Codes
A linear [n,k] code over GF(q) is a k-dimensional subspace of GF(q)ⁿ. The generator matrix G (k×n) maps messages to codewords: c = mG. The parity-check matrix H ((n−k)×n) satisfies Hcᵀ = 0 for codewords. The Hamming distance d(c₁,c₂) is the number of positions where they differ. The minimum distance d of a code determines its error-correction capability: t = ⌊(d−1)/2⌋ errors can be corrected. The Singleton bound: d ≤ n−k+1. Codes achieving this are MDS (maximum distance separable). The Hamming code [2^r−1, 2^r−r−1, 3] corrects 1 error per block. The binary [7,4,3] Hamming code has 16 codewords. The Golay code [23,12,7] corrects 3 errors — used by Voyager. The weight enumerator W(x,y) = Σ A_i x^{n−i} y^i counts codewords by weight. MacWilliams identity relates weight enumerators of a code and its dual.
Linear codes transform error correction into linear algebra — parity checks detect where errors occur, and the minimum distance tells you how many you can fix.
Part 2

🌀 Algebraic Codes — Reed-Solomon and BCH

Polynomials
Reed-Solomon Codes — Polynomial Evaluation and Berlekamp-Massey
Reed-Solomon (RS) codes evaluate polynomials over GF(q). For message (m₀,...,m_{k−1}), form polynomial p(X) = m₀ + m₁X + ... + m_{k−1}X^{k−1}, then codeword c = (p(α₁),...,p(α_n)) for distinct evaluation points α_i. RS codes are MDS: [n,k] with d = n−k+1. The Berlekamp-Massey algorithm efficiently decodes RS codes by finding the error locator polynomial from syndromes. BCH codes (Bose-Chaudhuri-Hocquenghem) are cyclic codes with designed minimum distance using roots in extension fields. A BCH code with designed distance δ has α, α², ..., α^{δ−1} as roots of the generator polynomial. The Peterson-Gorenstein-Zierler algorithm solves the key equation for BCH decoding. RS codes are a special case of BCH codes (n = q−1). RS codes are used in CDs, DVDs, QR codes, and satellite communication. The [255,223,33] RS code is used by NASA — it corrects 16 byte errors per block.
Reed-Solomon codes use polynomial evaluation over finite fields — the elegant algebra makes them both powerful and efficiently decodable.
Part 3

🔄 Convolutional Codes and Turbo Codes

Memory
Convolutional Codes, Viterbi Algorithm, and Turbo Codes
Convolutional codes process a sliding window of input bits through a finite state machine. The encoder has memory m; the constraint length K = m+1. The trellis diagram represents all possible state transitions. The Viterbi algorithm (1967) finds the most likely transmitted sequence by dynamic programming on the trellis — it's the maximum-likelihood decoder for convolutional codes. The free distance d_free determines performance. Convolutional codes are often combined with puncturing to adjust the rate. Turbo codes (Berrou, 1993) consist of two parallel convolutional encoders separated by an interleaver, decoded iteratively by exchanging extrinsic information — they approach the Shannon limit (< 1 dB away). The BCJR algorithm (Bahl-Cocke-Jelinek-Raviv) computes MAP symbol probabilities for turbo decoding. Turbo codes revolutionized coding — they're used in 3G/4G cellular, satellite, and deep-space communication.
Turbo codes achieved near-Shannon-limit performance by iteratively exchanging soft information between two decoders — a breakthrough that changed communications.
Part 4

⚡ LDPC Codes, Polar Codes, and Capacity-Achieving Codes

Sparse
LDPC, Polar Codes, and Modern Iterative Decoding
LDPC codes (Gallager, 1963; rediscovered 1990s) are linear codes with a sparse parity-check matrix H. The Tanner graph is a bipartite graph with variable nodes and check nodes. The iterative belief propagation (BP) decoder (sum-product algorithm) passes messages along edges: variable nodes send likelihood estimates to check nodes, check nodes enforce parity constraints. LDPC codes achieve capacity on the binary erasure channel and approach it on AWGN — they're used in 5G, Wi-Fi, DVB-S2, and 10GBASE-T. Irregular LDPC codes with optimized degree distributions perform even better. Polar codes (Arikan, 2009) are the first provably capacity-achieving codes for symmetric channels. They use channel polarization: by recursively combining and splitting channels, some become perfectly reliable and others completely noisy. Information is sent on the reliable bits (frozen bits are fixed). Successive cancellation decoding (SC) is the basic decoder; SC-list (SCL) decoding improves performance. Polar codes are used in 5G control channels. The noisy-channel coding theorem (Shannon) provides the fundamental limit: the capacity C = max I(X;Y) bits per channel use.
LDPC codes with iterative decoding approach Shannon's limit; polar codes provably achieve it — the sixty-year quest to reach capacity is essentially complete.
