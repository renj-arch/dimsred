Key Concepts

Idioms & Phrases

Idioms are fixed expressions whose meaning can't be deduced from individual words (kick the bucket = die). Exams test theme-grouped idioms with meaning, usage, and literal-trap options that sound plausible but are wrong.

  • Meaning vs literal: Never interpret literally. 'Break the ice' = initiate conversation, not smash ice. 'Once in a blue moon' = rarely, not a lunar event.
  • Usage: Idioms fit specific contexts — 'bite the bullet' = endure something unpleasant unavoidably; 'burn the midnight oil' = work/study late at night.
  • Learning method: Group by theme (success/failure, emotions, money, time, difficulty, health, relationships, weather, animals, colors) to remember clusters.
  • Exam trap: One option gives the literal meaning — always avoid it.

Note
The idiom bank above is a representative starter set (themes A–K). Build your own theme-wise list from previous-year questions of your target exam.

Common Traps

  • Choosing the literal meaning option (e.g., 'spill the beans' → literally spill beans; correct = reveal secret).
  • Confusing similar idioms ('burn bridges' vs 'burn the midnight oil').
  • Using an idiom in wrong register/context in sentence-improvement questions.
  • Guessing meaning from component words instead of learning the fixed phrase.

Memory Tricks

  • Theme clusters: Learn 8–10 idioms per theme per week.
  • Personal sentences: Write one sentence using each idiom in your own context.
  • Opposite pairs: 'burn bridges' (destroy) vs 'build bridges' (create relations).
Idioms exam strategy
Read the whole sentence to catch context. Eliminate literal-meaning options first. Among remaining, pick the option matching the stem's situation (success/failure/emotion/difficulty). If unsure, root meaning sometimes helps (e.g., 'heart' idioms relate to emotion/courage).
