Key Concepts

Spelling & Confusable Words

Spelling and confusable-word questions test attention to detail. Exams ask misspelt-word identification, correct-spelling choice, and near-homophone distinctions (e.g., stationary vs stationery).

  • Common spelling rules:
    • i before e except after c (receive, believe, ceiling, receipt — exceptions: science, sufficient, either, neither, foreign, height, leisure, weird, seizure).
    • Drop silent e before vowel suffix: hope → hoping, write → writing, love → loving, use → using; keep e before consonant suffix: hope → hopeful, care → careful.
    • Double final consonant before vowel suffix when stressed syllable ends in single vowel+consonant: begin → beginning, occur → occurring, prefer → preferred (British), travel → travelling (British); open → opening (not stressed, no double).
    • y → i before suffix when preceded by consonant: happy → happiness, beauty → beautiful, try → tries, carry → carries; keep y before -ing: try → trying, enjoy → enjoying.
    • ie/ei words: seize, weird, neither, foreign (exceptions).
    • American vs British: color/color, theater/theater, traveling/travelling, program/programme, realize/realise, license/licence (noun/verb distinction in British).

Confusable Word Pairs

  • Advice (noun) / Advise (verb): He gave me good advice / I advise you to wait.
  • Affect (verb) / Effect (noun): The rain affected the crop / The effect was immediate.
  • Altar (noun, church) / Alter (verb, change): wedding altar / alter the plan.
  • Bare (adjective, uncovered) / Bear (verb, carry/endure; noun, animal): bare feet / bear the pain / polar bear.
  • Breath (noun) / Breathe (verb): hold your breath / breathe deeply.
  • Canvas (noun, cloth) / Canvass (verb, solicit votes): oil canvas / canvass voters.
  • Capital (city/wealth) / Capitol (building): Delhi is capital / Capitol Hill.
  • Censor (verb/official) / Censure (verb/noun, criticize): censor the film / censure his conduct.
  • Complement (verb/noun, completes) / Compliment (verb/noun, praise): wine complements food / pay a compliment.
  • Conscience (noun, inner right/wrong) / Conscious (adjective, aware): guilty conscience / conscious decision.
  • Coarse (rough) / Course (route/class/meal): coarse cloth / course of action / main course.
  • Desert (abandon/dry place) / Dessert (sweet course): desert the post / Sahara desert / apple dessert.
  • Elicit (verb, draw out) / Illicit (adjective, illegal): elicit a response / illicit trade.
  • Emigrate (leave country) / Immigrate (enter country): emigrate from India / immigrate to Canada.
  • Eminent (famous) / Imminent (about to happen) / Emanate (come from): eminent scientist / imminent danger / heat emanates.
  • Farther (physical distance) / Further (additional/figurative): farther down the road / further information.
  • Flaunt (show off) / Flout (disregard rule): flaunt wealth / flout the law.
  • Foreword (intro to book) / Forward (toward front): read the foreword / move forward.
  • Grisly (horrible) / Gristly (full of gristle) / Grizzly (bear/gray): grisly murder / grizzly bear.
  • Imply (suggest) / Infer (deduce): he implied it / I inferred he meant X.
  • Stationary (stationary = not moving) / Stationery (writing materials): stationary vehicle / buy stationery.
  • Stationary vs Stationery mnemonic: stationERy has 'ER' like papER/ envelopER.
  • Storm (weather) / Storm (verb) / Storm (figurative): storm approaching / storm the castle / take by storm.
  • Than (comparison) / Then (time/sequence): taller than me / then we left.
  • Their (possessive) / There (place) / They're (they are): their book / over there / they're coming.
  • To (preposition/infinitive) / Too (also/excessively) / Two (number): go to school / too cold / two apples.
  • Your (possessive) / You're (you are): your book / you're late.
  • Whose (possessive) / Who's (who is): whose bag? / who's coming?
  • Lose (verb, miss) / Loose (adjective, not tight): don't lose it / loose shoes.
  • Quiet (silent) / Quite (completely): keep quiet / quite good.
  • Accept (receive) / Except (exclude): accept the gift / everyone except John.
  • Affect/Effect — see above.
  • All ready (prepared) / Already (by this time): all ready to go / already done.
  • Altogether (totally) / All together (in one place): altogether wrong / all together now.
  • Any one (single person) / Anyone (any person): any one of them / anyone can come.

Common Traps

  • Choosing a word that sounds right but is spelled wrong (recieve vs receive).
  • Confusing stationary/stationery in sentence-improvement questions.
  • Using 'your' for 'you're' or 'their' for 'there'.
  • Picking affect/effect wrongly based on sound rather than part of speech.
  • Missing silent letters (receipt, colonel, knight, doubt, island).

Memory Tricks

  • Stationary/Stationery: stationERy sells papER/envelopER.
  • Principal (main person, ends in -pal = your pal) / Principle (rule): principal = head.
  • Desert (one s, dry/sand) / Dessert (two s, sweet — you want two helpings): two s's = two servings.
  • Complement (completes, has 'e' like complete) / Compliment (praise, has 'i' like I like praise).
  • Stationary (a = at a standstill) / Stationery (e = envelope).
Spelling/confusables exam strategy
Read slowly; the eye skips double letters (accommodate, necessary). For confusables, identify the part of speech needed (advice = noun after 'some/good', advise = verb after subject). Build a personal error-log of words you repeatedly misspell.
