Q8. Quantitative Aptitudemodel-generated · 2026-11-07
A two-digit number has the property that the sum of its digits is 9. If 27 is added to this number, the digits interchange their places. Find the number.
A. 63
B. 54
C. 72
D. 81
Correct Answer: A
Let the tens digit be x and units digit be y. The number is 10x + y. Given x + y = 9, so y = 9 - x. Adding 27 gives 10y + x. Equation: 10x + y + 27 = 10y + x => 9x - 9y = -27 => x - y = -3. Substituting y = 9 - x: x - (9 - x) = -3 => 2x = 6 => x = 3, y = 6. The number is 36. Option A (63) has sum 9 but 63+27=90 (digits reversed from 36, not 63). Option B (54): 54+27=81 (not 45). Option C (72): 72+27=99. Option D (81): 81+27=108.

B. 9 seconds

D. 12 seconds
Correct Answer: B
When a clock strikes 4 times, there are 3 intervals between the strikes, not 4. Since each interval takes 3 seconds, the total time is 3 intervals × 3 seconds/interval = 9 seconds. Q10. Quantitative Aptitudemodel-generated · 2026-11-07
The base of a rectangular parallelepiped is increased by 20% and its height is decreased by 20%. What is the percentage change in its volume?
A. No change
B. 4% decrease
C. 4% increase
D. 16% decrease
Correct Answer: B
Let original base be b and height h. New base = 1.2b, new height = 0.8h. The new volume is (1.2 * 0.8) * b*h = 0.96V. This represents a 4% decrease in volume. A 4% increase would imply a factor of 1.04, which is incorrect here. No change assumes the product remains 1, which is false. 16% decrease corresponds to a factor of 0.84.
