Q3.
Which number replaces the question mark in the following series: 2, 5, 10, 17, 26, ?
A. 35
B. 37
C. 39
D. 41
Correct Answer: B
The series follows the pattern n^2 + 1, where n starts from 1. For n=1, 1^2 + 1 = 2. For n=2, 2^2 + 1 = 5. For n=3, 3^2 + 1 = 10. For n=4, 4^2 + 1 = 17. For n=5, 5^2 + 1 = 26. Therefore, for n=6, 6^2 + 1 = 36 + 1 = 37.
