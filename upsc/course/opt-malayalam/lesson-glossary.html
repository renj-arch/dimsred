How to use this glossary

The Malayalam optional is examined in Malayalam, but the names, titles and movement labels are where candidates lose easy marks: a paper that asks for ഇന്ദുലേഖ and receives Indulekha written in English, or a date attached to the wrong author, is a mark gone. Learn each entry as a pair — Malayalam script + English — and be able to write both.

Movements to name correctly

നവോത്ഥാനം (Renaissance) — the reform wave around Sree Narayana Guru, Ayyankali and the printing press; പച്ചമലയാളം (Pacha Malayalam) — the plain-language movement against heavy Sanskritised prose; ആധുനികത (modernism) — the 1960s break in poetry and fiction; ദളിത് സാഹിത്യം — Dalit writing from the 1990s. A question that asks you to place a writer in a movement is testing the label, not the plot: attach each writer to one movement and one representative work.

How to revise this page

Cover the English column and read the Malayalam; then cover the Malayalam and write it by hand. Ten entries a day, and by the end of a fortnight you can write every name and title the paper is likely to ask for. Dates to hold: ഇന്ദുലേഖ 1889, മാർത്താണ്ഡവർമ്മ 1891, വീണപൂവ് 1908, രമണൻ 1936, ഖസാക്ക് 1969.
