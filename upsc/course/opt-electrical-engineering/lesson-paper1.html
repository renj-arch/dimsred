Common Traps

  • Kirchhoff's Laws: KCL - algebraic sum of currents entering a node = 0; KVL - algebraic sum of voltages around a closed loop = 0; sign convention for voltage drops and rises; sign convention for current entering/leaving a node.
  • Superposition Theorem: Applicable only to linear circuits; turn off all independent sources except one (voltage sources → short circuit, current sources → open circuit), calculate contribution, sum algebraically; dependent sources remain active.
  • Maximum Power Transfer: Maximum power transferred to load when R_L = R_th; maximum power P_max = V_th²/(4R_th); efficiency at maximum power transfer = 50%.
  • Resonance: Series resonance: impedance minimum, current maximum, power factor = 1; Parallel resonance: impedance maximum, current minimum, power factor = 1; resonance frequency f₀ = 1/(2π√(LC)) for both series and parallel LC circuits.
  • Transient Response: First-order circuits (RC, RL): time constant τ = RC (RC circuit), τ = L/R (RL circuit); second-order circuits (RLC): underdamped, critically damped, overdamped based on damping ratio ζ; critical damping when ζ = 1.
Technique: Nodal Analysis
Question: Find node voltage V₁ at node 1 connected to 10V source via 2Ω resistor, to ground via 4Ω resistor, and to node 2 via 2Ω resistor; node 2 connected to ground via 6Ω resistor and to node 1 via 2Ω resistor.
Answer: KCL at node 1: (V₁ - 12)/2 + (V₁ - V₂)/2 + V₁/4 = 0 → multiply by 4: 2(V₁ - 12) + 2(V₁ - V₂) + V₁ = 0 → 2V₁ - 24 + 2V₁ - 2V₂ + V₁ = 0 → 5V₁ - 2V₂ = 24. KCL at node 2: (V₂ - V₁)/2 + V₂/6 = 0 → multiply by 6: 3(V₂ - V₁) + V₂ = 0 → 3V₂ - 3V₁ + V₂ = 0 → 4V₂ - 3V₁ = 0 → V₂ = 0.75V₁. Substitute: 5V₁ - 2(0.75V₁) = 24 → 5V₁ - 1.5V₁ = 24 → 3.5V₁ = 24 → V₁ = 6.857V, V₂ = 0.75 × 6.857 = 5.143V.

Common Traps

  • KCL/KCL Sign Convention: Currents entering node = currents leaving node; or sum of currents leaving node = 0; be consistent with sign convention.
  • Source Transformation: Voltage source V in series with R ↔ current source I = V/R in parallel with R; remember R_th = R_N = R_th.
  • Superposition Theorem: Turn off all independent sources except one; voltage sources → short circuit, current sources → open circuit; dependent sources remain active; sum contributions algebraically.
  • Maximum Power Transfer: Maximum power transferred when R_L = R_th; maximum power P_max = V_th²/(4R_th); efficiency at maximum power transfer = 50% (not 100%).
  • Supermesh: When current source is on branch shared by two meshes, create supermesh by excluding current source; apply KVL around supermesh; add constraint equation I₁ - I₂ = I_source.
Mains strategy
Electrical engineering answers: draw circuit diagrams clearly, label all nodes/branches/nodes, show step-by-step derivation of circuit equations, state assumptions clearly, quote IS codes (IS 456 for RCC, IS 800 for steel, IS 1893 for seismic design, IS 10262 for mix design), quote standard values (electrical resistivity of copper 1.72×10⁻⁸ Ω·m, copper density 8.96 g/cm³, electrical resistivity of aluminium 2.83×10⁻⁸ Ω·m, aluminium density 2.7 g/cm³).
