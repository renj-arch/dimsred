Statistics Paper II — Linear Models, Design of Experiments & Sampling

Linear Models & Regression

  • Simple Linear Regression: Y = β₀ + β₁X + ε, assumptions (linearity, independence, homoscedasticity, normality of errors), least squares estimation: β̂₁ = Σ(xᵢ-x̄)(yᵢ-ȳ)/Σ(xᵢ-x̄)², β̂₀ = ȳ - β̂₁x̄, properties: unbiasedness, consistency, efficiency (Gauss-Markov theorem: BLUE under classical assumptions), R² (coefficient of determination), correlation coefficient r = Cov(X,Y)/(σ_Xσ_Y), relationship r² = R² for simple linear regression.
  • Multiple Linear Regression: Y = Xβ + ε, matrix form Y = Xβ + ε, OLS estimator β̂ = (X'X)⁻¹X'Y, properties: unbiased (E[β̂] = β), variance-covariance matrix Var(β̂) = σ²(X'X)⁻¹, Gauss-Markov theorem: β̂ is BLUE under classical assumptions (linearity, independence, homoscedasticity, no perfect multicollinearity, zero conditional mean), hypothesis testing: t-test for individual coefficients, F-test for overall significance (F = (SSR/k)/(SSE/(n-k-1))), confidence intervals, prediction intervals, prediction interval vs confidence interval.
  • Model Diagnostics: Residual analysis (residual plots: residuals vs fitted values, Q-Q plot, scale-location plot), heteroscedasticity (Breusch-Pagan test, White test), autocorrelation (Durbin-Watson test), multicollinearity (VIF - Variance Inflation Factor, VIF_j = 1/(1-R²_j), VIF > 10 indicates high multicollinearity), influential observations (Cook's distance, leverage, DFBETAS), outliers.
  • Model Selection: AIC (Akaike Information Criterion), BIC (Bayesian Information Criterion), adjusted R², stepwise selection (forward selection, backward elimination, stepwise selection), cross-validation.

Design of Experiments (DOE)

  • Principles of Experimental Design: Replication, Randomization, Local Control (Blocking).
  • Completely Randomized Design (CRD): One-way ANOVA model: Y_ij = μ + τ_i + ε_ij, assumptions (independence, normality, homoscedasticity), ANOVA table: Source (Treatment, Error, Total), df, SS, MS, F-statistic, F-test for equality of treatment means, assumptions checking (residual plots, normality plots), multiple comparisons (LSD, Tukey's HSD, Bonferroni, Scheffe).
  • Randomized Complete Block Design (RCBD): Model: Y_ij = μ + τ_i + β_j + ε_ij, blocking to control heterogeneity, ANOVA table (Blocks, Treatments, Error, Total), advantages: reduces error variance by accounting for block effects, assumptions: additivity (no interaction between treatments and blocks), assumptions checking.
  • Latin Square Design (LSD): Model: Y_ijk = μ + R_i + C_j + T_k + ε_ijk, controls two sources of variation (rows and columns), assumptions: no interaction between rows, columns, and treatments, advantages: controls two sources of variability, limitations: number of treatments = number of rows = number of columns.
  • Factorial Experiments: 2^k factorial design: main effects and interaction effects, main effect of factor A: average effect of changing A from low to high, averaging over other factors; interaction effect: effect of one factor depends on level of another factor, interpretation of interaction plots, Yates' method for 2^k designs, ANOVA for 2^k factorial: main effects and interactions, degrees of freedom.
  • Fractional Factorial Designs: 2^(k-p) fractional factorial designs, confounding/aliasing, resolution (Resolution III, IV, V), resolution III: main effects confounded with two-factor interactions, Resolution IV: main effects not confounded with two-factor interactions but two-factor interactions confounded with each other, Resolution V: main effects and two-factor interactions not confounded with each other but confounded with three-factor interactions.

Sampling Theory

  • Simple Random Sampling (SRS): Simple random sampling without replacement (SRSWOR), with replacement (SRSWR), estimation of population mean: ȳ = (1/n)Σy_i, Var(ȳ) = (1-f)(S²/n) where f = n/N (sampling fraction), finite population correction (FPC) = (N-n)/(N-1), estimation of population total: Ť = Nȳ, Var(Ť) = N²(1-f)S²/n.
  • Stratified Random Sampling: Population divided into H strata, sample n_h from stratum h, sample allocation: proportional allocation (n_h = n·N_h/N), optimal allocation (Neyman allocation: n_h ∝ N_hS_h), cost-optimal allocation (minimize cost for fixed precision or minimize variance for fixed cost), stratified mean estimator: ȳ_st = Σ(W_h ȳ_h), Var(ȳ_st) = Σ(W_h² S_h²/n_h)(1-f_h), gain from stratification: Var(ȳ_ran) - Var(ȳ_st) = ΣW_h(μ_h - ȳ)² - ΣW_hS_h²/n_h + ... (between-stratum variance - within-stratum variance reduction).
  • Cluster Sampling: Primary sampling units (PSUs) and secondary sampling units (SSUs), one-stage cluster sampling: select m clusters, measure all elements within selected clusters, Var(ȳ_cluster) = (1-f)(S_b²/m + S_w²/(mn)) where S_b² = between-cluster variance, S_w² = within-cluster variance, intraclass correlation ρ = S_b²/(S_b² + S_w²), design effect DEFF = 1 + (m-1)ρ.
  • Systematic Sampling: Select every k-th element after random start, k = N/n (sampling interval), variance depends on population ordering: Var(ȳ_sys) ≈ (1-f)S²/n when population ordered randomly, Var(ȳ_sys) < Var(ȳ_SRS) when population ordered monotonically (periodic variation aligned with sampling interval increases variance), stratified systematic sampling.
  • Multistage Sampling: Two-stage sampling: select n₁ PSUs, then n₂ SSUs from each selected PSU, Var(ȳ_2stage) = (1-f₁)S₁²/n₁ + (1-f₂)S₂²/(n₁n₂), where S₁² = between-PSU variance, S₂² = within-PSU variance, optimal allocation: minimize variance for fixed cost or minimize cost for fixed variance.
  • Ratio & Regression Estimators: Ratio estimator: ȳ_R = (ȳ/ x̄)X̄, bias ≈ (1/n)(θ̄_x/μ_x)(S_y²/σ_y² - ρσ_y/σ_x), MSE ≈ (1-f)(1/n)(S_y² + R²S_x² - 2ρS_yS_x), regression estimator: ȳ_reg = ȳ + β(x̄ - x̄_0), β = S_xy/S_x², variance: Var(ȳ_reg) = (1-f)(1/n)(S_y² - ρ²S_y²) = (1-f)(S_y²/n)(1-ρ²), regression estimator more efficient when ρ² > 0.
Technique: Ratio Estimator
Question: Estimate total yield Y from sample: n=50 farms, sample mean yield ȳ=2.5 tons/ha, sample mean area x̄=5 ha, total area X̄=10,000 ha.
Answer: Ratio estimator ȳ_R = (ȳ/x̄)X̄ = (2.5/5)×10,000 = 5,000 tons. Variance: Var(ȳ_R) ≈ (1-f)(1/n)(S_y² - 2ρS_yS_x + R²S_x²). Assuming ρ=0.8, S_y=1.5, S_x=2: Var ≈ (1-50/1000)(1/50)(1.5² - 2(0.8)(1.5)(2) + 0.5²×2²) = 0.95(0.02)(2.25 - 4.8 + 4) = 0.95(0.02)(1.25) = 0.02375. SE(ȳ_R) ≈ √0.02375 = 0.154 tons/ha. Total estimate: 5,000 ± 1.96×0.154×100 = 5,000 ± 154 tons.

Memory Tricks

  • OLS Assumptions: LINEAR - Linearity, Independence, No perfect multicollinearity, Zero conditional mean, Homoscedasticity.
  • ANOVA decomposition: SST = SSR + SSE (Total Sum of Squares = Regression SS + Error SS), R² = SSR/SST = 1 - SSE/SST.
  • Sampling: SRS: Var(ȳ) = (1-f)S²/n; Stratified: Var(ȳ_st) = ΣW_h²S_h²/n_h; Cluster: Var(ȳ_c) = (1-f)(S_b²/m + S_w²/(mn)).
  • DEFF = 1 + (m-1)ρ: Design effect for cluster sampling, ρ = intraclass correlation.
Mains strategy
Statistics answers: state model assumptions, write likelihood/estimating equations, show derivation step by step, state distribution of estimator under H₀, compute test statistic, compare with critical value or compute p-value, state conclusion in context. Quote formulas: OLS β̂ = (X'X)⁻¹X'Y, Var(β̂) = σ²(X'X)⁻¹, F-statistic, t-statistic, EOQ formula, Neyman allocation n_h ∝ N_hS_h, DEFF = 1 + (m-1)ρ.
