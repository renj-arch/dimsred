Q1. Reasoning
Under Section 56 of the Indian Contract Act, 1872, a contract is frustrated when a supervening event makes performance impossible or unlawful. Which of the following is NOT a required element for frustration?
A. The event occurs without fault of either party
B. The event was unforeseen and not provided for in the contract
C. The event renders performance merely more expensive or delayed
D. The event destroys the foundation of the contract or makes performance fundamentally different
Correct Answer: C
Correct answer: The event renders performance merely more expensive or delayed.
