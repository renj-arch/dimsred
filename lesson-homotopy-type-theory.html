Homotopy Type Theory — Univalence, Higher Inductive Types & the Foundations of Mathematics

Homotopy Type Theory (HoTT) is a foundational approach to mathematics that interprets types as spaces in homotopy theory. In this paradigm, the identity type Id_A(a,b) becomes the path space — the collection of paths from point a to point b in the space A. Martin-Löf's dependent type theory provides the logical backbone, while Voevodsky's univalence axiom (equivalent types are equal) introduces a revolutionary principle: isomorphic mathematical structures can be identified. Higher inductive types (HITs) allow the construction of cell complexes — spheres, tori, and pushouts — directly as types. The concept of h-levels stratifies types by homotopical complexity: sets (h-level 2), groupoids (h-level 3), and ∞-groupoids. Voevodsky's simplicial set model provides a rigorous semantics for HoTT, while the emerging field of synthetic homotopy theory proves classical theorems (π₁(S¹) = ℤ, Blakers-Massey) using only type-theoretic reasoning. HoTT has been formalized in proof assistants like Coq, Agda, and Lean, powering applications from the formalization of the Grothendieck l-adic Galois representations to the Atiyah-Singer index theorem.

Part 1

📏 Martin-Löf Type Theory and the Identity Type

Foundations
Dependent Type Theory, Π-Types, Σ-Types, and the Identity Type
Martin-Löf dependent type theory provides the core language of HoTT. Π-types (dependent functions) generalize function types: for a family B: A → 𝒰, the type Π(x:A) B(x) consists of functions f where f(a): B(a). Σ-types (dependent pairs) generalize Cartesian products: Σ(x:A) B(x) consists of pairs (a,b) with a: A and b: B(a). The natural numbers ℕ are an inductive type with 0: ℕ and succ: ℕ → ℕ. The identity type Id_A(a,b), often written a =_A b, is the type of propositions of equality — its terms are proofs that a equals b. The reflexivity constructor refl_a: a = a provides the trivial equality. The J-rule (path induction): given a family C(x,y,p) over x =_A y with a term c(x): C(x,x,refl_x), we can construct J(c; x,y,p): C(x,y,p) for any x, y, and p. This is the elimination principle for the identity type. Homotopical interpretation: types are spaces, terms are points, and Id_A(a,b) is the path space of paths from a to b. The J-rule corresponds to path induction: to prove something about all paths, it suffices to prove it for constant paths. The groupoid laws arise: reflexivity gives identity paths, concatenation composes paths, inversion reverses them — and these satisfy the groupoid axioms up to higher homotopies. The Eckmann-Hilton argument shows that composition of 2-loops is commutative, revealing the ∞-groupoid structure of types. Every type is an ∞-groupoid: it has objects (points), 1-morphisms (paths), 2-morphisms (homotopies between paths), and so on.
In HoTT, types are spaces, terms are points, and the identity type captures the entire homotopical path structure — each type is an ∞-groupoid.
Part 2

🌍 The Univalence Axiom

Univalence
Equivalences, the Map idtoeqv, and the Univalence Axiom
Given two types A and B, the type of equivalences Equiv(A,B) consists of functions f: A → B that have a two-sided inverse — that is, there exists g: B → A such that g∘f ∼ id_A and f∘g ∼ id_B, along with coherence conditions. There is a canonical map idtoeqv: (A =_𝒰 B) → Equiv(A,B) defined by path induction: idtoeqv(refl_A) = id_Equiv(A,A). The univalence axiom (Voevodsky, 2009) asserts that idtoeqv is itself an equivalence — i.e., for any A, B: 𝒰, the map idtoeqv is an equivalence. Hence we have (A =_𝒰 B) ≃ Equiv(A,B): equivalent types are equal. This is the core axiom of HoTT. Consequences: function extensionality — pointwise equal functions are equal (f ∼ g implies f = g). Propositional extensionality — logically equivalent propositions are equal. The universe 𝒰 itself acquires a rich structure: it becomes a classifier for small fibrations in the homotopy sense. The structure identity principle (SIP): isomorphic mathematical structures (groups, rings, graphs, etc.) can be identified as equal — for example, isomorphic groups are equal as group structures on a carrier type. Univalence collapses the distinction between isomorphism and identity, radically changing the foundations of mathematics.
Univalence makes mathematics more "structural": any property preserved under equivalence can be transported along identities — isomorphic objects are indistinguishable.
Part 3

🧮 Higher Inductive Types

HITs
Higher Inductive Types: Circles, Spheres, Suspensions, and Pushouts
Higher inductive types (HITs) extend ordinary inductive types by adding constructors that generate paths (1-dimensional equalities), 2-paths, and so on. The canonical example: the circle S¹ as a HIT — base: S¹, loop: base =_S¹ base. The homotopy group π₁(S¹) = ℤ can be proved synthetically in HoTT using the universal cover of S¹ (encoded as a fibration over S¹). The 2-sphere S² has base: S² and a 2-dimensional loop surf: refl_base = refl_base. The suspension ΣA of a type A has constructors N, S: ΣA, and merid: A → (N =_ΣA S). The pushout of f: C → A and g: C → B is a HIT with constructors inl: A → P, inr: B → P, and glue: (c:C) → inl(f(c)) =_P inr(g(c)). The torus T² can be defined as a HIT with generating loops p, q: base = base and a 2-cell a: p∘q = q∘p (commutativity). The Blakers-Massey theorem in HoTT: for a pushout P of f: C → A and g: C → B, the map from the fiber of f over c to the fiber of g over c (induced by the glue constructor) is (m+n-2)-truncated, where f is m-truncated and g is n-truncated. The van Kampen theorem: the fundamental group of a pushout is the amalgamated free product of the fundamental groups of the input types.
HITs bring the power of algebraic topology into type theory — cell complexes become types, and their homotopy groups can be computed synthetically.

🔥 Synthetic Homotopy Theory and Formalization

Synthetic
Homotopy Groups of Spheres, Freudenthal Suspension, Brunerie Number, and Formalization
Synthetic homotopy theory proves classical homotopy-theoretic results using only type-theoretic reasoning inside HoTT. Key results: π₁(S¹) = ℤ and πₖ(S¹) = 0 for k > 1 (the circle's higher homotopy groups vanish). π₂(S²) = ℤ and π₃(S²) = ℤ via the Hopf fibration — a family of circles parametrized by S². The Freudenthal suspension theorem: the suspension map Σ: π_k(Sⁿ) → π_{k+1}(S^{n+1}) is an isomorphism for k < 2n-1. The Brunerie number: π₄(S³) = ℤ/2 — a concrete computational result verified in HoTT using a lengthy cubical computation; the "Brunerie number" refers to an integer β such that π₄(S³) = ℤ/βℤ, and β was computed to be 2. The Serre spectral sequence has been constructed in HoTT, providing a powerful computational tool. Formalization in proof assistants: the UniMath project (Voevodsky et al.) formalizes a large body of mathematics in Coq using univalence. The HoTT library in Coq and Agda provides extensive infrastructure for synthetic homotopy theory. Cubical type theory (Cohen-Coquerot-Huber-Mörtberg) gives a computational interpretation of univalence — unlike the original model, cubical type theory has a canonicity property and enables computation with univalence. Applications to mathematics: the formalization of the Grothendieck l-adic Galois representations (Voevodsky), and the formal proof of the Atiyah-Singer index theorem in Lean. HoTT continues to influence the foundations of mathematics, proof theory, and the development of proof assistants.
HoTT provides a synthetic framework for homotopy theory where classical theorems can be proven and formalized in proof assistants, bridging topology, type theory, and computation.

Cubical Type Theory and Computational Univalence

Cubical type theory provides a constructive model of homotopy type theory in which the univalence axiom computes. Introduced by Cohen, Coquand, Huber, and Mörtberg in their 2016 paper Cubical Type Theory: a constructive interpretation of the univalence axiom, the theory extends Martin‑Löf type theory with an interval type I having endpoints 0 and 1. A path in a type A is a function I → A, and path composition, inversion, and higher coherences are expressed by Kan composition operations comp and hcomp. The crucial addition is the Glue type former, which internalises the equivalence‑to‑equality map and makes univalence a theorem rather than an axiom. As a consequence, closed terms of natural number type reduce to numerals — canonicity holds — and transport along ua(e) for an equivalence e reduces definitionally to the action of e. This computational behaviour is absent in the original axiomatic formulation, where transport is stuck at the axiom.

The first implementation was Cubical Agda (2019) by Vezzosi, Mörtberg, and Abel, which integrates cubical primitives directly into the Agda language. Subsequent work produced Cartesian cubical type theory (Angiuli, Favonia, Harper, 2021) to simplify universe management and support higher inductive types with computational rules. Cubical type theory also validates function extensionality and propositional extensionality by computation, and it has become the basis for several formalisation projects that require executable proofs, such as the verification of the Brunerie number in synthetic homotopy theory.

Higher Inductive‑Inductive Types and Quotients

Higher inductive‑inductive types (HIITs) generalise higher inductive types by allowing a type and a family over that type to be defined simultaneously. The concept was introduced by Altenkirch, Capriotti, and others in the 2017 paper Higher Inductive‑Inductive Types. A canonical example is the Cauchy real numbers: one defines a type ℝ of real numbers together with a family ≈ of approximation relations, with constructors for rational approximations, limits, and the required equalities. Another example is the syntax of dependent type theory itself, where contexts, types, and terms are defined mutually with their well‑formedness predicates.

Quotient types arise as a special case of HIITs. Given a type A and a relation R : A → A → 𝒰, the quotient A/R can be presented as a higher inductive type with a point constructor q : A → A/R and a path constructor eq : ∀ {x y}, R x y → q x = q y. When the quotient is required to be a set (0‑truncated), an additional truncation constructor is added. HIITs allow the relation R to be defined inductively at the same time as the quotient, which is essential for constructing quotients of higher structures such as the free group on a type or the set‑quotient of a groupoid. These constructions have been formalised in Cubical Agda and in the Coq HoTT library, and they admit an initial‑algebra semantics in any (∞,1)‑topos.

Worked Example: Defining the Integers as a HIIT
Show how the integers ℤ can be defined as a higher inductive‑inductive type with a simultaneous equivalence relation, and explain why this avoids the need for a separate set‑quotient construction.

Define a type ℤ and a family _≈_ : ℤ → ℤ → 𝒰 by the following constructors:

  • zero : ℤ
  • pos : ℕ → ℤ
  • neg : ℕ → ℤ
  • eq_pos_zero : pos 0 ≈ zero
  • eq_neg_zero : neg 0 ≈ zero
  • eq_pos_succ : ∀ n, pos (n+1) ≈ pos n
  • eq_neg_succ : ∀ n, neg (n+1) ≈ neg n
  • eq_pos_neg : ∀ n, pos n ≈ neg n (for n>0)

The relation ≈ is generated inductively by these constructors together with reflexivity, symmetry, and transitivity (which are also constructors of the family). Because the equivalence relation is built simultaneously with the type, the resulting ℤ is already a set — no separate 0‑truncation is needed. The usual integer operations are then defined by recursion on the constructors, and the fact that they respect ≈ follows by induction on the relation. This pattern generalises to any quotient where the relation is inductively generated.

Exam‑Day Strategy
When a question asks for a quotient construction in HoTT, first decide whether the relation is decidable or inductively generated. If it is inductively generated, reach for a HIIT; if it is an arbitrary equivalence relation on a set, a plain HIT with a truncation constructor suffices. Remember that HIITs give you the quotient and its equivalence relation in one go, which often simplifies the proof that the quotient is a set.

Modalities and Cohesive Homotopy Type Theory

Modalities in HoTT are idempotent (co)monads on the universe that capture notions of “being of a certain shape”. The systematic study began with Shulman’s 2015 work Brouwer’s fixed‑point theorem in real‑cohesive homotopy type theory. A modality consists of an endofunctor ○ : 𝒰 → 𝒰 equipped with a unit η : A → ○A such that ○η and η○ are equivalences. Common modalities include n‑truncation (‖−‖ₙ), the double negation modality, and the shape modality ʃ.

Cohesive HoTT adds a string of adjoint modalities ʃ ⊣ ♭ ⊣ ♯ satisfying axioms that mirror Lawvere’s cohesion: ʃ (shape) preserves finite products, ♭ (flat) gives the discrete reflection, and ♯ (sharp) gives the codiscrete reflection. These modalities allow one to do synthetic differential geometry inside type theory: the real line ℝ can be equipped with a cohesive structure where ♭ℝ is the discrete real line and ʃℝ is its fundamental ∞‑groupoid. The axioms have been formalised in the RealCohesiveHoTT library for Coq and in Agda, and they enable the definition of differential cohomology, de Rham cohomology, and the synthetic formulation of the Stokes theorem.

Synthetic ∞‑Category Theory in HoTT

Because types in HoTT behave as ∞‑groupoids, the theory serves as a native language for (∞,1)‑categories. A precategory consists of a type of objects Ob and for each x y : Ob a hom‑type Hom(x,y) that is a set (1‑truncated), together with composition and identities. A univalent category (or complete Segal type) further requires that the canonical map Ob → Core(C) from objects to the core (the maximal subgroupoid) is an equivalence — this is precisely the Rezk completeness condition. Ahrens, Kapulkin, and Shulman (2015) proved that every precategory admits a Rezk completion into a univalent category, and that the type of univalent categories is itself a higher inductive type.

Higher categorical structures are encoded as Segal types: a type X equipped with maps Xₙ → X₁ ×X₀ … ×X₀ X₁ that are equivalences. Completeness (the Rezk condition) is again expressed by a univalence‑like axiom. These ideas have been formalised in the UniMath library (Coq) and in the Agda HoTT library, providing a foundation for (∞,1)‑topos theory and higher algebra inside proof assistants. The synthetic approach avoids the combinatorial complexity of simplicial models and makes the ∞‑categorical reasoning directly accessible to type‑theoretic computation.

Formalization of Algebraic Topology in Proof Assistants

The HoTT libraries in Coq (started 2014) and Agda (started 2015) have been used to formalise a substantial body of synthetic homotopy theory. Landmark results include the proof that π₁(S¹) = ℤ (Licata and Shulman, 2013) and the computation of the Brunerie number π₄(S³) = ℤ/2ℤ (Brunerie, 2016), the latter requiring a lengthy cubical computation that was later verified in Cubical Agda. The Blakers‑Massey theorem was formalised by Finster, Licata, and others (2018) in Agda, and the Serre spectral sequence was constructed by Buchholtz and Rijke (2020) in Agda, providing a powerful computational tool for higher homotopy groups.

Beyond homotopy theory, the UniMath project (Voevodsky et al.) formalises mathematics using univalence in Coq, including categories, homological algebra, and parts of algebraic geometry. In Lean, the mathlib community completed a formal proof of the Atiyah‑Singer index theorem (2023), demonstrating that HoTT‑inspired techniques can scale to deep analytic results. Cubical Agda’s computational univalence has been essential for verifying concrete numbers such as the Brunerie number, while the Coq HoTT library emphasises axiomatic development. Current challenges include universe management, performance of higher inductive type elimination, and automation of synthetic arguments, but the trajectory shows that machine‑checked proofs of major topological theorems are becoming routine.

Ordinal Truncation, Cumulative Universes, and the Hierarchy of h‑Levels

In Homotopy Type Theory each type carries an h‑level that measures its homotopical complexity: a type of h‑level 0 is contractible, h‑level 1 are propositions, h‑level 2 are sets, and so on. The process of “truncating’’ a type to a lower h‑level is formalised by the n‑truncation HIT ‖A‖ₙ, which freely forces all paths above dimension n to become equal. This operation is central when one wishes to extract set‑level information from higher‑dimensional data, for example to define the fundamental group π₁(X) as the loop space of the 1‑truncation of X.

Beyond simple truncations, HoTT adopts a cumulative hierarchy of universes 𝒰₀ : 𝒰₁ : 𝒰₂ : ⋯ . Each universe 𝒰ᵢ is itself a type in the next level, and the cumulative rule 𝒰ᵢ ⊂ 𝒰ᵢ₊₁ guarantees that a type can be regarded at any higher universe without loss of information. This stratification mirrors the classical set‑theoretic hierarchy (Vα) but is internal to type theory, allowing one to reason about “large’’ constructions such as the type of all small categories (Cat : 𝒰₁) while staying within a single formal system.

The interaction between truncation and universes is subtle. The n‑truncation ‖A‖ₙ lives in the same universe as A, yet its universal property quantifies over all types of h‑level ≤ n, which may reside in lower universes. Consequently, when defining a cumulative family of truncations across universes one must insert a universe‑lifting operation, often written liftᵢⱼ : 𝒰ᵢ → 𝒰ⱼ for i ≤ j. The lift is a definable equivalence that respects identity paths, ensuring that truncation commutes with universe inclusion.

Ordinal truncations extend the idea further: given an ordinal α (represented as a well‑founded, transitive set in HoTT), one can define a transfinite truncation τ_α(A) that collapses all homotopy groups above dimension α to triviality. This construction is useful in synthetic homotopy theory when analysing Postnikov towers. The tower of truncations τ₀(A) → τ₁(A) → τ₂(A) → … converges to A under the condition that A is < ∞‑truncated, i.e. there exists an n such that τₙ(A) ≃ A. The convergence proof uses the univalence axiom to identify each stage with a higher inductive type built from the previous one.

From an exam perspective, candidates should be able to:

  • State the universal property of ‖A‖ₙ and give a concrete example (e.g., constructing the set of connected components π₀(X) as ‖X‖₀).
  • Explain why cumulative universes are needed for large constructions and how liftᵢⱼ preserves identity types.
  • Describe the role of ordinal truncations in building Postnikov towers and indicate the convergence criterion.

Synthetic Cohomology via Univalent Foundations

Classical cohomology assigns to a topological space X a graded abelian group Hⁿ(X;G) defined via singular cochains, sheaf cohomology, or derived functors. In HoTT the same invariants can be obtained synthetically, without reference to point‑set topology. The key idea is to replace the coefficient group G by a type equipped with an abelian group structure, and to define cohomology classes as maps into an appropriate Eilenberg–Mac Lane type K(G,n).

The Eilenberg–Mac Lane HIT K(G,n) is characterised by the property that its only non‑trivial homotopy group is πₙ(K(G,n)) ≃ G. Its construction uses higher inductive types: one introduces a point constructor, an n‑dimensional loop constructor for each element of G, and higher path constructors ensuring that all other homotopy groups vanish. Univalence guarantees that any two such HITs with the same homotopy groups are equivalent, making K(G,n) unique up to equivalence.

Given X : 𝒰, the n‑th cohomology group with coefficients in G is defined as the set of homotopy classes of maps:

Hⁿ(X;G) := ‖X → K(G,n)‖₀.

Because the codomain is (n‑truncated) and the function type X → K(G,n) is automatically an (n+1)‑type, the 0‑truncation yields a set, matching the classical notion of a cohomology group. The cup product arises from the smash product of Eilenberg–Mac Lane types, and the Steenrod operations can be defined using the higher‑inductive structure of K(ℤ/2, n).

One of the most striking synthetic results is the proof of the Hopf invariant one theorem entirely within HoTT. By analysing maps S³ → S² as elements of H³(S³;ℤ) and using the univalence‑based identification of loop spaces, one shows that only the classical Hopf maps have Hopf invariant 1, without invoking cellular homology.

Exam‑level expectations include:

  • Constructing K(G,n) as a HIT and stating its universal property.
  • Deriving the definition of Hⁿ(X;G) as a 0‑truncation of a function type.
  • Explaining how the cup product is obtained from the smash product and how univalence ensures associativity and commutativity up to higher homotopy.
Technique: Translating a Classical Cohomology Computation into HoTT
Compute H¹(S¹;ℤ) using the synthetic definition H¹(X;G) := ‖X → K(G,1)‖₀. Show that the answer is ℤ.

Step 1: Identify K(ℤ,1). By definition K(ℤ,1) is a HIT with a point base and a loop constructor ℓ : ℤ → (base = base). This type is equivalent to the circle S¹, because the loop space of S¹ is ℤ.

Step 2: Observe that maps S¹ → K(ℤ,1) correspond to based maps S¹ → S¹, i.e. to integers via the degree. In HoTT, the type (S¹ → S¹) is equivalent to ℤ by the fundamental theorem of the circle (Licata–Shulman 2013).

Step 3: Apply 0‑truncation. Since (S¹ → K(ℤ,1)) is already a set (its homotopy groups above 0 are trivial), the truncation does not change it: ‖S¹ → K(ℤ,1)‖₀ ≃ ℤ.

Conclusion: H¹(S¹;ℤ) ≃ ℤ, matching the classical singular cohomology result.

Exam‑day strategy
When a question asks for a cohomology computation, first translate the coefficient group into a HIT K(G,n). Then check whether the mapping type X → K(G,n) is already a set; if so you can skip the 0‑truncation step and directly identify the function space with a known algebraic object (e.g., degrees of maps S¹ → S¹). This saves time and avoids unnecessary formalism.

Parametricity, Equivalences, and the “Transport‑Free” Proof Technique

Parametricity in type theory expresses the principle that functions behave uniformly across all types. In HoTT this principle is sharpened by the univalence axiom: an equivalence e : A ≃ B can be transported to an equality p : A = B, and any construction that is natural in A automatically respects equivalences. This gives rise to the “transport‑free’’ proof technique, where one replaces explicit transports along equalities by applying the equivalence directly.

Consider a family P : 𝒰 → 𝒰. The usual transport operation transport^P(p, x) : P A → P B for p : A = B can be re‑expressed as P‑map(e) where e : A ≃ B is the equivalence corresponding to p via univalence. Because equivalences preserve all higher structure, many lemmas that classically require tedious path‑algebra become simple applications of functoriality of P.

A concrete illustration is the proof that the loop space of a suspension ΣX is equivalent to the join of X with itself: ΩΣX ≃ X * X. Classical homotopy theory proves this by analysing the cellular structure of ΣX. In HoTT one defines ΣX as a HIT with two points north and south and a meridian constructor for each x : X. The loop space ΩΣX is then the type of paths north = south, which by HIT elimination is equivalent to the pushout of X ← X × X → X, i.e. the join X * X. The equivalence is constructed directly, without any transport, because the recursion principle for ΣX already yields a map that respects the higher constructors.

Parametricity also yields “free theorems”. For any polymorphic function f : ∀(A : 𝒰). A → A, univalence forces f to be the identity function. The proof proceeds by assuming an equivalence e : A ≃ B, applying f at A and B, and using naturality to obtain a commuting square; univalence then collapses the square to an equality, forcing f_A = id_A for all A.

Key points for examinations:

  • State the parametricity principle: a term of type ∀A. P A is automatically natural in A.
  • Show how transport along p : A = B can be replaced by applying the equivalence e : A ≃ B obtained from univalence.
  • Apply the transport‑free method to a standard HIT, such as proving ΩΣX ≃ X * X.
  • Derive a free theorem for a polymorphic function and explain why only the identity satisfies the type.

Reedy Model Structures and Their Interpretation in Cubical Type Theory

Model categories provide an abstract setting for homotopy theory, and the Reedy model structure is particularly suited to diagrammatic objects such as simplicial or cubical types. In the cubical setting, where types are interpreted as presheaves on the cube category □, the Reedy structure distinguishes between “matching’’ and “latching’’ objects, enabling inductive constructions that respect the cubical dimension.

A Reedy category 𝔯 comes equipped with a degree function deg : Obj(𝔯) → ℕ and two subcategories 𝔯⁺ (degree‑raising) and 𝔯⁻ (degree‑lowering). For a diagram X : 𝔯 → 𝒰, the latching object LₙX is the colimit of X over the subcategory of maps into the object of degree n, while the matching object MₙX is the limit over maps out of that object. A map f : X → Y is a Reedy cofibration if each induced map LₙX ⊔LₙY Yₙ → Yₙ is a cofibration in the underlying model structure; dually, f is a Reedy fibration if each Xₙ → MₙX ×MₙY Yₙ is a fibration.

In Cubical Agda, the interval I = {0,1} with connections provides the basic cube category. The Reedy model structure on cubical sets aligns with the Kan‑fibration condition: a map is a fibration iff it has the right lifting property against the generating cofibrations (the inclusions of boundary cubes). The Reedy perspective clarifies why composition of Kan fibrations is again a fibration: the matching objects encode precisely the horn‑filling conditions needed for Kan extensions.

One practical advantage is the construction of higher inductive types with “recursive” constructors, such as the torus T² defined by two loops and a 2‑dimensional square filling their commutator. Using Reedy cofibrancy, one can build T² as a colimit of a diagram of cubes where each stage adds a new cell while preserving fibrancy. The Reedy cofibration condition guarantees that the resulting HIT satisfies the desired elimination principle without extra coherence axioms.

For exam preparation, students should be able to:

  • Define the degree function, latching, and matching objects for a Reedy category.
  • State the Reedy cofibration and fibration conditions in terms of these objects.
  • Explain how the Reedy model structure on cubical sets reproduces the Kan condition.
  • Illustrate the construction of a non‑trivial HIT (e.g., the torus) using a Reedy diagram and argue why the resulting type is fibrant.

Univalent Foundations for Algebraic Geometry: Schemes as Stacks in HoTT

Algebraic geometry traditionally rests on set‑theoretic foundations, with schemes defined as locally ringed spaces. In the univalent setting, one can reinterpret schemes as sheaves of commutative rings on a site, and then promote these sheaves to ∞‑stacks—objects that satisfy descent not only for objects but also for higher morphisms. The key insight is that a sheaf of types automatically carries higher‑groupoid information, making it a natural host for derived and spectral geometry.

The construction begins with the Zariski site on the category of affine schemes Aff, where a covering is a family of open immersions {U_i → Spec A} that jointly surject on prime spectra. In HoTT one defines a presheaf F : Affᵒᵖ → 𝒰 and imposes the sheaf condition via a higher‑inductive type that glues together sections over overlaps, using path constructors for compatibility on double and triple intersections. Univalence guarantees that the resulting glued object is unique up to equivalence, mirroring the classical sheaf condition.

To obtain a stack, one further requires descent for equivalences: for any covering {U_i} the canonical map

F(Spec A) → limΔ F(Ui₀…iₙ)

must be an equivalence, where the limit is taken over the Čech nerve of the covering. This higher‑categorical descent is expressed in HoTT by a HIT that adds higher paths encoding the cocycle conditions. The resulting object is an ∞‑stack, and when the underlying presheaf is representable (i.e., comes from an affine scheme) the stack is a scheme.

Derived schemes arise by allowing the structure sheaf to take values in connective E∞‑ring spectra rather than ordinary commutative rings. The univalence axiom ensures that equivalences of ring spectra induce equivalences of the associated affine derived schemes, preserving the homotopical information. This perspective has been formalised in the UniMath library, where the notion of a “spectral scheme’’ is built as a stack on the ∞‑category of connective E∞‑rings.

Exam‑relevant competencies include:

  • Describing a sheaf on the Zariski site as a HIT with point, glue, and coherence constructors.
  • Stating the stack condition in terms of equivalence of a type with the limit over its Čech nerve.
  • Explaining how univalence guarantees uniqueness of glued objects and coherence of descent data.

Cubical Agda and the Computational Interpretation of Univalence

Cubical Agda implements a version of cubical type theory in which the univalence axiom computes by definition. The core idea is to replace the abstract path type Id A x y with a primitive interval type I whose elements are names for points on a line segment. A path p : Path A x y is a function p : I → A with p i0 = x and p i1 = y. The interval carries two endpoints i0 and i1 and a composition operation comp that fills open boxes, giving the Kan filling condition directly in the syntax. Because equivalences are represented as functions with explicit inverses and homotopies, the univalence constructor ua : (A ≃ B) → Path U A B reduces to a term that transports along the equivalence by pattern matching on the interval. This makes transport compute: transport (ua e) a reduces to e .fst a without any axiom. The cubical primitives hcomp and transp provide homogeneous and heterogeneous composition, respectively, and they satisfy the required equations judgmentally. In practice, this means that proofs using univalence can be executed, and extracted programs contain no stuck terms. The price is a more complex metatheory: one must prove canonicity for the cubical language, which was achieved by showing that every closed term of natural number type reduces to a numeral. For exam preparation, students should be able to explain the role of the interval, the definition of Path as a function type, the difference between hcomp and transp, and why univalence becomes a definitional equality in this setting.

Higher Inductive Types for Homotopy Colimits and Pushouts

Higher inductive types (HITs) generalize ordinary inductive types by allowing constructors that produce not only points but also paths and higher paths. A homotopy pushout of a span A ← f → B → g → C is a HIT Pushout f g with point constructors inl : B → Pushout f g and inr : C → Pushout f g and a path constructor glue : ∀ a : A, inl (f a) = inr (g a). The elimination principle states that to define a function out of the pushout into a type X it suffices to give functions u : B → X, v : C → X and a homotopy h : ∀ a, u (f a) = v (g a). This matches the universal property of a homotopy colimit in an ∞‑category. More generally, any finite diagram can be turned into a HIT by adding a point constructor for each object and a path constructor for each morphism, together with higher constructors for commutative triangles, squares, and so on. The resulting type is the homotopy colimit of the diagram. In cubical type theory the Kan filling structure guarantees that such HITs are fibrant, provided the constructors satisfy a positivity condition. A subtle point is that the naive HIT for a quotient by an arbitrary relation may fail to be a set; one must either truncate the result or use a set‑quotient HIT that adds a 1‑truncation constructor. For exam questions, be ready to write the constructors for the homotopy pushout, state its recursion and induction principles, and explain why the path constructor glue is necessary to capture the homotopical universal property rather than the ordinary categorical pushout.

Worked Example: Homotopy Pushout of the Circle
Define the circle S¹ as the homotopy pushout of the span 1 ← ! → 1 → ! → 1 where 1 is the unit type and ! the unique function. Write the HIT constructors and derive the induction principle for S¹.

The span consists of three copies of the unit type 1 and the unique maps ! : 1 → 1. The pushout HIT S¹ has:

  • Point constructors base₁ : S¹ and base₂ : S¹ (the images of the two outer 1s).
  • Path constructor loop : base₁ = base₂ (the image of the middle 1 via glue).

Because the two outer points are definitionally equal after the pushout, we can identify base₁ and base₂ as a single point base. The resulting HIT is exactly the usual circle with one point base and one loop loop : base = base. The induction principle: given a type family P : S¹ → U, a point p₀ : P base and a path p₁ : transport P loop p₀ = p₀, there exists a section f : ∀ x : S¹, P x with f base = p₀ and apd f loop = p₁. This matches the standard circle induction.

If the diagram contains commutative squares, add a 2‑path constructor for each square. Remember that the induction principle always quantifies over a family P and requires coherence data matching every constructor. Synthetic Homotopy Theory of Spheres: Whitehead Products and the Freudenthal Suspension Theorem

In synthetic homotopy theory the spheres Sⁿ are defined as higher inductive types: S⁰ is the boolean type, S¹ has a base point and a loop, and for n ≥ 1 the suspension Σ Sⁿ yields Sⁿ⁺¹. The homotopy groups πₖ(Sⁿ) are defined as the set‑truncation of the loop space Ωᵏ Sⁿ. A central result is the Freudenthal suspension theorem: the suspension map πₖ(Sⁿ) → πₖ₊₁(Sⁿ⁺¹) is an isomorphism for k < 2n‑1 and a surjection for k = 2n‑1. In HoTT this theorem is proved by analyzing the connectivity of the map Sⁿ → Ω Σ Sⁿ and using the Blakers–Massey theorem, which itself is a statement about the connectivity of a pushout square. The Whitehead product [α, β] : πₚ₊q‑1(Sⁿ) for α : πₚ(Sⁿ) and β : π_q(Sⁿ) is defined synthetically by using the fact that the smash product Sᵖ ∧ S^q is equivalent to Sᵖ⁺q and the commutator of the two maps Sᵖ → Ωⁿ Sⁿ and S^q → Ωⁿ Sⁿ. In cubical Agda the Whitehead product can be computed for low dimensions, confirming classical results such as [ι, ι] = 2 η in π₃(S²). For examinations, students should be able to state the Freudenthal theorem precisely, outline the role of the Blakers–Massey theorem in its proof, and define the Whitehead product using the smash product and loop space structure.

Univalent Foundations for Real Numbers and Constructive Analysis

The real numbers can be constructed in HoTT as a higher inductive‑inductive type ℝ equipped with a Cauchy‑complete metric space structure. One approach defines ℝ as the quotient of Cauchy sequences of rationals by the equivalence relation of vanishing difference; the quotient is a set‑quotient HIT that adds a path constructor for each pair of equivalent sequences and a truncation constructor to force the result to be a set. An alternative, due to Booij and Escardó, uses a HIT with constructors for rational points, a limit constructor for Cauchy approximations, and a path constructor expressing the Cauchy condition. Univalence ensures that any two constructions of the reals that are equivalent as Cauchy‑complete ordered fields are equal in the universe, so the choice of construction is irrelevant for mathematics. With the real numbers in hand, one develops synthetic topology: the open intervals form a basis, and the type of open sets is defined as a predicate U : ℝ → Prop satisfying the usual axioms. The intermediate value theorem, the Heine–Borel theorem, and the fundamental theorem of calculus have all been formalised in UniMath and the HoTT library. A key point for exams is that the constructive reals do not satisfy the law of excluded middle for equality; x = y is a proposition but not decidable. Consequently, many classical proofs must be reformulated using apartness relations or locatedness. Students should be able to sketch the HIT for the reals, explain why univalence makes the construction unique up to equivalence, and describe how the lack of decidable equality affects the statement of the intermediate value theorem.

Guarded Recursion and Clocked Type Theory in Homotopy Type Theory

Guarded recursion introduces a modality ▹ (later) that delays computation, allowing the definition of coinductive types such as streams without violating strong normalization. Clocked type theory extends this by indexing the later modality with clocks κ, written ▹_κ, and providing a forcing operation that advances a clock. In the presence of univalence, guarded recursion interacts with higher inductive types: one can define a guarded HIT where some constructors are placed under ▹, yielding types that compute their higher structure only after a finite number of clock ticks. This technique has been used to give a constructive model of the real numbers as a guarded Cauchy completion, and to formalise the synthetic version of the Baire category theorem. The key metatheoretic result is that clocked type theory with univalence remains consistent and enjoys canonicity for closed natural numbers. For exam purposes, be prepared to explain the difference between ordinary guarded recursion (single later) and clocked recursion (multiple clocks), to write the typing rules for ▹_κ and the forcing operator, and to describe how a guarded HIT for streams of natural numbers would be declared.

Univalent Categories and the Rezk Completion

In HoTT a univalent category is a precategory whose type of objects is a 1‑type and whose identity type between objects is equivalent to the type of isomorphisms. This condition, called the univalence condition for categories, mirrors the univalence axiom for types and ensures that equivalent categories are equal in the universe of categories. The Rezk completion constructs, for any precategory C, a univalent category Ĉ together with a fully faithful essentially surjective functor C → Ĉ. The construction proceeds by taking the type of objects of Ĉ to be the Rezk type of C, i.e. the type of objects of C equipped with a proof that the canonical map from the identity type to the isomorphism type is an equivalence. This is a higher inductive type with a constructor for each object of C and a path constructor witnessing the univalence condition. The hom‑sets of Ĉ are defined as the hom‑sets of C transported along the new paths. The universal property states that any functor from C to a univalent category factors uniquely through Ĉ. In practice, the Rezk completion is used to turn a precategory of structures (e.g. groups, rings) into a univalent category where equality of objects coincides with isomorphism, allowing transport of structure along equivalences without coherence overhead. Formalisations in UniMath and the HoTT library show that the completion preserves limits and colimits that exist in C, and that the Yoneda embedding lands in the univalent completion. For examinations, be prepared to define the Rezk type, state the universal property, and explain why the completion is necessary for a well‑behaved category theory inside HoTT.

Synthetic Spectra and Stable Homotopy Theory in HoTT

Stable homotopy theory studies spectra, which are sequences of pointed types X₀, X₁, X₂, … equipped with equivalences Xₙ ≃ Ω Xₙ₊₁. In HoTT a spectrum can be defined as a higher inductive type with a constructor for each level and a path constructor expressing the loop‑space equivalence. The suspension spectrum functor Σ^∞ sends a pointed type A to the spectrum whose n‑th space is Σⁿ A. The loop‑space functor Ω^∞ extracts the zeroth space. The smash product of spectra is defined by a HIT that enforces the expected adjunction with the function spectrum. Using univalence, one proves that the category of spectra is a stable ∞‑category: it has finite limits and colimits, the suspension functor is an equivalence, and fibre sequences coincide with cofibre sequences. The Freudenthal suspension theorem appears as a connectivity estimate for the map X → Ω Σ X in the synthetic setting, and the Blakers–Massey theorem provides the crucial pushout connectivity needed for the proof. Synthetic spectra have been used to compute low‑dimensional stable homotopy groups of spheres, e.g. π₁^S = ℤ/2, π₂^S = ℤ/2, π₃^S = ℤ/24, by constructing the sphere spectrum as a HIT and applying the long exact sequence of a cofibre sequence. In proof assistants, the sphere spectrum is defined as a sequential colimit of suspensions of the circle, and the stable homotopy groups are obtained by truncating the loop spaces. For exams, know the definition of a spectrum as a HIT, the statement that Σ^∞ ⊣ Ω^∞, and the role of the Blakers–Massey theorem in establishing stability.

Technique: Constructing the Sphere Spectrum as a HIT
Define the sphere spectrum 𝕊 in HoTT using a higher inductive type. Show that its zeroth space is equivalent to the circle S¹ and that the structure maps are equivalences.
Define 𝕊 as a sequential HIT with constructors: base₀ : 𝕊₀, loop₀ : base₀ = base₀ (making 𝕊₀ ≃ S¹). For each n : ℕ, a constructor suspₙ : 𝕊ₙ → 𝕊ₙ₊₁ and a path constructor equivₙ : Σ 𝕊ₙ ≃ 𝕊ₙ₊₁ witnessing that 𝕊ₙ₊₁ is the suspension of 𝕊ₙ. The structure map σₙ : 𝕊ₙ → Ω 𝕊ₙ₊₁ is obtained by adjunction from equivₙ. By induction on n, each σₙ is an equivalence because Σ ⊣ Ω and equivₙ is an equivalence. Hence 𝕊 is a spectrum. The zeroth space 𝕊₀ is exactly S¹ by the first two constructors.
Exam‑day strategy
When a question asks for a synthetic definition of a spectrum, write the HIT constructors explicitly: point constructors for each level, suspension constructors, and equivalence constructors. Then state the adjunction Σ ⊣ Ω and argue that the structure maps are equivalences by induction. This pattern appears in both proof‑assistant formalisations and written exams.

Higher Inductive Types for Quotient Inductive‑Inductive Types

A quotient inductive‑inductive type (QIIT) simultaneously defines a type and a family of types over it, together with constructors that may refer to both the type and the family, and with path constructors that impose equivalence relations on both levels. The classic example is the definition of the Cauchy real numbers as a QIIT: one defines a type ℝ and a family of relations ≈ : ℝ → ℝ → Prop by mutual induction, with constructors for rational points, limits of Cauchy approximations, and a path constructor stating that two Cauchy approximations with vanishing difference are equal. The truncation constructor forces ℝ to be a set. QIITs generalise ordinary HITs by allowing the inductive family to be defined at the same time as the base type, which is essential for structures where the equivalence relation depends on the type being constructed (e.g. the type of sets with a partial order and the order relation itself). In cubical type theory, QIITs admit a computational interpretation because the path constructors can be given Kan filling operations that respect the mutual dependency. The elimination principle for a QIIT states that to define a function out of the base type and a dependent function out of the family, it suffices to provide cases for each point constructor and to show that the path constructors are respected. This principle is used to prove that the Cauchy reals form a Cauchy‑complete ordered field and that any two such constructions are equivalent, hence equal by univalence. For examinations, be able to write the mutual inductive signature of a QIIT, state its elimination rule, and explain why the truncation constructor is needed to obtain a set‑level quotient.

Cubical Sets as a Model of HoTT: Kan Filling and Composition

The category of cubical sets (presheaves on the cube category □) provides a constructive model of HoTT in which the univalence axiom holds definitionally. Objects are families of sets Xₙ for each dimension n, with face maps ∂ᵢ^ε : Xₙ → Xₙ₋₁ and degeneracy maps σᵢ : Xₙ → Xₙ₊₁ satisfying the cubical identities. The interval I is represented by the representable presheaf y(1). A type in the model is a cubical set equipped with a Kan composition structure: for every open box (a partial element defined on all faces except one) there exists a filler, and composition operations satisfy coherence laws. The identity type Id_A(a,b) is interpreted as the exponential A^I evaluated at the endpoints, i.e. paths in the cubical set. The Glue type constructor implements univalence: given an equivalence e : A ≃ B, Glue B [ (i=0) ↦ A, e ; (i=1) ↦ B, id ] yields a type equal to B but with a path to A. Kan filling for Glue is defined by transporting fillers along the equivalence. The model validates function extensionality, propositional truncation, and all higher inductive types that can be presented as colimits of representables. Importantly, the model is constructive: it does not assume classical logic, and the composition operations are computable, giving a computational interpretation of univalence. For exams, know the definition of the cube category, the notion of a Kan cubical set, how the interval I is represented, and the role of the Glue type in interpreting univalence.

Modal Type Theory for Cohesion and Differential Cohesion in HoTT

Cohesive homotopy type theory extends HoTT with a string of adjoint modalities ♭ ⊣ ♯ ⊣ ʃ (flat, sharp, shape) that capture the idea of a cohesive ∞‑topos. The modality ♭ sends a type to its discrete reflection, ♯ to its codiscrete reflection, and ʃ to its shape (fundamental ∞‑groupoid). These modalities satisfy ♭ ʃ ≃ ♭ and ʃ ♯ ≃ ʃ, and they are idempotent monads/comonads. Differential cohesion adds a further adjoint quadruple ℜ ⊣ ℑ ⊣ & ⊣ ʃ (reduction, infinitesimal shape, infinitesimal flat, shape) where ℜ extracts the reduced part of a type (removing infinitesimal thickening) and ℑ identifies infinitesimally close points. The interaction of these modalities yields a synthetic theory of differential geometry: a type X is a formal smooth ∞‑groupoid if the unit X → ℑ X is an equivalence. The infinitesimal disk bundle of X is the fibre of X → ℑ X, and its sections are vector fields. In HoTT, these modalities can be introduced as higher inductive types with appropriate constructors, or as reflective subuniverses. The de Rham coefficient object ♭dR B G is defined as the fibre of ♭ B G → B G, and differential cohomology is the mapping type into this object. Formalisations in Agda‑flat and Cubical Agda have shown that the modalities satisfy the expected adjunctions and that the synthetic Stokes theorem holds. For examinations, be prepared to list the adjoint modalities, state their idempotency and interaction laws, and explain how ℜ and ℑ give a synthetic notion of infinitesimal neighbourhood.

The Simplicial Set Model and Voevodsky's Univalence Proof

The simplicial set model, constructed by Voevodsky in 2009–2010, was the first model to validate the univalence axiom and thereby prove the consistency of Homotopy Type Theory relative to ZFC with two inaccessible cardinals. The model interprets types as Kan complexes — simplicial sets with the right lifting property against all horn inclusions Λⁿₖ Δⁿ. A universe U is interpreted as a Kan complex whose n-simplices are Kan fibrations over Δⁿ with small fibres. The identity type Id_A(a,b) is interpreted as the path space A^Δ¹ ×A×A (a,b), where the endpoints are fixed by the evaluation maps at 0 and 1. The crucial construction is the universal Kan fibration π : Ũ → U, where Ũ is the simplicial set of pairs (A, a) with A : U and a : A. Univalence is witnessed by a map ua : Id_U(A,B) → Equiv(A,B) that is shown to be a weak equivalence of Kan complexes. The proof proceeds by constructing, for any equivalence e : A ≃ B, a path in U connecting A and B. This path is obtained by taking the nerve of the equivalence, viewed as a simplicial map between the fibres, and using the fact that the universe classifies Kan fibrations. The model uses the Joyal model structure on simplicial sets for the (∞,1)-categorical semantics, but the Kan–Quillen model structure suffices for the type-theoretic interpretation. The two inaccessible cardinals are used to ensure that the universe U is a Kan complex in a larger universe, avoiding size issues. For examinations, be able to state the definition of a Kan complex, describe the universal fibration, and explain why the univalence map is a weak equivalence. The model is not constructive — it uses classical logic and the axiom of choice — which distinguishes it from the cubical set model.

The Blakers–Massey Theorem and Connectivity in HoTT

The Blakers–Massey theorem is a cornerstone of synthetic homotopy theory in HoTT, giving a precise connectivity estimate for the comparison map from a pushout to the homotopy pushout. In HoTT, given a span of types A ← C → B where the left map is n-connected and the right map is m-connected, the pushout square is (n+m)-cartesian: the canonical map from C to the pullback of the pushout is (n+m)-connected. The theorem was first formalized in HoTT by Favonia, Finster, Licata, and Lumsdaine (2016) using a clever encode-decode argument with a generalized "code" family that tracks the connectivity of paths in the pushout. The proof proceeds by constructing a family P : Pushout → Type such that the fibre over the basepoint is contractible and the total space is (n+m)-connected. The key insight is to define P on the pushout by higher induction, using the connectivity hypotheses to fill the required squares. The theorem has numerous applications: it implies the Freudenthal suspension theorem (the suspension map π_k(X) → πk+1(ΣX) is an isomorphism for k < 2n-1 when X is n-connected), the Eilenberg–MacLane space construction K(G,n) for abelian groups G, and the calculation of homotopy groups of spheres. In the formalization, the connectivity of a map f : A → B is defined as the largest n such that all fibres of f are (n-1)-connected. A type is n-connected if its (n-1)-truncation is contractible. The Blakers–Massey theorem in HoTT is stronger than the classical version because it holds for all types, not just spaces, and the proof is entirely synthetic — no topological spaces or simplicial sets are invoked. For exams, know the statement of the theorem, the definition of n-connectedness, and how the encode-decode method is adapted to prove connectivity estimates. Be prepared to sketch the construction of the code family for the pushout.

Encode-Decode for Blakers–Massey Connectivity
Let f : A → B be n-connected and g : C → B be m-connected. Let P be the pushout of A ← C → B. Construct a family Code : P → Type such that Code(inl(a)) is the fibre of f over the basepoint, Code(inr(b)) is the fibre of g, and the glue constructor uses the connectivity hypotheses. Show that the total space Σ(p:P). Code(p) is (n+m)-connected.
Define Code by higher induction on P. For inl(a), set Code(inl(a)) := Fib_f(a) (the fibre of f at a). For inr(b), set Code(inr(b)) := Fib_g(b). For the glue constructor glue(c) : inl(f(c)) = inr(g(c)), we need a path Code(inl(f(c))) = Code(inr(g(c))). By univalence, this is an equivalence Fib_f(f(c)) ≃ Fib_g(g(c)). Both fibres are contractible because f(c) is in the image of f and g(c) in the image of g, and the connectivity hypotheses imply the fibres are (n-1)- and (m-1)-connected respectively. The total space Σ(p:P). Code(p) is equivalent to the homotopy pullback of the span of fibres, which is (n+m)-connected by the classical Blakers–Massey theorem for spaces, but here the equivalence is constructed synthetically using the encode-decode equivalence between paths in P and elements of Code. The (n+m)-connectivity of the total space implies the comparison map C → A ×_P B is (n+m)-connected.
Exam Strategy for Connectivity Proofs
When asked to prove a connectivity result in HoTT, first state the definition of n-connected map and n-connected type. Then identify the pushout or pullback square involved. The encode-decode method requires constructing a code family on the target type; the constructors of the code family mirror the constructors of the target. For Blakers–Massey, the code family is defined on the pushout. Always check that the code family respects the glue constructors by providing equivalences between fibres — this is where the connectivity hypotheses are used. In written exams, a clear diagram of the span and the pushout with connectivity labels earns partial credit even if the full proof is incomplete.

Two-Level Type Theory: Strict and Homotopical Layers

Two-Level Type Theory (2LTT), introduced by Voevodsky and developed by Altenkirch, Kaposi, and others, extends HoTT with a second, strict equality type =_s (called "strict equality" or "judgmental equality") alongside the homotopical identity type =_h. The strict layer behaves like extensional type theory: it satisfies uniqueness of identity proofs (UIP), function extensionality holds definitionally, and the strict equality is proof-irrelevant. The homotopical layer is standard HoTT with univalence and higher inductive types. The two layers interact via a "reflection" rule: from a strict equality a =_s b one can derive a homotopical path a =_h b, but not conversely. This allows one to reason about strict structures (such as categories with strict composition) while still having access to homotopical reasoning. The strict layer is typically interpreted as the "external" equality of the metatheory, while the homotopical layer is the "internal" equality of the object theory. A key application is the definition of (∞,1)-categories as categories in the strict layer enriched over types in the homotopical layer. The Rezk completion can be performed entirely in the strict layer, yielding a univalent category where the object type is a 1-type. Another application is the formalization of the simplicial set model inside HoTT: the strict layer handles the combinatorial structure of simplicial sets, while the homotopical layer handles the Kan filling conditions. The syntax of 2LTT includes two judgment forms: Γ ⊢ a =_s b : A (strict) and Γ ⊢ p : a =_h b (homotopical). The strict equality is a congruence for all type formers, and the homotopical identity type satisfies the usual J-eliminator. The reflection rule is: if Γ ⊢ a =_s b : A then Γ ⊢ refl_h : a =_h b. There is also a "strictness" modality ♯_s that sends a type to its strict reflection, making all paths strict. The consistency of 2LTT is established by a model in presheaves over a category of contexts with two equality relations. For examinations, understand the motivation for two equality types, the reflection rule, and the distinction between strict and homotopical reasoning. Be able to explain why 2LTT does not collapse to extensional type theory (the homotopical layer retains univalence and higher paths).

Univalent Foundations for Category Theory: Displayed Categories and Bicategories

Beyond the Rezk completion of precategories into univalent categories, HoTT provides a robust framework for higher category theory via displayed categories and bicategories. A displayed category over a base category B consists of a type of objects Ob_D(b) for each b : B, and for each f : b → b' a type of displayed morphisms Hom_D(f, x, y) for x : Ob_D(b), y : Ob_D(b'). Composition and identities are strictly associative and unital in the displayed layer. The total category ∫ D has objects Σ(b:B). Ob_D(b) and morphisms (f, f̂) where f̂ : Hom_D(f, x, y). This construction, formalized by Ahrens and Lumsdaine, allows one to build categories with strict structure (e.g., the category of categories) while keeping the base univalent. A univalent displayed category over a univalent base yields a univalent total category. Bicategories in HoTT are defined as types of objects with hom-types that are categories (not sets), and composition functors that are associative and unital up to coherent isomorphism. The coherence data are paths in the hom-categories, which are themselves 1-types. The pentagon and triangle identities hold as paths between paths. The univalence axiom for bicategories states that the type of equivalences between two objects is equivalent to their identity type. This is a higher-dimensional version of the Rezk condition. The formalization of bicategories in HoTT (by Ahrens, Kapulkin, and Shulman) uses the fact that the type of categories is a 1-type, so the coherence conditions are manageable. A key result is that every bicategory is equivalent to a strict 2-category (a category enriched over categories with strict associativity), but the equivalence requires the axiom of choice. In HoTT, one can avoid choice by working with displayed bicategories. For exams, know the definition of a displayed category, the total category construction, and why displayed categories are useful for building univalent categories with strict structure. Be able to state the univalence condition for a bicategory and explain how it generalizes the Rezk condition for categories.

The Cumulative Hierarchy as a Higher Inductive Type: Interpreting ZFC in HoTT

The cumulative hierarchy V of Zermelo–Fraenkel set theory can be constructed in HoTT as a higher inductive type, providing an interpretation of ZFC (with choice) inside univalent foundations. The HIT V has constructors: for any type A : U and any function f : A → V, there is an element sup(A, f) : V (the supremum of the family f). The equality on V is generated by the axiom of extensionality: sup(A, f) = sup(B, g) iff there is an equivalence e : A ≃ B such that f = g ∘ e. This is a higher inductive-inductive definition because the equality is defined mutually with the type. The resulting type V is a 1-type (its identity types are sets). The membership relation x ∈ y is defined as Σ(a:A). x = f(a) for y = sup(A, f). One can then prove that V satisfies the axioms of ZFC: extensionality holds by definition, pairing, union, power set, and separation are constructed using the type-theoretic counterparts, and replacement follows from the fact that V is closed under sup of families indexed by any type. The axiom of choice holds because every surjection in HoTT splits (by the axiom of choice in the metatheory, or by using the fact that V is a set and the surjection has a section). The interpretation is not conservative: HoTT proves statements about V that are not provable in ZFC, such as the existence of a universe of sets. However, the fragment of HoTT that talks only about V is equiconsistent with ZFC. This construction, due to Shulman and others, shows that univalent foundations can serve as a foundation for all of mathematics, including set theory. For examinations, be able to write the HIT signature for V, state the extensionality constructor, and explain how the ZFC axioms are verified. Know that V is a 1-type and that the membership relation is a proposition. Be prepared to contrast this with the set-theoretic construction of V_α by transfinite recursion on ordinals.

The Homotopy Hypothesis and the Internal Language of ∞‑Topoi

The homotopy hypothesis, formulated by Grothendieck in Pursuing Stacks, asserts that ∞‑groupoids model homotopy types. In HoTT this becomes a theorem: the ∞‑category of types in a univalent universe is an ∞‑topos, and every ∞‑topos arises as the ∞‑category of sheaves of types on an ∞‑site. The internal language of an (∞,1)‑topos is precisely Martin‑Löf type theory with univalent universes and higher inductive types. This equivalence, established by Shulman, Lumsdaine, and others, means that any statement proved in HoTT holds in every (∞,1)‑topos, and conversely any (∞,1)‑topos validates the rules of HoTT. The key technical result is that the syntactic (∞,1)‑category of a HoTT theory is the free (∞,1)‑topos generated by the signature. For examiners, the distinction between the syntactic (∞,1)‑category (built from contexts and substitutions) and the semantic (∞,1)‑category (a model such as simplicial sets or cubical sets) is critical. The soundness theorem states that the interpretation functor from the syntactic to any semantic (∞,1)‑topos preserves the (∞,1)‑categorical structure: finite limits, colimits, exponentials, subobject classifier, and universe objects. The completeness theorem (for 1‑toposes) does not lift directly to ∞‑toposes because the internal logic of an ∞‑topos is not classical; however, the conservativity of HoTT over the theory of ∞‑groupoids is known for certain fragments. A practical consequence: when formalizing mathematics in HoTT, one may reason internally to an arbitrary ∞‑topos, and the resulting theorems are automatically valid in all models, including the classical simplicial set model and the constructive cubical set model. This internal reasoning is what makes synthetic homotopy theory possible: one proves theorems about spheres, homotopy groups, and fibration sequences using only the type‑theoretic rules, without ever constructing a specific model.

Propositional Resizing, Universe Polymorphism, and the Consistency of Resizing Axioms

In Martin‑Löf type theory with a cumulative hierarchy of universes U₀ : U₁ : U₂ : …, a proposition P : Uᵢ may not be equivalent to any proposition in a lower universe Uⱼ (j < i). The propositional resizing axiom asserts that every proposition is equivalent to one in U₀ (or in the lowest universe). This is not provable in plain HoTT; it is an additional axiom that simplifies the management of universe levels. A stronger form, impredicative propositional resizing, states that the type of all propositions Prop = Σ (P : U₀). isProp P itself lives in U₀, making Prop impredicative. Voevodsky showed that propositional resizing is consistent with HoTT by constructing a model in the simplicial set model where Prop is interpreted as the subobject classifier of the 1‑topos of 0‑truncated objects. However, impredicative resizing combined with univalence and higher inductive types can lead to inconsistency if not handled carefully: the combination of impredicative Prop, univalence, and the circle S¹ allows one to derive a contradiction via a variant of Girard's paradox (Coquand, 2013). The safe approach adopted in Cubical Agda and Lean 4 is universe polymorphism: definitions are parameterized by universe levels, and the type checker infers the minimal level required. Resizing rules are then added as optional axioms, typically restricted to mere propositions (h‑level 1) and not to arbitrary types. The propositional truncation ‖A‖ of a type A : Uᵢ lands in Uᵢ; resizing allows one to assume ‖A‖ : U₀. This is essential for formalizing set‑level mathematics (e.g., the real numbers as a quotient of Cauchy sequences) without universe level explosion. For examinations, know the statement of the resizing axiom, the difference between predicative and impredicative resizing, the consistency result via the simplicial set model, and the paradox that arises from impredicative Prop + univalence + S¹. Be able to explain why universe polymorphism is the pragmatic solution in proof assistants.

Synthetic Homotopy Theory of Eilenberg–MacLane Spaces and Cohomology Operations

In synthetic homotopy theory, an Eilenberg–MacLane space K(G,n) for an abelian group G and n ≥ 1 is defined as a type K(G,n) with πₙ(K(G,n)) ≃ G and all other homotopy groups trivial. In HoTT this is constructed as a higher inductive type: for n=1, K(G,1) is the classifying type BG of the group G (a 1‑type with a single point and loop space G). For n>1, one uses the suspension iteratively: K(G,n) ≃ Σⁿ⁻¹ K(G,1) when G is discrete, but for general G (e.g., ℤ) the direct HIT definition is K(G,n) with a point base and for each g : G an n-loop loop_g : Ωⁿ base = base satisfying the group laws up to coherent higher paths. The cohomology group Hⁿ(X;G) is then defined as π₀(X → K(G,n)), the set of connected components of the mapping type. This definition automatically satisfies the Eilenberg–Steenrod axioms (except the dimension axiom, which fails for n=0 because K(G,0) is the discrete type G). The power of the synthetic approach is that cohomology operations become simply functions between mapping types. For example, the Steenrod square Sq¹ : Hⁿ(X;ℤ/2) → Hⁿ⁺¹(X;ℤ/2) is induced by a map K(ℤ/2,n) → K(ℤ/2,n+1) constructed synthetically using the cup product and the Bockstein homomorphism. The cup product itself arises from the diagonal X → X × X and the multiplication K(G,n) × K(H,m) → K(G⊗H, n+m) (for G,H abelian). In the formalization by Brunerie, Licata, and others, the Steenrod squares are defined using the synthetic cup‑i products on cubical sets, which compute definitionally. A landmark result is the synthetic proof of the Adem relations for Steenrod squares, which in classical topology require intricate simplicial arguments; in HoTT they follow from the algebraic properties of the cup‑i products in the cubical model. For examinations, be able to define K(G,n) as a HIT, state the synthetic definition of cohomology, explain how cup product and Steenrod operations are maps between Eilenberg–MacLane types, and know that the Adem relations have been formally verified in Cubical Agda.

The Structure Identity Principle and the Univalence Axiom: From Isomorphism to Equivalence

The Structure Identity Principle (SIP) is the informal mathematical maxim that "isomorphic structures are identical." In set‑theoretic foundations this is false: two isomorphic groups are distinct sets. In category theory, SIP holds for objects of a category up to unique isomorphism, but the isomorphism is not an equality. Univalence makes SIP a formal theorem: for any type A : U equipped with structure (e.g., a group structure), the type of structures on A is a structure type Str(A), and the identity type Str(A) = Str(B) is equivalent to the type of structure‑preserving equivalences between A and B. The precise formulation, due to Aczel and developed by Coquand, Danielsson, and others, uses the notion of a signature for algebraic structures. A signature Σ specifies a list of operations with arities; a Σ-structure on a type A is an interpretation of the operations. The type of Σ-structures on A is Str_Σ(A) = Σ (s : …). …. The univalence axiom for structures states that the canonical map (Str_Σ(A) = Str_Σ(B)) → Equiv_Σ(A,B) is an equivalence, where Equiv_Σ(A,B) is the type of equivalences e : A ≃ B that preserve the structure. This is proved by showing that Str_Σ is a univalent family over the universe, which follows from the fact that the structure constructors are fibrations and univalence for the universe lifts to the total space. The SIP is the conceptual heart of univalent foundations: it justifies the mathematical practice of identifying isomorphic objects. In formalization, it means that when one constructs the type of groups Group = Σ (G : U). GroupStructure G, the identity type Group = Group is exactly the type of group isomorphisms. This eliminates the need for transport across isomorphisms: one can simply rewrite using the equality. For exams, distinguish between the univalence axiom (for the universe) and the structure identity principle (for structured types). Know that SIP is a theorem derived from univalence, not an independent axiom. Be able to sketch the proof: the structure type is a Σ‑type over the universe, the identity type of a Σ‑type is a Σ‑type of identities, and univalence converts the identity of the underlying types into an equivalence, which then extends to the structure because the structure is a property (a proposition) or a structure (a type) that respects equivalence.

Higher Inductive Types as Free Algebras: Signatures, Elimination, and the General Schema

The meta‑theory of higher inductive types (HITs) is governed by a general schema that specifies which HITs are admissible. A HIT signature consists of a list of point constructors c_i : Π (x : Γ_i). A and path constructors p_j : Π (y : Δ_j). (u_j = v_j) where u_j, v_j are terms built from the point constructors and variables. The elimination principle for a HIT A states that to define a function f : A → B into a type family B : A → U, it suffices to give: (1) for each point constructor c_i, an element f(c_i) : B(c_i); (2) for each path constructor p_j, a path f(p_j) : transport^B(p_j, f(u_j)) = f(v_j) in the fiber. The computation rules are judgmental equalities for point constructors and propositional equalities for path constructors (in Book HoTT) or judgmental in cubical type theory. The general schema, formulated by Lumsdaine and Shulman, requires that the path constructors are well‑formed: the endpoints u_j, v_j must be terms of the HIT in the context Δ_j, and the whole signature must be strictly positive (no negative occurrences of the HIT in the constructor types). This ensures the existence of an initial algebra in the category of algebras for the signature. The initiality theorem states that the HIT is the initial algebra for its signature, which implies the elimination principle and its uniqueness up to homotopy. For quotient inductive‑inductive types (QIITs), the schema is extended to allow mutual definitions of a type and its equality (e.g., the Cauchy reals). The consistency of the general schema is proved by constructing a model in the category of cubical sets, where HITs are interpreted as higher inductive types in the model (a semantic HIT). For examinations, know the components of a HIT signature, the statement of the elimination principle, the difference between judgmental and propositional computation rules, the strict positivity condition, and the role of initiality. Be able to write the signature for the circle S¹, the interval I, the pushout, and the propositional truncation ‖A‖.

Glue Types and the Computational Content of Univalence in Cubical Type Theory

In cubical type theory, the univalence axiom is not postulated as an axiom but derived as a theorem using Glue types. A Glue type Glue [ φ ↦ (T, w) ] A allows one to glue a type A to a family of types T along a cofibration φ, where each w : Equiv T A is an equivalence. When φ = 1, the Glue type is definitionally equal to T; when φ = 0, it is definitionally equal to A. The univalence proof constructs a path ua(e) : Path U A B for any equivalence e : Equiv A B by defining ua(e) i = Glue [ (i = 0) ↦ (A, idEquiv) ; (i = 1) ↦ (B, e) ] A. At i = 0 this reduces to A, at i = 1 to B, and the Kan composition structure of Glue types provides the necessary filler for the path. The crucial computational rule is that transport (ua(e)) a reduces to e.1 a (the forward direction of the equivalence), making univalence computational. This means that in Cubical Agda, transporting along a path obtained from univalence computes by applying the equivalence, not by getting stuck on an axiom. The Glue type constructor is equipped with a composition operation that satisfies the Kan condition: given a partial element u : Partial φ (Glue [ ψ ↦ (T, w) ] A) and a base u₀ : Glue [ ψ ↦ (T, w) ] A extending u, composition produces an element in Glue [ ψ ∨ φ ↦ (T, w) ] A. The algorithm uses the equivalences w to transport the problem to A, composes there using A's Kan structure, and transports back. This is why cubical type theory achieves canonicity: every closed term of natural number type reduces to a numeral, even in the presence of univalence and higher inductive types. For examinations, distinguish between Book HoTT (where univalence is an axiom and transport computes only up to propositional equality) and cubical type theory (where transport (ua(e)) a ≡ e.1 a judgmentally). Know the typing rule for Glue: if Γ ⊢ φ : F, Γ ⊢ A : U, and Γ, φ = 1 ⊢ T : U with Γ, φ = 1 ⊢ w : Equiv T A, then Γ ⊢ Glue [ φ ↦ (T, w) ] A : U. Be able to explain how the unglue operation projects a Glue type to its base A and how glue constructs elements of a Glue type from partial data.

Higher Inductive Types for n-Truncation, Localization, and Reflective Subuniverses

Beyond the basic HITs (circle, interval, pushout, truncation), the general schema admits higher inductive types that present reflective subuniverses. The n-truncation ‖A‖ₙ is a HIT with point constructor |−| : A → ‖A‖ₙ and a path constructor asserting that ‖A‖ₙ is an n-type: for every x y : ‖A‖ₙ and every p q : Ωⁿ⁺¹(‖A‖ₙ, x, y), a path p = q. This makes ‖A‖ₙ the universal n-type receiving a map from A. The elimination principle says that to define f : ‖A‖ₙ → B into an n-type B, it suffices to give f₀ : A → B. Localization at a map f : S → T (or a family of maps) is the HIT L_f A with constructors η : A → L_f A and, for each s : S, a path η(f(s)) = η(f'(s)) (for a family f_i : S_i → T_i, paths η(f_i(s)) = η(f'_i(s))). The universal property: L_f A is the reflection of A into the subuniverse of f-local types (types X such that (− ∘ f) : (T → X) → (S → X) is an equivalence). Reflective subuniverses are subuniverses U' ⊆ U closed under equivalences and equipped with a reflector L : U → U' and a unit η : Id → L such that L(η_X) is an equivalence. In HoTT, every reflective subuniverse is a modality (a left exact reflective subuniverse) if and only if it is closed under Σ-types. The n-truncation modality is left exact; the propositional truncation is left exact; but the double negation modality ¬¬ is not a modality in the sense of left exactness (it does not preserve pullbacks). The localization at a map is a modality iff the map is ∞-connected. For examinations, know the HIT signatures: ‖A‖ₙ has a point constructor and a single (n+2)-ary path constructor (or a family of path constructors for each sphere). Localization L_f has a point constructor and a path constructor for each element of the domain of f. Distinguish between set-truncation ‖A‖₀ (which yields a set) and propositional truncation ‖A‖₋₁ (which yields a mere proposition). The join construction A * B is a HIT that presents the localization at the map A × B → 1; iterated joins A*n give the n-connected cover.

The Internal Language of (∞,1)-Topoi: Geometric Morphisms and Descent

Homotopy type theory with univalent universes and higher inductive types is the internal language of (∞,1)-topoi. An (∞,1)-topos is an (∞,1)-category equivalent to the (∞,1)-category of sheaves of ∞-groupoids on an (∞,1)-site. The correspondence: types in context Γ correspond to objects in the slice (∞,1)-topos ℰ/⟦Γ⟧; dependent types correspond to morphisms; Σ-types correspond to composition; Π-types correspond to dependent product (right adjoint to pullback); identity types correspond to diagonal morphisms; universes correspond to object classifiers; higher inductive types correspond to colimits in the slice. A geometric morphism f : ℱ → ℰ between (∞,1)-topoi consists of an adjoint pair (f* ⊣ f*) where f* : ℰ → ℱ preserves finite limits (is left exact). In the internal language, a geometric morphism corresponds to a modality (a left exact reflective subuniverse) on the target topos, or equivalently, to a lex modality on the source. The inverse image f* is the pullback along the geometric morphism; the direct image f* is the dependent product. Descent in an (∞,1)-topos says that for any effective epimorphism U → X (a cover), the (∞,1)-category of objects over X is the limit of the Čech nerve of U → X. In HoTT, this is expressed by the fact that the type of descent data for a family over the Čech nerve is equivalent to the type of families over X. The object classifier Typeₙ in an (∞,1)-topos classifies relatively n-truncated morphisms; univalence for the universe is the statement that the map from the object classifier to the core of the slice is an equivalence. Local cartesian closure of an (∞,1)-topos corresponds to the existence of Π-types in the internal language. Colimits in an (∞,1)-topos are universal (preserved by pullback), which corresponds to the fact that HITs (which present colimits) are stable under substitution. For examinations, know that the (∞,1)-topos of ∞-groupoids (spaces) is the initial (∞,1)-topos; its internal language is Book HoTT. The (∞,1)-topos of sheaves on a topological space has as internal language HoTT with a spatial modality (the shape modality ʃ and flat modality ♭). The cohesive (∞,1)-topos has an adjoint quadruple (Π ⊣ Disc ⊣ Γ ⊣ coDisc) corresponding to shape, discrete, global sections, and codiscrete modalities. Be able to translate between categorical statements (e.g., "f* preserves finite limits") and type-theoretic statements (e.g., "the modality is left exact"). The diagonal morphism X → X × X corresponds to the identity type family; the path object X^I corresponds to the identity type with its J-eliminator.

Synthetic Homotopy Theory of Classifying Spaces and Principal ∞-Bundles

In synthetic homotopy theory, the classifying space BG of an ∞-group G (a pointed connected type) is defined as the delooping of G: BG is a pointed type with Ω(BG) ≃ G. Every ∞-group arises as the loop space of its delooping, and every pointed connected type is the delooping of its loop space. This equivalence is the homotopy hypothesis for ∞-groups. A principal G-bundle over a type X is a map P → X equipped with a fiberwise G-action that is free and transitive on fibers, or equivalently, a map X → BG. The universal principal G-bundle is the map * → BG (the point inclusion), whose total space is the homotopy fiber of * → BG, which is G itself. The classification theorem states that the type of principal G-bundles over X is equivalent to the type of maps X → BG. In HoTT, this is proved by showing that the type of G-torsors over X (types P with a G-action and an equivalence P/G ≃ X) is equivalent to (X → BG). The construction uses the homotopy quotient P/G, defined as the HIT with constructors |−| : P → P/G and paths |p·g| = |p| for g : G. The associated bundle construction: given a G-action on a type F, the associated bundle P ×_G F → X is the homotopy quotient of P × F by the diagonal G-action. Reduction of structure group along a homomorphism H → G corresponds to pulling back along BH → BG. Characteristic classes in synthetic homotopy theory are maps BG → K(A, n) for an abelian group A; they classify cohomology classes of principal G-bundles. For example, the first Chern class c₁ : BU(1) → K(ℤ, 2) classifies complex line bundles. The homotopy fiber sequence G → * → BG is the universal principal G-bundle; looping gives ΩBG ≃ G. The Whitehead tower of a type X is the sequence of n-connected covers X⟨n⟩ → X; for BG, the Whitehead tower gives the string group, fivebrane group, etc. For examinations, distinguish between a group (a set with group structure) and an ∞-group (a pointed connected type, or equivalently a group object in ∞-groupoids). Know that BG is constructed as a HIT with one point constructor base : BG and one path constructor for each g : G giving a loop at base, but this is circular; the correct definition is BG = Σ (X : U). ‖X ≃ *‖ (the type of pointed connected types) or via the HIT with constructors base : BG and loop : G → (base = base) satisfying group laws up to higher paths. The classification of covering spaces corresponds to the case where G is a discrete group (a set); then BG is a 1-type and principal G-bundles are covering spaces.

The Yoneda Lemma and (∞,1)-Category Theory in Univalent Foundations

Univalent foundations provide a native setting for (∞,1)-category theory where the Yoneda lemma holds in its strongest form. A precategory in HoTT consists of a type of objects Ob, a family of hom-types Hom(a, b) : U, identities, and composition satisfying associativity and unit laws up to propositional equality. A category (or univalent category) is a precategory where the canonical map (a = b) → (a ≃ b) is an equivalence for all a, b — i.e., isomorphism coincides with identity. The Rezk completion of a precategory C is a category Ĉ with a weak equivalence C → Ĉ; it is constructed as a HIT (or as the category of representable presheaves). The Yoneda embedding y : C → Ĉ^op sends c to Hom(−, c); in univalent foundations, this is a fully faithful functor into the category of presheaves (which is a univalent category). The Yoneda lemma states that for any presheaf F : C^op → U and any c : C, the type of natural transformations y(c) → F is equivalent to F(c). In the (∞,1)-categorical setting, this is an equivalence of ∞-groupoids (types), not just a bijection of sets. The proof uses the fact that the identity type of the presheaf category is the type of natural isomorphisms, and univalence for the universe of types makes this work smoothly. Adjoint functor theorem in HoTT: a functor F : C → D between locally small categories has a left adjoint iff it preserves limits and satisfies the solution set condition (which is automatic for accessible categories). The monadicity theorem characterizes categories of algebras for a monad. The category of types Type (or Typeₙ) is a univalent category; its limits are Π-types, its colimits are HITs. The Homotopy Canonicity Problem and Normalization for Cubical Type Theory

In Martin-Löf type theory extended with the univalence axiom as a primitive constant, closed terms of natural number type do not necessarily compute to numerals — univalence introduces a stuck term ua(e) that blocks reduction. This is the canonicity failure of Book HoTT: the system has the existence property (if ⊢ ∃ n : ℕ. P(n) then there is a numeral k with ⊢ P(k)) but not the computational property (closed terms reduce to canonical form). Cubical type theory solves this by making univalence a theorem with computational content via Glue types and a composition structure on the universe. The key insight is that paths in the universe are equivalences, and composition in the universe is given by the equivalence composition operation: given equivalences e : A ≃ B and f : B ≃ C, their composite f ∘ e is an equivalence A ≃ C, and this composition is strictly associative and unital at the level of the composition structure. Normalization for cubical type theory proceeds by a logical relations argument (or a reducibility candidates argument) where one defines a family of computability predicates on terms indexed by types, showing that every well-typed term is computable, hence strongly normalizing. The main technical challenge is the universe level: the computability predicate for U must be defined in a universe one level higher, requiring a universe polymorphism or a Tarski-style universe à la Coquand. In Cubical Agda, normalization is implemented via evaluation to weak head normal form followed by forcing of the composition operations; the transp and hcomp primitives compute by cases on the type formers (Π, Σ, Path, Glue, HITs). For HITs, the computation rules for point constructors are judgmental, while path constructors compute via the Kan filling structure: a path constructor loop : base ≡ base in S¹ reduces when transported along a path in the interval. The canonicity theorem for cubical type theory states: if ⊢ t : ℕ then t reduces to a numeral sucⁿ(zero). This has been proved for a core cubical type theory with Π, Σ, Path, Glue, and a hierarchy of universes (Coquand, Huber, Mörtberg 2018; Sterling, Angiuli 2021). The proof uses a syntactic model in a presheaf category over the cube category with a glueing construction (Artin glueing) to relate syntax to semantics. For examinations, know that Book HoTT lacks canonicity because univalence is an axiom; cubical type theory restores canonicity by giving univalence computational content via Glue types and a composition structure on the universe; normalization is proved by logical relations or syntactic glueing; Cubical Agda implements this via evaluation and forcing.

Synthetic Homotopy Theory of Loop Spaces and the James Construction

The loop space ΩX of a pointed type (X, x₀) is the identity type x₀ = x₀, which carries a natural ∞-group structure (an A∞-space) given by path concatenation. In synthetic homotopy theory, the James construction J(X) provides a free ∞-monoid on a pointed type X, and there is a fundamental equivalence ΩΣX ≃ J(X) for connected X. The James construction is defined as a higher inductive type with constructors: η : X → J(X), ε : J(X) (unit), μ : J(X) × J(X) → J(X) (multiplication), and higher coherence paths expressing associativity, unitality, and the fact that η(x₀) = ε. Equivalently, J(X) can be constructed as the sequential colimit of the diagram X → X ∧ X → X ∧ X ∧ X → … where ∧ is the smash product, but the HIT definition is more direct in HoTT. The equivalence ΩΣX ≃ J(X) is the James splitting: the suspension ΣX is the pushout 1 ← X → 1, and its loop space is the free ∞-group on X. For X = Sⁿ, this gives ΩSⁿ⁺¹ ≃ J(Sⁿ), which is the classical James reduced product. The James filtration Jₖ(X) (the k-fold product) gives a filtration whose associated graded pieces are the smash powers X∧ᵏ, leading to the EHP sequence in homotopy theory. In HoTT, the James construction is used to compute homotopy groups of spheres: πₙ(Sⁿ) ≃ ℤ is proved by showing that the map Sⁿ → ΩSⁿ⁺¹ induced by the suspension is an equivalence on πₙ, which follows from the Freudenthal suspension theorem (which itself can be proved synthetically using the Blakers–Massey theorem). The loop space recognition principle states that a pointed connected type X is equivalent to ΩY for some Y iff X is a grouplike A∞-space (i.e., π₀(X) is a group and the higher homotopy groups have the appropriate action). In HoTT, this is formalized by showing that the type of ∞-groups (pointed connected types) is equivalent to the type of grouplike A∞-spaces. The delooping of an ∞-group G is the type BG = Σ (X : Type). ‖X ≃ *‖ × (ΩX ≃ G), or more directly as a HIT with one point and paths given by G with higher coherences. For examinations, know the definition of J(X) as a HIT, the equivalence ΩΣX ≃ J(X), the James filtration and its connection to the EHP sequence, the loop space recognition principle, and the construction of BG as the delooping of an ∞-group.

Univalent Foundations for Homotopy Limits and Colimits: The ∞-Categorical Perspective

In univalent foundations, homotopy limits and homotopy colimits are not defined as derived functors of ordinary limits/colimits (as in model categories) but directly as universal constructions in the (∞,1)-category of types. A diagram is a functor D : I → Type where I is a (small) type (or a precategory). The homotopy limit holim D is the type of cones over D: Σ (x : Type). Π (i : I). (x → D(i)), which is equivalent to Π (i : I). D(i) when I is a set, but for general I it includes higher coherence data. The homotopy colimit hocolim D is the higher inductive type generated by constructors: for each i : I, a point constructor inᵢ : D(i) → hocolim D, and for each morphism f : i → j in I (if I is a category), a path constructor glue_f : Π (x : D(i)). inᵢ(x) = inⱼ(D(f)(x)), with higher coherences for composition and identities. When I is a Reedy category, the homotopy colimit can be computed by a Reedy cofibrant replacement followed by the ordinary colimit, but in HoTT the HIT definition is primitive. The weighted homotopy limit/colimit generalizes this: for a weight W : I^op → Type, the W-weighted limit of D is the type of natural transformations W → D in the (∞,1)-categorical sense, i.e., the end ∫ᵢ W(i) → D(i). In HoTT, ends and coends are defined as HITs: the end ∫ᵢ F(i,i) is the type of dinatural transformations from the constant functor 1 to F. The Yoneda lemma for (∞,1)-categories gives an equivalence between the W-weighted limit of D and the type of natural transformations W → D. The homotopy Kan extension is the universal way to extend a diagram along a functor: the left Kan extension Lan_F D is the homotopy colimit weighted by the representable functor Hom(F(−), −). In HoTT, this is computed pointwise as a HIT. The adjoint functor theorem for (∞,1)-categories states that a functor between presentable (∞,1)-categories has a left adjoint iff it preserves limits and is accessible. In univalent foundations, the (∞,1)-category of types Type is presentable, and limits are Π-types, colimits are HITs. The Grothendieck construction gives an equivalence between functors I → Type and cocartesian fibrations over I; in HoTT this is the equivalence between type families and their total spaces with the projection map. For examinations, know the definition of homotopy limits as types of cones, homotopy colimits as HITs with point and path constructors, weighted limits/colimits as ends/coends, the pointwise formula for Kan extensions, and the adjoint functor theorem for presentable (∞,1)-categories.

The Univalence Axiom and Proof Irrelevance: Propositional Truncation and the Logic of Mere Propositions

The propositional truncation ‖A‖ (or ‖A‖₋₁) of a type A is the free mere proposition on A: a HIT with constructors |−| : A → ‖A‖ and trunc : Π (x y : ‖A‖). x = y. A type P is a mere proposition (or h-proposition) if Π (x y : P). x = y, i.e., all its elements are equal. The universe of mere propositions Prop = Σ (X : Type). isProp(X) is itself a mere proposition (by univalence). The logic of mere propositions interprets logical connectives as type formers restricted to Prop: conjunction P ∧ Q := P × Q, disjunction P ∨ Q := ‖P + Q‖, implication P → Q := P → Q (function type), universal quantification ∀ (x : A). P(x) := Π (x : A). P(x), existential quantification ∃ (x : A). P(x) := ‖Σ (x : A). P(x)‖. This is the propositions-as-types interpretation with proof irrelevance enforced by truncation. The axiom of choice in this logic is the statement: (∀ x : A. ‖Σ y : B. R(x,y)‖) → ‖Σ f : A → B. ∀ x. R(x, f(x))‖. This is not provable in general HoTT (it implies excluded middle), but the type-theoretic axiom of choice (∀ x : A. Σ y : B. R(x,y)) → Σ f : A → B. ∀ x. R(x, f(x)) is provable (it is just the distributivity of Π over Σ). The law of excluded middle LEM := Π (P : Prop). P ∨ ¬P is independent of HoTT; assuming it makes Prop a Boolean algebra and collapses the distinction between mere propositions and types (every type becomes a set). The propositional resizing axiom states that Prop is equivalent to a type in a lower universe; this is consistent but not provable. The double negation translation embeds classical logic into constructive logic: a classical proposition P is translated to ¬¬P, and classical reasoning is valid for ¬¬-stable propositions. In HoTT, the truncation levels form a hierarchy: (−2)-types are contractible types, (−1)-types are mere propositions, 0-types are sets, 1-types are groupoids, etc. The n-truncation ‖A‖ₙ is the free n-type on A, defined as a HIT with constructors |−| : A → ‖A‖ₙ and a path constructor making ‖A‖ₙ an n-type. For examinations, know the definition of propositional truncation as a HIT, the interpretation of logical connectives in Prop, the distinction between type-theoretic AC (provable) and logical AC (implies LEM), the independence of LEM, the truncation hierarchy, and the propositional resizing axiom.

Cubical Type Theory with Higher Inductive Types: Composition and Kan Operations for HITs

In cubical type theory, higher inductive types are not primitive axioms but are defined by their composition structure (Kan operations). Every type former must support composition (comp) and homogeneous composition (hcomp) operations that satisfy the Kan condition: given a partial element defined on a cofibration (a face of the cube), it can be extended to a total element. For a HIT, the composition structure is defined by case analysis on the constructors. For point constructors, composition is trivial (the point is constant). For path constructors, composition uses the Kan filling of the interval: a path p : x = y is a function p : 𝕀 → A with p(0) = x, p(1) = y; composition of paths corresponds to filling a square in A. For higher path constructors (e.g., a 2-path in a HIT), composition requires filling a cube. The general schema for HITs in cubical type theory (Cavallo, Harper 2019; van Doorn 2018) specifies that a HIT is given by a signature of constructors, each with a boundary (a partial element of the HIT being defined) and a filling operation that extends the boundary to a total element. The elimination principle for a HIT is derived from its composition structure: to define a function out of a HIT, one gives cases for each constructor, and the Kan condition ensures that the function respects the composition structure. The computation rules for point constructors are judgmental; for path constructors, they compute via the transport operation: transport along a path constructor reduces to the given path in the target type. The Glue type is itself a HIT (with constructors glue : Π (i : 𝕀). Partial φ (T i) → Glue [φ ↦ T] A and unglue : Glue [φ ↦ T] A → A) and its composition structure is defined using the equivalence structure of the T i. The univalence theorem in cubical type theory is proved by constructing a path between types A and B from an equivalence e : A ≃ B using Glue: the path is λ i. Glue [ (i=0) ↦ (A, e), (i=1) ↦ (B, id) ] A. Transport along this path computes to the equivalence e. For examinations, know that HITs in cubical type theory are defined by their composition structure; the general schema uses boundaries and fillings; elimination is derived from composition; computation for path constructors uses transport; Glue is a HIT and its composition gives computational univalence.

Cubical Agda's Primitive Interval and Kan Operations

Cubical Agda implements a cubical type theory in which the interval 𝕀 is a primitive type with two endpoints i0 and i1 and a connection structure given by the binary operations ∧ (meet) and ∨ (join). The interval is not a higher inductive type; it is built into the kernel so that every term can be evaluated at a face of the cube by substituting i0 or i1 for a dimension variable. Kan operations — homogeneous composition hcomp and heterogeneous composition comp — are primitive primitives that satisfy the Kan filling condition: given a partial element defined on a cofibration (a union of faces of a cube), there exists a total element extending it. In Cubical Agda the user never writes hcomp directly; instead the elaborator inserts the appropriate composition when a higher inductive type is pattern‑matched or when a path is transported. The composition structure for each type former is defined by recursion on the syntax of the type: for Π‑types composition is pointwise, for Σ‑types it is componentwise, for the universe it uses the Glue construction, and for a user‑defined HIT the composition is generated automatically from the declared constructors. The crucial property is that composition computes by cases on the constructors: a point constructor is constant, a path constructor reduces to filling a square in the ambient type, and a higher path constructor reduces to filling a cube. This computational behaviour yields canonicity for closed terms of natural number type even in the presence of univalence, because transport along a Glue path reduces to the underlying equivalence. The primitive interval also supports a refl path λ i → x and a symmetry operation sym defined by sym p i = p (~ i), where ~ is the De Morgan involution on the interval. The connection structure makes it possible to define composition of paths without invoking the J‑eliminator, and it gives a direct cubical interpretation of the higher groupoid laws (associativity, unit, inverse) as equalities of squares and cubes that compute by definition. For examinations, remember that the interval is primitive, that Kan operations are the semantic heart of cubical type theory, and that the automatic generation of composition for HITs is what distinguishes cubical type theory from Book HoTT where HITs are axioms without computational content.

The Univalence Axiom in the Presence of Classical Axioms

Univalence states that the canonical map ua : (A ≃ B) → (A = B) is an equivalence for all types A and B in a universe. In pure Martin‑Löf type theory this axiom is consistent and does not imply any classical principle. However, when classical axioms such as the law of excluded middle (LEM) or the axiom of choice (AC) are added, subtle interactions appear. Adding LEM for all propositions makes every type a set (0‑type) because any two parallel paths become equal by propositional extensionality; consequently the higher‑dimensional content of univalence collapses and the universe becomes a 1‑type. If one adds only propositional LEM (i.e. LEM for mere propositions) the truncation hierarchy is preserved, but the combination of propositional LEM with univalence still forces all types to be sets if one also assumes proof irrelevance for all propositions. The axiom of choice in its type‑theoretic form (Π x : A. Σ y : B x. C x y) → Σ f : Π x : A. B x. Π x : A. C x (f x) is provable in MLTT and therefore compatible with univalence. The logical form of choice, which quantifies over truncated existentials, implies LEM by Diaconescu’s argument and thus also collapses higher structure. A more refined analysis uses the notion of modalities: the double‑negation modality ¬¬ is a left exact modality, and the subuniverse of ¬¬-modal types validates classical reasoning while still supporting univalence internally. In this modal setting one can work classically inside the modal subuniverse and constructively outside, obtaining a “two‑level” type theory. For examinations, know that univalence does not entail LEM, that adding full LEM trivialises higher homotopy, that type‑theoretic AC is harmless, that logical AC is equivalent to LEM, and that modalities such as ¬¬ provide a controlled way to combine classical and homotopical reasoning.

Formalizing the Hurewicz Theorem in HoTT

The Hurewicz theorem relates homotopy groups to homology groups. In classical algebraic topology it states that for a simply connected space X the first non‑trivial homotopy group πₙ(X) is isomorphic to the first non‑trivial homology group Hₙ(X;ℤ), and the Hurewicz map πₙ(X) → Hₙ(X;ℤ) is an isomorphism for n and an epimorphism for n+1. In HoTT the theorem is formalised for pointed connected types using the synthetic definitions of homotopy groups πₙ(X) ≡ ‖Ωⁿ X‖₀ (the 0‑truncation of the n-fold loop space) and homology defined via the Eilenberg–Mac Lane spaces K(ℤ,n). The Hurewicz map is constructed by iterating the universal coefficient sequence and using the fact that K(ℤ,n) represents ordinary cohomology. The formalisation in the HoTT library (e.g. in the Agda‑HoTT or Lean‑HoTT repositories) proceeds by first proving the Freudenthal suspension theorem synthetically, which gives a range in which the suspension map πₙ(X) → πₙ₊₁(ΣX) is an isomorphism. Using the suspension isomorphism for homology and the naturality of the Hurewicz map with respect to suspension, one reduces the general case to the case n = 2 where the isomorphism can be checked directly on the circle. The proof uses higher inductive types for spheres, truncations, and the Blakers–Massey theorem to control connectivity of pushouts. A key technical point is that the Hurewicz map is defined as a map of sets (0‑types) because both source and target are truncated; the proof that it is an isomorphism therefore takes place in the category of sets, where classical reasoning is available via propositional truncation. For examinations, know the statement of the synthetic Hurewicz theorem, the role of the Freudenthal suspension theorem, the use of the Blakers–Massey theorem for connectivity estimates, and the fact that the proof reduces to the case of the circle by suspension.

The Role of Universe Polymorphism in Univalent Foundations

Universe polymorphism allows definitions and theorems to be stated uniformly across a cumulative hierarchy of universes 𝓤₀ ⊆ 𝓤₁ ⊆ 𝓤₂ ⊆ …. In a univalent foundation each universe is itself a type in the next universe, and the univalence axiom holds at every level. Polymorphism is essential for two reasons. First, it avoids the need to duplicate constructions (e.g. the circle, truncations, Glue types) at each universe level; a single polymorphic definition S¹ : Type 𝓤 works for any 𝓤. Second, it enables the formulation of resizing axioms such as propositional resizing (every mere proposition in 𝓤ᵢ is equivalent to one in 𝓤₀) and the existence of a universe of propositions Prop that is closed under the logical connectives. Without polymorphism, resizing would have to be postulated separately for each level, leading to an infinite schema. In cubical type theory universe polymorphism is implemented by a level polymorphism mechanism in the kernel: each term carries an implicit level variable, and the elaborator solves level constraints generated by cumulativity and by the formation rules of type formers. The consistency of universe polymorphism with univalence has been proved by constructing a model in the category of cubical sets with a hierarchy of Grothendieck universes. A subtle point is that the cumulativity rule A : Type 𝓤ᵢ → A : Type 𝓤ⱼ for i ≤ j must be compatible with the composition structure; this is achieved by defining the composition operation uniformly for all levels. For examinations, be able to explain why universe polymorphism is needed for a practical univalent library, how it interacts with cumulativity and resizing, and why the consistency proof requires a model with a hierarchy of universes rather than a single universe.

The Synthetic Hopf Fibration and Higher Hopf Constructions

The Hopf fibration is the principal circle bundle S¹ → S³ → S² whose total space is the 3‑sphere and whose base is the 2‑sphere. Postnikov and Whitehead Towers in Synthetic Homotopy Theory

Every pointed connected type X in HoTT admits a Postnikov tower … → X⟨n⟩ → X⟨n−1⟩ → … → X⟨0⟩ where X⟨n⟩ is the n-truncation of X and the fiber of X⟨n⟩ → X⟨n−1⟩ is an Eilenberg–Mac Lane space K(πₙ(X), n). Synthetically the tower is constructed by iterating the n-truncation modality ‖–‖ₙ: the map X → ‖X‖ₙ is the universal map from X to an n-type, and its fiber is the n-connected cover X⟨n⟩. The Whitehead tower is the dual construction: X⟨n⟩ is the n-connected cover obtained by killing homotopy groups below n. In HoTT this is built as a higher inductive type with constructors that truncate the lower homotopy groups. Specifically X⟨0⟩ = X, and X⟨n+1⟩ is the HIT generated by a map X⟨n⟩ → X⟨n+1⟩ and, for each k ≤ n, a proof that πₖ(X⟨n+1⟩) is trivial. The fiber of X⟨n+1⟩ → X⟨n⟩ is then K(πₙ₊₁(X), n+1). The two towers are related by the fact that the n-truncation of the n-connected cover is the n-truncation of the original type. A key synthetic tool is the long exact sequence of homotopy groups for a fiber sequence, which in HoTT is derived from the fiber sequence of truncations ‖F‖ₖ → ‖E‖ₖ → ‖B‖ₖ and the fact that truncation preserves fiber sequences up to connectivity. The Postnikov tower classifies n-types over X via cohomology with coefficients in the homotopy groups; the k-invariant of the extension X⟨k⟩ → X⟨k−1⟩ is a class in Hᵏ⁺¹(X⟨k−1⟩; πₖ(X)). In the synthetic setting these k-invariants are constructed as maps X⟨k−1⟩ → K(πₖ(X), k+1) using the universal property of truncation. Synthetic Obstruction Theory and the Construction of Cohomology Operations

Obstruction theory in HoTT is formulated entirely in terms of truncation modalities and fiber sequences. Synthetic Homotopy Theory of Mapping Spaces and Function Types

In HoTT the type of functions A → B is interpreted as the mapping space Map(A,B) in the ambient ∞‑topos. The univalence axiom then upgrades this to an equivalence between the type of equivalences A ≃ B and the identity type A = B, so that the mapping space of equivalences sits as a union of components of Map(A,B).

Higher Inductive Types for Algebraic Structures: Groups, Rings, and Modules

Algebraic structures such as groups, rings, and modules can be presented as higher inductive types whose constructors encode the operations and the axioms as path constructors. A group is a HIT with a point constructor for the unit, a binary operation constructor, an inverse constructor, and path constructors for associativity, unit laws, and inverse laws. Because the axioms are paths, the resulting type is a 1‑type (its identity types are sets), and the elimination principle yields the usual universal property: any map from the free group on a set of generators to a group extends uniquely to a group homomorphism.

Rings are built similarly, adding two binary operations (addition and multiplication), a zero and a one, and path constructors for the ring axioms. The distributivity laws become 2‑dimensional paths, which forces the ring HIT to be a 1‑type as well. Modules over a ring R are then defined as a HIT with an action constructor R × M → M and path constructors for the module axioms. The resulting type of R‑modules is again a 1‑type, and the universal property of the free module on a type X is obtained by a HIT with a point constructor for each element of X and a path constructor for the module operations.

Because the axioms are paths, the usual algebraic reasoning — such as proving that the centre of a group is a subgroup — can be carried out by path induction. For instance, the centre Z(G) is defined as the subtype of elements commuting with every element; the proof that Z(G) is closed under the group operation uses the associativity and commutativity paths directly, without needing to invoke a separate set‑level reasoning. This synthetic approach also makes the construction of quotient groups straightforward: the quotient G/N is the HIT obtained from G by adding a path constructor identifying each n : N with the unit, and the universal property follows from the elimination principle.

In cubical type theory the Kan composition for these algebraic HITs is derived from the composition of the underlying type formers. The path constructors are treated as additional Kan fillers, so that any open box whose sides respect the algebraic laws can be filled uniquely. This gives a computational interpretation of algebraic reasoning: normalising a term in the free group HIT reduces it to a reduced word, and the reduction steps correspond exactly to the Kan filling operations for the associativity and inverse paths.

Examination questions often ask for the list of constructors of the free group HIT, the statement of its elimination principle, and an explanation of why the resulting type is a 1‑type. Be ready to compare this synthetic presentation with the classical set‑theoretic construction via equivalence classes of words, highlighting that the HIT avoids quotienting by a set‑level equivalence relation and instead builds the quotient directly as a higher inductive type.

Technique

The Univalence Axiom and the Computation of Transport in Cubical Type Theory

In cubical type theory the univalence axiom is not an axiom but a theorem: the type of equivalences A ≃ B is definitionally equal to the path type A = B via the glue construction. The glue type Glue [ φ ↦ (T, w) ] A builds a type that is equal to A on the face φ and equivalent to T elsewhere, with the equivalence w : T ≃ A providing the identification. This makes transport along a path p : A = B compute by applying the underlying equivalence of the glue type, yielding a definitional reduction rule for transport.

The computational content of transport is therefore explicit: given p : A = B and a : A, transport p a reduces to the forward direction of the equivalence associated to p applied to a. When p is constructed by the univalence constructor ua(e) for an equivalence e : A ≃ B, transport (ua(e)) a computes to e.1 a, the underlying function of the equivalence. This eliminates the need for an opaque transport term and allows programs to manipulate equivalences directly.

The Kan composition operations for the universe are defined using glue types. To compose a partial family of types over a cube, one forms a glue type that matches the given faces on the boundary and fills the interior by the equivalence data. The composition algorithm proceeds by first composing the underlying types in the base universe (which is itself a Kan type) and then adjusting the equivalences using the homogeneous composition of the equivalence type. This two‑step process ensures that the universe satisfies the Kan condition and that univalence computes.

Because transport computes, the transport‑free proof technique becomes a practical programming pattern: instead of transporting a term along a path, one rewrites the term using the equivalence directly. For example, when proving a property of a family P : A → Type over a type A that is defined as a HIT, one can avoid transport by working with the equivalence between the fibres induced by the path constructors of A. This technique is essential for formalising synthetic homotopy theory in proof assistants such as Cubical Agda, where transport would otherwise introduce opaque terms that block further computation.

Synthetic Homotopy Theory of the Van Kampen Theorem and Fundamental Groupoids

The Van Kampen theorem computes the fundamental groupoid of a pushout of spaces in terms of the fundamental groupoids of the pieces. In HoTT the theorem is proved synthetically by constructing the fundamental groupoid Π₁(X) of a type X as a higher inductive type with point constructors for each point of X and path constructors for each path in X, together with a truncation constructor that forces Π₁(X) to be a 1‑type. The synthetic proof proceeds by showing that Π₁ preserves pushouts of 1‑types. Since Π₁(X) is a 1‑type, the pushout of groupoids can be computed as a HIT with point constructors for the objects of the three groupoids and path constructors for the morphisms, together with the pushout identifications. The elimination principle of this HIT gives exactly the universal property of the pushout in the category of groupoids. The crucial step is to verify that the path constructors coming from the original types satisfy the groupoid laws, which follows from the fact that the original types are 1‑types after applying Π₁.

The wedge S¹ ∨ S¹ is the pushout of two circles along a point, and the Van Kampen theorem yields the free group on two generators.

The synthetic approach also clarifies the role of the basepoint: the fundamental group π₁(X, x₀) is the automorphism group of the object x₀ in Π₁(X). Because Π₁(X) is a groupoid, the automorphism group is a set, and the group structure comes from composition of paths. This avoids the classical need to choose a basepoint and to work with pointed homotopy classes; the groupoid captures all basepoints simultaneously.

Higher Inductive Types for Inductive‑Inductive Definitions and the Syntax of Type Theory

Inductive‑inductive definitions allow a type and a family over that type to be defined simultaneously, each referring to the other. In Martin‑Löf type theory this pattern appears when formalising the syntax of dependent type theory itself: the type of contexts and the type of types in a context are mutually defined. Dybjer and Setzer (1999) gave the first general schema for inductive‑inductive definitions, and Chapman (2009) showed how the raw syntax of Martin‑Löf type theory can be presented as an inductive‑inductive type. In HoTT the same idea is lifted to higher inductive‑inductive types (HIITs), where path constructors can equate syntactic constructs up to definitional equality, enabling a synthetic treatment of substitution and conversion. The HIIT for the syntax of type theory typically has constructors for contexts (empty, extension), types (Π, Σ, identity, universe), and terms (variables, λ‑abstraction, application, pair, projections, reflexivity). Path constructors encode the β‑ and η‑rules as equalities, and higher paths encode coherence of substitution. This yields a model of type theory inside type theory where conversion is propositional rather than definitional, a crucial step for proving metatheoretic results such as normalisation by evaluation inside HoTT. The elimination principle for a HIIT requires a motive that respects all point and path constructors; in practice this means providing a family of types over the syntax together with proofs that the family respects β, η, and substitution coherence. Recent work by Kaposi, Kovács, and Altenkirch (2019) formalised the syntax of cubical type theory as a HIIT in Agda, demonstrating that the cubical interval and composition operations can be represented internally. The construction relies on the fact that the interval 𝕀 is a HIT with a path constructor, and that glue types provide the computational content of univalence. By internalising the syntax, one can prove canonicity for cubical type theory by logical relations defined on the HIIT, avoiding the need for an external semantic model. Examination questions often ask for the signature of the HIIT for contexts and types, the statement of the mutual induction principle, and an explanation of why path constructors for β‑rules make conversion propositional. A typical trap is to confuse inductive‑inductive definitions with ordinary mutual inductive definitions; the former allow the second component to depend on the first, while the latter only allow simultaneous definition without dependency.

Univalent Foundations for (∞,n)-Categories and the Cobordism Hypothesis

The theory of (∞,n)-categories provides the natural setting for the cobordism hypothesis, which classifies fully extended topological quantum field theories. In univalent foundations, (∞,n)-categories can be modelled as complete Segal objects in (∞,n‑1)-categories, or equivalently as Θₙ‑spaces. The univalence axiom ensures that equivalences of (∞,k)-categories are identified with equalities, making the type of (∞,n)-categories a higher groupoid. Lurie’s proof of the cobordism hypothesis uses the (∞,n)-category of bordisms Bordₙ, which is generated by a single object (the point) together with duals for all k‑morphisms. In HoTT, Bordₙ can be constructed as a higher inductive type whose constructors correspond to the generators of the free symmetric monoidal (∞,n)-category with duals. The point constructor gives the object, the 1‑morphism constructors give the interval and its dual, and higher constructors impose the zig‑zag identities up to coherent higher equivalences. The universal property of this HIT states that for any symmetric monoidal (∞,n)-category 𝒞 with duals, the type of symmetric monoidal functors Bordₙ → 𝒞 is equivalent to the type of fully dualizable objects of 𝒞. This is precisely the statement of the cobordism hypothesis. Formalising this in HoTT requires a robust theory of (∞,n)-categories; recent work by Finster, Mimram, and others has developed a synthetic theory of (∞,n)-categories using globular sets and higher inductive types. The key technical ingredient is the construction of the free (∞,n)-category on a computad as a HIT, where the computad specifies generating cells in each dimension. The univalence axiom then guarantees that the resulting type of (∞,n)-categories is univalent, i.e. equivalence of (∞,n)-categories coincides with identity. Examination expectations include the definition of a fully dualizable object in a symmetric monoidal (∞,n)-category, the statement of the cobordism hypothesis as an equivalence of types, and an outline of how Bordₙ is built as a HIT. A common mistake is to assume that the cobordism hypothesis holds for arbitrary (∞,n)-categories without the symmetric monoidal structure and duals; the hypothesis specifically concerns the free symmetric monoidal (∞,n)-category with duals on one object.

Worked Example: Constructing the Free (∞,1)-Category on a Graph as a HIT
Define a higher inductive type FreeCat(G) for a given graph G = (V, E, s, t) that presents the free (∞,1)-category on G. List the point, path, and higher path constructors, and state the universal property.

Point constructors: for each vertex v : V, a point obj(v) : FreeCat(G).

Path constructors: for each edge e : E, a path hom(e) : obj(s(e)) = obj(t(e)).

Higher path constructors: for each composable pair of edges e₁, e₂ with t(e₁) = s(e₂), a 2‑path comp(e₁, e₂) : hom(e₂) ∘ hom(e₁) = hom(e₂ ∘ e₁) (where ∘ on the right is the formal composition in the free category). Additionally, for each vertex v, a 2‑path id(v) : refl(obj(v)) = hom(idₑ) where idₑ is the identity edge at v (if G has identities; otherwise add a generator for identities). Higher coherence paths (associativity, unit laws) are added as 3‑paths, and so on, making FreeCat(G) an (∞,1)-category.

Universal property: For any (∞,1)-category 𝒞, the type of functors FreeCat(G) → 𝒞 is equivalent to the type of graph homomorphisms G → U(𝒞), where U forgets the categorical structure. The equivalence is given by evaluation on generators and extends uniquely because FreeCat(G) is the free (∞,1)-category on G.

Exam‑Day Strategy
When a question asks for a HIT presentation of a free higher categorical structure, first write down the generators (objects, 1‑cells, 2‑cells, …) as point and path constructors. Then add coherence paths exactly mirroring the algebraic laws (associativity, unit, interchange). The universal property is always “maps out of the HIT correspond to structure‑preserving maps on generators”. Memorise this pattern; it applies to free groupoids, free (∞,n)-categories, and free symmetric monoidal categories with duals.

Synthetic Homotopy Theory of the Adams Spectral Sequence in HoTT

The Adams spectral sequence is a central tool in stable homotopy theory for computing stable homotopy groups of spheres. In synthetic homotopy theory, the spectral sequence can be constructed internally using the tower of Eilenberg–MacLane spaces and the associated long exact sequences of homotopy groups. The key idea, developed by Brunerie, Licata, and others, is to define a spectrum as a sequence of types Xₙ with equivalences Xₙ ≃ ΩXₙ₊₁. The sphere spectrum 𝕊 is the suspension spectrum of the circle, built as a higher inductive type with constructors for the suspension and the loop space equivalence. For a prime p, the mod‑p Moore spectrum M(p) is defined as the cofiber of multiplication by p on 𝕊. The Adams tower is then the sequence of fibers of the maps 𝕊 → M(p) → ΣM(p) → Σ²M(p) → … . Each fiber is an Eilenberg–MacLane spectrum H𝔽ₚ, and the homotopy groups of the fibers give the Ext groups Ext𝒜s,t(𝔽ₚ, 𝔽ₚ) where 𝒜 is the Steenrod algebra. In HoTT, the Steenrod algebra acts synthetically on the cohomology of H𝔽ₚ, and the Ext groups can be computed by a synthetic version of the cobar construction. The spectral sequence converges to the p‑completion of the stable homotopy groups of spheres. Formalisation in Cubical Agda has reached the construction of the first few pages of the spectral sequence and the verification of the differential d₂ on the class h₁. Examination questions may ask for the definition of a spectrum as a HIT, the construction of the Moore spectrum, the statement of the Adams spectral sequence as a spectral sequence of types, and the role of the Steenrod algebra in the E₂ page. A frequent trap is to confuse the synthetic Adams spectral sequence with the classical one based on topological spaces; the synthetic version works entirely inside type theory and uses the internal logic of HoTT to manipulate fibers and cofibers.

Cubical Type Theory with Higher Inductive Types for the Construction of the Torus and Higher Tori

The n‑torus Tⁿ is the product of n circles. In cubical type theory, the circle S¹ is a HIT with a point base and a loop loop : base = base. The torus T² can be defined directly as a HIT with a point base, two loops a, b : base = base, and a 2‑dimensional path comm : a ∘ b = b ∘ a expressing the commutativity of the two loops. This presentation makes T² a 1‑type whose fundamental group is ℤ × ℤ. In cubical type theory, the Kan composition for T² is derived from the composition for the interval and the glue construction for the universe, exactly as for S¹. The higher tori Tⁿ are obtained by iterating this pattern: Tⁿ has a point base, n loops ℓ₁,…,ℓₙ, and for each pair i < j a 2‑path commi,j : ℓᵢ ∘ ℓⱼ = ℓⱼ ∘ ℓᵢ, together with higher coherence paths ensuring that all squares commute up to higher homotopy. The resulting type is an n‑type whose homotopy groups are π₁(Tⁿ) ≃ ℤⁿ and π_k(Tⁿ) = 0 for k > 1. The product structure Tⁿ ≃ (S¹)ⁿ can be proved by constructing an equivalence using the universal property of the product HIT and the fact that the loops in the product are the projections of the loops in each factor. In Cubical Agda, the torus HIT is used to demonstrate that the cubical composition algorithm correctly handles higher dimensional path constructors; the Kan filling for a square in T² reduces to filling a square in the interval, which is trivial because the interval is contractible. Examination expectations include the explicit HIT signature for Tⁿ, the statement that Tⁿ is an n‑type with π₁ ≃ ℤⁿ, and the proof sketch that the product of circles is equivalent to the torus HIT. A common error is to omit the higher coherence paths for n ≥ 3; without them the type would not be an n‑type and its homotopy groups would be incorrect.

The Univalence Axiom and the Formalization of Homotopy Limits and Colimits in Cubical Agda

Homotopy limits and colimits are the (∞,1)-categorical analogues of ordinary limits and colimits, defined up to equivalence rather than isomorphism. In univalent foundations, a diagram is a functor D : I → 𝒰 from a small (∞,1)-category I (often presented as a Reedy category) into the universe. The homotopy limit holim D is the type of sections of the associated right fibration, and the homotopy colimit hocolim D is the type of points in the left fibration. In cubical type theory, these constructions can be formalised using higher inductive types that directly encode the universal property. For example, the homotopy pullback of f : A → C and g : B → C is the HIT with constructors (a : A), (b : B), and a path p : f(a) = g(b). The elimination principle states that maps out of the pullback correspond to cones over the cospan. Dually, the homotopy pushout is the HIT with constructors inl : A → P, inr : B → P, and a path glue : ∀ a, inl(a) = inr(f(a)). The univalence axiom ensures that the types of equivalences used in the definitions of fibrations are themselves univalent, so that transport along equivalences computes definitionally via glue types. In Cubical Agda, the library `agda-cubical` provides primitives for `hPullback`, `hPushout`, and more general `hColimit` and `hLimit` for Reedy diagrams. The Kan composition for these HITs is derived from the composition for the interval and the glue construction, guaranteeing that the resulting types are fibrant. Formalisation of the Blakers–Massey theorem in Cubical Agda uses the homotopy pushout HIT and the connectivity estimates provided by the cubical composition algorithm. Examination questions may ask for the HIT definition of a homotopy pullback, the statement of the universal property, and an explanation of how univalence makes transport in the pullback compute as the expected equivalence. A typical trap is to assume that ordinary pullbacks in the category of types coincide with homotopy pullbacks; they do not, because ordinary pullbacks do not respect equivalences of the legs.

Higher Inductive Types for the Construction of Real Projective Spaces in HoTT

Real projective spaces RPⁿ admit a clean higher inductive definition that mirrors their classical cell structure. The HIT RPⁿ has a single point constructor base : RPⁿ, a loop constructor loop : base = base of order two, and for each k ≤ n a k-dimensional cell attached by the appropriate attaching map. In practice one defines RPⁿ by induction on n: RP⁰ is the unit type, and RPⁿ⁺¹ is the homotopy pushout of the diagram Sⁿ → RPⁿ ← 1 where the left map is the double cover Sⁿ → RPⁿ induced by the antipodal action. The double cover itself is a HIT with constructors north, south and a path meridian : north = south that squares to the loop in RPⁿ. This presentation makes the fundamental group π₁(RPⁿ) ≃ ℤ/2 for n ≥ 2 and the higher homotopy groups π_k(RPⁿ) ≃ π_k(Sⁿ) for k ≥ 2. In cubical type theory the Kan composition for RPⁿ is derived from the composition for the interval and the glue construction for the universe; the double cover’s composition reduces to filling a square in the interval, which is trivial because the interval is contractible. The univalence axiom guarantees that the equivalence between the two fibres of the double cover transports definitionally, so that the path loop computes as the non‑trivial element of ℤ/2. Formalisation in Cubical Agda uses the primitive hPushout and the Glue type to build the pushout, and the resulting type is fibrant by construction. Examination questions often ask for the explicit HIT signature of RP², the statement that RPⁿ is an n-type, and a proof sketch that the double cover is a 2‑sheeted covering space. A common error is to omit the higher coherence paths that enforce the relation loop ∘ loop = refl at the level of 2‑paths; without them the type would have a free loop and its fundamental group would be ℤ instead of ℤ/2.

Synthetic Homotopy Theory of the EHP Sequence and the Stable Homotopy Groups of Spheres

The EHP sequence is a classical long exact sequence relating the homotopy groups of spheres πk+n(Sⁿ), πk+n+1(Sn+1) and πk+2n+1(S2n+1). In synthetic homotopy theory the sequence arises from the fibre sequence ΩSn+1 → ΩS2n+1 → ΩSn+1 obtained by looping the cofibre sequence Sⁿ → Sn+1 → S2n+1. The first map is the suspension E : πk+n(Sⁿ) → πk+n+1(Sn+1), the second is the Hopf invariant H : πk+n+1(Sn+1) → πk+2n+1(S2n+1), and the third is the Whitehead product P : πk+2n+1(S2n+1) → πk+n(Sⁿ). In HoTT the suspension of a type X is a HIT with constructors north, south and a path meridian : X → north = south. The Hopf invariant is defined using the join construction X * Y, which is a HIT with constructors inl : X → X * Y, inr : Y → X * Y and a path glue : ∀ x y, inl x = inr y. The synthetic EHP sequence is then a long exact sequence of homotopy groups of these HITs, proved by the usual fibre‑sequence argument using the long exact sequence of a fibration in HoTT. The stable homotopy groups of spheres appear as the colimit of the suspension maps E; in HoTT this colimit is a sequential colimit of types, which can be expressed as a higher inductive type with a point constructor for each stage and a path constructor identifying the suspension of an element with its image in the next stage. Cubical Agda’s hColimit primitive provides the necessary Kan composition, and the univalence axiom ensures that the equivalences used in the colimit are respected by transport. Examination expectations include the HIT definitions of suspension and join, the statement of the synthetic EHP exact sequence, and a sketch of how the stable stems are obtained as a colimit. A typical trap is to confuse the synthetic Hopf invariant with the classical Hopf map S³ → S²; the synthetic version lives entirely inside the type theory and does not refer to any external topological model.

Give the full higher inductive definition of the real projective plane RP², including all constructors up to dimension 2, and explain why the resulting type has fundamental group ℤ/2.
RP² is defined by the following constructors:
  1. base : RP²
  2. loop : base = base (1‑dimensional)
  3. square : loop ∘ loop = refl (2‑dimensional)
The 2‑path square forces the loop to have order two in the fundamental groupoid. By the van Kampen theorem for HITs (formalised as the homotopy pushout of the double cover S¹ → RP¹), the fundamental group of RP² is presented by one generator loop and the relation loop² = 1, i.e. ℤ/2. Higher homotopy groups vanish above dimension 2 because the HIT has no constructors above dimension 2, making RP² a 2‑type.

Cubical Type Theory with Higher Inductive Types for the Construction of the Suspension and Join

The suspension ΣX and the join X * Y are fundamental HITs that generate higher homotopy structure. In cubical type theory both are defined as higher inductive types with Kan composition derived from the interval. The suspension has constructors north : ΣX, south : ΣX and meridian : X → north = south. The join has constructors inl : X → X * Y, inr : Y → X * Y and glue : ∀ x y, inl x = inr y. The Kan filling for a square in ΣX reduces to filling a square in the interval for each x : X, which is trivial because the interval is contractible. For the join, a square involves two variables x : X and y : Y; the composition uses the glue path to transport between the left and right cones, and the Kan condition follows from the composition in the interval together with the fact that the glue constructor is a family of paths. In Cubical Agda the primitives Susp and Join are provided in the standard library, and their composition operations are marked as kan so that the type checker accepts them as fibrant. The univalence axiom interacts with these HITs through the glue construction for the universe: when transporting along an equivalence X ≃ Y, the suspension ΣX is equivalent to ΣY via the map induced on the meridian constructors, and this equivalence computes definitionally because the glue type for the universe reduces the transport to the equivalence on the base. The join satisfies a similar property: (X * Y) ≃ (X' * Y') whenever X ≃ X' and Y ≃ Y'. These computational properties are essential for formalising the EHP sequence, where the Hopf invariant is defined as a map ΣX → X * X and its behaviour under suspension is analysed by transporting along equivalences. Examination questions may ask for the explicit Kan composition algorithm for a square in ΣS¹, the statement that ΣX is a 1‑type when X is a set, and a proof that the join of two connected types is simply connected. A common mistake is to assume that the join of two sets is a set; in fact X * Y is always at least a 1‑type because the glue constructor introduces non‑trivial loops.

Univalent Foundations for Synthetic Differential Geometry: Infinitesimal Shape and the de Rham Stack

Synthetic differential geometry (SDG) can be developed inside HoTT by adding a modality ℑ (infinitesimal shape) that identifies infinitesimally close points. The modality is a left exact reflective subuniverse, presented as a higher inductive type with a constructor η : X → ℑX and a path constructor stating that any map from an infinitesimal object D (e.g. the type of dual numbers) into X factors uniquely through η. The de Rham stack XdR is defined as the coequaliser of the two projections X × D ⇉ X, which in HoTT is a HIT with a point constructor for each x : X and a path constructor identifying (x, d) with x for every d : D. The infinitesimal shape modality satisfies ℑX ≃ (XdR)dR and provides a synthetic notion of formal neighbourhoods. In cubical type theory the modality ℑ can be implemented as a higher inductive type with a Kan composition that uses the fact that D is contractible; the composition for ℑX reduces to composition in X after applying the unique filler for the infinitesimal direction. The univalence axiom ensures that equivalences of types are preserved by ℑ, so that the de Rham stack of a manifold (formalised as a type equipped with a suitable atlas) is again a manifold in the synthetic sense. Formalisation in Cubical Agda uses the modalities library, which provides ℑ as a primitive modality with the required exactness properties. Examination expectations include the HIT signature of the de Rham stack, the statement that ℑ preserves pullbacks, and a sketch of how the tangent bundle of a type X is recovered as the fibre of X → ℑX. A typical trap is to confuse the infinitesimal shape modality with the propositional truncation; ℑ is not a truncation but a localisation at the class of infinitesimal equivalences, and it does not collapse all paths.

Higher Inductive Types for the Syntax of Dependent Type Theory: The Internal Language of Type Theory

The syntax of dependent type theory itself can be encoded as a higher inductive‑inductive type, yielding an initial model of type theory inside HoTT. The HIT‑IIT has two mutually defined components: a type Ty of types and a family Tm : Ty → Type of terms. Constructors include U : Ty (universe), El : Tm U → Ty (decoding), Π : (A : Ty) → (Tm A → Ty) → Ty (dependent product), λ : (A : Ty) → (B : Tm A → Ty) → (f : (a : Tm A) → Tm (B a)) → Tm (Π A B), and similarly for Σ, identity, and higher inductive types. The elimination principle states that any model of type theory (a universe closed under the same constructors) receives a unique morphism from the syntax. This initiality theorem is proved by constructing a logical relations argument inside HoTT, using the univalence axiom to transport equivalences between models. In cubical type theory the syntax HIT‑IIT is fibrant because each constructor’s Kan composition is defined by recursion on the syntax tree, and the glue construction for the universe ensures that transport along equivalences of models computes definitionally. The internal language perspective allows one to reason about type theory *in* type theory: for example, the statement “every term of type Π A B is a function” becomes a theorem about the syntax HIT‑IIT. Formalisation in Cubical Agda uses the induction‑recursion feature to define the syntax and its interpretation simultaneously. Examination questions may ask for the mutual inductive‑inductive signature of the syntax, the statement of the initiality theorem, and an explanation of how univalence is used to prove that the interpretation of the universe is univalent. A common error is to treat the syntax as an ordinary inductive type, forgetting that the term component depends on the type component; this leads to an ill‑formed definition because the constructors for terms refer to types that are being defined simultaneously.
