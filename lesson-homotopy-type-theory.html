Homotopy Type Theory — Univalence, Higher Inductive Types & the Foundations of Mathematics

Homotopy Type Theory (HoTT) is a foundational approach to mathematics that interprets types as spaces in homotopy theory. In this paradigm, the identity type Id_A(a,b) becomes the path space — the collection of paths from point a to point b in the space A. Martin-Löf's dependent type theory provides the logical backbone, while Voevodsky's univalence axiom (equivalent types are equal) introduces a revolutionary principle: isomorphic mathematical structures can be identified. Higher inductive types (HITs) allow the construction of cell complexes — spheres, tori, and pushouts — directly as types. The concept of h-levels stratifies types by homotopical complexity: sets (h-level 2), groupoids (h-level 3), and ∞-groupoids. Voevodsky's simplicial set model provides a rigorous semantics for HoTT, while the emerging field of synthetic homotopy theory proves classical theorems (π₁(S¹) = ℤ, Blakers-Massey) using only type-theoretic reasoning. HoTT has been formalized in proof assistants like Coq, Agda, and Lean, powering applications from the formalization of the Grothendieck l-adic Galois representations to the Atiyah-Singer index theorem.

Part 1

📏 Martin-Löf Type Theory and the Identity Type

Foundations
Dependent Type Theory, Π-Types, Σ-Types, and the Identity Type
Martin-Löf dependent type theory provides the core language of HoTT. Π-types (dependent functions) generalize function types: for a family B: A → 𝒰, the type Π(x:A) B(x) consists of functions f where f(a): B(a). Σ-types (dependent pairs) generalize Cartesian products: Σ(x:A) B(x) consists of pairs (a,b) with a: A and b: B(a). The natural numbers ℕ are an inductive type with 0: ℕ and succ: ℕ → ℕ. The identity type Id_A(a,b), often written a =_A b, is the type of propositions of equality — its terms are proofs that a equals b. The reflexivity constructor refl_a: a = a provides the trivial equality. The J-rule (path induction): given a family C(x,y,p) over x =_A y with a term c(x): C(x,x,refl_x), we can construct J(c; x,y,p): C(x,y,p) for any x, y, and p. This is the elimination principle for the identity type. Homotopical interpretation: types are spaces, terms are points, and Id_A(a,b) is the path space of paths from a to b. The J-rule corresponds to path induction: to prove something about all paths, it suffices to prove it for constant paths. The groupoid laws arise: reflexivity gives identity paths, concatenation composes paths, inversion reverses them — and these satisfy the groupoid axioms up to higher homotopies. The Eckmann-Hilton argument shows that composition of 2-loops is commutative, revealing the ∞-groupoid structure of types. Every type is an ∞-groupoid: it has objects (points), 1-morphisms (paths), 2-morphisms (homotopies between paths), and so on.
In HoTT, types are spaces, terms are points, and the identity type captures the entire homotopical path structure — each type is an ∞-groupoid.
Part 2

🌍 The Univalence Axiom

Univalence
Equivalences, the Map idtoeqv, and the Univalence Axiom
Given two types A and B, the type of equivalences Equiv(A,B) consists of functions f: A → B that have a two-sided inverse — that is, there exists g: B → A such that g∘f ∼ id_A and f∘g ∼ id_B, along with coherence conditions. There is a canonical map idtoeqv: (A =_𝒰 B) → Equiv(A,B) defined by path induction: idtoeqv(refl_A) = id_Equiv(A,A). The univalence axiom (Voevodsky, 2009) asserts that idtoeqv is itself an equivalence — i.e., for any A, B: 𝒰, the map idtoeqv is an equivalence. Hence we have (A =_𝒰 B) ≃ Equiv(A,B): equivalent types are equal. This is the core axiom of HoTT. Consequences: function extensionality — pointwise equal functions are equal (f ∼ g implies f = g). Propositional extensionality — logically equivalent propositions are equal. The universe 𝒰 itself acquires a rich structure: it becomes a classifier for small fibrations in the homotopy sense. The structure identity principle (SIP): isomorphic mathematical structures (groups, rings, graphs, etc.) can be identified as equal — for example, isomorphic groups are equal as group structures on a carrier type. Univalence collapses the distinction between isomorphism and identity, radically changing the foundations of mathematics.
Univalence makes mathematics more "structural": any property preserved under equivalence can be transported along identities — isomorphic objects are indistinguishable.
Part 3

🧮 Higher Inductive Types

HITs
Higher Inductive Types: Circles, Spheres, Suspensions, and Pushouts
Higher inductive types (HITs) extend ordinary inductive types by adding constructors that generate paths (1-dimensional equalities), 2-paths, and so on. The canonical example: the circle S¹ as a HIT — base: S¹, loop: base =_S¹ base. The homotopy group π₁(S¹) = ℤ can be proved synthetically in HoTT using the universal cover of S¹ (encoded as a fibration over S¹). The 2-sphere S² has base: S² and a 2-dimensional loop surf: refl_base = refl_base. The suspension ΣA of a type A has constructors N, S: ΣA, and merid: A → (N =_ΣA S). The pushout of f: C → A and g: C → B is a HIT with constructors inl: A → P, inr: B → P, and glue: (c:C) → inl(f(c)) =_P inr(g(c)). The torus T² can be defined as a HIT with generating loops p, q: base = base and a 2-cell a: p∘q = q∘p (commutativity). The Blakers-Massey theorem in HoTT: for a pushout P of f: C → A and g: C → B, the map from the fiber of f over c to the fiber of g over c (induced by the glue constructor) is (m+n-2)-truncated, where f is m-truncated and g is n-truncated. The van Kampen theorem: the fundamental group of a pushout is the amalgamated free product of the fundamental groups of the input types.
HITs bring the power of algebraic topology into type theory — cell complexes become types, and their homotopy groups can be computed synthetically.
Part 4

🔥 Synthetic Homotopy Theory and Formalization

Synthetic
Homotopy Groups of Spheres, Freudenthal Suspension, Brunerie Number, and Formalization
Synthetic homotopy theory proves classical homotopy-theoretic results using only type-theoretic reasoning inside HoTT. Key results: π₁(S¹) = ℤ and πₖ(S¹) = 0 for k > 1 (the circle's higher homotopy groups vanish). π₂(S²) = ℤ and π₃(S²) = ℤ via the Hopf fibration — a family of circles parametrized by S². The Freudenthal suspension theorem: the suspension map Σ: π_k(Sⁿ) → π_{k+1}(S^{n+1}) is an isomorphism for k < 2n-1. The Brunerie number: π₄(S³) = ℤ/2 — a concrete computational result verified in HoTT using a lengthy cubical computation; the "Brunerie number" refers to an integer β such that π₄(S³) = ℤ/βℤ, and β was computed to be 2. The Serre spectral sequence has been constructed in HoTT, providing a powerful computational tool. Formalization in proof assistants: the UniMath project (Voevodsky et al.) formalizes a large body of mathematics in Coq using univalence. The HoTT library in Coq and Agda provides extensive infrastructure for synthetic homotopy theory. Cubical type theory (Cohen-Coquerot-Huber-Mörtberg) gives a computational interpretation of univalence — unlike the original model, cubical type theory has a canonicity property and enables computation with univalence. Applications to mathematics: the formalization of the Grothendieck l-adic Galois representations (Voevodsky), and the formal proof of the Atiyah-Singer index theorem in Lean. HoTT continues to influence the foundations of mathematics, proof theory, and the development of proof assistants.
HoTT provides a synthetic framework for homotopy theory where classical theorems can be proven and formalized in proof assistants, bridging topology, type theory, and computation.
