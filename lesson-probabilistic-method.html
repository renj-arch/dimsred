The Probabilistic Method — Random Graphs, the Alteration Method & the Lovász Local Lemma

The Probabilistic Method is one of the most powerful and elegant tools in combinatorics, pioneered by Paul Erdős in the 1940s. The basic idea is deceptively simple: to prove that an object with a certain property exists, one defines a probability space over candidate objects and shows that the probability a random object has the desired property is positive. This non-constructive technique has produced spectacular results across Ramsey theory, graph theory, discrepancy theory, and the theory of random graphs. The Erdős–Rényi random graph G(n,p) serves as the canonical probability space. The first moment method (Markov's inequality) shows that if the expected number of "bad" objects tends to zero, then a desirable structure exists almost surely. The second moment method (Chebyshev's inequality or the Paley–Zygmund inequality) handles cases where the expected count diverges but the variance is small relative to the mean. The alteration method — construct a random structure and then delete offending elements — yields improved bounds for Ramsey numbers. The Lovász Local Lemma (LLL) handles situations with many unlikely but mildly dependent bad events. The differential equation method tracks random processes via their expected drift, while concentration inequalities (Chernoff, Azuma, Talagrand) quantify how tightly random variables concentrate around their means.

"If you cannot prove what you want, prove something else and hope it's close enough."
— Paul Erdős
Part 1

📏 The First and Second Moment Methods

Moments
Markov's Inequality, Chebyshev's Inequality, and the Moment Methods
Markov's inequality: for a non-negative random variable X and t > 0, we have P(X ≥ t) ≤ E[X]/t. This simple bound is the foundation of the first moment method. If X counts the number of "bad" configurations and we show E[X] → 0, then P(X = 0) → 1 — the desired structure exists asymptotically almost surely. Example — lower bound on the Ramsey number R(k,k): consider G(n,½) with edges appearing independently with probability ½. For a fixed k-set S, the probability S is monochromatic (all edges present or all absent) is 2·2^{−C(k,2)} = 2^{1−k(k−1)/2}. The expected number X of monochromatic K_k is E[X] = 2·(n choose k)·2^{−C(k,2)}. When n < 2^{k/2}, we have E[X] < 1, so P(X = 0) > 0 — there exists a 2-coloring of K_n with no monochromatic K_k, giving R(k,k) > 2^{k/2}.

Chebyshev's inequality: P(|X − E[X]| ≥ t) ≤ Var(X)/t². The second moment method says: if Var(X)/E[X]² → 0, then P(X > 0) → 1. Equivalently, if E[X²] ∼ E[X]² (i.e., E[X²]/E[X]² → 1), then X concentrates. The Paley–Zygmund inequality: P(X > 0) ≥ E[X]²/E[X²] for non-negative X — useful when E[X] is large but P(X = 0) might still be significant. Example — threshold for triangles in G(n,p): let X be the number of triangles in G(n,p). When p = c/n with c constant, E[X] = (n choose 3)p³ → c³/6. Computing the second moment shows E[X²] ∼ E[X]² + O(E[X]) and thus P(X > 0) → 1 − exp(−c³/6) as n→∞. The threshold for the appearance of a triangle is precisely p = Θ(1/n).
The first moment method shows nonexistence by vanishing expectation; the second moment method shows existence by controlling the variance relative to the mean.
Part 2

🌍 The Alteration Method and Random Graphs

Alteration
Constructing Random Structures, Then Deleting Offending Elements
The alteration method works in two steps: (1) construct a random object, (2) delete elements that violate the desired property, and argue that enough remains. This typically gives better bounds than a direct first-moment approach.

Example — lower bound R(3,k): we want a K₃-free graph on n vertices with no independent set of size k (i.e., α(G) < k). Consider G(n,p) with p = c/n. The expected number of triangles is O(1). For each triangle, delete one vertex; the remaining graph G' is K₃-free on n' ≥ n − O(1) vertices. The independence number α(G') ≤ α(G), and for G(n,c/n), α(G) ≤ (3 log n)/c almost surely. Thus R(3,k) ≥ c'·k²/log²k — the best known lower bound up to constants.

Phase transitions in G(n,p): the random graph G(n,p) undergoes dramatic changes as p grows. When p ≪ 1/n, the graph consists of isolated trees and cycles. At p = 1/n, the giant component emerges — a connected component of size Θ(n). This is the percolation threshold. At p = (log n)/n, the graph becomes connected — the connectivity threshold. At p = (log n + log log n)/n, the graph becomes Hamiltonian — the Hamiltonicity threshold. More generally, for any monotone graph property, there is a sharp threshold function p(n) where the property goes from almost surely false to almost surely true.
The alteration method trades a small number of deletions for a much cleaner structure — a recurring theme in probabilistic combinatorics.
Part 3

🧮 The Lovász Local Lemma

LLL
The Symmetric and General LLL, the Algorithmic LLL, and the Moser–Tardos Theorem
The Lovász Local Lemma (Erdős–Lovász, 1973) is a powerful tool for avoiding "bad" events when each event is unlikely and depends on few other events. Symmetric LLL: let A₁,…,Aₙ be events with P(A_i) ≤ p, and suppose each A_i depends on at most d other events. If ep(d+1) ≤ 1 (equivalently p ≤ 1/(e(d+1))), then P(∩ ̄A_i) > 0 — with positive probability, none of the bad events occur.

General LLL: suppose there exist real numbers x_i ∈ (0,1) such that for each i, P(A_i) ≤ x_i·Π_{j∈N(i)} (1−x_j). Then P(∩ ̄A_i) ≥ Π (1−x_i) > 0. This weighted version is more flexible and often gives better bounds.

Application — k-SAT: for a k-CNF formula where each clause has k distinct literals and each variable appears in at most 2^{k−1}/(ek) clauses, the LLL guarantees satisfiability. Let A_i be the event that clause i is falsified; P(A_i) = 2^{−k}. Each clause shares variables with at most d = k·(2^{k−1}/(ek) − 1) ≈ 2^{k−1}/e other clauses. The condition p ≤ 1/(e(d+1)) holds, so there exists a satisfying assignment.

Algorithmic LLL (Moser–Tardos, 2010): when the events are determined by independent random variables (the variable model), the LLL conditions guarantee that the simple resampling algorithm terminates quickly: sample all variables; while any A_i occurs, resample all variables that determine A_i. The expected number of resampling steps is polynomial in n. The proof uses a beautiful resampling table argument and the analysis of a branching process (the "witness tree").
The LLL transforms the probabilistic method into an algorithmic tool: if bad events are rare and localized, the simple resampling strategy finds a good configuration efficiently.
Part 4

🔥 Concentration Inequalities and the Differential Equation Method

Concentration
Chernoff Bounds, Azuma's Inequality, Talagrand's Inequality, and the Differential Equation Method
Chernoff bounds: for independent X_i ∈ {0,1} with sum S = Σ X_i and μ = E[S], we have P(|S − μ| ≥ εμ) ≤ 2·exp(−ε²μ/3) for 0 < ε < 1, and P(|S − μ| ≥ t) ≤ 2·exp(−2t²/n) for additive deviations. These are exponentially tight and fundamental for random graph analysis.

Azuma–Hoeffding inequality: for a martingale (M_n) with |M_i − M_{i−1}| ≤ c_i, we have P(|M_n − M_0| ≥ t) ≤ 2·exp(−t²/(2Σ c_i²)). This is the workhorse for concentration in random processes — e.g., the vertex-exposure martingale for G(n,p). Example — chromatic number of G(n,½): the vertex-exposure martingale shows χ(G(n,½)) is concentrated within O(√n) of its mean (which is ∼ n/(2 log₂ n)), and Talagrand's inequality sharpens this to O(√n).

Talagrand's inequality: for Lipschitz functions on product spaces, the distribution of f(X) is tightly concentrated around its median. It applies even when the Lipschitz condition holds in a "certificate" sense — the function must satisfy that small changes in many coordinates are needed to alter the output significantly.

The differential equation method (Wormald): to analyze a random process over time, compute the expected change in state variables per step, write a system of differential equations describing the limiting trajectory, and use martingale concentration (Azuma's inequality) to prove the actual process stays close to the deterministic trajectory with high probability. Applications: the random greedy algorithm for finding large independent sets, the evolution of the giant component in G(n,p) (Karp's O(n³) algorithm), the analysis of the random k-SAT threshold, and the behavior of the Erdős–Rényi graph process.

Pseudo-random graphs: graphs that mimic the properties of random graphs without being random. The Paley graphs are canonical examples. The Chung–Graham–Wilson theorem characterizes quasi-random graphs via several equivalent properties (uniform edge distribution, eigenvalue gap, count of 4-cycles). The Lovász–Simonovits theorem relates the mixing rate of random walks on a graph to its spectral gap.
Concentration inequalities quantify the "almost sure" nature of the probabilistic method; the differential equation method converts heuristic mean-field approximations into rigorous theorems about random processes.
