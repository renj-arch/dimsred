The Probabilistic Method — Random Graphs, the Alteration Method & the Lovász Local Lemma

The Probabilistic Method is one of the most powerful and elegant tools in combinatorics, pioneered by Paul Erdős in the 1940s. The basic idea is deceptively simple: to prove that an object with a certain property exists, one defines a probability space over candidate objects and shows that the probability a random object has the desired property is positive. This non-constructive technique has produced spectacular results across Ramsey theory, graph theory, discrepancy theory, and the theory of random graphs. The Erdős–Rényi random graph G(n,p) serves as the canonical probability space. The first moment method (Markov's inequality) shows that if the expected number of "bad" objects tends to zero, then a desirable structure exists almost surely. The second moment method (Chebyshev's inequality or the Paley–Zygmund inequality) handles cases where the expected count diverges but the variance is small relative to the mean. The alteration method — construct a random structure and then delete offending elements — yields improved bounds for Ramsey numbers. The Lovász Local Lemma (LLL) handles situations with many unlikely but mildly dependent bad events. The differential equation method tracks random processes via their expected drift, while concentration inequalities (Chernoff, Azuma, Talagrand) quantify how tightly random variables concentrate around their means.

Part 1

📏 The First and Second Moment Methods

Moments
Markov's Inequality, Chebyshev's Inequality, and the Moment Methods
Markov's inequality: for a non-negative random variable X and t > 0, we have P(X ≥ t) ≤ E[X]/t. This simple bound is the foundation of the first moment method. If X counts the number of "bad" configurations and we show E[X] → 0, then P(X = 0) → 1 — the desired structure exists asymptotically almost surely. Example — lower bound on the Ramsey number R(k,k): consider G(n,½) with edges appearing independently with probability ½. For a fixed k-set S, the probability S is monochromatic (all edges present or all absent) is 2·2^{−C(k,2)} = 2^{1−k(k−1)/2}. The expected number X of monochromatic K_k is E[X] = 2·(n choose k)·2^{−C(k,2)}. When n < 2^{k/2}, we have E[X] < 1, so P(X = 0) > 0 — there exists a 2-coloring of K_n with no monochromatic K_k, giving R(k,k) > 2^{k/2}.

Chebyshev's inequality: P(|X − E[X]| ≥ t) ≤ Var(X)/t². The second moment method says: if Var(X)/E[X]² → 0, then P(X > 0) → 1. Equivalently, if E[X²] ∼ E[X]² (i.e., E[X²]/E[X]² → 1), then X concentrates. The Paley–Zygmund inequality: P(X > 0) ≥ E[X]²/E[X²] for non-negative X — useful when E[X] is large but P(X = 0) might still be significant. Example — threshold for triangles in G(n,p): let X be the number of triangles in G(n,p). When p = c/n with c constant, E[X] = (n choose 3)p³ → c³/6. Computing the second moment shows E[X²] ∼ E[X]² + O(E[X]) and thus P(X > 0) → 1 − exp(−c³/6) as n→∞. The threshold for the appearance of a triangle is precisely p = Θ(1/n).
The first moment method shows nonexistence by vanishing expectation; the second moment method shows existence by controlling the variance relative to the mean.
Part 2

🌍 The Alteration Method and Random Graphs

Alteration
Constructing Random Structures, Then Deleting Offending Elements
The alteration method works in two steps: (1) construct a random object, (2) delete elements that violate the desired property, and argue that enough remains. This typically gives better bounds than a direct first-moment approach.

Example — lower bound R(3,k): we want a K₃-free graph on n vertices with no independent set of size k (i.e., α(G) < k). Consider G(n,p) with p = c/n. The expected number of triangles is O(1). For each triangle, delete one vertex; the remaining graph G' is K₃-free on n' ≥ n − O(1) vertices. The independence number α(G') ≤ α(G), and for G(n,c/n), α(G) ≤ (3 log n)/c almost surely. Thus R(3,k) ≥ c'·k²/log²k — the best known lower bound up to constants.

Phase transitions in G(n,p): the random graph G(n,p) undergoes dramatic changes as p grows. When p ≪ 1/n, the graph consists of isolated trees and cycles. At p = 1/n, the giant component emerges — a connected component of size Θ(n). This is the percolation threshold. At p = (log n)/n, the graph becomes connected — the connectivity threshold. At p = (log n + log log n)/n, the graph becomes Hamiltonian — the Hamiltonicity threshold. More generally, for any monotone graph property, there is a sharp threshold function p(n) where the property goes from almost surely false to almost surely true.
The alteration method trades a small number of deletions for a much cleaner structure — a recurring theme in probabilistic combinatorics.

🧮 The Lovász Local Lemma

LLL
The Symmetric and General LLL, the Algorithmic LLL, and the Moser–Tardos Theorem
The Lovász Local Lemma (Erdős–Lovász, 1973) is a powerful tool for avoiding "bad" events when each event is unlikely and depends on few other events. Symmetric LLL: let A₁,…,Aₙ be events with P(A_i) ≤ p, and suppose each A_i depends on at most d other events. If ep(d+1) ≤ 1 (equivalently p ≤ 1/(e(d+1))), then P(∩ ̄A_i) > 0 — with positive probability, none of the bad events occur.

General LLL: suppose there exist real numbers x_i ∈ (0,1) such that for each i, P(A_i) ≤ x_i·Π_{j∈N(i)} (1−x_j). Then P(∩ ̄A_i) ≥ Π (1−x_i) > 0. This weighted version is more flexible and often gives better bounds.

Application — k-SAT: for a k-CNF formula where each clause has k distinct literals and each variable appears in at most 2^{k−1}/(ek) clauses, the LLL guarantees satisfiability. Let A_i be the event that clause i is falsified; P(A_i) = 2^{−k}. Each clause shares variables with at most d = k·(2^{k−1}/(ek) − 1) ≈ 2^{k−1}/e other clauses. The condition p ≤ 1/(e(d+1)) holds, so there exists a satisfying assignment.

Algorithmic LLL (Moser–Tardos, 2010): when the events are determined by independent random variables (the variable model), the LLL conditions guarantee that the simple resampling algorithm terminates quickly: sample all variables; while any A_i occurs, resample all variables that determine A_i. The expected number of resampling steps is polynomial in n. The proof uses a beautiful resampling table argument and the analysis of a branching process (the "witness tree").
The LLL transforms the probabilistic method into an algorithmic tool: if bad events are rare and localized, the simple resampling strategy finds a good configuration efficiently.

🔥 Concentration Inequalities and the Differential Equation Method

Concentration
Chernoff Bounds, Azuma's Inequality, Talagrand's Inequality, and the Differential Equation Method
Chernoff bounds: for independent X_i ∈ {0,1} with sum S = Σ X_i and μ = E[S], we have P(|S − μ| ≥ εμ) ≤ 2·exp(−ε²μ/3) for 0 < ε < 1, and P(|S − μ| ≥ t) ≤ 2·exp(−2t²/n) for additive deviations. These are exponentially tight and fundamental for random graph analysis.

Azuma–Hoeffding inequality: for a martingale (M_n) with |M_i − M_{i−1}| ≤ c_i, we have P(|M_n − M_0| ≥ t) ≤ 2·exp(−t²/(2Σ c_i²)). This is the workhorse for concentration in random processes — e.g., the vertex-exposure martingale for G(n,p). Example — chromatic number of G(n,½): the vertex-exposure martingale shows χ(G(n,½)) is concentrated within O(√n) of its mean (which is ∼ n/(2 log₂ n)), and Talagrand's inequality sharpens this to O(√n).

Talagrand's inequality: for Lipschitz functions on product spaces, the distribution of f(X) is tightly concentrated around its median. It applies even when the Lipschitz condition holds in a "certificate" sense — the function must satisfy that small changes in many coordinates are needed to alter the output significantly.

The differential equation method (Wormald): to analyze a random process over time, compute the expected change in state variables per step, write a system of differential equations describing the limiting trajectory, and use martingale concentration (Azuma's inequality) to prove the actual process stays close to the deterministic trajectory with high probability. Applications: the random greedy algorithm for finding large independent sets, the evolution of the giant component in G(n,p) (Karp's O(n³) algorithm), the analysis of the random k-SAT threshold, and the behavior of the Erdős–Rényi graph process.

Pseudo-random graphs: graphs that mimic the properties of random graphs without being random. The Paley graphs are canonical examples. The Chung–Graham–Wilson theorem characterizes quasi-random graphs via several equivalent properties (uniform edge distribution, eigenvalue gap, count of 4-cycles). The Lovász–Simonovits theorem relates the mixing rate of random walks on a graph to its spectral gap.
Concentration inequalities quantify the "almost sure" nature of the probabilistic method; the differential equation method converts heuristic mean-field approximations into rigorous theorems about random processes.

The Rödl Nibble and Semi-Random Methods

The Rödl nibble, introduced by Vojtěch Rödl in 1985, is a semi‑random technique for constructing large combinatorial structures such as packings, coverings, and Steiner systems. The idea is to run a random greedy process but to stop it early — after a small fraction of the steps — and then to finish the construction by a deterministic or a second random phase. In the classic nibble one selects a random family of edges (or blocks) from a hypergraph, deletes all edges that intersect the chosen ones, and repeats. Because each step removes only a tiny proportion of the remaining edges, the degree and codegree sequences stay close to their expected trajectories, and concentration inequalities (typically Azuma–Hoeffding or Chernoff bounds) guarantee that the process does not deviate significantly from its mean behaviour.

A key parameter is the nibble size ε, usually taken as a small power of the maximum degree Δ. After O(log Δ) rounds the maximum degree drops from Δ to Δ1−c for some constant c>0, while the number of uncovered vertices shrinks by a factor (1−ε). The method yields asymptotic existence results for designs: for any fixed k and λ there exists a Steiner system S(k, k+1, n) for all sufficiently large n satisfying the necessary divisibility conditions. This was proved by Rödl and later refined by Frankl and Rödl, and by Keevash using the more powerful random greedy algorithm with a “absorbing” phase. The nibble also underpins the proof of the Erdős–Hanani conjecture on packing numbers, and it has been adapted to hypergraph matching problems, giving near‑optimal bounds for the size of a matching in a uniform hypergraph with bounded codegrees.

The semi‑random method extends the nibble by allowing a limited amount of adversarial choice after each random step. One typical pattern: pick a random set of edges, then an adversary (or a deterministic algorithm) deletes a few “bad” edges to maintain a pseudorandom degree distribution. This idea appears in the analysis of the random greedy independent set algorithm, where the adversary removes vertices that would create large degree spikes. The combination of randomness and controlled correction yields stronger concentration than a purely random process, because the adversary can enforce a “smooth” degree profile that is easier to analyse with martingale methods. The technique has been used to prove the existence of large induced subgraphs with prescribed properties, to construct Ramsey graphs with no large cliques or independent sets, and to obtain improved bounds for the Turán density of certain hypergraphs.

In practice, the nibble is implemented by iterating the following loop: while the maximum degree exceeds a threshold, choose each remaining edge independently with probability p = ε/Δ, add the chosen edges to the packing, and delete all edges intersecting them. The expected degree drop per round is (1−p)Δ ≈ e−ε, so after O(log Δ) rounds the degree becomes polylogarithmic. At that point a simple greedy completion finishes the packing. The analysis requires tracking not only degrees but also codegrees (the number of edges containing a given pair of vertices), because codegrees control the variance of the degree evolution. The differential equation method (Wormald) provides a systematic way to prove that the random variables stay close to the solution of a system of differential equations describing the expected trajectories.

Entropy Compression and the Algorithmic Lovász Local Lemma

Entropy compression is a proof technique that transforms a probabilistic existence argument into an efficient algorithm by showing that a random process cannot run forever without violating an information‑theoretic bound. The method was pioneered by Moser and Tardos in their 2010 algorithmic proof of the Lovász Local Lemma (LLL), and later abstracted by Grytczuk, Kozik, and Micek (2013) into a general framework. The core idea: suppose a randomized algorithm repeatedly resamples the variables of a bad event whenever it occurs. Each resampling step can be encoded by a short “log” that records which event was resampled and the new random bits used. If the algorithm ran for too many steps, the log would compress the initial random string beyond its entropy, a contradiction. Therefore the algorithm must terminate quickly, producing a configuration that avoids all bad events.

In the variable model, each bad event A_i is determined by a subset of independent random variables. The Moser–Tardos algorithm starts with a uniformly random assignment, then while some A_i holds, it resamples all variables in the scope of A_i with fresh independent bits. The expected number of resamplings of A_i is at most x_i/(1−x_i) where the x_i satisfy the general LLL condition P(A_i) ≤ x_i ∏j∈N(i) (1−x_j). The proof constructs a witness tree for each resampling, showing that the probability of a given tree is bounded by the product of the x_i. Summing over all trees yields the expected bound. Entropy compression refines this by encoding the entire execution history: the initial random string R of length m bits, the sequence of resampled events, and the fresh random bits used at each step. Because each resampling replaces a block of bits, the total length of the log is at most the number of steps times the maximum scope size. If the algorithm took T steps, the log would have length ≤ T·k + O(log T) where k is the maximum number of variables per event. Since the initial string has entropy m, we must have T·k ≥ m − O(log T), giving a polynomial bound on T.

The entropy compression framework has been applied far beyond the LLL. It yields algorithmic versions of the Lopsided LLL, of the Moser–Tardos algorithm for non‑product probability spaces (e.g., random permutations), and of the “partial resampling” variant where only a subset of variables is refreshed. Notable applications include constructive proofs of the existence of proper colourings of graphs with bounded degree (the algorithmic version of Johansson’s theorem on triangle‑free graphs), of acyclic edge colourings, and of non‑repetitive sequences (Thue’s problem). In each case the compression argument replaces a non‑constructive probabilistic proof with a polynomial‑time algorithm, often with a simpler analysis than the original LLL witness‑tree approach.

A practical limitation is that the compression bound depends on the maximum scope size k. For events that depend on many variables (e.g., global constraints), the log may not compress enough to guarantee polynomial termination. This has motivated the development of “cluster expansion” and “entropy compression with a potential function” techniques, which assign weights to events and show that a carefully chosen potential decreases in expectation. These extensions recover algorithmic LLL results for a broader class of dependency graphs, including those arising in the random k‑SAT threshold and in the analysis of the random greedy independent set algorithm.

Worked Example: Entropy Compression for 3‑SAT
Consider a 3‑CNF formula with n variables and m clauses where each variable appears in at most d clauses. Show that if d ≤ 2k−1/(e k) with k=3, the Moser–Tardos algorithm finds a satisfying assignment in expected polynomial time. Compute the bound on the expected number of resamplings per clause.
For k=3 each clause has probability p = 2−3 = 1/8 of being falsified under a uniform assignment. The symmetric LLL condition is e p (d+1) ≤ 1. Substituting p gives e·(1/8)·(d+1) ≤ 1 ⇒ d+1 ≤ 8/e ≈ 2.94 ⇒ d ≤ 1.94. Since d is integer, the condition holds for d ≤ 1. However the general LLL with x_i = 1/(d+1) gives P(A_i) ≤ x_i (1−x_i)^d. For d=5, x=1/6, RHS = (1/6)(5/6)5 ≈ 0.067 > 1/8, so the condition fails. The known tight bound for 3‑SAT is d ≤ 22/(e·3) = 4/(3e) ≈ 0.49, which is not useful. The correct application uses the asymmetric LLL: set x = 1/(2d). Then P(A)=1/8 ≤ x (1−x)^d ≈ (1/(2d)) e−1/2. This holds for d up to about 5. The expected number of resamplings per clause is x/(1−x) ≤ 1/(2d−1). For d=5 this is ≤ 1/9. Hence the total expected resamplings is O(m). The algorithm runs in expected polynomial time.
Exam‑Day Strategy
When a question asks for an algorithmic version of the LLL, first identify whether the variable model or the permutation model is intended. Write down the symmetric condition e p (d+1) ≤ 1 and the general condition with x_i. If the problem gives a concrete bound on variable occurrences, plug it into the symmetric condition; if it gives a more complex dependency graph, set up the general LLL inequalities and solve for x_i. Remember that the Moser–Tardos expected resampling count for event i is x_i/(1−x_i). For entropy compression, the key step is to argue that a long execution would compress the initial random bits — state the entropy bound clearly: initial entropy = number of random bits; each resampling adds at most log₂(scope size) bits to the log. Equate to get a polynomial bound on the number of steps.

Hypergraph Containers and Their Applications

The hypergraph container theorem, proved independently by Balogh, Morris, and Samotij (2015) and by Saxton and Thomason (2015), provides a powerful structural description of independent sets in uniform hypergraphs. Given a k‑uniform hypergraph H on vertex set V with average degree d and bounded codegrees, the theorem asserts that there exists a family C of subsets of V (the containers) such that: (i) every independent set of H is contained in some C ∈ C; (ii) each container C has size at most (1−δ)|V| for some δ>0 depending on the codegree bounds; (iii) the number of containers is at most exp(O(|V|/d1/(k−1) log d)). This result translates the problem of counting independent sets into a problem of counting containers, which is often much easier because the containers are few and have a simple structure.

The proof uses an iterative “container algorithm”: start with the whole vertex set, repeatedly pick a vertex of high degree in the current hypergraph, add it to a “fingerprint” set, and delete its neighbourhood. The fingerprint size is bounded by O(|V|/d1/(k−1)), and the remaining vertices form a container. The codegree conditions ensure that the algorithm does not delete too many vertices at each step, so the final container is still large. The family of all possible fingerprints yields the container family C. The theorem has been extended to non‑uniform hypergraphs, to hypergraphs with weighted edges, and to the “supersaturation” setting where one counts subsets with few edges rather than independent sets.

Applications are numerous. In extremal combinatorics, containers give a short proof of the Erdős–Kleitman–Rothschild theorem on the number of triangle‑free graphs: the number of triangle‑free graphs on n vertices is 2n²/4+o(n²). In additive combinatorics, they yield the best known bounds for the size of sum‑free subsets of [n] and for the number of subsets of [n] with no three‑term arithmetic progression. In Ramsey theory, containers provide a new proof of the Kohayakawa–Łuczak–Rödl theorem on the Ramsey number of sparse graphs. In theoretical computer science, they imply that the number of satisfying assignments of a k‑SAT formula with bounded variable occurrences is at most 2(1−Ω(1))n, which is used in the analysis of the random k‑SAT threshold. The container method also underlies the recent proof of the Erdős–Sós conjecture for large graphs and the resolution of the Cameron–Erdős conjecture on sum‑free sets.

A key technical point is the trade‑off between the codegree bounds and the container size. If the maximum codegree Δ₂ is too large relative to the average degree d, the containers may not be significantly smaller than V. The theorem requires Δ₂ ≤ d1−ε for some ε>0, or more generally that the ℓ‑codegrees satisfy Δ_ℓ ≤ d1−(ℓ−1)/(k−1)+o(1). When these conditions fail, one can sometimes apply a “supersaturation” version: instead of independent sets, one counts subsets that contain few edges. This leads to the “robust” container lemma, which has been used to prove the existence of dense subgraphs with prescribed properties in pseudorandom graphs.

The Differential Equation Method for Random Graph Processes

The differential equation method, systematised by Nicholas Wormald in the 1990s, turns heuristic mean‑field approximations into rigorous proofs that a discrete random process stays close to a deterministic trajectory. The method applies to processes where the state at step t can be described by a vector of variables (e.g., the number of vertices of each degree in the random graph process). One writes a system of differential equations for the expected evolution of these variables, assuming that the random fluctuations are negligible. Then one proves, using martingale concentration inequalities such as Azuma–Hoeffding or Freedman’s inequality, that with high probability the actual variables remain within o(n) of the solution of the differential equations for all steps up to the stopping time.

A classic example is the random graph process G(n, m) where edges are added one by one uniformly at random. Let X_k(t) be the number of vertices of degree k after t edges have been added. The expected change in X_k when a new edge is added depends on the current degree distribution. In the limit n→∞ with t = τ n/2, the scaled variables x_k(τ) = X_k(τ n/2)/n satisfy the differential equations dx_k/dτ = (k−1) xk−1 − k x_k for k≥1, with x0(0)=1, x_k(0)=0 for k≥1. The solution is the Poisson distribution with mean τ. Wormald’s theorem guarantees that for any fixed τ, the actual degree distribution is within n−1/3 of the Poisson law with probability 1−o(1). This yields a rigorous derivation of the phase transition at τ=1 (the emergence of the giant component) and of the degree distribution in the supercritical regime.

The method also analyses algorithms. The Karp–Sipser algorithm for finding a large matching in a random graph proceeds by repeatedly picking a vertex of degree 1, matching it with its neighbour, and deleting both vertices; if no degree‑1 vertex exists, it picks a random edge. The state variables are the numbers of vertices of each degree. The differential equations describe the evolution of these numbers, and the solution predicts that the algorithm finds a matching of size n/2 − O(n1/2) in G(n, c/n) for c>e. The analysis uses a “stopping time” argument: one proves that the process stays close to the differential equations until the number of vertices drops below n2/3, at which point a direct combinatorial argument finishes the proof. This technique has been extended to the random greedy independent set algorithm, to the analysis of the random k‑SAT process, and to the evolution of the core in random hypergraphs.

Freedman’s inequality is often preferred over Azuma–Hoeffding because it uses the conditional variance of the martingale increments, giving tighter bounds when the increments are usually small but occasionally large. In the random graph process, the degree of a vertex can jump by more than 1 when an edge is added, but the conditional variance is bounded by the maximum degree. Freedman’s inequality then yields concentration with a variance term that scales with the sum of conditional variances, leading to error bounds of order √(n log n) rather than √n. The differential equation method also requires a “boundedness” condition: the one‑step change in each variable must be bounded by a constant (or at most no(1)). When this fails, one can sometimes truncate the process or use a “self‑correcting” modification, as in the analysis of the random graph process with a power‑law degree distribution.

Lopsided and Asymmetric Lovász Local Lemma Variants

The original Lovász Local Lemma assumes a symmetric dependency graph where each event is mutually independent of all events outside its neighbourhood. In many applications the dependency structure is “lopsided”: an event A may be positively correlated with some events and negatively correlated with others, but the negative correlations can be exploited to weaken the LLL condition. The Lopsided LLL, introduced by Erdős and Spencer (1991) and later refined by Bissacot, Fernández, Procacci, and Scoppola (2011), replaces the dependency graph by a “lopsidependency” graph where an edge i→j indicates that conditioning on the non‑occurrence of A_j can only increase the probability of A_i. The condition becomes P(A_i) ≤ x_i ∏j∈Γ⁺(i) (1−x_j) where Γ⁺(i) is the set of events that positively influence A_i. This often allows a much larger probability bound p because the product runs over a smaller set.

The Asymmetric LLL (also called the General LLL) is the most flexible form: for each event A_i there exists a real number x_i ∈ (0,1) such that P(A_i) ≤ x_i ∏j∈N(i) (1−x_j). Shearer’s condition gives a necessary and sufficient criterion for the existence of such x_i in terms of the independence polynomial of the dependency graph. Specifically, let I(G) be the independence polynomial of the graph G on vertices {1,…,n} with edges representing dependencies. Shearer’s theorem states that the LLL holds for all probability assignments with given upper bounds p_i if and only if the vector (p1,…,p_n) lies in the interior of the Shearer region, which is defined by the positivity of the independence polynomial evaluated at (−p1,…,−p_n). This characterisation is tight: if the vector is outside the region, there exists a probability space and events with those bounds for which the LLL fails.

Algorithmic versions of the Lopsided and Asymmetric LLL have been developed. The Moser–Tardos algorithm works for the variable model under the general LLL condition, and the expected number of resamplings is still bounded by x_i/(1−x_i). For the lopsided case, one can define a “resampling oracle” that resamples only the variables that appear in the positively dependent events. The entropy compression proof adapts by encoding only the resamplings that correspond to positive dependencies. Recent work by Kolmogorov (2016) and by Harris and Srinivasan (2017) gives polynomial‑time algorithms for the Lopsided LLL in the permutation model and for the general LLL with a “commutativity” condition on the resampling operations.

Applications of these variants include the constructive proof of the existence of proper colourings of graphs with maximum degree Δ using (1+o(1))Δ/log Δ colours (the Johansson–Molloy–Reed theorem), the algorithmic version of the “entropy compression” proof for non‑repetitive colourings of graphs, and the analysis of the random k‑SAT threshold where clauses share variables in a highly asymmetric way. In the random k‑SAT setting, the lopsidependency graph is much sparser than the full dependency graph because two clauses that share a variable are negatively correlated when one is satisfied. This yields a better bound on the clause density for which a satisfying assignment exists, matching the known satisfiability threshold up to lower‑order terms.

  • Confusing the symmetric LLL condition e p (d+1) ≤ 1 with the general LLL condition; the symmetric version is a special case and often gives weaker bounds.
  • Assuming the Moser–Tardos algorithm works for any dependency graph without checking the variable model; the algorithm requires that each event is determined by a set of independent random variables.
  • Neglecting the codegree bounds in the hypergraph container theorem; the theorem fails if codegrees are too large relative to the average degree.
  • Applying the differential equation method without verifying the boundedness and Lipschitz conditions on the one‑step changes; unbounded increments invalidate the martingale concentration step.
  • Mixing up lopsided dependency (positive influence) with ordinary dependency; the lopsided condition uses a directed graph of positive influence, not the undirected dependency graph.
  • Forgetting that Shearer’s condition is both necessary and sufficient for the asymmetric LLL; it characterises exactly the region where the LLL holds for all probability spaces with given marginal bounds.
  • Overlooking the need for an absorbing or completion phase in the Rödl nibble; the nibble alone leaves a small uncovered set that must be handled by a separate argument.

These advanced tools extend the probabilistic method from pure existence proofs to algorithmic constructions and precise counting results, and they appear regularly in modern combinatorics examinations.

The Probabilistic Method in Ramsey Theory and the Erdős–Szekeres Bound

The probabilistic method gave the first non‑constructive proof that the Ramsey number R(k,k) grows exponentially in k. Erdős (1947) considered a random two‑colouring of the edges of the complete graph K_n where each edge is coloured red or blue independently with probability 1/2. For a fixed set of k vertices the probability that it forms a monochromatic K_k is 2·2−(k choose 2). There are (n choose k) such sets, so by the union bound the expected number of monochromatic K_k is (n choose k)·21−(k choose 2). If this expectation is < 1 then there exists a colouring with no monochromatic K_k, proving R(k,k) > n. Choosing n = ⌊2k/2⌋ makes the expectation tend to 0 as k grows, yielding R(k,k) > 2k/2. This argument is the prototype of the first moment method: bound the probability that a bad event occurs by the expected number of bad events.

The same idea gives lower bounds for off‑diagonal Ramsey numbers R(s,t). For fixed s and large t, a random graph G(n, p) with p = n−2/(s+1) has expected number of K_s roughly constant while the expected number of independent sets of size t is (n choose t)(1−p)(t choose 2). Optimising p shows R(s,t) = Ω(t(s+1)/2 / (log t)(s+1)/2). The probabilistic method also provides upper bounds via the alteration method: start with a random graph, delete a vertex from each copy of K_s, and the remaining graph has no K_s and relatively few edges, giving an upper bound on the independence number. This interplay between the first moment and alteration underlies the best known asymptotic bounds for many Ramsey‑type problems.

Erdős and Szekeres (1935) proved that any sequence of (r−1)(s−1)+1 distinct real numbers contains an increasing subsequence of length r or a decreasing subsequence of length s. The probabilistic proof considers a random permutation of {1,…,n} and defines the length of the longest increasing subsequence L_n. Using the first moment method on the number of increasing subsequences of length r one shows that if n > (r−1)(s−1) then the expected number of permutations avoiding both patterns is < 1, so such a permutation cannot exist. This classic result illustrates how the probabilistic method can be applied to extremal problems on sequences, not only graphs.

Discrepancy Theory and Spencer's Six Deviations Theorem

Discrepancy theory asks: given a family of subsets of an n‑element set, can we colour the elements red/blue so that each subset is nearly balanced? Formally, for a set system (X, 𝒮) with |X| = n and 𝒮 = {S1,…,S_m}, the discrepancy is disc(𝒮) = min_{χ:X→{−1,1}} maxS∈𝒮 |∑x∈S χ(x)|. The probabilistic method shows that a random colouring gives discrepancy O(√(n log m)) with high probability by Chernoff bounds and the union bound. Spencer (1985) proved the celebrated “six deviations” theorem: for any set system with m = n, disc(𝒮) ≤ 6√n. The proof uses the partial colouring method (also called the entropy method). One iteratively assigns colours to a constant fraction of the uncoloured elements while keeping the discrepancy of every set bounded by O(√n). At each step a random signing of the remaining elements is considered; the Lovász Local Lemma (or a simpler concentration argument) guarantees the existence of a signing that does not increase any set’s discrepancy too much. After O(log n) steps all elements are coloured and the total discrepancy is O(√n).

The constant 6 is not optimal; Bansal (2010) gave a polynomial‑time algorithm based on semidefinite programming that achieves O(√n) and later work reduced the constant to 2√2. The partial colouring technique has become a cornerstone of modern discrepancy theory and has applications in computational geometry (e.g., bounding the discrepancy of axis‑parallel rectangles), in the analysis of rounding algorithms for linear programs, and in the construction of low‑discrepancy sequences for quasi‑Monte Carlo integration. The method also extends to the Komlós conjecture (bounding discrepancy of vectors with ℓ₂ norm ≤ 1) and to the Beck–Fiala theorem (disc(𝒮) ≤ 2t−1 when each element lies in at most t sets).

The Probabilistic Method in List Coloring and Johansson's Theorem

List colouring assigns each vertex v a list L(v) of allowed colours; a proper list colouring chooses a colour from each list so that adjacent vertices receive different colours. The list chromatic number χ_ℓ(G) is the smallest k such that G is k‑choosable (i.e., has a proper list colouring for any assignment of lists of size k). Johansson (1996) proved that for triangle‑free graphs with maximum degree Δ, χ_ℓ(G) = O(Δ / log Δ). The proof uses the probabilistic method in two stages. First, a random partial colouring is created by giving each vertex a random colour from its list with probability p = c log Δ / Δ. Using the Lovász Local Lemma one shows that with positive probability the partial colouring has no conflicts and each uncoloured vertex retains a list of size at least (1−ε)k. Second, the uncoloured subgraph has maximum degree Δ' = O(Δ / log Δ) and can be coloured greedily because its lists are still large. Iterating this nibble (a semi‑random process) yields the final bound.

The result is tight up to the constant factor: there exist triangle‑free graphs with χ_ℓ(G) = Ω(Δ / log Δ). Johansson's theorem was a breakthrough because it showed that the list chromatic number can be much smaller than the maximum degree for sparse graphs, contrasting with the trivial bound χ_ℓ(G) ≤ Δ+1. The method has been extended to graphs with bounded local density, to hypergraph colouring, and to the problem of finding independent transversals in partite graphs. Algorithmic versions based on the Moser–Tardos resampling algorithm give polynomial‑time constructions of the colourings.

A key technical tool is the asymmetric Lovász Local Lemma applied to the bad events “vertex v receives a colour that conflicts with a neighbour”. The dependency graph has degree roughly Δ², but the probability of each bad event is about p² = (c log Δ / Δ)². The LLL condition e p (d+1) ≤ 1 becomes e (c log Δ / Δ)² Δ² ≤ 1, which holds for sufficiently small c. This illustrates how the LLL can handle dependencies that are polynomially large in Δ, a situation where the symmetric LLL would fail.

Derandomization via the Method of Conditional Expectations

The method of conditional expectations converts a probabilistic existence proof into a deterministic polynomial‑time algorithm. Suppose a random variable X is defined on a product probability space Ω = Ω1 × … × Ω_n and we know E[X] ≤ μ. To find an outcome ω with X(ω) ≤ μ, we fix the coordinates one by one. At step i we have already chosen ω1,…,ωi−1. We compute the conditional expectations E[X | ω1,…,ωi−1, ω_i = a] for each a ∈ Ω_i and pick a value a_i that minimises this expectation. Because the overall expectation is a convex combination of the conditional expectations, there always exists a choice that does not increase the expectation. After n steps we obtain a full assignment with X ≤ μ.

This technique derandomises the first moment method. For example, to find a cut of size at least m/2 in a graph with m edges, let X be the number of crossing edges when each vertex is independently placed on the left or right with probability 1/2. E[X] = m/2. The conditional expectation given a partial assignment can be computed in polynomial time (it is a linear function of the unassigned vertices). The algorithm yields a cut of size at least m/2 deterministically. More sophisticated applications include derandomising the Lovász Local Lemma via the Moser–Tardos algorithm, which can be viewed as a conditional expectation argument on a carefully chosen potential function.

Limitations: the method requires that the conditional expectations can be computed efficiently. For many problems (e.g., finding a large independent set in a random graph) the conditional expectation is #P‑hard to compute exactly. In such cases one uses pessimistic estimators — functions that upper‑bound the true conditional expectation and are easy to compute. The method of pessimistic estimators, introduced by Raghavan (1988), extends derandomisation to a wide range of probabilistic constructions, including the algorithmic version of the LLL and the construction of expander graphs.

Random Graph Phase Transitions and the Emergence of the Giant Component

The Erdős–Rényi random graph G(n, p) exhibits a sharp phase transition at p = 1/n. For p = c/n with c < 1, all components have size O(log n) with high probability; for c > 1 there is a unique giant component of size Θ(n) and all other components are O(log n). The probabilistic method proves this by analysing the exploration process of a component starting from a fixed vertex. The process is approximated by a Galton–Watson branching process with Poisson(c) offspring distribution. When c < 1 the branching process is subcritical and dies out quickly, giving logarithmic component sizes. When c > 1 it is supercritical and survives with positive probability ρ(c), the survival probability. The giant component size is concentrated around ρ(c)n.

The differential equation method (Wormald, 1995) gives a rigorous proof of concentration. One tracks the number of vertices of each degree during the exploration and shows that the trajectories follow a system of differential equations with high probability. The method requires bounded one‑step changes and Lipschitz continuity of the expected drift; these hold for G(n, p) because each step reveals at most one new vertex and changes degrees by at most 1. The solution of the differential equations yields the exact size of the giant component as the unique positive root of 1−x = e−cx.

At the critical window p = 1/n + λ n−4/3, component sizes scale as n2/3 and the largest components converge in distribution to the ordered excursions of a Brownian motion with parabolic drift (Aldous, 1997). This scaling limit is a deep result connecting random graphs to continuum stochastic processes. The phase transition also appears in random k‑SAT, where the clause density α = m/n undergoes a satisfiability threshold at α_s ≈ 2^k log 2. The probabilistic method, combined with the first and second moment methods, gives upper and lower bounds on α_s that match up to lower‑order terms.

  • Applying the Lovász Local Lemma without verifying the variable model; the Moser–Tardos algorithm only works when each bad event is determined by a set of independent random variables.

  • Overlooking that Johansson's theorem applies only to triangle‑free graphs; for graphs with triangles the list chromatic number can be as large as Δ.

The Probabilistic Method in Coding Theory: Random Linear Codes and the Gilbert–Varshamov Bound

The probabilistic method provides a clean existence proof for good error‑correcting codes. Let F2 be the binary field. A random linear code of length n and dimension k is obtained by choosing a k × n generator matrix G uniformly from all matrices of rank k. For any non‑zero message x ∈ F2k, the codeword xG is uniformly distributed over F2n \ {0}. The Hamming weight of a random non‑zero vector follows a binomial distribution with parameters n and 1/2. By the first moment method, the expected number of codewords of weight ≤ d − 1 is at most 2k · Vol2(n, d − 1) / 2n, where Vol2(n, r) = Σi=0r C(n, i) is the volume of a Hamming ball. If this expectation is < 1, there exists a linear code with minimum distance at least d. Setting the rate R = k/n and relative distance δ = d/n, the asymptotic Gilbert–Varshamov bound states that for any 0 < δ < 1/2 there exist binary linear codes with rate R ≥ 1 − H2(δ) where H2 is the binary entropy function. The proof uses the standard entropy estimate Vol2(n, δn) ≈ 2nH2(δ). The same argument works for q‑ary alphabets, giving the q‑ary GV bound R ≥ 1 − Hq(δ). The method also yields a simple randomized encoding algorithm: pick G at random, test the distance (which can be done in polynomial time for a given G), and repeat until success. The expected number of trials is constant because the success probability is bounded away from zero. This existential result underpins modern coding theory; it shows that random linear codes achieve the GV bound with high probability, and it motivated the development of explicit algebraic‑geometric codes that meet or beat the bound for certain parameters.

The Probabilistic Method in Property Testing: The Goldreich–Goldwasser–Ron Framework

Property testing asks whether a given object (a function, a graph, a string) satisfies a property or is far from satisfying it, using only a small number of queries. The Goldreich–Goldwasser–Ron (GGR) framework formalises this: a property Π of functions f : {0,1}n → {0,1} is testable with query complexity q(ε) if there exists a randomized algorithm that makes at most q(ε) queries, accepts every f ∈ Π with probability ≥ 2/3, and rejects every f that is ε‑far from Π (i.e., differs from every function in Π on at least ε2n inputs) with probability ≥ 2/3. The probabilistic method enters in two ways. First, to prove upper bounds one often designs a tester that samples random inputs and checks a local constraint; the analysis uses concentration inequalities (Chernoff bounds) to show that if the object is far from the property, a random sample will witness a violation with high probability. The classic linearity test of Blum‑Luby‑Rubinfeld picks random x, y and checks f(x) ⊕ f(y) = f(x⊕y); if f is ε‑far from linear, the test rejects with probability ≥ ε. Second, to prove lower bounds one constructs a hard distribution over functions that are far from the property but look locally like functions in the property. Yao’s minimax principle reduces the problem to showing that any deterministic decision tree of depth q cannot distinguish the two distributions. The probabilistic method supplies the hard distribution: for example, to prove an Ω(1/ε) lower bound for testing monotonicity of Boolean functions on the hypercube, one takes a random function that is a random monotone function perturbed on a random ε‑fraction of points. The analysis uses the second moment method to show that the perturbed function is far from monotone with high probability, while any small set of queries sees a distribution statistically close to that of a truly monotone function. This interplay between random constructions for upper bounds and random hard instances for lower bounds is a hallmark of the GGR framework.

The Probabilistic Method in Random Matrix Theory: The Circular Law and Universality

Random matrix theory studies the eigenvalue distribution of large matrices with independent entries. Let Xn be an n × n matrix whose entries are i.i.d. complex random variables with mean 0 and variance 1. The circular law states that the empirical spectral distribution of Xn/√n converges almost surely to the uniform distribution on the unit disk in the complex plane. The probabilistic method proves this by a combination of moment methods and concentration inequalities. The k‑th moment of the empirical distribution is (1/n) Tr((Xn/√n)k). Expanding the trace yields a sum over closed walks of length k on the complete directed graph; the expectation is non‑zero only for walks where each directed edge appears an even number of times. Counting such pairings gives the Catalan numbers, which are the moments of the circular law. To upgrade convergence in expectation to almost sure convergence, one uses the second moment method on the trace of resolvents or applies Talagrand’s concentration inequality for Lipschitz functions of independent variables. The key technical step is a replacement principle: if two matrix ensembles have matching first four moments, their eigenvalue distributions are close in the sense of smooth test functions. This universality phenomenon, pioneered by Tao and Vu, shows that the circular law holds for any entry distribution with finite (2+ε)‑moment, not just Gaussian. The proof uses a Lindeberg‑type swapping argument combined with a delicate bound on the least singular value of Xn − zI for complex z. The least singular value bound itself is obtained by a probabilistic covering argument on the unit sphere and a small‑ball probability estimate (the Erdős–Littlewood–Offord theorem). Thus the circular law exemplifies how the probabilistic method — moment calculations, concentration, and anti‑concentration — yields universal spectral laws for a vast class of random matrices.

The Probabilistic Method in Percolation Theory: Sharp Thresholds and the Russo–Seymour–Welsh Theorem

Percolation on the square lattice ℤ² considers each edge open with probability p and closed otherwise, independently. The Russo–Seymour–Welsh (RSW) theorem asserts that at the critical probability pc = 1/2, the probability of a left‑right crossing of an n × n square is bounded away from 0 and 1 uniformly in n. The probabilistic method enters through the FKG inequality and the concept of pivotal edges. For any increasing event A, the derivative of its probability with respect to p equals the expected number of pivotal edges for A. Russo’s formula (also called the Margulis–Russo formula) gives d/dp ℙp(A) = Σe ℙp(e is pivotal for A). To prove a sharp threshold, one shows that the sum of pivotal probabilities is large whenever ℙp(A) is bounded away from 0 and 1. The RSW theorem provides the necessary crossing estimates: it guarantees that at p = 1/2 there are both horizontal and vertical crossings with probability ≥ c > 0. Using a gluing argument (the “box‑crossing” technique), one deduces that the probability of a crossing of a rectangle of aspect ratio ρ is bounded below by a function of ρ alone. This uniform bound implies that the expected number of pivotal edges for the crossing event is at least of order n², which by Russo’s formula forces the derivative to be large. Consequently, the crossing probability jumps from ε to 1 − ε over a window of width O(1/n²). The modern proof of sharpness (by Kesten, and later by Bollobás–Riordan) combines RSW with a differential inequality (the OSSS inequality) to obtain quantitative bounds on the threshold window. The probabilistic method thus transforms a geometric crossing statement into a quantitative analytic statement about the derivative of a monotone function, illustrating the deep interplay between combinatorial geometry and probability.

The Probabilistic Method in Discrete Geometry: The Erdős–Moser Problem and Unit Distances

The Erdős–Moser problem asks for the maximum number of unit distances determined by n points in the plane. The probabilistic method gives a lower bound by constructing a random point set. Place n points independently and uniformly in a square of side length L. The expected number of pairs at distance exactly 1 is zero because the distance distribution is continuous. To obtain a discrete construction, one instead considers a random subset of a fine grid. Let G be a √n × √n integer grid scaled so that the spacing is δ = 1/√n. Choose each grid point independently with probability p = c/√n for a suitable constant c. The expected number of chosen points is c√n. The expected number of unit‑distance pairs among chosen points is roughly p² times the number of unit‑distance pairs in the full grid. The grid contains Θ(n) pairs at distance 1 (each point has O(1) neighbours at that distance). Hence the expected number of unit distances is Θ(p² n) = Θ(c²). By the alteration method, we can delete one endpoint from each unit‑distance pair, losing at most O(c²) points, and obtain a set of size Ω(√n) with no unit distances. This shows that the maximum size of a unit‑distance‑free set in an n × n grid is Ω(√n). The same idea, combined with a more careful second‑moment calculation, yields the best known lower bound for the original Erdős–Moser problem: there exist n‑point sets with Ω(n log n) unit distances. The upper bound, due to Spencer, Szemerédi, and Trotter, uses the crossing lemma and gives O(n4/3). The gap remains open, but the probabilistic construction demonstrates that the extremal configuration is not a simple lattice; it must exploit randomness to avoid too many coincidences while still packing many unit distances.

The Probabilistic Method in Additive Combinatorics: Sum‑Product Phenomena and the Erdős–Szemerédi Conjecture

The sum‑product problem asks whether a finite set A of real numbers must have either a large sumset A+A or a large product set A·A. Erdős and Szemerédi conjectured that for every ε>0 there exists cε>0 such that max(|A+A|, |A·A|) ≥ cε|A|2−ε. The probabilistic method enters through random sampling and the construction of sets with few additive or multiplicative relations. A classic construction by Erdős and Szemerédi uses a random subset of a geometric progression: choose each element of {a, a2, …, an} independently with probability p. The expected size of the sumset is controlled by the number of solutions to ai+aj=ak+aℓ, which is small because the representation of an integer as a sum of two powers of a is essentially unique for large a. A second‑moment calculation shows that with positive probability the random set has size Θ(pn) and both sumset and product set of size O(|A|2−δ) for some δ>0, providing a lower bound that matches the conjecture up to the exponent. Later work by Elekes, Nathanson, and Ruzsa refined the exponent using the crossing lemma and incidence geometry, while Bourgain, Katz, and Tao introduced a sum‑product estimate over finite fields using the probabilistic method combined with the polynomial method. The modern approach often combines random sampling with the Balog–Szemerédi–Gowers lemma: one first finds a large subset with small doubling via a random partition, then applies the lemma to extract a structured subset. This interplay between randomness and structure is a hallmark of the probabilistic method in additive combinatorics.

The Probabilistic Method in Random Regular Graphs: Expansion and the Alon–Boppana Bound

Random d‑regular graphs on n vertices are a central model for studying expansion. The configuration model (pairing dn half‑edges uniformly) yields a random d‑regular multigraph; conditioning on simplicity gives the uniform distribution on simple d‑regular graphs. Friedman’s theorem (2003) proved that for any ε>0, a random d‑regular graph has second eigenvalue λ2 ≤ 2√(d−1)+ε with probability tending to 1 as n→∞. This matches the Alon–Boppana lower bound λ2 ≥ 2√(d−1)−o(1), showing that random regular graphs are asymptotically optimal expanders. The proof uses the trace method: 𝔼[tr(Ak)] counts closed walks of length k in the random graph. By analysing the contribution of non‑backtracking walks and using the fact that the expected number of cycles of length ≤ k is bounded, one shows that the spectral radius of the non‑backtracking operator concentrates around √(d−1). The alteration method then removes a small set of vertices to destroy short cycles, yielding a simple graph with the same spectral bound. Applications include the construction of Ramanujan graphs (Lubotzky–Phillips–Sarnak, Margulis) and the analysis of the mixing time of random walks on expanders. The probabilistic method also gives a simple proof that almost all d‑regular graphs have vertex expansion at least (d/2)−O(√d) via the expander mixing lemma and Chernoff bounds on the number of edges between a set and its complement.

The Probabilistic Method in the Random Graph Process: The Achlioptas Process and Explosive Percolation

The Achlioptas process modifies the Erdős–Rényi random graph process by presenting two random edges at each step and allowing the algorithm to choose one according to a rule that tries to delay the emergence of a giant component. The product rule (choose the edge that minimises the product of the sizes of the two components it would join) was conjectured to produce a discontinuous phase transition — “explosive percolation”. Riordan and Warnke (2012) proved that for a wide class of bounded‑size rules, including the product rule, the transition remains continuous: the size of the largest component scales as n2/3 at criticality, just as in the Erdős–Rényi process. The proof uses the differential equation method to track the evolution of the component size distribution. One defines a system of differential equations for the densities of components of each size, shows that the random process stays close to the deterministic trajectory with high probability, and then analyses the critical point of the deterministic system. The key observation is that any rule that only looks at component sizes up to a fixed bound cannot create a discontinuity because the susceptibility (mean component size) diverges continuously. However, if the rule is allowed to use global information (e.g., the sum of squares of component sizes), a discontinuous transition can be forced. This result illustrates how the probabilistic method, combined with the differential equation method, can resolve questions about the nature of phase transitions in random graph processes.

The Probabilistic Method in the Stochastic Block Model: Community Detection and the Kesten–Stigum Threshold

The stochastic block model (SBM) with two equal communities of size n/2 places edges within communities with probability a/n and between communities with probability b/n. The problem of community detection asks whether one can recover the hidden partition better than random guessing from the graph alone. The Kesten–Stigum threshold states that detection is possible iff (a−b)2 > 2(a+b). The probabilistic method proves both directions. For the upper bound (impossibility below the threshold), one uses the second moment method on the likelihood ratio between the planted model and the Erdős–Rényi graph G(n, (a+b)/(2n)). The calculation shows that the second moment remains bounded, implying contiguity of the two models and hence no algorithm can distinguish them. For the lower bound (algorithm above the threshold), one analyses belief propagation (BP) on the graph. The BP update equations linearise around the uninformative fixed point; the spectral radius of the linearised operator is exactly (a−b)/√(a+b). When this exceeds 1, the uninformative fixed point becomes unstable and BP converges to a correlated estimate. A rigorous proof uses the non‑backtracking matrix of the graph: its leading eigenvalue separates from the bulk exactly at the Kesten–Stigum threshold, and the corresponding eigenvector correlates with the true partition. This spectral algorithm achieves detection down to the threshold. The probabilistic method also yields tight bounds for the exact recovery regime (where a, b = Θ(log n)) via Chernoff bounds and the method of types.

The Probabilistic Method in the Hales–Jewett Theorem and Density Hales–Jewett

The Hales–Jewett theorem states that for any r, k there exists N such that any r‑colouring of the kN grid contains a monochromatic combinatorial line. The density version (proved by Furstenberg and Katznelson using ergodic theory, and later by the Polymath project using a purely combinatorial argument) asserts that any subset of [k]N of density δ>0 contains a combinatorial line for sufficiently large N. The probabilistic method enters the combinatorial proof via the density increment strategy: one assumes a dense set A ⊆ [k]N with no lines, then uses a random restriction (fixing a random subset of coordinates) to find a subspace where the density of A increases. Iterating this increment leads to a contradiction because density cannot exceed 1. The random restriction is chosen by independently setting each coordinate to a fixed symbol with probability ε and leaving it free with probability 1−ε. The expected density of A in the restricted subspace is the same as the original density, but the variance can be controlled using the fact that A has no lines. A key lemma (the “correlation with a 12‑insensitive set”) shows that if A has no lines, it must correlate with a set that depends only on a small number of coordinates. This correlation is detected by a probabilistic sampling argument: pick a random subspace of dimension m and test whether the density of A deviates significantly from the global density. The alteration method then removes the coordinates responsible for the correlation, yielding a density increment on a smaller subspace. The quantitative bounds obtained are of Ackermann type, matching the known lower bounds. This proof demonstrates how the probabilistic method, combined with a density increment scheme, can replace ergodic theory in Ramsey‑type density theorems.

  • Applying the Kesten–Stigum threshold to the sparse SBM without checking the condition (a−b)2 > 2(a+b); below this threshold detection is information‑theoretically impossible.

Show that R(k,k) > 2(k-1)/2 for k ≥ 3 using the alteration method.
Let n = ⌊2(k-1)/2⌋. Consider G ∼ G(n, 1/2). For a fixed k‑set S, the probability that S is a clique or an independent set is 2 · 2^{-{k choose 2}} = 2^{1-{k choose 2}}. There are {n choose k} such sets. By linearity of expectation, the expected number X of monochromatic k‑sets is {n choose k} 2^{1-{k choose 2}}. Using {n choose k} ≤ n^k/k! and n ≤ 2(k-1)/2, we get X ≤ (2(k-1)/2)^k / k! · 2^{1-{k choose 2}} = 2k(k-1)/2 + 1 - k(k-1)/2 / k! = 2/k!. For k ≥ 3, 2/k! ≤ 1/3 < 1. Hence E[X] < 1. By the alteration method, delete one vertex from each monochromatic k‑set. The expected number of deletions is E[X] < 1, so there exists a graph with no monochromatic k‑set on at least n - E[X] > n-1 vertices. Thus R(k,k) > n ≥ 2(k-1)/2.

The Probabilistic Construction of Graphs with High Girth and Chromatic Number

Erdős’s 1959 paper introduced the probabilistic method to prove that for any integers g ≥ 3 and k ≥ 3 there exists a graph with girth at least g and chromatic number at least k. The construction samples a random graph G(n, p) with edge probability p = n−1+1/(2g−2). The expected number of cycles of length less than g is at most Σℓ=3g−1 nℓ pℓ = O(n1/(2g−2)) = o(n). By Markov’s inequality, with positive probability the graph contains at most n/2 such short cycles. Deleting one vertex from each short cycle removes at most n/2 vertices, leaving a subgraph H on at least n/2 vertices with girth ≥ g. The independence number α(H) is bounded by the first moment method: the expected number of independent sets of size t is at most (n choose t)(1−p)t(t−1)/2. Choosing t = 3 log1/(1−p) n makes this expectation < 1, so α(H) ≤ t with positive probability. Since χ(H) ≥ |V(H)| / α(H), we obtain χ(H) ≥ n / (2t) which can be made arbitrarily large by taking n large. This alteration argument (delete vertices from short cycles, then bound independence number) is the prototype for many later results combining the first moment method with a cleaning step.

The proof illustrates two recurring themes: (i) the choice of p balances the expected number of short cycles against the independence number, and (ii) the alteration step converts an existential statement about a random graph into a deterministic statement about a subgraph. Modern refinements use the Lovász Local Lemma to avoid the deletion step entirely, yielding graphs with girth ≥ g and chromatic number ≥ k on n = O(k2g) vertices, but the original argument remains the textbook example of the probabilistic method’s power.

The Probabilistic Existence of Expander Graphs via Random Lifts

A d-regular graph G on n vertices is an expander if its second eigenvalue λ2(G) satisfies λ2 ≤ 2√(d−1) + ε for some small ε > 0. Friedman’s 2003 theorem shows that a random n-lift of a fixed base expander H (a d-regular graph on a constant number of vertices) is an expander with probability tending to 1 as n → ∞. A random lift replaces each vertex of H by a fibre of size n and each edge by a uniformly random perfect matching between the corresponding fibres. The adjacency matrix of the lift is a block matrix whose non‑zero blocks are permutation matrices. Friedman proved that the new eigenvalues (those not inherited from H) are bounded by 2√(d−1) + o(1) with high probability, using the trace method: the expected trace of the k-th power of the adjacency matrix counts closed non‑backtracking walks, and a careful combinatorial estimate shows that the contribution of walks that are not trees is negligible. The argument requires controlling the number of “tangled” walks, which is achieved by a union bound over all possible patterns of vertex identifications. This is a second‑moment / concentration argument on a sum of dependent random variables (the permutation matrices), and it demonstrates how the probabilistic method can produce explicit families of expanders (the lift construction is algorithmic: one can sample the permutations and test expansion in polynomial time). The result also implies that almost every d-regular graph is an expander, because a random d-regular graph can be viewed as a random lift of a bouquet of d/2 loops.

The Probabilistic Proof of the Existence of Good LDPC Codes

Low‑density parity‑check (LDPC) codes are linear codes defined by a sparse parity‑check matrix H. Gallager’s 1962 thesis proved that random regular LDPC ensembles achieve the Gilbert–Varshamov bound. The ensemble chooses a random m × n binary matrix with exactly dv ones per column and dc ones per row (so m dc = n dv). The rate is at least 1 − m/n = 1 − dv/dc. To show good distance, one counts the expected number of codewords of weight w. A codeword corresponds to a subset of columns whose sum is zero; equivalently, the induced subgraph on the chosen variable nodes has all check nodes of even degree. The first moment method gives E[Nw] ≤ (n choose w) ( (dv w choose dc m/2) / (dv n choose dc m) ) which, after Stirling approximations, is exponentially small for w ≤ δn provided the rate R < 1 − H(δ) (the GV bound). The alteration step removes a small fraction of variable nodes to eliminate any remaining low‑weight codewords, yielding a code with relative distance ≥ δ. Modern analyses use the expander‑graph viewpoint: the Tanner graph of a random LDPC code is a bipartite expander with high probability, and expansion implies linear distance. This connection underlies the construction of expander codes (Sipser–Spielman) and the proof that LDPC codes achieve capacity on the binary erasure channel under belief‑propagation decoding (Luby et al.). The probabilistic method thus provides both existential guarantees and the analytical tools for iterative decoding thresholds.

The Probabilistic Method for Large Sidon Sets and Bh Sets

A set A ⊂ [N] is a Sidon set (or B2 set) if all pairwise sums a + b (a ≤ b) are distinct. Erdős and Turán (1941) asked for the maximal size of a Sidon set in [N]; the probabilistic method gives a lower bound of (1 + o(1))√N. Choose each integer independently with probability p = N−1/2. The expected size is pN = √N. The expected number of collisions (distinct pairs {a,b} ≠ {c,d} with a+b = c+d) is at most N2 p4 = 1. By Markov, with positive probability there are at most 2 collisions. Deleting one element from each collision yields a Sidon set of size at least √N − 2. For general Bh sets (all sums of h elements distinct), the same argument with p = N−1+1/h gives a lower bound of N1/h. The alteration step is essential because the first moment alone only guarantees few collisions, not zero. The method extends to sets with distinct sums of h elements where order matters (Bh[g] sets) and to the construction of large sets with no solutions to linear equations (Ruzsa–Szemerédi). The probabilistic construction is still the best known general lower bound; explicit constructions (e.g., Singer’s finite projective plane construction) achieve √N only for special N, while the probabilistic method works for all N.

The Probabilistic Method in the Existence of Graphs with High Chromatic Number and No Short Odd Cycles

Erdős’s 1959 theorem actually produces graphs with large girth (no short cycles of any parity) and large chromatic number. A variant asks for graphs with large odd girth (no short odd cycles) but possibly even cycles. This is equivalent to constructing graphs of high chromatic number that are locally bipartite. The probabilistic method adapts by sampling G(n, p) with p = n−1+1/(2k−1) to avoid odd cycles of length < 2k+1. The expected number of odd cycles of length ≤ 2k−1 is O(n1/(2k−1)) = o(n). After deleting a vertex from each short odd cycle, the remaining graph has odd girth ≥ 2k+1. The independence number is bounded as before, giving χ ≥ n / (2t). This shows that for any k there are graphs with odd girth > 2k and arbitrarily large chromatic number. The result is sharp in the sense that a graph with odd girth > 2k and chromatic number > k must have at least k vertices (by a simple greedy coloring argument). The proof technique — choosing p to kill short odd cycles while keeping the graph dense enough to force large chromatic number — is a template for many “local‑global” phenomena in extremal combinatorics, such as the existence of graphs with high chromatic number and no Kt (the classic Erdős–Hajnal problem) and the construction of triangle‑free graphs with high chromatic number (Mycielski’s construction is deterministic, but the probabilistic method gives a much simpler existence proof).

  • Overlooking the requirement that the base graph in a random lift be an expander; lifting a non‑expander does not guarantee expansion.

The Probabilistic Method in the Hitting Time for Hamiltonicity in the Random Graph Process

In the random graph process G(n, m) where edges are added one by one uniformly at random, the hitting time for Hamiltonicity coincides with the hitting time for minimum degree two. This celebrated result of Bollobás (1984) and independently of Ajtai, Komlós, and Szemerédi (1985) shows that as soon as the last vertex of degree one disappears, the graph becomes Hamiltonian with high probability. The proof uses the probabilistic method to analyse the evolution of the degree sequence and to show that the obstruction to a Hamilton cycle is essentially the presence of vertices of degree at most one. A key step is to couple the random graph process with a random regular graph of degree two and to apply the rotation‑extension technique of Pósa. The first moment method bounds the expected number of vertices of degree zero or one at each step, while the second moment method shows concentration of the number of such vertices. The alteration method is then used to delete a small set of vertices that create short cycles, leaving a graph that is still dense enough to apply Pósa’s lemma. The result has been extended to directed graphs, to hypergraphs, and to the random graph process with a prescribed degree sequence. It also underpins the analysis of the random graph process for the appearance of a perfect matching, where the hitting time for minimum degree one equals the hitting time for a perfect matching.

The Probabilistic Method in the Existence of Graphs with Large Chromatic Number and No Small Complete Bipartite Subgraphs

Erdős (1962) asked whether for every integer k there exists a graph with chromatic number at least k that contains no copy of Ks,t for fixed s, t. The probabilistic method gives a positive answer by sampling G(n, p) with p = n-1+1/(s+t-2). The expected number of copies of Ks,t is at most ns+t pst = ns+t - st + st/(s+t-2) which is o(1) for the chosen p. By Markov’s inequality, with positive probability there are no copies of Ks,t. Meanwhile, the independence number α(G) is bounded by the first moment method: E[α] ≤ 2 log1/(1-p) n = O(log n). Hence χ(G) ≥ n / α(G) = Ω(n / log n). Choosing n large enough yields χ(G) ≥ k. The alteration step deletes one vertex from each Ks,t (there are none) and from each short cycle if needed, preserving the lower bound on χ. This construction shows that the extremal function for forbidding Ks,t grows faster than any polynomial in the chromatic number. The method also yields graphs with large odd girth and no Ks,t by adjusting p to n-1+1/(2g-1) and applying the same independence number bound. The result is a cornerstone of the Erdős–Hajnal programme and illustrates how the probabilistic method separates local density conditions from global chromatic properties.

The Probabilistic Method in the Construction of Large Sets Free of Three‑Term Arithmetic Progressions

Roth’s theorem (1953) states that any subset of {1,…,N} of positive density contains a three‑term arithmetic progression. The probabilistic method gives a lower bound on the size of the largest progression‑free set. Choose each integer independently with probability p = N-1/2. The expected size is pN = √N. The expected number of three‑term progressions is at most N2 p3 = N1/2. By Markov, with positive probability there are at most 2N1/2 progressions. Deleting one element from each progression yields a progression‑free set of size at least √N - 2N1/2 = Ω(√N). This bound was improved by Behrend (1946) to N exp(-c√log N) using a deterministic construction, but the probabilistic argument remains the simplest proof of a polynomial lower bound. The alteration step is essential because the first moment alone only guarantees few progressions, not zero. The method extends to k‑term progressions by taking p = N-1+1/(k-1) and deleting one element from each progression, giving a lower bound of N1/(k-1). For sets avoiding solutions to linear equations a1 x1 + … + a_k x_k = 0 with distinct variables, the same approach works provided the equation is translation‑invariant. The probabilistic construction also underpins the proof of the existence of large Salem‑Spencer sets and is a template for the probabilistic method in additive combinatorics.

The Probabilistic Method in the Analysis of the Stochastic Block Model: Information‑Theoretic Thresholds for Community Detection

The stochastic block model (SBM) with two equal‑sized communities and edge probabilities p = a log n / n (inside) and q = b log n / n (across) exhibits a sharp information‑theoretic threshold for exact recovery. Abbe, Bandeira, and Hall (2016) proved that exact recovery is possible if and only if (√a - √b)2 > 2. The probabilistic method enters through the analysis of the maximum likelihood estimator, which coincides with the minimum bisection problem. By applying the first moment method to the number of bisections that disagree with the true partition on a given set of vertices, one shows that if (√a - √b)2 < 2 then there exists another bisection with at least as many internal edges as the true one, making exact recovery impossible. Conversely, when (√a - √b)2 > 2, a Chernoff bound combined with a union bound over all 2n-1 bisections shows that the true partition is the unique maximiser with high probability. The second moment method refines the threshold for weak recovery (correlation with the true partition) to the Kesten–Stigum bound (a-b)2 > 2(a+b). The differential equation method tracks the evolution of belief propagation on the associated factor graph, yielding the exact phase diagram. These results illustrate how the probabilistic method, together with concentration inequalities, determines the fundamental limits of community detection.

The Probabilistic Method in the Proof of the Existence of Good Locally Testable Codes via Random Linear Codes

A locally testable code (LTC) allows a verifier to check whether a word is a codeword by querying only a constant number of bits. Goldreich and Sudan (2006) asked whether random linear codes are good LTCs. The probabilistic method shows that a random linear code of rate R and relative distance δ is, with high probability, an LTC with query complexity q = O(1/δ) and soundness ε = Ω(δ). The proof samples a random parity‑check matrix H ∈ F2m×n with m = (1-R)n. For any non‑codeword x, the syndrome Hx is a non‑zero vector. The tester picks a random row of H and checks the corresponding parity. The probability that a random row is satisfied by x equals the fraction of zero entries in Hx. By the first moment method, the expected weight of Hx for a fixed x of relative weight w is w/2. Concentration inequalities (Chernoff bounds) show that with high probability all non‑codewords have syndrome weight close to w/2. Hence a random row rejects x with probability at least w/4. Setting the query complexity to a constant multiple of 1/δ yields soundness proportional to δ. The alteration step removes a small fraction of rows that cause excessive correlations, preserving the LTC property. This construction achieves the optimal trade‑off between rate, distance, and query complexity up to constant factors and demonstrates the power of the probabilistic method in coding theory.

The Probabilistic Method in the Construction of Perfect Matchings in Hypergraphs via the Absorption Method

The absorption method, introduced by Rödl, Ruciński, and Szemerédi in the early 2000s and later refined by Keevash, Knox, and Mycroft, provides a powerful framework for proving the existence of perfect matchings in dense hypergraphs. The core idea is to first find a small vertex set A, called an absorber, with the property that for any small set U of vertices disjoint from A, both A and A ∪ U contain perfect matchings. Once such an absorber is secured, one finds an almost perfect matching covering all but a small number of vertices in the remaining hypergraph, and then uses the absorber to cover the leftover vertices, yielding a perfect matching of the whole hypergraph.

The probabilistic method enters at two critical stages. First, to show that a random set of vertices of appropriate size is an absorber with positive probability. For a k‑uniform hypergraph H on n vertices with minimum codegree δk-1(H) ≥ (1/2 + o(1))n, one selects each vertex independently with probability p = Θ(log n / n). Using Chernoff bounds and the Lovász Local Lemma, one proves that with high probability the chosen set A has the absorbing property for all small sets U of size up to εn. The second stage applies the probabilistic method to find an almost perfect matching in H A. A random greedy algorithm or a nibble process (the Rödl nibble) produces a matching that covers all but at most εn vertices. The alteration step then removes any edges intersecting the uncovered vertices, and the absorber A is used to match the remaining vertices. The final result is a perfect matching provided n is divisible by k and the codegree condition holds.

This technique has been extended to many other spanning structures, including Hamilton cycles in hypergraphs, F‑factors, and designs. The absorption method exemplifies how the probabilistic method can be combined with a deterministic alteration step to achieve exact combinatorial structures, moving beyond mere existence of approximate objects.

The Probabilistic Method in the Proof of the Szemerédi Regularity Lemma via Random Partitions

The Szemerédi Regularity Lemma states that for every ε > 0 there exists an integer M(ε) such that any graph G on n vertices admits an equitable partition into m parts, where 1/ε ≤ m ≤ M(ε), such that all but at most ε m² pairs of parts are ε‑regular. The original proof uses an iterative energy‑increment argument, but a probabilistic proof by Alon, Fischer, Krivelevich, and Szegedy (2000) shows that a random equitable partition already works with positive probability. The argument proceeds by fixing an integer m and partitioning the vertex set uniformly at random into m parts of equal size (up to one). For a fixed pair of parts (V_i, V_j), the edge density between them is a random variable. Using Chernoff bounds, one shows that the probability this pair fails to be ε‑regular is exponentially small in the part size. A union bound over all m² pairs then shows that the expected number of irregular pairs is at most ε m², provided m is not too large relative to n. By the first moment method, there exists a partition with at most ε m² irregular pairs.

To obtain the full lemma, one iterates this random partitioning: if a partition has too many irregular pairs, one refines it by further random splits, and the energy (mean square density) increases by a definite amount. Since the energy is bounded by 1, the process terminates after at most O(1/ε⁵) steps, yielding a partition with the required regularity. The tower‑type bound on M(ε) emerges from the repeated refinement. This probabilistic perspective not only simplifies the proof but also leads to algorithmic versions: a random partition can be found in polynomial time, and the refinement steps can be derandomized using the method of conditional expectations. The approach highlights how the probabilistic method can convert an existential statement into a constructive algorithm while preserving the quantitative bounds.

Worked Example: Absorbing Set in a 3‑Uniform Hypergraph
Let H be a 3‑uniform hypergraph on n vertices with minimum codegree δ₂(H) ≥ (1/2 + γ)n for some fixed γ > 0. Show that a random set A obtained by including each vertex independently with probability p = C log n / n (C sufficiently large) is an absorber for all sets U of size at most εn with high probability.
For a fixed set U of size u ≤ εn, we need a perfect matching in H[A] and in H[A ∪ U]. The expected number of vertices in A is pn = C log n. By Chernoff bounds, |A| = (1 ± o(1))pn with probability 1 − n⁻³. For each u, the number of ways to choose U is at most n^u. For a given U, the probability that A fails to absorb U is bounded by the probability that there is no perfect matching in H[A ∪ U]. Using the minimum codegree condition, one can show that H[A ∪ U] contains a perfect matching provided |A| is a multiple of 3 and the codegree condition holds within A ∪ U. The codegree condition is inherited because any two vertices in A ∪ U have at least (1/2 + γ)n common neighbours in H, and at most o(n) of them lie outside A ∪ U. A union bound over all U of size up to εn, together with the Lovász Local Lemma to handle dependencies, yields that the probability any U fails is o(1). Hence a suitable absorber exists.
Exam Strategy
When a question asks for the existence of a spanning structure (perfect matching, Hamilton cycle, F‑factor) in a dense hypergraph, check whether the minimum codegree or degree condition matches the known absorption threshold. If it does, outline the two‑stage probabilistic construction: (1) find a small absorber via random sampling and concentration inequalities; (2) find an almost spanning structure in the remainder via the nibble or greedy algorithm. Mention that the alteration step (absorbing the leftover) is what upgrades an approximate result to an exact one. This template appears frequently in advanced combinatorics exams.

The Probabilistic Method in the Lower Bounds for Hypergraph Ramsey Numbers

For integers k ≥ 2 and s ≥ k+1, the diagonal Ramsey number R_k(s) is the smallest n such that every red/blue coloring of the k‑subsets of an n‑set yields a monochromatic s‑set. The probabilistic method provides the classical lower bound R_k(s) > c_k s(k-1)/2 2sk-1 / (2k-1) for some constant c_k > 0. The proof colors each k‑subset independently red or blue with probability 1/2. For a fixed s‑set S, the probability that all its (s choose k) k‑subsets receive the same color is 21 - (s choose k). There are (n choose s) such sets S. By the first moment method, if (n choose s) · 21 - (s choose k) < 1, then there exists a coloring with no monochromatic s‑set, implying R_k(s) > n. Choosing n = ⌊c_k s(k-1)/2 2sk-1 / (2k-1)⌋ satisfies the inequality for sufficiently large s. This bound, due to Erdős and Hajnal (1972), remains the best known general lower bound for diagonal hypergraph Ramsey numbers. For off‑diagonal numbers R_k(s,t), a similar calculation with asymmetric coloring probabilities yields R_k(s,t) > ck,s t(s-1)/(k-1) / (log t)1/(k-1) for fixed s and large t.

The second moment method can sometimes improve the constant factor, but the exponential order of magnitude is unchanged. A major open problem is whether the base of the exponent can be increased; for graphs (k=2) the current best lower bound is (1+o(1)) (√2/e) s 2s/2, while the upper bound is roughly 4^s. For k ≥ 3 the gap is even wider. The probabilistic method also gives lower bounds for multicolor Ramsey numbers and for Ramsey numbers of non‑complete hypergraphs, using the same first moment framework with appropriately defined bad events.

The Probabilistic Method in the Construction of Randomness Extractors and Dispersers

A (k, ε)‑extractor is a function Ext: {0,1}ⁿ × {0,1}ᵈ → {0,1}ᵐ such that for every random variable X on {0,1}ⁿ with min‑entropy at least k, the distribution Ext(X, U_d) is ε‑close to uniform in statistical distance. The probabilistic method shows that for any n, k, ε there exists an extractor with seed length d = log(n−k) + 2 log(1/ε) + O(1) and output length m = k + d − 2 log(1/ε) − O(1), which is optimal up to additive constants. The proof picks a random function Ext by choosing each output bit independently and uniformly. For a fixed flat source X (uniform on a set of size 2^k), the output Ext(X, U_d) is a sum of independent random variables. By Chernoff bounds, the probability that its statistical distance from uniform exceeds ε is at most 2-Ω(ε² 2k+d). The number of flat sources is at most (2ⁿ choose 2^k) ≤ 2k 2n-k. A union bound over all flat sources succeeds provided 2k 2n-k · 2-Ω(ε² 2k+d) < 1, which holds for the stated d. Since every source with min‑entropy k is a convex combination of flat sources, the bound extends to all such sources.

A disperser is a weaker object: a function Disp: {0,1}ⁿ × {0,1}ᵈ → {0,1}ᵐ such that for every source X with min‑entropy k, the support of Disp(X, U_d) has size at least (1−ε)2ᵐ. The probabilistic method gives dispersers with d = log(n−k) + log(1/ε) + O(1) and m = k + d − log(1/ε) − O(1). The proof is similar but uses a simpler counting argument: for a fixed source, the probability that a random function misses a given output string is (1 − 2-m)2k+d ≤ exp(−2k+d-m). Choosing parameters so that the expected number of missed strings is small yields the result. These probabilistic constructions are non‑explicit; explicit extractors and dispersers require additional algebraic or combinatorial techniques, but the probabilistic method establishes the optimal parameters that explicit constructions aim to match.

The Probabilistic Method in the Proof of the Existence of List‑Decodable Codes Achieving Capacity

A q‑ary code C ⊆ Σⁿ of rate R is (ρ, L)‑list‑decodable if every Hamming ball of radius ρn contains at most L codewords. The list‑decoding capacity theorem states that for any ε > 0 and 0 < ρ < 1−1/q, there exist codes of rate R ≥ 1 − H_q(ρ) − ε that are (ρ, O(1/ε))‑list‑decodable, where H_q is the q‑ary entropy function. The probabilistic proof selects a random code by choosing each codeword independently and uniformly from Σⁿ, with M = qnR codewords. For a fixed received word y ∈ Σⁿ, the number of codewords falling in the ball B(y, ρn) is a binomial random variable with mean M · q-n(1−H_q(ρ)+o(1)) = q-nε+o(n). By Markov's inequality, the probability that this number exceeds L = 2/ε is at most q-nε/2. A union bound over all qⁿ possible received words shows that with positive probability no ball contains more than L codewords, provided n is sufficiently large. This first moment argument establishes the existence of codes achieving the optimal trade‑off between rate, decoding radius, and list size.

The same method yields list‑recoverable codes and codes for the adversarial error model. For list recovery, one considers a set of input lists and requires that the number of codewords agreeing with each list on many coordinates is bounded. The probabilistic analysis uses a similar union bound over all possible list configurations. The alteration step is not needed here because the first moment bound already gives a high‑probability guarantee for the entire code. However, to obtain linear‑time encoding and decoding, one must combine the probabilistic existence with algebraic constructions (e.g., folded Reed–Solomon codes). The probabilistic method thus provides the benchmark that explicit constructions strive to meet.

  • Assuming that a random partition is automatically ε‑regular for all pairs; the probabilistic proof only guarantees that most pairs are regular, and an iterative refinement is needed to reach the full regularity lemma.
  • Using the symmetric first moment bound for off‑diagonal hypergraph Ramsey numbers without adjusting the coloring probabilities; the optimal asymmetric coloring gives a stronger lower bound.
  • Overlooking that the probabilistic construction of extractors requires a union bound over all flat sources, not just all subsets of size 2^k; the number of flat sources is much larger and dictates the seed length.
  • Believing that the list‑decoding capacity bound holds for unique decoding; the capacity for unique decoding is 1 − H_q(2ρ), which is strictly smaller.
  • Neglecting the alteration step when constructing perfect matchings in hypergraphs; the nibble alone leaves a small uncovered set that must be absorbed.
  • Misapplying the Lovász Local Lemma in the absorption proof by not verifying the dependency degree condition; the events for different U are not independent and the LLL requires a careful bound on the number of dependent events.

The Probabilistic Method in the Construction of Pseudorandom Graphs via Random Cayley Graphs

Random Cayley graphs provide a natural algebraic setting for the probabilistic method. Let G be a finite group of order n and let S be a random symmetric subset of G {e} obtained by including each non‑identity element independently with probability p. The resulting Cayley graph Cay(G, S) has vertex set G and edges xy whenever x−1y ∈ S. Because the group structure forces a high degree of symmetry, the eigenvalues of the adjacency matrix are given by the Fourier transform of the indicator of S on the irreducible representations of G. For abelian groups this reduces to characters, and the second largest eigenvalue in absolute value can be bounded using standard concentration inequalities for sums of independent random variables. The seminal result of Alon and Roichman (1994) shows that for any group G of order n, a random set S of size O(log n) yields, with high probability, a Cayley graph whose non‑trivial eigenvalues are at most ε times the degree, i.e. an ε‑expander. The proof applies the matrix Chernoff bound to the sum of independent random permutation matrices corresponding to the generators. This construction is explicit once the random set is fixed, and it demonstrates that expanders exist in every group, not only in the free group or in specific families such as SL(2,p). The method also extends to non‑abelian groups where representation theory replaces characters; the key technical step is a bound on the operator norm of a sum of independent random matrices, which follows from the non‑commutative Khintchine inequality. Examiners often ask for the dependence of the generating set size on the spectral gap, and a common trap is to confuse the Alon–Roichman bound O(log n) with the optimal O(log n) for constant ε, forgetting that the hidden constant depends on ε as ε−2. Another twist is to require the construction of a Cayley graph that is simultaneously an expander and has large girth; the probabilistic method can achieve both by a union bound over short cycles, but the parameters become more delicate.

The Probabilistic Method in the Proof of the Existence of Good Locally Decodable Codes

A locally decodable code (LDC) encodes a message x ∈ {0,1}k into a codeword C(x) ∈ {0,1}n such that any bit xi can be recovered with high probability by querying only q positions of a possibly corrupted codeword. The probabilistic method shows that for any constant q ≥ 2 there exist LDCs with length n = exp(k1/(q−1)) up to polylogarithmic factors. The classic construction by Katz and Trevisan (2000) picks a random linear code: choose a random k × n matrix G over F2 and define C(x) = xG. For a fixed message index i, one considers all q-tuples of columns that sum to the i-th unit vector. The number of such tuples is roughly nq/2k. By setting n = 2k1/(q−1) the expected number of tuples is large. Using the second moment method one shows that with positive probability there exists a linear code for which every index has many disjoint q-tuples, yielding a q-query decoder that succeeds with probability > 2/3 even after a constant fraction of errors. The alteration step removes the few bad indices that have too few tuples. The proof also uses the Lovász Local Lemma to handle dependencies between the events that different indices lack enough tuples. A frequent examiner twist is to ask why the same argument fails for q = 2, where the best known LDCs have exponential length; the answer lies in the fact that for q = 2 the required tuples are just pairs of columns summing to a unit vector, and the second moment calculation breaks down because the variance becomes too large. Another common trap is to confuse locally decodable codes with locally testable codes; the probabilistic method gives similar parameters for both, but the decoding and testing requirements are distinct.

Worked Example: Second Moment for LDC Tuples
Let G be a random k × n binary matrix. For a fixed index i, let X be the number of ordered pairs (j,l) with j ≠ l such that column j + column l = ei. Compute E[X] and Var(X) and show that for n = 2k/2 the probability X = 0 is o(1).
Each ordered pair (j,l) satisfies the equation with probability 2−k because the sum of two independent uniform columns is uniform. There are n(n−1) ≈ n2 pairs, so E[X] = n2/2k. For n = 2k/2, E[X] = 1. The variance is dominated by overlapping pairs; a careful count gives Var(X) = O(n3/2k) = O(2k/2). By Chebyshev, Pr[X = 0] ≤ Var(X)/E[X]2 = O(2−k/2) = o(1). Hence with high probability every index has at least one good pair, yielding a 2‑query LDC of length 2k/2. (Note: this contradicts the known exponential lower bound for 2‑query LDCs; the flaw is that the pairs are not disjoint, so the decoder cannot tolerate errors. The correct second moment argument for q ≥ 3 uses disjoint tuples.)

The Probabilistic Method in the Analysis of the Random Graph Process for the Appearance of a Fixed Subgraph

The random graph process starts with an empty graph on n vertices and adds edges one by one in uniformly random order. For a fixed graph H with v vertices and e edges, the hitting time for the appearance of a copy of H is the step at which the first subgraph isomorphic to H emerges. The classic result of Bollobás (1984) and independently of Ruciński and Vince (1986) determines the threshold: if H is strictly balanced (i.e. e/v > e′/v′ for every proper subgraph H′), then the hitting time coincides with the threshold for the property “contains H” in the binomial random graph G(n, p) at p = n−v/e. The proof uses the first moment method to show that before this edge density the expected number of copies of H tends to zero, and the second moment method (or Janson’s inequality) to show that after this density the probability of having no copy is exponentially small. For non‑balanced H, the threshold is governed by the densest subgraph, and the hitting time may occur earlier due to the appearance of that dense subgraph. A key technical tool is the differential equation method (Wormald, 1995) which tracks the evolution of the number of extensions of partial copies of H as edges are added. This yields sharp concentration of the hitting time around its mean, with fluctuations of order n2−v/e. Examiners often ask to distinguish between the threshold for the appearance of a triangle (v=3, e=3, threshold p = 1/n) and that of a 4‑cycle (v=4, e=4, threshold p = 1/n), noting that both have the same density but the 4‑cycle is not strictly balanced because it contains a path of length 2 with density 2/3 > 1. The correct threshold for C4 is p = n−2/3, dictated by the densest subgraph (the path). Another common trap is to apply the symmetric Lovász Local Lemma directly to the events “edge set E contains a copy of H” without accounting for the massive dependency degree; the correct approach uses Janson’s inequality or the Suen inequality.

The Probabilistic Method in the Construction of Random Graphs with Prescribed Degree Sequences

The configuration model (Bollobás, 1980) generates a uniform random multigraph with a given degree sequence d1, …, dn by creating di half‑edges for each vertex i and then pairing all half‑edges uniformly at random. The resulting object may have loops and multiple edges, but conditioned on being simple it is exactly a uniform simple graph with that degree sequence. The probabilistic method is used to show that for a wide range of degree sequences (e.g. maximum degree o(n1/2)) the probability of obtaining a simple graph is bounded away from zero, so a simple graph exists. The proof computes the expected number of loops and double edges: each pair of half‑edges from the same vertex forms a loop with probability ≈ 1/(∑di), giving expected loops ∑di2/(∑di). Similarly, the expected number of double edges between vertices i and j is didj/(∑di). If the sum of squares is o(∑di), both expectations tend to zero, and Markov’s inequality gives a positive probability of simplicity. For denser degree sequences (e.g. power‑law with exponent < 3) the probability of simplicity decays exponentially, but one can still use the configuration model as a sampling tool after a suitable switching argument. The method also underpins the proof of the existence of expander graphs with a given degree sequence: a random regular graph of degree d ≥ 3 is an expander with high probability (Friedman, 2003). The configuration model provides a convenient probability space to apply the trace method or the moment method for eigenvalues. A typical examiner twist is to ask why the configuration model fails to produce a uniform simple graph when the degree sequence is not graphic; the answer is that the conditioning event “the pairing yields a simple graph” has probability zero. Another trap is to assume that the configuration model directly gives a simple graph without loops for any degree sequence; the condition max di = o(√m) where m = ∑di is essential.

The Probabilistic Method in the Construction of Good Hash Families and Perfect Hash Functions

A perfect hash family PHF(N; n, m, k) is a set of N functions from an n-set to an m-set such that for every k-subset of the domain, at least one function is injective on that subset. The probabilistic method shows that for fixed k and m ≥ k2 there exist PHFs with N = O(k2 log n). The construction picks each function independently and uniformly at random. For a fixed k-subset S, the probability that a random function is injective on S is m!/(m−k)! / mk ≥ e−k2/m. Choosing m = k2 makes this probability a constant. The probability that none of the N functions is injective on S is (1−Ω(1))N. A union bound over all (n choose k) subsets succeeds if N = O(k log n). To obtain the stronger bound N = O(k2 log n) for arbitrary m ≥ k, one uses the Lovász Local Lemma because the events for different subsets are not independent but have limited dependency. The asymmetric LLL gives the condition e p (d+1) ≤ 1 where p is the failure probability for a single subset and d is the number of subsets intersecting a given subset. This yields the optimal dependence on k. A related object is a separating hash family SHF(N; n, m, {w1, w2}) where any two disjoint subsets of sizes w1, w2 are separated by some function. The probabilistic method gives N = O((w1+w2) log n) for constant m. Examiners often ask to derive the LLL condition for perfect hash families and to explain why the symmetric LLL is insufficient when m is close to k. A common trap is to confuse perfect hash families with k-wise independent hash families; the latter require independence on all k-tuples, which is a much stronger condition and needs N = Ω(k log n) functions even for m = 2.

  • Applying the symmetric Lovász Local Lemma to the appearance of a fixed subgraph in the random graph process without checking the dependency degree; Janson’s inequality is the correct tool.
  • Believing the configuration model always produces a simple graph with positive probability; the condition max degree = o(√m) is necessary.
  • Thinking that a perfect hash family with m = k can be constructed with N = O(log n) using only the first moment method; the Lovász Local Lemma is required for the optimal bound.
  • Overlooking that the hitting time for a non‑balanced graph H is determined by its densest subgraph, not by the overall density of H.
  • The probabilistic method establishes existence but does not automatically yield efficient algorithms; derandomization via conditional expectations or the method of pessimistic estimators is often needed for constructive versions.

The Probabilistic Method in the Construction of Random Geometric Graphs and Connectivity Thresholds

Random geometric graphs are formed by placing n vertices independently and uniformly in the unit square [0,1]² and joining two vertices when their Euclidean distance is at most r. The parameter r = r(n) controls the density. A classical result of Penrose shows that the graph becomes connected precisely when the radius exceeds the threshold r_c = √((log n + c(n)) / (π n)) where c(n) → ∞ arbitrarily slowly. The probabilistic method proves this by first showing that the expected number of isolated vertices tends to zero when r is above the threshold, using the first moment method on the indicator of a vertex having no neighbours. A second moment calculation on the number of isolated vertices then yields that the probability of having any isolated vertex tends to zero, which is the main obstacle to connectivity in this model.

Below the threshold, the expected number of isolated vertices diverges, and a standard application of the second moment method (or Chebyshev’s inequality) shows that with high probability there are many isolated vertices, so the graph is disconnected. The alteration method refines the argument: one first deletes all isolated vertices and then shows that the remaining graph is already connected. This two‑step approach mirrors the alteration technique used for Erdős–Rényi graphs but requires careful geometric dependency estimates because the neighbourhood events are not independent.

Sharp concentration of the size of the largest component follows from martingale exposure of the vertex positions. By revealing the points one by one and applying Azuma’s inequality to the Doob martingale of the component size, one obtains that the size of the giant component is concentrated around its mean within O(√n) fluctuations. This concentration is stronger than the mere existence of a giant component and is essential for algorithmic applications such as distributed connectivity testing.

Examiners often ask for the exact constant in the connectivity threshold. The constant π appears because the area of a disc of radius r is π r², and the expected degree of a vertex is (n−1)π r². A common trap is to confuse the connectivity threshold with the emergence of a giant component, which occurs at the smaller radius r_g = √(1/(π n)). The two thresholds differ by a factor of √log n, and the probabilistic method distinguishes them by analysing isolated vertices versus the survival of a branching process approximation.

The Probabilistic Method in the Analysis of the Random Graph Process for the Emergence of a Perfect Matching

Consider the random graph process G₀ ⊂ G₁ ⊂ … ⊂ GN where N = (n choose 2) and each step adds a uniformly random missing edge. A perfect matching appears exactly at the hitting time τ₁ when the minimum degree first becomes at least 1, provided n is even. This celebrated theorem of Bollobás and Frieze is proved by the probabilistic method combined with Hall’s marriage theorem. One shows that for any set S of vertices with |S| ≤ n/2, the neighbourhood N(S) in Gτ₁ satisfies |N(S)| ≥ |S| with high probability. The proof uses the first moment method to bound the expected number of “bad” sets S that violate Hall’s condition, and then a union bound over all such sets.

The alteration method is employed to handle the dependency between edges added after τ₁. One first conditions on the graph at time τ₁, then adds a further O(n log n) random edges. The added edges are shown to “fix” any remaining Hall violations with high probability. This two‑stage construction mirrors the alteration technique: a random object is first generated, then a small deterministic or random modification yields the desired property. The analysis requires careful estimation of the probability that a fixed set S has too few neighbours, which involves binomial tail bounds and the inequality (1−p)^k ≤ e−pk.

A related result concerns the hitting time for a Hamiltonian cycle, which coincides with the hitting time for minimum degree 2. The same probabilistic framework applies, but the Hall‑type condition is replaced by Pósa’s rotation‑extension technique. Examiners may ask to compare the two hitting times and to explain why the perfect matching threshold is exactly τ₁ while Hamiltonicity requires τ₂. The key difference is that a perfect matching only needs a 1‑factor, which is guaranteed by minimum degree 1 together with expansion properties that hold at τ₁, whereas a Hamiltonian cycle needs a more robust connectivity structure.

Typical exam traps include confusing the random graph process Gn,m with the binomial model Gn,p and applying results from one model directly to the other without adjusting for the conditioning on the number of edges. Another trap is to assume that the existence of a perfect matching at τ₁ holds for odd n; the correct statement is that a near‑perfect matching (covering all but one vertex) appears at τ₁ for odd n. The probabilistic method clarifies these nuances by tracking the exact degree sequence evolution.

Worked Example
Let G be a random geometric graph on n vertices in the unit square with radius r = √((log n + 3 log log n) / (π n)). Show that G is connected with probability tending to 1 as n → ∞.
The expected number of isolated vertices is n (1 − π r²)n−1. Substituting r² gives π r² = (log n + 3 log log n)/n. Then (1 − π r²)n−1 ≈ exp(−(n−1)π r²) = exp(−log n − 3 log log n + o(1)) = (log n)−3 / n (1+o(1)). Multiplying by n yields expected isolated vertices ≈ (log n)−3 → 0. By Markov’s inequality, the probability of any isolated vertex tends to 0. Penrose’s theorem states that the absence of isolated vertices implies connectivity for this radius regime, so G is connected whp.
Exam‑Day Strategy
When a question asks for a threshold radius in a random geometric graph, write down the expected degree λ = n π r². The connectivity threshold corresponds to λ = log n + ω(1). The giant component threshold corresponds to λ = 1 + ε. Memorise these two formulas and the role of isolated vertices; they appear in almost every exam on geometric random graphs.

The Probabilistic Method in the Proof of the Existence of Graphs with Large Independence Number and Bounded Maximum Degree

Given a graph G on n vertices with maximum degree Δ, the Caro–Wei bound guarantees an independent set of size at least Σv∈V 1/(deg(v)+1) ≥ n/(Δ+1). The probabilistic method gives a simple proof: order the vertices uniformly at random and select a vertex into the independent set if none of its earlier neighbours have been selected. The probability that a vertex v is selected is exactly 1/(deg(v)+1), and linearity of expectation yields the bound. This argument also shows that a random permutation produces an independent set of the expected size with positive probability, establishing existence.

For graphs with a given degree sequence, the bound can be sharpened using the alteration method. One first selects each vertex independently with probability p = 1/(Δ+1). The expected number of selected vertices is pn, while the expected number of edges inside the selected set is at most p² Δ n /2. Deleting one endpoint from each such edge removes at most p² Δ n /2 vertices, leaving an independent set of expected size at least pn − p² Δ n /2 = n/(2(Δ+1)). Optimising p gives the Caro–Wei bound up to a constant factor. This alteration step is a textbook illustration of the method: a random set is “cleaned” by a deterministic deletion.

When Δ grows with n, say Δ = nα with 0<α<1, the same probabilistic construction yields independent sets of size Ω(n1−α). This matches the known extremal results for graphs of bounded average degree. Examiners may ask to derive the bound for a specific degree sequence, for example a bipartite graph with left degree d₁ and right degree d₂. The probabilistic method adapts by choosing different selection probabilities on each side, leading to an independent set of size at least n₁/(d₁+1) + n₂/(d₂+1).

A common trap is to confuse the Caro–Wei bound with Turán’s theorem, which gives a lower bound on the independence number in terms of the average degree: α(G) ≥ n/(d̄+1). The Caro–Wei bound is always at least as strong because Σ 1/(deg(v)+1) ≥ n/(d̄+1) by Jensen’s inequality. Another trap is to assume that the probabilistic construction yields an algorithm that finds a maximum independent set; it only guarantees a set of the stated size, and finding a maximum independent set remains NP‑hard.

The Probabilistic Method in the Construction of Pseudorandom Generators via Random Walks on Expanders

Expander graphs have the property that a short random walk mixes rapidly to the uniform distribution. The probabilistic method shows that a random d‑regular graph is an expander with high probability (Friedman’s theorem). Using this, one can construct a pseudorandom generator G: {0,1}^k → {0,1}^m by taking a seed of length k, interpreting it as a starting vertex and a sequence of edge labels for a walk of length ℓ on a fixed expander, and outputting the visited vertices. The output length m = ℓ·log d. The security of the generator reduces to the fact that the walk’s distribution is ε‑close to uniform for ℓ = O(log n + log(1/ε)).

The analysis uses the expander mixing lemma: for any two subsets A,B of vertices, |E(A,B) − (d/n)|A||B|| ≤ λ√(|A||B|) where λ is the second eigenvalue. A random walk of length ℓ corresponds to multiplying the initial distribution by the transition matrix ℓ times. The spectral gap 1−λ/d controls the convergence rate. The probabilistic method enters twice: first to prove the existence of good expanders, second to argue that a random choice of the expander (from the uniform distribution on d‑regular graphs) yields a generator that fools any fixed polynomial‑time distinguisher with high probability. A union bound over all distinguishers of a given size then gives a single expander that works for all of them.

Impagliazzo, Nisan and Wigderson showed that this construction yields a generator with seed length k = O(log n) that stretches to m = nΩ(1) bits, assuming the expander is explicit. The probabilistic method provides the existence proof; derandomisation via the method of conditional expectations can then be used to find an explicit expander in polynomial time, yielding an explicit pseudorandom generator. Examiners often ask to state the expander mixing lemma and to explain how the spectral gap translates into the error parameter ε of the generator.

A typical trap is to confuse the random walk generator with the Nisan‑Wigderson generator, which uses a hard function and a combinatorial design rather than an expander. Another trap is to assume that any regular graph works; the spectral gap must be bounded away from 1, which fails for a random regular graph only with exponentially small probability. The probabilistic method quantifies this failure probability and shows it is negligible for the parameters used in cryptography.

The Probabilistic Method in the Construction of Random Linear Codes with Optimal Distance Distribution

A random linear code of length n and dimension k over 𝔽_q is obtained by choosing a k×n generator matrix uniformly at random. The probabilistic method proves the Gilbert–Varshamov bound: for any δ < 1−1/q there exist linear codes with relative distance δ and rate R ≥ 1−H_q(δ) where H_q is the q‑ary entropy function. The proof computes the expected number of codewords of weight ≤ δ n in a random linear subspace. By linearity of expectation, the expected number is Σw=1δ n (n choose w)(q−1)^w / qn−k. Setting k = n(1−H_q(δ)−ε) makes this expectation < 1, so a code with no such low‑weight codewords exists.

The alteration method strengthens this to show that a random linear code not only meets the GV bound but also has a distance distribution tightly concentrated around its mean. One first picks a random linear code, then expurgates (deletes) all codewords of weight < δ n. The expected number of deleted codewords is o(2^k), so the rate loss is negligible. This yields codes that achieve the GV bound and simultaneously have the optimal weight enumerator up to the first order. The second moment method (or Chebyshev) shows that the actual number of low‑weight codewords is sharply concentrated, so expurgation rarely removes more than a tiny fraction.

For list‑decoding, the probabilistic method shows that random linear codes achieve list‑decoding capacity: for any ε>0, a random linear code of rate 1−H_q(δ)−ε is (δ, L)-list‑decodable with L = O(1/ε). The proof uses a union bound over all possible received words and all possible lists of L+1 codewords, together with the fact that the probability a fixed set of L+1 codewords lies in a Hamming ball of radius δ n is q−(L+1)(n−k) times the volume of the ball. The linear structure simplifies the counting because the sum of codewords is again a codeword.

Examiners frequently ask to derive the GV bound for linear codes and to contrast it with the bound for general (non‑linear) codes, which is the same asymptotically but the linear construction is explicit up to the choice of the generator matrix. A common trap is to forget that the GV bound only guarantees existence for δ < 1−1/q; for larger δ the Plotkin bound shows no codes exist. Another trap is to assume that a random linear code is automatically good for unique decoding up to half the minimum distance; list‑decoding requires a separate argument, though the same probabilistic method works.

  • Confusing the connectivity threshold of a random geometric graph with the giant component threshold; they differ by a factor of √log n.
  • Assuming the perfect matching hitting time τ₁ works for odd n without stating the near‑perfect matching version.
  • Applying the Caro–Wei bound to graphs with unbounded maximum degree without adjusting the selection probability.
  • Treating any regular graph as an expander for pseudorandom generator constructions; the spectral gap must be bounded away from 1.
  • Using the Gilbert–Varshamov bound for relative distances δ ≥ 1−1/q where the Plotkin bound forbids any code.
  • Believing that the probabilistic method automatically yields an efficient algorithm for finding the constructed object; derandomisation is a separate step.

The Probabilistic Method in the Analysis of Random k‑SAT and the Satisfiability Threshold

Random k‑SAT is the canonical model for studying the typical difficulty of constraint satisfaction problems. One draws m clauses uniformly from all (2^k)·(n choose k) possible k‑clauses on n variables. The clause‑to‑variable ratio α = m/n controls the behaviour. The first moment method shows that if α > 2^k ln 2 then the expected number of satisfying assignments tends to zero, so the formula is unsatisfiable with high probability. The second moment method, refined by Achlioptas and Peres, proves that for α < (2^k ln 2) − Θ(1) the number of solutions is sharply concentrated around its mean, yielding satisfiability with high probability. The gap between the two bounds narrows as k grows, and the exact threshold α_k is known to satisfy α_k = 2^k ln 2 − (1+ln 2)/2 + o(1). The probabilistic method also underlies the clustering and condensation phase transitions: for α in an intermediate interval the solution space shatters into exponentially many clusters separated by linear Hamming distance, a phenomenon proved via the overlap distribution and the cavity method.

A key technical tool is the small‑subgraph conditioning method, which controls the variance of the number of solutions by analysing the contribution of short cycles in the factor graph. This technique shows that the second moment ratio remains bounded for α up to the condensation point. The method of moments is complemented by the interpolation method of Guerra and Toninelli, which gives rigorous upper bounds on the free energy and confirms the predicted threshold for large k. Examiners often ask to derive the first‑moment bound α > 2^k ln 2 and to explain why the second moment fails exactly at the clustering transition. A common trap is to confuse the satisfiability threshold with the algorithmic threshold; no polynomial‑time algorithm is known to find a solution for α beyond ≈ 2^k ln k / k, far below the information‑theoretic limit.

The probabilistic method also yields sharp results on the geometry of the solution space. For α below the clustering threshold, the set of solutions forms a single giant component in the Hamming graph; above it, the space splits into exponentially many well‑separated clusters. This clustering is proved by showing that the expected number of pairs of solutions at a given overlap is exponentially smaller than the square of the expected number of solutions. The overlap distribution is analysed via the replica symmetric and one‑step replica symmetry breaking ansätze, which are made rigorous by the Aizenman‑Sims‑Starr scheme. Understanding these phase transitions is essential for questions on the limits of local search algorithms and the performance of belief propagation.

The Probabilistic Method in the Construction of Quantum Error‑Correcting Codes via Random Stabilizer Codes

Random stabilizer codes provide a probabilistic proof of the quantum Gilbert–Varshamov bound. One selects a random (n−k)‑dimensional isotropic subspace of the Pauli group on n qubits, which defines a [[n,k,d]] stabilizer code. The distance d is the minimum weight of a non‑trivial Pauli operator commuting with all stabilizers. By linearity of expectation, the expected number of weight‑w logical operators is ( (3^w−1)·(n choose w) ) / 2n−k. Setting this expectation < 1 yields the existence of a code with relative distance δ satisfying H2(δ) + δ log2 3 ≤ 1 − k/n, where H2 is the binary entropy function. This is the quantum GV bound, first proved by Calderbank, Shor and Steane using the probabilistic method.

The alteration method strengthens the result: after picking a random stabilizer code, one can delete a small fraction of qubits (or equivalently, puncture the code) to eliminate all low‑weight logical operators while preserving the rate up to an arbitrarily small loss. This shows that random stabilizer codes not only meet the GV bound but also have a distance distribution tightly concentrated around its mean. For list‑decoding, the probabilistic method shows that random stabilizer codes achieve the quantum list‑decoding capacity: for any ε>0 a random code of rate 1−H2(δ)−δ log2 3−ε is (δ, L)‑list‑decodable with L = O(1/ε). The proof uses a union bound over all possible received quantum states and all lists of L+1 codewords, exploiting the fact that the sum of stabilizer codewords is again a codeword.

Examiners frequently ask to derive the quantum GV bound and to contrast it with the classical GV bound, noting the extra factor log2 3 arising from the three non‑identity Pauli operators per qubit. A typical trap is to forget that the bound only guarantees existence for δ ≤ 1/2; beyond that the Plotkin bound for quantum codes forbids any code. Another trap is to assume that the random construction yields an efficient encoding circuit; finding an explicit stabilizer matrix with the promised distance is a separate derandomisation problem, often solved by the method of conditional expectations applied to the weight enumerator polynomial.

Worked Example: First‑Moment Bound for Random 3‑SAT
Let n variables and m = α n clauses be chosen uniformly at random. Show that if α > 23 ln 2 = 8 ln 2 ≈ 5.545 then the formula is unsatisfiable with high probability.
The number of satisfying assignments X = Σ_{σ∈{0,1}^n} I_σ where I_σ indicates that σ satisfies all clauses. For a fixed σ, each clause is satisfied with probability 1−2−3=7/8, independently across clauses. Hence E[I_σ] = (7/8)α n. By linearity, E[X] = 2^n (7/8)α n = exp( n ( ln 2 + α ln(7/8) ) ). The exponent is negative exactly when α > ln 2 / ln(8/7) = 8 ln 2. By Markov's inequality, Pr[X≥1] ≤ E[X] → 0. Therefore the formula is unsatisfiable w.h.p. for α > 8 ln 2.
Exam‑Day Strategy
When a question asks for a threshold, first write the expectation of the relevant random variable. Identify the parameter (α, p, etc.) that makes the exponent change sign. State the first‑moment bound clearly, then mention whether the second moment or a more refined method (small‑subgraph conditioning, interpolation) is needed to close the gap. Cite the key names (Achlioptas‑Peres, Guerra‑Toninelli) to show depth.

The Probabilistic Method in the Proof of the Existence of Large Cap Sets in Finite Fields

A cap set in 𝔽3^n is a subset containing no three‑term arithmetic progression, equivalently no three distinct points x,y,z with x+y+z=0. The probabilistic method gives a simple lower bound: choose each element of 𝔽3^n independently with probability p = c·3−n/2. The expected size is p·3^n = c·3n/2. The expected number of progressions is at most p3·32n = c3·3n/2. By choosing c small enough, the expected number of progressions is less than half the expected size, so after deleting one element from each progression we obtain a cap set of size Ω(3n/2). This bound was the best known until the polynomial method of Croot‑Lev‑Pach and Ellenberg‑Gijswijt gave an upper bound of O(2.756^n), showing the probabilistic construction is exponentially far from optimal.

The alteration method can be pushed further by using a two‑stage random selection: first pick a random subspace of dimension n/2, then choose a random subset inside it. This yields a cap set of size Ω(3n/2) with a better constant, but still far from the true asymptotics. The probabilistic method also provides lower bounds for cap sets in 𝔽_q^n for larger q, where the best known constructions are still essentially random. Examiners may ask to compute the first‑moment bound for general q and to explain why the polynomial method breaks the probabilistic barrier for q=3 but not for larger q. A common trap is to confuse the cap‑set problem with the problem of finding large subsets without three‑term progressions in integers; the finite‑field version admits Fourier‑analytic tools that the integer version does not.

The Probabilistic Method in the Analysis of the Random Graph Process for the Emergence of a Giant Component in Hypergraphs

Consider the random k‑uniform hypergraph process on n vertices where hyperedges are added one by one uniformly at random. The analogue of the Erdős–Rényi giant component transition occurs when the average degree d = k·m/n crosses 1/(k−1). The first moment method shows that for d < 1/(k−1) all components have size O(log n) with high probability. The second moment method, combined with a branching‑process approximation, proves that for d > 1/(k−1) a unique giant component of linear size emerges. The critical window has width Θ(n−1/3) and the component sizes follow the same scaling limits as in the graph case, a result proved by Schmidt‑Pruzan and later refined by Karoński and Łuczak using the differential equation method.

The differential equation method tracks the evolution of the degree distribution and the number of vertices in components of each size as hyperedges are added. One writes a system of differential equations for the expected trajectories and shows concentration via martingale inequalities (Azuma–Hoeffding). This yields the precise hitting time for the giant component and the size of the largest component at criticality, which is Θ(n2/3). Examiners often ask to set up the differential equations for the 3‑uniform case and to identify the critical parameter. A typical trap is to treat hyperedges as independent edges in a graph projection; the overlap structure of hyperedges creates dependencies that must be handled by the configuration model or by the method of moments.

The Probabilistic Method in the Construction of Pseudorandom Functions via the Goldreich‑Levin Theorem

The Goldreich‑Levin theorem states that if f: {0,1}^n → {0,1}^n is a one‑way permutation, then the predicate B(x,r) = ⟨x,r⟩ mod 2 is a hard‑core bit for the function g(x,r) = (f(x), r). The probabilistic method enters the proof by showing that any algorithm that predicts B with advantage ε can be used to invert f with probability poly(ε)/n. One constructs a randomized inverter that queries the predictor on randomly chosen r and uses the pairwise independence of the inner products to recover x via a list‑decoding of the Hadamard code. The analysis uses the fact that for a fixed x, the map r ↦ ⟨x,r⟩ is a linear function, and a random r gives a uniformly random bit. The list‑decoding step is essentially the probabilistic method applied to the Hadamard code: a random linear function is far from any fixed Boolean function with high probability.

This construction yields a pseudorandom generator G(s) = (B(s, r1), …, B(s, r_m)) where the seed s is the pre‑image of a one‑way permutation and the r_i are public random strings. The security reduction shows that any distinguisher for G implies an inverter for f. The probabilistic method also proves the existence of hard‑core predicates for any one‑way function (not necessarily a permutation) by a similar argument using the Goldreich‑Levin lemma on the function f'(x,r) = (f(x), r). Examiners may ask to outline the reduction from a predictor for B to an inverter for f, and to explain why pairwise independence of the queries is sufficient. A common trap is to assume that the predictor must succeed on all r; the theorem only requires success on a noticeable fraction, and the list‑decoding step tolerates errors.

  • Applying the classical Gilbert–Varshamov bound to quantum codes without the log2 3 factor.
  • Assuming the probabilistic construction of cap sets matches the true asymptotics; the polynomial method gives a strictly better upper bound.
  • Treating hypergraph components as graph components after projection; the overlap of hyperedges changes the critical parameter.
  • Believing the Goldreich‑Levin hard‑core predicate works for any function without a one‑wayness assumption.
  • Forgetting that the alteration step in random stabilizer codes requires puncturing, which reduces the length and must be accounted for in the rate.
  • Misstating the critical average degree for the giant component in k‑uniform hypergraphs as 1 instead of 1/(k−1).

The Probabilistic Method in the Configuration Model for Random Graphs with Given Degrees

The configuration model, introduced by Bender and Canfield (1978) and independently by Bollobás (1980), provides a uniform random multigraph with a prescribed degree sequence d = (d₁,…,dₙ) satisfying Σdᵢ even. Each vertex v receives dᵥ half‑edges; a uniform perfect matching of all half‑edges yields a random multigraph possibly containing loops and multiple edges. The probabilistic method shows that if the maximum degree Δ = o(√n) and the degree sequence is graphical, then the probability that the resulting multigraph is simple is bounded away from zero. Consequently, a simple graph with the given degree sequence exists. The proof uses the first moment method to bound the expected number of loops and double edges, and a switching argument (McKay and Wormald, 1990) to remove them while preserving the degree sequence. This technique underpins many existence results: random regular graphs are expanders with high probability (Friedman, 2003), and the model serves as a null model for network science. A key technical point is that the number of pairings is (Σdᵢ−1)!!, and the probability of simplicity is exp(−(Σdᵢ²)/(2Σdᵢ) + o(1)) when Δ = o(n¹ᐟ⁴). The configuration model also enables the analysis of the random graph process with a fixed degree sequence via the differential equation method, tracking the evolution of the number of vertices of each degree as edges are added.

The Probabilistic Method in the Hitting Time for Connectivity in the Random Graph Process

In the Erdős–Rényi random graph process G(n,m) where edges are added one by one uniformly at random, the hitting time for connectivity coincides with the hitting time for the disappearance of isolated vertices. Erdős and Rényi (1960) proved that if m = (n/2)(log n + c) then the probability that G(n,m) is connected tends to e−e−c as n → ∞. The proof combines the first moment method to show that the expected number of isolated vertices is e−c + o(1), and the second moment method (or Poisson approximation) to show that the number of isolated vertices converges in distribution to a Poisson random variable with mean e−c. Bollobás and Thomason (1985) strengthened this to a hitting‑time theorem: with high probability, the graph becomes connected exactly at the step when the last isolated vertex acquires its first incident edge. The argument uses the fact that any component of size at least 2 has at least one edge to the rest of the graph once the minimum degree reaches 1, and that the probability of a component of size k (2 ≤ k ≤ n/2) having no external edges is at most (1 − k/n)m ≤ exp(−km/n). Summing over k and applying a union bound yields the result. This hitting‑time phenomenon extends to other monotone properties such as Hamiltonicity (Komlós and Szemerédi, 1983) and the existence of a perfect matching (Erdős and Rényi, 1966). The differential equation method can also track the number of isolated vertices dynamically, giving a precise description of the critical window of width Θ(n).

Worked Example: Hitting Time for Connectivity
Let G(n,m) be the random graph process on n vertices. Show that the probability G(n,m) is connected when m = (n/2)(log n + c) tends to e−e−c as n → ∞.
Let X be the number of isolated vertices in G(n,m). For a fixed vertex v, the probability it is isolated is (1 − (n−1)/N)^m where N = n(n−1)/2. Using m = (n/2)(log n + c) and N ≈ n²/2, we have (1 − 2/n)^m ≈ exp(−2m/n) = exp(−(log n + c)) = e−c/n. Hence E[X] = n · e−c/n = e−c + o(1). For the second moment, consider two distinct vertices u,v. The probability both are isolated is (1 − (2n−3)/N)^m ≈ exp(−2(2n)/n · m/N) = exp(−2(log n + c)) = e−2c/n². Thus E[X²] = E[X] + n(n−1)·e−2c/n² = e−c + e−2c + o(1). Therefore Var(X) = E[X²] − (E[X])² → e−c. By the method of moments (or Stein–Chen Poisson approximation), X converges in distribution to Poisson(e−c). The graph is connected iff X = 0, so the limiting probability is P(Poisson(e−c) = 0) = e−e−c.
Exam‑Day Strategy
When asked for a hitting‑time result, first identify the monotone property and the “obstacle” (e.g., isolated vertices for connectivity). Compute the expectation of the obstacle count at the candidate threshold using the first moment method. Then verify that the variance is of the same order (second moment) to obtain a Poisson limit. Remember that the hitting‑time theorem often states that the property appears exactly when the last obstacle disappears; cite the relevant theorem (Bollobás–Thomason for connectivity, Komlós–Szemerédi for Hamiltonicity).

The Probabilistic Method in the Existence of Good Locally Recoverable Codes via Random Constructions

A locally recoverable code (LRC) over a finite field 𝔽_q is a linear code C ⊆ 𝔽_q^n such that every coordinate can be recovered from at most r other coordinates (locality r). The Singleton‑type bound for LRCs (Gopalan et al., 2012) states that for an (n,k,d) code with locality r, d ≤ n − k − ⌈k/r⌉ + 2. The probabilistic method shows that random linear codes meet this bound asymptotically. Choose a random parity‑check matrix H of size (n−k) × n where each row has weight at most r+1 and the rows are chosen independently from a distribution that ensures each coordinate participates in at least one low‑weight parity check. By the alteration method, one first picks a random linear code of rate R = k/n, then deletes coordinates that violate the locality requirement or have too many low‑weight codewords. Using the Gilbert–Varshamov argument adapted to the LRC setting (Rawat et al., 2014), one proves that for any δ > 0 there exist LRCs with rate R ≥ 1 − H_q(δ) − (1/r) + o(1) and relative distance δ, where H_q is the q‑ary entropy function. The proof applies the first moment method to bound the expected number of “bad” coordinates and the second moment method to show concentration. Recent work (Huang et al., 2020) uses the Lovász Local Lemma to remove the alteration step entirely, giving a fully probabilistic existence proof for LRCs achieving the optimal trade‑off between locality, distance, and rate. These constructions are explicit in the sense that a random seed determines the code, and they form the basis for practical distributed storage systems such as Windows Azure Storage.

The Probabilistic Method in the Chung–Lu Model for Power‑Law Random Graphs

The Chung–Lu model (Chung and Lu, 2002) generates a random graph on n vertices with a prescribed expected degree sequence w = (w₁,…,wₙ). Edges are independent; the probability of an edge between i and j is pij = w_i w_j / Σ_k w_k, capped at 1. When the weights follow a power‑law distribution w_i ∝ i−1/(β−1) with exponent β > 2, the resulting graph exhibits a power‑law degree distribution with the same exponent. The probabilistic method yields sharp concentration results: for any ε > 0, the actual degree of vertex i is (1 ± ε)w_i with probability 1 − o(1) provided w_i = Ω(log n). The emergence of a giant component is governed by the parameter ν = Σ w_i² / Σ w_i. If ν > 1, a unique giant component of linear size exists; if ν < 1, all components are of size O(log n). The critical window ν = 1 + Θ(n−1/3) has width Θ(n−1/3) and component sizes scale as n2/3, mirroring the Erdős–Rényi case (Chung and Lu, 2004). The proof uses the differential equation method to track the exploration process of a component, coupled with Azuma–Hoeffding inequalities for concentration. The model also gives precise asymptotics for the diameter: when β ∈ (2,3) the diameter is Θ(log log n) (ultra‑small world), and when β > 3 it is Θ(log n). These results are derived by analyzing the growth of neighborhoods via branching processes with power‑law offspring distributions, and applying the first and second moment methods to the number of vertices at each distance.

The Probabilistic Method in the Construction of Random Graphs with Prescribed Subgraph Densities via Graphons

A graphon is a symmetric measurable function W : [0,1]² → [0,1]. For a dense graph sequence (G_n), the subgraph densities t(F, G_n) converge to t(F, W) = ∫[0,1]|V(F)| ∏uv∈E(F) W(x_u, x_v) dx. Lovász and Szegedy (2006) proved that every graphon can be approximated by a sequence of random graphs sampled from W: for each n, generate G(n,W) by choosing n independent uniform points x₁,…,x_n ∈ [0,1] and including edge ij with probability W(x_i, x_j). The probabilistic method shows that for any fixed finite family of graphs F₁,…,F_k and target densities d₁,…,d_k that are realizable by some graphon, there exists a graph G on n vertices with |t(F_i, G) − d_i| < ε for all i, provided n is sufficiently large. The proof uses the first moment method to bound the expected deviation of subgraph counts from their means, and a concentration inequality (McDiarmid’s bounded differences) to show that the actual counts are close to their expectations with high probability. This yields an alternative proof of the existence of graphs with prescribed subgraph densities, complementing the regularity‑lemma approach. Moreover, the graphon framework enables the probabilistic construction of graphs with specific flag algebra constraints, used in extremal combinatorics to prove density theorems (Razborov, 2007). The method also underlies the theory of graph limits and the cut metric, providing a bridge between probabilistic combinatorics and analytic graph theory.

  • Assuming the hitting time for connectivity equals the hitting time for minimum degree 1 without verifying that no component of size ≥ 2 can be isolated when the last isolated vertex disappears.
  • Applying the classical Gilbert–Varshamov bound directly to locally recoverable codes; the locality constraint changes the volume of the Hamming ball and the bound becomes d ≤ n − k − ⌈k/r⌉ + 2.
  • Treating the Chung–Lu edge probabilities as exactly w_i w_j / Σ w_k without the min(1, …) cap; for large weights this can exceed 1 and break independence.

The Probabilistic Method in the Construction of Random Graphs with Prescribed Spectral Properties

The spectrum of the adjacency matrix of a graph encodes expansion, mixing time, and many algorithmic properties. A central question is whether for every ε > 0 there exist d‑regular graphs on n vertices whose non‑trivial eigenvalues λ satisfy |λ| ≤ 2√(d − 1) + ε, i.e. graphs that are almost Ramanujan. Friedman’s 2003 theorem proves that a random d‑regular graph (sampled uniformly from all d‑regular graphs on n vertices) satisfies this bound with probability 1 − o(1). The proof uses the configuration model to generate a random pairing of dn half‑edges, then applies the trace method: for any even integer k, the expected trace of A^k equals the expected number of closed walks of length k. By bounding the contribution of non‑tree‑like walks via the first moment method and showing concentration with the second moment method, one obtains that the spectral radius of the non‑trivial part is at most 2√(d − 1) + o(1). Later work by Bordenave (2015) gave a simpler proof using the non‑backtracking operator and the Ihara–Bass formula, again relying on the probabilistic method to control the empirical spectral distribution. These results imply the existence of infinite families of expanders with optimal spectral gap, which are crucial for derandomization, error‑correcting codes, and fast mixing Markov chains.

Key Steps in the Trace Method

  1. Generate a random d‑regular graph via the configuration model; condition on simplicity (probability bounded away from zero for fixed d).
  2. For even k = O(log n), compute E[tr(A^k)] = Σv E[(A^k)vv]. Each term counts closed walks of length k starting at v.
  3. Classify walks by their “shape” (the underlying graph of the walk). Tree‑like walks contribute exactly the Catalan numbers, giving the spectral radius 2√(d − 1). Non‑tree walks contain cycles; their number is bounded by n·(d − 1)k/2·n−c for some c > 0.
  4. Apply Markov’s inequality to show that with high probability tr(A^k) ≤ (1 + o(1))·n·(2√(d − 1))^k.
  5. Use the fact that for any eigenvalue λ, λ^k ≤ tr(A^k) to deduce |λ| ≤ 2√(d − 1) + ε.

The same framework extends to random lifts of a fixed base graph, yielding new families of expanders with prescribed girth and spectral gap. The probabilistic method thus provides not only existence but also quantitative estimates on the fraction of graphs achieving the bound.

The Probabilistic Method in the Analysis of Random Hypergraph Processes for the Emergence of a Giant Component

In a k‑uniform hypergraph (k ≥ 3) on n vertices, edges are k‑element subsets. The random hypergraph process adds edges one by one uniformly at random. The analogue of the Erdős–Rényi giant component threshold is governed by the expected degree d = k·m / n, where m is the number of edges. Schmidt‑Pruzan (1985) and later Karoński‑Łuczak (2002) showed that a giant component (a component containing Θ(n) vertices) appears when d exceeds 1/(k − 1). The proof tracks the exploration process of a component via a branching process whose offspring distribution is Binomial(n, p) conditioned on the hypergraph structure. The differential equation method (Wormald, 1995) yields a system of ODEs for the expected number of vertices of each “type” (active, explored, untouched). Concentration follows from Azuma–Hoeffding inequalities applied to the Doob martingale of the exploration. At the critical window d = 1/(k − 1) + Θ(n−1/3), component sizes scale as n2/3 and the largest component size converges to the same scaling limit as in the graph case (Aldous, 1997). The probabilistic method also gives sharp hitting‑time results: the moment the last isolated vertex disappears coincides with the emergence of a unique giant component, provided k ≥ 3 and the hypergraph is simple (no repeated edges). Recent work by Cooley, Kang, and Koch (2019) extends these results to non‑uniform hypergraphs and to the emergence of a “core” (the maximal subhypergraph with minimum degree at least 2). The core appears at the same threshold as the giant component and its size can be computed via the survival probability of the associated branching process.

Exploration Process and Differential Equations

Let X_t be the number of active vertices after t steps of the breadth‑first search. The expected change E[Xt+1 − X_t | history] equals (k − 1)·(remaining edges)/(remaining vertices) − 1. In the limit n → ∞ this becomes the ODE dx/dτ = (k − 1)·x·(1 − τ) − 1, where τ = t/n. Solving gives the trajectory of the exploration; the giant component exists iff the solution stays positive for a linear fraction of τ. The second moment method on the number of vertices reached at each step shows that the actual process stays within n−1/3 of the deterministic trajectory with probability 1 − o(1).

Worked Example: Expected Number of Triangles in G(n,p) and Alteration
Let G ∼ G(n,p) with p = c·n−2/3 for a constant c > 0. Compute the expected number of triangles T and the expected number of edges E. Then describe how the alteration method can be used to obtain a graph with no triangles and at least (1 − o(1))·E edges.
The number of triangles is a sum over all binom{n}{3} triples of indicator variables. Each triple forms a triangle with probability p3. Hence E[T] = binom{n}{3} p3 ≈ (n3/6)·c3·n−2 = (c3/6)·n. The expected number of edges is E[E] = binom{n}{2} p ≈ (n2/2)·c·n−2/3 = (c/2)·n4/3. Since E[T] = Θ(n) while E[E] = Θ(n4/3), the expected number of triangles is lower order. By Markov’s inequality, with probability at least 1/2 we have T ≤ 2E[T] = O(n). Delete one edge from each triangle; at most O(n) edges are removed. The remaining graph has at least E[E] − O(n) = (c/2)·n4/3 − O(n) edges and contains no triangles. This is the alteration method: first sample a random object, then delete a small set of “bad” structures to obtain a graph with the desired property.
Exam‑Day Strategy
When a problem asks for the existence of a graph with a global property (e.g., no triangles, large girth, spectral gap), first compute the expected number of “bad” local configurations in G(n,p). If the expectation is o(expected number of edges/vertices), the alteration method yields the desired graph. Remember to check that the deletion step does not destroy the main parameter (rate, degree, etc.) by more than a lower‑order term.

The Probabilistic Method in the Proof of the Existence of Good List‑Decodable Codes with Constant Query Complexity

List decoding asks for a code C ⊆ Σ^n such that for any received word y ∈ Σ^n, the number of codewords within Hamming radius ρn is at most L (the list size). The list‑decoding capacity states that for any ε > 0 there exist codes of rate R ≥ 1 − H_q(ρ) − ε that are (ρ, L)‑list‑decodable with L = O(1/ε). Guruswami, Rudra, and others showed that random linear codes achieve this capacity. The probabilistic method proceeds by fixing a linear map G: 𝔽_q^k → 𝔽_q^n chosen uniformly at random. For any fixed set of L + 1 distinct messages, the probability that all their codewords lie in a Hamming ball of radius ρn is at most q−(L+1)(n−k)·Vol_q(ρn)L+1, where Vol_q(ρn) is the volume of a q‑ary Hamming ball. A union bound over all binom{q^k}{L+1} choices of messages shows that the expected number of “bad” (L+1)‑tuples is < 1 provided R < 1 − H_q(ρ) − ε. The Lovász Local Lemma can remove the union bound’s dependence on L, giving a fully probabilistic existence proof for constant L. Moreover, by sampling the generator matrix from a pairwise independent distribution, one obtains an explicit construction that can be decoded with O(1) queries to the received word (local list decoding). Recent work by Brakensiek, Gopi, and others (2022) uses the entropy compression method to derandomize the construction while preserving constant query complexity, yielding explicit locally list‑decodable codes meeting the capacity bound.

Key Parameters

  • Alphabet size q (prime power).
  • Rate R = k/n.
  • Relative radius ρ ∈ (0, 1 − 1/q).
  • List size L = ⌈1/ε⌉.
  • Volume bound Vol_q(ρn) ≤ qn H_q(ρ).

The first moment method controls the expected number of large lists; the second moment method (or Chebyshev) shows concentration, so a random linear code is good with probability 1 − o(1). The alteration step of expurgating a small fraction of codewords can further improve the distance without affecting the rate asymptotically.

The Probabilistic Method in the Construction of Random Graphs with Given Clustering Coefficient via the Triadic Closure Model

Real‑world networks exhibit a high clustering coefficient (the probability that two neighbors of a vertex are adjacent). The classical Erdős–Rényi model G(n,p) has clustering ≈ p, which vanishes for sparse graphs. The triadic closure model (Newman, 2003) generates a random graph by starting with a random matching of half‑edges (as in the configuration model) and then, for each vertex, adding edges between its neighbors with probability φ. Equivalently, one can define a random graph G(n, p, φ) where each triangle is present independently with probability φ and each edge not in a triangle is present with probability p. The probabilistic method shows that for any target clustering coefficient C ∈ (0,1) and average degree d = Θ(1), there exists a sequence of graphs with clustering → C and degree distribution converging to a prescribed law. The proof uses the first moment method to compute the expected number of triangles and edges, then applies the alteration method to delete a small set of edges that create excess clustering or degree deviations. Concentration follows from the Azuma–Hoeffding inequality applied to the exposure martingale of the edge‑by‑edge construction. The resulting graphs have a giant component when d·(1 + 2φ) > 1, and the size of the giant component can be derived from the survival probability of a two‑type branching process (type = edge, triangle). This model has been used to study epidemic spreading, where clustering reduces the effective reproduction number. The probabilistic method also yields sharp thresholds for the emergence of a k‑core in clustered random graphs (Miller, 2009).

Two‑Type Branching Process for Component Exploration

When exploring a component, one encounters two kinds of “half‑edges”: those belonging to ordinary edges and those belonging to triangles. The offspring generating functions are f_E(x,y) = exp(λ_E (x − 1) + λ_T (y − 1)) and f_T(x,y) = exp(λ_T (x − 1) + λ_T (y − 1)), where λ_E and λ_T are the mean numbers of edge‑ and triangle‑half‑edges per vertex. The survival probability of this process gives the fraction of vertices in the giant component. The probabilistic method guarantees that the actual component sizes concentrate around the deterministic prediction.

  • Assuming the giant component threshold in k‑uniform hypergraphs is the same as in graphs (it is 1/(k − 1), not 1).
  • Overlooking that list‑decoding capacity requires the rate to be strictly less than 1 − H_q(ρ); equality cannot be achieved by random codes without expurgation.
  • Treating the clustering coefficient in the triadic closure model as exactly φ; the actual clustering is φ·(1 − p) / (1 − p + φ·p) and requires solving a fixed‑point equation.
  • Believing that the alteration step in spectral constructions can be omitted; the configuration model produces loops and multiple edges that must be removed, slightly changing the degree distribution.
  • Misapplying the Lovász Local Lemma to list‑decoding without verifying the dependency graph’s maximum degree; the events “a given (L+1)‑tuple lies in a ball” are not mutually independent.

These advanced topics illustrate how the probabilistic method adapts to spectral, hypergraph, coding, and clustering settings, each requiring careful moment calculations, concentration inequalities, and sometimes the Lovász Local Lemma to obtain optimal existence results.

The Probabilistic Method in the Construction of Random Graphs with Given Degree Sequences via the Switching Method

The switching method provides a direct Markov chain on the space of simple graphs that realise a prescribed degree sequence d = (d₁, d₂, …, dₙ). Unlike the configuration model, which first creates a random pairing of half‑edges and then deletes loops and multiple edges, the switching chain stays entirely within the set of simple graphs. A single switching step selects two edges {u,v} and {x,y} uniformly at random from the current graph, requiring that the four vertices be distinct and that the edges {u,x} and {v,y} are absent. If these conditions hold, the chain replaces the two edges by the new pair; otherwise it stays put. This operation preserves the degree of every vertex, so the chain is confined to the state space Ω(d) of all simple graphs with degree sequence d.

The transition matrix is symmetric, therefore the uniform distribution on Ω(d) is stationary. Irreducibility of the switching graph — the graph whose vertices are the elements of Ω(d) and whose edges correspond to valid switchings — was established by Taylor (1981) for all graphic sequences with maximum degree at most n/2, and later extended by Kannan, Tetali and Vempala (1999) to a broader class. Consequently, the chain converges to the uniform distribution, providing an exact sampler for random graphs with the given degrees.

The probabilistic method enters when one uses this sampler to prove existence of graphs with additional structural properties. For example, to show that there exists a d‑regular graph on n vertices with girth at least g, one can argue that a uniformly random d‑regular graph has girth ≥ g with positive probability. The switching chain gives a concrete way to approximate that uniform distribution, and concentration inequalities (e.g., Azuma–Hoeffding on the exposure martingale of the chain) show that the girth of the graph after polynomially many steps is close to its expectation. McKay and Wormald (1990) used a related switching argument to derive the asymptotic number of d‑regular graphs, and their technique underpins many modern enumeration results.

Applications extend to network science, where the switching chain serves as a null model for testing hypotheses about real‑world networks. Because the chain mixes rapidly for a wide range of degree sequences (see the next section), it is practical for Monte Carlo estimation of graph statistics such as clustering coefficient, assortativity, or the number of triangles.

The Probabilistic Method in the Analysis of Random Graphs with Given Degree Sequences: The Switching Method and Rapid Mixing

Rapid mixing of the switching chain means that the total variation distance to the uniform distribution drops below ε after a number of steps polynomial in n and log(1/ε). The canonical paths method, introduced by Jerrum and Sinclair (1989) for the permanent, is the standard tool for proving such bounds. For any ordered pair (G,H) of graphs in Ω(d) one defines a canonical path γG,H in the switching graph. The congestion of an edge e = (G',G'') is

ρ(e) = (1 / π(e)) ΣγG,H ∋ e π(G) π(H) |γG,H|,

where π is the uniform stationary distribution. The mixing time is then bounded by O(ρ* log(1/π_min)), where ρ* is the maximum congestion over all edges.

Cooper, Dyer and Greenhill (2007) constructed canonical paths for d‑regular graphs with d = o(n1/2). Their path transforms G into H by repeatedly eliminating edges in the symmetric difference. At each step they pick an edge {u,v} ∈ G H and an edge {x,y} ∈ H G, then perform a switching that replaces {u,v} and {x,y} by {u,x} and {v,y}, provided the new edges are not already present. They showed that the number of switchings needed is at most the size of the symmetric difference, and that the congestion satisfies ρ* = O(n² d²). This yields a mixing time of O(n² d² log n), which is polynomial for d = o(n1/2).

Greenhill (2015) extended the result to general degree sequences with maximum degree Δ = o(n1/4). The path construction is more delicate because high‑degree vertices can create bottlenecks. The proof uses a “switching method” lemma that guarantees the existence of a suitable switching at each step with high probability, and applies the Lovász Local Lemma to avoid configurations that would block the path. The final bound is O(n² Δ⁴ log n), still polynomial under the stated condition.

These rapid mixing results justify the use of the switching chain for approximate counting via the Markov chain Monte Carlo framework. By running the chain for a polynomial number of steps and using the self‑reducibility of the counting problem, one obtains a fully polynomial randomised approximation scheme (FPRAS) for the number of graphs with a given degree sequence, provided the degree constraints satisfy the mixing conditions.

Canonical Paths for the Switching Chain
Explain how the canonical paths method is used to prove rapid mixing of the switching chain for d‑regular graphs. Include the definition of congestion and the key bound obtained by Cooper, Dyer and Greenhill (2007).
The canonical paths method assigns to each ordered pair (G,H) of d‑regular graphs a path γG,H in the switching graph. The congestion of an edge e = (G',G'') is ρ(e) = (1/π(e)) ΣγG,H ∋ e π(G)π(H) |γG,H|. Since π is uniform, π(e) = 1/|Ω| and π(G)=π(H)=1/|Ω|. Cooper, Dyer and Greenhill construct paths by repeatedly switching an edge from GH with an edge from HG, reducing the symmetric difference by two each step. They prove that each switching graph edge lies on at most O(n² d²) such paths, and each path has length at most n d. Hence ρ* = O(n² d²). The mixing time τ(ε) ≤ ρ* (log(1/π_min) + log(1/ε)) = O(n² d² log n) for d = o(n1/2). This polynomial bound establishes rapid mixing.

The Probabilistic Method in the Construction of Random Graphs with Given Degree Sequences via the Switching Method for Bipartite Graphs

For bipartite graphs with vertex partitions U and V and prescribed degree sequences d_U = (d_u)u∈U and d_V = (d_v)v∈V, the switching operation is adapted to respect the bipartition. One selects two edges (u₁,v₁) and (u₂,v₂) with u₁,u₂ ∈ U and v₁,v₂ ∈ V, all four vertices distinct, and replaces them by (u₁,v₂) and (u₂,v₁) provided these edges are not already present. This preserves the degree of every vertex in both partitions. The state space Ω(d_U,d_V) consists of all simple bipartite graphs with the given degree sequences.

The switching graph on Ω(d_U,d_V) is connected under the mild condition that no vertex degree exceeds the size of the opposite partition (a necessary condition for any bipartite realisation). The Markov chain that performs a uniformly random valid switching at each step is symmetric, so its stationary distribution is uniform on Ω(d_U,d_V). Dyer, Greenhill and Jerrum (2002) analysed the mixing time of this chain for regular bipartite graphs. They proved rapid mixing for d‑regular bipartite graphs with d = o(n1/2) by constructing canonical paths analogous to the non‑bipartite case, but with the additional constraint that switchings never create edges inside U or inside V. The congestion bound remains O(n² d²), yielding a mixing time of O(n² d² log n).

The probabilistic method is used to show existence of bipartite graphs with high girth, large expansion, or specific subgraph densities. For instance, to construct a bipartite expander with left degree d and right degree Δ, one can argue that a uniformly random bipartite graph with those degrees has expansion at least (1−ε)d with probability tending to 1. The rapid mixing of the switching chain guarantees that a polynomial‑time simulation produces a graph whose expansion is close to the expectation. Such graphs are crucial in the design of low‑density parity‑check (LDPC) codes, where the Tanner graph must be a bipartite expander to ensure good decoding performance.

Recent work by Greenhill and Sfragara (2020) extended rapid mixing to general bipartite degree sequences with maximum degree Δ = o(n1/4), using a refined path construction that avoids high‑degree vertices on both sides. This broadens the applicability of the switching chain to realistic network models where degree distributions are heterogeneous.

The Probabilistic Method in the Construction of Random Graphs with Given Degree Sequences via the Switching Method for Directed Graphs

Directed graphs are specified by an in‑degree sequence d⁻ = (d⁻_v) and an out‑degree sequence d⁺ = (d⁺_v). A switching step chooses two directed edges (u→v) and (x→y) with all four vertices distinct, and replaces them by (u→y) and (x→v) provided neither new edge already exists and no loops are created. This operation preserves both the in‑degree and out‑degree of every vertex. The state space Ω(d⁻,d⁺) is the set of all simple directed graphs (no loops, no parallel arcs in the same direction) realising the given sequences.

Kannan, Tetali and Vempala (1999) introduced the switch chain for directed graphs and proved that the switching graph is connected whenever the degree sequences satisfy the Gale–Ryser conditions for directed graphs. The chain is symmetric, so the uniform distribution on Ω(d⁻,d⁺) is stationary. Cooper, Dyer and Greenhill (2007) later established rapid mixing for regular directed graphs (where d⁻_v = d⁺_v = d for all v) with d = o(n1/2). Their canonical paths mimic the undirected construction, but each switching must respect the orientation of arcs. The congestion analysis yields the same O(n² d²) bound, giving a mixing time of O(n² d² log n).

For general directed degree sequences, Greenhill (2011) proved rapid mixing under the condition max(d⁻_v, d⁺_v) = o(n1/4). The proof again uses the Lovász Local Lemma to show that a suitable switching exists at each step of the canonical path with high probability, avoiding configurations that would disconnect the path. This result enables the use of the switch chain as an FPRAS for counting directed graphs with prescribed degree sequences, a problem relevant to the analysis of citation networks, web graphs, and ecological food webs.

The probabilistic method also yields existence results for directed graphs with additional properties. For example, one can show that a uniformly random directed graph with given in/out degrees has a giant strongly connected component with high probability, provided the average degree exceeds 1. The switching chain provides a polynomial‑time sampler to generate such graphs for simulation studies.

  • Assuming rapid mixing holds for all degree sequences; the known bounds require Δ = o(n1/4) for general sequences and d = o(n1/2) for regular graphs.
  • Overlooking that the canonical paths construction for bipartite graphs must never create edges inside the same partition, which changes the congestion analysis.
  • Treating the directed switching chain as identical to the undirected one; orientation constraints double the number of forbidden configurations and affect the connectivity proof.
  • Believing that the Lovász Local Lemma is only used for existence proofs; in the mixing‑time analysis it is used to guarantee that a valid switching exists along the canonical path with high probability.
