The Probabilistic Method — Random Graphs, the Alteration Method & the Lovász Local Lemma

The Probabilistic Method is one of the most powerful and elegant tools in combinatorics, pioneered by Paul Erdős in the 1940s. The basic idea is deceptively simple: to prove that an object with a certain property exists, one defines a probability space over candidate objects and shows that the probability a random object has the desired property is positive. This non-constructive technique has produced spectacular results across Ramsey theory, graph theory, discrepancy theory, and the theory of random graphs. The Erdős–Rényi random graph G(n,p) serves as the canonical probability space. The first moment method (Markov's inequality) shows that if the expected number of "bad" objects tends to zero, then a desirable structure exists almost surely. The second moment method (Chebyshev's inequality or the Paley–Zygmund inequality) handles cases where the expected count diverges but the variance is small relative to the mean. The alteration method — construct a random structure and then delete offending elements — yields improved bounds for Ramsey numbers. The Lovász Local Lemma (LLL) handles situations with many unlikely but mildly dependent bad events. The differential equation method tracks random processes via their expected drift, while concentration inequalities (Chernoff, Azuma, Talagrand) quantify how tightly random variables concentrate around their means.

"If you cannot prove what you want, prove something else and hope it's close enough."
— Paul Erdős
Part 1

📏 The First and Second Moment Methods

Moments
Markov's Inequality, Chebyshev's Inequality, and the Moment Methods
Markov's inequality: for a non-negative random variable X and t > 0, we have P(X ≥ t) ≤ E[X]/t. This simple bound is the foundation of the first moment method. If X counts the number of "bad" configurations and we show E[X] → 0, then P(X = 0) → 1 — the desired structure exists asymptotically almost surely. Example — lower bound on the Ramsey number R(k,k): consider G(n,½) with edges appearing independently with probability ½. For a fixed k-set S, the probability S is monochromatic (all edges present or all absent) is 2·2^{−C(k,2)} = 2^{1−k(k−1)/2}. The expected number X of monochromatic K_k is E[X] = 2·(n choose k)·2^{−C(k,2)}. When n < 2^{k/2}, we have E[X] < 1, so P(X = 0) > 0 — there exists a 2-coloring of K_n with no monochromatic K_k, giving R(k,k) > 2^{k/2}.

Chebyshev's inequality: P(|X − E[X]| ≥ t) ≤ Var(X)/t². The second moment method says: if Var(X)/E[X]² → 0, then P(X > 0) → 1. Equivalently, if E[X²] ∼ E[X]² (i.e., E[X²]/E[X]² → 1), then X concentrates. The Paley–Zygmund inequality: P(X > 0) ≥ E[X]²/E[X²] for non-negative X — useful when E[X] is large but P(X = 0) might still be significant. Example — threshold for triangles in G(n,p): let X be the number of triangles in G(n,p). When p = c/n with c constant, E[X] = (n choose 3)p³ → c³/6. Computing the second moment shows E[X²] ∼ E[X]² + O(E[X]) and thus P(X > 0) → 1 − exp(−c³/6) as n→∞. The threshold for the appearance of a triangle is precisely p = Θ(1/n).
The first moment method shows nonexistence by vanishing expectation; the second moment method shows existence by controlling the variance relative to the mean.
Part 2

🌍 The Alteration Method and Random Graphs

Alteration
Constructing Random Structures, Then Deleting Offending Elements
The alteration method works in two steps: (1) construct a random object, (2) delete elements that violate the desired property, and argue that enough remains. This typically gives better bounds than a direct first-moment approach.

Example — lower bound R(3,k): we want a K₃-free graph on n vertices with no independent set of size k (i.e., α(G) < k). Consider G(n,p) with p = c/n. The expected number of triangles is O(1). For each triangle, delete one vertex; the remaining graph G' is K₃-free on n' ≥ n − O(1) vertices. The independence number α(G') ≤ α(G), and for G(n,c/n), α(G) ≤ (3 log n)/c almost surely. Thus R(3,k) ≥ c'·k²/log²k — the best known lower bound up to constants.

Phase transitions in G(n,p): the random graph G(n,p) undergoes dramatic changes as p grows. When p ≪ 1/n, the graph consists of isolated trees and cycles. At p = 1/n, the giant component emerges — a connected component of size Θ(n). This is the percolation threshold. At p = (log n)/n, the graph becomes connected — the connectivity threshold. At p = (log n + log log n)/n, the graph becomes Hamiltonian — the Hamiltonicity threshold. More generally, for any monotone graph property, there is a sharp threshold function p(n) where the property goes from almost surely false to almost surely true.
The alteration method trades a small number of deletions for a much cleaner structure — a recurring theme in probabilistic combinatorics.
Part 3

🧮 The Lovász Local Lemma

LLL
The Symmetric and General LLL, the Algorithmic LLL, and the Moser–Tardos Theorem
The Lovász Local Lemma (Erdős–Lovász, 1973) is a powerful tool for avoiding "bad" events when each event is unlikely and depends on few other events. Symmetric LLL: let A₁,…,Aₙ be events with P(A_i) ≤ p, and suppose each A_i depends on at most d other events. If ep(d+1) ≤ 1 (equivalently p ≤ 1/(e(d+1))), then P(∩ ̄A_i) > 0 — with positive probability, none of the bad events occur.

General LLL: suppose there exist real numbers x_i ∈ (0,1) such that for each i, P(A_i) ≤ x_i·Π_{j∈N(i)} (1−x_j). Then P(∩ ̄A_i) ≥ Π (1−x_i) > 0. This weighted version is more flexible and often gives better bounds.

Application — k-SAT: for a k-CNF formula where each clause has k distinct literals and each variable appears in at most 2^{k−1}/(ek) clauses, the LLL guarantees satisfiability. Let A_i be the event that clause i is falsified; P(A_i) = 2^{−k}. Each clause shares variables with at most d = k·(2^{k−1}/(ek) − 1) ≈ 2^{k−1}/e other clauses. The condition p ≤ 1/(e(d+1)) holds, so there exists a satisfying assignment.

Algorithmic LLL (Moser–Tardos, 2010): when the events are determined by independent random variables (the variable model), the LLL conditions guarantee that the simple resampling algorithm terminates quickly: sample all variables; while any A_i occurs, resample all variables that determine A_i. The expected number of resampling steps is polynomial in n. The proof uses a beautiful resampling table argument and the analysis of a branching process (the "witness tree").
The LLL transforms the probabilistic method into an algorithmic tool: if bad events are rare and localized, the simple resampling strategy finds a good configuration efficiently.
Part 4

🔥 Concentration Inequalities and the Differential Equation Method

Concentration
Chernoff Bounds, Azuma's Inequality, Talagrand's Inequality, and the Differential Equation Method
Chernoff bounds: for independent X_i ∈ {0,1} with sum S = Σ X_i and μ = E[S], we have P(|S − μ| ≥ εμ) ≤ 2·exp(−ε²μ/3) for 0 < ε < 1, and P(|S − μ| ≥ t) ≤ 2·exp(−2t²/n) for additive deviations. These are exponentially tight and fundamental for random graph analysis.

Azuma–Hoeffding inequality: for a martingale (M_n) with |M_i − M_{i−1}| ≤ c_i, we have P(|M_n − M_0| ≥ t) ≤ 2·exp(−t²/(2Σ c_i²)). This is the workhorse for concentration in random processes — e.g., the vertex-exposure martingale for G(n,p). Example — chromatic number of G(n,½): the vertex-exposure martingale shows χ(G(n,½)) is concentrated within O(√n) of its mean (which is ∼ n/(2 log₂ n)), and Talagrand's inequality sharpens this to O(√n).

Talagrand's inequality: for Lipschitz functions on product spaces, the distribution of f(X) is tightly concentrated around its median. It applies even when the Lipschitz condition holds in a "certificate" sense — the function must satisfy that small changes in many coordinates are needed to alter the output significantly.

The differential equation method (Wormald): to analyze a random process over time, compute the expected change in state variables per step, write a system of differential equations describing the limiting trajectory, and use martingale concentration (Azuma's inequality) to prove the actual process stays close to the deterministic trajectory with high probability. Applications: the random greedy algorithm for finding large independent sets, the evolution of the giant component in G(n,p) (Karp's O(n³) algorithm), the analysis of the random k-SAT threshold, and the behavior of the Erdős–Rényi graph process.

Pseudo-random graphs: graphs that mimic the properties of random graphs without being random. The Paley graphs are canonical examples. The Chung–Graham–Wilson theorem characterizes quasi-random graphs via several equivalent properties (uniform edge distribution, eigenvalue gap, count of 4-cycles). The Lovász–Simonovits theorem relates the mixing rate of random walks on a graph to its spectral gap.
Concentration inequalities quantify the "almost sure" nature of the probabilistic method; the differential equation method converts heuristic mean-field approximations into rigorous theorems about random processes.

The Rödl Nibble and Semi-Random Methods

The Rödl nibble, introduced by Vojtěch Rödl in 1985, is a semi‑random technique for constructing large combinatorial structures such as packings, coverings, and Steiner systems. The idea is to run a random greedy process but to stop it early — after a small fraction of the steps — and then to finish the construction by a deterministic or a second random phase. In the classic nibble one selects a random family of edges (or blocks) from a hypergraph, deletes all edges that intersect the chosen ones, and repeats. Because each step removes only a tiny proportion of the remaining edges, the degree and codegree sequences stay close to their expected trajectories, and concentration inequalities (typically Azuma–Hoeffding or Chernoff bounds) guarantee that the process does not deviate significantly from its mean behaviour.

A key parameter is the nibble size ε, usually taken as a small power of the maximum degree Δ. After O(log Δ) rounds the maximum degree drops from Δ to Δ1−c for some constant c>0, while the number of uncovered vertices shrinks by a factor (1−ε). The method yields asymptotic existence results for designs: for any fixed k and λ there exists a Steiner system S(k, k+1, n) for all sufficiently large n satisfying the necessary divisibility conditions. This was proved by Rödl and later refined by Frankl and Rödl, and by Keevash using the more powerful random greedy algorithm with a “absorbing” phase. The nibble also underpins the proof of the Erdős–Hanani conjecture on packing numbers, and it has been adapted to hypergraph matching problems, giving near‑optimal bounds for the size of a matching in a uniform hypergraph with bounded codegrees.

The semi‑random method extends the nibble by allowing a limited amount of adversarial choice after each random step. One typical pattern: pick a random set of edges, then an adversary (or a deterministic algorithm) deletes a few “bad” edges to maintain a pseudorandom degree distribution. This idea appears in the analysis of the random greedy independent set algorithm, where the adversary removes vertices that would create large degree spikes. The combination of randomness and controlled correction yields stronger concentration than a purely random process, because the adversary can enforce a “smooth” degree profile that is easier to analyse with martingale methods. The technique has been used to prove the existence of large induced subgraphs with prescribed properties, to construct Ramsey graphs with no large cliques or independent sets, and to obtain improved bounds for the Turán density of certain hypergraphs.

In practice, the nibble is implemented by iterating the following loop: while the maximum degree exceeds a threshold, choose each remaining edge independently with probability p = ε/Δ, add the chosen edges to the packing, and delete all edges intersecting them. The expected degree drop per round is (1−p)Δ ≈ e−ε, so after O(log Δ) rounds the degree becomes polylogarithmic. At that point a simple greedy completion finishes the packing. The analysis requires tracking not only degrees but also codegrees (the number of edges containing a given pair of vertices), because codegrees control the variance of the degree evolution. The differential equation method (Wormald) provides a systematic way to prove that the random variables stay close to the solution of a system of differential equations describing the expected trajectories.

Entropy Compression and the Algorithmic Lovász Local Lemma

Entropy compression is a proof technique that transforms a probabilistic existence argument into an efficient algorithm by showing that a random process cannot run forever without violating an information‑theoretic bound. The method was pioneered by Moser and Tardos in their 2010 algorithmic proof of the Lovász Local Lemma (LLL), and later abstracted by Grytczuk, Kozik, and Micek (2013) into a general framework. The core idea: suppose a randomized algorithm repeatedly resamples the variables of a bad event whenever it occurs. Each resampling step can be encoded by a short “log” that records which event was resampled and the new random bits used. If the algorithm ran for too many steps, the log would compress the initial random string beyond its entropy, a contradiction. Therefore the algorithm must terminate quickly, producing a configuration that avoids all bad events.

In the variable model, each bad event A_i is determined by a subset of independent random variables. The Moser–Tardos algorithm starts with a uniformly random assignment, then while some A_i holds, it resamples all variables in the scope of A_i with fresh independent bits. The expected number of resamplings of A_i is at most x_i/(1−x_i) where the x_i satisfy the general LLL condition P(A_i) ≤ x_i ∏j∈N(i) (1−x_j). The proof constructs a witness tree for each resampling, showing that the probability of a given tree is bounded by the product of the x_i. Summing over all trees yields the expected bound. Entropy compression refines this by encoding the entire execution history: the initial random string R of length m bits, the sequence of resampled events, and the fresh random bits used at each step. Because each resampling replaces a block of bits, the total length of the log is at most the number of steps times the maximum scope size. If the algorithm took T steps, the log would have length ≤ T·k + O(log T) where k is the maximum number of variables per event. Since the initial string has entropy m, we must have T·k ≥ m − O(log T), giving a polynomial bound on T.

The entropy compression framework has been applied far beyond the LLL. It yields algorithmic versions of the Lopsided LLL, of the Moser–Tardos algorithm for non‑product probability spaces (e.g., random permutations), and of the “partial resampling” variant where only a subset of variables is refreshed. Notable applications include constructive proofs of the existence of proper colourings of graphs with bounded degree (the algorithmic version of Johansson’s theorem on triangle‑free graphs), of acyclic edge colourings, and of non‑repetitive sequences (Thue’s problem). In each case the compression argument replaces a non‑constructive probabilistic proof with a polynomial‑time algorithm, often with a simpler analysis than the original LLL witness‑tree approach.

A practical limitation is that the compression bound depends on the maximum scope size k. For events that depend on many variables (e.g., global constraints), the log may not compress enough to guarantee polynomial termination. This has motivated the development of “cluster expansion” and “entropy compression with a potential function” techniques, which assign weights to events and show that a carefully chosen potential decreases in expectation. These extensions recover algorithmic LLL results for a broader class of dependency graphs, including those arising in the random k‑SAT threshold and in the analysis of the random greedy independent set algorithm.

Worked Example: Entropy Compression for 3‑SAT
Consider a 3‑CNF formula with n variables and m clauses where each variable appears in at most d clauses. Show that if d ≤ 2k−1/(e k) with k=3, the Moser–Tardos algorithm finds a satisfying assignment in expected polynomial time. Compute the bound on the expected number of resamplings per clause.
For k=3 each clause has probability p = 2−3 = 1/8 of being falsified under a uniform assignment. The symmetric LLL condition is e p (d+1) ≤ 1. Substituting p gives e·(1/8)·(d+1) ≤ 1 ⇒ d+1 ≤ 8/e ≈ 2.94 ⇒ d ≤ 1.94. Since d is integer, the condition holds for d ≤ 1. However the general LLL with x_i = 1/(d+1) gives P(A_i) ≤ x_i (1−x_i)^d. For d=5, x=1/6, RHS = (1/6)(5/6)5 ≈ 0.067 > 1/8, so the condition fails. The known tight bound for 3‑SAT is d ≤ 22/(e·3) = 4/(3e) ≈ 0.49, which is not useful. The correct application uses the asymmetric LLL: set x = 1/(2d). Then P(A)=1/8 ≤ x (1−x)^d ≈ (1/(2d)) e−1/2. This holds for d up to about 5. The expected number of resamplings per clause is x/(1−x) ≤ 1/(2d−1). For d=5 this is ≤ 1/9. Hence the total expected resamplings is O(m). The algorithm runs in expected polynomial time.
Exam‑Day Strategy
When a question asks for an algorithmic version of the LLL, first identify whether the variable model or the permutation model is intended. Write down the symmetric condition e p (d+1) ≤ 1 and the general condition with x_i. If the problem gives a concrete bound on variable occurrences, plug it into the symmetric condition; if it gives a more complex dependency graph, set up the general LLL inequalities and solve for x_i. Remember that the Moser–Tardos expected resampling count for event i is x_i/(1−x_i). For entropy compression, the key step is to argue that a long execution would compress the initial random bits — state the entropy bound clearly: initial entropy = number of random bits; each resampling adds at most log₂(scope size) bits to the log. Equate to get a polynomial bound on the number of steps.

Hypergraph Containers and Their Applications

The hypergraph container theorem, proved independently by Balogh, Morris, and Samotij (2015) and by Saxton and Thomason (2015), provides a powerful structural description of independent sets in uniform hypergraphs. Given a k‑uniform hypergraph H on vertex set V with average degree d and bounded codegrees, the theorem asserts that there exists a family C of subsets of V (the containers) such that: (i) every independent set of H is contained in some C ∈ C; (ii) each container C has size at most (1−δ)|V| for some δ>0 depending on the codegree bounds; (iii) the number of containers is at most exp(O(|V|/d1/(k−1) log d)). This result translates the problem of counting independent sets into a problem of counting containers, which is often much easier because the containers are few and have a simple structure.

The proof uses an iterative “container algorithm”: start with the whole vertex set, repeatedly pick a vertex of high degree in the current hypergraph, add it to a “fingerprint” set, and delete its neighbourhood. The fingerprint size is bounded by O(|V|/d1/(k−1)), and the remaining vertices form a container. The codegree conditions ensure that the algorithm does not delete too many vertices at each step, so the final container is still large. The family of all possible fingerprints yields the container family C. The theorem has been extended to non‑uniform hypergraphs, to hypergraphs with weighted edges, and to the “supersaturation” setting where one counts subsets with few edges rather than independent sets.

Applications are numerous. In extremal combinatorics, containers give a short proof of the Erdős–Kleitman–Rothschild theorem on the number of triangle‑free graphs: the number of triangle‑free graphs on n vertices is 2n²/4+o(n²). In additive combinatorics, they yield the best known bounds for the size of sum‑free subsets of [n] and for the number of subsets of [n] with no three‑term arithmetic progression. In Ramsey theory, containers provide a new proof of the Kohayakawa–Łuczak–Rödl theorem on the Ramsey number of sparse graphs. In theoretical computer science, they imply that the number of satisfying assignments of a k‑SAT formula with bounded variable occurrences is at most 2(1−Ω(1))n, which is used in the analysis of the random k‑SAT threshold. The container method also underlies the recent proof of the Erdős–Sós conjecture for large graphs and the resolution of the Cameron–Erdős conjecture on sum‑free sets.

A key technical point is the trade‑off between the codegree bounds and the container size. If the maximum codegree Δ₂ is too large relative to the average degree d, the containers may not be significantly smaller than V. The theorem requires Δ₂ ≤ d1−ε for some ε>0, or more generally that the ℓ‑codegrees satisfy Δ_ℓ ≤ d1−(ℓ−1)/(k−1)+o(1). When these conditions fail, one can sometimes apply a “supersaturation” version: instead of independent sets, one counts subsets that contain few edges. This leads to the “robust” container lemma, which has been used to prove the existence of dense subgraphs with prescribed properties in pseudorandom graphs.

The Differential Equation Method for Random Graph Processes

The differential equation method, systematised by Nicholas Wormald in the 1990s, turns heuristic mean‑field approximations into rigorous proofs that a discrete random process stays close to a deterministic trajectory. The method applies to processes where the state at step t can be described by a vector of variables (e.g., the number of vertices of each degree in the random graph process). One writes a system of differential equations for the expected evolution of these variables, assuming that the random fluctuations are negligible. Then one proves, using martingale concentration inequalities such as Azuma–Hoeffding or Freedman’s inequality, that with high probability the actual variables remain within o(n) of the solution of the differential equations for all steps up to the stopping time.

A classic example is the random graph process G(n, m) where edges are added one by one uniformly at random. Let X_k(t) be the number of vertices of degree k after t edges have been added. The expected change in X_k when a new edge is added depends on the current degree distribution. In the limit n→∞ with t = τ n/2, the scaled variables x_k(τ) = X_k(τ n/2)/n satisfy the differential equations dx_k/dτ = (k−1) xk−1 − k x_k for k≥1, with x0(0)=1, x_k(0)=0 for k≥1. The solution is the Poisson distribution with mean τ. Wormald’s theorem guarantees that for any fixed τ, the actual degree distribution is within n−1/3 of the Poisson law with probability 1−o(1). This yields a rigorous derivation of the phase transition at τ=1 (the emergence of the giant component) and of the degree distribution in the supercritical regime.

The method also analyses algorithms. The Karp–Sipser algorithm for finding a large matching in a random graph proceeds by repeatedly picking a vertex of degree 1, matching it with its neighbour, and deleting both vertices; if no degree‑1 vertex exists, it picks a random edge. The state variables are the numbers of vertices of each degree. The differential equations describe the evolution of these numbers, and the solution predicts that the algorithm finds a matching of size n/2 − O(n1/2) in G(n, c/n) for c>e. The analysis uses a “stopping time” argument: one proves that the process stays close to the differential equations until the number of vertices drops below n2/3, at which point a direct combinatorial argument finishes the proof. This technique has been extended to the random greedy independent set algorithm, to the analysis of the random k‑SAT process, and to the evolution of the core in random hypergraphs.

Freedman’s inequality is often preferred over Azuma–Hoeffding because it uses the conditional variance of the martingale increments, giving tighter bounds when the increments are usually small but occasionally large. In the random graph process, the degree of a vertex can jump by more than 1 when an edge is added, but the conditional variance is bounded by the maximum degree. Freedman’s inequality then yields concentration with a variance term that scales with the sum of conditional variances, leading to error bounds of order √(n log n) rather than √n. The differential equation method also requires a “boundedness” condition: the one‑step change in each variable must be bounded by a constant (or at most no(1)). When this fails, one can sometimes truncate the process or use a “self‑correcting” modification, as in the analysis of the random graph process with a power‑law degree distribution.

Lopsided and Asymmetric Lovász Local Lemma Variants

The original Lovász Local Lemma assumes a symmetric dependency graph where each event is mutually independent of all events outside its neighbourhood. In many applications the dependency structure is “lopsided”: an event A may be positively correlated with some events and negatively correlated with others, but the negative correlations can be exploited to weaken the LLL condition. The Lopsided LLL, introduced by Erdős and Spencer (1991) and later refined by Bissacot, Fernández, Procacci, and Scoppola (2011), replaces the dependency graph by a “lopsidependency” graph where an edge i→j indicates that conditioning on the non‑occurrence of A_j can only increase the probability of A_i. The condition becomes P(A_i) ≤ x_i ∏j∈Γ⁺(i) (1−x_j) where Γ⁺(i) is the set of events that positively influence A_i. This often allows a much larger probability bound p because the product runs over a smaller set.

The Asymmetric LLL (also called the General LLL) is the most flexible form: for each event A_i there exists a real number x_i ∈ (0,1) such that P(A_i) ≤ x_i ∏j∈N(i) (1−x_j). Shearer’s condition gives a necessary and sufficient criterion for the existence of such x_i in terms of the independence polynomial of the dependency graph. Specifically, let I(G) be the independence polynomial of the graph G on vertices {1,…,n} with edges representing dependencies. Shearer’s theorem states that the LLL holds for all probability assignments with given upper bounds p_i if and only if the vector (p1,…,p_n) lies in the interior of the Shearer region, which is defined by the positivity of the independence polynomial evaluated at (−p1,…,−p_n). This characterisation is tight: if the vector is outside the region, there exists a probability space and events with those bounds for which the LLL fails.

Algorithmic versions of the Lopsided and Asymmetric LLL have been developed. The Moser–Tardos algorithm works for the variable model under the general LLL condition, and the expected number of resamplings is still bounded by x_i/(1−x_i). For the lopsided case, one can define a “resampling oracle” that resamples only the variables that appear in the positively dependent events. The entropy compression proof adapts by encoding only the resamplings that correspond to positive dependencies. Recent work by Kolmogorov (2016) and by Harris and Srinivasan (2017) gives polynomial‑time algorithms for the Lopsided LLL in the permutation model and for the general LLL with a “commutativity” condition on the resampling operations.

Applications of these variants include the constructive proof of the existence of proper colourings of graphs with maximum degree Δ using (1+o(1))Δ/log Δ colours (the Johansson–Molloy–Reed theorem), the algorithmic version of the “entropy compression” proof for non‑repetitive colourings of graphs, and the analysis of the random k‑SAT threshold where clauses share variables in a highly asymmetric way. In the random k‑SAT setting, the lopsidependency graph is much sparser than the full dependency graph because two clauses that share a variable are negatively correlated when one is satisfied. This yields a better bound on the clause density for which a satisfying assignment exists, matching the known satisfiability threshold up to lower‑order terms.

  • Confusing the symmetric LLL condition e p (d+1) ≤ 1 with the general LLL condition; the symmetric version is a special case and often gives weaker bounds.
  • Assuming the Moser–Tardos algorithm works for any dependency graph without checking the variable model; the algorithm requires that each event is determined by a set of independent random variables.
  • Neglecting the codegree bounds in the hypergraph container theorem; the theorem fails if codegrees are too large relative to the average degree.
  • Applying the differential equation method without verifying the boundedness and Lipschitz conditions on the one‑step changes; unbounded increments invalidate the martingale concentration step.
  • Mixing up lopsided dependency (positive influence) with ordinary dependency; the lopsided condition uses a directed graph of positive influence, not the undirected dependency graph.
  • Forgetting that Shearer’s condition is both necessary and sufficient for the asymmetric LLL; it characterises exactly the region where the LLL holds for all probability spaces with given marginal bounds.
  • Overlooking the need for an absorbing or completion phase in the Rödl nibble; the nibble alone leaves a small uncovered set that must be handled by a separate argument.

These advanced tools extend the probabilistic method from pure existence proofs to algorithmic constructions and precise counting results, and they appear regularly in modern combinatorics examinations.

The Probabilistic Method in Ramsey Theory and the Erdős–Szekeres Bound

The probabilistic method gave the first non‑constructive proof that the Ramsey number R(k,k) grows exponentially in k. Erdős (1947) considered a random two‑colouring of the edges of the complete graph K_n where each edge is coloured red or blue independently with probability 1/2. For a fixed set of k vertices the probability that it forms a monochromatic K_k is 2·2−(k choose 2). There are (n choose k) such sets, so by the union bound the expected number of monochromatic K_k is (n choose k)·21−(k choose 2). If this expectation is < 1 then there exists a colouring with no monochromatic K_k, proving R(k,k) > n. Choosing n = ⌊2k/2⌋ makes the expectation tend to 0 as k grows, yielding R(k,k) > 2k/2. This argument is the prototype of the first moment method: bound the probability that a bad event occurs by the expected number of bad events.

The same idea gives lower bounds for off‑diagonal Ramsey numbers R(s,t). For fixed s and large t, a random graph G(n, p) with p = n−2/(s+1) has expected number of K_s roughly constant while the expected number of independent sets of size t is (n choose t)(1−p)(t choose 2). Optimising p shows R(s,t) = Ω(t(s+1)/2 / (log t)(s+1)/2). The probabilistic method also provides upper bounds via the alteration method: start with a random graph, delete a vertex from each copy of K_s, and the remaining graph has no K_s and relatively few edges, giving an upper bound on the independence number. This interplay between the first moment and alteration underlies the best known asymptotic bounds for many Ramsey‑type problems.

Erdős and Szekeres (1935) proved that any sequence of (r−1)(s−1)+1 distinct real numbers contains an increasing subsequence of length r or a decreasing subsequence of length s. The probabilistic proof considers a random permutation of {1,…,n} and defines the length of the longest increasing subsequence L_n. Using the first moment method on the number of increasing subsequences of length r one shows that if n > (r−1)(s−1) then the expected number of permutations avoiding both patterns is < 1, so such a permutation cannot exist. This classic result illustrates how the probabilistic method can be applied to extremal problems on sequences, not only graphs.

Discrepancy Theory and Spencer's Six Deviations Theorem

Discrepancy theory asks: given a family of subsets of an n‑element set, can we colour the elements red/blue so that each subset is nearly balanced? Formally, for a set system (X, 𝒮) with |X| = n and 𝒮 = {S1,…,S_m}, the discrepancy is disc(𝒮) = min_{χ:X→{−1,1}} maxS∈𝒮 |∑x∈S χ(x)|. The probabilistic method shows that a random colouring gives discrepancy O(√(n log m)) with high probability by Chernoff bounds and the union bound. Spencer (1985) proved the celebrated “six deviations” theorem: for any set system with m = n, disc(𝒮) ≤ 6√n. The proof uses the partial colouring method (also called the entropy method). One iteratively assigns colours to a constant fraction of the uncoloured elements while keeping the discrepancy of every set bounded by O(√n). At each step a random signing of the remaining elements is considered; the Lovász Local Lemma (or a simpler concentration argument) guarantees the existence of a signing that does not increase any set’s discrepancy too much. After O(log n) steps all elements are coloured and the total discrepancy is O(√n).

The constant 6 is not optimal; Bansal (2010) gave a polynomial‑time algorithm based on semidefinite programming that achieves O(√n) and later work reduced the constant to 2√2. The partial colouring technique has become a cornerstone of modern discrepancy theory and has applications in computational geometry (e.g., bounding the discrepancy of axis‑parallel rectangles), in the analysis of rounding algorithms for linear programs, and in the construction of low‑discrepancy sequences for quasi‑Monte Carlo integration. The method also extends to the Komlós conjecture (bounding discrepancy of vectors with ℓ₂ norm ≤ 1) and to the Beck–Fiala theorem (disc(𝒮) ≤ 2t−1 when each element lies in at most t sets).

Worked Example: Applying Spencer's Theorem
Let X = {1,…,100} and let 𝒮 consist of all 100 intervals of length 10 (i.e., {i,…,i+9} for i=1,…,91) together with 9 arbitrary 10‑element subsets. Show that there exists a red/blue colouring of X such that every set in 𝒮 has discrepancy at most 60.
We have n = 100 and m = 100 sets. Spencer's theorem guarantees a colouring with discrepancy ≤ 6√n = 6·10 = 60. The theorem applies directly because m = n. No further calculation is needed; the existence of such a colouring follows from the theorem. If an explicit colouring is required, one can use Bansal's SDP‑based algorithm which runs in polynomial time and produces a colouring with discrepancy O(√n).
Exam‑Day Strategy
When a question asks for a discrepancy bound, first check whether the number of sets equals the number of elements. If m = n, Spencer's 6√n bound is the standard answer. If m > n, use the general bound O(√(n log(m/n))) derived from the partial colouring method. Remember that the constant 6 is not required to be proved; citing the theorem by name is sufficient for full credit.

The Probabilistic Method in List Coloring and Johansson's Theorem

List colouring assigns each vertex v a list L(v) of allowed colours; a proper list colouring chooses a colour from each list so that adjacent vertices receive different colours. The list chromatic number χ_ℓ(G) is the smallest k such that G is k‑choosable (i.e., has a proper list colouring for any assignment of lists of size k). Johansson (1996) proved that for triangle‑free graphs with maximum degree Δ, χ_ℓ(G) = O(Δ / log Δ). The proof uses the probabilistic method in two stages. First, a random partial colouring is created by giving each vertex a random colour from its list with probability p = c log Δ / Δ. Using the Lovász Local Lemma one shows that with positive probability the partial colouring has no conflicts and each uncoloured vertex retains a list of size at least (1−ε)k. Second, the uncoloured subgraph has maximum degree Δ' = O(Δ / log Δ) and can be coloured greedily because its lists are still large. Iterating this nibble (a semi‑random process) yields the final bound.

The result is tight up to the constant factor: there exist triangle‑free graphs with χ_ℓ(G) = Ω(Δ / log Δ). Johansson's theorem was a breakthrough because it showed that the list chromatic number can be much smaller than the maximum degree for sparse graphs, contrasting with the trivial bound χ_ℓ(G) ≤ Δ+1. The method has been extended to graphs with bounded local density, to hypergraph colouring, and to the problem of finding independent transversals in partite graphs. Algorithmic versions based on the Moser–Tardos resampling algorithm give polynomial‑time constructions of the colourings.

A key technical tool is the asymmetric Lovász Local Lemma applied to the bad events “vertex v receives a colour that conflicts with a neighbour”. The dependency graph has degree roughly Δ², but the probability of each bad event is about p² = (c log Δ / Δ)². The LLL condition e p (d+1) ≤ 1 becomes e (c log Δ / Δ)² Δ² ≤ 1, which holds for sufficiently small c. This illustrates how the LLL can handle dependencies that are polynomially large in Δ, a situation where the symmetric LLL would fail.

Derandomization via the Method of Conditional Expectations

The method of conditional expectations converts a probabilistic existence proof into a deterministic polynomial‑time algorithm. Suppose a random variable X is defined on a product probability space Ω = Ω1 × … × Ω_n and we know E[X] ≤ μ. To find an outcome ω with X(ω) ≤ μ, we fix the coordinates one by one. At step i we have already chosen ω1,…,ωi−1. We compute the conditional expectations E[X | ω1,…,ωi−1, ω_i = a] for each a ∈ Ω_i and pick a value a_i that minimises this expectation. Because the overall expectation is a convex combination of the conditional expectations, there always exists a choice that does not increase the expectation. After n steps we obtain a full assignment with X ≤ μ.

This technique derandomises the first moment method. For example, to find a cut of size at least m/2 in a graph with m edges, let X be the number of crossing edges when each vertex is independently placed on the left or right with probability 1/2. E[X] = m/2. The conditional expectation given a partial assignment can be computed in polynomial time (it is a linear function of the unassigned vertices). The algorithm yields a cut of size at least m/2 deterministically. More sophisticated applications include derandomising the Lovász Local Lemma via the Moser–Tardos algorithm, which can be viewed as a conditional expectation argument on a carefully chosen potential function.

Limitations: the method requires that the conditional expectations can be computed efficiently. For many problems (e.g., finding a large independent set in a random graph) the conditional expectation is #P‑hard to compute exactly. In such cases one uses pessimistic estimators — functions that upper‑bound the true conditional expectation and are easy to compute. The method of pessimistic estimators, introduced by Raghavan (1988), extends derandomisation to a wide range of probabilistic constructions, including the algorithmic version of the LLL and the construction of expander graphs.

Random Graph Phase Transitions and the Emergence of the Giant Component

The Erdős–Rényi random graph G(n, p) exhibits a sharp phase transition at p = 1/n. For p = c/n with c < 1, all components have size O(log n) with high probability; for c > 1 there is a unique giant component of size Θ(n) and all other components are O(log n). The probabilistic method proves this by analysing the exploration process of a component starting from a fixed vertex. The process is approximated by a Galton–Watson branching process with Poisson(c) offspring distribution. When c < 1 the branching process is subcritical and dies out quickly, giving logarithmic component sizes. When c > 1 it is supercritical and survives with positive probability ρ(c), the survival probability. The giant component size is concentrated around ρ(c)n.

The differential equation method (Wormald, 1995) gives a rigorous proof of concentration. One tracks the number of vertices of each degree during the exploration and shows that the trajectories follow a system of differential equations with high probability. The method requires bounded one‑step changes and Lipschitz continuity of the expected drift; these hold for G(n, p) because each step reveals at most one new vertex and changes degrees by at most 1. The solution of the differential equations yields the exact size of the giant component as the unique positive root of 1−x = e−cx.

At the critical window p = 1/n + λ n−4/3, component sizes scale as n2/3 and the largest components converge in distribution to the ordered excursions of a Brownian motion with parabolic drift (Aldous, 1997). This scaling limit is a deep result connecting random graphs to continuum stochastic processes. The phase transition also appears in random k‑SAT, where the clause density α = m/n undergoes a satisfiability threshold at α_s ≈ 2^k log 2. The probabilistic method, combined with the first and second moment methods, gives upper and lower bounds on α_s that match up to lower‑order terms.

  • Confusing the first moment bound (expectation < 1) with the second moment bound (variance control); the second moment is needed when the expectation is large but the probability of zero is still positive.
  • Assuming Spencer's 6√n bound holds for any m; the theorem requires m = n, otherwise the bound becomes O(√(n log(m/n))).
  • Applying the Lovász Local Lemma without verifying the variable model; the Moser–Tardos algorithm only works when each bad event is determined by a set of independent random variables.
  • Using the method of conditional expectations when the conditional expectation is not efficiently computable; one must construct a pessimistic estimator instead.
  • Neglecting the bounded‑difference condition in the differential equation method; unbounded increments invalidate the martingale concentration step.
  • Mixing up the subcritical and supercritical regimes in G(n, p); the giant component appears only when p > 1/n, not at p = 1/n exactly.
  • Overlooking that Johansson's theorem applies only to triangle‑free graphs; for graphs with triangles the list chromatic number can be as large as Δ.

These advanced topics illustrate how the probabilistic method evolves from pure existence proofs into algorithmic constructions, precise counting, and the analysis of critical phenomena in random structures.
