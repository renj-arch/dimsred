Sieve Theory — the Brun Sieve, the Selberg Sieve & the Linear Sieve

Sieve theory studies the set A = {aₙ} of integers with no small prime factors. The fundamental problem: count how many elements of A survive after sifting by primes up to z. The Eratosthenes-Legendre sieve uses inclusion-exclusion via the Möbius function: S(A, ℙ, z) = Σ_{d|P(z)} μ(d) |A_d| where P(z) = Π_{pBrun sieve (1919) replaces μ(d) with bounded coefficients to control the exponentially many divisor terms, proving the twin prime density is O(x/(log x)²). The Selberg sieve (1947) uses quadratic forms and optimal weights λ_d = μ(d) y_d — the optimal choice minimizes the variance and gives the essentially best possible upper bound. The combinatorial sieve (Buchstab, Jurkat-Richert) refines the Brun sieve using the Buchstab identity and the fundamental lemma. The linear sieve handles dimension κ = 1 sieve problems. The large sieve uses harmonic analysis and exponential sums over arithmetic progressions, culminating in the Bombieri-Vinogradov theorem. The parity problem — the Selberg parity obstacle — limits all sieve methods: they cannot distinguish even and odd numbers of prime factors. Yet breakthrough results like Chen's theorem (p + P₂), Friedlander-Iwaniec (a² + b⁴ primes), and Zhang-Maynard-Tao (bounded gaps between primes) show the power and limits of modern sieve theory.

Part 1

📏 The Sieve of Eratosthenes and the Brun Sieve

Eratosthenes–Brun
The Principle: Counting Integers with No Small Prime Factors
The Eratosthenes-Legendre sieve: let A = {aₙ} be a set of integers, ℙ the set of primes, and z a sifting limit. Write P(z) = Π_{pBrun's coarse sieve (1919): replace μ(d) with bounded coefficients λ_d supported on small d. The Brun pure sieve: let Λ_k = {d: ω(d) ≤ k} and set λ_d = μ(d) if d ∈ Λ_k, 0 otherwise. Choosing k = C log log x keeps the error term small while preserving enough cancellations. Brun's theorem: the number of twin primes p ≤ x (p and p+2 both prime) satisfies π₂(x) ≤ C·x/(log x)². The Brun-Titchmarsh inequality: π(x; q, a) ≤ 2x/(φ(q) log(x/q)) for q < x. This bound, nearly optimal assuming GRH, is essential in many applications.
The Eratosthenes-Legendre sieve is exact but useless for large z; Brun's innovation replaces the Möbius function with truncated coefficients to control the error while maintaining the main term's shape.
Part 2

🌍 The Selberg Sieve

Selberg
Quadratic Forms and Optimal Weighting
The Selberg sieve (1947): write S(A, ℙ, z) ≤ Σ_{n} (Σ_{d|n} λ_d)² where λ_₁ = 1 and λ_d are real numbers supported on squarefree d ≤ D (the sifting level). The choice λ_d = μ(d) y_d with arbitrary real y_d (d ≤ D) and y_₁ = 1. The sifting function is bounded by Σ_{n} (Σ_{d|(n,P(z))} μ(d) y_d)². Expanding the square and interchanging sums gives Σ_{d₁,d₂ ≤ D} μ(d₁)μ(d₂) y_{d₁} y_{d₂} |A_{[d₁,d₂]}|. Approximate |A_d| = g(d) X + r_d where g is multiplicative and X ≈ |A|. The main term becomes X·Σ_{d₁,d₂} μ(d₁)μ(d₂) y_{d₁} y_{d₂} g([d₁,d₂]). The optimal choice of y_d minimizes this quadratic form: y_d = μ(d) G(D/d)/G(D) where G(m) = Σ_{d≤m} μ(d)² g(d). For the twin prime problem, g(p) = 1/(p−1), and G(m) ∼ log m. The Selberg upper bound: S(A, ℙ, z) ≤ X/G(D) + O(Σ_{d≤D²} |r_d|). For the twin prime twist with D = x^{1/2−ε}, one obtains π₂(x) ≤ 4x/(log x)² — improving Brun's constant. The Selberg sieve is essentially optimal for upper bounds in problems of dimension κ = 1.
The Selberg sieve transforms the sieving problem into a quadratic optimization — the optimal weights produce the best possible upper bound among all linear combinations of divisor sums.

🧮 The Combinatorial Sieve and the Linear Sieve

Combinatorial
Buchstab Identity, Jurkat-Richert Theorem, and the Fundamental Lemma
The Buchstab identity: for z' < z, S(A, ℙ, z) = S(A, ℙ, z') − Σ_{z'≤pBuchstab function ω(u) emerges as the limit of the sifting density: S(A, ℙ, x^{1/u}) = x·W(z) ω(u)/log x + o(x/log x) where W(z) = Π_{p 2, with ω(u) = 1/u for 1 ≤ u ≤ 2. The Jurkat-Richert theorem (1965): for sieve dimension κ = 1, the linear sieve gives S(A, ℙ, x^{1/u}) = x·W(z){F(u) + O(e^{-u})} in the upper bound form, and x·W(z){f(u) + O(e^{-u})} in the lower bound form, where F and f are the continuous sieve functions satisfying F(u) = 1/f(u−1). The fundamental lemma of the sieve: if z = x^{ε} for a small ε > 0, the combinatorial sieve gives S(A, ℙ, z) = x·W(z){1 + O(ε)} — the main term dominates and the relative error is small. This is the sieve analogue of the prime number theorem in short intervals.
The combinatorial sieve refines the Brun sieve through the Buchstab identity, yielding both upper and lower bounds that match asymptotically when the sifting limit is a small power of x.
Part 4

🔥 The Parity Problem and Recent Breakthroughs

Parity–Breakthrough
The Selberg Parity Obstacle, Chen's Theorem, Friedlander-Iwaniec, and Bounded Gaps
The parity problem: sieve methods in their classical form cannot distinguish between integers with an even number of prime factors and those with an odd number. This is because the Möbius function averages to zero on the sifted set — any linear combination of divisor sums inherits this cancellation. This obstacle prevents any pure sieve from proving the twin prime conjecture or Goldbach's conjecture directly. Chen's theorem (1973): every sufficiently large even number N can be written as N = p + P₂ where p is prime and P₂ has at most two prime factors. Chen combined the linear sieve with a weighted version of the Goldbach problem using the Jurkat-Richert bounds — the weighted sieve assigns extra weight to numbers with few prime factors, partially bypassing the parity barrier. The Friedlander-Iwaniec theorem (1997): there are infinitely many primes of the form a² + b⁴. The proof uses a remarkable asymptotic sieve for the sparse set A = {a² + b⁴: a, b integers}, combining the linear sieve with estimates for bilinear forms and a delicate decomposition of the sequence using Heath-Brown's identity. Zhang's theorem (2013): liminf_{n→∞} (p_{n+1} − p_n) < 70,000,000. The proof uses the GPY sieve (Goldston-Pintz-Yıldırım, 2005) — a weighted Selberg sieve that detects primes in tuples by assigning weights λ_{d₁,…,d_k} that vanish unless the tuple has many primes. Zhang added a crucial dispersion estimate (a refined Weil bound for Kloosterman sums) to handle arithmetic progressions with large moduli. The Maynard-Tao theorem (2014) simplified the method using a symmetric multi-dimensional Selberg sieve, proving that for any k ≥ 1, there are infinitely many integer intervals of length ≤ C·e^{4k} containing at least k+1 primes. The Polymath8 project reduced Zhang's gap to 4,680 and then to 246.
The parity problem is the central obstacle in sieve theory — yet by combining sieves with deep arithmetic information (bilinear forms, spectral methods, and dispersion estimates), one can still prove spectacular results about primes.
