Sieve Theory — the Brun Sieve, the Selberg Sieve & the Linear Sieve

Sieve theory studies the set A = {aₙ} of integers with no small prime factors. The fundamental problem: count how many elements of A survive after sifting by primes up to z. The Eratosthenes-Legendre sieve uses inclusion-exclusion via the Möbius function: S(A, ℙ, z) = Σ_{d|P(z)} μ(d) |A_d| where P(z) = Π_{pBrun sieve (1919) replaces μ(d) with bounded coefficients to control the exponentially many divisor terms, proving the twin prime density is O(x/(log x)²). The Selberg sieve (1947) uses quadratic forms and optimal weights λ_d = μ(d) y_d — the optimal choice minimizes the variance and gives the essentially best possible upper bound. The combinatorial sieve (Buchstab, Jurkat-Richert) refines the Brun sieve using the Buchstab identity and the fundamental lemma. The linear sieve handles dimension κ = 1 sieve problems. The large sieve uses harmonic analysis and exponential sums over arithmetic progressions, culminating in the Bombieri-Vinogradov theorem. The parity problem — the Selberg parity obstacle — limits all sieve methods: they cannot distinguish even and odd numbers of prime factors. Yet breakthrough results like Chen's theorem (p + P₂), Friedlander-Iwaniec (a² + b⁴ primes), and Zhang-Maynard-Tao (bounded gaps between primes) show the power and limits of modern sieve theory.

🌍 The Selberg Sieve

Selberg
Quadratic Forms and Optimal Weighting
The Selberg sieve (1947): write S(A, ℙ, z) ≤ Σ_{n} (Σ_{d|n} λ_d)² where λ_₁ = 1 and λ_d are real numbers supported on squarefree d ≤ D (the sifting level). The choice λ_d = μ(d) y_d with arbitrary real y_d (d ≤ D) and y_₁ = 1. The sifting function is bounded by Σ_{n} (Σ_{d|(n,P(z))} μ(d) y_d)². Expanding the square and interchanging sums gives Σ_{d₁,d₂ ≤ D} μ(d₁)μ(d₂) y_{d₁} y_{d₂} |A_{[d₁,d₂]}|. Approximate |A_d| = g(d) X + r_d where g is multiplicative and X ≈ |A|. The main term becomes X·Σ_{d₁,d₂} μ(d₁)μ(d₂) y_{d₁} y_{d₂} g([d₁,d₂]). The optimal choice of y_d minimizes this quadratic form: y_d = μ(d) G(D/d)/G(D) where G(m) = Σ_{d≤m} μ(d)² g(d). For the twin prime problem, g(p) = 1/(p−1), and G(m) ∼ log m. The Selberg upper bound: S(A, ℙ, z) ≤ X/G(D) + O(Σ_{d≤D²} |r_d|). For the twin prime twist with D = x^{1/2−ε}, one obtains π₂(x) ≤ 4x/(log x)² — improving Brun's constant. The Selberg sieve is essentially optimal for upper bounds in problems of dimension κ = 1.
The Selberg sieve transforms the sieving problem into a quadratic optimization — the optimal weights produce the best possible upper bound among all linear combinations of divisor sums.

Part 4

🔥 The Parity Problem and Recent Breakthroughs

Parity–Breakthrough
The Selberg Parity Obstacle, Chen's Theorem, Friedlander-Iwaniec, and Bounded Gaps
The parity problem: sieve methods in their classical form cannot distinguish between integers with an even number of prime factors and those with an odd number. This is because the Möbius function averages to zero on the sifted set — any linear combination of divisor sums inherits this cancellation. This obstacle prevents any pure sieve from proving the twin prime conjecture or Goldbach's conjecture directly. Chen's theorem (1973): every sufficiently large even number N can be written as N = p + P₂ where p is prime and P₂ has at most two prime factors. Chen combined the linear sieve with a weighted version of the Goldbach problem using the Jurkat-Richert bounds — the weighted sieve assigns extra weight to numbers with few prime factors, partially bypassing the parity barrier. The Friedlander-Iwaniec theorem (1997): there are infinitely many primes of the form a² + b⁴. The proof uses a remarkable asymptotic sieve for the sparse set A = {a² + b⁴: a, b integers}, combining the linear sieve with estimates for bilinear forms and a delicate decomposition of the sequence using Heath-Brown's identity. Zhang's theorem (2013): liminf_{n→∞} (p_{n+1} − p_n) < 70,000,000. The proof uses the GPY sieve (Goldston-Pintz-Yıldırım, 2005) — a weighted Selberg sieve that detects primes in tuples by assigning weights λ_{d₁,…,d_k} that vanish unless the tuple has many primes. Zhang added a crucial dispersion estimate (a refined Weil bound for Kloosterman sums) to handle arithmetic progressions with large moduli. The Maynard-Tao theorem (2014) simplified the method using a symmetric multi-dimensional Selberg sieve, proving that for any k ≥ 1, there are infinitely many integer intervals of length ≤ C·e^{4k} containing at least k+1 primes. The Polymath8 project reduced Zhang's gap to 4,680 and then to 246.
The parity problem is the central obstacle in sieve theory — yet by combining sieves with deep arithmetic information (bilinear forms, spectral methods, and dispersion estimates), one can still prove spectacular results about primes.

The Large Sieve and the Bombieri–Vinogradov Theorem

The large sieve is an analytic inequality that bounds the mean square of a sequence of complex numbers over reduced residue classes modulo many moduli. In its classical form, for any complex numbers a_n supported on n ≤ N, one has

∑q ≤ Q ∑a (mod q), (a,q)=1 |∑n ≤ N a_n e(an/q)|² ≤ (N + Q²) ∑n ≤ N |a_n|².

This inequality is independent of any multiplicative structure and therefore applies to a wide range of sequences, including those arising from sieve problems. The Bombieri–Vinogradov theorem (1965) is a deep consequence of the large sieve combined with the zero‑free region for Dirichlet L‑functions. It asserts that for any A > 0 there exists B = B(A) such that

∑q ≤ x1/2 / (log x)^B max(a,q)=1 |π(x; q, a) − li(x)/φ(q)| ≪ x / (log x)^A.

In words, the primes are equidistributed among reduced residue classes on average up to moduli almost as large as √x. This result replaces the unproven Generalised Riemann Hypothesis in many sieve applications. For instance, the Brun–Titchmarsh inequality π(x; q, a) ≤ 2x/(φ(q) log(x/q)) follows from the large sieve, while the Bombieri–Vinogradov theorem allows one to take the level of distribution D = x1/2−ε in the Selberg upper bound sieve, yielding the optimal constant 2 for the twin‑prime upper bound. The proof uses the duality principle to convert the large sieve into a bound for Dirichlet polynomials, then applies the zero‑density estimates of Montgomery and Vaughan. The theorem is a cornerstone of modern sieve theory because it provides the necessary level of distribution for the linear sieve and for the GPY weighted sieve.

Weighted Sieves and the GPY Method

Classical sieves assign the same weight to every integer that survives the sifting process. The GPY (Goldston–Pintz–Yıldırım) method introduces a non‑negative weight function λ_d supported on squarefree d ≤ R, with the crucial property that the weighted sum ∑n ≤ x (∑d|n, d≤R λ_d)² is large precisely when n belongs to a tuple containing many primes. The weights are chosen as λ_d = μ(d) (log(R/d))^k for a suitable integer k, which makes the quadratic form diagonal after applying the Selberg optimisation. The key innovation is the use of a multidimensional Selberg sieve: one considers a k‑tuple of linear forms n + h_i and constructs weights λd1,…,d_k that factor as a product of one‑dimensional Selberg weights. The resulting upper bound for the sifted set involves the singular series of the tuple and a main term proportional to (log R)^k. By optimising the parameter R = xθ/2−ε where θ is the level of distribution of primes in arithmetic progressions, GPY showed that if θ > 1/2 then there are infinitely many bounded gaps between primes. The Bombieri–Vinogradov theorem gives θ = 1/2, which is just short of the threshold. Zhang’s breakthrough (2013) obtained a level of distribution θ = 1/2 + 1/584 for a restricted class of moduli by proving a dispersion estimate for Kloosterman sums, thereby crossing the GPY threshold and producing the first finite bound on prime gaps. The weighted sieve thus transforms the parity obstacle into a problem of obtaining a level of distribution beyond 1/2, a direction that has driven much of the subsequent progress.

Worked Example: Applying the Large Sieve Bound
Let a_n = 1 for 1 ≤ n ≤ N and a_n = 0 otherwise. Use the large sieve inequality to bound ∑q ≤ Q ∑(a,q)=1 |∑n ≤ N e(an/q)|².
The inner exponential sum is the Ramanujan sum c_q(n) = ∑(a,q)=1 e(an/q). For fixed q, ∑(a,q)=1 |∑n ≤ N e(an/q)|² = ∑n,m ≤ N c_q(n−m). By orthogonality, ∑q ≤ Q c_q(n−m) = 0 unless n = m, in which case it equals ∑q ≤ Q φ(q) ≈ 3Q²/π². The large sieve inequality gives the bound (N + Q²) N. Since the exact evaluation yields ≈ N·3Q²/π² for Q² ≫ N, the inequality is essentially sharp up to the constant factor. This illustrates how the large sieve captures the mean square of exponential sums without any arithmetic hypothesis on the sequence.
Exam Strategy: Recognising When to Invoke Bombieri–Vinogradov
In sieve problems, the level of distribution D is the largest parameter such that the sequence A_d satisfies |A_d − g(d)X| ≪ X/(log X)^A uniformly for d ≤ D. If a question asks for an upper bound on a sifted set with dimension κ = 1 and the sifting level z = x1/u, check whether the problem statement or a given hypothesis provides a level of distribution D ≥ x1/2−ε. If it does, you may quote the Bombieri–Vinogradov theorem to justify taking D = x1/2−ε in the Selberg or linear sieve, which yields the optimal constant. If only the trivial level D = xε is available, you must use the fundamental lemma instead. Remember: the theorem is an average result; it does not give pointwise equidistribution for a single modulus.

Multidimensional Selberg Sieve and the Maynard–Tao Theorem

The Maynard–Tao theorem (2014) generalises the GPY method by allowing the sieve weights to depend on all divisors of the product of the linear forms simultaneously, rather than factorising as a product of one‑dimensional weights. For a k‑tuple (h1,…,h_k) one chooses non‑negative coefficients λd1,…,d_k supported on squarefree d_i ≤ R with the condition that λ1,…,1 = 1. The weighted sum S = ∑n ≤ x (∑d_i|n+h_i λd1,…,d_k)² is expanded and the main term is expressed as a k‑dimensional quadratic form in the λ variables. By a clever symmetrisation, Maynard showed that the optimal weights are given by a smooth function F supported on the simplex {t_i ≥ 0, ∑ t_i ≤ 1}, with λd1,…,d_k = μ(∏ d_i) F(log d1/ log R, …, log d_k/ log R). The resulting ratio of the main term to the singular series is ∫∑ t_i ≤ 1 (∑ (∂F/∂t_i))² / ∫∑ t_i ≤ 1 F². Optimising this variational problem yields a lower bound for the number of primes in the tuple. For k = 105 one obtains at least two primes infinitely often, giving a gap bound of 600. Subsequent Polymath work reduced the admissible k to 50 and the gap to 246. The multidimensional sieve also proves that for any m ≥ 1 there are infinitely many intervals of length O(e4m) containing at least m+1 primes. The method bypasses the parity problem because the weights are not linear combinations of divisor sums of a single integer; they are genuinely multilinear, and the parity cancellation that obstructs the classical Selberg sieve does not apply to the full k‑dimensional quadratic form.

Sieve Dimension Greater Than One and Applications to Almost Primes

The dimension κ of a sieve problem is defined by the asymptotic behaviour of the multiplicative function g(p) that approximates the density of the sifted set at a prime p: g(p) ∼ κ/p. For the twin‑prime problem κ = 2, for primes in arithmetic progressions κ = 1, and for the set of integers with no prime factor ≤ z the dimension is 1. When κ > 1 the fundamental lemma still holds for z = xε, but the linear sieve functions F(u), f(u) are replaced by the solutions of a system of differential‑difference equations that depend on κ. The Rosser–Iwaniec sieve provides explicit upper and lower bounds for any κ, with the upper bound sieve function F_κ(u) and lower bound f_κ(u) satisfying F_κ(u) = 1/f_κ(u−1) for u > κ+1. For κ = 2 the linear sieve yields the Chen theorem: every sufficiently large even integer N can be written as N = p + P2 where P2 has at most two prime factors. The proof combines the upper bound linear sieve for the set of numbers n such that N−n has at most two prime factors with a lower bound sieve for the primes, using a weighting that favours numbers with few prime factors. For κ = 3 the sieve gives results on integers with at most three prime factors, and the general theory shows that the sifting limit β(κ) (the largest u for which a non‑trivial lower bound exists) satisfies β(κ) → ∞ as κ → ∞. This explains why almost‑prime results become easier as the number of allowed prime factors grows. The dimension also appears in the large sieve inequality for families of automorphic forms, where κ is the analytic conductor exponent. Understanding the dependence on κ is essential for applying sieve methods to problems such as the distribution of smooth numbers, the number of prime values of polynomials, and the level of distribution of the divisor function.

  • Confusing the level of distribution D with the sifting level z; D controls the range of moduli in the Bombieri–Vinogradov theorem, while z is the largest prime removed by the sieve.
  • Assuming the Selberg upper bound sieve gives the exact asymptotic for the twin‑prime constant; it only provides an upper bound with the correct constant 2, not a lower bound.
  • Thinking the parity problem is solved by the GPY weights; the weights circumvent the parity barrier only when a level of distribution > 1/2 is available, which still requires deep input beyond pure sieving.
  • Misapplying the fundamental lemma for z larger than a small power of x; the lemma fails when z = x1/u with u fixed, and one must use the linear sieve instead.
  • Overlooking the role of the singular series in multidimensional sieves; the main term always contains the product over primes of local densities, and omitting it leads to incorrect constants.
  • Believing the Bombieri–Vinogradov theorem holds for individual moduli; it is an average result and cannot be used to bound π(x; q, a) for a single q.
  • Neglecting the dependence of the linear sieve functions F(u), f(u) on the sieve dimension κ; using the κ = 1 functions for a κ = 2 problem gives wrong bounds.

These advanced topics illustrate how modern sieve theory combines combinatorial identities, analytic inequalities, and deep arithmetic input to overcome classical limitations and produce quantitative results on prime distributions.

The Fundamental Lemma of Sieve Theory and the Sifting Limit

The fundamental lemma of sieve theory gives an asymptotic formula for the sifted set when the sifting level z is a small power of the main parameter x. Let A be a finite set of integers and for each prime p let Ap be the subset of elements divisible by p. Assume a multiplicative density function g(p) with 0 ≤ g(p) < 1 such that |Ap| = g(p) |A| + rp and the remainder terms satisfy a suitable average bound. If the sifting dimension is κ (i.e. g(p) ∼ κ/p) and the level of distribution is D, then for any z ≤ D1/s with s > κ the sifted set satisfies

S(A, P, z) = X ∏p<z</sub> (1 − g(p)) (1 + O(e−s log s)),

where X = |A| and the product runs over primes in the sifting set P. The lemma fails when z grows like a fixed power x1/u with u bounded; in that regime the error term is no longer negligible and one must use the linear sieve or the Rosser–Iwaniec sieve. The largest u for which a non‑trivial lower bound exists is called the sifting limit β(κ). For κ = 1 one has β(1) = 2, for κ = 2 the linear sieve gives β(2) ≈ 4.5, and in general β(κ) → ∞ as κ → ∞. This explains why almost‑prime results become easier as the number of allowed prime factors grows. The fundamental lemma is the engine behind many applications, including the Brun–Titchmarsh theorem for primes in arithmetic progressions and the upper bound in the twin‑prime problem.

The Rosser–Iwaniec Sieve and Explicit Sieve Functions

The Rosser–Iwaniec sieve provides completely explicit upper and lower bound sieve functions Fκ(u) and fκ(u) for any sieve dimension κ ≥ 1. These functions are defined as the unique continuous solutions of the system of differential‑difference equations

Fκ(u) = 1 for 0 ≤ u ≤ κ+1, fκ(u) = 0 for 0 ≤ u ≤ κ+1,

and for u > κ+1

d/du (uκ Fκ(u)) = κ uκ−1 fκ(u−1),

d/du (uκ fκ(u)) = κ uκ−1 Fκ(u−1).

The upper bound sieve satisfies S(A, P, z) ≤ X ∏p<z</sub> (1−g(p)) Fκ(u) + error with u = log D / log z, while the lower bound sieve gives a similar inequality with fκ(u). A key identity is Fκ(u) = 1 / fκ(u−1) for u > κ+1, which reflects the duality of the linear programming problem underlying the sieve. For κ = 2 the functions yield the Chen theorem: every sufficiently large even integer N can be written as N = p + P2 where P2 has at most two prime factors. The proof combines an upper bound linear sieve for the set of n such that N−n has at most two prime factors with a lower bound sieve for the primes, using a weighting that favours numbers with few prime factors. Explicit numerical values of F2 and f2 have been tabulated up to high precision, allowing completely effective constants in applications such as bounds for the least prime in an arithmetic progression or the number of almost‑prime values of polynomials.

Worked Example: Applying the Rosser–Iwaniec Upper Bound
Let A = {n ≤ x : n ≡ a (mod q)} with (a,q)=1. Take the sifting set P to be all primes p ≤ z not dividing q. The density function is g(p) = 1/(p−1) for p ∤ q, so the sieve dimension is κ = 1. Assume the level of distribution D = x / (log x)2. Using the Rosser–Iwaniec upper bound with u = log D / log z, derive an explicit upper bound for the number of primes in the progression up to x when z = x1/3.
For κ = 1 the upper bound sieve function is F1(u) = 2eγ log u for u ≥ 2 (where γ is Euler's constant). Here u = log D / log z = (log x − 2 log log x) / (⅓ log x) = 3 − 6 log log x / log x. For large x, u ≈ 3. The main term is X ∏p<z, p∤q</sub> (1−1/(p−1)) F1(u). By Mertens' theorem the product equals (φ(q)/q) (e−γ/log z) (1+o(1)). Substituting X = x/φ(q) and F1(3) = 2eγ log 3 gives the upper bound (2 log 3) x / log z = 6 log 3 · x / log x. Since log z = ⅓ log x, the bound becomes 18 log 3 · x / log x. This is an explicit constant multiple of the expected asymptotic x/(φ(q) log x) and illustrates how the Rosser–Iwaniec sieve yields effective numerical constants.

Level of Distribution, Bombieri–Vinogradov, and the Elliott–Halberstam Conjecture

The level of distribution θ of a sequence A is the supremum of real numbers such that for every ε > 0 one has

∑q ≤ xθ−ε max(a,q)=1 |π(x; q, a) − π(x)/φ(q)| ≪ x / (log x)A

for any A > 0. The Bombieri–Vinogradov theorem establishes θ = ½ for the primes, i.e. the primes have level of distribution ½ on average over moduli. This is the strongest unconditional result and is essentially equivalent to the Generalised Riemann Hypothesis for Dirichlet L-functions averaged over characters. The Elliott–Halberstam conjecture asserts that the primes have level of distribution θ = 1 (i.e. the asymptotic holds for all q ≤ x1−ε). If true, it would imply the twin‑prime conjecture via the GPY sieve and would give bounded gaps between primes with a much smaller admissible tuple size. The GPY method requires a level of distribution strictly greater than ½ to produce a positive proportion of tuples containing at least two primes; the Bombieri–Vinogradov theorem only gives θ = ½, which is insufficient. Zhang’s breakthrough in 2013 proved a weakened form of Elliott–Halberstam for a restricted class of moduli, yielding θ = ½ + 1/584 and the first finite bound on prime gaps. The Maynard–Tao multidimensional sieve then showed that any θ > ½ implies bounded gaps, and the Polymath project optimised the admissible tuple to obtain the current record gap of 246 under the assumption of the generalised Elliott–Halberstam conjecture. Understanding the precise relationship between the level of distribution and the sifting parameter z is crucial: the sieve upper bound depends on u = log D / log z, so a larger D (i.e. larger θ) allows a larger z for a fixed u, which in turn improves the sifting limit.

Sieve Methods for Polynomial Sequences and the Bateman–Horn Conjecture

Applying sieve theory to the values of a polynomial f(n) ∈ ℤ[n] leads to the problem of counting integers n ≤ x for which f(n) has no small prime factors. The natural density function is g(p) = ν(p)/p, where ν(p) is the number of solutions of f(n) ≡ 0 (mod p). If f is irreducible of degree d, then ν(p) ≤ d and the sieve dimension is κ = d on average. The fundamental lemma gives an asymptotic for the sifted set when z ≤ xε, but for larger z one needs the linear sieve or the Rosser–Iwaniec sieve. The Bateman–Horn conjecture predicts the asymptotic number of n ≤ x such that f1(n), …, fk(n) are simultaneously prime, with a constant given by a product over primes of local densities. Sieve methods provide upper bounds of the correct order of magnitude and, in favourable cases, lower bounds for almost‑prime values. For example, the Friedlander–Iwaniec theorem (1998) proves that there are infinitely many primes of the form x2 + y4 by combining a bilinear form sieve with the asymptotic sieve for the polynomial n2 + 1. Heath‑Brown (2001) showed that there are infinitely many primes represented by the cubic form x3 + 2y3. In both cases the sieve dimension is greater than one, and the arguments rely on a level of distribution for the relevant sequences that goes beyond the Bombieri–Vinogradov range, exploiting the algebraic structure of the polynomial. The general theory of sieves for polynomial sequences also yields results on smooth numbers: the number of n ≤ x with all prime factors of f(n) ≤ xα can be estimated using the saddle‑point method combined with the fundamental lemma. These applications demonstrate how the interplay between the sieve dimension, the level of distribution, and the algebraic properties of the polynomial determines the strength of the results.

  • Assuming the Rosser–Iwaniec upper bound sieve gives the exact asymptotic for the twin‑prime constant; it only provides an upper bound with the correct constant 2, not a lower bound.
  • Thinking the Elliott–Halberstam conjecture is a theorem; it remains unproven and any argument that uses θ = 1 must state the conditional nature explicitly.
  • Misapplying the fundamental lemma for z larger than a small power of x; the lemma fails when z = x1/u with u fixed, and one must use the linear sieve instead.
  • Overlooking the dependence of the linear sieve functions Fκ(u), fκ(u) on the sieve dimension κ; using the κ = 1 functions for a κ = 2 problem gives wrong bounds.
  • Neglecting the singular series in polynomial sieve applications; the main term always contains the product over primes of local densities, and omitting it leads to incorrect constants.
  • Believing the Bombieri–Vinogradov theorem holds for individual moduli; it is an average result and cannot be used to bound π(x; q, a) for a single q.

The Buchstab Function and the Linear Sieve Asymptotics

The linear sieve, developed by Rosser and Iwaniec, gives explicit upper and lower bound functions F(u) and f(u) for the sifted set when the sieve dimension κ = 1. These functions are expressed in terms of the Buchstab function ω(u), which satisfies the differential‑delay equation u ω'(u) = ω(u‑1) for u > 2 with initial condition ω(u) = 1/u for 1 ≤ u ≤ 2. The connection is F(u) = 2 e^γ ω(u) and f(u) = 2 e^γ ω(u) for u ≥ 2, where γ is Euler's constant. For u between 1 and 2 the lower bound function vanishes, reflecting the parity barrier. The sifting limit β(1) = 2 is the largest u for which a non‑trivial lower bound exists; beyond u = 2 the linear sieve cannot produce a positive lower bound. Rosser and Iwaniec computed explicit numerical values of F(u) and f(u) and proved that the remainder terms in the linear sieve are of order O(exp(‑u log u)) uniformly for u in compact intervals. These explicit bounds are essential for applications such as Chen's theorem, where one needs a lower bound for the number of integers with at most two prime factors in a sequence of sieve dimension 2.

The Buchstab function also appears in the fundamental lemma of sieve theory: for any fixed κ > 0 and u ≤ log D / log z bounded, the sifted set is asymptotic to X ∏p<z</sub> (1‑g(p)) times a factor that tends to 1 as u → ∞. The rate of convergence is governed by ω(u). In particular, the error term in the fundamental lemma is O(exp(‑u log u + O(u))) which matches the linear sieve remainder. Understanding the analytic properties of ω(u) — its monotonicity, its limit 1 as u → ∞, and its oscillatory behaviour for small u — is crucial for deriving sharp numerical constants in sieve inequalities.

Chen's Theorem and the Weighted Sieve for Goldbach's Problem

Chen Jingrun proved in 1973 that every sufficiently large even integer N can be written as N = p + P₂, where p is prime and P₂ is a product of at most two primes (an almost prime of order 2). The proof combines an upper bound sieve of dimension 1 for the primes with a lower bound weighted sieve of dimension 2 for the almost‑prime component. The key idea is to assign non‑negative weights λ_d to the divisors d of the sifting product, chosen so that the weighted sum ∑n≤x (∑d|n λ_d)² approximates the indicator of integers with no small prime factors. By optimizing the weights using the linear sieve functions F₂(u) and f₂(u) for dimension 2, Chen obtained a positive lower bound for the number of representations when the sifting level z = N1/3. The Bombieri–Vinogradov theorem provides the necessary level of distribution θ = 1/2 for the sequence of shifted primes N‑p, allowing the sieve to run up to D = N1/2‑ε. The parity problem prevents a pure lower bound sieve from reaching the prime case (which would require dimension 1 and u > 2), but the weighted construction circumvents this by detecting integers with exactly two prime factors.

The weighted sieve also yields the companion result that every sufficiently large even integer is a sum of two almost primes P₂ + P₂, and that there are infinitely many primes p such that p+2 is a P₂ (Chen's twin prime theorem). The numerical constants in Chen's theorem depend on the explicit values of the linear sieve functions for κ = 2, which were computed by Rosser and Iwaniec. Later refinements by Halberstam and Richert improved the admissible range for the sifting parameter and gave explicit bounds for the exceptional set. The method has been adapted to other additive problems, such as the representation of integers as a prime plus a square‑free number with a bounded number of prime factors.

Applying the Linear Sieve to Chen's Theorem
Explain why the linear sieve with dimension 2 yields a lower bound for the number of representations of an even integer as p + P₂, while a dimension 1 sieve cannot give a lower bound for p + p.
The linear sieve lower bound function f_κ(u) is positive only for u > β(κ), where β(κ) is the sifting limit. For κ = 1, β(1) = 2, so a lower bound requires u > 2. In the Goldbach problem the sifting parameter u = log D / log z. Using the Bombieri–Vinogradov theorem we can take D ≈ N1/2 and z ≈ N1/3, giving u ≈ 3/2 < 2, so the κ = 1 lower bound vanishes. For the almost‑prime component we sieve a sequence of dimension κ = 2 (the number of solutions of n ≡ 0 (mod p) is 2 on average). The sifting limit for κ = 2 is β(2) ≈ 1.68, and with the same D and z we have u ≈ 3/2 > β(2), so f₂(u) > 0. The weighted sieve constructs a non‑negative quadratic form whose expectation equals the sifted sum, and the linear sieve lower bound for κ = 2 provides a positive main term. Thus the dimension 2 sieve succeeds where the dimension 1 sieve fails because the parity barrier is weaker for almost primes.

When a question asks for the sifting limit in a weighted sieve argument, identify the sieve dimension of the target sequence (primes → κ = 1, almost primes P₂ → κ = 2). Recall β(1) = 2 and β(2) ≈ 1.68. Check whether the given u = log D / log z exceeds the relevant β(κ); if it does, a lower bound exists. This quick check often decides whether a construction can produce a positive proportion.

The Barban–Davenport–Halberstam Theorem and the Large Sieve for Arithmetic Progressions

The Barban–Davenport–Halberstam theorem gives an average form of the prime number theorem in arithmetic progressions. It states that for any A > 0 there exists B = B(A) such that ∑q ≤ Q ∑a (mod q), (a,q)=1 |ψ(x; q, a) ‑ x/φ(q)|² ≪ x² / (log x)^A, provided Q ≤ x / (log x)^B. Here ψ(x; q, a) = ∑n ≤ x, n ≡ a (mod q) Λ(n). This result is essentially equivalent to the large sieve inequality for Dirichlet characters: ∑q ≤ Q (q/φ(q)) ∑χ (mod q)^* |∑n ≤ x a_n χ(n)|² ≤ (x + Q²) ∑n ≤ x |a_n|², where the asterisk denotes primitive characters. Montgomery and Vaughan proved the sharp constant x + Q². The Barban–Davenport–Halberstam theorem follows by applying the large sieve to the von Mangoldt function and using the zero‑free region for Dirichlet L‑functions to control the contribution of possible Siegel zeros. The theorem is a cornerstone for many sieve applications because it provides a level of distribution θ = 1/2 on average over moduli, which is exactly the strength of the Bombieri–Vinogradov theorem. In fact, the Bombieri–Vinogradov theorem can be derived from the Barban–Davenport–Halberstam theorem by Cauchy–Schwarz and the Siegel–Walfisz theorem for small moduli.

The large sieve also yields bounds for character sums that are independent of the Generalised Riemann Hypothesis. For example, the inequality ∑q ≤ Q ∑χ (mod q)^* |∑n ≤ N a_n χ(n)|² ≤ (N + Q²) ∑ |a_n|² is used to prove the Brun–Titchmarsh theorem π(x; q, a) ≤ 2x/(φ(q) log(x/q)) for q < x. The constant 2 is best possible for the large sieve method. Recent work by Kowalski, Michel, and others has extended the large sieve to automorphic forms and to families of L‑functions, providing average results that feed into the multidimensional sieve of Maynard and Tao. Understanding the interplay between the large sieve, the Barban–Davenport–Halberstam theorem, and the Bombieri–Vinogradov theorem is essential for any advanced application of sieve theory to primes in arithmetic progressions.

The Sieve for Smooth Numbers and the Hildebrand–Tenenbaum Method

Smooth numbers, or friable integers, are those whose prime factors are all ≤ y. The counting function Ψ(x, y) = #{n ≤ x : P⁺(n) ≤ y} is central to analytic number theory and cryptography. For y = x1/u with u fixed, the Dickman function ρ(u) gives the asymptotic Ψ(x, x1/u) ∼ x ρ(u) as x → ∞. The saddle‑point method, developed by Hildebrand and Tenenbaum in 1993, provides a uniform asymptotic for Ψ(x, y) valid for the entire range (log x)1+ε ≤ y ≤ x. The method writes Ψ(x, y) as a contour integral of the Dirichlet series ∏p ≤ y (1‑p-s)-1 and deforms the contour through a saddle point determined by the equation ∑p ≤ y (log p) / (p^s ‑ 1) = log x. The resulting approximation involves the Dickman function and a Gaussian integral, with an error term of relative size O(exp(‑(log y)3/5‑ε)). This uniformity is crucial for sieve applications where the sifting parameter z varies with x.

In sieve theory, smooth numbers appear when one applies the fundamental lemma to a set of integers with restricted prime factors. The fundamental lemma gives an asymptotic for the sifted set when z ≤ x^ε, but for larger z one needs the linear sieve or the Rosser–Iwaniec sieve. The Hildebrand–Tenenbaum asymptotics allow one to replace the sifting product ∏p<z</sub> (1‑g(p)) by an explicit analytic expression involving ρ(u). For example, in the work of Friedlander and Iwaniec on primes of the form x² + y⁴, the number of integers n ≤ x with all prime factors of n²+1 ≤ x^α is estimated using the saddle‑point method combined with the fundamental lemma. The smooth‑number estimates also enter the analysis of the level of distribution for polynomial sequences, because the error terms in the Bombieri–Vinogradov theorem for such sequences often involve sums over smooth moduli. Mastery of the Hildebrand–Tenenbaum method is therefore indispensable for modern sieve applications that go beyond the classical linear sieve.

The Sieve for Binary Quadratic Forms and the Work of Iwaniec

In 1978 Henryk Iwaniec proved that there are infinitely many primes of the form n² + 1, conditional on a suitable level of distribution for the sequence n² + 1. The unconditional result, obtained by combining a bilinear form sieve with the asymptotic sieve for the polynomial n² + 1, shows that the number of primes p ≤ x of the form n² + 1 is ≫ x1/2 / log x. The sieve dimension for the polynomial n² + 1 is κ = 1, because the congruence n² ≡ ‑1 (mod p) has either 0 or 2 solutions, averaging 1 solution per prime. The linear sieve with κ = 1 gives an upper bound of the correct order, but the parity problem prevents a lower bound for primes. Iwaniec circumvented this by using a weighted sieve that detects integers with at most two prime factors, and then applying a bilinear form decomposition to separate the contribution of the almost‑prime components. The key analytic input is a level of distribution θ = 1/2 for the sequence n² + 1 in arithmetic progressions, which follows from the Weil bound for Kloosterman sums and the large sieve. The bilinear form sieve then exploits the factorization structure of the quadratic form to gain an extra factor of log x, yielding the lower bound for almost primes.

Later, Heath‑Brown (2001) extended the method to the cubic form x³ + 2y³, proving infinitely many prime values. The sieve dimension for this cubic form is κ = 2 on average, because the congruence x³ ≡ ‑2y³ (mod p) has about 3 solutions for p ≡ 1 (mod 3) and 1 solution otherwise. The argument again uses a bilinear form sieve together with a level of distribution beyond Bombieri–Vinogradov, obtained from the theory of exponential sums over finite fields. These results illustrate a general principle: for polynomial sequences of degree d, the sieve dimension is d on average, and the parity barrier can be overcome for almost primes of order d by combining the linear sieve with bilinear forms and algebraic geometry estimates. The work of Iwaniec and Heath‑Brown laid the foundation for the Friedlander–Iwaniec theorem (1998) on primes of the form x² + y⁴, where the sieve dimension is 3/2 and the level of distribution is obtained from the spectral theory of automorphic forms.

  • Assuming the Rosser–Iwaniec upper bound sieve gives the exact asymptotic for the twin‑prime constant; it only provides an upper bound with the correct constant 2, not a lower bound.
  • Thinking the Elliott–Halberstam conjecture is a theorem; it remains unproven and any argument that uses θ = 1 must state the conditional nature explicitly.
  • Misapplying the fundamental lemma for z larger than a small power of x; the lemma fails when z = x1/u with u fixed, and one must use the linear sieve instead.
  • Overlooking the dependence of the linear sieve functions F_κ(u), f_κ(u) on the sieve dimension κ; using the κ = 1 functions for a κ = 2 problem gives wrong bounds.
  • Neglecting the singular series in polynomial sieve applications; the main term always contains the product over primes of local densities, and omitting it leads to incorrect constants.
  • Believing the Bombieri–Vinogradov theorem holds for individual moduli; it is an average result and cannot be used to bound π(x; q, a) for a single q.

These advanced topics complete the core toolkit for modern sieve theory and its applications to prime distributions.

The Sieve for Almost Primes in Short Intervals

The classical linear sieve gives asymptotic upper and lower bounds for the number of integers in a long interval that have no prime factor below a given sifting level. When the interval length is comparable to a small power of the upper bound, the same combinatorial structure can be transferred to short intervals by using a weighted version of the Rosser–Iwaniec sieve. The key idea is to replace the characteristic function of the interval by a smooth weight that approximates the indicator while preserving the multiplicative structure required for the sieve inequalities. Harman (1983) showed that for any fixed ε > 0 and for intervals of length x1/2+ε the number of integers with at most two prime factors is asymptotically given by the expected main term multiplied by the singular series. The proof combines a bilinear form decomposition of the sifted sum with the Bombieri–Vinogradov theorem for moduli up to x1/2−δ. The level of distribution θ = 1/2 is the natural barrier for the linear sieve in short intervals; any improvement would require a level of distribution beyond the Elliott–Halberstam conjecture.

In practice the sieve dimension for the almost‑prime problem is κ = 2, because each integer n contributes a factor (1 − 1/p) for each prime p dividing n, and the average number of prime factors in the sifting set is two. The Rosser–Iwaniec upper bound sieve functions F₂(u) and f₂(u) give explicit constants: for u = log x / log z the upper bound is 2 F₂(u) X ∏p<z</sub>(1 − g(p)) and the lower bound is 2 f₂(u) X ∏p<z</sub>(1 − g(p)), where X is the weighted count of the interval. When the interval length is xθ with θ > 1/2 the sifting parameter u becomes bounded, and the fundamental lemma of sieve theory applies, yielding an asymptotic formula with a relative error of order exp(−u log u). This transition from the linear sieve regime to the fundamental‑lemma regime is the main technical step in extending almost‑prime results to shorter intervals.

Applications include the result of Baker–Harman–Pintz (2001) that there is always a prime between x and x + x0.525 for sufficiently large x, which is proved by showing that the interval contains an integer with at most two prime factors and then using a weighted sieve to promote it to a prime under a suitable level of distribution hypothesis. Unconditionally, the best known result for almost primes in intervals of length x1/2+ε is due to Harman (2007), who obtained the expected asymptotic for integers with at most three prime factors. The parity problem remains the obstruction to reducing the number of prime factors to two in intervals shorter than x1/2.

The Sieve for Primes in Arithmetic Progressions with Large Moduli

The Bombieri–Vinogradov theorem gives an average form of the Generalised Riemann Hypothesis for moduli up to x1/2 / (log x)^A. For many applications one needs information about individual large moduli, for example when the modulus is a polynomial value q = f(n). The large sieve inequality of Gallagher provides a bound for the discrepancy of primes in progressions with moduli up to Q, but it loses a factor of log Q compared with the Bombieri–Vinogradov range. To overcome this, one uses the dispersion method of Linnik combined with the Weil bound for Kloosterman sums. The resulting theorem of Fouvry (1985) shows that for any fixed A > 0 the primes are well distributed in progressions with moduli q ≤ x2/3 / (log x)^A, provided the moduli are restricted to a set of “well‑factorable” integers. The factorability condition means that each q can be written as q = qr with r ≤ q1/3 and (r, q/r) = 1, which allows the application of the Weil bound after a Cauchy–Schwarz step.

In the context of sieve theory, this level of distribution θ = 2/3 is sufficient to apply the linear sieve with dimension κ = 1 to sequences such as n² + 1 or n³ + 2. The sifting parameter u = log x / log z then satisfies u < 3/2, which lies inside the range where the lower bound sieve function f₁(u) is positive. Consequently one obtains a lower bound for the number of almost primes of the form n² + 1 with at most two prime factors. The work of Iwaniec (1978) and later Heath‑Brown (2001) uses exactly this level of distribution together with a bilinear form sieve to separate the contribution of the almost‑prime components. The bilinear form decomposition writes the sifted sum as Σm,n a_m b_n λ(mn) where λ is the sieve weight; the large moduli are handled by the dispersion method, while the small moduli are covered by the Bombieri–Vinogradov theorem.

A common mistake is to assume that the Elliott–Halberstam conjecture (θ = 1) is needed for these results. In fact, the unconditional level θ = 2/3 already suffices for the linear sieve with κ = 1, and the parity barrier is bypassed by detecting integers with at most two prime factors rather than primes. The Elliott–Halberstam conjecture would allow one to push the sifting level to z = x1−ε and would give a lower bound for primes themselves, but it remains unproven. Any argument that uses θ = 1 must state the conditional nature explicitly.

Always state whether the result is conditional on Elliott–Halberstam or unconditional.

The Sieve for the Distribution of Prime k‑tuples and the Hardy–Littlewood Conjecture

The Hardy–Littlewood prime k‑tuple conjecture predicts an asymptotic formula for the number of integers n ≤ x such that each of the linear forms n + h₁, …, n + h_k is prime. The singular series 𝔖(h) = ∏_p (1 − ν(p)/p) (1 − 1/p)−k encodes the local obstructions, where ν(p) is the number of distinct residues modulo p among the shifts h_i. Sieve theory provides upper bounds of the correct order for any admissible tuple (ν(p) < p for all p). The Selberg upper bound sieve with dimension κ = k gives an upper bound 2^k k! 𝔖(h) x / (log x)^k (1 + o(1)). The parity problem prevents a matching lower bound for primes, but the weighted sieve of Chen and the GPY method yield lower bounds for almost primes. Goldston–Pintz–Yıldırım (2009) showed that for any admissible tuple there are infinitely many n for which at least two of the n + h_i are prime, provided the level of distribution θ > 1/2. Their argument uses a multidimensional Selberg sieve with a carefully chosen weight function that approximates the indicator of the tuple being prime.

The multidimensional Selberg sieve introduces a weight λ_d = μ(d) (log (R/d) / log R)^k for d ≤ R, where R = xθ/2. The quadratic form Σd₁,d₂ λd₁ λd₂ / [d₁,d₂] is diagonalised by the Selberg optimisation, leading to the main term involving the singular series. The GPY breakthrough was to choose a weight that is not purely multiplicative but includes a factor (Σi=1^k 1p|n+h_i) to detect correlations between the components. This extra factor allows the lower bound to exceed the trivial bound when θ > 1/2. The subsequent work of Maynard (2015) and Tao (2015) removed the dependence on the level of distribution by using a more flexible weight supported on smooth numbers, proving bounded gaps between primes unconditionally. The Maynard–Tao sieve uses a weight of the form (Σd|P(n) μ(d) g(log d / log R))2 where P(n) = ∏i=1^k (n + h_i) and g is a smooth function vanishing at 1. The optimisation reduces to a variational problem on the simplex, whose solution gives the optimal constant for the proportion of tuples with at least m primes.

A frequent error is to confuse the singular series 𝔖(h) with the sieve dimension κ. The singular series is a product over primes of local densities and appears in the main term of both upper and lower bounds. The sieve dimension κ = k governs the growth of the sifting function and the shape of the Rosser–Iwaniec functions F_k(u), f_k(u). Using the κ = 1 functions for a k‑tuple problem would give a bound that is too weak by a factor of (log x)k-1. Another trap is to assume that the GPY method gives a lower bound for prime tuples themselves; it only gives a lower bound for tuples with at least two primes, and the parity barrier still blocks a lower bound for exactly k primes.

The Sieve for the Ternary Goldbach Problem

The ternary Goldbach conjecture states that every sufficiently large odd integer N can be written as a sum of three primes. Vinogradov (1937) proved this for all large N using the circle method, not a sieve. However, sieve methods give complementary results for almost‑prime representations. The linear sieve with dimension κ = 3 applied to the set of representations N = p₁ + p₂ + p₃ yields an upper bound of the correct order for the number of representations with each p_i having at most two prime factors. The singular series for the ternary problem is 𝔖₃(N) = ∏_p (1 − (p−1)-2) (1 + O(p-2)), which converges to a positive constant for odd N. Chen (1973) used a weighted sieve to show that every sufficiently large even integer is a sum of a prime and an integer with at most two prime factors (Chen’s theorem). The same technique adapted to three variables gives that every large odd N is a sum of a prime and two almost primes of order two. The weight function is constructed from the Selberg sieve weights for each variable, combined with a bilinear form decomposition that separates the major arcs (where the circle method gives asymptotics) from the minor arcs (where the large sieve gives bounds).

The key analytic input is the level of distribution for the sequence of primes in arithmetic progressions, which is provided by the Bombieri–Vinogradov theorem (θ = 1/2). For the ternary problem one needs a level of distribution for the convolution of two prime sequences, which is essentially the same as the level for the binary Goldbach problem. The work of Liu and Wang (2002) improved the almost‑prime result to show that every large odd N is a sum of three integers each having at most two prime factors, using a refined linear sieve with dimension κ = 3 and a level of distribution θ = 4/7 obtained from the Barban–Davenport–Halberstam theorem for the ternary divisor function. The sifting parameter u = log N / log z then satisfies u = 7/4 = 1.75, which lies in the range where the lower bound sieve function f₃(u) is positive (f₃(u) > 0 for u < 3.506…). Hence the linear sieve gives a non‑trivial lower bound for the number of representations with three almost primes.

A common misconception is that the ternary Goldbach problem has been solved by sieve methods alone. The circle method remains essential for the prime case; sieve methods only reach almost primes. Another trap is to apply the linear sieve with κ = 1 to each variable separately and multiply the bounds, which ignores the correlation between the variables and yields an upper bound that is too large by a factor of (log N)2. The correct approach uses a multidimensional sieve that treats the tuple (p₁, p₂, p₃) as a single object of dimension 3.

The Sieve for the Distribution of Values of Multiplicative Functions

Beyond counting integers with restricted prime factors, sieve techniques can be used to study the distribution of values of multiplicative functions such as the divisor function τ(n), the Euler totient φ(n), or the sum‑of‑divisors function σ(n). The fundamental lemma of sieve theory gives an asymptotic for the number of n ≤ x with τ(n) ≤ y when y is a small power of x. For larger y one needs the Selberg–Delange method, which combines the sieve with complex analysis of the Dirichlet series Σ τ(n)^z n-s. The saddle‑point method applied to the generating function yields the precise asymptotic τ(n) ≤ y ∼ x (log x)α-1 / (Γ(α) log y) where α = log y / log log x. This result, due to Hildebrand (1986), shows that the distribution of τ(n) is governed by the same Buchstab function ω(u) that appears in the linear sieve, with u = log x / log y.

A more recent development is the work of Granville and Soundararajan (2007) on the distribution of multiplicative functions in short intervals. They proved that for any multiplicative function f with |f(n)| ≤ 1, the mean value (1/H) Σx < n ≤ x+H f(n) is close to the expected product over primes ∏p ≤ H (1 − 1/p) Σk≥0 f(p^k)/p^k, provided H ≥ xε. The proof uses a sieve to remove the contribution of large prime factors, reducing the problem to a sum over smooth numbers, which is then handled by the Hildebrand–Tenenbaum saddle‑point method. This technique has been extended to correlations of multiplicative functions, leading to progress on the Chowla and Elliott conjectures. The sieve dimension in these applications is typically κ = 1, because the condition “p divides n” is a single linear congruence, but the weight function is not the indicator of a sifted set; it is a multiplicative function itself, which requires a more delicate treatment of the error terms.

When applying sieve methods to multiplicative functions, one must keep track of the singular series that arises from the local factors of the Dirichlet series. For τ(n) the singular series is ζ(2) = π²/6, while for φ(n) it is ζ(2)ζ(3)/ζ(6). Omitting the singular series leads to an incorrect constant in the asymptotic formula. Another pitfall is to use the fundamental lemma for y larger than a small power of x; the lemma fails when y = x1/u with u fixed, and one must switch to the Selberg–Delange or saddle‑point method. The transition point is exactly where the sifting parameter u becomes bounded, mirroring the transition from the fundamental lemma to the linear sieve in the classical setting.

The Sieve for Primes in Polynomial Progressions and the Green–Tao Theorem

The Green–Tao theorem (2004) asserts that the primes contain arbitrarily long arithmetic progressions. The proof combines a transference principle with a dense model theorem and a sieve argument that produces a pseudorandom majorant for the von Mangoldt function. The majorant is constructed using the Selberg sieve with a carefully chosen weight function that mimics the divisor sum Λ(n) = Σd|n μ(d) log(n/d). The sieve dimension in this setting is κ = 1 because each congruence condition “p divides n” is a single linear condition. The level of distribution required is θ > 1/2, which is supplied by the Bombieri–Vinogradov theorem on average over moduli. The transference principle then allows one to transfer Szemerédi’s theorem for dense subsets of integers to the sparse set of primes. A key technical point is the construction of a measure ν(n) supported on integers n ≤ N such that ν(n) ≥ Λ(n) and the Fourier coefficients of ν are small. The Selberg sieve provides an upper bound ν(n) = (Σd|n, d≤R μ(d) g(d))² with g(d) = (log(R/d))/log R, and the choice R = N1/2−ε ensures the required pseudorandomness. The argument also uses the Gowers uniformity norms to control correlations of ν with nilsequences. Subsequent work by Green, Tao, and Ziegler extended the result to polynomial progressions of the form {x + P₁(y), …, x + P_k(y)} where the P_i are integer polynomials with zero constant term. The sieve dimension remains 1, but the complexity of the nilsequence analysis increases with the degree of the polynomials. The current state of the art shows that any system of polynomials with distinct degrees yields infinitely many prime constellations of that shape, assuming the inverse conjecture for the Gowers norms, which is now a theorem.

The Sieve for Squarefree Values of Polynomials and the Work of Granville

Determining how often a polynomial f(n) ∈ ℤ[n] takes squarefree values is a classical application of the squarefree sieve. The basic heuristic predicts that the proportion of n ≤ x with f(n) squarefree equals the product over primes p of (1 − ρ(p²)/p²), where ρ(p²) is the number of solutions to f(n) ≡ 0 (mod p²). For irreducible f of degree d ≥ 2, the sieve dimension is κ = d because the condition “p² divides f(n)” imposes d independent congruence conditions modulo p. The fundamental lemma of sieve theory gives an asymptotic for the number of n ≤ x with f(n) squarefree when the sifting level z satisfies z ≤ x1/(2d+ε). Granville (1998) refined this by using the Selberg sieve with a weight that incorporates the Möbius function μ²(f(n)) and obtained an asymptotic with a power‑saving error term for any fixed degree d, provided the abc conjecture holds for the polynomial values. Unconditionally, the best known result for general f is due to Heath‑Brown (2001), who proved that the number of n ≤ x with f(n) squarefree is C_f x + O(x1−δ) for some δ > 0 depending on d, using a combination of the large sieve and the geometry of numbers. For quadratic polynomials, the squarefree sieve reduces to the classical problem of squarefree values of n² + 1, where the constant C = ∏p (1 − χ(p)/p²) with χ the Legendre symbol. The parity problem appears here as an obstruction to obtaining a lower bound of the correct order when the sieve dimension exceeds 1; the linear sieve gives only an upper bound of the right magnitude. Recent work by Browning and Vishe (2017) uses a weighted sieve to overcome the parity barrier for certain families of polynomials, achieving lower bounds that match the expected asymptotic up to a constant factor.

The Sieve for Bounded Gaps Between Primes and the Zhang–Maynard–Polymath Method

Zhang’s 2013 breakthrough proved that there are infinitely many prime pairs with gap ≤ 70 000 000. The core of the argument is a modified GPY sieve that uses a level of distribution θ > 1/2 for the primes in arithmetic progressions, specifically the Bombieri–Vinogradov theorem with a well‑factorable modulus. Zhang introduced a truncated divisor sum weight Λ_R(n) = (Σd|n, d≤R μ(d) (log(R/d))^k)² with k large, and showed that for a suitable admissible k‑tuple 𝓗 = {h₁,…,h_k} the sum Σn≤x (Σh∈𝓗 Λ_R(n+h) − log 3x) is positive. The positivity forces at least two of the n+h to be prime. Maynard (2015) and the Polymath project simplified the weight to a multidimensional Selberg sieve: choose non‑negative coefficients λd₁,…,d_k supported on d₁⋯d_k ≤ R and maximize the ratio of the main term to the error term. The optimization reduces to a variational problem involving the function F(t₁,…,t_k) on the simplex Σ t_i ≤ 1. The optimal value yields the bound liminfn→∞ (pn+1−p_n) ≤ 246. The sieve dimension in this setting is κ = k because each prime imposes k independent congruence conditions on the tuple. The parity problem is circumvented by working with an upper bound sieve that detects at least two primes rather than exactly one. The method also extends to prime k‑tuples with positive density, giving bounded gaps between m primes for any m. The current record (Polymath 8b) is 246, and under the Elliott–Halberstam conjecture the bound improves to 6.

The Sieve for Primes in Beatty Sequences and Non‑Linear Sequences

A Beatty sequence is the set ⌊α n + β⌋ for irrational α > 1. The distribution of primes in such sequences is a natural extension of the prime number theorem for arithmetic progressions. The sieve dimension remains κ = 1 because the condition “p divides ⌊α n + β⌋” is a single linear congruence in n modulo p, but the coefficients are not periodic; they are given by the fractional parts of α n. Harman (1983) developed a sieve for sequences with a “well‑distributed” property, showing that if α has bounded partial quotients then the primes in the Beatty sequence have the expected asymptotic density 1/(α log x). The proof uses the large sieve inequality for exponential sums Σn≤x e(α n²) to control the error terms. For general irrational α, the level of distribution is limited by the Diophantine approximation properties of α. Recent work by Baker and Harman (2020) combined the Harman sieve with the Vinogradov–Korobov zero‑free region to obtain primes in Beatty sequences for almost all α. The method also applies to polynomial sequences ⌊P(n)⌋ where P is a polynomial with at least one irrational coefficient. The sieve dimension is still 1, but the level of distribution depends on the degree of P and the irrationality measure of its coefficients. The parity problem does not obstruct upper bounds, but lower bounds of the correct order remain open for non‑linear sequences.

The Sieve for Almost Primes in Thin Sets and the Bourgain–Gamburd–Sarnak Approach

Thin sets are subsets of integers of zero density, such as the values of a polynomial map on a sparse set or the orbit of a group action. Bourgain, Gamburd, and Sarnak (2016) developed a sieve for almost primes in the orbit of a thin subgroup of SL₂(ℤ) acting on ℤ². The sieve dimension is determined by the spectral gap of the associated Laplacian on the quotient space; a uniform spectral gap yields a level of distribution θ > 1/2 for the relevant congruence conditions. The weight function is built from the Selberg sieve on the group, using the expander property of the Cayley graphs modulo q. The main term involves the product of local densities, which are computed via the representation theory of SL₂(𝔽_p). The parity problem is avoided because the goal is to produce almost primes (numbers with at most r prime factors) rather than primes. The result shows that the orbit contains infinitely many integers with at most 2 prime factors, and under a stronger spectral gap the bound improves to r = 1 (i.e. primes). This method has been extended to other algebraic groups and to the affine sieve for integral points on varieties. The key technical input is the uniform expansion of the group action modulo q, which is established via the Bourgain–Gamburd expansion theorem. The sieve dimension in these applications can be larger than 1, but the expander machinery provides the necessary level of distribution to overcome the parity barrier for almost primes.

The Sieve for Primes of the Form x² + y⁴ and the Friedlander–Iwaniec Theorem

The Friedlander–Iwaniec theorem (1998) is a landmark result that established the existence of infinitely many primes of the shape x² + y⁴. The sequence A = {x² + y⁴ : 1 ≤ x, y ≤ N} has sieve dimension κ = 3/2 because the congruence x² ≡ −y⁴ (mod p) has on average p + O(1) solutions, giving a local density of 1 − 1/p + O(1/p²) and a product over primes that behaves like (log N)3/2. The classical linear sieve cannot reach this dimension; the parity problem would only yield an upper bound of the correct order. Friedlander and Iwaniec overcame this by constructing a weighted sieve that exploits a bilinear structure coming from the factorisation x² + y⁴ = (x + i y²)(x − i y²) in the Gaussian integers ℤ[i]. This factorisation allows the sifting condition d | x² + y⁴ to be rewritten as a sum over divisors in ℤ[i], which separates the variables x and y and produces Type I and Type II sums. The Type II sums are estimated using a large‑sieve inequality for Hecke Grössencharaktere, while the Type I sums are handled by the fundamental lemma of the combinatorial sieve. The weight function λ_d is supported on squarefree d ≤ z with an even number of prime factors, and its choice follows the Rosser–Iwaniec optimisation for dimension 3/2. The final asymptotic shows that the number of primes in A up to N is ≫ N / (log N)3/2, matching the expected order of magnitude. The proof also requires a level of distribution θ = 1/2 for the sequence in arithmetic progressions, which is supplied by the Bombieri–Vinogradov theorem for the Gaussian integers. This result opened the way for further applications of half‑dimensional sieves to other polynomial sequences where a suitable algebraic factorisation exists.

The Sieve for Almost Primes in Polynomial Values and the Work of Heath‑Brown on the Cubic Form x³ + 2y³

Heath‑Brown (2001) proved that the cubic form x³ + 2y³ represents infinitely many primes. The sequence A = {x³ + 2y³ : 1 ≤ x, y ≤ N} has sieve dimension κ = 4/3, reflecting the fact that the congruence x³ ≡ −2y³ (mod p) has on average p + O(p1/2) solutions. The parity problem again prevents a direct lower bound for primes, but a weighted sieve targeting almost primes with at most two prime factors succeeds. Heath‑Brown’s method combines the Selberg upper bound sieve with a bilinear decomposition that arises from the factorisation of x³ + 2y³ in the cubic field ℚ(∛2). In this field the polynomial splits as (x + ∛2 y)(x² − ∛2 xy + ∛4 y²), and the norm form gives a multiplicative structure that can be exploited. The sieve weight is chosen as a linear combination of divisor sums λ_d = μ(d) (log(z/d))^k for d ≤ z, with k optimised for dimension 4/3. The bilinear form is then estimated by separating the variables through a double sum over ideals in the ring of integers, applying the large sieve for number fields to control the Type II sums. The level of distribution required is θ > 1/2, which is provided by the Bombieri–Vinogradov theorem for the relevant Hecke L‑functions. The final result yields a lower bound of the expected order for integers in A with at most two prime factors, and under the Generalised Riemann Hypothesis the bound can be sharpened to primes. This work illustrates how algebraic factorisation in higher degree fields can be combined with the combinatorial sieve to bypass the parity barrier for specific polynomial sequences.

The Sieve for Primes in Short Intervals and the Huxley–Iwaniec Method

The problem of finding primes in short intervals [x, x + x^θ] has a long history. Huxley (1972) proved that for any ε > 0 there is a prime in [x, x + x7/12+ε] for sufficiently large x, using a combination of the large sieve and zero‑density estimates for the Riemann zeta function. Iwaniec (1978) refined this by introducing a sieve weight that detects primes in intervals of length x1/2+ε under the assumption of a suitable level of distribution for the sequence of integers in the interval. The modern formulation uses the Selberg sieve with a weight supported on integers having no prime factors below x^δ, where δ is chosen to balance the Type I and Type II sums arising from the Vaughan identity decomposition of the von Mangoldt function. The level of distribution required is θ = 1/2, which is provided by the Bombieri–Vinogradov theorem on average over moduli. The parity problem limits the method to upper bounds of the correct order for primes, but lower bounds for almost primes with a bounded number of prime factors can be obtained. Recent work by Baker, Harman and Pintz (2001) combined the Huxley–Iwaniec sieve with a refined zero‑free region to show that there is always a prime in [x, x + x0.525] for large x. The method also extends to primes in arithmetic progressions within short intervals, where the large sieve for Dirichlet characters replaces the large sieve for the zeta function. The key technical input is the estimation of exponential sums Σn≤x Λ(n) e(α n) for α close to a rational with small denominator, which is handled by the Vinogradov–Korobov method. This line of research demonstrates how sieve methods interact with analytic properties of L‑functions to push the exponent θ towards the conjectural 1/2.

The Sieve for the Distribution of Primes in Linear Recurrence Sequences

Linear recurrence sequences such as the Fibonacci numbers, Lucas sequences, and more general sequences defined by a_n = A α^n + B β^n with algebraic integers α, β, have been studied extensively with sieve methods. The set of indices n for which a_n is prime is expected to have density zero, but one can prove the existence of infinitely many almost primes in the sequence. The sieve dimension for a non‑degenerate binary recurrence is κ = 1, because the congruence a_n ≡ 0 (mod p) has either 0 or 2 solutions modulo the period of the sequence modulo p, giving an average of one solution per prime. The fundamental lemma of the combinatorial sieve then yields an upper bound of the correct order for the number of prime terms up to x. To obtain a lower bound, a weighted sieve is required. The work of Moree and Stevenhagen (2000) applied the Selberg sieve with a weight built from the Chebotarev density theorem for the splitting field of the characteristic polynomial. They showed that the sequence contains infinitely many integers with at most two prime factors. The level of distribution needed is θ = 1/2, which follows from the Bombieri–Vinogradov theorem for the associated Hecke L‑functions of the splitting field. The parity problem is circumvented by targeting almost primes rather than primes. For higher order recurrences the sieve dimension equals the number of distinct roots of the characteristic polynomial, and the same method applies provided the Galois group is sufficiently large to guarantee the required equidistribution of Frobenius elements. This area illustrates the interplay between algebraic number theory, sieve theory, and the distribution of Frobenius conjugacy classes.

The Harman Sieve and Primes in Short Intervals

Glyn Harman developed a flexible combinatorial sieve in the early 1990s that substantially improved the classical results on primes in short intervals. The Harman sieve combines a Selberg‑type upper‑bound weight with a careful bilinear decomposition of the remainder terms, allowing the level of distribution to be pushed up to 1/2 + ε for a wide class of sequences. The key innovation is the treatment of Type II sums via the large sieve for Dirichlet polynomials, which yields cancellation beyond the range accessible to the Bombieri–Vinogradov theorem alone. In his 1991 paper Harman proved that for any ε > 0 the interval [x, x + x7/12 + ε] contains a prime for all sufficiently large x; the exponent 7/12 ≈ 0.5833 was the first unconditional result breaking the √x barrier. Later, Baker, Harman and Pintz (2001) refined the method, incorporating a more delicate optimisation of the sieve weights and a sharper treatment of the minor arcs, to obtain the current record θ = 0.525. The sieve dimension for the interval problem is κ = 1, and the fundamental lemma of the combinatorial sieve supplies the correct main term once the level of distribution reaches 1/2. The parity problem is circumvented because the interval length exceeds x1/2, which forces a bilinear structure that the sieve can exploit. Harman’s monograph Prime‑Detecting Sieves (2007) gives a complete exposition of the method, including its application to Piatetski‑Shapiro sequences and to primes in arithmetic progressions with large moduli.

The Harman sieve constructs a weight w(n) = (∑d|n λ_d)2 where the coefficients λ_d are supported on d ≤ z and are chosen by solving a quadratic optimisation problem derived from Selberg’s sieve. The parameter z is taken as a small power of x, typically z = x1/4 − δ. The Type I sums are handled directly by the Bombieri–Vinogradov theorem, while the Type II sums require a large‑sieve estimate for Dirichlet polynomials of the form ∑m∼M a_m m-it. Harman’s innovation was to split the Type II range into sub‑ranges where either the large sieve or a Vinogradov‑type estimate gives sufficient cancellation. This flexibility allows the sieve to reach a level of distribution θ = 1/2 + ε for the interval problem, which is the threshold for the fundamental lemma to produce a lower bound of the correct order. The method also yields lower bounds for the number of primes in intervals of length xθ with an explicit constant depending on the sieve weights.

Beyond short intervals, the Harman sieve has been applied to the Piatetski‑Shapiro sequence ⌊n^c⌋. Harman showed that for c < 2817/2426 ≈ 1.161 the sequence contains infinitely many primes. The proof uses the same bilinear decomposition but with a different choice of the parameter z to accommodate the sparser sequence. The level of distribution required is again 1/2, supplied by the Bombieri–Vinogradov theorem for the relevant exponential sums. The exponent 2817/2426 remains the best unconditional result for this problem. The Harman sieve thus represents a versatile tool that bridges the gap between the classical Brun–Titchmarsh bounds and the more recent advances of the GPY and Maynard–Tao methods.

Maynard's Sieve for Primes with Missing Digits

In 2019 James Maynard proved that for any base q ≥ 2 and any digit a ∈ {0,…,q − 1} there are infinitely many primes whose base‑q expansion does not contain the digit a. The proof adapts the multidimensional Selberg sieve that underlies the Maynard–Tao theorem on bounded gaps between primes. The crucial new ingredient is a weight function that factorises over the digits of an integer, allowing the sieve to restrict the digit set while retaining a level of distribution θ > 1/2. The sieve dimension remains κ = 1 because the condition “digit a is missing” imposes a local restriction at each prime power dividing q, and the average number of solutions modulo p is still one. Maynard constructs a smooth weight w(n) = (∑d|n λ_d)2 where the coefficients λ_d are supported on integers d composed solely of primes not dividing q, and d ≤ x^θ with θ = 1/2 − δ. The Bombieri–Vinogradov theorem for arithmetic progressions with moduli coprime to q provides the required level of distribution. The weight is designed so that its correlation with the von Mangoldt function Λ(n) is asymptotically equal to the density of integers without the digit a, which is (1 − 1/q)log_q x ≈ x−δ with δ = log_q(q/(q − 1)). The resulting lower bound shows that the number of such primes up to x is ≫ x1 − δ / log x, which tends to infinity.

The parity problem is avoided because the sieve does not attempt to detect primes directly through a characteristic function; instead it uses a smooth majorant that correlates with Λ(n) and is supported on a set of integers with a prescribed digit pattern. The multidimensional nature of the sieve allows the weight to be a product of one‑dimensional Selberg weights, each corresponding to a digit position. This product structure is essential for obtaining a level of distribution up to 1/2, as it reduces the problem to estimating correlations of Λ(n) with multiplicative functions that are periodic modulo powers of q. Maynard’s argument also yields quantitative results: for base 10 and any missing digit, the number of primes ≤ x without that digit is at least x0.99 for large x. The method extends to simultaneous restrictions on several digits and to missing blocks of digits, demonstrating the flexibility of the multidimensional Selberg sieve when combined with a carefully chosen digit‑wise weight.

The Green–Tao–Ziegler Sieve for Polynomial Patterns in Primes

Ben Green, Terence Tao and Tamar Ziegler (2012) proved that the primes contain arbitrarily shaped polynomial patterns: for any polynomials P1,…,P_k ∈ ℤ[m] with zero constant term there exist infinitely many integers x, y such that x + P_i(y) are simultaneously prime. The proof combines the dense model theorem from additive combinatorics with the inverse theorem for the Gowers Us+1 norms, and it uses a transference principle to transfer a result about dense subsets of a pseudorandom set to the primes. The sieve component is the construction of a pseudorandom majorant ν(n) for the von Mangoldt function Λ(n) that satisfies the linear forms condition and the correlation condition required by the dense model theorem. This majorant is built using the multidimensional Selberg sieve with a weight that factorises over the polynomials P_i. The sieve dimension equals the number of polynomials k, and the level of distribution needed is θ > 1/2, which is supplied by the Bombieri–Vinogradov theorem for the nilsequences that arise from the inverse theorem. The parity problem is circumvented because the argument never attempts to sieve the primes directly; instead it works with the majorant ν, which is designed to be orthogonal to all structured functions of bounded complexity. The inverse theorem for the Gowers norms, proved by Green, Tao and Ziegler in a series of papers, guarantees that any function with large Gowers norm correlates with a nilsequence, and the Bombieri–Vinogradov theorem for nilsequences (established by Green and Tao) provides the necessary equidistribution. The final result yields a lower bound of the correct order for the number of polynomial patterns up to N, namely ≫ N2 / (log N)^k.

The construction of the majorant ν begins with a Selberg weight λ_d supported on d ≤ R where R = Nθ/2 and θ = 1/2 − ε. The weight is chosen so that ν(n) = (∑d|n λ_d)2 approximates Λ(n) on average. The linear forms condition requires that for any collection of linear forms L1,…,L_m in several variables, the average of ∏ ν(L_i) is 1 + o(1). This is verified by expanding the square and using the Bombieri–Vinogradov theorem for the resulting arithmetic progressions. The correlation condition controls correlations of ν with bounded functions; it follows from the fact that the weight is supported on smooth numbers and from the Siegel–Walfisz theorem. The dense model theorem then produces a bounded function f ≤ ν that has the same averages as Λ against all test functions of bounded complexity. Applying the inverse theorem to f yields a nilsequence correlation, which is then transferred back to Λ using the correlation condition. The polynomial patterns are finally obtained by a multidimensional Szemerédi theorem for nilsequences, proved by Green and Tao. The entire argument is unconditional and represents a profound synthesis of sieve theory, higher‑order Fourier analysis, and ergodic theory.

The Selberg upper‑bound sieve is then applied to each factor separately, with the Rosser–Iwaniec functions f_κ, F_κ tuned to the dimension κ = d − 1. The level of distribution θ > 1/2 is achieved by invoking the Bombieri–Vinogradov theorem for the Dedekind zeta function ζ_L(s) of the Galois closure L, which gives equidistribution of prime ideals in arithmetic progressions up to modulus x1/2 − ε.

The Intricacies of the Sifting Limit and the Parity Problem's Core

The concept of the sifting limit (often denoted by β or s) is central to understanding the inherent limitations of sieve methods, particularly in their classical forms. It represents a threshold beyond which a sieve cannot distinguish between integers with an even number of prime factors and those with an odd number of prime factors. For the linear sieve (sieve dimension κ = 1), this limit is typically 1/2. This means that if we attempt to sieve for primes (numbers with exactly one prime factor, an odd count), a linear sieve with a sifting range R = xα can only provide non-trivial lower bounds if α > 1/2. However, the classical linear sieve (like the Rosser–Iwaniec sieve) can only achieve a sifting limit of 1/2. This fundamental barrier is known as the parity problem.

The parity problem arises because standard sieve weights, which are multiplicative functions, cannot "see" the parity of the number of prime factors. A typical sieve weight function λd depends only on the divisors d of an integer n. When we sum these weights, the resulting sum is often a function of the number of prime factors of n, but it cannot differentiate between, for instance, a prime (one prime factor) and a product of three distinct primes (three prime factors), both of which have an odd number of prime factors. Similarly, it struggles to distinguish between a product of two distinct primes and a product of four distinct primes. The sieve functions Fκ and fκ, which provide upper and lower bounds respectively, are constructed using these weights. For κ = 1, the functions F1(s) and f1(s) converge to a common value only as s → ∞, which corresponds to an infinitely large sifting range, an impossibility in practice. When the sifting range R is limited (e.g., R = xα), the lower bound function f1(s) becomes negative for s ≤ 1/2, indicating that the sieve cannot guarantee a positive count of primes.

This limitation is not merely a technicality; it reflects a deep structural issue. The sieve weights are designed to count integers that have *no* prime factors up to a certain bound R. When R is small, say R = x1/2 - ε, the sieve effectively removes multiples of small primes. However, it cannot distinguish between numbers that are prime and those that are products of two primes, both of which are larger than R. For example, if we sieve up to R, a number p (prime) and a number p1p2 (product of two primes, p1, p2 > R) will both survive the sieve. The sieve cannot differentiate between these two cases based on the parity of their prime factors. This is why sieves are highly effective at finding "almost primes" (numbers with a bounded number of prime factors), but struggle with true primes. Breakthroughs like Chen's Theorem (showing that there are infinitely many primes p such that p+2 is a product of at most two primes) circumvent the parity problem by targeting almost primes, or by using weighted sieve methods that introduce additional structure to overcome this fundamental obstacle, often by combining sieve methods with other analytic tools like exponential sums or higher-order Fourier analysis.

Constructing Sieve Weights: Selberg's λd and Rosser–Iwaniec's ρd

The effectiveness of any sieve method hinges critically on the choice and construction of its sieve weights. These weights, typically denoted λd or ρd, are real numbers assigned to square-free integers d, and they dictate how "strongly" multiples of d are counted or excluded in the sifting process. Two of the most influential constructions are the Selberg λd weights and the Rosser–Iwaniec ρd weights, each serving distinct purposes and employing different mathematical strategies.

The Selberg λd weights are primarily used for constructing upper bound sieves. Selberg's method transforms the problem of estimating the size of a sifted set into a quadratic minimization problem. Specifically, for a set A of integers, we want to estimate S(A, P, z) = |{n ∈ A : gcd(n, P(z)) = 1}|, where P(z) = ∏p < z p. Selberg introduced a majorant function (a function that is always greater than or equal to the characteristic function of the sifted set) of the form (∑d|n λd)2. The weights λd are chosen to minimize the sum ∑n∈A (∑d|n λd)2, subject to the condition λ1 = 1. This minimization leads to an explicit formula for λd involving the Möbius function μ(d) and a quantity g(d) related to the density of the sequence A in arithmetic progressions. The Selberg weights are typically supported on d ≤ R, where R is the sifting limit, and they are designed to be "smooth" and rapidly decaying. Their quadratic nature inherently leads to an upper bound, as (∑d|n λd)2 ≥ 0, and if n is prime, it's 1. The Selberg sieve is renowned for its sharpness and relative simplicity in deriving upper bounds, often achieving the "natural" upper bound for many problems.

In contrast, the Rosser–Iwaniec ρd weights are designed to yield both upper and lower bounds, especially for the linear sieve (κ = 1). The Rosser–Iwaniec sieve is a combinatorial sieve that builds upon the Buchstab identity, which relates S(A, P, z) to S(A, P, z1) and sums over primes p in the interval [z1, z). By iteratively applying this identity, one can express S(A, P, z) as a sum involving a complex set of weights. The Rosser–Iwaniec method introduces a specific choice of these weights, ρd, which are constructed using a "smooth" version of the Möbius function, often defined via a product of characteristic functions of intervals. These weights are designed to satisfy certain "sifting limit" conditions, ensuring that the error terms remain manageable. The construction is more intricate than Selberg's, involving a careful balance to control the sign changes that naturally arise when trying to obtain lower bounds. The Rosser–Iwaniec sieve is particularly powerful because it can achieve the theoretical sifting limit of 1/2 for the linear sieve, providing the strongest possible bounds for κ = 1 problems without overcoming the parity problem. Its strength lies in its ability to handle general sequences A and its explicit control over the error terms, making it a cornerstone for many applications in analytic number theory, including Chen's theorem.

Understanding Sieve Weight Properties
Consider a sequence A = {n : n ≤ X} and we wish to sieve out multiples of primes p < z. For the Selberg sieve, the weights λd are chosen to minimize ∑n≤X (∑d|n λd)2 subject to λ1 = 1. Explain why this construction inherently leads to an upper bound for the number of unsifted elements, and what property of λd is crucial for this.
The Selberg sieve aims to estimate S(A, P, z) = |{n ∈ A : gcd(n, P(z)) = 1}|. It does this by constructing a majorant function Q(n) = (∑d|n λd)2 such that Q(n) ≥ 1 if gcd(n, P(z)) = 1, and Q(n) ≥ 0 for all n.

If gcd(n, P(z)) = 1, then n has no prime factors less than z. In this case, the only divisor d of n that can be less than the sifting limit R (where λd are supported) is d=1. Since λ1 = 1, then for such an n, Q(n) = (λ1 + ∑d|n, d>1 λd)2. The condition λ1=1 is imposed. If n is prime and n > z, then the only divisor d of n is 1, so Q(n) = (λ1)2 = 12 = 1.

For any n, the term (∑d|n λd)2 is always non-negative. Therefore, if we sum Q(n) over all n ∈ A, we get ∑n∈A Q(n) = ∑n∈A (∑d|n λd)2. This sum will always be an upper bound for S(A, P, z) because for every n that survives the sieve (i.e., gcd(n, P(z)) = 1), Q(n) ≥ 1. For n that do not survive, Q(n) ≥ 0. Thus, ∑n∈A Q(n) ≥ S(A, P, z).

The crucial property of λd for this upper bound is that λ1 = 1. This ensures that any element n that we *want* to count (i.e., an unsifted element) contributes at least 1 to the sum. The minimization process then finds the specific λd that make this upper bound as tight as possible.
Distinguishing Sieve Weight Functions
When encountering questions about sieve weights, remember the core purpose: Selberg weights (λd) are primarily for upper bounds and arise from a quadratic minimization. Rosser–Iwaniec weights (ρd) are for both upper and lower bounds, are combinatorially constructed using Buchstab's identity, and are crucial for achieving the sifting limit in linear sieves. Focus on the underlying mathematical technique (minimization vs. combinatorial identity) and the type of bound they provide.

The General Large Sieve Inequality and its Probabilistic Interpretation

The Large Sieve Inequality is a powerful and versatile tool in analytic number theory, providing bounds for sums over arithmetic progressions. Unlike traditional sieves that count integers with no small prime factors, the Large Sieve quantifies how "well-distributed" a sequence of integers is across many arithmetic progressions simultaneously. Its general form is an inequality that bounds the sum of squares of character sums, or more generally, sums of squares of Fourier coefficients.

Let A be a finite set of integers in an interval [M+1, M+N]. For each integer q ≥ 1, let χ be a Dirichlet character modulo q. The Large Sieve inequality, in one of its fundamental forms, states that for any sequence of complex numbers {an}, and for any set of pairwise inequivalent characters χ (mod q) with q ≤ Q, we have:
∑q≤Q ∑*χ (mod q) |∑n∈A an χ(n)|2 ≤ (N + Q2) ∑n∈A |an|2.
Here, ∑*χ (mod q) denotes a sum over primitive characters modulo q. A more general form involves a set of real numbers {xr} that are "well-separated" (e.g., |xr - xs| ≥ δ for r ≠ s), and bounds sums of exponential sums |∑ an e(nxr)|2. The term N + Q2 is crucial; it indicates that the inequality is non-trivial when Q2 is not too large compared to N.

The probabilistic interpretation of the Large Sieve is profound. Imagine a sequence A that is "randomly" distributed. We expect its elements to be roughly uniformly distributed across arithmetic progressions modulo q, for many q. If A were perfectly random, the sums ∑n∈A an χ(n) would be small on average. The Large Sieve essentially states that if a sequence A deviates significantly from this uniform distribution for many moduli q (i.e., many character sums are large), then the total number of elements N must be correspondingly large. It provides a quantitative measure of this deviation.

This "probabilistic" nature makes the Large Sieve invaluable for establishing level of distribution results, such as the Bombieri–Vinogradov theorem. The Bombieri–Vinogradov theorem essentially states that the primes are well-distributed in arithmetic progressions on average, up to moduli q as large as x1/2 - ε. The proof of such theorems relies heavily on the Large Sieve to bound error terms arising from sums over many moduli. It allows us to treat the distribution of primes (or other sequences) in arithmetic progressions as if they were nearly random up to a certain range of moduli, which is a critical input for many advanced sieve applications. Without the Large Sieve, establishing such strong average distribution results would be significantly harder, if not impossible, for many problems in analytic number theory.

Sieve Dimension: Quantifying the Density of Sifted Sequences

The concept of sieve dimension, denoted by κ (kappa), is a fundamental parameter in sieve theory that quantifies the "density" or "thinness" of the sequence being sifted. It plays a crucial role in determining the behavior of sieve functions (like Fκ and fκ) and the effectiveness of a sieve method for a particular problem. Essentially, κ measures the average number of congruence classes modulo p that are "removed" by the sieve for each prime p.

More formally, for a sequence A of integers, we define ω(p) as the number of residue classes modulo p that are forbidden (or "sifted out"). For instance, if we are sieving for primes, we remove the class 0 (mod p) for each prime p. So, ω(p) = 1 for all primes p. The sieve dimension κ is then defined such that, on average, ω(p) ≈ κ. This approximation is often expressed as ∑p≤z ω(p)/p log p ≈ κ log log z. For many problems, κ is a constant, but it can also be a function of p or other parameters in more complex scenarios.

Let's consider some examples:

  • Primes (κ = 1): When sieving for primes, we exclude multiples of p, meaning ω(p) = 1 for each prime p. Thus, the sieve dimension is κ = 1. This is the most challenging case for sieves due to the parity problem.
  • Almost Primes (κ = 1): Problems like finding integers with a bounded number of prime factors also typically fall under κ = 1, as the underlying sifting process is similar to that for primes.
  • Square-free numbers (κ = 1): To find square-free numbers, we remove multiples of p2 for each prime p. This means we remove one residue class (0 mod p2) for each prime p. While this might seem different, the effective density of numbers removed is still related to 1/p, so κ = 1.
  • Primes of the form n2 + 1 (κ = 1/2): For this problem, we consider the sequence A = {n2 + 1 : n ≤ X}. The number of roots of x2 + 1 ≡ 0 (mod p) is ω(p). This is 2 if p ≡ 1 (mod 4), 0 if p ≡ 3 (mod 4), and 1 if p = 2. On average, ω(p) is 1 for p ≡ 1 (mod 4) and 0 for p ≡ 3 (mod 4), leading to an average of 1/2. Hence, κ = 1/2. Problems with κ < 1 are generally easier for sieves, as the "density" of numbers being removed is lower, making it easier to obtain lower bounds.
  • Prime k-tuples (κ = k): For the Hardy–Littlewood conjecture concerning prime k-tuples (e.g., twin primes, where k=2), we are looking for integers n such that n+h1, n+h2, ..., n+hk are all prime. For each prime p, we must exclude n from ω(p) residue classes modulo p, where ω(p) is the number of distinct values among h1, ..., hk modulo p. On average, if the hi are distinct, ω(p) ≈ k, so κ = k. These problems are significantly harder as κ increases.

The sieve dimension directly influences the behavior of the sieve functions Fκ(s) and fκ(s), which are solutions to certain differential-difference equations. For κ < 1, the lower bound function fκ(s) can be positive for s > 0, meaning non-trivial lower bounds can be obtained even for small sifting ranges. For κ = 1, f1(s) is positive only for s > 1/2, highlighting the sifting limit and the parity problem. For κ > 1, obtaining positive lower bounds becomes increasingly difficult, often requiring very large sifting ranges or specialized techniques to overcome the inherent "thinness" of the sifted set.

The Role of Bilinear Forms and Type I/Type II Sums in Sieve Applications

Advanced sieve applications, especially those aiming for strong lower bounds or dealing with complex sequences, frequently employ a technique known as bilinear decomposition. This method transforms the problem of estimating a sum over a single variable into a sum of products of two sequences, often referred to as Type I sums and Type II sums. This decomposition is crucial because different analytic tools are effective for different types of sums, allowing researchers to leverage the strengths of various techniques.

Consider a sum of the form ∑n≤X Λ(n) f(n), where Λ(n) is the von Mangoldt function (or a similar arithmetic function) and f(n) is some test function. The goal is to estimate this sum. The characteristic function of a sifted set, or a function like Λ(n), can be written as a sum of products. For instance, the identity Λ(n) = ∑d|n μ(d) log(n/d) (or a variant like the Vaughan's identity) allows us to decompose sums involving Λ(n) into terms that resemble Type I and Type II sums.

A Type I sum typically takes the form ∑m≤M am ∑k≤X/m bk. Here, one of the sequences (e.g., am) is "well-behaved" or "smooth," and the summation range M is relatively small. These sums are often estimated using tools like the large sieve inequality, character sum estimates, or the theory of exponential sums. The key is that the inner sum over k can often be evaluated or bounded effectively because bk is a simple function (e.g., 1 or μ(k)).

A Type II sum is more complex, typically taking the form ∑M < m ≤ M' am ∑K < k ≤ K' bk, where both M and K are in an intermediate range (e.g., M, K ≈ X1/2), and both sequences am and bk can be "rough" or oscillatory. These sums are generally the hardest to estimate and often represent the bottleneck in sieve applications. They require sophisticated techniques, including the use of the large sieve for GL(d) (for higher-dimensional problems), deep results from the theory of exponential sums (e.g., Weil's bounds), or spectral theory of automorphic forms. The challenge lies in the entanglement of the variables m and k, which are often related by a multiplicative or additive structure.

The success of a sieve method in obtaining strong results (especially lower bounds) often depends on finding an optimal bilinear decomposition and then effectively estimating the resulting Type I and Type II sums. For example, in the proof of the Bombieri–Vinogradov theorem, the main term is handled by Type I sums, while the error terms require careful estimation of Type II sums. The "level of distribution" θ, which dictates how large the moduli q can be for which primes are well-distributed in arithmetic progressions, is often determined by the ability to control these Type II sums. A higher θ allows for a larger sifting range R = xθ, which in turn leads to stronger sieve results. The interplay between these decompositions and the choice of analytic tools is a hallmark of modern sieve theory, allowing it to push beyond the limitations of classical combinatorial methods.

The Harman Sieve and its Adaptations for Primes in Short Intervals

While classical sieve methods often struggle to obtain lower bounds for primes, especially in specific configurations like short intervals, the Harman Sieve represents a significant advancement. Developed by Glyn Harman, this method is a variant of the linear sieve that cleverly combines combinatorial arguments with Fourier analysis and exponential sum estimates. Its primary strength lies in its ability to find primes in "thin" sets or short intervals, where traditional sieves often fail due to the parity problem or insufficient level of distribution.

The core idea of the Harman Sieve is to avoid the explicit construction of sieve weights (like λd or ρd) that are designed to count numbers with *no* small prime factors. Instead, it directly estimates the sum ∑n∈A Λ(n) (where A is the set of interest, e.g., integers in a short interval) by decomposing Λ(n) into a sum of bilinear forms, similar to Vaughan's identity. However, unlike standard approaches, the Harman Sieve does not rely on a fixed sifting limit R. Instead, it carefully chooses the ranges of the variables in the bilinear sums to optimize the application of various analytic tools.

The decomposition leads to sums of the form ∑m am ∑k bk f(mk), where f(n) is the characteristic function of the set A. These sums are then split into "major arcs" and "minor arcs" using Fourier analysis. The major arcs correspond to terms where the argument of the exponential sum is close to a rational number with a small denominator, and these are estimated using classical analytic number theory techniques (e.g., properties of Dirichlet characters and L-functions). The minor arcs, where the argument is "far" from such rationals, are estimated using powerful exponential sum bounds (e.g., Weyl's inequality, Vinogradov's mean value theorem, or bounds for Kloosterman sums).

A key feature of the Harman Sieve is its flexibility in handling the "level of distribution." Instead of requiring a uniform distribution for primes in arithmetic progressions up to a fixed power of X (like X1/2 - ε), it can work with weaker, conditional distribution results or even directly estimate sums without relying on a pre-established level of distribution. This makes it particularly effective for problems where the Bombieri–Vinogradov theorem is not available or insufficient, such as finding primes in very short intervals (e.g., (X, X + Xθ) for θ < 1/2) or in sequences with complex multiplicative structures.

For example, Harman used his sieve to show that there are primes in the interval (X, X + X0.525), improving earlier results. The method's strength lies in its ability to adapt to the specific problem at hand, making optimal use of available exponential sum estimates. It represents a departure from the traditional combinatorial sieve paradigm, demonstrating how a direct analytic approach, carefully structured through bilinear forms and Fourier analysis, can overcome some of the inherent limitations of classical sieve theory, particularly the parity problem, by not directly sieving for primes but rather estimating sums involving the von Mangoldt function.

Common Traps in Advanced Sieve Theory

  • Confusing Sifting Limit with Sifting Range: The sifting range R is the upper bound for primes used in the sieve (e.g., p < R). The sifting limit (e.g., 1/2 for linear sieves) is a theoretical threshold for the exponent α in R = xα, below which lower bounds for primes cannot be obtained due to the parity problem. They are related but distinct concepts.
  • Misattributing Sieve Weight Purposes: Incorrectly stating that Selberg weights are for lower bounds or Rosser–Iwaniec weights are exclusively for upper bounds. Remember: Selberg for upper bounds (quadratic minimization), Rosser–Iwaniec for both (combinatorial, Buchstab identity).
  • Overlooking the "Average" Nature of Large Sieve: Assuming the Large Sieve guarantees uniform distribution for *every* modulus q. It provides an *average* statement over many moduli, which is crucial for results like Bombieri–Vinogradov, but not for individual q.
  • Incorrectly Calculating Sieve Dimension (κ): Failing to correctly identify ω(p), the number of forbidden residue classes modulo p, for a given problem. This directly impacts the expected behavior of the sieve functions and the difficulty of the problem.
  • Ignoring the Difficulty of Type II Sums: Underestimating the complexity of Type II sums in bilinear decompositions. These are generally the hardest to bound and often determine the ultimate strength (e.g., level of distribution) of a sieve result.
  • Assuming Harman Sieve is a Universal Prime Finder: While powerful, the Harman Sieve is highly technical and problem-specific. It doesn't "solve" the parity problem generally but circumvents it for specific applications by using a direct analytic approach rather than a combinatorial one.
  • Mixing Up Sieve Theory with Elementary Number Theory: While related, sieve theory uses advanced analytic techniques (Fourier analysis, L-functions, exponential sums) to go beyond what elementary counting arguments can achieve, especially for primes.

The Diamond–Halberstam–Richert Beta Sieve and Optimized Upper Bounds

The beta sieve, introduced by Diamond, Halberstam and Richert in the 1970s, refines the Selberg upper‑bound sieve by introducing a continuous parameter β that interpolates between the linear sieve (β = 1) and the classical Selberg quadratic form (β = 2). For a sifted set A with sieve dimension κ, the sieve weight λ_d is chosen to minimise the quadratic form ∑d|P(z) λ_d2 g(d) subject to λ1 = 1 and λ_d = 0 for d > z^β, where g is the multiplicative density function. The resulting upper bound takes the shape S(A, P, z) ≤ X V(z) (F_κ(β, s) + o(1)), where s = log X / log z and F_κ is the sifting function computed by solving a differential‑difference system. The optimal β for a given κ and s is determined by the point where the derivative of F_κ with respect to β vanishes; this yields the smallest possible constant in the upper bound. In practice the beta sieve gives the strongest known unconditional upper bounds for many problems of dimension κ > 1, for example the number of integers ≤ X with no prime factor below X1/u when u lies between the linear‑sieve limit 2 and the Selberg limit 4. The method also supplies explicit numerical values for F_κ, which are tabulated in the monograph of Diamond and Halberstam (2008) and used in applications such as bounding the number of almost‑prime values of polynomials.

The Sieve for Primes in Piatetski‑Shapiro Sequences n^c

Piatetski‑Shapiro proved in 1953 that for any fixed c with 1 < c < 12/11 the sequence ⌊n^c⌋ contains infinitely many primes. The proof combines the Hardy–Littlewood circle method with a combinatorial sieve of Brun type. Later, Harman (1983) and Baker–Harman (1996) extended the admissible range to c < 2817/2426 ≈ 1.161 by exploiting bilinear forms and the large sieve. The modern approach writes the characteristic function of primes as a sum of Type I and Type II sums via Vaughan’s identity, then applies the Bombieri–Vinogradov theorem on average over moduli q ≤ Q with Q = X1/2 - ε. The crucial estimate is a bound for exponential sums ∑n ≤ N e(α n^c) on minor arcs, which follows from van der Corput’s method and the theory of exponent pairs. For c close to 1 the sieve dimension is 1, so the linear sieve asymptotics (Buchstab function) give the expected main term. The current record c < 1.161 remains the best unconditional result; under the Elliott–Halberstam conjecture the range can be pushed to c < 3/2. The method illustrates how a sieve of dimension one can be combined with deep exponential‑sum estimates to treat sparse polynomial‑like sequences.

Worked Example: Upper Bound for ⌊n^c⌋ Primes
Let c = 1.1 and X = 1012. Using the linear sieve with level of distribution θ = 1/2, estimate an upper bound for the number of primes of the form ⌊n^c⌋ ≤ X.
The sifted set is A = {⌊n^c⌋ : n ≤ X1/c}. Its size is |A| ∼ X1/c. The sieve dimension is κ = 1. Choose z = X1/2. By the Fundamental Lemma, S(A, P, z) ≤ 2 e^γ |A| / log z (1 + o(1)). Here log z = (1/2) log X. Substituting |A| ≈ X1/c gives an upper bound ≈ 4 e^γ X1/c / log X. For X = 1012 and c = 1.1 this evaluates to roughly 4·1.78·1010.9 / 27.6 ≈ 2.6·109. This crude bound already shows the expected order of magnitude; sharper constants come from the linear sieve function F1(s) with s = 2.

The Sieve for Primes in Exponential Sequences a^n + b

Sequences of the form a^n + b with fixed integers a > 1, b ≠ 0 present a different sparsity: the n‑th term grows exponentially, so the counting function up to X is about log X / log a. Classical sieve methods cannot be applied directly because the natural density is zero. Instead one uses a weighted sieve combined with primitive divisor theorems (Zsigmondy, Bang) and lower bounds for linear forms in logarithms (Baker’s theory). Schinzel (1962) conjectured that a^n + b contains infinitely many primes unless a trivial obstruction exists (e.g., a and b both odd). Unconditionally, results are scarce: for a = 2, b = 1 (Fermat numbers) only five primes are known; for a = 2, b = -1 (Mersenne numbers) the Lucas–Lehmer test gives a primality criterion but no infinitude proof. Harman (1991) developed a sieve for sequences with exponential growth by decomposing the von Mangoldt function via Vaughan’s identity and estimating the resulting Type II sums using bounds for exponential sums ∑ e(α a^n). The key input is a non‑trivial estimate for ∑n ≤ N e(α a^n) on minor arcs, which follows from the theory of linear forms in logarithms and the large sieve for exponential sequences. This yields upper bounds of the correct order of magnitude for the number of prime values up to X, and under GRH one can obtain asymptotic formulas. The method showcases how sieve ideas adapt to zero‑density sets when strong Diophantine approximation tools are available.

The Sieve for Primes in Polynomial Values over Function Fields

Over the polynomial ring F_q[t] the analogue of the integers is the set of monic polynomials. The prime number theorem for function fields (Weil, 1948) gives an exact formula for the number of irreducible polynomials of degree n. Sieve methods transfer almost verbatim: the large sieve inequality holds with the same shape, and the Bombieri–Vinogradov theorem was proved by Hsu (1996) and later refined by Hall (2010). The Selberg sieve yields upper bounds for the number of polynomial values f(P) that are irreducible, where f ∈ F_q[t][X] is a fixed polynomial. The sieve dimension equals the number of irreducible factors of f over the algebraic closure, and the sifting limit is 1/2 for dimension one, exactly as over ℤ. A striking application is the function‑field version of the twin prime conjecture: for any non‑constant polynomial f, there are infinitely many P such that f(P) and f(P)+1 are both irreducible, provided q is large enough relative to deg f. This was proved by Pollack (2008) using a multidimensional Selberg sieve together with the equidistribution of Frobenius conjugacy classes (Katz’s work on monodromy groups). The function‑field setting also allows exact computation of the singular series, which becomes a product over closed points of the affine line. These results serve as a testing ground for conjectures over ℤ and illustrate the parallel between number fields and function fields.

The Sieve for Primes in Norm Forms from Division Algebras

Let D be a central division algebra of degree d over a number field K, and let Nrd: D → K be the reduced norm. The set of values Nrd(x) for x in a maximal order O_D is a multiplicative semigroup. Ellenberg and Venkatesh (2007) applied a sieve to count elements of bounded height whose reduced norm is prime. The sieve dimension equals the dimension of the algebraic group SL1(D), which is d2 - 1. The main technical tool is the spectral large sieve for the adelic quotient SL1(D)SL1(D_A), developed via the theory of automorphic forms on inner forms of SL_n. The level of distribution is governed by bounds for matrix coefficients of unitary representations, which follow from the work of Clozel and Oh on exponential mixing. Under the Generalised Ramanujan Conjecture for GL_n, one obtains a level of distribution θ = 1/2 - ε, sufficient to run a linear sieve and produce infinitely many prime norms when d = 2 (quaternion algebras). For higher degree the parity problem reappears, but weighted sieves (GPY type) give almost‑prime results. This circle of ideas connects the classical sieve for integers with the modern theory of automorphic representations and illustrates how the geometry of the underlying algebraic group dictates the sieve dimension and the quality of distribution estimates.

The Sieve for Primes in the Values of a Polynomial at Prime Arguments

Let f ∈ ℤ[X] be an irreducible polynomial of degree d ≥ 2 with positive leading coefficient. The problem of counting primes p ≤ x for which f(p) is also prime is a natural extension of the classical prime‑value problem. The Bateman–Horn conjecture predicts an asymptotic formula of the shape

πf(x) ∼ Cf x / (log x)2

where Cf is a product over primes encoding local obstructions. Unconditionally, sieve methods give upper bounds of the correct order of magnitude. Applying the linear sieve (Rosser–Iwaniec) to the sequence A = {f(p) : p ≤ x, p prime} with sifting level z = x1/2 yields

|{p ≤ x : f(p) prime}| ≤ (2d + o(1)) Cf x / (log x)2.

The constant 2d comes from the sieve dimension κ = d and the linear‑sieve upper bound function F(s) evaluated at s = 2. The level of distribution for the sequence A is essentially 1/2, because the primes p are well distributed in arithmetic progressions up to modulus Q = x1/2−ε by the Bombieri–Vinogradov theorem. Harman (1983) refined this by combining the linear sieve with a bilinear‑form decomposition of the von Mangoldt function, obtaining the same order of magnitude with an explicit constant depending only on d. For quadratic polynomials, Iwaniec (1978) showed that the number of primes p ≤ x with p2+1 prime is ≪ x/(log x)2, and the same method works for any irreducible quadratic. The parity problem prevents lowering the exponent 2 to 1, so an asymptotic formula remains out of reach without assuming the Elliott–Halberstam conjecture or the Generalised Riemann Hypothesis.

The Sieve for Primes in the Values of a Polynomial at Smooth Numbers

Let Ψ(x, y) denote the number of y‑smooth integers ≤ x. For a fixed polynomial f ∈ ℤ[X] of degree d ≥ 1, one studies the set

S(x, y) = {n ≤ x : f(n) is y‑smooth}.

When y = x1/u with u fixed, the Hildebrand–Tenenbaum saddle‑point method gives an asymptotic for Ψ(x, y) involving the Dickman function ρ(u). For polynomial values, the same technique applies after a change of variables: the condition f(n) ≤ x and f(n) y‑smooth translates into a smoothness condition on n in a region of size ≈ x1/d. Granville (1998) proved that for any fixed u > 1,

|S(x, x1/u)| ∼ Cf x1/d ρ(u d) / log x

where Cf is a constant depending on the splitting field of f. The proof uses the Selberg sieve to remove integers n for which f(n) has a prime factor > y, together with the fundamental lemma of sieve theory to control the error terms. The sieve dimension equals the number of irreducible factors of f over ℚ, and the sifting limit is 1/2 for dimension one, matching the classical case. For higher‑degree polynomials, the dimension is >1 and the sifting limit drops below 1/2; the linear sieve then gives upper bounds of the correct order but not asymptotics. Recent work of Harper (2020) combined the hypergraph container method with the Selberg sieve to obtain sharp upper bounds for the number of smooth values of f when y is as small as exp((log x)1/2+ε). This illustrates how modern combinatorial tools can push the smoothness threshold beyond the reach of classical analytic methods.

Worked Example: Upper Bound for Prime Values of a Quadratic at Prime Arguments
Let f(X) = X2 + 1. Using the linear sieve with level of distribution 1/2, show that the number of primes p ≤ x such that p2 + 1 is prime is ≪ x / (log x)2.
Consider the sequence A = {p2+1 : p ≤ x, p prime}. For each prime q, the congruence p2 ≡ −1 (mod q) has either 0 or 2 solutions modulo q. Hence the sifting density is κ = 2. By the Bombieri–Vinogradov theorem, the primes are well distributed in progressions up to modulus Q = x1/2−ε, giving level of distribution θ = 1/2. Apply the Rosser–Iwaniec linear sieve with sifting parameter z = x1/2. The upper bound sieve function F(s) satisfies F(2) = 2. Therefore the sifted set size is ≤ (2·2 + o(1)) Cf x / (log x)2 = O(x/(log x)2). The constant Cf = ∏q (1 − ω(q)/q)/(1 − 1/q)2 where ω(q) = 2 if q ≡ 1 (mod 4) and 0 otherwise. This yields the claimed bound.

Remember that the parity problem forces the exponent 2 in the denominator; any claim of an asymptotic with exponent 1 requires an unproven hypothesis.

The Sieve for Primes in the Values of a Polynomial at Almost Primes

An integer is called an Er‑number (or almost prime of order r) if it has at most r prime factors counted with multiplicity. Chen’s theorem (1973) states that every sufficiently large even integer is a sum of a prime and an E2‑number. The same sieve machinery produces results for polynomial values. Let f ∈ ℤ[X] be irreducible of degree d ≥ 2. Using the weighted sieve of Goldston–Graham–Pintz–Yıldırım (GPY) one can show that there are infinitely many integers n such that f(n) is an Er‑number with r = d + 1. The argument proceeds by constructing non‑negative sieve weights λd supported on squarefree d ≤ z = x1/(d+1) and optimizing the ratio of the main term to the error term. The sieve dimension is κ = d, and the sifting limit for the upper bound sieve is β = 2. By choosing the weight function to approximate the indicator of integers with ≤ r prime factors, one obtains a lower bound of the correct order of magnitude for the count of n ≤ x with f(n) ∈ Er. For quadratic polynomials (d = 2) this yields r = 3, i.e. infinitely many n with f(n) having at most three prime factors. Heath‑Brown (1983) improved this to r = 2 for the specific cubic form X3 + 2Y3 by exploiting the bilinear structure of the associated exponential sums. The parity problem prevents reaching r = 1 (primes) without additional hypotheses such as the Elliott–Halberstam conjecture. Recent work of Maynard (2015) on multidimensional sieves shows that for any admissible k‑tuple of linear forms, one can produce infinitely many integers n for which at least two of the forms are prime; adapting this to polynomial values remains an open challenge.

The Sieve for Primes in the Values of a Polynomial at Fibonacci Numbers

The Fibonacci sequence (Fn) grows exponentially, so the set {f(Fn) : n ≤ N} is extremely sparse. Standard sieve axioms assume a positive density sequence; here the counting function is ≈ c log N. To apply sieve methods one introduces a weight function w(n) = 1/Fn (or a smooth approximation) so that the weighted sum ∑n≤N w(n) behaves like a constant. The large sieve inequality for exponential sequences, developed by Harman (1984) and refined by Baker–Harman (1996), gives non‑trivial bounds for ∑n≤N e(α Fn) on minor arcs. Combining this with Vaughan’s identity for the von Mangoldt function yields a level of distribution θ = 1/2 − ε for the weighted sequence. The Selberg upper bound sieve then produces

|{n ≤ N : f(Fn) prime}| ≤ (2d + o(1)) Cf N / (log N)2.

The constant Cf involves the product over primes of local densities, which can be computed using the fact that the Fibonacci sequence modulo q is periodic with period dividing q − (5/q). For quadratic f, the sieve dimension is 2 and the bound matches the conjectured order of magnitude up to the constant factor. Under the Generalised Riemann Hypothesis for the relevant L‑functions, one can replace the upper bound by an asymptotic formula with the same main term. This illustrates how Diophantine approximation (bounds for linear forms in logarithms) and the large sieve for exponential sequences enable sieve theory to handle zero‑density sets.

The Sieve for Primes in the Values of a Polynomial at Squarefree Arguments

Let f ∈ ℤ[X] be a polynomial without fixed square factors. The problem of counting squarefree values of f is classical; Erdős (1951) proved that a positive proportion of integers n give squarefree f(n). The sieve for squarefree values uses the Möbius function μ and the identity

∑d2|f(n) μ(d) = 1 if f(n) is squarefree, 0 otherwise.

Summing over n ≤ x and interchanging the order gives a main term x ∏p (1 − ρ(p2)/p2) where ρ(m) is the number of solutions of f(n) ≡ 0 (mod m). The error term is controlled by the large sieve for the sequence f(n) modulo p2. Granville (1998) showed that the error is O(x1−δ) for some δ > 0 depending on the degree of f. For the related problem of primes among squarefree values, one applies the linear sieve to the subsequence of n with f(n) squarefree. The sieve dimension remains the number of irreducible factors of f, but the level of distribution improves because the squarefree condition removes the contribution of higher prime powers. This yields an upper bound of the shape O(x/(log x)2) for the number of n ≤ x such that f(n) is both squarefree and prime. The parity problem again prevents an asymptotic. Recent work of Browning–Heath‑Brown (2021) combined the squarefree sieve with the hypergraph container method to obtain power‑saving error terms for the number of squarefree values of f in short intervals, a result that feeds into the study of almost primes in thin sets.

  • Treating the level of distribution for prime arguments as 1 instead of 1/2; the Bombieri–Vinogradov theorem limits it to 1/2 unconditionally.
  • Overlooking the need for a weight function when sifting exponential or Fibonacci sequences; without it the sequence has zero density and standard sieve axioms fail.
  • Believing that the squarefree sieve automatically produces primes; it only removes higher prime powers, the parity problem remains for the prime condition.

The Sieve for Primes in the Values of a Polynomial at Arguments with a Fixed Number of Prime Factors

Let f ∈ ℤ[X] be a polynomial without fixed prime divisors. The problem of counting integers n ≤ x such that f(n) is prime and n has exactly k prime factors (counted with multiplicity) combines two sifting conditions. The sequence 𝒜 = {f(n) : n ≤ x, Ω(n) = k} has density roughly x(log log x)k−1 / ((k−1)! log x) by the Sathe–Selberg theorem. The sieve dimension for the polynomial values is the number of irreducible factors of f over ℚ, denoted κ. To obtain an upper bound for the number of prime values, one applies the Selberg upper bound sieve with weights supported on integers having exactly k prime factors. The level of distribution for the sequence f(n) restricted to Ω(n) = k can be derived from the Bombieri–Vinogradov theorem for the polynomial sequence, which holds with exponent 1/2 unconditionally for κ = 1 and under GRH for higher κ. Chen’s theorem (1973) on Goldbach’s problem is the prototype: it shows that every large even integer is a sum of a prime and an almost prime with at most two prime factors. For polynomial values, Iwaniec (1978) used the linear sieve to prove that n2+1 is an almost prime with at most two prime factors infinitely often. The same method yields an upper bound of the shape (2κ+o(1)) Cf x / (log x)2 for the number of n with Ω(n) = k and f(n) prime, where Cf is the singular series. The parity problem blocks a matching lower bound; one cannot distinguish between integers with an even or odd number of prime factors in the sifted set without additional hypotheses such as the Elliott–Halberstam conjecture. Recent work of Maynard (2015) on multidimensional sieves produces bounded gaps between primes, but adapting it to polynomial values at almost prime arguments remains open. The constant Cf involves the product over primes of local densities ρ(p)/p, where ρ(m) counts solutions of f(n) ≡ 0 (mod m). For k = 1 (prime arguments) the level of distribution is limited to 1/2 by Bombieri–Vinogradov; for k ≥ 2 the level improves because the condition Ω(n) = k removes the contribution of small prime factors, allowing a larger sifting range. The Rosser–Iwaniec sieve gives explicit upper bound sieve functions F(s) and lower bound functions f(s) for the linear sieve dimension κ = 1, with the sifting limit β = 2. For κ > 1 the sifting limit is β = 2κ/(κ−1), which is larger, making the problem harder. The fundamental lemma of sieve theory provides an asymptotic for the sifted set when the sifting parameter s = log x / log z is bounded, but here s grows with x, so the linear sieve asymptotics are needed.

The Sieve for Primes in the Values of a Polynomial at Arguments Free of Small Prime Factors

An integer is called y-rough if it has no prime factor smaller than y. The set of y-rough numbers up to x has density ∼ ω(u) where u = log x / log y and ω is the Buchstab function, satisfying ω(u) = 1/u for 1 ≤ u ≤ 2 and uω′(u) = −ω(u−1) for u > 2. Sifting the polynomial sequence f(n) over y-rough arguments n ≤ x is a classical tool for primes in short intervals and for the Harman sieve. The sequence 𝒜 = {f(n) : n ≤ x, n is y-rough} has a level of distribution that can be taken as θ = 1/2 − ε by the large sieve for rough numbers, developed by Harman (1984) and refined by Baker–Harman (1996). The Selberg upper bound sieve then yields |{n ≤ x : n is y-rough, f(n) prime}| ≤ (2κ+o(1)) Cf x ω(u) / log x. The constant Cf is the same singular series as before. The parity problem again prevents a lower bound of the same order. The sifting parameter for the rough condition is s = log x / log y = u. The linear sieve asymptotics for the Buchstab function give the main term when u is bounded. For u → ∞, ω(u) ∼ e−γ / log u, where γ is Euler’s constant. This matches the density of integers free of small prime factors. The Harman sieve uses a decomposition of the von Mangoldt function into Type I and Type II sums, where the Type II sums involve bilinear forms with one variable restricted to rough numbers. The large sieve inequality for rough numbers, ∑q≤Q ∑a mod q |∑n≤x, n rough an e(an/q)|2 ≤ (x+Q2) ∑ |an|2, holds with a saving because the rough numbers are well distributed in arithmetic progressions. This allows a level of distribution θ = 1/2 for the rough sequence, which is the same as for the full sequence of integers. The fundamental lemma of sieve theory gives an asymptotic for the number of rough numbers up to x when u is bounded, but for the polynomial values one needs the linear sieve because the sifting range for the prime condition extends to z = x1/2. The Rosser–Iwaniec sieve provides explicit upper and lower bound functions for the linear sieve dimension κ = 1, with the sifting limit β = 2. For higher dimension κ > 1 the sifting limit is larger, and the upper bound sieve functions are given by the Diamond–Halberstam–Richert beta sieve. The parity problem manifests as the inability to sieve beyond the sifting limit β = 2 for the prime condition, regardless of the rough condition. Under the Elliott–Halberstam conjecture, the level of distribution for the rough sequence can be taken as 1, which would break the parity barrier for certain k-tuples.

Worked Example: Upper Bound for Primes of the Form n²+1 with n Rough
Let f(n) = n²+1. Use the Selberg upper bound sieve to show that the number of n ≤ x such that n is x1/4-rough and f(n) is prime is ≤ (4+o(1)) Cf x ω(4) / log x, where Cf is the singular series and ω is the Buchstab function.
The polynomial f(n) = n²+1 is irreducible, so sieve dimension κ = 1. The singular series is Cf = ∏p (1 − ρ(p)/p) / (1 − 1/p) with ρ(p) = 1 + (−1/p) (Legendre symbol). For p = 2, ρ(2) = 1; for odd p, ρ(p) = 2 if p ≡ 1 (mod 4), 0 if p ≡ 3 (mod 4). The product converges to a positive constant. The set of n ≤ x that are x1/4-rough has u = log x / log x1/4 = 4. The Buchstab function ω(4) satisfies ω(4) = 1/4 ∫34 ω(t−1) dt = 1/4 ∫34 ω(u) du. Using ω(u) = 1/u for 1 ≤ u ≤ 2 and the differential equation, one computes ω(3) = (1+log 2)/3 ≈ 0.564, ω(4) = (1+log 3)/4 ≈ 0.524. The Selberg sieve with dimension κ = 1 gives an upper bound of the form (2κ+o(1)) Cf x ω(u) / log x = (2+o(1)) Cf x ω(4) / log x. However, the polynomial values f(n) are even for odd n, so one must restrict to even n or incorporate the factor 2 into the singular series. The key steps are: (1) compute the Buchstab function ω(u) for the given u; (2) determine the sieve dimension κ of the polynomial; (3) apply the Selberg upper bound sieve with level of distribution θ = 1/2 (unconditional) or θ = 1 (under Elliott–Halberstam); (4) write the upper bound as (2κ+o(1)) Cf x ω(u) / log x. The constant Cf is the singular series product over primes of (1 − ρ(p)/p)/(1 − 1/p). Do not confuse the sifting parameter s = log x / log z with the rough parameter u = log x / log y; they control different aspects of the sieve.

The Sieve for Primes in the Values of a Polynomial at Arguments Represented by a Binary Quadratic Form

Let Q(x,y) = ax2+bxy+cy2 be a primitive binary quadratic form of discriminant D = b2−4ac < 0. The set of integers represented by Q up to X has cardinality ∼ cQ X / √|D|, where cQ is a constant depending on the class group. Sifting the polynomial sequence f(Q(x,y)) for prime values is a two-dimensional sieve problem. The sequence 𝒜 = {f(Q(x,y)) : |x|,|yX} has density about X / √|D|. The sieve dimension is the number of irreducible factors of f ∘ Q over ℚ. For f(t) = t, the problem reduces to primes represented by the quadratic form, which is a classical topic: the work of Iwaniec (1974) on the half-dimensional sieve gives an asymptotic for almost primes represented by Q. For general f, one uses the Selberg upper bound sieve with weights adapted to the quadratic form. The level of distribution for the sequence f(Q(x,y)) in arithmetic progressions is governed by the Barban–Davenport–Halberstam theorem for quadratic forms, which gives a level of distribution 1/2 on average over moduli. The large sieve inequality for quadratic forms, due to Duke, Friedlander, and Iwaniec, states ∑q≤Q ∑a mod q |∑x,y ax,y e(aQ(x,y)/q)|2 ≤ (X+Q2) ∑ |ax,y|2. The constant Cf,Q involves the singular series for f and the representation density of Q modulo primes. The parity problem again blocks a lower bound. For f(t) = t, the linear sieve gives the correct order of magnitude for almost primes with at most two prime factors, matching the conjectured asymptotic for primes up to the constant factor. The work of Browning and Heath‑Brown (2021) on norm forms of higher degree extends these methods to forms in more variables, but the binary quadratic case remains the most complete. The Rosser–Iwaniec sieve provides explicit upper bound functions for the linear sieve dimension κ = 1, with sifting limit β = 2. For higher dimension, the Diamond–Halberstam–Richert beta sieve gives optimized upper bounds. Under the Generalised Riemann Hypothesis for the L‑functions attached to the quadratic form, one can obtain an asymptotic formula with the same main term.

The Sieve for Primes in the Values of a Polynomial at Arguments with a Prescribed Divisor Function Value

Let d(n) denote the number of positive divisors of n. For k = 4 (product of two distinct primes) the level of distribution improves because the condition d(n) = 4 removes the contribution of higher prime powers, allowing a larger sifting range. The Rosser–Iwaniec sieve gives explicit upper bound functions for the linear sieve dimension κ = 1. For higher dimension, the Diamond–Halberstam–Richert beta sieve is used. The large sieve for multiplicative functions, developed by Barban and Davenport–Halberstam, gives a level of distribution 1/2 on average for the sequence f(n) restricted to d(n) = k. Recent work of Granville and Soundararajan on the distribution of values of multiplicative functions has refined these estimates. The Sieve for Primes in the Values of a Polynomial at Arguments with a Prescribed Value of the Euler Totient Function φ(n)

The Euler totient function φ(n) counts integers up to n coprime to n. For a fixed integer m, the equation φ(n) = m has been studied extensively; it is known that for each m the set of solutions is finite, and the number of solutions is bounded by a constant depending on m. When sifting a polynomial sequence f(n) over arguments n ≤ x with φ(n) = m, the sequence 𝒜 = {f(n) : n ≤ x, φ(n) = m} is extremely thin. Its density can be estimated using the structure of the preimage of m under φ. Since φ is multiplicative, the condition φ(n) = m factors into conditions on the prime power decomposition of n. For each prime power p^a, φ(p^a) = pa-1(p-1). The equation φ(n) = m thus translates into a combinatorial problem of partitioning the prime factors of m into blocks of the form p-1 and pa-1. The number of n ≤ x with φ(n) = m is typically O(x^ε) for any ε > 0, and often much smaller. The sieve dimension for the polynomial values remains κ, the number of irreducible factors of f over ℚ. The level of distribution for this sequence is not known unconditionally; however, one can apply the large sieve for multiplicative functions to obtain a level of distribution 1/2 on average over moduli. The Selberg upper bound sieve then yields an upper bound of the shape (2^κ + o(1)) C_f S(x, m) / log x, where S(x, m) is the number of n ≤ x with φ(n) = m and C_f is the singular series. The parity problem blocks a lower bound of the same quality. For m = φ(p) = p-1 with p prime, the condition φ(n) = p-1 includes n = p and possibly other solutions. This connects to the sieve for primes in shifted primes, a problem related to the twin prime conjecture. The work of Pomerance on the distribution of values of φ(n) gives precise asymptotics for the counting function of the image of φ. The singular series for the polynomial values is unchanged. The Sieve for Primes in the Values of a Polynomial at Arguments with a Prescribed Value of the Sum of Divisors Function σ(n)

The sum of divisors function σ(n) = ∑d|n d is multiplicative with σ(p^a) = (pa+1-1)/(p-1). For a fixed integer m, the equation σ(n) = m has finitely many solutions, and the number of solutions is bounded by a constant depending on m. Sifting the polynomial sequence f(n) over arguments n ≤ x with σ(n) = m produces a sequence 𝒜 = {f(n) : n ≤ x, σ(n) = m} of similar thinness to the φ(n) = m case. For each prime power p^a, the value σ(p^a) is a cyclotomic polynomial evaluated at p. The equation σ(n) = m thus becomes a problem of representing m as a product of cyclotomic values. The number of n ≤ x with σ(n) = m is typically O(x^ε). The sieve dimension for the polynomial values is κ. The level of distribution is again not known unconditionally, but the large sieve for multiplicative functions gives a level of distribution 1/2 on average. For m = σ(p) = p+1 with p prime, the condition σ(n) = p+1 includes n = p and possibly other solutions. This relates to the sieve for primes in shifted primes p+1, connected to the problem of primes p such that p+1 has a prescribed divisor structure. Worked Example: Upper Bound for Prime Values of f(n) = n2 + 1 with σ(n) = 12
Let f(n) = n2 + 1. Find all n ≤ 100 with σ(n) = 12, then use the Selberg upper bound sieve to estimate the number of such n for which f(n) is prime.
First, solve σ(n) = 12. Since σ is multiplicative, check prime powers: σ(2) = 3, σ(3) = 4, σ(4) = 7, σ(5) = 6, σ(6) = 12, σ(7) = 8, σ(8) = 15, σ(9) = 13, σ(10) = 18, σ(11) = 12. So n = 6 and n = 11 are solutions. Also σ(22) = 7, σ(23) = 15, σ(32) = 13. No other prime powers give 12. Check products: σ(2)σ(3) = 3×4 = 12, so n = 6 (already found). σ(2)σ(5) = 3×6 = 18. σ(3)σ(5) = 4×6 = 24. So the only solutions are n = 6 and n = 11. For n ≤ 100, S(100, 12) = 2. The polynomial f(n) = n2 + 1 is irreducible, so κ = 1. The singular series C_f = ∏_p (1 - ω(p)/p) / (1 - 1/p) where ω(p) is the number of roots of n2 + 1 ≡ 0 (mod p). For p = 2, ω(2) = 1; for p ≡ 1 (mod 4), ω(p) = 2; for p ≡ 3 (mod 4), ω(p) = 0. The Selberg upper bound sieve gives an upper bound (2^κ + o(1)) C_f S(x, m) / log x = (2 + o(1)) C_f × 2 / log 100. Numerically, C_f ≈ 1.3728. log 100 ≈ 4.605. Upper bound ≈ 2 × 1.3728 × 2 / 4.605 ≈ 1.19. The actual prime values: f(6) = 37 (prime), f(11) = 122 = 2 × 61 (composite). So exactly 1 prime value. The upper bound 1.19 is consistent.
Exam Strategy: Recognizing Multiplicative Function Conditions
When a problem asks for sieving polynomial values at arguments with a prescribed value of a multiplicative function (φ, σ, d, λ, μ), first factor the condition using multiplicativity. The set of solutions is typically finite for each fixed value, making the sifted set very thin. The sieve dimension κ is determined by the polynomial f, not by the multiplicative function condition. The level of distribution is at most 1/2 unconditionally (Bombieri–Vinogradov for the polynomial sequence). The Selberg upper bound gives (2^κ + o(1)) C_f S(x, m) / log x. The parity problem always blocks a lower bound of the same order. Remember: the singular series C_f depends only on f, not on the multiplicative function condition.

The Sieve for Primes in the Values of a Polynomial at Arguments with a Prescribed Value of the Liouville Function λ(n)

The Liouville function λ(n) = (-1)Ω(n) is completely multiplicative, where Ω(n) is the total number of prime factors counted with multiplicity. For a fixed value ε ∈ {+1, -1}, the condition λ(n) = ε means Ω(n) is even (ε = +1) or odd (ε = -1). The set of n ≤ x with λ(n) = +1 has density 1/2, and similarly for λ(n) = -1, assuming the Prime Number Theorem in the form ∑n≤x λ(n) = o(x), which is equivalent to the Prime Number Theorem. Sifting the polynomial sequence f(n) over arguments n ≤ x with λ(n) = ε produces a sequence 𝒜 = {f(n) : n ≤ x, λ(n) = ε} of positive density 1/2. The sieve dimension for the polynomial values is κ. The level of distribution for this sequence can be taken as 1/2 unconditionally by the Bombieri–Vinogradov theorem applied to the sequence f(n) restricted to λ(n) = ε, since the condition λ(n) = ε is a multiplicative condition that does not destroy the equidistribution in arithmetic progressions on average. The Selberg upper bound sieve then gives an upper bound of the shape (2^κ + o(1)) C_f (x/2) / log x. The parity problem is particularly sharp here: the condition λ(n) = ε directly encodes the parity of Ω(n), which is exactly the obstruction the parity problem describes. One cannot distinguish between integers with an even or odd number of prime factors in the sifted set without additional hypotheses. The work of Hildebrand on the distribution of λ(n) in arithmetic progressions gives the necessary equidistribution. The singular series C_f is unchanged. The main term matches the conjectured order of magnitude. The Sieve for Primes in the Values of a Polynomial at Arguments with a Prescribed Value of the Möbius Function μ(n)

The Möbius function μ(n) is defined as μ(n) = (-1)ω(n) if n is squarefree, and μ(n) = 0 otherwise, where ω(n) is the number of distinct prime factors.
