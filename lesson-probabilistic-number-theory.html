Probabilistic Number Theory — the Erdős-Kac Theorem, Normal Order & the Turán-Kubilius Inequality

Probabilistic number theory applies probability theory to study the distribution of arithmetic functions. The central motif: many arithmetic objects (prime factors of integers, cycle lengths of permutations, factorization of polynomials over finite fields) behave like random variables. The Erdős–Kac theorem (1940) is the crown jewel: the number of distinct prime factors ω(n) of a random integer n ≤ x is asymptotically normal with mean log log x and variance log log x — a profound connection between number theory and probability. The Turán–Kubilius inequality provides a quantitative bound for additive functions, analogous to Chebyshev's inequality in probability. The Kubilius model approximates the prime factor structure by assigning independent Bernoulli random variables to each prime. Delange's theorem, Halász's theorem, and Wirsing–Elliott theory classify mean values of multiplicative functions. These ideas extend to random permutations (Goncharov's log log n law), random polynomials over 𝔽_q, and the Selberg central limit theorem for the Riemann zeta function.

"Number theory is not random — but it behaves as if it were."
— Marc Kac
Part 1

📏 Arithmetic Functions and Their Mean Values

Normal Order
Additive Functions, Multiplicative Functions, and the Turán–Kubilius Inequality
An arithmetic function f is additive if f(mn) = f(m) + f(n) for coprime m,n; it is completely additive if this holds for all m,n. For an additive function, f(p^a) = f(p) + ... + f(p) (a times). A function f is multiplicative if f(mn) = f(m)f(n) for coprime m,n, and completely multiplicative if it holds for all m,n. For a multiplicative function, f(p^a) = f(p)^a. The normal order of an arithmetic function f(n) is a function g(n) such that for every ε > 0, the inequality |f(n) − g(n)| < ε·g(n) holds for almost all n — i.e., the set of n ≤ x where it fails has density 0. Example: the function ω(n) (number of distinct prime factors of n) has normal order log log n. The Turán–Kubilius inequality is the fundamental inequality for additive functions. Let f be an additive function. Define the mean value M(x) = Σ_{p^a ≤ x} f(p^a)/p^a and the variance V(x) = Σ_{p^a ≤ x} |f(p^a)|²/p^a. Then for any x ≥ 2, (1/x) Σ_{n≤x} |f(n) − M(x)|² ≤ C·V(x) where C is an absolute constant. In particular, for ω(n), M(x) = Σ_{p ≤ x} 1/p = log log x + O(1), V(x) = Σ_{p ≤ x} 1/p = log log x + O(1), so the mean square deviation of ω(n) from log log n is O(log log n). This inequality is the engine behind the normal order and the Erdős–Kac theorem.
The Turán–Kubilius inequality shows that additive functions are concentrated near their mean values, paving the way for distributional limit theorems in number theory.
Part 2

🌍 The Erdős–Kac Theorem

Central Limit
The Erdős–Kac Theorem, the Kubilius Model, and Berry–Esseen Bounds
The Erdős–Kac theorem (Erdős and Kac, 1940): For a random integer n uniformly chosen from {1, …, x}, the normalized number of distinct prime factors (ω(n) − log log n)/√(log log n) converges in distribution to the standard normal distribution N(0,1). Explicitly, the density of n ≤ x for which a < (ω(n) − log log n)/√(log log n) < b tends to Φ(b) − Φ(a) = (1/√(2π))∫_a^b e^{-t²/2} dt as x → ∞. The proof uses the Kubilius model: for each n ≤ x, approximate ω_x(n) (the number of prime factors of n with p ≤ x) by a sum of independent Bernoulli random variables X_p for each prime p ≤ x, where P(X_p = 1) = 1/p and P(X_p = 0) = 1 − 1/p. The sum S_x = Σ_{p ≤ x} X_p has mean Σ_{p ≤ x} 1/p = log log x + O(1) and variance Σ_{p ≤ x} (1/p)(1 − 1/p) = log log x + O(1). The Berry–Esseen theorem gives the rate of convergence: sup_t |P((S_x − μ_x)/σ_x < t) − Φ(t)| = O(1/√(log log x)). By the Kubilius model, the total variation distance between the distribution of ω(n) and S_x tends to 0 as x → ∞. Extensions: The function Ω(n) (total number of prime factors counted with multiplicity) also satisfies the Erdős–Kac theorem with the same normalization. More generally, any additive function f satisfying appropriate moment conditions (the Erdős–Kac criterion) will converge to a normal distribution. The theorem has been extended to polynomial values, algebraic number fields, and function fields.
The Erdős–Kac theorem reveals that the prime factor count distribution is universal — it follows the bell curve, just like sums of independent random variables.
Part 3

🧮 Mean Values of Multiplicative Functions

Delange–Halász
Delange's Theorem, Halász's Theorem, and the Wirsing–Elliott Theory
Delange's theorem (1961): Let f be a multiplicative function with |f| ≤ 1. The mean value M(f) = lim_{x→∞} (1/x) Σ_{n≤x} f(n) exists if and only if the series Σ_p (1 − f(p))/p converges. When the mean value exists, it is given by the Euler product M(f) = Π_p (1 − 1/p) Σ_{k≥0} f(p^k)/p^k. This is a deep generalization of the prime number theorem: for the completely multiplicative function f(n) = μ(n) (the Möbius function), Delange's condition holds trivially since Σ_p (1 + 1)/p diverges, consistent with the fact that (1/x) Σ_{n≤x} μ(n) → 0. Halász's theorem (1968): For a multiplicative function f with |f| ≤ 1, the mean value is small unless f(n) behaves like n^{it} for some real t (possibly twisted by a Dirichlet character). The Halász inequality quantifies this: |(1/x) Σ_{n≤x} f(n)| ≤ C·exp(−M(T, x) + o(1)) where M(T, x) = min_{|t| ≤ T} Σ_{p ≤ x} (1 − Re f(p)p^{−it})/p. If the minimum is large, the mean value decays. A corollary: if f is multiplicative with |f| ≤ 1 and there is no t such that f(p) ≈ p^{it} for many primes, then the mean value tends to 0. The Wirsing–Elliott theorem gives a classification: a multiplicative function f with |f| ≤ 1 has a nonzero mean value if and only if f(p) = p^{it} for some t in a precise sense, and the limit is given by an Euler product involving the exceptional character.
Mean values of multiplicative functions are controlled by Dirichlet characters and the behavior of f on primes; the Halász inequality is the precise tool for bounding these averages.
Part 4

🔥 Large Deviations and Applications

Applications
Large Deviations, Random Permutations, Random Matrices, and the Selberg CLT
The theory of large deviations for additive functions studies the probability that ω(n) deviates significantly from its mean log log n. A Cramér-type theorem holds: for δ > 0, the proportion of n ≤ x with ω(n) > (1 + δ) log log n is bounded above by (log x)^{−c(δ)} for some c(δ) > 0, decaying like a power of log x. The Erdős–Kac theorem for polynomial values: if P ∈ ℤ[t] is an irreducible polynomial, then ω(P(n)) has normal order log log n and satisfies the Erdős–Kac theorem (the distribution of (ω(P(n)) − log log n)/√(log log n) is normal). The Kubilius model in function fields: for polynomials over the finite field 𝔽_q, the Turán–Kubilius inequality and the Erdős–Kac theorem have natural analogs — the factorization pattern of a random monic polynomial of degree n over 𝔽_q behaves like the prime factor structure of a random integer. Random permutations: the cycle structure of a random permutation of S_n is remarkably analogous. The number of cycles C_n of a random permutation has mean H_n ≈ log n and variance ≈ log n, and (C_n − log n)/√(log n) converges to N(0,1) (Goncharov's theorem). This parallels ω(n) with log n replacing log log n. The limiting distribution of the logarithm of the discriminant of a random number field: the discriminant of a random integral polynomial of degree n has a distribution related to the extreme value law. The Manstavičius semicircle law: certain additive functions with restricted support converge to the Wigner semicircle law rather than the normal distribution, under appropriate conditions on the prime support. Selberg's central limit theorem (1946): for large T, the values of log ζ(½ + it) for t ∈ [0, T] behave like a complex normal random variable: the moments of Re log ζ(½ + it) converge to those of a Gaussian, and (log ζ(½ + it))/(½√(log log T)) converges in distribution to a complex normal. The proof uses the approximation of log ζ(s) near Re(s) = 1 by a Dirichlet polynomial and the Erdős–Kac type arguments (the moments method).
The probabilistic viewpoint unifies number theory with combinatorics (random permutations), algebraic geometry (random polynomials over 𝔽_q), and analytic number theory (moments of ζ(s)).
