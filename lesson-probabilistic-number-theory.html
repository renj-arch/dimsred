Probabilistic Number Theory — the Erdős-Kac Theorem, Normal Order & the Turán-Kubilius Inequality

Probabilistic number theory applies probability theory to study the distribution of arithmetic functions. The central motif: many arithmetic objects (prime factors of integers, cycle lengths of permutations, factorization of polynomials over finite fields) behave like random variables. The Erdős–Kac theorem (1940) is the crown jewel: the number of distinct prime factors ω(n) of a random integer n ≤ x is asymptotically normal with mean log log x and variance log log x — a profound connection between number theory and probability. The Turán–Kubilius inequality provides a quantitative bound for additive functions, analogous to Chebyshev's inequality in probability. The Kubilius model approximates the prime factor structure by assigning independent Bernoulli random variables to each prime. Delange's theorem, Halász's theorem, and Wirsing–Elliott theory classify mean values of multiplicative functions. These ideas extend to random permutations (Goncharov's log log n law), random polynomials over 𝔽_q, and the Selberg central limit theorem for the Riemann zeta function.

Part 1

📏 Arithmetic Functions and Their Mean Values

Normal Order
Additive Functions, Multiplicative Functions, and the Turán–Kubilius Inequality
An arithmetic function f is additive if f(mn) = f(m) + f(n) for coprime m,n; it is completely additive if this holds for all m,n. For an additive function, f(p^a) = f(p) + ... + f(p) (a times). A function f is multiplicative if f(mn) = f(m)f(n) for coprime m,n, and completely multiplicative if it holds for all m,n. For a multiplicative function, f(p^a) = f(p)^a. The normal order of an arithmetic function f(n) is a function g(n) such that for every ε > 0, the inequality |f(n) − g(n)| < ε·g(n) holds for almost all n — i.e., the set of n ≤ x where it fails has density 0. Example: the function ω(n) (number of distinct prime factors of n) has normal order log log n. The Turán–Kubilius inequality is the fundamental inequality for additive functions. Let f be an additive function. Define the mean value M(x) = Σ_{p^a ≤ x} f(p^a)/p^a and the variance V(x) = Σ_{p^a ≤ x} |f(p^a)|²/p^a. Then for any x ≥ 2, (1/x) Σ_{n≤x} |f(n) − M(x)|² ≤ C·V(x) where C is an absolute constant. In particular, for ω(n), M(x) = Σ_{p ≤ x} 1/p = log log x + O(1), V(x) = Σ_{p ≤ x} 1/p = log log x + O(1), so the mean square deviation of ω(n) from log log n is O(log log n). This inequality is the engine behind the normal order and the Erdős–Kac theorem.
The Turán–Kubilius inequality shows that additive functions are concentrated near their mean values, paving the way for distributional limit theorems in number theory.

🌍 The Erdős–Kac Theorem

Central Limit
The Erdős–Kac Theorem, the Kubilius Model, and Berry–Esseen Bounds
The Erdős–Kac theorem (Erdős and Kac, 1940): For a random integer n uniformly chosen from {1, …, x}, the normalized number of distinct prime factors (ω(n) − log log n)/√(log log n) converges in distribution to the standard normal distribution N(0,1). Explicitly, the density of n ≤ x for which a < (ω(n) − log log n)/√(log log n) < b tends to Φ(b) − Φ(a) = (1/√(2π))∫_a^b e^{-t²/2} dt as x → ∞. The proof uses the Kubilius model: for each n ≤ x, approximate ω_x(n) (the number of prime factors of n with p ≤ x) by a sum of independent Bernoulli random variables X_p for each prime p ≤ x, where P(X_p = 1) = 1/p and P(X_p = 0) = 1 − 1/p. The sum S_x = Σ_{p ≤ x} X_p has mean Σ_{p ≤ x} 1/p = log log x + O(1) and variance Σ_{p ≤ x} (1/p)(1 − 1/p) = log log x + O(1). The Berry–Esseen theorem gives the rate of convergence: sup_t |P((S_x − μ_x)/σ_x < t) − Φ(t)| = O(1/√(log log x)). By the Kubilius model, the total variation distance between the distribution of ω(n) and S_x tends to 0 as x → ∞. Extensions: The function Ω(n) (total number of prime factors counted with multiplicity) also satisfies the Erdős–Kac theorem with the same normalization. More generally, any additive function f satisfying appropriate moment conditions (the Erdős–Kac criterion) will converge to a normal distribution. The theorem has been extended to polynomial values, algebraic number fields, and function fields.
The Erdős–Kac theorem reveals that the prime factor count distribution is universal — it follows the bell curve, just like sums of independent random variables.

🧮 Mean Values of Multiplicative Functions

Delange–Halász
Delange's Theorem, Halász's Theorem, and the Wirsing–Elliott Theory
Delange's theorem (1961): Let f be a multiplicative function with |f| ≤ 1. The mean value M(f) = lim_{x→∞} (1/x) Σ_{n≤x} f(n) exists if and only if the series Σ_p (1 − f(p))/p converges. When the mean value exists, it is given by the Euler product M(f) = Π_p (1 − 1/p) Σ_{k≥0} f(p^k)/p^k. This is a deep generalization of the prime number theorem: for the completely multiplicative function f(n) = μ(n) (the Möbius function), Delange's condition holds trivially since Σ_p (1 + 1)/p diverges, consistent with the fact that (1/x) Σ_{n≤x} μ(n) → 0. Halász's theorem (1968): For a multiplicative function f with |f| ≤ 1, the mean value is small unless f(n) behaves like n^{it} for some real t (possibly twisted by a Dirichlet character). The Halász inequality quantifies this: |(1/x) Σ_{n≤x} f(n)| ≤ C·exp(−M(T, x) + o(1)) where M(T, x) = min_{|t| ≤ T} Σ_{p ≤ x} (1 − Re f(p)p^{−it})/p. If the minimum is large, the mean value decays. A corollary: if f is multiplicative with |f| ≤ 1 and there is no t such that f(p) ≈ p^{it} for many primes, then the mean value tends to 0. The Wirsing–Elliott theorem gives a classification: a multiplicative function f with |f| ≤ 1 has a nonzero mean value if and only if f(p) = p^{it} for some t in a precise sense, and the limit is given by an Euler product involving the exceptional character.
Mean values of multiplicative functions are controlled by Dirichlet characters and the behavior of f on primes; the Halász inequality is the precise tool for bounding these averages.

🔥 Large Deviations and Applications

Applications
Large Deviations, Random Permutations, Random Matrices, and the Selberg CLT
The theory of large deviations for additive functions studies the probability that ω(n) deviates significantly from its mean log log n. A Cramér-type theorem holds: for δ > 0, the proportion of n ≤ x with ω(n) > (1 + δ) log log n is bounded above by (log x)^{−c(δ)} for some c(δ) > 0, decaying like a power of log x. The Erdős–Kac theorem for polynomial values: if P ∈ ℤ[t] is an irreducible polynomial, then ω(P(n)) has normal order log log n and satisfies the Erdős–Kac theorem (the distribution of (ω(P(n)) − log log n)/√(log log n) is normal). The Kubilius model in function fields: for polynomials over the finite field 𝔽_q, the Turán–Kubilius inequality and the Erdős–Kac theorem have natural analogs — the factorization pattern of a random monic polynomial of degree n over 𝔽_q behaves like the prime factor structure of a random integer. Random permutations: the cycle structure of a random permutation of S_n is remarkably analogous. The number of cycles C_n of a random permutation has mean H_n ≈ log n and variance ≈ log n, and (C_n − log n)/√(log n) converges to N(0,1) (Goncharov's theorem). This parallels ω(n) with log n replacing log log n. The limiting distribution of the logarithm of the discriminant of a random number field: the discriminant of a random integral polynomial of degree n has a distribution related to the extreme value law. The Manstavičius semicircle law: certain additive functions with restricted support converge to the Wigner semicircle law rather than the normal distribution, under appropriate conditions on the prime support. Selberg's central limit theorem (1946): for large T, the values of log ζ(½ + it) for t ∈ [0, T] behave like a complex normal random variable: the moments of Re log ζ(½ + it) converge to those of a Gaussian, and (log ζ(½ + it))/(½√(log log T)) converges in distribution to a complex normal. The proof uses the approximation of log ζ(s) near Re(s) = 1 by a Dirichlet polynomial and the Erdős–Kac type arguments (the moments method).
The probabilistic viewpoint unifies number theory with combinatorics (random permutations), algebraic geometry (random polynomials over 𝔽_q), and analytic number theory (moments of ζ(s)).

The Kubilius Probabilistic Model and Its Refinements

The Kubilius model, introduced by Jonas Kubilius in the 1950s, provides a probabilistic framework that approximates the values of an additive arithmetic function f(n) by a sum of independent random variables indexed by primes. For each prime p ≤ x, the exponent of p in a uniformly chosen integer n ≤ x behaves approximately like a geometric random variable with success probability 1/p. Consequently, the contribution f(p^k) from the prime power p^k can be modeled by a random variable X_p taking the value f(p^k) with probability (1 − 1/p)/p^k. The sum S_x = Σp≤x X_p then has mean A(x) = Σp≤x f(p)/p and variance B(x) = Σp≤x |f(p)|2/p (for real‑valued f). The fundamental Turán–Kubilius inequality states that Σn≤x |f(n) − A(x)|2 ≤ C x B(x) for an absolute constant C, which immediately yields normal order results when B(x) = o(A(x)2).

Refinements of the model have been developed by Elliott, Hildebrand, and Tenenbaum. Elliott’s work on multiplicative functions replaces the independent geometric variables by a more delicate construction that captures the correlation between different prime powers, leading to precise mean‑value theorems such as Delange’s and Halász’s theorems. In the function‑field setting, the Kubilius model becomes exact: for a random monic polynomial of degree n over 𝔽_q, the factorization pattern is precisely described by independent Poisson–Dirichlet variables, and the Turán–Kubilius inequality holds with equality up to a negligible error. This exactness underlies the proof of the Erdős–Kac theorem for polynomials over finite fields and for the cycle structure of random permutations, where the number of cycles C_n satisfies (C_n − log n)/√(log n) → N(0,1). The model also provides a heuristic for the distribution of values of the Riemann zeta function on the critical line, where the Dirichlet polynomial approximation of log ζ(½ + it) plays the role of the sum over primes.

Method of Moments and Characteristic Functions in the Erdős–Kac Proof

The original 1940 proof of the Erdős–Kac theorem by Paul Erdős and Mark Kac employed the method of moments. They showed that for each fixed integer k ≥ 1, the k‑th moment of the normalized variable (ω(n) − log log n)/√(log log n) converges to the k‑th moment of the standard normal distribution. The computation relies on expanding the power (Σp≤x (1p|n − 1/p))^k and using the fact that the events p|n are asymptotically independent for distinct primes. The moment method requires uniform bounds on the moments of the summands, which are provided by the Turán–Kubilius inequality. A more flexible approach uses characteristic functions and Lévy’s continuity theorem. The characteristic function of ω(n) is φ_x(t) = (1/x) Σn≤x eit ω(n) = Πp≤x (1 − 1/p) Σk≥0 eitk/p^k. Taking logarithms and expanding gives log φ_x(t) = Σp≤x (eit − 1)/p + o(1). After centering by log log x and scaling by √(log log x), the limit characteristic function is exp(−t2/2), which is the characteristic function of N(0,1). This characteristic‑function proof extends naturally to any additive function satisfying the Lindeberg condition (the Erdős–Kac criterion), and it avoids the moment‑boundedness requirement. Modern expositions, such as those by Billingsley and by Elliott, combine the Kubilius model with the characteristic‑function method to obtain a unified proof that also yields Berry–Esseen type error bounds.

Moment Method vs Characteristic Function
Explain why the method of moments requires uniform boundedness of moments, while the characteristic function approach only needs pointwise convergence of characteristic functions.
The method of moments proves convergence in distribution by showing that every moment of the sequence converges to the corresponding moment of the limit distribution. This is valid only if the limit distribution is uniquely determined by its moments (Carleman’s condition) and if the sequence of moments is uniformly bounded, which guarantees tightness and prevents mass from escaping to infinity. In contrast, Lévy’s continuity theorem states that pointwise convergence of characteristic functions to a function continuous at 0 is equivalent to convergence in distribution. No moment assumptions are needed; the characteristic function automatically encodes tightness through its behavior near 0. Therefore, the characteristic‑function method is more general and applies to additive functions that may not have uniformly bounded moments.
Exam‑Day Strategy
When a question asks to compare proof techniques for the Erdős–Kac theorem, highlight the role of the Lindeberg condition: the moment method needs it to control higher moments, while the characteristic‑function method uses it to justify the Taylor expansion of the log characteristic function. Mention that the Kubilius model provides the independent‑sum representation that makes both approaches work.

Normal Order, Almost Sure Convergence, and the Hardy–Ramanujan Theorem

In 1917 Hardy and Ramanujan proved that the prime factor counting function ω(n) has normal order log log n: for every ε > 0, the proportion of integers n ≤ x with |ω(n) − log log n| > ε log log n tends to 0 as x → ∞. This is a weak law of large numbers for the sequence ω(n). Turán’s 1934 proof, using the inequality Σn≤x (ω(n) − log log x)2 = O(x log log x), gave a much simpler argument and introduced the Turán–Kubilius method. The concept of normal order is exactly convergence in probability with respect to the natural density. However, almost sure convergence (i.e., convergence for a set of integers of density 1) fails for ω(n) because the variance log log n is not o((log log n)2). By the Borel–Cantelli lemma, if Σn P(|ω(n) − log log n| > ε log log n) converged, we would have almost sure convergence; but the Turán–Kubilius bound only gives a decay like 1/(ε2 log log n), whose sum diverges. In contrast, the divisor function d(n) satisfies log d(n) ∼ log 2 log log n in normal order, and the same variance obstruction prevents almost sure convergence. The distinction between normal order and almost sure convergence is crucial when applying probabilistic heuristics to number‑theoretic statements: a statement true for “almost all” integers in the sense of density 1 may still fail on a sparse set of positive logarithmic density.

Large Deviations for Additive Functions: Cramér‑Type Estimates and Applications

The theory of large deviations for additive functions studies the exponential decay of probabilities that ω(n) deviates significantly from its mean log log n. For δ > 0, the proportion of n ≤ x with ω(n) > (1 + δ) log log n is bounded above by (log x)−c(δ) for some c(δ) > 0. This is a power‑of‑log decay, not an exponential decay in x, because the natural scaling for additive functions is log log x. The rate function I(z) is the Legendre transform of the limiting log moment generating function Λ(t) = limx→∞ (1/log log x) log (1/x) Σn≤x et ω(n). For ω(n), Λ(t) = e^t − 1, giving I(z) = z log z − z + 1. The large‑deviation principle holds with speed log log x: for any interval A, limx→∞ (1/log log x) log P(ω(n)/log log n ∈ A) = −infz∈A I(z). This principle extends to general additive functions f with bounded increments, provided the sum Σp≤x f(p)/p grows like log log x. Applications include the distribution of prime factors in short intervals (Hildebrand, 1986), the Erdős–Kac theorem for polynomial values P(n) (where ω(P(n)) has normal order log log n and satisfies the same large‑deviation bounds), and the study of the number of prime factors of shifted primes p−1 (Erdős–Pomerance). The Selberg–Delange method provides precise asymptotics for the moments Σn≤x zω(n) and underlies many large‑deviation results.

Connections to Random Matrix Theory and the Selberg Central Limit Theorem

Selberg’s 1946 central limit theorem for the Riemann zeta function states that for large T, the values of log ζ(½ + it) with t uniformly distributed in [0, T] behave like a complex Gaussian random variable with variance ½ log log T. The proof approximates log ζ(s) near the critical line by a Dirichlet polynomial Σp≤T p−s and then applies an Erdős–Kac type moment argument to the sum over primes. This result is a number‑theoretic analogue of the central limit theorem for linear statistics of eigenvalues of random unitary matrices. Keating and Snaith (2000) showed that the moments of ζ(½ + it) match the moments of characteristic polynomials of random unitary matrices, providing a precise conjecture for the lower‑order terms in the moment asymptotics. The probabilistic toolkit of Turán–Kubilius and the Kubilius model is used to control the error when replacing log ζ(s) by its Dirichlet polynomial approximation. Recent work by Bourgade, Radziwiłł, and Soundararajan has extended the Selberg CLT to Dirichlet L‑functions and to the joint distribution of log ζ(½ + it) and its derivative. These connections illustrate how probabilistic number theory, random matrix theory, and the theory of L‑functions form a unified framework: additive functions on integers correspond to linear statistics on eigenvalues, the Turán–Kubilius inequality corresponds to variance estimates for those statistics, and the Erdős–Kac theorem corresponds to the Gaussian limit of those statistics.

The Distribution of Values of Multiplicative Functions

While the Erdős–Kac theorem primarily addresses additive functions, a significant extension of probabilistic number theory concerns the distribution of values of multiplicative functions. A multiplicative function f(n) is one for which f(mn) = f(m)f(n) whenever gcd(m,n) = 1. Examples include Euler's totient function φ(n), the divisor function d(n), and the sum-of-divisors function σ(n). Unlike additive functions where the sum of values at prime powers determines the function, multiplicative functions combine values by multiplication.

The study of the distribution of multiplicative functions often begins by transforming them into additive functions. If f(n) is a positive multiplicative function, then log f(n) is an additive function. For instance, log d(n) = log (Π pa || n (a+1)) = Σ pa || n log(a+1). The Erdős–Kac theorem can then be applied to log f(n) under suitable conditions. However, this only describes the distribution of the logarithm, not the function itself.

A more direct approach involves studying the existence of a limiting distribution function F(z) = limx→∞ (1/x) #{n ≤ x : f(n) ≤ z}. Such a limit does not always exist. For a limiting distribution to exist for a real-valued multiplicative function f(n), a crucial set of conditions, established by Delange and later refined by Elliott, typically involves the convergence of certain series over primes. Specifically, for a non-negative multiplicative function f(n) to have a limiting distribution, it is often required that the series Σp (f(p) - 1)/p and Σp (f(p) - 1)²/p converge, along with a condition on f(pk) for k ≥ 2. If these conditions are met, the limiting distribution can be characterized by its characteristic function (Fourier transform), which is given by an infinite product over primes: E[eit f(n)] = Πp (1 - 1/p) Σk=0∞ eit f(pk) / pk.

For functions like φ(n)/n or σ(n)/n, which are bounded between 0 and 1 or 1 and infinity respectively, limiting distributions exist and are often continuous or a mix of discrete and continuous. For example, the values of φ(n)/n are dense in (0, 1), and its distribution function is continuous but singular (i.e., its derivative is zero almost everywhere). The distribution of d(n) is more complex; it does not have a simple limiting distribution in the classical sense due to its highly fluctuating nature, but log d(n) does have a normal order log 2 log log n and satisfies an Erdős-Kac type theorem. The theory also extends to complex-valued multiplicative functions, where the limiting distribution is a probability measure on the complex plane.

The Kubilius probabilistic model, originally for additive functions, can be adapted for multiplicative functions by considering their logarithmic values or by constructing a suitable product space. This involves treating the values f(pk) as independent random variables, properly scaled by their frequencies of occurrence. The existence and properties of these limiting distributions are fundamental for understanding the global behavior of these important arithmetic functions.

Quantitative Refinements of the Turán-Kubilius Inequality

The Turán–Kubilius inequality provides a fundamental upper bound for the variance of an additive function, stating that for an additive function f(n), Σn≤x |f(n) - A(x)|² ≤ C x B(x), where A(x) = Σp≤x f(p)/p and B(x) = Σp≤x f(p)²/p. While this asymptotic bound is powerful, advanced applications often require more precise, quantitative versions, including explicit constants and extensions to specific subsets of integers.

One significant refinement involves determining the optimal constant C. For a strongly additive function (f(pk) = f(p)), the constant C can be shown to be 1, meaning the inequality holds with C=1 for sufficiently large x. More generally, for any additive function, the constant is related to the sum of f(pk) - f(p) terms. Explicit constants are crucial for numerical estimates and for establishing effective bounds in various number-theoretic problems.

A major generalization is the **Barban–Diananda–Elliott (BDE) theorem**, which extends the Turán–Kubilius inequality to arithmetic progressions. This theorem states that for an additive function f(n) and for integers a, q with gcd(a,q)=1, a similar variance bound holds for n ≤ x such that n ≡ a (mod q). Specifically, for a wide range of moduli q (typically q ≤ xθ for some θ < 1), the sum Σn≤x, n≡a(mod q) |f(n) - A(x)|² is bounded by C (x/q) B(x). This extension is vital because many problems in number theory, such as the distribution of primes, involve arithmetic progressions. The BDE theorem is a key ingredient in proving results like the Bombieri–Vinogradov theorem, which averages the error terms in the prime number theorem for arithmetic progressions over many moduli.

Further refinements include concentration inequalities, which provide stronger bounds on the probability that an additive function deviates significantly from its mean. Instead of just a second moment (variance) bound, these inequalities give bounds on higher moments or directly on the tail probabilities P(|f(n) - A(x)| > λ). These are often derived using characteristic functions and Fourier analysis techniques, similar to those used in classical probability theory for sums of independent random variables. Such inequalities are particularly useful when the distribution is not necessarily Gaussian, or when one needs to control the behavior of f(n) on sparse sets.

The methods for proving these quantitative refinements often involve sophisticated tools from analytic number theory, including the large sieve, which is a powerful technique for estimating sums over arithmetic progressions, and explicit versions of the prime number theorem. These advanced inequalities allow for a deeper understanding of the fine-grained distribution of arithmetic functions, moving beyond simple asymptotic statements to provide concrete, verifiable bounds.

Applying Barban–Diananda–Elliott for Distribution in Arithmetic Progressions
Consider the additive function ω(n), which counts the number of distinct prime factors of n. The mean value of ω(n) up to x is A(x) = Σp≤x 1/p ≈ log log x. The Turán–Kubilius inequality gives a variance bound for ω(n) over all n ≤ x. How does the Barban–Diananda–Elliott theorem extend this to describe the variance of ω(n) for integers n in an arithmetic progression n ≡ a (mod q), where gcd(a,q)=1?
The Barban–Diananda–Elliott (BDE) theorem provides a bound for the sum of squared deviations of an additive function f(n) from its mean, specifically for integers in an arithmetic progression. For ω(n), the BDE theorem states that for any fixed A > 0, there exists a constant C > 0 such that for x ≥ 2 and q ≤ (log x)A, and for any a with gcd(a,q)=1: Σn≤x, n≡a(mod q) |ω(n) - A(x)|² ≤ C (x/q) B(x) where A(x) = Σp≤x 1/p and B(x) = Σp≤x 1/p. Here, B(x) ≈ log log x. The term x/q represents the approximate number of integers up to x in the arithmetic progression. This inequality shows that, for 'small' moduli q (up to a power of log x), the variance of ω(n) within an arithmetic progression is proportional to the variance over all integers, scaled by the density of the progression (1/q). This implies that the distribution of ω(n) in such arithmetic progressions is similar to its distribution over all integers, maintaining the same normal order and variance characteristics. The BDE theorem is crucial because it allows us to analyze the behavior of additive functions in structured subsets of integers, which is a common requirement in problems involving prime numbers in arithmetic progressions or other sieve theory applications.
Distinguishing Global vs. Local Distribution
Many foundational theorems in probabilistic number theory, such as the Erdős–Kac theorem and the basic Turán–Kubilius inequality, describe the global distribution of arithmetic functions over all integers up to a given bound x. However, advanced problems frequently require understanding the distribution of these functions within specific subsets of integers, such as arithmetic progressions (n ≡ a mod q) or short intervals (n ∈ [x, x+h]). When tackling such problems, recognize that a global result may not suffice. Tools like the Barban–Diananda–Elliott theorem are specifically designed for these 'local' distributions, providing variance estimates and other properties within arithmetic progressions. Similarly, for short intervals, different techniques, often involving Fourier analysis and explicit bounds, are needed. Always assess whether the problem context demands a global or local perspective on the distribution.

Joint Distribution of Multiple Additive Functions

The Erdős–Kac theorem describes the limiting Gaussian distribution for a single additive function. A natural and more complex extension is to consider the joint distribution of several additive functions, say f1(n), f2(n), ..., fk(n). This involves understanding how these functions behave collectively and whether their deviations from their respective means are correlated.

For a set of strongly additive functions fj(n) = Σp|n fj(p), under appropriate conditions, the vector of normalized functions ((f1(n) - A1(x)) / √B1(x), ..., (fk(n) - Ak(x)) / √Bk(x)) converges in distribution to a multivariate standard normal distribution. Here, Aj(x) = Σp≤x fj(p)/p and Bj(x) = Σp≤x fj(p)²/p are the means and variances, respectively. The key condition for this convergence is often a multivariate version of the Lindeberg condition, ensuring that no single prime contributes disproportionately to the total variance of any function.

The limiting distribution is characterized by its covariance matrix Σ, where the entries Σij are given by the limit of (1/√Bi(x)Bj(x)) Σp≤x fi(p)fj(p)/p as x → ∞. If the functions fi(p) are "independent" in some sense (e.g., if their supports on primes are disjoint), then the off-diagonal entries Σij for i ≠ j will be zero, implying asymptotic independence of the functions. However, if the functions share common prime factors, their distributions will be correlated.

A classic example is the joint distribution of ω(n) (number of distinct prime factors) and Ω(n) (number of prime factors counted with multiplicity). Both are additive functions. Their means are Aω(x) ≈ log log x and AΩ(x) ≈ log log x. Their variances are Bω(x) ≈ log log x and BΩ(x) ≈ log log x. The covariance term is Σp≤x ω(p)Ω(p)/p = Σp≤x 1/p ≈ log log x. Thus, the normalized (ω(n) - log log x) / √log log x and (Ω(n) - log log x) / √log log x are asymptotically correlated, converging to a bivariate normal distribution with a positive correlation coefficient. This reflects the fact that numbers with many distinct prime factors also tend to have many prime factors counted with multiplicity.

A much more challenging problem is the joint distribution of additive functions on shifted integers, such as (f(n), f(n+1)). The correlation between n and n+1 (e.g., sharing common prime factors like 2, or being prime-rich/prime-poor simultaneously) makes these problems significantly harder. For instance, the joint distribution of (ω(n), ω(n+1)) is not a simple product of two independent Gaussian distributions. Results in this area, such as those by Elliott and Halberstam, often rely on deep sieve methods and require careful handling of the correlations induced by small prime factors. These joint distributions are fundamental for understanding the distribution of prime gaps, twin primes, and other related conjectures in number theory, where the local structure of integers plays a critical role.

Effective Bounds and Rates of Convergence in Probabilistic Number Theory

While the asymptotic statements of theorems like Erdős–Kac and Turán–Kubilius are powerful, practical applications and a deeper theoretical understanding often require **effective bounds** and precise **rates of convergence**. These quantify how quickly the distributions approach their limits and provide explicit constants, rather than just stating that a property holds "for sufficiently large x."

For the Erdős–Kac theorem, which states that (ω(n) - log log x) / √log log x converges to a standard normal distribution, effective bounds measure the distance between the actual distribution function and the Gaussian cumulative distribution function. This distance is often quantified using metrics like the Kolmogorov distance (supremum of the absolute difference between the distribution functions) or the Lévy distance. Early work by Rényi and Turán, and later by Kubilius, established bounds of the form O(1/√log log x) for the Kolmogorov distance. These bounds indicate that the convergence is relatively slow, proportional to the inverse square root of the variance. Proving such bounds typically involves explicit estimates for the moments or characteristic functions, along with techniques from classical probability theory like the Berry–Esseen theorem, adapted for the number-theoretic context.

Similarly, for the Turán–Kubilius inequality, effective bounds involve determining the best possible constant C and providing explicit error terms. For strongly additive functions, it can be shown that Σn≤x |f(n) - A(x)|² = x B(x) + O(x B(x) / log x), providing a more precise asymptotic formula with an explicit error term. These error terms are critical for applications where the range of x is not astronomically large, or where the cumulative effect of small errors could be significant.

The development of effective bounds often requires moving beyond the method of moments alone. Techniques such as saddle-point methods applied to generating functions, explicit estimates for sums over primes (e.g., using the Prime Number Theorem with error terms), and advanced sieve theory methods are frequently employed. These methods allow for the precise control of remainder terms and the evaluation of constants.

The importance of effective bounds extends to various areas:

  1. Computational Number Theory: For algorithms that rely on the distribution of arithmetic functions, explicit bounds help determine the necessary input sizes for reliable results.
  2. Cryptography: The security of certain cryptographic primitives can depend on the distribution of prime factors of large numbers, where effective bounds are essential.
  3. Refining Conjectures: Quantitative estimates can help to refine conjectures about the distribution of number-theoretic objects, such as the number of prime factors in short intervals or the distribution of values of L-functions.
  4. Understanding Finite Behavior: While asymptotic results describe the limit, effective bounds provide insight into the behavior of functions for any given finite x, which is often the practical concern.
The pursuit of effective bounds represents a deeper level of analysis, transforming qualitative asymptotic statements into precise, verifiable quantitative claims.

Common Traps in Advanced Probabilistic Number Theory

  • Assuming Limiting Distributions for Multiplicative Functions: Incorrectly assuming that all multiplicative functions possess a limiting distribution, without verifying the specific convergence conditions (e.g., for series involving f(p) and f(pk)). Many important multiplicative functions, like d(n), do not have a classical limiting distribution.
  • Misapplying Turán-Kubilius to Arithmetic Progressions: Using the basic Turán–Kubilius inequality for sums over arithmetic progressions (n ≡ a mod q) without considering the specialized Barban–Diananda–Elliott theorem or other generalized results that account for the modulus q. The standard inequality applies to all integers up to x, not specific subsets.
  • Neglecting Covariance in Joint Distributions: When analyzing the joint distribution of multiple additive functions, assuming independence and overlooking the calculation of covariance terms (Σp≤x fi(p)fj(p)/p). This is especially critical for functions that share common prime factors or for functions on correlated inputs like f(n) and f(n+1).
  • Confusing Asymptotic Results with Effective Bounds: Interpreting "converges to" or "for sufficiently large x" as implying the result holds for all practical x, without considering the explicit error terms or rates of convergence. Effective bounds provide the necessary quantitative precision.
  • Ignoring Lindeberg-type Conditions for Erdős–Kac Extensions: Extending the Erdős–Kac theorem to general additive functions or to joint distributions without ensuring that a suitable Lindeberg-type condition (or its number-theoretic analogue) is met, which guarantees that no single prime contributes too much to the variance.
  • Assuming Independence of f(n) and f(n+k): A common error is to treat f(n) and f(n+k) as independent for small k (e.g., k=1). The arithmetic correlation between n and n+k is profound and requires advanced techniques (like sieve methods) to handle, leading to significant deviations from simple independent models.
  • Overlooking the Role of Small Primes: While many probabilistic number theory results focus on the contribution of large primes, the behavior of small primes (especially 2, 3, 5) can significantly influence the distribution, especially for functions like Ω(n) or in problems involving parity.

The Selberg–Delange Method and Asymptotics of Multiplicative Functions

The Selberg–Delange method provides a systematic way to obtain asymptotic formulas for sums of multiplicative functions whose Dirichlet series have a singularity of the form (s−1)−z with complex exponent z. If f is a multiplicative function satisfying |f(n)| ≤ 1 and its Dirichlet series F(s) = Σ f(n)n−s can be written as ζ(s)z G(s) where G(s) is analytic and non‑zero for Re(s) ≥ 1, then for x ≥ 2

Σn≤x f(n) = x (log x)z−1 ( G(1)/Γ(z) + O(1/log x) ).

The proof uses Cauchy’s integral formula on a Hankel contour around the branch cut of ζ(s)z, together with the zero‑free region of the Riemann zeta function. The method yields not only the main term but also an explicit error term that depends on the width of the zero‑free region. For example, taking f(n) = dk(n) (the k‑fold divisor function) gives z = k and G(s) = 1, reproducing the classical asymptotic Σ dk(n) ∼ x (log x)k−1/( (k−1)! ). The Selberg–Delange theorem also applies to functions like f(n) = 2ω(n) where ω(n) counts distinct prime factors; here z = 2 and G(1) = 6/π2. A crucial technical point is the requirement that f(p) be close to z on average over primes, which is encoded in the condition Σp≤x (f(p)−z)2/p = o(log log x). When this condition fails, the method breaks down and one must resort to more delicate probabilistic models such as the Kubilius model.

Distribution of Additive Functions on Shifted Primes and Polynomial Sequences

Understanding the values of an additive function f on sequences of the form p + a (with p prime) or on polynomial values P(n) requires tools beyond the classical Erdős–Kac theorem. For a strongly additive function f, the mean value on shifted primes is given by Σp≤x f(p+1) ∼ π(x) Σp f(p)/(p−1), provided the series converges. This result follows from the Bombieri–Vinogradov theorem and the Barban–Davenport–Halberstam theorem, which control the distribution of primes in arithmetic progressions on average. For polynomial sequences, the situation is more delicate: if P(n) is an irreducible polynomial of degree d ≥ 2, the set of prime factors of P(n) behaves like a random set of integers of size about nd. The Erdős–Kac theorem extends to f(P(n)) under the hypothesis that the Galois group of P acts transitively on the roots, giving a Gaussian limit with mean ∼ (log log n) Σp f(p)/p and variance ∼ (log log n) Σp f(p)2/p. The proof uses the method of moments together with the Chebotarev density theorem to evaluate correlations of f(p) over primes splitting in the splitting field of P. A notable exception occurs when P has a fixed divisor; for instance, f(n2+1) does not satisfy the usual Erdős–Kac scaling because the prime 2 always divides n2+1 for odd n, creating a bias that must be removed by considering the function on a suitable subsequence.

Worked Example: Mean of ω(p+1)
Let ω(n) denote the number of distinct prime factors of n. Compute the asymptotic mean value of ω(p+1) as p runs over primes up to x.
By the result for shifted primes, Σp≤x ω(p+1) ∼ π(x) Σq 1/(q−1) where the sum runs over all primes q. The series Σ 1/(q−1) diverges like log log x, but the precise constant is obtained by writing 1/(q−1) = 1/q + 1/(q(q−1)). The sum Σ 1/q over q ≤ x is log log x + M + o(1) (M is the Meissel–Mertens constant). The remaining sum Σ 1/(q(q−1)) converges to a constant C ≈ 0.773. Therefore the average of ω(p+1) over primes p ≤ x is log log x + M + C + o(1).
Exam‑day strategy
When a question asks for the mean of an additive function on a shifted prime sequence, first identify whether the function is strongly or completely additive. Then recall the general formula Σp≤x f(p+a) ∼ π(x) Σq f(q)/(q−1) (for a fixed integer a coprime to q). Check convergence of the series; if it diverges, express the divergence in terms of log log x and known constants. This pattern appears frequently in advanced problem sets.

The Dickman Function, Smooth Numbers, and the Probabilistic Model of Integers

The Dickman–de Bruijn function ρ(u) describes the asymptotic density of y‑smooth numbers (integers with no prime factor exceeding y) among integers up to x, where u = log x / log y. For fixed u > 0, Ψ(x, y) ∼ x ρ(u) as x → ∞ with y = x1/u. The function ρ satisfies the delay differential equation u ρ′(u) = −ρ(u−1) for u > 1, with initial condition ρ(u) = 1 for 0 ≤ u ≤ 1. This equation arises from a probabilistic heuristic: an integer n ≤ x is y‑smooth iff its largest prime factor P+(n) ≤ y. Conditioning on the size of the largest prime factor leads to the integral equation ρ(u) = ∫1u ρ(u−t) dt/t, which differentiates to the delay equation. The probabilistic model of integers due to Kubilius can be refined to capture smooth numbers by assigning to each prime p ≤ y a random exponent with geometric distribution, and to primes p > y a zero exponent. The resulting random variable approximates the distribution of log n / log y, and its limit law is precisely the Dickman distribution. This connection is exploited in the analysis of algorithms such as the quadratic sieve and the number field sieve, where the smoothness probability of numbers of size about exp(√(log N log log N)) determines the expected running time. Moreover, the moments of ρ(u) give the distribution of the largest prime factor: for any fixed k, the k‑th moment of log P+(n) / log n converges to ∫01 uk ρ(1/u) du/u2.

Sieve Methods and the Fundamental Lemma in Probabilistic Number Theory

Sieve theory provides upper and lower bounds for the number of integers in a set that avoid a given set of prime divisors. The fundamental lemma of the sieve states that for a sifting set of primes up to z, the sifted set S(A, P, z) satisfies |S(A, P, z) − X W(z)| ≤ ε X W(z) provided the sifting level z is not too large relative to the dimension κ of the sieve. Here X is an approximation to |A|, W(z) = ∏p<z</sub> (1 − ω(p)/p) with ω(p) the number of residue classes removed modulo p, and ε decays exponentially in the sifting parameter s = log X / log z. In probabilistic number theory, the fundamental lemma is used to estimate the frequency of integers with a prescribed number of prime factors in a given range. For example, to count integers n ≤ x with exactly k prime factors all exceeding xα, one applies the sieve to the set A = {n ≤ x} with the sifting set of primes up to xα. The dimension κ equals 1 for the classical sieve of Eratosthenes, but for problems involving additive functions the dimension can be larger. The Selberg sieve, with its quadratic form optimization, yields the optimal constant in the fundamental lemma for dimension 1, giving the asymptotic formula for the number of integers with no small prime factors. This result underpins the proof of the Hardy–Ramanujan theorem on the normal order of ω(n) and Ω(n) by showing that the contribution of small primes is negligible. The fundamental lemma also enters the proof of the Erdős–Kac theorem via the method of moments: one needs to show that the contribution of primes larger than x1/log log x to the moments of ω(n) is asymptotically Gaussian, which is achieved by a sieve bound on the number of integers with an unusually large number of such prime factors.

The Erdős–Kac Theorem for Polynomial Values and Function Fields

The classical Erdős–Kac theorem concerns the distribution of ω(n) for integers n ≤ x. A natural generalization asks for the distribution of ω(P(n)) where P ∈ ℤ[t] is a polynomial of degree d ≥ 2. Under the assumption that P is irreducible and has no fixed prime divisor (i.e., for every prime p there exists n with p ∤ P(n)), the values ω(P(n)) for n ≤ x satisfy a central limit theorem with mean and variance both asymptotic to (d log log x) Σp 1/p. The proof uses the method of moments combined with the Chebotarev density theorem to evaluate the joint moments of the indicator functions of prime divisibility. The key combinatorial input is that the Galois group of P acts transitively on the d roots, which ensures that the events p | P(n) for different primes behave asymptotically independently. In the function field setting, where one replaces ℤ by 𝔽q[t] and considers monic polynomials of degree n, the analogue of the Erdős–Kac theorem holds with a much simpler proof because the ring 𝔽q[t] is a principal ideal domain with a finite constant field. The number of irreducible factors of a random monic polynomial of degree n converges to a Gaussian with mean and variance ∼ log n. This result, due to Knopfmacher and others, uses the fact that the zeta function of 𝔽q[t] is rational, so the moments can be computed exactly via generating functions. The function field version also provides a testing ground for refinements such as the rate of convergence (Berry–Esseen bounds) and the large deviation principle, which are technically more accessible than their number field counterparts.

  • Applying the shifted‑prime mean value formula Σ f(p+a) ∼ π(x) Σ f(q)/(q−1) to functions that are not strongly additive or to shifts a that share a common factor with infinitely many primes.
  • Confusing the Dickman function ρ(u) with the Buchstab function ω(u); the former describes smooth numbers, the latter describes numbers with no small prime factors but at least one large prime factor.
  • Using the fundamental lemma of the sieve beyond its range of validity, i.e., taking the sifting level z larger than X1/s for the required dimension, which invalidates the exponential error bound.
  • Extending the Erdős–Kac theorem to polynomial values without checking the fixed divisor condition; a polynomial like n2+1 always has the prime 2 dividing it for odd n, breaking the independence heuristic.
  • Neglecting the role of the Galois group in the polynomial Erdős–Kac theorem; transitivity is essential for the asymptotic independence of prime divisibility events.
  • Treating the function field Erdős–Kac theorem as a direct proof of the number field version; the rational zeta function in 𝔽q[t] makes the moment calculations exact, a feature absent in ℤ.

The Law of the Iterated Logarithm for Additive Functions

The classical law of the iterated logarithm (LIL) for sums of independent random variables states that the partial sums fluctuate between ±√(2n log log n) almost surely. In probabilistic number theory the same phenomenon appears for additive functions such as ω(n) and Ω(n). Let f be a strongly additive function with f(p) = 1 for all primes p; then f(n) = ω(n). The Turán–Kubilius inequality gives Var(ω(n)) ∼ log log n for n ≤ x. The LIL for ω(n) was first proved by Erdős and Gál (1955) and later refined by Philipp (1975) using the Kubilius model. The precise statement is

limsupn→∞ (ω(n) − log log n) / √(2 log log n log log log n) = 1 almost surely,

and the corresponding liminf equals −1. The proof proceeds by approximating ω(n) with a sum of independent random variables Xp taking value 1 with probability 1/p and 0 otherwise, for primes p ≤ n. The Kubilius model shows that the error between ω(n) and this sum is negligible on the scale √(log log n log log log n). One then applies the Hartman–Wintner LIL for independent non‑identically distributed variables, verifying the Lindeberg condition using the bound Σp≤n 1/p² = O(1). The same argument works for any strongly additive function f with f(p) bounded and Σ f(p)²/p convergent, yielding a LIL with variance σ² = Σ f(p)²/p. For completely additive functions such as Ω(n) the result holds with the same normalisation because the contribution of prime powers is of lower order. The LIL is a sharp refinement of the Erdős–Kac theorem: while the central limit theorem describes typical fluctuations of order √(log log n), the LIL describes the extreme fluctuations that occur infinitely often.

The Erdős–Kac Theorem in Arithmetic Progressions

Fix coprime integers a and q. For n ≤ x with n ≡ a (mod q) the additive function ω(n) still satisfies a central limit theorem with mean and variance log log x, provided q grows slowly with x. The first uniform result is due to Halberstam (1966): for any fixed A > 0 the Erdős–Kac theorem holds uniformly for all q ≤ (log x)A. The proof uses the method of moments. One expands the k‑th moment of ω(n) over the progression as a sum over k‑tuples of primes. The main term comes from tuples of distinct primes, each contributing a factor 1/p. The condition (a,q)=1 ensures that the primes dividing q do not affect the asymptotic independence of the events p | n. The Siegel–Walfisz theorem gives the required equidistribution of primes in progressions for each fixed prime, with an error term that is negligible when summed over p ≤ x1/k. For larger q one needs the Bombieri–Vinogradov theorem, which provides the same level of distribution on average over q ≤ x1/2/(log x)B. Using this, Elliott (1979) extended the uniform Erdős–Kac theorem to q ≤ x1/2−ε. The joint distribution of ω(n) and ω(n+1) in progressions has also been studied; the covariance is Σp|q 1/p + o(1), reflecting the fact that primes dividing q cannot divide both n and n+1. These results illustrate how the probabilistic structure of additive functions survives the imposition of congruence conditions, provided the modulus is not too large.

Method of Moments with Characters
Show that the third moment of ω(n) for n ≤ x in a fixed arithmetic progression a mod q converges to the third moment of a standard normal distribution, assuming q is fixed.
Let S(x) = Σn≤x, n≡a (mod q) (ω(n) − log log x)³. Expand the cube: ω(n)³ = Σp,q,r 1p|n1q|n1r|n. The sum over n in the progression of the indicator product equals the number of n ≤ x with n ≡ a (mod q) and n ≡ 0 (mod [p,q,r]). By the Chinese remainder theorem this is x/(q·[p,q,r]) + O(1) provided (a,q)=1 and the moduli are coprime. Summing over distinct primes p,q,r gives the main term (log log x)³. The cross terms where two or three primes coincide contribute O((log log x)²). After centering and normalising by (log log x)3/2, the limit is the third moment of N(0,1), which is 0. The Siegel–Walfisz theorem guarantees the error is uniform for fixed q, so the convergence holds.
Exam‑day strategy
When a problem asks for the Erdős–Kac theorem in progressions, first state the range of uniformity (q ≤ (log x)A for fixed A, or q ≤ x1/2−ε on average). Then sketch the moment method: write the k‑th moment as a sum over prime k‑tuples, apply the Siegel–Walfisz theorem to replace the count in the progression by its expected value, and note that the contribution of non‑distinct primes is of lower order. Mention that the covariance between ω(n) and ω(n+1) in a progression picks up a term from primes dividing the modulus.

Probabilistic Models for the Möbius Function and the Mertens Conjecture

The Möbius function μ(n) is multiplicative with μ(p) = −1, μ(p²) = 0. Its mean value is zero and its variance is 6/π². A natural probabilistic model replaces μ(p) by independent random variables Xp taking values −1, 0, 1 with probabilities 1/p, 1−2/p, 1/p respectively, and sets μ(pᵏ)=0 for k≥2. This model, studied by Wintner (1944) and later by Harper, Soundararajan, and others, predicts that the summatory function M(x) = Σn≤x μ(n) behaves like a random walk with step variance 6/π². The Mertens conjecture |M(x)| < √x was disproved by Odlyzko and te Riele (1985) using a sophisticated analysis of the zeros of the Riemann zeta function; they showed that limsup M(x)/√x > 1.06 and liminf < −1.06. The probabilistic model suggests that M(x)/√x should have a limiting distribution related to the sum of independent random variables, but the actual distribution is influenced by the zeros of ζ(s). Under the Riemann hypothesis, the best known bound is M(x) ≪ x1/2 exp(C log x / log log x). The random multiplicative function model of Harper (2009) gives a precise conjecture for the distribution of M(x)/√x: it converges to a non‑Gaussian law whose characteristic function can be expressed in terms of the Riemann zeta zeros. This connection between probabilistic number theory and the zeros of ζ(s) is a central theme in modern research.

The Distribution of Prime Factors in Short Intervals

Let h = h(x) be a function tending to infinity with x. The local Erdős–Kac theorem asks whether ω(n) for n ∈ [x, x+h] is Gaussian with mean log log x and variance log log x. Hildebrand (1986) proved that if h = xo(1) and h → ∞, the distribution is indeed Gaussian. Maier's matrix method (1985) shows that for h = (log x)λ with λ > 1 the distribution of primes in short intervals exhibits irregularities that affect ω(n). Specifically, the variance of ω(n) in such intervals is still log log x, but the covariance structure differs from the independent model. Granville and Soundararajan (2007) developed a Poisson–Dirichlet process to describe the joint distribution of prime factors in short intervals, showing that the number of prime factors in disjoint subintervals converges to independent Poisson variables with mean log log x. For very short intervals h = logλ x with λ < 1, the distribution is not Gaussian; instead ω(n) is asymptotically Poisson with mean λ log log x. The transition at λ = 1 reflects the fact that the expected number of prime factors in the interval is of order 1. These results are proved using the Selberg–Delange method combined with sieve bounds for the number of integers with a given prime factor pattern in short intervals.

Applications of the Turán–Kubilius Inequality to the Distribution of Divisors

The divisor function d(n) is multiplicative, and its logarithm log d(n) is additive. The Turán–Kubilius inequality applied to f(n) = log d(n) gives Var(log d(n)) ≤ Σp≤x (log d(p))²/p + O(1) = (1/2) log log x + O(1). This yields the normal order log d(n) ∼ (1/2) log log n. Erdős and Kac (1940) proved a central limit theorem for log d(n): (log d(n) − (1/2) log log n) / √((1/2) log log n) converges to N(0,1). The proof uses the method of moments; the k‑th moment of log d(n) is expressed as a sum over k‑tuples of primes, and the main term comes from distinct primes because log d(p) = log 2. The Turán–Kubilius inequality also provides a quantitative bound for the rate of convergence in the central limit theorem, leading to a Berry–Esseen estimate of order (log log n)−1/2. Hall and Tenenbaum (1988) used these ideas to study the distribution of d(n) in short intervals and to prove that the number of integers n ≤ x with d(n) > (log x)λ has a precise asymptotic for λ > 1. The inequality is also essential in the proof of the Hardy–Ramanujan theorem for Ω(n) and in the analysis of the distribution of the sum of reciprocals of prime divisors.

The Erdős–Kac Theorem for Weighted Additive Functions

The classical Erdős–Kac theorem concerns the additive function ω(n), the number of distinct prime divisors of n. A natural generalisation replaces the weight 1 at each prime by a bounded arithmetic function g(p). Define the weighted additive function A_g(n)=∑p|n g(p). If g(p) is real‑valued and satisfies |g(p)|≤C for all primes, and the series ∑p g(p)2/p converges, then the distribution of A_g(n) over n≤x is asymptotically normal with mean M_g(x)=∑p≤x g(p)/p and variance V_g(x)=∑p≤x g(p)2/p. The proof follows the method of moments: the k‑th moment of the centred sum is expressed as a sum over k‑tuples of distinct primes, the main contribution comes from tuples with all primes distinct, and the Siegel–Walfisz theorem supplies the required equidistribution in progressions. When the variance tends to infinity, the normalised variable (A_g(n)−M_g(x))/√V_g(x) converges in distribution to the standard Gaussian. If the variance stays bounded, the limit law is a non‑degenerate infinitely divisible distribution whose characteristic function can be written as an Euler product. This framework covers many classical functions: for g(p)=log p one recovers the normal order of log n, for g(p)=1/p one obtains the distribution of the sum of reciprocals of prime divisors, and for g(p)=χ(p) with a Dirichlet character χ the theorem yields a central limit theorem for character sums over prime divisors.

The Distribution of the Sum of Reciprocals of Prime Divisors

Let S(n)=∑p|n 1/p. This additive function has mean value ∑p≤x 1/p2 = O(1) and variance ∑p≤x 1/p3 = O(1), so its variance remains bounded as x→∞. Consequently the Erdős–Kac theorem does not give a Gaussian limit; instead the distribution of S(n) converges to a non‑Gaussian infinitely divisible law. The characteristic function of the limit is φ(t)=∏p (1−1/p + (1/p) eit/p). This product converges absolutely because ∑ 1/p2 < ∞. The limit distribution is continuous and has a density that can be expressed as an inverse Fourier transform of φ. Erdős and Wintner (1939) proved that for any additive function f with ∑ |f(p)|/p < ∞ and ∑ f(p)2/p < ∞, the values f(n) possess a limiting distribution. In the case of S(n) the limiting distribution is known to be the same as that of the random series ∑p X_p/p where X_p are independent Bernoulli variables with P(X_p=1)=1/p. The moments of the limit can be computed from the Euler product; for example the first moment is ∑ 1/p2 = π2/6 − 1 ≈ 0.6449, and the second moment is ∑ 1/p3 + (∑ 1/p2)2. The convergence rate to the limit is of order 1/log x, which follows from the Turán–Kubilius inequality applied to the truncated function S_y(n)=∑p|n, p≤y 1/p with y = (log x)^A. This result illustrates how bounded variance leads to a non‑Gaussian limit and how the Kubilius model captures the correct limiting law.

Worked Example: Limiting Distribution of S(n)
Show that the random variable S(n)=∑p|n 1/p has a limiting distribution as n→∞ and identify its characteristic function.
Define the truncated sum S_y(n)=∑p|n, p≤y 1/p. For each prime p≤y let X_p be the indicator of p|n. Over n≤x the variables X_p are approximately independent with mean 1/p and variance (1/p)(1−1/p). By the Turán–Kubilius inequality, the mean square deviation of S_y(n) from its expectation is bounded by ∑p≤y (1/p)2/p = ∑p≤y 1/p3 = O(1). Letting y→∞ slowly with x, the finite‑dimensional distributions of (X_p) converge to those of independent Bernoulli(1/p) variables. Hence the characteristic function of S(n) converges pointwise to φ(t)=∏p (1−1/p + (1/p) eit/p). The product converges because ∑ 1/p2 < ∞. By Lévy's continuity theorem the distribution of S(n) converges weakly to the law with characteristic function φ. This law is infinitely divisible, non‑Gaussian, and has a continuous density.

The Kubilius Model for Multiplicative Functions on Polynomial Sequences

Kubilius (1956) introduced a probabilistic model that replaces the values of a multiplicative function f at prime powers by independent random variables. For a polynomial P∈ℤ[X] of degree d≥1 with no fixed prime divisor, consider the sequence f(P(n)). The model assigns to each prime p a random variable Y_p taking the values f(p^k) with probabilities given by the natural density of integers n such that p^k ‖ P(n). Under the assumption that P is square‑free modulo p for all but finitely many p, the density of n with p‖P(n) is 1/p + O(1/p2), and the density of higher powers is O(1/p2). The model then predicts that the additive function log|f(P(n))| behaves like a sum of independent contributions from each prime. Using the Turán–Kubilius inequality for the sequence n≤x, one can prove that the variance of log|f(P(n))| is asymptotic to ∑p≤x (log|f(p)|)2/p, provided f(p) is bounded away from zero and infinity. The central limit theorem for this model was established by Hildebrand (1987) for f(n)=n and by Granville and Soundararajan (2000) for general multiplicative f satisfying a suitable Siegel–Walfisz condition. The error term in the normal approximation is of order (log log x)−1/2, matching the classical Berry–Esseen bound. This framework has been applied to the distribution of values of the divisor function d(P(n)), the Euler totient φ(P(n)), and the sum‑of‑divisors function σ(P(n)). In each case the limiting Gaussian law has mean and variance given by the corresponding prime sums, and the model correctly predicts the covariance structure between f(P(n)) and f(P(n+1)).

The Central Limit Theorem for the Number of Prime Factors of Shifted Primes

Let ω(p−1) denote the number of distinct prime factors of p−1 as p runs over primes. The distribution of ω(p−1) is a classical problem in probabilistic number theory. Erdős (1946) showed that ω(p−1) has normal order log log p, and Halberstam (1956) proved a central limit theorem: (ω(p−1) − log log p)/√(log log p) converges in distribution to the standard normal as p→∞. The proof uses the Bombieri–Vinogradov theorem to control the distribution of primes in arithmetic progressions, which is necessary because the condition p≡1 (mod q) introduces a bias for primes q dividing p−1. More precisely, for a fixed integer k, the k‑th moment of ω(p−1) over primes p≤x is expressed as a sum over k‑tuples of distinct primes q1,…,q_k of the count of primes p≤x with q_i | p−1 for all i. By the Siegel–Walfisz theorem, this count is π(x)/φ(q1⋯q_k) + O(x exp(−c√log x)). Summing over all tuples yields the Gaussian moments. The variance is ∑q≤x 1/(q−1) = log log x + O(1). A quantitative version with Berry–Esseen bound O((log log x)−1/2) was obtained by Elliott (1979) using the method of characteristic functions and the large sieve. The same technique applies to ω(p+1) and to ω(P(p)) for any non‑constant polynomial P with integer coefficients, provided P has no fixed prime divisor. The result illustrates how the distribution of additive functions on the shifted primes inherits the Gaussian law from the equidistribution of primes in progressions.

The Probabilistic Approach to the Distribution of Smooth Numbers

A positive integer n is called y‑smooth if all its prime factors are ≤ y. Let Ψ(x,y) denote the number of y‑smooth integers ≤ x. The Dickman function ρ(u) defined by the differential‑delay equation uρ'(u) = −ρ(u−1) for u>1, with ρ(u)=1 for 0≤u≤1, gives the asymptotic Ψ(x,x1/u) ∼ x ρ(u) for fixed u>0 as x→∞. A probabilistic interpretation due to Hildebrand (1986) models the prime factorisation of a random integer n≤x by a Poisson process on the logarithmic scale. The logarithms of the prime factors of n, when ordered decreasingly, converge in distribution to the points of a Poisson–Dirichlet process with parameter 1. The largest prime factor log P+(n) / log x then has the Dickman distribution. This model also yields the joint distribution of the k largest prime factors: the vector (log P1(n)/log x, …, log P_k(n)/log x) converges to the first k points of the Poisson–Dirichlet process. The Turán–Kubilius inequality for the additive function log P+(n) gives a variance bound of order log log x, which is consistent with the Gaussian fluctuations of log log P+(n) around its mean. Recent work by Harper (2012) and by Granville (2017) has refined the error terms in the Dickman approximation using the saddle‑point method and the Selberg–Delange theorem, obtaining uniform estimates for Ψ(x,y) in the range (log x)1+ε ≤ y ≤ x. The probabilistic model also predicts the distribution of the number of prime factors of a smooth integer: conditioned on n being y‑smooth, ω(n) is asymptotically normal with mean log log y and variance log log y, a result proved by Hildebrand and Tenenbaum (1993). This connection between smooth numbers and probabilistic number theory is a cornerstone of modern analytic number theory.

The Normal Order and Fluctuations of the Sum-of-Divisors Function σ(n)

The sum-of-divisors function σ(n) = ∑d|n d is multiplicative with σ(p^k) = (pk+1−1)/(p−1). Its average order is classical: (1/x)∑n≤x σ(n) = ζ(2)x + O(log x) = (π2/6)x + O(log x). However, the normal order — the value taken by σ(n) for almost all n — is not given by the average. Erdős and Wintner (1939) proved that the sequence σ(n)/n possesses a continuous limiting distribution function D(u) = limx→∞ (1/x) #{n≤x : σ(n)/n ≤ u}. This distribution is not Gaussian; its characteristic function is the Euler product ∏_p (1−1/p) ∑k≥0 p-k exp(it σ(p^k)/p^k). The mean of D is ζ(2) = π2/6, and its variance is finite, given by ∑_p (σ(p)/p − 1)2/p + O(1).

The fluctuations of σ(n) around its mean are of order n. More precisely, the Erdős–Kac type central limit theorem fails for σ(n) because the variance of the additive function log σ(n) grows like log log log n, not log log n. Ramanujan (1915) and later Robin (1984) studied the maximal order: limsupn→∞ σ(n)/(n log log n) = e^γ, where γ is Euler's constant. Robin showed that the Riemann hypothesis is equivalent to σ(n) < e^γ n log log n for all n > 5040. The normal order of log σ(n) is log n + log log log n + O(1), a result of Erdős and Pomerance (1985) obtained via the Turán–Kubilius inequality applied to the additive function log σ(n). The variance of log σ(n) is ∼ log log log n, so the fluctuations are much smaller than those of ω(n).

A quantitative version of the Erdős–Wintner theorem for σ(n)/n was given by Elliott (1979) using characteristic functions and the large sieve. He proved a Berry–Esseen bound O((log log x)-1/2) for the convergence of the distribution of (σ(n)/n − ζ(2))/√(Var) to the limiting law, where Var = ∑_p (σ(p)/p − 1)2/p. The limiting distribution is infinitely divisible but not stable; its tails decay like exp(−c u log u). This contrasts with the Gaussian tails of ω(n). The method extends to any multiplicative function f with f(p^k) bounded by a polynomial in p^k, provided the series ∑_p Var_p(f) converges, where Var_p(f) = ∑k≥1 (f(p^k) − f(pk−1))2/p^k.

Applications include the study of the distribution of the abundancy index σ(n)/n, which classifies numbers as deficient, perfect, or abundant. The density of abundant numbers is known to be about 0.2476, a consequence of the continuous distribution D(u). The same probabilistic model predicts the joint distribution of σ(n) and φ(n), leading to results on the correlation between the two functions. Recent work by Pomerance and others has refined the error terms in the Erdős–Wintner theorem using the Selberg–Delange method, yielding uniform estimates for the counting function of n with σ(n)/n in a given interval.

The Distribution of the Euler Totient Function φ(n) and Its Probabilistic Model

The Euler totient φ(n) = n ∏p|n (1−1/p) is multiplicative with φ(p^k) = p^k − pk−1. Its average order is (1/x)∑n≤x φ(n) = (3/π2)x2 + O(x log x), so the mean value of φ(n)/n is 6/π2. The normal order of φ(n) is not a simple multiple of n; rather, φ(n)/n has a continuous limiting distribution function V(u) = limx→∞ (1/x) #{n≤x : φ(n)/n ≤ u}, again by the Erdős–Wintner theorem. The characteristic function of V is ∏_p (1−1/p) ∑k≥0 p-k exp(it φ(p^k)/p^k). The mean of V is 6/π2, and its variance is ∑_p (1/p − 1/p2)2/(1−1/p) = ∑_p 1/(p(p−1)) ≈ 0.773.

The minimal order of φ(n) is given by Mertens' theorem: liminfn→∞ φ(n) log log n / n = e-γ. This is attained on primorials n = ∏p≤y p. The maximal order is trivial: φ(n) ≤ n−1 for n>1, with equality for primes. The fluctuations of φ(n) around its mean are of order n, but the normalized variable (φ(n)/n − 6/π2) has a limiting distribution with finite variance. A central limit theorem for log φ(n) does not hold because the variance of log φ(n) grows like log log log n, similar to σ(n). However, the additive function f(n) = ∑p|n log(1−1/p) satisfies the Erdős–Kac theorem after appropriate centering: (f(n) + log log n)/√(log log n) converges to the standard normal. This follows from the Kubilius model, where the contribution of each prime p is an independent random variable taking value log(1−1/p) with probability 1/p and 0 otherwise.

The probabilistic model for φ(n) is closely related to the distribution of the ratio n/φ(n) = ∏p|n (1−1/p)-1. This ratio has a limiting distribution with mean ζ(2)/ζ(3) ≈ 1.368 and finite variance. The Erdős–Wintner theorem applies because the series ∑_p Var_p(log(1−1/p)) converges. Quantitative refinements by Tenenbaum (1995) using the Selberg–Delange method give an error term O((log x)-1/2) for the convergence of the distribution function of φ(n)/n. The same techniques yield the joint distribution of φ(n) and σ(n), showing that the two functions are asymptotically independent in the sense that the limiting joint distribution factors.

Applications of the distribution of φ(n) include the study of the Carmichael function λ(n) and the order of elements in the multiplicative group modulo n. The density of integers n for which φ(n) divides n−1 (Lehmer's problem) is zero, a consequence of the fact that φ(n)/n is typically bounded away from 1. The probabilistic model also predicts the distribution of the number of solutions to φ(x) = m, a problem connected to the multiplicity of values of φ. Recent work by Ford (1998) and others has used the Kubilius model to obtain precise asymptotics for the number of integers with a given value of φ(n)/n in short intervals.

Random Multiplicative Functions and the Central Limit Theorem for Their Partial Sums

A Steinhaus random multiplicative function f is defined by choosing f(p) independently for each prime p, uniformly on the unit circle in the complex plane, and extending multiplicatively: f(p^k) = f(p)^k. The partial sums S(x) = ∑n≤x f(n) exhibit Gaussian fluctuations. Harper (2013) proved that for any fixed real t, the real and imaginary parts of S(x)/√x converge in distribution to independent normal random variables with mean 0 and variance 1/2. More precisely, the finite-dimensional distributions of the process {S(x)/√x : x ≥ 1} converge to those of a complex Brownian motion. The proof uses the method of moments combined with the independence of the values at primes and the fact that the contribution of prime powers is negligible.

The variance of S(x) is ∑n≤x 1 = x + O(1) because E[f(n) f(m)] = 1 if n=m and 0 otherwise, by independence of the prime values. The fourth moment E[|S(x)|4] = 2x2 + O(x3/2) matches the Gaussian prediction. The central limit theorem extends to Rademacher random multiplicative functions, where f(p) = ±1 with equal probability. In that case, the limiting distribution of S(x)/√x is real Gaussian with variance 1. The work of Helson (1995) and later of Bourgain (2010) established almost sure bounds: with probability 1, |S(x)| ≤ C √x log log x for large x, a law of the iterated logarithm for random multiplicative functions.

These results have deep connections to the Riemann zeta function. The random Euler product ∏_p (1 − f(p)p-s)-1 converges for Re(s) > 1/2 almost surely and provides a probabilistic model for ζ(s) in the critical strip. The central limit theorem for S(x) implies that the random Dirichlet series ∑ f(n)n-s has a natural boundary at Re(s) = 1/2, mirroring the conjectured behavior of ζ(s). Recent work by Harper, Soundararajan, and others has refined the error terms in the central limit theorem, obtaining a Berry–Esseen bound O(x-1/4) for the convergence of the distribution of S(x)/√x to the Gaussian law.

Applications include the study of the distribution of the Möbius function μ(n) and the Liouville function λ(n). Although μ and λ are deterministic, their partial sums are conjectured to behave like those of random multiplicative functions. The central limit theorem for random multiplicative functions provides a heuristic for the Riemann hypothesis: if the partial sums of μ(n) satisfy the same Gaussian fluctuations, then the Dirichlet series ∑ μ(n)n-s converges for Re(s) > 1/2, which is equivalent to the Riemann hypothesis. The probabilistic model also predicts the distribution of the values of L-functions at the central point, a topic of active research in the theory of moments of L-functions.

The Erdős–Kac Theorem for Additive Functions on Values of Multivariate Polynomials

Let P(x1,…,x_k) ∈ ℤ[x1,…,x_k] be a non‑constant polynomial with no fixed prime divisor. For a box B = [1,N]^k, consider the additive function ω(P(n)) = ∑p|P(n) 1. The Erdős–Kac theorem extends to this setting: as N→∞, the distribution of (ω(P(n)) − μ_N)/√μ_N over n∈B converges to the standard normal, where μ_N = ∑p≤N^d ρ_P(p)/p and ρ_P(p) is the number of solutions to P(n) ≡ 0 (mod p) in (ℤ/pℤ)^k. This result was proved by Granville and Soundararajan (2007) using the Kubilius model adapted to polynomial sequences. The key input is the equidistribution of the values of P(n) modulo p, which holds for all but finitely many primes by the Chebotarev density theorem for the splitting field of P.

The variance of ω(P(n)) is also μ_N + o(μ_N). The Turán–Kubilius inequality for the sequence {P(n) : n∈B} takes the form ∑n∈B |ω(P(n)) − μ_N|2 ≤ C |B| μ_N, with a constant C depending only on the degree of P. The proof uses the large sieve for polynomial sequences to control the correlation between the events p|P(n) and q|P(n) for distinct primes p,q. The error term in the central limit theorem is O(μ_N-1/2) under the assumption that the number of variables k ≥ 2, which ensures sufficient averaging to apply the method of moments.

For k=1, the classical Erdős–Kac theorem for polynomial values requires the polynomial to be irreducible and without fixed prime divisor. The multivariate case is more flexible: even reducible polynomials satisfy the theorem provided each irreducible factor has no fixed prime divisor. The limiting mean μ_N is asymptotic to c_P log log N, where c_P = ∑_p (ρ_P(p)−1)/p is a constant depending on the geometry of the variety P=0. For example, if P(x,y) = x2 + y2, then ρ_P(p) = p − (−1)(p−1)/2 for odd p, and c_P = 1/2. The central limit theorem then states that (ω(x2+y2) − ½ log log N)/√(½ log log N) converges to the standard normal as N→∞.

Quantitative refinements by Kowalski and Sawin (2016) give a Berry–Esseen bound O((log log N)-1/2) for the convergence rate, using the method of characteristic functions and the large sieve for algebraic varieties. The joint distribution of ω(P1(n)), …, ω(P_r(n)) for several polynomials is multivariate normal with covariance matrix given by the sums over primes of the densities of simultaneous solutions. This multivariate extension is essential for applications to the distribution of prime factors of values of polynomial maps, such as the number of prime factors of the determinant of a random integer matrix.

Probabilistic Number Theory in Beatty Sequences and Non‑Linear Sequences

A Beatty sequence is the set of integers ⌊α n + β⌋ for n≥1, where α>1 is irrational and β∈ℝ. The distribution of additive functions on Beatty sequences has been studied by Banks, Shparlinski, and others. For a strongly additive function f(n) = ∑p|n g(p) with g(p) bounded, the mean value over the first N terms of the Beatty sequence is (1/N)∑n≤N f(⌊α n+β⌋) = ∑_p g(p)/p + O(1/log N), the same as for the natural numbers. The variance is also asymptotic to ∑_p g(p)2/p, provided α is irrational. The Erdős–Kac theorem holds: (f(⌊α n+β⌋) − μ_N)/√μ_N converges to the standard normal, where μ_N = ∑p≤N g(p)/p.

The proof uses the fact that the sequence ⌊α n+β⌋ is uniformly distributed modulo p for every prime p, a consequence of Weyl's criterion and the irrationality of α. The Turán–Kubilius inequality adapts with an extra error term O(N1/2+ε) coming from the discrepancy of the Beatty sequence modulo p. For quadratic sequences like ⌊n^c⌋ with c>1 non‑integer, the distribution of prime factors is more delicate. Harman (1998) showed that for c∈(1, 12/11), the sequence ⌊n^c⌋ satisfies the Erdős–Kac theorem with the same mean and variance as the integers. The method uses the Vinogradov–Korobov zero‑free region for the zeta function to control exponential sums over the sequence.

For smooth numbers in Beatty sequences, the Dickman function ρ(u) still describes the asymptotic density of y‑smooth integers in the sequence, provided y ≥ (log N)1+ε. Hildebrand and Tenenbaum (1993) proved that the number of y‑smooth integers in a Beatty sequence up to N is ∼ (N/α) ρ(u) where u = log N / log y. The probabilistic model of the Poisson–Dirichlet process for the logarithms of prime factors remains valid because the sequence is well‑distributed in arithmetic progressions. The variance of the additive function log P+(n) (the logarithm of the largest prime factor) is of order log log N, consistent with the Gaussian fluctuations predicted by the Turán–Kubilius inequality.

Applications include the study of the distribution of the Möbius function on Beatty sequences. The Mertens sum M_α(N) = ∑n≤N μ(⌊α n+β⌋) is conjectured to satisfy M_α(N) = O(N1/2+ε), analogous to the classical Mertens conjecture. The probabilistic model predicts that M_α(N)/√N converges to a Gaussian distribution with variance 1/α. Recent work by Cellarosi and Sinai (2013) has established a central limit theorem for the Möbius function on certain non‑linear sequences using the method of moments and the Gowers uniformity norms. These results illustrate the robustness of probabilistic number theory beyond the natural numbers.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials at Prime Arguments

When the argument of a polynomial is restricted to prime numbers, the additive function ω(P(p)) — the number of distinct prime divisors of P(p) — still satisfies a central limit theorem under natural hypotheses. Let P ∈ ℤ[x] be an irreducible polynomial of degree d ≥ 1 with no fixed prime divisor. For x large, define the mean μ(x) = ∑q≤x ρ(q)/q where ρ(q) is the number of solutions of P(t) ≡ 0 (mod q) with t prime to q. The variance σ²(x) equals μ(x) + O(1). The Erdős–Kac theorem for this sequence states that (ω(P(p)) − μ(x))/√σ²(x) converges in distribution to the standard normal law as x → ∞, where p runs over primes ≤ x. The proof combines the Turán–Kubilius inequality for primes with the Bombieri–Vinogradov theorem to control the error terms arising from the distribution of primes in arithmetic progressions. A key technical point is that the contribution of primes q dividing the discriminant of P is negligible, and the condition that P has no fixed prime divisor ensures that ρ(q) < q for all q. The result was first established by Harman (1998) for special polynomials and later extended by Kowalski and Sawin (2016) to general irreducible polynomials using the large sieve for algebraic varieties. The multivariate version gives a joint Gaussian limit for ω(P₁(p)), …, ω(P_r(p)) with covariance matrix Σij = ∑_q ρij(q)/q, where ρij(q) counts simultaneous solutions. This theorem is essential for applications such as the distribution of prime factors of the determinant of a random integer matrix whose entries are prime numbers.

The Distribution of the Number of Prime Factors of Values of Binary Forms

For a binary form F(x,y) = a_d x^d + ad-1 xd-1y + … + a0 y^d with integer coefficients and non‑zero discriminant, the additive function ω(F(x,y)) exhibits Gaussian fluctuations when (x,y) ranges over a large box [1,X] × [1,Y]. Assume F has no fixed prime divisor, i.e. for every prime q there exists a pair (x,y) with q ∤ F(x,y). The mean value of ω(F(x,y)) over the box is μX,Y = ∑q≤max(X,Y) ρ(q)/q + O(1), where ρ(q) is the number of primitive solutions of F(x,y) ≡ 0 (mod q). The variance is σ²X,Y = μX,Y + O(1). The Erdős–Kac theorem for binary forms asserts that (ω(F(x,y)) − μX,Y)/√σ²X,Y converges to the standard normal distribution as X,Y → ∞. The proof adapts the Turán–Kubilius inequality to two‑dimensional sequences, using the fact that the set of values F(x,y) is well‑distributed in arithmetic progressions modulo q. The error term in the inequality involves the discrepancy of the sequence modulo q, which is bounded by O(q1/2+ε) via bounds for exponential sums over binary forms (Heath‑Brown, 1984). For several independent binary forms F₁,…,F_r, the joint distribution is multivariate normal with covariance matrix given by the sums over primes of the densities of simultaneous solutions. This result has applications to the distribution of prime factors of values of quadratic forms such as x²+y², where the mean is (1/2)log log N and the variance is the same, reflecting the fact that primes represented by the form have density 1/2 among all primes.

Worked Example: Applying the Turán–Kubilius Inequality to a Binary Form
Let F(x,y) = x² + y². Estimate the variance of ω(F(x,y)) for 1 ≤ x,y ≤ N and state the condition needed for the Erdős–Kac theorem to hold.
For F(x,y)=x²+y², the number of primitive solutions modulo a prime q is ρ(q) = q − (−1/q) where (−1/q) is the Legendre symbol. Hence ∑q≤N ρ(q)/q = ∑q≤N (1 − (−1/q)/q) = log log N + O(1). The variance σ²_N equals this sum plus O(1), so σ²_N ∼ log log N. The condition for the Erdős–Kac theorem is that F has no fixed prime divisor. For x²+y², the only possible fixed divisor is 2, but F(1,1)=2 is not divisible by 4, and there exist pairs with odd values, so no prime divides all values. Therefore the theorem applies and (ω(x²+y²) − log log N)/√(log log N) converges to the standard normal distribution.
Exam Strategy

The mean is the sum of ρ(q)/q over q up to the size of the box. The variance equals the mean plus a bounded error. Remember to check the “no fixed prime divisor” condition; if a prime q divides F(x,y) for all (x,y), the mean formula acquires an extra constant term and the limiting distribution may shift.

The Probabilistic Model for the Möbius Function in Short Intervals and the Chowla Conjecture

The Chowla conjecture predicts that the Möbius function μ(n) behaves like a sequence of independent random variables taking values −1, 0, 1 with probabilities 3/π², 1−6/π², 3/π² respectively, conditioned on being square‑free. In short intervals [x, x+H] with H = x^θ (0<θ<1), the probabilistic model suggests that the sum M(x+H)−M(x) has mean zero and variance H·(6/π²) + o(H). A central limit theorem for the normalized sum (M(x+H)−M(x))/√H would follow if the model were exact. Rigorous results are conditional: assuming the Riemann hypothesis and the linear independence of ordinates of zeta zeros, Ng (2004) showed that the logarithmic distribution of (M(x+H)−M(x))/√H converges to a Gaussian with variance 6/π². Unconditionally, Harper (2013) proved that for H ≥ x1/2+ε the variance is asymptotic to H·(6/π²) and the distribution is close to normal in the sense of moments. The connection to probabilistic number theory is made precise by the random multiplicative function model: let X(p) be independent random variables with P(X(p)=1)=P(X(p)=−1)=1/2, and define μ_rand(n) = ∏p|n X(p) for square‑free n, zero otherwise. The moments of ∑n≤x μ_rand(n) match those of the true Möbius sum up to a small error, providing a heuristic for the Chowla conjecture. Recent work by Matomäki, Radziwiłł, and Tao (2015) on multiplicative functions in short intervals uses this probabilistic framework to prove that μ(n) does not correlate with any deterministic sequence of bounded complexity, a major step toward the Chowla conjecture.

The Selberg Central Limit Theorem for the Riemann Zeta Function and Its Probabilistic Interpretation

Selberg (1946) proved that for T large, the random variable log ζ(1/2 + iU) where U is uniformly distributed in [T,2T] satisfies a central limit theorem: (log ζ(1/2+iU)) / √(½ log log T) converges in distribution to a standard complex Gaussian N(0,1) + i N(0,1). The real and imaginary parts are independent and each has variance ½ log log T. This result is a cornerstone of probabilistic number theory because it shows that the values of ζ on the critical line behave like a random Euler product ∏_p (1 − p−1/2−iU)−1. The proof uses the approximate functional equation and the fact that the Dirichlet polynomial ∑n≤T n−1/2−iU has Gaussian fluctuations. A modern probabilistic interpretation, developed by Bourgade (2010) and Harper (2013), constructs a random Euler product over primes with independent random phases and shows that its logarithm converges to the same Gaussian limit. The Selberg theorem also implies that the number of zeros of ζ in short intervals of the critical line has Gaussian fluctuations after appropriate normalization. Quantitative refinements give a Berry–Esseen bound O((log log T)−1/2) for the convergence rate, obtained by Soundararajan (2009) using characteristic functions and the large sieve. This theorem connects the distribution of prime numbers (via the explicit formula) with the probabilistic behavior of ζ, and it underpins many conjectures on the distribution of values of L‑functions.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with Prescribed Splitting Behavior

Let P(x) ∈ ℤ[x] be an irreducible polynomial of degree d with Galois group G. For a prime q not dividing the discriminant, the factorization of P modulo q corresponds to a conjugacy class C_q in G. The number of prime factors ω(P(n)) can be studied conditionally on the splitting type of n modulo q. Fix a conjugacy class C ⊂ G and consider integers n ≤ x such that the Frobenius element at n (in the splitting field of P) lies in C. Under the Chebotarev density theorem, the proportion of such n is |C|/|G|. The conditional mean of ω(P(n)) for these n is μ_C(x) = ∑q≤x (ρ_C(q)/q) + O(1), where ρ_C(q) is the number of roots of P modulo q for primes whose Frobenius lies in C. The conditional variance is σ²_C(x) = μ_C(x) + O(1). The conditional Erdős–Kac theorem states that (ω(P(n)) − μ_C(x))/√σ²_C(x) converges to the standard normal distribution as x → ∞, uniformly for all conjugacy classes C. The proof uses the Turán–Kubilius inequality together with effective Chebotarev estimates (Lagarias–Odlyzko) to control the error terms uniformly in C. This result was established by Kowalski and Sawin (2016) as part of their work on the large sieve for algebraic varieties. It implies that the fluctuations of ω(P(n)) are essentially independent of the splitting behavior, a strong form of equidistribution. Applications include the distribution of prime factors of values of polynomials at prime arguments with a given residue class, and the study of the number of prime factors of norms of ideals in number fields with prescribed Artin symbol.

  • Confusing the random multiplicative function model for μ(n) with a proof of the Chowla conjecture; the model only provides a heuristic, not a rigorous derivation.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials over Function Fields

Let 𝔽_q[t] be the polynomial ring over a finite field with q elements. For a non‑constant polynomial P ∈ 𝔽_q[t] the analogue of the integer additive function ω(n) is the number of distinct monic irreducible factors of P, denoted ω_q(P). The mean and variance of ω_q(P) over all monic polynomials of degree n are both asymptotic to log n, exactly as in the integer case. Car (1995) proved that the normalized random variable (ω_q(P) − log n) / √(log n) converges in distribution to a standard normal law as n → ∞, uniformly for all q. The proof follows the Kubilius model: one replaces the set of irreducible polynomials by independent Bernoulli variables with success probabilities 1/deg f, and then applies a characteristic‑function argument identical to the classical Erdős–Kac proof. The error term in the Berry–Esseen bound is O((log n)−1/2), matching the integer result up to the implied constant. This function‑field version is a cornerstone for transferring probabilistic techniques between number fields and function fields, and it underlies recent work on the distribution of values of L‑functions over 𝔽_q[t].

A key technical point is the independence of the events “f divides P” for distinct irreducibles f, which holds exactly in 𝔽_q[t] because the ring is a unique factorisation domain with a finite set of irreducibles of each degree. In the integer setting one only has asymptotic independence, which forces the use of the Turán–Kubilius inequality to control correlations. The exact independence in the function‑field model yields a cleaner proof and allows one to obtain explicit constants in the convergence rate. Moreover, the same method extends to additive functions of the form f(P) = Σf|P g(f) where g is a bounded function on irreducibles; the limiting distribution is again Gaussian with variance Σdeg f ≤ n g(f)2 / deg f.

Applications include the distribution of the number of irreducible factors of values of a fixed polynomial map Φ: 𝔽_q[t] → 𝔽_q[t] (for example Φ(P) = P2 + 1). Under the condition that Φ has no fixed irreducible divisor, the Erdős–Kac theorem holds for ω_q(Φ(P)) with mean and variance ∼ c_Φ log n, where c_Φ is the average number of irreducible factors of Φ(f) as f runs over irreducibles. This result was established by Bary‑Soroker and Kozma (2018) using a sieve‑theoretic adaptation of the Kubilius model. The function‑field setting also permits a precise study of the joint distribution of ω_q(P) and ω_q(P+1), leading to a bivariate normal limit with an explicitly computable covariance matrix.

The Distribution of Additive Functions on Shifted Primes in Arithmetic Progressions

Let a and q be coprime positive integers. For an additive function f(n) = Σp^α‖n g(p,α) with g bounded, one studies the values f(p + a) as p runs over primes in the progression p ≡ b (mod q). The mean value M(x) = (1/π(x;q,b)) Σp≤x, p≡b (mod q) f(p+a) is asymptotic to Σp≤x g(p,1) / φ(q) log p, provided the level of distribution of the sequence {p+a} in arithmetic progressions reaches beyond x1/2. Under the Generalised Riemann Hypothesis (GRH) for Dirichlet L‑functions, the Bombieri–Vinogradov theorem gives level of distribution x1/2 (log x)−A, which is sufficient for a central limit theorem when f is strongly additive (g(p,α)=g(p)). The variance V(x) satisfies V(x) ∼ Σp≤x g(p)2 / φ(q) log p.

The proof combines the Turán–Kubilius inequality with the large sieve for primes in progressions. One first approximates f(p+a) by a truncated sum over primes ℓ ≤ y, where y = x1/2 (log x)−B. The contribution of large prime factors is shown to be negligible in L² using the Brun–Titchmarsh inequality. The truncated sum is a linear combination of indicator functions of the events ℓ | (p+a). By the Siegel–Walfisz theorem these events are equidistributed among the φ(q) reduced residue classes modulo qℓ, with an error term that is uniform in ℓ up to y. Applying the method of moments (or characteristic functions) yields convergence to a normal distribution with the stated mean and variance. The rate of convergence is O((log log x)−1/2) under GRH, matching the classical Erdős–Kac bound.

Unconditionally, the result holds for a restricted range of moduli q ≤ (log x)A by the classical Bombieri–Vinogradov theorem. For larger q one needs a level of distribution beyond the Siegel–Walfisz range; this is precisely the content of the Elliott–Halberstam conjecture. Recent work of Matomäki, Radziwiłł and Shao (2020) shows that for any fixed additive function f with bounded g, the Erdős–Kac theorem for shifted primes holds in almost all progressions q ≤ x1/2−ε, using a new “pretentious” large sieve. The method also gives a quantitative bound for the Kolmogorov distance between the distribution of (f(p+a)−M(x))/√V(x) and the standard normal law.

The Probabilistic Model for the Liouville Function and Its Correlations

The Liouville function λ(n) = (−1)Ω(n) is completely multiplicative and takes values ±1. Its partial sums L(x) = Σn≤x λ(n) are conjectured to satisfy L(x) = O(x1/2+ε) (the Liouville conjecture, equivalent to the Riemann hypothesis). A probabilistic model replaces λ(p) by independent Rademacher variables ε_p with P(ε_p = 1) = P(ε_p = −1) = 1/2, and defines λ_rand(n) = Πp^α‖n ε_p^α. This random multiplicative function has mean zero and covariance E[λ_rand(m) λ_rand(n)] = 1 if m=n, 0 otherwise. Consequently the random partial sums S_rand(x) = Σn≤x λ_rand(n) behave like a simple symmetric random walk with step variance 1, giving typical fluctuations of order √x.

Harper (2013) proved that the true Liouville function exhibits “pretentious” behaviour: it correlates with the character nit for some real t, which reduces its cancellation compared to the random model. The quantitative form is the Halász–Montgomery theorem: for any multiplicative f with |f|≤1, the mean value M_f(x) = (1/x) Σn≤x f(n) satisfies |M_f(x)| ≤ exp(−D(f, nit; x)2) + o(1), where D is the pretentious distance. For λ(n) the distance to nit is minimal at t=0, giving the bound M_λ(x) ≪ exp(−c √log log x). This is far larger than the random‑model prediction x−1/2, explaining why the Mertens conjecture (|L(x)| < √x) fails.

Correlations of λ at shifted arguments are modelled by E[λ_rand(n) λ_rand(n+h)] = 0 for h≠0, while the true correlations are the subject of the Chowla conjecture: Σn≤x λ(n) λ(n+h) = o(x) for every fixed h≠0. The random model predicts Gaussian fluctuations for the normalized correlation sums, and recent work of Tao (2016) and Matomäki–Radziwiłł–Tao (2015) established logarithmic averaging versions of Chowla using entropy decrement arguments combined with the probabilistic model. The model also predicts that the joint distribution of (λ(n+1), …, λ(n+k)) converges to the uniform distribution on {±1}^k, a statement known as the “local Chowla conjecture”. While unproven in full, these predictions guide the search for structural obstructions such as pretentious characters.

The Central Limit Theorem for the Number of Prime Divisors of Random Integers in Short Intervals

Let I = [x, x + y] with y = xθ, 0 < θ < 1. For a uniformly chosen integer n ∈ I, consider ω(n). The mean over I is μ_I = Σp≤x (1/p) + O(1) = log log x + O(1), and the variance is σ_I² = Σp≤x (1/p) + O(1) = log log x + O(1), provided y is not too small. The classical Erdős–Kac theorem corresponds to θ = 1 (the whole interval [1,x]). For short intervals one needs a level of distribution of the sequence {n mod p} for p up to x. Using the Barban–Davenport–Halberstam theorem, one obtains that for any fixed θ > 1/2 the Erdős–Kac theorem holds uniformly for almost all intervals of length y = xθ. The proof applies the Turán–Kubilius inequality to the additive function ω restricted to the interval, together with the large sieve to control the variance of the remainder terms.

When θ ≤ 1/2 the situation changes: the variance of ω(n) over a typical short interval is still ∼ log log x, but the distribution need not be Gaussian. In fact, for y = (log x)^A the values of ω(n) are essentially determined by the small prime factors, and the limiting distribution is a compound Poisson law (the Kubilius model with a truncated prime set). The transition from Poisson to Gaussian occurs around y = exp((log log x)1+ε). Precise results were obtained by Hildebrand (1987) and later refined by Granville and Soundararajan (2007) using the anatomy of integers. They showed that for y = xo(1) the distribution of ω(n) is given by the sum of independent Bernoulli variables with parameters 1/p for p ≤ y, plus a negligible error. This yields a Berry–Esseen bound of order (log log x)−1/2 when y ≥ exp((log log x)2+ε), and a Poisson approximation with explicit total variation distance for smaller y.

Applications include the study of the distribution of smooth numbers in short intervals, the normal order of the divisor function d(n) on short intervals, and the analysis of algorithms that factor integers by trial division up to xθ. The short‑interval Erdős–Kac theorem also implies that for any fixed ε > 0, the proportion of integers n ∈ [x, x + x1/2+ε] with |ω(n) − log log x| > ε √(log log x) tends to zero as x → ∞. This quantitative statement is essential in probabilistic algorithms that rely on the typical size of ω(n).

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Fixed Irreducible Divisor

When an integer polynomial f(n) possesses a fixed irreducible divisor d > 1, every value f(n) is divisible by d. This forces the additive function ω(f(n)) to contain the prime factors of d for all n. Consequently the mean of ω(f(n)) is shifted by the constant ω(d) and the variance acquires an extra term coming from the deterministic contribution of d. The classical Erdős–Kac theorem for polynomial values assumes that f has no fixed prime divisor; under that hypothesis the normalized additive function converges to a standard Gaussian. If a fixed divisor exists, the limiting distribution becomes a Gaussian with mean ω(d) and the same variance, provided the remaining prime factors behave independently. The proof adapts the Turán–Kubilius inequality by subtracting the deterministic part: one writes ω(f(n)) = ω(d) + ω(f(n)/d) and applies the inequality to the reduced polynomial f(n)/d, which now has no fixed divisor. The error terms are controlled by the large sieve for polynomials, and the characteristic function method yields convergence to the normal law with the shifted mean. This refinement is essential for applications where the polynomial naturally carries a fixed divisor, such as f(n) = n2 + 1 (which is always even) or f(n) = n(n+1) (always divisible by 2). In these cases the theorem predicts that the number of distinct prime factors of f(n) is normally distributed around log log n + ω(d) with variance log log n. The result also extends to additive functions weighted by the logarithm of the prime, giving a central limit theorem for log f(n) itself.

The Probabilistic Model for the Liouville Function on Polynomial Sequences

The Liouville function λ(n) = (−1)Ω(n) is completely multiplicative and takes values ±1. A probabilistic model replaces λ by a sequence of independent random variables λrand(n) with P(λrand(n) = 1) = P(λrand(n) = −1) = 1/2. For polynomial sequences f(n) the model predicts that the partial sums Sf(x) = Σn≤x λ(f(n)) behave like a random walk with step variance 1. Under the assumption that f has no fixed prime divisor and satisfies a suitable equidistribution condition modulo primes, one can prove that the variance of Sf(x) is ∼ x and that the normalized sum Sf(x)/√x converges in distribution to a standard normal law. The proof uses the method of moments: one expands the k-th moment of Sf(x) and shows that the main contribution comes from pairings of indices, exactly as in the Gaussian moment calculation. The Turán–Kubilius inequality for the additive function Ω(f(n)) provides the necessary control of correlations. When f has a fixed divisor, the model must be modified because λ(f(n)) is no longer symmetric; the deterministic factor λ(d) introduces a bias that shifts the mean of the limiting Gaussian. Recent work by Harper (2013) and others has established such central limit theorems for a wide class of polynomials, including irreducible quadratics and products of linear forms, under the Generalized Riemann Hypothesis for the relevant L‑functions. Unconditionally, one obtains Gaussian limits for polynomials of degree ≤ 2 using the Barban–Davenport–Halberstam theorem for polynomial progressions. The model also predicts that the joint distribution of (λ(f(n+1)), …, λ(f(n+k))) converges to the uniform distribution on {±1}k, a statement known as the local Chowla conjecture for polynomial sequences. While this remains open in general, it has been verified for linear polynomials under logarithmic averaging by Tao (2016) using entropy decrement arguments combined with the probabilistic model.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Given Discriminant

The discriminant Δ(f) of a polynomial f controls the splitting behavior of primes in the splitting field of f. For an irreducible polynomial of degree d, the Chebotarev density theorem implies that the proportion of primes p for which f splits completely is 1/|G|, where G is the Galois group. This directly affects the mean and variance of ω(f(n)): the sum Σ ρf(p)/p over p ≤ x equals (1/|G|) log log x + O(1) plus contributions from other conjugacy classes. Consequently the Erdős–Kac theorem for ω(f(n)) holds with mean and variance both ∼ (1/|G|) log log x. If the discriminant is a perfect square, the Galois group is a subgroup of the alternating group, and the splitting probabilities change accordingly. The proof uses the Turán–Kubilius inequality together with effective Chebotarev estimates under GRH, or unconditional zero‑density estimates for the relevant Artin L‑functions. For reducible polynomials, the discriminant factors into discriminants of the irreducible components, and the additive function ω(f(n)) decomposes into a sum of independent (asymptotically) contributions from each component. The joint distribution of the component counts is then multivariate normal with a covariance matrix determined by the shared prime factors. This refinement is crucial for problems where the polynomial is constructed to have a prescribed Galois group, such as in the study of Hilbert’s irreducibility theorem with quantitative error terms.

Moments of the Riemann Zeta Function and the Keating–Snaith Conjecture

The 2k‑th moment of the Riemann zeta function on the critical line, Ik(T) = ∫0T |ζ(1/2 + it)|2k dt, is a central object in probabilistic number theory. The probabilistic interpretation is that log |ζ(1/2 + it)| behaves like a Gaussian random variable with variance (1/2) log log T, and the moments arise from the exponential of a Gaussian field. The Selberg central limit theorem (1946) proves that the real and imaginary parts of log ζ(1/2 + it) are asymptotically independent normals with variance (1/2) log log T, which is consistent with the moment conjecture. Recent work by Harper (2013) and others has established upper bounds of the correct order for all k, and lower bounds for a dense set of k. The connection to probabilistic number theory is deep: the moments of ζ encode the distribution of values of multiplicative functions, and the Keating–Snaith conjecture implies precise asymptotics for the moments of the partial sums of the Möbius and Liouville functions. This circle of ideas also underlies the conjectural distribution of the maximum of |ζ(1/2 + it)| on intervals of length 1, which is predicted to be (1/√2) log log T + O(log log log T) by the branching random walk model of Fyodorov, Hiary, and Keating (2012).

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Prescribed Number of Irreducible Factors

When an additive function such as ω(f(n)) is restricted to integers n for which the polynomial f(n) splits into exactly r irreducible factors over ℚ, the classical Erdős–Kac theorem acquires a new scaling factor. The mean and variance of ω(f(n)) on this thin set are both asymptotic to (r/|G|) log log x, where G is the Galois group of the splitting field of f. The proof combines the Turán–Kubilius inequality with a sieve that isolates the condition “f(n) has exactly r irreducible factors”. The sieve introduces a multiplicative weight that is essentially the indicator of the property, and its mean value is handled by the Selberg–Delange method. The resulting Gaussian limit holds uniformly for r up to a small power of log log x; beyond that range the distribution transitions to a Poisson law because the number of prime factors becomes bounded. This refinement is essential for problems that count integers with a prescribed factorisation pattern, such as the distribution of almost‑prime values of polynomials.

The key technical step is to show that the contribution of primes p for which f mod p has a given splitting type is independent across different p, up to an error controlled by the large sieve. The independence follows from the Chebotarev density theorem applied to the compositum of the splitting fields of the irreducible factors. When r is fixed, the covariance between the counts of prime factors coming from distinct irreducible components vanishes in the limit, so the total ω(f(n)) is a sum of r asymptotically independent copies of the basic Erdős–Kac variable. Consequently the limiting normal distribution has variance r times the basic variance. If r grows with x, the Lindeberg condition must be checked carefully; the critical threshold is r ≈ (log log x)¹⁻ε, beyond which the central limit theorem fails and a different scaling appears.

Applications include the study of the number of prime factors of values of polynomials that are products of a fixed number of irreducible polynomials, and the distribution of the Liouville function on such sets. In examinations, a typical question asks to derive the mean and variance of ω(f(n)) under the condition that f(n) has exactly two irreducible factors, given the Galois group of each factor. The answer requires identifying the splitting probabilities for each factor and summing them, remembering that the fixed‑divisor condition may shift the mean by a constant.

The Distribution of the Number of Prime Factors of Values of Polynomials with a Given Galois Group and Ramification

The splitting behaviour of a polynomial f modulo primes is governed by the Galois group G of its splitting field and by the ramification of primes in that field. For an unramified prime p, the Frobenius conjugacy class in G determines the cycle type of the factorisation of f mod p, and hence the number of irreducible factors of f(n) modulo p. The Chebotarev density theorem asserts that each conjugacy class C ⊂ G occurs with natural density |C|/|G|. Therefore the mean contribution of a prime p to ω(f(n)) is ΣC (number of cycles in C) · |C|/|G|, which simplifies to 1/|G| times the sum of the number of cycles over all elements of G. This sum equals the number of orbits of G acting on the roots, which is exactly the number of irreducible factors of f over ℚ. Consequently the mean of ω(f(n)) is (number of irreducible factors / |G|) log log x + O(1). The variance has the same leading term because the contributions from distinct primes are asymptotically independent.

Ramified primes require separate treatment. A ramified prime p divides the discriminant Δ(f), and its factorisation pattern does not follow the Chebotarev equidistribution. However, there are only finitely many ramified primes, so their total contribution to the mean and variance is O(1). In quantitative versions of the Erdős–Kac theorem, the error term depends on the size of Δ(f) and on the quality of effective Chebotarev estimates. Under the Generalised Riemann Hypothesis for the Artin L‑functions attached to the irreducible representations of G, one obtains an error term O((log log x)¹ᐟ²⁺ε). Unconditionally, zero‑density estimates for these L‑functions give a weaker but still power‑saving error. The discriminant also influences the fixed‑divisor condition: if a prime p divides all values f(n), then p contributes a constant shift to ω(f(n)) and must be removed before applying the central limit theorem.

When the Galois group is a proper subgroup of the symmetric group, the splitting probabilities change. For example, if G is the alternating group A_d, only even permutations occur, so the proportion of primes with a given cycle type is either zero or twice the symmetric group proportion. This alters the mean and variance by a factor that depends on the cycle structure of elements of G. In examinations, a common task is to compute the mean of ω(f(n)) for a specific polynomial, say f(x)=x⁴+1, whose Galois group is the dihedral group of order 8. One must list the conjugacy classes, their cycle types on the four roots, and apply the Chebotarev densities. The result is a mean of (1/2) log log x + O(1), reflecting the fact that x⁴+1 splits into two quadratic factors on average.

Worked Example: Mean of ω(f(n)) for a Given Galois Group
Let f(x)=x⁴−2. Its splitting field has Galois group D₈ (dihedral of order 8). Determine the asymptotic mean of ω(f(n)) as n≤x.
The group D₈ acts on the four roots {±√[4]{2}, ±i√[4]{2}}. The conjugacy classes are: identity (1 element, cycle type 1⁴), rotation by 180° (1 element, cycle type 2²), two reflections across axes (2 elements, cycle type 2¹1²), and two reflections across diagonals (2 elements, cycle type 2²). The number of cycles for each class: 4, 2, 3, 2 respectively. The Chebotarev density gives probabilities 1/8, 1/8, 2/8, 2/8. The expected number of cycles per prime is (1/8)·4 + (1/8)·2 + (2/8)·3 + (2/8)·2 = (4+2+6+4)/8 = 16/8 = 2. Hence the mean of ω(f(n)) is (2/|G|) log log x = (2/8) log log x = (1/4) log log x + O(1).

The variance has the same leading coefficient. Remember to subtract any fixed prime divisor before stating the final answer.

The Probabilistic Model for the Liouville Function on Polynomial Sequences in Short Intervals

The Liouville function λ(n) = (−1)Ω(n) is a completely multiplicative function taking values ±1. Its behaviour on polynomial sequences f(n) in short intervals [x, x+y] with y = x^θ, θ < 1, is modelled by a random multiplicative function where each prime p is assigned an independent random sign with probability 1/2. This model predicts that the partial sums Σn≤x λ(f(n)) exhibit square‑root cancellation on average, and that the distribution of the normalised sum converges to a Gaussian with variance proportional to the length of the interval. However, rigorous results are scarce. The work of Matomäki and Radziwiłł on multiplicative functions in short intervals shows that for any 1‑bounded multiplicative function, the mean square of the sum over [x, x+y] is ≪ y² for y ≥ (log x)^A. For the Liouville function on polynomial values, one must also control the correlation between λ(f(n)) and λ(f(n+h)). The conjectural asymptotic for these correlations is given by the Chowla conjecture, which remains open even for linear polynomials.

In the probabilistic model, the values λ(f(n)) for n in a short interval are treated as a stationary Gaussian process with covariance determined by the probability that a prime p divides both f(n) and f(n+h). This probability is ρ_f(p; h)/p, where ρ_f(p; h) is the number of solutions to f(n) ≡ f(n+h) ≡ 0 (mod p). Summing over p gives the covariance kernel. The model predicts that the maximum of the partial sums on intervals of length y is of order √(y log log y), consistent with the law of the iterated logarithm for random multiplicative functions. Recent work by Harper and others has established upper bounds of the correct order for the moments of Σn≤x λ(f(n)) under the assumption of the Generalised Riemann Hypothesis for the relevant L‑functions. Unconditionally, one can only prove non‑trivial bounds for y larger than a power of log x.

Examination questions often ask to derive the predicted variance of Σx<n≤x+y</sub> λ(f(n)) using the probabilistic model. The answer requires computing Σp≤y ρ_f(p; h)/p for the relevant shifts h, and then integrating over h. A common trap is to forget that the model only gives a heuristic; rigorous statements must be qualified with “assuming the Chowla conjecture” or “under GRH”. Another trap is to apply the model to intervals shorter than (log x)^A, where the Poisson regime dominates and the Gaussian approximation fails.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Given Discriminant and Galois Group

The discriminant Δ(f) of a polynomial f encodes the ramification data of its splitting field. When both the discriminant and the Galois group G are prescribed, the splitting probabilities for primes are completely determined by the Chebotarev density theorem applied to the unique extension with those invariants. The mean of ω(f(n)) is then (1/|G|) Σg∈G c(g) log log x, where c(g) is the number of cycles of g acting on the roots. This sum equals the number of irreducible factors of f over ℚ, as noted earlier. The variance has the same leading term because the contributions from distinct primes are asymptotically independent. However, the discriminant influences the error term: effective Chebotarev under GRH gives an error O((log log x)¹ᐟ²⁺ε) with an implied constant depending polynomially on log |Δ(f)|. Unconditionally, the error depends on zero‑free regions for Artin L‑functions, which are weaker when the discriminant is large.

If the discriminant is a perfect square, the Galois group is a subgroup of the alternating group, and only even permutations occur. This changes the cycle‑type distribution: for example, transpositions (cycle type 2 1d−2) have density zero. Consequently the mean number of prime factors of f(n) may be smaller than in the generic symmetric group case. In the extreme case where G is cyclic, the polynomial is a composition of linear factors over some extension, and ω(f(n)) behaves like a sum of independent copies of ω(n) on arithmetic progressions. The Erdős–Kac theorem then reduces to the classical result for ω(n) in arithmetic progressions, with mean and variance (1/φ(q)) log log x for each progression.

Applications include the study of Hilbert’s irreducibility theorem with quantitative error terms: one counts polynomials with given Galois group and discriminant for which f(n) has a prescribed number of prime factors. The joint distribution of ω(f_i(n)) for several polynomials with the same splitting field is multivariate normal with a covariance matrix determined by the shared prime factors. In examinations, a typical problem gives a polynomial with discriminant Δ and Galois group G, and asks for the leading term of the variance of ω(f(n)). The solution is to compute the average number of cycles in G and divide by |G|. One must also check whether any prime divides all values f(n) (a fixed divisor), which would add a constant to the mean and must be subtracted before applying the central limit theorem.

The Central Limit Theorem for the Number of Prime Factors of Values of Polynomials in Short Intervals with a Fixed Congruence Condition

When the Erdős–Kac theorem is restricted to a short interval [x, x+y] with y = x^θ, 0 < θ < 1, and further to integers n satisfying a congruence condition n ≡ a (mod q), the limiting distribution depends critically on the size of y relative to log log x. If y ≥ exp((log log x)1+ε), the number of prime factors ω(f(n)) still satisfies a central limit theorem with mean and variance both ∼ (δ/|G|) log log x, where δ is the density of the congruence class in the set of n for which f(n) has no fixed prime divisor. The proof uses the Turán–Kubilius inequality on the short interval, together with a Siegel–Walfisz type theorem for the distribution of primes in arithmetic progressions to handle the congruence condition. The error term in the mean is O(1) uniformly for q ≤ (log x)^A.

If y is smaller, say y = (log x)^A, the distribution of ω(f(n)) converges to a Poisson law with parameter λ = (δ/|G|) log log x. The transition between the Gaussian and Poisson regimes occurs at y ≈ exp((log log x)1+ε). This phenomenon is well understood for the classical ω(n) and extends to polynomial values via the Kubilius model. The congruence condition modifies the parameter λ by a factor that is the product over p|q of (1 − ρ_f(p)/p)-1, where ρ_f(p) is the number of roots of f modulo p. If the congruence class a (mod q) forces a fixed prime divisor, the Poisson parameter may be zero, and the limit degenerates.

In examinations, a common question asks to state the limiting distribution of ω(f(n)) for n in [x, x+y] with n ≡ a (mod q), distinguishing the three regimes: y large (Gaussian), y intermediate (compound Poisson), y small (Poisson). The answer must specify the mean and variance in the Gaussian regime, the Poisson parameter in the small regime, and note that the congruence condition only affects the constant factor δ. A frequent trap is to assume the variance is exactly Σp≤y ρ_f(p)/p without the O(1) error; the error can be significant for small y and must be included in quantitative statements. Another trap is to ignore the possibility that the congruence class introduces a correlation between ω(f(n)) and ω(f(n+h)) that shifts the covariance matrix in the joint distribution.

  • Assuming the Erdős–Kac theorem holds for all polynomials without checking the fixed‑divisor condition; a fixed divisor changes the mean by a constant and can destroy the Gaussian limit.
  • Applying the probabilistic model for the Liouville function on polynomial sequences as a rigorous proof; the model only provides a heuristic, and unconditional results require GRH or strong level‑of‑distribution theorems.
  • Neglecting the transition scale y = exp((log log x)1+ε) when stating the short‑interval Erdős–Kac theorem for polynomial values; below this scale the limit is Poisson, not Gaussian.
  • Treating the variance of ω(f(n)) on a short interval as exactly Σ ρ_f(p)/p without the O(1) error; the error can be significant for small ranges and must be included in quantitative statements.
  • Assuming the joint distribution of ω(f(n)) and ω(f(n+h)) on a short interval is always bivariate normal; a common fixed prime divisor introduces correlation that shifts the covariance matrix.
  • Overlooking the role of the discriminant in determining the Galois group and hence the splitting probabilities; the mean and variance of ω(f(n)) depend on the Galois group, not just the degree.
  • Confusing the Keating–Snaith moment conjecture with a theorem; it remains a conjecture for k ≥ 3, though it is supported by extensive numerical evidence and random matrix theory.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Given Discriminant and a Fixed Divisor

Let f be a non‑constant polynomial with integer coefficients, discriminant Δ ≠ 0, and let d be a fixed divisor of f, i.e. an integer d > 1 such that d | f(n) for every integer n. For an additive function a(n) = Σp|n g(p) with bounded g, the classical Erdős–Kac theorem states that the normalized sum (a(n) – M(x))/√V(x) converges in distribution to a standard normal law, where M(x) and V(x) are the mean and variance of a(n) over n ≤ x. When n is restricted to values f(m) with m ≤ x, the mean becomes M_f(x) = Σp≤x g(p) ρ_f(p)/p + O(1), where ρ_f(p) is the number of roots of f modulo p. The presence of a fixed divisor d contributes an extra constant term Σp|d g(p) to the mean, because every value f(m) is automatically divisible by each prime factor of d. The variance V_f(x) = Σp≤x g(p)² ρ_f(p)/p + O(1) is unaffected by the fixed divisor, since the divisor does not introduce additional fluctuation. The proof follows the Kubilius model: one replaces the indicator of p | f(m) by independent Bernoulli variables with success probability ρ_f(p)/p, then applies the method of moments together with a Siegel–Walfisz estimate for primes in the arithmetic progressions determined by the splitting field of f. The discriminant Δ enters through the Chebotarev density theorem, which gives the average of ρ_f(p) as the proportion of elements of the Galois group G fixing a root; this proportion equals the number of cycles of length one in the permutation representation of G on the roots. Consequently the leading term of the mean is (c_G/|G|) log log x, where c_G is the average number of fixed points, and the fixed divisor adds the constant Σp|d g(p). The error term O(1) is uniform for all polynomials with bounded degree and discriminant, provided the fixed divisor is taken into account before centering.

In examinations a typical question asks for the limiting distribution of ω(f(n)) where f has discriminant Δ and a fixed divisor d. The answer is that (ω(f(n)) – (c_G/|G|) log log x – Σp|d 1)/√((c_G/|G|) log log x) converges to N(0,1). One must explicitly subtract the contribution of the fixed divisor from the mean; forgetting this step is a common error that shifts the centering by a constant and destroys the Gaussian limit. The variance does not contain the fixed‑divisor term, so the normalisation uses only the logarithmic variance. The proof also requires checking that f has no other systematic congruence obstructions; if a prime p divides all values f(n) for n in a certain residue class, that prime must be treated as part of the fixed divisor for that subsequence.

The result extends to any additive function with bounded values, for example the sum of reciprocals of prime divisors Σp|n 1/p. In that case g(p)=1/p, the mean becomes Σp≤x ρ_f(p)/p² + O(1) and the variance Σp≤x ρ_f(p)/p² + O(1); both converge to finite constants, so the limiting distribution is degenerate. The non‑degenerate Gaussian regime appears only when Σ g(p)² ρ_f(p)/p diverges, which for ω corresponds to g(p)=1. The discriminant influences the constant c_G/|G|, while the fixed divisor influences only the additive constant in the mean. This separation of effects is a key structural feature that examiners often test by asking to identify which part of the asymptotic formula depends on Δ and which part depends on d.

The Distribution of the Number of Prime Factors of Values of Polynomials with a Given Discriminant and a Fixed Divisor

For a polynomial f with discriminant Δ and fixed divisor d, the random variable ω(f(n)) counts the total number of prime factors of f(n) with multiplicity. The normal order of ω(f(n)) is (c_G/|G|) log log n + Σp|d 1, where c_G/|G| is the average number of fixed points of the Galois group G acting on the roots of f. This follows from the Turán–Kubilius inequality applied to the additive function ω on the sequence f(1), f(2), …, f(x). The inequality gives Σn≤x |ω(f(n)) – M_f(x)|² ≤ C x V_f(x) for an absolute constant C, where M_f(x) and V_f(x) are the mean and variance defined in the previous section. Because V_f(x) ∼ (c_G/|G|) log log x, Chebyshev’s inequality shows that for any ε > 0 the proportion of n ≤ x with |ω(f(n)) – M_f(x)| > ε √V_f(x) tends to zero. Hence ω(f(n)) has normal order M_f(x). The fixed divisor contributes exactly the number of distinct prime factors of d, each counted once, because every value f(n) is divisible by those primes. If d contains a prime power p^k, the contribution to ω is still 1, not k, since ω counts distinct primes. The discriminant Δ influences the constant c_G/|G| through the Chebotarev density theorem: the density of primes p for which f has a root modulo p equals the proportion of elements of G that fix at least one root. This proportion is exactly the average number of cycles of length one in the permutation representation of G, which can be computed from the cycle type distribution of G.

Quantitative refinements of the Turán–Kubilius inequality give an explicit error term O(x (log log x)1/2) for the second moment, which translates into a rate of convergence in the normal order statement. In particular, for any function ψ(x) → ∞, the set of n ≤ x with |ω(f(n)) – M_f(x)| > ψ(x) √V_f(x) has size o(x). This is the analogue of the Hardy–Ramanujan theorem for polynomial values. The proof uses the large sieve to control correlations between the events p | f(n) and q | f(n) for distinct primes p, q. The discriminant enters the large‑sieve constant through the degree of the splitting field, while the fixed divisor only affects the mean and does not enlarge the variance. Consequently the normal order is robust under the addition or removal of a fixed divisor, provided the mean is adjusted accordingly.

In examination problems one often encounters a concrete polynomial such as f(n) = n² + 1, which has discriminant Δ = –4 and no fixed divisor (since n²+1 is odd for all n). The Galois group is cyclic of order 2, so c_G/|G| = 1/2. The normal order of ω(n²+1) is therefore (1/2) log log n. If the polynomial is f(n) = n(n+1), the discriminant is 1 and the fixed divisor is 2 (because one of n, n+1 is even). The Galois group is trivial, so c_G/|G| = 1, and the normal order becomes log log n + 1. A frequent trap is to forget the +1 coming from the fixed divisor 2, leading to an off‑by‑constant error in the centering. Another trap is to treat the discriminant as the only invariant; the fixed divisor must be computed separately, for instance by evaluating the content of f over ℤ. The normal order statement does not require the full Erdős–Kac theorem; it follows directly from the Turán–Kubilius inequality and is therefore easier to prove and to apply in short‑answer questions.

Worked Example
Let f(n) = n³ – n. Determine the normal order of ω(f(n)) and the leading constant in the Erdős–Kac theorem for ω(f(n)).
The polynomial factors as f(n) = n(n–1)(n+1). Its discriminant is Δ = 4 (non‑zero). The fixed divisor is the greatest common divisor of all values f(n); evaluating at n = 0,1,2 gives f(0)=0, f(1)=0, f(2)=6, so the fixed divisor is 6 = 2·3. The Galois group of f is trivial because f splits completely over ℚ; hence |G| = 1 and every element fixes all three roots, so the average number of fixed points c_G = 3. Therefore c_G/|G| = 3. The mean of ω(f(n)) is M_f(x) = 3 log log x + ω(6) + O(1) = 3 log log x + 2 + O(1). The variance is V_f(x) = 3 log log x + O(1). By the Erdős–Kac theorem, (ω(f(n)) – 3 log log x – 2)/√(3 log log x) converges in distribution to N(0,1). The normal order is 3 log log n + 2.
Exam‑Day Strategy
When a polynomial is given, first factor it over ℤ to read off the fixed divisor (the gcd of all values). Then determine the Galois group of the splitting field; for fully split polynomials the group is trivial, giving c_G/|G| equal to the number of irreducible factors. Use the Chebotarev density only when the polynomial is irreducible or has a non‑trivial Galois group. Remember that the fixed divisor contributes an additive constant to the mean but does not affect the variance. Write the final normal order as (c_G/|G|) log log n + ω(d) where d is the fixed divisor.

The Probabilistic Model for the Möbius Function on Polynomial Sequences with a Given Discriminant and a Fixed Divisor

The Möbius function μ(n) is multiplicative and takes values –1, 0, 1. On a polynomial sequence f(n) with discriminant Δ and fixed divisor d, the values μ(f(n)) are not independent, but the Kubilius probabilistic model replaces the indicator of p² | f(n) by independent Bernoulli variables with probability ρ_f(p²)/p², where ρ_f(p²) counts solutions of f(x) ≡ 0 (mod p²). For primes p ∤ d, the probability that p divides f(n) exactly once is ρ_f(p)/p – ρ_f(p²)/p², and the probability that p² divides f(n) is ρ_f(p²)/p². The fixed divisor d forces μ(f(n)) = 0 whenever a prime factor of d appears with exponent ≥ 2 in f(n); if d is square‑free, μ(f(n)) is simply multiplied by (–1)ω(d) for all n. The model predicts that the mean of μ(f(n)) is ∏p (1 – ρ_f(p)/p) times a correction factor for the fixed divisor, and that the variance is of order 1/√log log x after appropriate normalisation. Rigorous results require a level of distribution for the sequence f(n) in arithmetic progressions; the Bombieri–Vinogradov theorem for polynomial sequences (proved by Huxley and later refined) gives the necessary estimate for moduli up to x1/2–ε. The discriminant Δ controls the degree of the splitting field and therefore the size of the error term in the Bombieri–Vinogradov theorem. The fixed divisor only changes the Euler product by a finite factor and does not affect the asymptotic variance. Under the Generalised Riemann Hypothesis for the Dedekind zeta function of the splitting field, one obtains a central limit theorem for the partial sums Σn≤x μ(f(n)) with Gaussian fluctuations of size √x. Unconditionally, one can prove a law of the iterated logarithm for the normalised sums, showing that the limsup of the normalised sum is a constant depending on the Euler product.

In examinations the probabilistic model is often used as a heuristic to guess the correct asymptotic formula for Σn≤x μ(f(n)). A typical question asks to write down the predicted main term using the Euler product ∏p (1 – ρ_f(p)/p) and to explain why the fixed divisor contributes a factor (–1)ω(d) if d is square‑free. The rigorous justification requires citing the Bombieri–Vinogradov theorem for polynomial sequences and noting that the error term is o(x) for moduli up to x1/2–ε. A common trap is to apply the model for μ on polynomial sequences as if it were a theorem; the model only provides a conjecture unless GRH or a strong level‑of‑distribution result is assumed. Another trap is to ignore the contribution of primes dividing the discriminant, which may have ρ_f(p) > degree(f) because of ramification; these primes must be treated separately in the Euler product.

The connection with random matrix theory appears when one studies the moments of the partial sums of μ(f(n)). The Keating–Snaith conjecture predicts that the 2k‑th moment of Σn≤x μ(f(n)) is asymptotic to a constant times x (log x)k(k–1) where the constant is expressed in terms of the Barnes G‑function and the Euler product. This conjecture has been verified for k = 1,2 under GRH, but remains open for higher moments. The discriminant enters the constant through the Euler product, while the fixed divisor contributes only a finite multiplicative factor. In short‑answer questions, examiners may ask to state the conjectural moment formula and to identify which part depends on Δ and which part depends on d.

The Central Limit Theorem for the Number of Prime Factors of Values of Polynomials in Short Intervals with a Given Discriminant and a Fixed Divisor

Let f be a polynomial with discriminant Δ and fixed divisor d. For a short interval [x, x+y] with y = x^θ, 0 < θ ≤ 1, consider the additive function ω(f(n)). The Turán–Kubilius inequality on the short interval gives Σx<n≤x+y</sub> |ω(f(n)) – M_f(x,y)|² ≤ C y V_f(x,y), where M_f(x,y) = Σp≤y ρ_f(p)/p + Σp|d 1 + O(1) and V_f(x,y) = Σp≤y ρ_f(p)/p + O(1). The discriminant influences ρ_f(p) through the Chebotarev density theorem as before. If y ≥ exp((log log x)1+ε), the variance V_f(x,y) → ∞ and the central limit theorem holds: (ω(f(n)) – M_f(x,y))/√V_f(x,y) converges to N(0,1) uniformly for n in the interval. The proof uses the method of moments together with a Siegel–Walfisz type theorem for primes in arithmetic progressions to handle the congruence conditions imposed by the splitting field of f. The error term in the mean is O(1) uniformly for moduli q ≤ (log x)^A. If y is smaller, say y = (log x)^A, the variance stays bounded and the limiting distribution is Poisson with parameter λ = Σp≤y ρ_f(p)/p + Σp|d 1. The transition between the Gaussian and Poisson regimes occurs at y ≈ exp((log log x)1+ε). The fixed divisor adds the constant Σp|d 1 to the Poisson parameter but does not affect the Gaussian variance. In the intermediate range y = exp((log log x)1+o(1)) the limit is a compound Poisson distribution whose characteristic function can be written explicitly in terms of the limiting frequencies of prime divisors.

Examination questions often ask to distinguish the three regimes and to write down the limiting distribution in each case. The answer must specify the mean and variance in the Gaussian regime, the Poisson parameter in the small‑y regime, and note that the congruence condition (if n is restricted to a residue class a mod q) only modifies the constant factor δ = ∏p|q (1 – ρ_f(p)/p)-1. A frequent trap is to assume the variance is exactly Σp≤y ρ_f(p)/p without the O(1) error; for small y this error can be comparable to the main term and must be included in quantitative statements. Another trap is to ignore the possibility that the fixed divisor forces a prime to divide every value in the interval, which would make the Poisson parameter zero and the limit degenerate. The discriminant enters the constant c_G/|G| in the Gaussian mean and variance, while the fixed divisor enters only as an additive constant in the mean and as an additive term in the Poisson parameter. The proof of the Gaussian regime uses the Kubilius model with independent Bernoulli variables for primes p ≤ y, together with a large‑sieve estimate to control correlations; the discriminant determines the degree of the splitting field and thus the large‑sieve constant.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Given Galois Group and a Fixed Divisor

Let f be a polynomial with Galois group G (acting on the roots) and fixed divisor d. For an additive function a(n) = Σp|n g(p) with bounded g, the Erdős–Kac theorem states that the normalized sum (a(f(n)) – M_f(x))/√V_f(x) converges to a standard normal distribution, where M_f(x) = Σp≤x g(p) ρ_f(p)/p + Σp|d g(p) + O(1) and V_f(x) = Σp≤x g(p)² ρ_f(p)/p + O(1). The average of ρ_f(p) over primes is given by the Chebotarev density theorem: it equals the proportion of elements of G that fix a root, i.e. the average number of cycles of length one in the permutation representation of G. This proportion is c_G/|G| where c_G = Σσ∈G fix(σ). Consequently the leading term of the mean is (c_G/|G|) Σp≤x g(p)/p and the leading term of the variance is (c_G/|G|) Σp≤x g(p)²/p. The fixed divisor contributes the additive constant Σp|d g(p) to the mean but does not appear in the variance. The proof follows the method of moments: one expands the k‑th moment of the normalized sum, replaces the indicators of p | f(n) by independent Bernoulli variables with success probability ρ_f(p)/p, and shows that the error introduced by this replacement is negligible using the large sieve and the Bombieri–Vinogradov theorem for the splitting field of f. The discriminant Δ influences the degree of the splitting field and therefore the range of moduli for which the Bombieri–Vinogradov theorem is available; the fixed divisor only changes the mean by a constant and does not affect the error terms.

In examinations a typical problem gives a polynomial with a specified Galois group (for example, the symmetric group S₃) and a fixed divisor (for example, 2). The student must compute c_G/|G| from the cycle structure of G. For S₃ acting on three roots, the cycle types are: identity (3 fixed points), three transpositions (1 fixed point each), two 3‑cycles (0 fixed points). The average number of fixed points is (3 + 3·1 + 2·0)/6 = 1. Hence c_G/|G| = 1. The mean of ω(f(n)) is then log log x + ω(2) + O(1) = log log x + 1 + O(1). The variance is log log x + O(1). The Erdős–Kac theorem yields (ω(f(n)) – log log x – 1)/√(log log x) → N(0,1). A common trap is to confuse the number of irreducible factors of f with the average number of fixed points; for S₃ the polynomial is irreducible, yet the average number of fixed points is 1, not 3. Another trap is to forget to subtract the fixed‑divisor contribution before normalising; the centering must be M_f(x) = log log x + 1, not log log x. The theorem also requires that f has no other systematic congruence obstructions; if a prime p divides f(n) for all n in a certain residue class, that prime must be incorporated into the fixed divisor for that subsequence.

The result extends to joint distributions of several additive functions a₁(f₁(n)), …, a_k(f_k(n)) where the polynomials share the same splitting field. The covariance matrix is determined by the shared prime factors and the Galois group action on the combined set of roots. The fixed divisors of the individual polynomials add constants to the respective means but do not affect the covariance matrix. In short‑answer questions, examiners may ask to write down the covariance between ω(f₁(n)) and ω(f₂(n)) in terms of the proportion of primes that split completely in both splitting fields. The answer is (cG₁,G₂/|G|) log log x where cG₁,G₂ is the average number of simultaneous fixed points of the two permutation representations. The discriminant of the compositum of the splitting fields controls the error term in the Bombieri–Vinogradov theorem used in the proof.

  • Assuming the Erdős–Kac theorem holds for all polynomials without checking the fixed‑divisor condition; a fixed divisor changes the mean by a constant and can destroy the Gaussian limit.
  • Applying the probabilistic model for the Möbius function on polynomial sequences as a rigorous proof; the model only provides a heuristic, and unconditional results require GRH or strong level‑of‑distribution theorems.
  • Neglecting the transition scale y = exp((log log x)1+ε) when stating the short‑interval Erdős–Kac theorem for polynomial values; below this scale the limit is Poisson, not Gaussian.
  • Treating the variance of ω(f(n)) on a short interval as exactly Σ ρ_f(p)/p without the O(1) error; the error can be significant for small ranges and must be included in quantitative statements.
  • Assuming the joint distribution of ω(f₁(n)) and ω(f₂(n)) on a short interval is always bivariate normal; a common fixed prime divisor introduces correlation that shifts the covariance matrix.
  • Overlooking the role of the discriminant in determining the Galois group and hence the splitting probabilities; the mean and variance of ω(f(n)) depend on the Galois group, not just the degree.
  • Confusing the Keating–Snaith moment conjecture with a theorem; it remains a conjecture for k ≥ 3, though it is supported by extensive numerical evidence and random matrix theory.

The Law of the Iterated Logarithm for Additive Functions on Polynomial Values

The classical law of the iterated logarithm (LIL) for the additive function ω(n) — the number of distinct prime factors of n — states that

lim supn→∞ (ω(n) − log log n) / √(2 log log n log log log n) = 1

almost surely with respect to the natural density. This result, first proved by Erdős and Kac in the context of the central limit theorem and later refined by Khinchin for independent random variables, was extended to polynomial sequences by Hildebrand (1986) and by Elliott (1990). For a polynomial f ∈ ℤ[x] of degree d ≥ 1 without a fixed prime divisor, the LIL holds for ω(f(n)) with the same normalising factor √(2 log log n log log log n), provided f is not a perfect power of another polynomial. The proof uses the Kubilius probabilistic model together with a sharp form of the Turán–Kubilius inequality on short intervals, and it requires a level of distribution for the sequence f(n) modulo primes that follows from the Bombieri–Vinogradov theorem for the splitting field of f. If f has a fixed divisor D, the centering term becomes log log n + ω(D) and the LIL remains valid after this shift. A common trap is to assume the LIL holds for any polynomial; counterexamples exist when f(n) = g(n)², because then ω(f(n)) = ω(g(n)) and the variance is halved, destroying the √(2 log log n log log log n) scaling.

Quantitative versions give explicit error terms: for any ε > 0, the set of n ≤ x for which

|ω(f(n)) − log log n| > (1 + ε) √(2 log log n log log log n)

has density zero, while the set where the inequality holds with (1 − ε) has density one. These bounds are essential in applications to the distribution of smooth values of polynomials and to the study of the largest prime factor of f(n). The method of moments, combined with a careful treatment of the contribution of large prime factors via the Selberg–Delange method, yields the LIL for a wide class of additive functions, including the sum of reciprocals of prime divisors and the logarithm of the radical of f(n).

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials over Number Fields

Let K be a number field of degree r over ℚ with ring of integers 𝒪K. For an ideal 𝔞 ⊂ 𝒪K, define ΩK(𝔞) as the total number of prime ideal factors counted with multiplicity, and ωK(𝔞) as the number of distinct prime ideal factors. The Erdős–Kac theorem in this setting, proved by Knobloch (1975) and later by Billingsley (1977) using the method of moments, asserts that for any fixed non‑zero ideal 𝔟, the normalized random variable

(ωK(𝔞) − log log N(𝔞)) / √(log log N(𝔞))

converges in distribution to the standard Gaussian as N(𝔞) → ∞, where N(𝔞) denotes the absolute norm. The mean and variance are both log log N(𝔞) + O(1), the implicit constant depending only on K. The proof replaces the indicator of a prime ideal dividing 𝔞 by independent Bernoulli variables with success probability 1/N(𝔭), and controls the error via the Chebotarev density theorem for the Hilbert class field of K. A crucial point is that the contribution of ramified primes is absorbed into the O(1) term; they do not affect the limiting distribution. For additive functions of the form f(𝔞) = Σ𝔭|𝔞 g(𝔭) with g bounded, the same Gaussian limit holds provided the mean ΣN(𝔭)≤x g(𝔭)/N(𝔭) and variance ΣN(𝔭)≤x g(𝔭)²/N(𝔭) both tend to infinity. The theorem also extends to polynomial values f(α) with α ∈ 𝒪K, where the norm is taken relative to the field generated by the coefficients of f. In examinations, a typical question asks to compute the limiting variance for ωK(𝔞) when K = ℚ(i); the answer is log log x because the prime ideals split into two types (inert, split, ramified) but the Chebotarev density gives equal weight 1/2 to the split primes, reproducing the rational case.

Worked Example
Let K = ℚ(√−5) and consider the additive function ωK(𝔞) on ideals of 𝒪K. Show that the Erdős–Kac theorem holds and identify the centering constant.
The field K has discriminant −20 and class number 2. The Chebotarev density theorem for the Hilbert class field (which is K itself because the class group is of order 2) gives that the set of prime ideals of degree 1 has natural density 1/2. The mean of ωK(𝔞) for N(𝔞) ≤ x is ΣN(𝔭)≤x 1/N(𝔭) = log log x + MK + o(1), where MK is a constant depending on the residue of the Dedekind zeta function at s = 1. The variance equals the same sum because the indicators are asymptotically independent. Hence (ωK(𝔞) − log log N(𝔞)) / √(log log N(𝔞)) → N(0,1). The centering constant is log log N(𝔞); no extra term from the class group appears because the fixed divisor of the norm form is trivial.
Exam‑day strategy
When a problem asks for the Erdős–Kac theorem over a number field, first write down the mean and variance as sums over prime ideals. Use the Chebotarev density theorem to evaluate the leading term log log x. Remember that ramified primes contribute only to the O(1) constant. If the field has non‑trivial class group, check whether the norm form has a fixed divisor; if it does, add the corresponding ω(D) to the centering term.

The Probabilistic Model for the Möbius Function on Polynomial Sequences over Function Fields with Prescribed Genus

Let 𝔽q be a finite field and consider the ring 𝔽q[t] of polynomials. For a polynomial f ∈ 𝔽q[t] of degree n, the Möbius function μ(f) is defined as (−1)k if f is square‑free with k irreducible factors, and 0 otherwise. Keating and Rudnick (2014) introduced a probabilistic model in which the irreducible factors of a random polynomial of degree n are approximated by independent random variables whose degrees follow the distribution of cycle lengths in a uniformly random permutation of n elements. The genus g of the associated hyperelliptic curve y² = f(t) (or more generally the curve defined by f) enters the model through the error term in the prime polynomial theorem: the number of irreducible polynomials of degree d is qd/d + O(qd/2). The Riemann hypothesis for function fields (Weil bounds) gives the square‑root cancellation that makes the model accurate up to an error of order q−n/2. For a fixed genus g, the variance of the sum Σdeg f = n μ(f) is asymptotically qn / ζ𝔽q[t](2) = qn (1 − 1/q), and the central limit theorem holds for the normalized sum. When the genus grows with n, the error terms from the Weil bounds become larger, and the Gaussian limit may break down; this is the regime where the model predicts a transition to a Poisson distribution for the number of irreducible factors of bounded degree. The model also explains the observed correlations of μ(f) over short intervals: for an interval of length qh with h < n/2, the covariance structure matches that of the random permutation model, while for h > n/2 the correlations decay because the interval contains polynomials with different factorisation patterns. In examinations, a typical question asks to compute the expected value of μ(f)² over all monic polynomials of degree n; the answer is 1 − 1/q, derived from the probability that a random polynomial is square‑free.

The Distribution of Additive Functions on Values of Polynomials in Arithmetic Progressions with a Prescribed Modulus

Let f ∈ ℤ[x] be a polynomial of degree d ≥ 1 without a fixed prime divisor, and let q be a positive integer. Consider the additive function ω(f(n)) restricted to n ≡ a (mod q) with (a,q) = 1. Elliott (1979) proved that the Erdős–Kac theorem holds uniformly for all moduli q ≤ (log x)A for any fixed A > 0, with mean and variance given by

Mf,q,a(x) = Σp≤x, p∤q ρf,q,a(p)/p + O(1),

Vf,q,a(x) = Σp≤x, p∤q ρf,q,a(p)/p + O(1),

where ρf,q,a(p) is the number of solutions to f(n) ≡ 0 (mod p) with n ≡ a (mod q). The condition p ∤ q ensures that the progression does not introduce extra congruence obstructions. The proof uses the Barban–Davenport–Halberstam theorem to control the error when replacing the indicator of p | f(n) by its average over the progression. For larger moduli, q up to xθ with θ < 1/2, the theorem still holds under the Generalised Riemann Hypothesis for the Dedekind zeta functions of the splitting fields of f. A common trap is to forget that the fixed divisor of f on the progression may differ from the global fixed divisor; for example, f(n) = n² + 1 has no fixed divisor over ℤ, but on the progression n ≡ 1 (mod 2) it is always even, so the fixed divisor becomes 2 and the mean shifts by 1. The joint distribution of ω(f(n)) for several progressions with the same modulus is multivariate normal with covariance matrix determined by the shared prime factors. This result is a key ingredient in the proof of the Erdős–Kac theorem for polynomial values in short intervals, because a short interval can be partitioned into a bounded number of arithmetic progressions with a small modulus.

  • Assuming the law of the iterated logarithm holds for any polynomial without checking the fixed‑divisor condition; a fixed divisor changes the centering constant and can alter the limsup scaling.
  • Confusing the mean of ωK(𝔞) over a number field with the rational mean log log x; the constant MK depends on the residue of the Dedekind zeta function and must be included in quantitative statements.
  • Treating the probabilistic model for the Möbius function on function fields as exact for all genera; the Weil bounds only guarantee square‑root error, and the model fails when the genus grows faster than √n.
  • Overlooking the progression‑dependent fixed divisor when applying the Erdős–Kac theorem in arithmetic progressions; the centering term must incorporate ω(Dq,a) where Dq,a is the fixed divisor on that progression.
  • Applying the Barban–Davenport–Halberstam theorem beyond its range of validity (q > x1/2) without assuming GRH; the unconditional result requires q ≤ (log x)A.
  • Neglecting the contribution of ramified primes in the number‑field Erdős–Kac theorem; they affect the O(1) constant but not the leading log log x term.
  • Assuming the central limit theorem for μ(f) on function fields holds for intervals of length qh with h > n/2; the covariance structure changes and the limit is no longer Gaussian.

The Probabilistic Model for the Liouville Function on Polynomial Sequences over Function Fields

Let 𝔽q be a finite field and consider the ring 𝔽q[t] of polynomials. For a monic polynomial f ∈ 𝔽q[t] of degree n, the Liouville function λ(f) is defined as (−1)Ω(f), where Ω(f) counts irreducible factors with multiplicity. The probabilistic model developed by Keating, Rudnick, and others replaces the factorisation of a random polynomial of degree n by a random permutation of n elements: each irreducible factor of degree d corresponds to a cycle of length d. Under this model the values λ(f) behave like the product of independent random signs attached to the cycles. The expected value of λ(f) over all monic polynomials of degree n is zero for n ≥ 1, while the second moment equals the probability that a random polynomial is square‑free, which is 1 − 1/q. Higher moments are controlled by the cycle structure of a uniform permutation; for fixed k the k‑th moment converges to the k‑th moment of a Rademacher product as n → ∞. The error terms come from the Weil bounds for the number of irreducible polynomials of degree d: πq(d) = qd/d + O(qd/2). This square‑root cancellation guarantees that the model is accurate up to an error of order q−n/2. When the genus g of the associated hyperelliptic curve y2 = f(t) grows with n, the Weil error term becomes larger and the Gaussian approximation for the partial sums Σdeg f = n λ(f) may break down, leading to a Poisson regime for the number of irreducible factors of bounded degree. In examinations, a typical question asks to compute the variance of the sum of λ(f) over all monic polynomials of degree n; the answer is qn(1 − 1/q), derived from the square‑free probability and the independence of signs in the permutation model.

The Central Limit Theorem for the Number of Prime Factors of Values of Polynomials in Short Intervals with a Given Galois Group

Let f ∈ ℤ[x] be an irreducible polynomial of degree d ≥ 2 with Galois group G. For a large parameter x and a short interval length h = h(x) satisfying (log x)A ≤ h ≤ xθ with θ < 1/2, consider the additive function ω(f(n)) restricted to n ∈ (x, x + h]. The Erdős–Kac theorem in short intervals, proved by Harper (2013) and refined by Lamzouri, Lester, and Radziwiłł, states that the distribution of (ω(f(n)) − Mf(x, h)) / √Vf(x, h) converges to the standard normal law, where the mean and variance are given by sums over primes p ≤ x of the local densities ρf(p)/p. The Galois group G enters through the Chebotarev density theorem: for each conjugacy class C ⊂ G, the set of primes with Frobenius in C has natural density |C|/|G|. The local density ρf(p) equals the number of roots of f modulo p, which is exactly the number of fixed points of the Frobenius element acting on the roots. Hence the mean Mf(x, h) = (|Fix(G)|/|G|) log log x + O(1) and the variance Vf(x, h) = (|Fix(G)|/|G|) log log x + O(1), where |Fix(G)| is the average number of fixed points of elements of G. The proof uses a truncated Turán–Kubilius inequality on the short interval together with a zero‑density estimate for Dirichlet L‑functions to control the error when replacing the indicator of p | f(n) by its average. The condition h ≥ (log x)A ensures that the interval contains enough integers for the probabilistic approximation to hold; for smaller h the distribution is governed by Poisson statistics. In examinations, a common problem asks to compute the limiting mean and variance for f(x) = x3 − 2, whose Galois group is S3. The average number of fixed points in S3 is 1, so both mean and variance are log log x + O(1).

Worked Example: Galois Group S3 and Short‑Interval CLT
Let f(x) = x3 − 2. Determine the asymptotic mean and variance of ω(f(n)) for n ∈ (x, x + h] with h = (log x)10. Explain why the central limit theorem applies.
The polynomial f is irreducible with discriminant −108, so its Galois group is S3. The conjugacy classes of S3 are: identity (size 1, 3 fixed points), three transpositions (size 3, 1 fixed point each), two 3‑cycles (size 2, 0 fixed points). The average number of fixed points is (1·3 + 3·1 + 2·0)/6 = 1. By Chebotarev, the density of primes with a given splitting type equals the proportion of the corresponding conjugacy class. Hence the local density ρf(p) equals the number of roots of f modulo p, which matches the fixed‑point count. Summing ρf(p)/p over p ≤ x gives (1) log log x + O(1). Therefore Mf(x, h) = log log x + O(1) and Vf(x, h) = log log x + O(1). The interval length h = (log x)10 satisfies the lower bound (log x)A for any fixed A, so the Harper–Lamzouri–Lester–Radziwiłł theorem applies and the normalized ω(f(n)) converges in distribution to N(0,1).
Exam‑Day Strategy
When a question asks for the mean and variance of ω(f(n)) in short intervals, first identify the Galois group of f. Compute the average number of fixed points of that group; this number is the constant multiplying log log x in both the mean and the variance. Check that the interval length h satisfies the required lower bound (usually a power of log x). If h is smaller, the limit is Poisson, not Gaussian. Remember that the O(1) term may depend on the discriminant and on ramified primes, but it never affects the leading log log x coefficient.

The Distribution of Additive Functions on Values of Polynomials in Arithmetic Progressions with a Prescribed Modulus and a Fixed Divisor

Let f ∈ ℤ[x] be a polynomial of degree d ≥ 1 without a fixed prime divisor over ℤ, and let q be a positive integer. Consider the additive function ω(f(n)) restricted to n ≡ a (mod q) with (a, q) = 1. Suppose further that f has a fixed divisor Dq,a on this progression, i.e. Dq,a = gcd{f(n) : n ≡ a (mod q)} > 1. Elliott (1979) proved the Erdős–Kac theorem uniformly for all moduli q ≤ (log x)A with mean and variance given by Mf,q,a(x) = Σp≤x, p∤q ρf,q,a(p)/p + ω(Dq,a) + O(1) and Vf,q,a(x) = Σp≤x, p∤q ρf,q,a(p)/p + O(1), where ρf,q,a(p) counts solutions to f(n) ≡ 0 (mod p) with n ≡ a (mod q). The term ω(Dq,a) appears because every value f(n) in the progression is automatically divisible by the primes dividing Dq,a; these primes contribute a deterministic shift to the centering but do not affect the variance. The proof uses the Barban–Davenport–Halberstam theorem to replace the indicator of p | f(n) by its average over the progression, and the condition p ∤ q ensures that the progression does not introduce extra congruence obstructions. For larger moduli, q up to xθ with θ < 1/2, the result holds conditionally on the Generalised Riemann Hypothesis. In examinations, a typical question gives f(x) = x2 + 1, q = 4, a = 1. The fixed divisor on this progression is D4,1 = 2 because x2 + 1 is always even for odd x. The mean becomes Σp≤x, p≠2 ρ(p)/p + 1 + O(1) where ρ(p) = 1 + (−1/p) is the number of roots of x2 + 1 modulo p. The variance lacks the +1 term. Students must remember to add ω(Dq,a) to the centering constant but not to the variance.

The Law of the Iterated Logarithm for Additive Functions on Polynomial Values over Function Fields

Let 𝔽q be a finite field and f ∈ 𝔽q[t] a polynomial of degree n. For an additive function A(f) = ΣP|f g(P) where the sum runs over monic irreducible divisors P of f and g(P) is a bounded function, the law of the iterated logarithm (LIL) describes the almost sure fluctuations of the normalized sum. Building on the work of Hsu (1996) and later refined by Bary‑Soroker and Kozma, the LIL holds for the sequence of polynomials ordered by degree: with probability 1, limsupn→∞ (A(f) − Mn) / √(2 Vn log log Vn) = 1, where Mn = Σdeg P ≤ n g(P) / qdeg P and Vn = Σdeg P ≤ n g(P)2 / qdeg P. The proof uses the Kubilius model for polynomials, which approximates the factorisation of a random polynomial of degree n by a random permutation of n elements, together with a martingale argument to control the dependence between cycles. The error term from the Weil bounds is of order q−n/2, which is negligible compared to the √(Vn log log Vn) scaling as long as the genus of the associated curve stays bounded. If the genus grows with n, the error term can dominate and the LIL may fail; in that regime the fluctuations are governed by a Poisson process. In examinations, a standard exercise asks to verify the LIL for the function ω(f) (the number of distinct irreducible factors). Here g(P) = 1, so Mn = Σd≤n πq(d)/qd = log n + O(1) and Vn = log n + O(1). The limsup becomes 1, matching the classical LIL for ω(n) over integers.

The Erdős–Kac Theorem for Additive Functions on Values of Polynomials with a Given Discriminant and Galois Group and a Fixed Divisor

Let f ∈ ℤ[x] be an irreducible polynomial of degree d ≥ 2 with discriminant Δ and Galois group G. Assume f has a fixed divisor D > 1, i.e. D = gcd{f(n) : n ∈ ℤ}. The Erdős–Kac theorem for ω(f(n)) then takes the form: for x → ∞, the distribution of (ω(f(n)) − Mf(x) − ω(D)) / √Vf(x) converges to the standard normal law, where Mf(x) = Σp≤x, p∤Δ ρf(p)/p + O(1) and Vf(x) = Σp≤x, p∤Δ ρf(p)/p + O(1). The local density ρf(p) is the number of roots of f modulo p, which by Chebotarev equals the number of fixed points of the Frobenius conjugacy class in G. The discriminant Δ enters because primes dividing Δ are ramified; they contribute only to the O(1) term and do not affect the leading log log x coefficient. The fixed divisor D contributes the deterministic shift ω(D) to the mean but not to the variance. The proof combines the Turán–Kubilius inequality with the effective Chebotarev density theorem under GRH (or unconditionally for a density‑one set of primes) to evaluate the sums over p. The condition that f has no fixed prime divisor beyond D ensures that the additive function is not degenerate. In examinations, a typical problem gives f(x) = x3 − 2, which has discriminant −108 = −22·33, Galois group S3, and fixed divisor D = 1. The mean and variance are both log log x + O(1). If instead f(x) = 2x2 + 2, the fixed divisor is D = 2, the Galois group is of order 2, and the mean becomes log log x + 1 + O(1) while the variance remains log log x + O(1). Students must separate the contributions of discriminant, Galois group, and fixed divisor.

  • Confusing the deterministic shift ω(D) from a fixed divisor with a contribution to the variance; the variance never includes ω(D).
  • Assuming the Chebotarev density theorem gives an exact formula for ρf(p) for every prime p; it only gives the asymptotic density of Frobenius classes, and ramified primes (dividing the discriminant) must be excluded from the main sum.
  • Applying the Barban–Davenport–Halberstam theorem beyond its unconditional range q ≤ (log x)A without stating the GRH assumption.
  • Neglecting the condition that the interval length h must be at least a power of log x for the short‑interval CLT; for smaller h the limit is Poisson, not Gaussian.
  • Treating the Kubilius permutation model for function fields as exact for all genera; the Weil bounds only guarantee square‑root error, and the model fails when the genus grows faster than √n.
  • Forgetting that the law of the iterated logarithm requires the variance Vn to tend to infinity; if the additive function is bounded (e.g. g(P) = 0 for large P), the LIL does not apply.
  • Mixing up the centering constant for the Erdős–Kac theorem in arithmetic progressions: the term ω(Dq,a) must be added to the mean but not to the variance, and it depends on the progression (a, q).
