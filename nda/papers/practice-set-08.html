Q4. General Knowledgemodel-generated · 2026-11-17
Night blindness (Nyctalopia) is caused by the deficiency of which vitamin?
A. Vitamin C
B. Vitamin D
C. Vitamin B1 (Thiamine)
D. Vitamin A (Retinol)
Correct Answer: D
Shortcut: Mnemonic/Function mapping. Vitamin A = Vision (Retina/Rhodopsin). Vitamin C = Scurvy (Collagen). Vitamin D = Rickets/Osteomalacia (Calcium absorption). Vitamin B1 = Beriberi (Nerve/Heart). 'Night' blindness links directly to 'A' for 'Aye' (Eye). Worked Solution: Vitamin A (Retinol) is a component of rhodopsin, the photopigment in rod cells of the retina essential for low-light (scotopic) vision. Its deficiency impairs rhodopsin regeneration, leading to night blindness. Prolonged deficiency causes xerophthalmia and keratomalacia.

An element with atomic number 18 belongs to which group and period of the modern periodic table?
A. Group 1, Period 3
B. Group 17, Period 3
C. Group 18, Period 3
D. Group 2, Period 4
Correct Answer: C
Shortcut: Write electronic configuration for Z=18: 2, 8, 8. Number of shells (3) = Period Number. Valence electrons (8) = Group Number (for noble gases, Group 18). Step-by-step: Atomic Number 18 implies 18 electrons. Distribution: K-shell (2), L-shell (8), M-shell (8). Since there are 3 shells occupied, the Period is 3. Since the outermost shell has 8 electrons (complete octet), it is a noble gas belonging to Group 18. The element is Argon (Ar).

Q10. General Knowledgemodel-generated · 2026-11-17
The SI unit of pressure is:
A. Newton
B. Pascal
C. Joule
D. Watt
Correct Answer: B
Shortcut: Use dimensional elimination. Newton (N) is Force (kg m/s²), Joule (J) is Work/Energy (kg m²/s²), Watt (W) is Power (kg m²/s³). Pressure is Force/Area (N/m²), which is uniquely defined as Pascal (Pa). Worked Solution: Pressure (P) = Force (F) / Area (A). SI unit of Force is Newton (N), SI unit of Area is m². Therefore, unit of Pressure = N/m². This derived unit is given the special name Pascal (Pa). 1 Pa = 1 N/m² = 1 kg/(m·s²).

Q13. General Knowledgemodel-generated · 2026-11-17
Which of the following physical quantities has the SI unit 'Joule per Second'?
A. Force (Newton)
B. Power (Watt)
C. Work (Joule)
D. Pressure (Pascal)
Correct Answer: B
Shortcut: Remember the definition of Watt: 1 Watt = 1 Joule/Second. Power is defined as the rate of doing work (Work/Time). Since Work is measured in Joules and Time in Seconds, the unit of Power is Joule per Second (Watt). Force is kg m/s² (Newton), Work/Energy is Joule, Pressure is N/m² (Pascal). Step-by-step: Unit of Work = Joule (J). Unit of Time = Second (s). Power = Work / Time = J / s. This derived unit is named Watt (W).
