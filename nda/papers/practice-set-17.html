If A = [[2,3],[1,4]], what is det(A^2)?
A. 5
B. 10
C. 25
D. 30
Correct Answer: C
Shortcut: det(A^2) = (det A)^2. det A = 2*4 - 3*1 = 5, so det(A^2) = 25. Full: Compute A^2 = [[7,18],[6,19]], then determinant = 7*19 - 18*6 = 133 - 108 = 25.

Q4. Mathematics
The number of trailing zeroes in <span class="math">100!</span> (factorial 100) is:
A. 20
B. 25
C. 24
D. 30
Correct Answer: C
Shortcut: Trailing zeroes in <span class="math">n!</span> = Sum of quotients of <span class="math">n</span> divided by powers of 5. <span class="math">\lfloor 100/5 \rfloor + \lfloor 100/25 \rfloor + \lfloor 100/125 \rfloor = 20 + 4 + 0 = 24</span>. Full Solution: A trailing zero is produced by a factor of 10 = 2 × 5. In factorials, factors of 2 are more frequent than 5, so we count factors of 5. Multiples of 5 up to 100: <span class="math">\lfloor 100/5 \rfloor = 20</span>. Multiples of 25 (extra factor of 5): <span class="math">\lfloor 100/25 \rfloor = 4</span>. Multiples of 125: <span class="math">\lfloor 100/125 \rfloor = 0</span>. Total factors of 5 = <span class="math">20 + 4 = 24</span>. Hence, 24 trailing zeroes.
Q5. Mathematics
A polygon has 44 diagonals. The number of its sides is:
A. 11
B. 10
C. 12
D. 8
Correct Answer: A
Shortcut: Diagonals = n(n-3)/2 = 44 ⇒ n² - 3n - 88 = 0 ⇒ (n-11)(n+8) = 0 ⇒ n = 11. Full Solution: Number of diagonals in an n-sided polygon is given by ⁿC₂ - n = n(n-1)/2 - n = n(n-3)/2. Given n(n-3)/2 = 44 ⇒ n² - 3n = 88 ⇒ n² - 3n - 88 = 0. Factorizing: (n - 11)(n + 8) = 0. Since n > 0, n = 11. Thus, the polygon has 11 sides.

Q7. Mathematics
If the equations <span class="math">x<sup>2</sup> + ax + b = 0</span> and <span class="math">x<sup>2</sup> + bx + a = 0</span> have a common root and <span class="math">a ≠ b</span>, then the value of <span class="math">a + b</span> is:
A. -1
B. 1
C. 0
D. 2
Correct Answer: A
Shortcut: Subtract the two equations to get <span class="math">(a-b)x + (b-a) = 0 ⇒ (a-b)(x-1)=0</span>. Since <span class="math">a ≠ b</span>, the common root is <span class="math">x=1</span>. Substitute <span class="math">x=1</span> in the first equation: <span class="math">1 + a + b = 0 ⇒ a+b = -1</span>. Full Solution: Let <span class="math">α</span> be the common root. Then <span class="math">α<sup>2</sup> + aα + b = 0</span> and <span class="math">α<sup>2</sup> + bα + a = 0</span>. Subtracting gives <span class="math">(a-b)α + (b-a) = 0 ⇒ (a-b)(α-1)=0</span>. As <span class="math">a ≠ b</span>, <span class="math">α=1</span>. Putting <span class="math">α=1</span> in first equation gives <span class="math">1+a+b=0 ⇒ a+b=-1</span>.
Q8. Mathematics
If the equations x² + ax + b = 0 and x² + bx + a = 0 (a ≠ b) have a common root, then the value of a + b is:
A. 1
B. -1
C. 0
D. 2
Correct Answer: B
Shortcut: Subtract the two equations to eliminate x²: (a-b)x + (b-a) = 0 ⇒ (a-b)(x-1)=0. Since a ≠ b, the common root x = 1. Substitute x=1 in first equation: 1 + a + b = 0 ⇒ a + b = -1. Full Solution: Let α be the common root. Then α² + aα + b = 0 and α² + bα + a = 0. Subtracting gives (a-b)α + (b-a) = 0 ⇒ (a-b)(α-1)=0. As a ≠ b, α = 1. Putting α=1 in α² + aα + b = 0 gives 1 + a + b = 0 ⇒ a + b = -1.
Q9. Mathematics
The derivative of y = ln(sin x) at x = π/6 is:
A. 1/√3
B. √3/2
C. √3
D. 2/√3
Correct Answer: C
Shortcut: dy/dx = cot x. At π/6, cot = √3. Full: dy/dx = (1/sin x)·cos x = cot x; substitute x=π/6 gives cos(π/6)/sin(π/6) = (√3/2)/(1/2) = √3.

Q11. Mathematics
The area of the triangle with vertices A(1, 2, 3), B(2, 3, 1) and C(3, 1, 2) is:
A. 3√3
B. 9/2
C. 3√3/2
D. √3
Correct Answer: C
Shortcut: Area = ½ |→AB × →AC|. →AB = (1, 1, -2), →AC = (2, -1, -1). Cross product = −3ı − 3Ĳ − 3ĳ. Magnitude = √(9+9+9) = 3√3. Area = ½ × 3√3 = 3√3/2. Full Solution: Vectors →AB = (2-1, 3-2, 1-3) = (1, 1, -2) and →AC = (3-1, 1-2, 2-3) = (2, -1, -1). Cross product →AB × →AC = det[[ı, Ĳ, ĳ], [1, 1, -2], [2, -1, -1]] = ı(-1-2) - Ĳ(-1+4) + ĳ(-1-2) = -3ı - 3Ĳ - 3ĳ. Magnitude = √((-3)²+(-3)²+(-3)²) = √27 = 3√3. Area of triangle = ½ |→AB × →AC| = 3√3/2.
Q12. Mathematics
The value of the definite integral ∫₀⁰ⁿ₂ π/2 (sin x)/(sin x + cos x) dx is:
A. π/4
B. π/2
C. π
D. 0
Correct Answer: A
Shortcut: Use King's Property ∫₀⁰ⁿ₂ f(x)dx = ∫₀⁰ⁿ₂ f(a-x)dx. Let I be the integral. Replacing x by π/2 - x gives I = ∫₀⁰ⁿ₂ (cos x)/(sin x + cos x) dx. Adding both forms: 2I = ∫₀⁰ⁿ₂ 1 dx = π/2 ⇒ I = π/4. Full Solution: Let I = ∫₀⁰ⁿ₂ sin x/(sin x+cos x) dx. Substitute x → π/2 - x, using sin(π/2-x)=cos x, cos(π/2-x)=sin x. I = ∫₀⁰ⁿ₂ cos x/(sin x+cos x) dx. Add the two equations: 2I = ∫₀⁰ⁿ₂ (sin x+cos x)/(sin x+cos x) dx = ∫₀⁰ⁿ₂ dx = [x]₀⁰ⁿ₂π/2 = π/2. Hence I = π/4.

B. 32
C. 64
D. 128
Correct Answer: A
Shortcut: Use formula |adj A| = |A|^(n-1). For n=3, |adj A| = 2^2 = 4. Then |adj(adj A)| = |adj A|^(n-1) = 4^2 = 16. Full Solution: Given |A|=2 and order n=3. Determinant of adjoint is |adj A| = |A|^(n-1) = 2^2 = 4. Treating adj A as a new matrix of order 3, |adj(adj A)| = |adj A|^(3-1) = 4^2 = 16.
