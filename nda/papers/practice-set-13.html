A fair coin is tossed 4 times. The probability of getting at least one head is:
A. 1/16
B. 7/8
C. 3/4
D. 15/16
Correct Answer: D
Shortcut: Use complement rule: P(at least one head) = 1 - P(no heads) = 1 - (1/2)^4 = 1 - 1/16 = 15/16. Full solution: Total outcomes = 2^4 = 16. Only one outcome (TTTT) has no heads. So favorable = 15, probability = 15/16.

The distance between the parallel planes 2x - 3y + 6z = 5 and 4x - 6y + 12z = 15 is:
A. 5/7
B. 1/7
C. 5/14
D. 10/7
Correct Answer: C
Shortcut: Make coefficients of x, y, z identical. Divide 2nd plane by 2: 2x - 3y + 6z = 7.5. Distance formula for parallel planes Ax+By+Cz=d₁ and Ax+By+Cz=d₂ is |d₁-d₂|/√(A²+B²+C²). Here |7.5 - 5| / √(4+9+36) = 2.5 / 7 = 5/14. Step-by-step: The planes are parallel because their normal vectors (2, -3, 6) and (4, -6, 12) are proportional. Rewrite 2nd plane as 2x - 3y + 6z = 15/2 = 7.5. The distance between planes Ax+By+Cz = d₁ and Ax+By+Cz = d₂ is |d₁ - d₂| / √(A²+B²+C²). Substituting A=2, B=-3, C=6, d₁=5, d₂=7.5: Distance = |5 - 7.5| / √(4+9+36) = 2.5 / √49 = 2.5 / 7 = 5/14.

B. π/2

D. 0
Correct Answer: A
Shortcut: Use King's Property: ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a-x) dx. Let I = ∫₀^(π/2) sin³x/(sin³x+cos³x) dx. Replace x by π/2 - x: I = ∫₀^(π/2) cos³x/(cos³x+sin³x) dx. Add both: 2I = ∫₀^(π/2) (sin³x+cos³x)/(sin³x+cos³x) dx = ∫₀^(π/2) 1 dx = π/2. Hence I = π/4. Step-by-step: Let I = ∫₀^(π/2) sin³x/(sin³x+cos³x) dx. Correct Answer: B

The minimum value of the function f(x) = 4x² + 1/x² for x > 0 is:
A. 4
B. 3
C. 2
D. 5
Correct Answer: A
Shortcut: Apply AM ≥ GM on the two positive terms 4x² and 1/x². AM = (4x² + 1/x²)/2 ≥ √(4x² × 1/x²) = √4 = 2. Thus minimum value = 2 × 2 = 4. Equality holds when 4x² = 1/x² → x⁴ = 1/4. Full: f'(x) = 8x - 2/x³ = 0 → 8x⁴ = 2 → x⁴ = 1/4 → x² = 1/2 (since x>0). f_min = 4(1/2) + 1/(1/2) = 2 + 2 = 4.
