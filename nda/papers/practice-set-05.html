Q1. Mathematics
The modulus of the complex number (1 + i)^8 is:
A. 16
B. 8
C. 32
D. 4
Correct Answer: A
Shortcut: |1+i| = √2, so |(1+i)^8| = (√2)^8 = 2^4 = 16. Full: (1+i)^2 = 2i, (1+i)^4 = (2i)^2 = -4, (1+i)^8 = (-4)^2 = 16, hence modulus = 16.

Q2. Mathematics
In a right-angled triangle, if one acute angle is 30°, what is the measure of the other acute angle?
A. 45°
B. 60°
C. 75°
D. 90°
Correct Answer: B
The sum of angles in any triangle is 180°. In a right-angled triangle, one angle is 90°. Therefore, the sum of the two acute angles must be 90°. If one acute angle is 30°, the other is 90° - 30° = 60°. Option A is incorrect as it assumes an isosceles right triangle; Options C and D exceed the limit for an acute angle in this specific context.
Research Team · ~2s · 30-60-90 Triangle
  1. Recognize 30° angle
  2. Other acute must be 60°
Q3. Mathematics
A shopkeeper sells a cricket bat with a marked price of ₹5,000. He offers two alternatives: Scheme A: 15% discount followed by a further 10% discount on the reduced price. Scheme B: A single flat discount of x%. To make the final selling price identical in both schemes, what is the value of x?
A. 25%
B. 23.5%
C. 22.5%
D. 24%
Correct Answer: B
Discount A = 15%. Remaining = 85%. Discount B = 10%. Remaining = 90%. Combined Remaining = 85% x 90% = 0.85 x 0.90 = 0.765. Total Discount = 1 - 0.765 = 0.235. x = 23.5%.
Q4. Mathematics
The exact value of tan 15° is:
A. 2 - √3
B. √3 - 1
C. 1/√3
D. √2 - 1
Correct Answer: A
Shortcut: Use tan(45°−30°) = (tan45°−tan30°)/(1+tan45°tan30°) = (1−1/√3)/(1+1/√3) = (√3−1)/(√3+1) = 2−√3. Full: tan15° = tan(45°−30°) = (1−1/√3)/(1+1/√3); rationalise to get 2−√3 ≈ 0.2679.
Q5. Mathematics
If the sum of the interior angles of a convex polygon is equal to 720°, what is the number of its sides?
A. 5
B. 6
C. 7
D. 8
Correct Answer: B
The sum of interior angles of an n-sided convex polygon is given by (n-2) × 180°. Setting (n-2) × 180 = 720 gives n-2=4, so n=6. Option A corresponds to a pentagon (540°), Option C to a heptagon (900°), and Option D to an octagon (1080°).
Q6. Mathematics
The derivative of f(x) = x^3 sin(x) with respect to x is:
A. x^2 cos(x)
B. 3x^2 sin(x) + x^3 cos(x)
C. sin(x) - x^3 cos(x)
D. x^3 cos(x)
Correct Answer: B
Using the product rule (uv)' = u'v + uv', where u=x^3 and v=sin(x). Derivative is 3x^2 sin(x) + x^3 cos(x). Option A misses the second term. Option C has wrong signs. Option D misses the first term.
Q7. Mathematics
A solid sphere of radius R has a volume of V. If the radius is reduced to half its original size, what fraction of the original volume remains?
A. 1/2
B. 1/4
C. 1/8
D. 1/16
Correct Answer: C
The volume of a sphere is given by (4/3)πr³. If the new radius r' = R/2, the new volume V' = (4/3)π(R/2)³ = (4/3)π(R³/8) = V/8. Thus, only one-eighth of the original volume remains. Options 1, 2, and 4 correspond to linear scaling or area-based errors.
Q8. Mathematics
If a 3×3 matrix has eigenvalues 2, −1, and 3, then the trace of its square is:
A. 6
B. 14
C. 12
D. 8
Correct Answer: B
Shortcut: trace(A²) = Σ λ_i² = 2² + (−1)² + 3² = 4+1+9 = 14. Full: For any diagonalizable matrix, eigenvalues of A² are squares of eigenvalues of A; trace is sum of eigenvalues, so trace(A²)=4+1+9=14.
Q9. Mathematics
If a set A has 3 elements and set B has 4 elements, the maximum number of elements in A × B is:
A. 7
B. 12
C. 8
D. 6
Correct Answer: B
The Cartesian product A × B contains ordered pairs (a,b). The cardinality |A × B| = |A| * |B|. So 3 * 4 = 12. Option A is sum, C and D are incorrect products.
Q10. Mathematics
A bank offers a special 'Festival Savings Scheme' where the interest rate for the first year is 5% per annum on the principal. However, the interest earned in the first year is added to the principal at the end of the year. If a customer deposits ₹10,000 and closes the account after exactly one year, what is the total amount received?
A. ₹10,500
B. ₹10,525
C. ₹10,600
D. ₹10,400
Correct Answer: A
Simple Interest = (P * R * T) / 100. Substituting values: P = 10000, R = 5%, T = 1 year. SI = (10000 * 5 * 1) / 100. SI = 500. Total Amount = Principal + Interest = 10000 + 500 = 10500.
Q11. Mathematics
If log₂(x) = 3 and log₃(y) = 2, then the value of x * y is:
A. 8
B. 72
C. 18
D. 6
Correct Answer: B
From log₂(x) = 3, we get x = 2³ = 8. From log₃(y) = 2, we get y = 3² = 9. The product x * y = 8 * 9 = 72. Options A, C, and D result from incorrect exponentiation or multiplication errors.
Q12. Mathematics
If sin(θ) = 1/2 and 0° ≤ θ ≤ 90°, then the value of cos(θ) is:
A. √3/2
B. 1/2
C. 0
D. √2/2
Correct Answer: A
Using the Pythagorean identity sin²(θ) + cos²(θ) = 1, we have (1/2)² + cos²(θ) = 1 => 1/4 + cos²(θ) = 1 => cos²(θ) = 3/4. Since θ is in the first quadrant, cos(θ) is positive, so cos(θ) = √3/2. Option B is sin(θ), C is tan(60°)-related but wrong value, D is sin(45°).
Q13. Mathematics
Let $f(x) = x^3 - 6x^2 + 9x + 1$. In which interval is the function strictly increasing?
A. (-∞, 0)
B. (0, 2)
C. (2, 3)
D. (3, ∞)
Correct Answer: D
The derivative $f'(x) = 3x^2 - 12x + 9$ factors to $3(x-1)(x-3)$. The function increases where $f'(x) > 0$, which occurs for $x < 1$ and $x > 3$. Among the given intervals, only $(3, ∞)$ lies entirely within the region where the function is increasing.
Q14. Mathematics
If a matrix A satisfies A² = I and A ≠ I, then which of the following must be true about the trace of A?
A. 7
B. 10
C. 5
D. 9
Correct Answer: A
The sum of roots α+β = 4 and product αβ = 3. Using identity α²+β² = (α+β)² - 2αβ, we get 4² - 2(3) = 16 - 6 = 10. Option A (7) is incorrect as it ignores the formula. Option C (5) assumes sum=4, prod=2.5. Option D (9) assumes sum=3 or prod=2.5 incorrectly.
Q15. Mathematics
What is the unit digit of 7^{2023}?
A. 7
B. 9
C. 3
D. 1
Correct Answer: C
Shortcut: The unit digit of powers of 7 repeats every 4: 7, 9, 3, 1. 2023 mod 4 = 3, so the third digit in the cycle is 3. Full: 7^1=7, 7^2=49→9, 7^3=343→3, 7^4=2401→1; cycle length 4. 2023 = 4×505 + 3 → unit digit = 3.
