1. Straight Lines

Slope & Equation Forms

The slope (or gradient) of a line measures its steepness. If a line passes through A(x₁, y₁) and B(x₂, y₂), the slope m = tan θ = (y₂ − y₁)/(x₂ − x₁), where θ is the inclination (0 ≤ θ < π). A vertical line has undefined slope; a horizontal line has slope 0.

the exam Shortcut — Slope from Two Points
In the exam, always write slope as difference in y over difference in x. Subtract in the same order for numerator and denominator. If the line is vertical, slope is undefined. For horizontal lines, slope = 0. the exam often tests this distinction.

Example 1 — Equation of a Line (the exam 2020 Pattern)
Find the equation of the line passing through (2, −3) and (−1, 5). Express in slope‑intercept form and find its intercepts on the axes.
Solution: Slope m = (5 + 3)/(−1 − 2) = 8/(−3) = −8/3. Using point‑slope with (2,−3): y + 3 = (−8/3)(x − 2) → y = (−8/3)x + 16/3 − 3 → y = (−8/3)x + 7/3. Slope‑intercept form: y = (−8/3)x + 7/3. Intercepts: set x = 0 → y = 7/3; set y = 0 → x = 7/8. So x‑intercept = 7/8, y‑intercept = 7/3.
the exam Exam Tip — Intercept Form
When a line cuts both axes, use x/a + y/b = 1. For a line with x‑intercept a and y‑intercept b, the equation is x/a + y/b = 1. the exam questions often give intercepts directly. Example: line with intercepts 3 and 4 → x/3 + y/4 = 1 → 4x + 3y = 12.

Angle Between Lines

If two lines have slopes m₁ and m₂, the acute angle θ between them is:

tan θ = |(m₁ − m₂) / (1 + m₁·m₂)|

Two lines are parallel if m₁ = m₂, and perpendicular if m₁·m₂ = −1. For lines in general form a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, parallelism requires a₁/a₂ = b₁/b₂, perpendicularity requires a₁a₂ + b₁b₂ = 0.

Perpendicular m₁·m₂ = −1 a₁a₂ + b₁b₂ = 0

Example 2 — Angle Between Lines (the exam 2021)
Find the acute angle between the lines 3x + 4y = 10 and 4x − 3y = 5. Determine if they are perpendicular.
Solution: Slope m₁ = −3/4, slope m₂ = 4/3. Check m₁·m₂ = (−3/4)(4/3) = −1. Since product is −1, the lines are perpendicular. The acute angle is 90°.
the exam Shortcut — Perpendicular Lines
For lines a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, they are perpendicular iff a₁a₂ + b₁b₂ = 0. In the exam, quickly check this sum — if zero, the lines are perpendicular. No need to compute slopes. This saves 30−40 seconds per question.

Distance of a Point from a Line

The perpendicular distance from point (x₁, y₁) to line ax + by + c = 0 is:

d = |ax₁ + by₁ + c| / √(a² + b²)

The distance between two parallel lines ax + by + c₁ = 0 and ax + by + c₂ = 0 is:

d = |c₁ − c₂| / √(a² + b²)

Example 3 — Distance Between Parallel Lines (the exam 2022)
Find the distance between the parallel lines 2x − 3y + 6 = 0 and 4x − 6y + 15 = 0.
Solution: Make coefficients proportional. Divide second by 2: 2x − 3y + 7.5 = 0. Now c₁ = 6, c₂ = 7.5. Distance = |6 − 7.5| / √(2² + (−3)²) = 1.5 / √13 = (1.5√13)/13 = (3√13)/26 units.
the exam Exam Tip — Distance Shortcut
For parallel lines, always make coefficients of x and y identical before applying the distance formula. the exam questions intentionally give lines with coefficients that need scaling. Failure to do so yields a wrong answer. Also note that distance is always non‑negative, so use absolute value.

Family of Lines

Any line passing through the intersection of L₁ ≡ a₁x + b₁y + c₁ = 0 and L₂ ≡ a₂x + b₂y + c₂ = 0 can be written as L₁ + λL₂ = 0, where λ is a real parameter. This family represents all lines through the intersection point (except L₂ itself).

Example 4 — Family of Lines (the exam 2021)
Find the equation of the line passing through the intersection of 2x + 3y − 5 = 0 and x − 2y + 1 = 0, and also through the point (1, 2).
Solution: Family: (2x + 3y − 5) + λ(x − 2y + 1) = 0. Substitute (1,2): (2 + 6 − 5) + λ(1 − 4 + 1) = 0 → 3 + λ(−2) = 0 → λ = 3/2. Thus (2x + 3y − 5) + (3/2)(x − 2y + 1) = 0. Multiply by 2: 4x + 6y − 10 + 3x − 6y + 3 = 0 → 7x − 7 = 0 → x = 1.
the exam Shortcut — Intersection Without Solving
Use the family method L₁ + λL₂ = 0 instead of solving for the intersection point. This saves 2−3 minutes. In the exam, this technique is especially useful when the line also satisfies an additional condition (like passing through a point or being parallel to a given line).

2. Circles

Standard Equation

A circle with centre C(h, k) and radius r has the standard equation (x − h)² + (y − k)² = r². The general equation is x² + y² + 2gx + 2fy + c = 0, where centre = (−g, −f) and radius = √(g² + f² − c). The circle is real if g² + f² − c ≥ 0, a point circle if g² + f² − c = 0, and imaginary if negative.

Example 5 — Circle Centre and Radius (the exam 2022)
Find the centre and radius of the circle 2x² + 2y² − 8x + 12y − 6 = 0.
Solution: Divide by 2: x² + y² − 4x + 6y − 3 = 0. Compare with x² + y² + 2gx + 2fy + c = 0: 2g = −4 → g = −2, 2f = 6 → f = 3, c = −3. Centre = (−g, −f) = (2, −3). Radius = √(g² + f² − c) = √(4 + 9 + 3) = √16 = 4 units.
the exam Shortcut — Centre from General Form
For x² + y² + 2gx + 2fy + c = 0, centre = (−g, −f). But if coefficients of x² and y² are not 1, first divide by the common factor. In the exam, this is a common trap — they give 2x² + 2y² + ... and many students forget to divide.

Tangents & Normals

The tangent to the circle x² + y² + 2gx + 2fy + c = 0 at point (x₁, y₁) on the circle is given by T = 0:

xx₁ + yy₁ + g(x + x₁) + f(y + y₁) + c = 0

For the standard circle x² + y² = a², the tangent at (x₁, y₁) is xx₁ + yy₁ = a². The slope of the tangent is −x₁/y₁, and the slope of the normal is y₁/x₁. The normal always passes through the centre of the circle.

Example 6 — Tangent to a Circle (the exam 2023)
Find the equation of the tangent to the circle x² + y² = 25 at the point (3, 4). Also find the equation of the normal.
Solution: Using xx₁ + yy₁ = a²: 3x + 4y = 25. Slope of tangent = −3/4. Normal slope = 4/3, and it passes through centre (0,0): equation y = (4/3)x or 4x − 3y = 0. The normal is the line joining the centre to the point of contact.
the exam Exam Tip — Tangent Shortcut (T = 0)
To write the tangent equation at (x₁, y₁) on any circle, use the T = 0 method: replace x² → xx₁, y² → yy₁, x → (x + x₁)/2, y → (y + y₁)/2, and xy → (xy₁ + x₁y)/2. Constant term remains unchanged. This works for all conics, not just circles.

Condition for Tangency

A line y = mx + c is tangent to the circle x² + y² = a² if the distance from the centre (0,0) to the line equals the radius a:

c = ± a √(1 + m²)

The length of the tangent from an external point (x₁, y₁) to the circle is √(S₁), where S₁ = x₁² + y₁² + 2gx₁ + 2fy₁ + c. The chord of contact from (x₁, y₁) is T = 0, which has the same form as the tangent equation.

Example 7 — Tangency Condition (the exam 2020)
Find the value of k if the line y = 2x + k is tangent to the circle x² + y² = 20.
Solution: For circle x² + y² = a², a = √20 = 2√5. Tangency: k = ± a√(1 + m²) = ± 2√5 · √(1 + 4) = ± 2√5 · √5 = ± 2 · 5 = ± 10. So k = 10 or k = −10. Both lines y = 2x + 10 and y = 2x − 10 are tangent to the circle.
the exam Shortcut — Two Tangents
For a given slope m, there are always two parallel tangents to a circle: c = ± a√(1 + m²). the exam questions often ask for the positive value of c. Remember the ± sign — both are valid tangents.

3. Conic Sections

Parabola

Standard Forms & Properties

A parabola is the locus of a point equidistant from a fixed point (focus) and a fixed line (directrix). The standard parabola y² = 4ax has focus at (a, 0), directrix x = −a, vertex at (0, 0), and axis along the x‑axis. The length of the latus rectum is 4a. The parametric form is (at², 2at).

Equation Axis Focus Directrix Latus Rectum
y² = 4ax x‑axis (right) (a, 0) x = −a x = a, length 4a
y² = −4ax x‑axis (left) (−a, 0) x = a x = −a, length 4a
x² = 4ay y‑axis (up) (0, a) y = −a y = a, length 4a
x² = −4ay y‑axis (down) (0, −a) y = a y = −a, length 4a
Example 8 — Parabola Focus (the exam 2021)
Find the focus, directrix, and length of latus rectum of the parabola 2y² = 16x.
Solution: Rewrite as y² = 8x. Compare with y² = 4ax: 4a = 8 → a = 2. Focus = (2, 0). Directrix: x = −2. Length of latus rectum = 4a = 8. Endpoints of latus rectum: (2, ±4). Parametric coordinates: (2t², 4t).
the exam Shortcut — Parabola Identification
Identify which variable is squared: if y², axis is horizontal (opens left/right); if x², axis is vertical (opens up/down). The sign determines direction: positive opens towards positive axis, negative towards negative. In the exam, the most common form is y² = 4ax (opens right).

Ellipse

Foci, Eccentricity, Latus Rectum

The standard ellipse is x²/a² + y²/b² = 1 where a > b. The foci are at (±ae, 0), eccentricity e = √(1 − b²/a²) where 0 < e < 1, and the directrices are x = ±a/e. The length of the latus rectum is 2b²/a. The sum of distances from any point on the ellipse to the two foci is constant (= 2a). If b > a, the major axis is along the x‑axis.

Example 9 — Ellipse Eccentricity (the exam 2022)
For the ellipse 9x² + 16y² = 144, find the eccentricity, foci, and length of latus rectum.
Solution: Divide by 144: x²/16 + y²/9 = 1. So a² = 16, b² = 9, a = 4, b = 3. e = √(1 − 9/16) = √(7/16) = √7/4. Foci = (±4·√7/4, 0) = (±√7, 0). Length of latus rectum = 2b²/a = 2·9/4 = 9/2 = 4.5 units.
the exam Exam Tip — Eccentricity Range
Remember the eccentricity ranges: ellipse → 0 < e < 1, parabola → e = 1, hyperbola → e > 1. For the exam MCQs, if the answer choices include values both less than and greater than 1, use this to eliminate options. For ellipse, e < 1 always.

Hyperbola

Rectangular Hyperbola

The standard hyperbola is x²/a² − y²/b² = 1. The foci are at (±ae, 0), eccentricity e = √(1 + b²/a²) where e > 1, and the directrices are x = ±a/e. The asymptotes are y = ±(b/a)x. A rectangular hyperbola has a = b, giving asymptotes at right angles (y = ±x) and eccentricity e = √2. Its equation is x² − y² = a² or, in rotated form, xy = c²/2.

Example 10 — Hyperbola Asymptotes (the exam 2023)
Find the asymptotes and eccentricity of the hyperbola 4x² − 9y² = 36.
Solution: Divide by 36: x²/9 − y²/4 = 1. Here a² = 9 → a = 3, b² = 4 → b = 2. Asymptotes: y = ±(b/a)x = ±(2/3)x. Eccentricity: e = √(1 + b²/a²) = √(1 + 4/9) = √(13/9) = √13/3. Since e > 1, it confirms a hyperbola.

the exam Shortcut — Conic Identification
Quickly identify conics by signs: both x² and y² positive → ellipse (circle if coefficients equal); one positive, one negative → hyperbola; only one squared term → parabola. For eccentricity: e = 1 → parabola, e < 1 → ellipse, e > 1 → hyperbola. the exam often tests this classification.

4. Locus & Transformation of Axes

Locus

The locus of a point is the path traced when it moves under a given condition. To find the locus, assume the moving point as P(h, k) or P(x, y), apply the geometric condition, and eliminate any parameters to obtain an equation in x and y. The resulting equation represents the locus.

Example 11 — Locus of a Point (the exam 2022)
A point P moves such that its distance from A(2, 3) is always equal to its distance from B(6, 5). Find the locus of P.
Solution: Let P = (x, y). Condition: PA = PB → (x − 2)² + (y − 3)² = (x − 6)² + (y − 5)². Expand: x² − 4x + 4 + y² − 6y + 9 = x² − 12x + 36 + y² − 10y + 25. Cancel common terms: −4x − 6y + 13 = −12x − 10y + 61 → 8x + 4y − 48 = 0 → 2x + y − 12 = 0. The locus is a straight line — the perpendicular bisector of AB.
the exam Exam Tip — Standard Loci to Memorise
Know these standard loci: PA = PB → perpendicular bisector (line). PA² + PB² = constant → circle. PA/PB = constant (≠1) → circle (Apollonius). |PA − PB| = constant → hyperbola. PA + PB = constant → ellipse. Distance from fixed point = distance from fixed line → parabola. These are directly tested in the exam.

Transformation of Axes

Transformation of axes involves shifting the origin or rotating the coordinate axes. Shifting the origin to (h, k) replaces x by X + h and y by Y + k. Rotation of axes by angle θ replaces x by X cos θ − Y sin θ and y by X sin θ + Y cos θ. This simplifies equations — for example, shifting the origin to the centre of a circle eliminates the linear terms.

Example 12 — Shift of Origin (the exam 2021)
Find the new equation of the circle (x − 3)² + (y + 2)² = 16 when the origin is shifted to (3, −2).
Solution: Let X = x − 3, Y = y + 2. Substituting: X² + Y² = 16. The circle's centre (3, −2) becomes the origin in the new coordinate system, and the equation simplifies to X² + Y² = 16 — a circle centred at the new origin with radius 4.
the exam Shortcut — Shift of Origin
When shifting origin to (h, k), substitute x = X + h and y = Y + k. The new equation has no linear terms if (h, k) is the centre of a circle or vertex of a parabola. This simplifies the equation for faster solving. In the exam, this technique is tested with circles and parabolas.

Family of Lines and Envelopes

A family of lines is a one‑parameter set of straight lines whose equations can be written as L₁ + λ L₂ = 0, where L₁ = 0 and L₂ = 0 are two fixed lines and λ is a real parameter. Every member of the family passes through the intersection point of L₁ = 0 and L₂ = 0. Conversely, any line through that intersection can be represented by a suitable λ. This representation is the algebraic backbone for problems that ask for a line satisfying two linear conditions (e.g., passing through a given point and having a given slope).

The envelope of a family of curves is the curve that is tangent to each member of the family. For a family of lines F(x, y, λ) = 0, the envelope is obtained by eliminating λ between F = 0 and ∂F/∂λ = 0. In the linear case F = L₁ + λ L₂, the envelope degenerates to the single point of intersection, but when the family is nonlinear in λ (for instance, the family of tangents to a parabola written as y = mx + a/m with parameter m), the envelope reproduces the original curve. This technique is a standard way to derive the equation of a conic from its tangent family.

Important applications include: (1) finding the equation of a line that bisects the angle between two given lines — the family of lines through their intersection with a parameter representing the angle; (2) determining the locus of the point of intersection of two moving lines that satisfy a linear relation between their parameters; (3) solving “line through the intersection of L₁ and L₂ and perpendicular to L₃” by first writing the family and then imposing the perpendicularity condition using slopes.

A classic JEE‑type problem: “Find the envelope of the family of lines x cos θ + y sin θ = p where p is constant and θ varies.” Differentiating with respect to θ gives −x sin θ + y cos θ = 0. Solving the two equations yields x = p cos θ, y = p sin θ, and eliminating θ gives x² + y² = p², a circle. This illustrates how a one‑parameter family of straight lines can generate a curved envelope.

Students should practice writing the family of lines through the intersection of two given lines, imposing extra conditions (parallelism, perpendicularity, passing through a third point), and eliminating the parameter to obtain the required line or locus. Mastery of this method reduces many coordinate‑geometry problems to simple algebraic elimination.

Pole and Polar with Respect to Conics

Given a conic S(x, y) = 0 and a point P(x₁, y₁) (which may lie inside, on, or outside the conic), the polar of P is the line whose equation is obtained by replacing x² → x x₁, y² → y y₁, xy → (x y₁ + y x₁)/2, x → (x + x₁)/2, y → (y + y₁)/2 in the equation of the conic. For the standard ellipse x²/a² + y²/b² = 1 the polar of P(x₁, y₁) is x x₁/a² + y y₁/b² = 1. For the hyperbola x²/a² − y²/b² = 1 it becomes x x₁/a² − y y₁/b² = 1. For the parabola y² = 4ax the polar is y y₁ = 2a(x + x₁).

The pole–polar relationship is symmetric: if the polar of P passes through Q, then the polar of Q passes through P. When P lies on the conic, its polar is the tangent at P. When P is outside, the polar is the chord of contact of the two tangents drawn from P to the conic. When P is inside, the polar is a line that does not intersect the conic in real points but still satisfies the harmonic‑conjugate property with respect to any chord through P.

Key properties used in examinations: (1) The equation of the chord of contact from P(x₁, y₁) to the ellipse is exactly the polar equation. (2) The polar of the focus of a parabola is the directrix. (3) For a rectangular hyperbola xy = c², the polar of (x₁, y₁) is x y₁ + y x₁ = 2c². (4) If a variable line moves such that its pole with respect to a fixed conic lies on a fixed line, then the envelope of the moving line is another conic (the reciprocal conic).

Problems often ask: “Find the pole of the line lx + my + n = 0 with respect to the ellipse x²/a² + y²/b² = 1.” The answer is obtained by solving the linear system derived from the polar formula, yielding the pole coordinates (−a² l / n, −b² m / n) (provided n ≠ 0). Another frequent twist: “If the polar of P with respect to the circle x² + y² = r² touches the parabola y² = 4ax, find the locus of P.” This combines pole–polar with tangency condition (discriminant = 0) and leads to a second‑degree locus.

Polar of a Point with Respect to an Ellipse
Find the equation of the polar of the point (2, 3) with respect to the ellipse x²/9 + y²/4 = 1.
For the ellipse x²/a² + y²/b² = 1 the polar of (x₁, y₁) is x x₁/a² + y y₁/b² = 1. Here a² = 9, b² = 4, x₁ = 2, y₁ = 3. Substituting gives x·2/9 + y·3/4 = 1. Multiply by 36: 8x + 27y = 36. Hence the required polar is 8x + 27y = 36.
Exam‑Day Strategy
Memorise the polar formulas for the three standard conics. When a problem gives a line and asks for its pole, write the polar equation of a generic point (h, k) and equate coefficients with the given line. This converts the problem into a simple linear system and avoids the more error‑prone method of solving for intersection of tangents.

Director Circle, Auxiliary Circle, and Orthoptic Locus

The director circle of a central conic is the locus of points from which the two tangents drawn to the conic are perpendicular. For the ellipse x²/a² + y²/b² = 1 (a > b) the director circle is x² + y² = a² + b². For the hyperbola x²/a² − y²/b² = 1 the director circle exists only when a > b and has equation x² + y² = a² − b²; if a ≤ b the director circle is imaginary, meaning no real point yields perpendicular tangents. The auxiliary circle of an ellipse is the circle on the major axis as diameter: x² + y² = a². It is used to define the eccentric angle parameter θ via the point (a cos θ, b sin θ) on the ellipse and (a cos θ, a sin θ) on the auxiliary circle.

The orthoptic locus (also called the director circle) is the same as the director circle for ellipses and hyperbolas. For a parabola y² = 4ax the orthoptic locus is the directrix x = −a, because tangents at the ends of a focal chord are perpendicular and intersect on the directrix. For a rectangular hyperbola xy = c² the orthoptic locus is the circle x² + y² = 2c².

Important derived results: (1) The product of the slopes of two perpendicular tangents to the ellipse is −1, leading to the director circle equation. (2) The foot of the perpendicular from a focus to any tangent of an ellipse lies on the auxiliary circle. (3) The chord of contact of a point on the director circle is a normal to the conic. (4) The locus of the point of intersection of perpendicular tangents to the hyperbola is the director circle when it is real.

Typical JEE questions: “Find the equation of the director circle of the ellipse 4x² + 9y² = 36.” Rewrite as x²/9 + y²/4 = 1, so a² = 9, b² = 4, director circle x² + y² = 13. Another: “Prove that the foot of the perpendicular from the focus (ae, 0) to any tangent of the ellipse lies on the auxiliary circle.” Use the tangent equation y = mx ± √(a²m² + b²) and the perpendicular distance condition to show the foot satisfies x² + y² = a².

Rotation of Axes and Classification of General Second‑Degree Curves

The general second‑degree equation in two variables is Ax² + Bxy + Cy² + Dx + Ey + F = 0. The presence of the xy term indicates that the axes of the conic are rotated with respect to the coordinate axes. To eliminate the xy term, rotate the axes through an angle θ satisfying cot 2θ = (A − C)/B (or tan 2θ = B/(A − C) when A ≠ C). The transformation is x = X cos θ − Y sin θ, y = X sin θ + Y cos θ. Substituting and simplifying yields an equation in X, Y without the XY term.

The discriminant Δ = B² − 4AC classifies the conic irrespective of translation or rotation: Δ < 0 → ellipse (or circle if A = C and B = 0); Δ = 0 → parabola; Δ > 0 → hyperbola (or pair of intersecting lines if the determinant of the 3×3 matrix vanishes). The degenerate cases (pair of parallel lines, coincident lines, point, empty set) are detected by evaluating the determinant of the augmented matrix | A B/2 D/2; B/2 C E/2; D/2 E/2 F |.

After rotation, the equation reduces to A'X² + C'Y² + D'X + E'Y + F' = 0. Completing squares in X and Y translates the centre to the origin, giving the canonical form. For an ellipse the canonical form is X²/a² + Y²/b² = 1; for a hyperbola X²/a² − Y²/b² = 1 or Y²/b² − X²/a² = 1; for a parabola Y² = 4aX or X² = 4aY.

Examination problems often give a rotated conic such as 5x² + 6xy + 5y² − 8 = 0 and ask for its type, centre, axes lengths, and orientation. Compute Δ = 36 − 100 = −64 (< 0) → ellipse. Since A = C, the axes are at 45° (θ = 45°). Rotation yields 8X² + 2Y² = 8 → X²/1 + Y²/4 = 1, so semi‑major axis = 2 along Y, semi‑minor = 1 along X. The original major axis is the line y = x.

Students should practice: (1) finding θ from cot 2θ formula; (2) performing the rotation algebraically; (3) completing squares to locate centre; (4) reading off geometric parameters. A systematic approach avoids sign errors and saves time.

Shortest Distance Between Skew Lines and Angle Between Planes

In three dimensions, two lines that are neither parallel nor intersecting are called skew lines. Let the lines be given in vector form r = a₁ + λ b₁ and r = a₂ + μ b₂. The shortest distance d between them is the length of the common perpendicular, computed as d = |(a₂ − a₁) · (b₁ × b₂)| / |b₁ × b₂|. The numerator is the absolute scalar triple product of the vectors (a₂ − a₁), b₁, b₂; the denominator is the magnitude of the cross product of the direction vectors. If the lines are parallel, b₁ × b₂ = 0 and the formula reduces to the distance from a point on one line to the other line.

The line of shortest distance is parallel to b₁ × b₂. Its points of contact on the two lines can be found by solving for λ and μ such that the vector joining the two points is perpendicular to both b₁ and b₂, i.e., (a₂ + μ b₂ − a₁ − λ b₁) · b₁ = 0 and (a₂ + μ b₂ − a₁ − λ b₁) · b₂ = 0. This yields a 2×2 linear system in λ, μ.

For planes, the angle between two planes π₁: n₁·r = d₁ and π₂: n₂·r = d₂ is the angle between their normal vectors n₁ and n₂: cos θ = |n₁·n₂| / (|n₁||n₂|). Two planes are perpendicular iff n₁·n₂ = 0; they are parallel iff n₁ × n₂ = 0 (i.e., n₁ is a scalar multiple of n₂). The distance between parallel planes n·r = d₁ and n·r = d₂ is |d₁ − d₂| / |n|.

Typical problems: “Find the shortest distance between the lines (x−1)/2 = (y+1)/−3 = (z−2)/1 and (x−3)/1 = (y−2)/2 = (z+1)/−2.” Convert to vector form, compute cross product, scalar triple product, and apply the formula. Another: “Determine the angle between the planes 2x − y + 2z = 5 and 3x + 6y − 2z = 7.” Normals are (2, −1, 2) and (3, 6, −2); dot product = 6 − 6 − 4 = −4; magnitudes = 3 and 7; cos θ = 4/21; θ = cos⁻¹(4/21).

Key pitfalls: forgetting the absolute value in the distance formula, mixing up the order of vectors in the scalar triple product (sign does not matter after absolute value), and using the wrong normal when the plane equation is not in normalised form. Always reduce the plane equation to the form n·r = d with n as the coefficient vector before applying formulas.

  • Confusing the director circle of a hyperbola with that of an ellipse — the hyperbola’s director circle exists only when a > b and has radius √(a² − b²).
  • Applying the polar formula for a point on the conic as if it were an external point; the polar then becomes the tangent, not the chord of contact.
  • Using the rotation angle formula tan 2θ = B/(A − C) without checking the quadrant of 2θ, leading to an incorrect orientation of axes.
  • Forgetting that the shortest‑distance formula for skew lines requires the cross product of direction vectors to be non‑zero; if it is zero the lines are parallel and a different formula applies.
  • Mixing the angle between planes (using normals) with the angle between a line and a plane (using direction vector and normal).
  • Neglecting the absolute value in the scalar triple product when computing the distance between skew lines, which can give a negative distance.
  • Assuming the auxiliary circle of an ellipse is always x² + y² = a² even when the major axis is along the y‑axis; the auxiliary circle is always on the major axis as diameter.

Conjugate Diameters of Ellipse and Hyperbola

A diameter of a central conic is the locus of mid‑points of a system of parallel chords. For an ellipse x²/a² + y²/b² = 1, the family of chords with slope m has its mid‑points on the line y = −(b²/a²)(1/m)x. This line is called the diameter conjugate to the direction m. The product of the slopes of two conjugate diameters equals −b²/a². In particular, the major and minor axes are conjugate diameters because their slopes are 0 and ∞, and the product condition is satisfied in the limiting sense. For a hyperbola x²/a² − y²/b² = 1, the conjugate diameter to a chord of slope m is y = (b²/a²)(1/m)x, and the product of slopes of conjugate diameters is +b²/a². The asymptotes themselves are a pair of conjugate diameters because each is the limit of chords whose mid‑points tend to infinity.

An important property: if P(a cos θ, b sin θ) is a point on the ellipse, the tangent at P has slope −(b/a) cot θ. The diameter conjugate to the direction of this tangent passes through the centre and has slope (b/a) tan θ, which is exactly the line joining the centre to the point Q(a cos(θ+π/2), b sin(θ+π/2)). Thus the endpoints of conjugate diameters correspond to parameters differing by π/2. The area of the parallelogram formed by the tangents at the ends of conjugate diameters is constant and equals 4ab. For the hyperbola, the same parametric representation P(a sec θ, b tan θ) yields conjugate points with parameters differing by π/2, and the area of the tangent parallelogram is 4ab as well.

Conjugate diameters are useful in solving problems that ask for the equation of a diameter bisecting chords of a given slope, or for the locus of the intersection of tangents at the ends of conjugate diameters (which is the director circle). They also simplify the proof that the sum of squares of any two conjugate semi‑diameters of an ellipse equals a²+b², while for a hyperbola the difference of squares equals a²−b². In coordinate‑free vector form, if u and v are conjugate semi‑diameters of the ellipse, then uᵀ A v = 0 where A = diag(1/a², 1/b²). This orthogonality with respect to the metric defined by the conic is the geometric essence of conjugacy.

Asymptotes of Hyperbola and Rectangular Hyperbola

The asymptotes of the standard hyperbola x²/a² − y²/b² = 1 are the lines y = ±(b/a)x. They are obtained by setting the constant term to zero in the equation, i.e. x²/a² − y²/b² = 0. For a hyperbola whose transverse axis is vertical, y²/a² − x²/b² = 1, the asymptotes are y = ±(a/b)x. The asymptotes intersect at the centre and form an angle 2 arctan(b/a) (or 2 arctan(a/b) for the vertical case). The distance from any point on the hyperbola to its asymptotes measured along a line parallel to the transverse axis tends to zero as the point recedes to infinity.

A rectangular (or equilateral) hyperbola has perpendicular asymptotes, which occurs when a = b. Its standard equation can be written as x² − y² = a², or after a rotation of 45° as xy = c²/2 where c² = a²/2. The eccentricity of a rectangular hyperbola is √2. The parametric form x = c sec θ, y = c tan θ (for the x²−y² form) or x = c t, y = c/t (for the xy = c² form) is especially convenient. The tangent at the point t on xy = c² is x/t + y t = 2c, and the normal is x t − y/t = c(t² − 1/t²). The chord of contact from an external point (x₁, y₁) is x₁y + y₁x = 2c².

Important properties: (1) The product of the perpendicular distances from any point on a rectangular hyperbola to its asymptotes is constant and equals c²/2. (2) The orthocentre of any triangle inscribed in a rectangular hyperbola also lies on the same hyperbola (the Feuerbach property). (3) The locus of the midpoint of a chord of a rectangular hyperbola that subtends a right angle at the centre is the circle x²+y² = 2c². (4) The asymptotes of any hyperbola are the tangents at the points where the hyperbola meets the line at infinity; for a rectangular hyperbola these points are the circular points at infinity, which explains the right angle between asymptotes.

Worked Example: Asymptotes and Tangent of a Rectangular Hyperbola
Find the equations of the asymptotes of the hyperbola 3x² − 3y² = 12 and the equation of the tangent at the point where the parameter t = 2 on the rectangular hyperbola xy = 4.
First, rewrite 3x² − 3y² = 12 as x²/4 − y²/4 = 1. Here a² = b² = 4, so a = b = 2. The asymptotes are y = ±(b/a)x = ±x, i.e. y = x and y = −x. For the rectangular hyperbola xy = 4, we have c² = 4, so c = 2. The parametric point for t = 2 is (x, y) = (c t, c/t) = (4, 1). The tangent at parameter t is x/t + y t = 2c. Substituting t = 2 and c = 2 gives x/2 + 2y = 4, or x + 4y = 8. Thus the required tangent is x + 4y = 8.
Exam‑Day Strategy
When a hyperbola equation lacks an xy term, its asymptotes are immediately obtained by equating the quadratic part to zero. For a rectangular hyperbola given as xy = c², remember the simple tangent form x/t + y t = 2c and normal form x t − y/t = c(t² − 1/t²). Memorising these avoids re‑deriving them under time pressure.

Polar Equation of Conics and the Focus‑Directrix Property

Any conic can be described in polar coordinates (r, θ) with one focus as the pole. The general polar equation is r = ℓ / (1 + e cos θ) where e is the eccentricity and ℓ = b²/a for ellipse and hyperbola, while for a parabola ℓ = 2a (the semi‑latus rectum). The directrix is the line r cos θ = −ℓ/e (or x = −ℓ/e in Cartesian form). For an ellipse (0 < e < 1) the denominator never vanishes, so r is finite for all θ. For a parabola (e = 1) the denominator can become zero when cos θ = −1, corresponding to the point at infinity on the axis. For a hyperbola (e > 1) the denominator vanishes at two angles, giving the directions of the asymptotes.

The focus‑directrix definition states that a conic is the locus of points whose distance to a fixed point (focus) is e times the distance to a fixed line (directrix). In polar form this is exactly r = e · distance to directrix. The semi‑latus rectum ℓ is the focal chord perpendicular to the major axis; its length is 2ℓ. For the ellipse, ℓ = a(1 − e²); for the hyperbola, ℓ = a(e² − 1); for the parabola, ℓ = 2a. The polar equation is especially useful for problems involving planetary motion (Kepler’s first law) and for computing the angle between the radius vector and the tangent: tan φ = r / (dr/dθ) = (1 + e cos θ) / (e sin θ).

If the polar axis is taken along the major axis but the focus is not at the pole, the equation becomes r = ℓ / (1 ± e cos θ) with the sign chosen according to which focus is used. Rotating the conic by an angle α simply replaces θ by θ − α. The general second‑degree equation in polar coordinates centred at a focus is r² = (ℓ + e r cos θ)² / (1 − e²) for ellipses and hyperbolas, which reduces to the familiar Cartesian form after substituting r cos θ = x, r sin θ = y.

Intersection of a Line with a Conic: Chord, Tangent, and Normal

Let the conic be given by the general quadratic S(x, y) = A x² + B xy + C y² + D x + E y + F = 0 and the line by y = m x + c (or in parametric form x = x₁ + λ l, y = y₁ + λ m). Substituting the line equation into S yields a quadratic in the parameter λ (or in x). The nature of the roots determines the intersection: two distinct real roots → secant (chord); a double root → tangent; complex roots → no intersection. The condition for tangency is that the discriminant of this quadratic vanishes. For the standard ellipse x²/a² + y²/b² = 1 and line y = m x + c, the tangency condition is c² = a² m² + b². The tangent at a point (x₁, y₁) on the ellipse is x x₁/a² + y y₁/b² = 1; the normal is a² x/x₁ − b² y/y₁ = a² − b².

For the hyperbola x²/a² − y²/b² = 1, the tangent at (x₁, y₁) is x x₁/a² − y y₁/b² = 1 and the normal is a² x/x₁ + b² y/y₁ = a² + b². For the parabola y² = 4 a x, the tangent at (a t², 2 a t) is y t = x + a t² and the normal is y = −t x + 2 a t + a t³. The chord of contact from an external point (x₁, y₁) to any conic is obtained by replacing x² → x x₁, y² → y y₁, xy → (x y₁ + y x₁)/2, x → (x + x₁)/2, y → (y + y₁)/2 in the equation of the conic (the T = 0 rule). The polar of (x₁, y₁) with respect to the conic is the same line; if the point lies on the conic the polar becomes the tangent.

The equation of the chord with a given midpoint (h, k) is T = S₁, where T is obtained by the same substitution as above and S₁ = S(h, k). This is the “midpoint chord” formula. The director circle of an ellipse is the locus of points from which perpendicular tangents can be drawn; its equation is x² + y² = a² + b². For a hyperbola the director circle exists only when a > b and is x² + y² = a² − b². The orthoptic locus (locus of points from which the tangents are at right angles) coincides with the director circle for central conics.

Three‑Dimensional Quadric Surfaces: Sphere, Cylinder, and Cone

A sphere is the set of points equidistant from a fixed centre (x₀, y₀, z₀). Its equation is (x − x₀)² + (y − y₀)² + (z − z₀)² = R². The general second‑degree equation in three variables represents a sphere iff the coefficients of x², y², z² are equal and the xy, yz, zx terms are absent. The centre is (−D/2, −E/2, −F/2) and the radius is √(D²+E²+F²−4G)/2 after writing the equation as x²+y²+z²+2Dx+2Ey+2Fz+G=0. A plane section of a sphere is always a circle; the intersection of two spheres is a circle lying in a plane (the radical plane). The power of a point P with respect to a sphere is the square of the length of the tangent from P to the sphere, equal to S(P) where S is the left‑hand side of the sphere equation.

A right circular cylinder is generated by lines parallel to a fixed axis passing through a given base curve (usually a circle). If the axis is the z‑axis and the base circle is x²+y² = a² in the plane z = 0, the cylinder equation is x²+y² = a². More generally, a cylinder with generators parallel to a vector (l, m, n) and guiding curve F(x, y, z)=0, G(x, y, z)=0 has equation obtained by eliminating the parameter along the generators. A cone with vertex at the origin and guiding curve the intersection of the sphere x²+y²+z² = a² with a plane lx+my+nz = p has homogeneous equation (lx+my+nz)² = (l²+m²+n²)(x²+y²+z²) · (p²/a²). The general homogeneous second‑degree equation in x, y, z represents a cone with vertex at the origin. The angle between two generators of a cone is found from the direction cosines satisfying the cone equation.

The tangent plane to a sphere at (x₁, y₁, z₁) is (x−x₀)(x₁−x₀)+(y−y₀)(y₁−y₀)+(z−z₀)(z₁−z₀)=R². For a cylinder x²+y² = a², the tangent plane at (x₁, y₁, z₁) is x x₁ + y y₁ = a². For a cone given by homogeneous equation F(x, y, z)=0, the tangent plane along a generator through (x₁, y₁, z₁) is x ∂F/∂x₁ + y ∂F/∂y₁ + z ∂F/∂z₁ = 0. The condition for a plane lx+my+nz = p to be tangent to the sphere x²+y²+z² = R² is p² = R²(l²+m²+n²). For the cylinder x²+y² = a², the plane is tangent iff the perpendicular distance from the axis to the plane equals a. These formulas are frequently combined with distance‑between‑skew‑lines and angle‑between‑planes techniques to solve three‑dimensional locus problems.

  • Confusing the polar equation r = ℓ/(1+e cos θ) with the Cartesian focus‑directrix form and forgetting to adjust the sign when the directrix is on the opposite side of the focus.
  • Applying the tangency condition c² = a² m² + b² for an ellipse to a hyperbola without changing the sign to c² = a² m² − b².
  • Using the chord‑of‑contact formula T = 0 for a point that lies on the conic, which yields the tangent, but then treating it as a chord of contact in subsequent steps.
  • Assuming the director circle of a hyperbola always exists; it exists only when a > b and its radius is √(a²−b²).
  • Neglecting the homogeneous nature of a cone’s equation when finding tangent planes, leading to an incorrect plane that does not pass through the vertex.
  • Forgetting that the intersection of two spheres is a circle whose plane is the radical plane, and trying to solve the system as if it were a single sphere.
  • Mixing the formula for the angle between two planes (using normals) with the angle between a line and a plane (using direction vector and normal) in three‑dimensional problems.

Parametric Equations of Conics and Chord Properties

The parametric representation of a conic turns many locus and chord problems into algebraic manipulations in a single parameter. For the parabola y² = 4ax the standard parameter is t with coordinates (a t² , 2a t). The tangent at t is y t = x + a t² and the normal is y = –t x + 2a t + a t³. The chord joining points t₁ and t₂ has equation y (t₁ + t₂) = 2x + 2a t₁ t₂. If this chord is a focal chord then t₁ t₂ = –1. The chord of contact from an external point (x₁ , y₁) is obtained by the T = 0 rule, which in parametric form becomes y y₁ = 2a (x + x₁).

For the ellipse x²/a² + y²/b² = 1 the eccentric angle θ gives (a cos θ , b sin θ). The tangent at θ is (x cos θ)/a + (y sin θ)/b = 1 and the normal is (a x)/cos θ – (b y)/sin θ = a² – b². The chord joining θ₁ and θ₂ is (x/a) cos((θ₁+θ₂)/2) + (y/b) sin((θ₁+θ₂)/2) = cos((θ₁–θ₂)/2). The midpoint of this chord is (a cos((θ₁+θ₂)/2) cos((θ₁–θ₂)/2) , b sin((θ₁+θ₂)/2) cos((θ₁–θ₂)/2)). The chord with a given midpoint (h , k) satisfies T = S₁ where T is (x h)/a² + (y k)/b² = 1 and S₁ = h²/a² + k²/b² – 1.

For the hyperbola x²/a² – y²/b² = 1 a convenient rational parameter is t with (a sec θ , b tan θ) or the hyperbolic parameter u giving (a cosh u , b sinh u). The tangent at θ is (x sec θ)/a – (y tan θ)/b = 1. The chord joining θ₁ and θ₂ is (x/a) cos((θ₁–θ₂)/2) – (y/b) sin((θ₁+θ₂)/2) = cos((θ₁+θ₂)/2). The condition for a chord to be a focal chord is tan(θ₁/2) tan(θ₂/2) = (e–1)/(e+1) where e is the eccentricity. These parametric forms make it straightforward to derive the equation of the pair of tangents from a point, the director circle, and the polar of a point without resorting to the general second‑degree equation.

Confocal Conics and Orthogonal Trajectories

Two conics are confocal when they share the same foci. For a given ellipse x²/a² + y²/b² = 1 with a > b and foci at (±c , 0) where c² = a² – b², the family of confocal conics is written as x²/(a²+λ) + y²/(b²+λ) = 1 where λ is a real parameter. When λ > –b² the denominator of y² stays positive and the curve is an ellipse; when –a² < λ < –b² the denominator of y² becomes negative and the curve is a hyperbola with the same foci. The limiting cases λ = –b² and λ = –a² give the focal axes.

A fundamental property is that through any point P(x₀ , y₀) not on the axes there pass exactly two confocal conics: one ellipse (λ₁) and one hyperbola (λ₂). They intersect orthogonally at P. The orthogonality can be proved by differentiating the family equation implicitly: 2x/(a²+λ) + 2y y'/(b²+λ) = 0 giving the slope y' = – (x (b²+λ)) / (y (a²+λ)). For the ellipse and hyperbola parameters λ₁ and λ₂ the product of the slopes is –1 because (a²+λ₁)(a²+λ₂) + (b²+λ₁)(b²+λ₂) = 0 follows from the fact that both λ₁ and λ₂ satisfy the quadratic in λ obtained by substituting (x₀ , y₀) into the family equation. Consequently the tangents are perpendicular.

The confocal family also provides a neat method for solving problems that ask for a conic passing through a given point and having the same foci as a given conic. One writes the family equation, substitutes the point to obtain a quadratic in λ, and selects the root that yields the required type (ellipse or hyperbola). The orthogonal trajectory property is frequently used in physics (equipotential lines and field lines) and in geometry to construct curvilinear coordinates.

When a problem asks for a conic confocal with a given one, write the family equation with parameter λ and use the given point to determine λ. Coordinate Geometry of the Triangle: Centroid, Orthocenter, Circumcenter, and Euler Line

Let the vertices of a triangle be A(x₁ , y₁), B(x₂ , y₂), C(x₃ , y₃). The centroid G is the arithmetic mean of the vertices: G = ((x₁+x₂+x₃)/3 , (y₁+y₂+y₃)/3). The circumcenter O is the intersection of the perpendicular bisectors. Using determinants, its coordinates are

Oₓ = ( (x₁²+y₁²)(y₂–y₃) + (x₂²+y₂²)(y₃–y₁) + (x₃²+y₃²)(y₁–y₂) ) / D

Oᵧ = ( (x₁²+y₁²)(x₃–x₂) + (x₂²+y₂²)(x₁–x₃) + (x₃²+y₃²)(x₂–x₁) ) / D

where D = 2[ x₁(y₂–y₃) + x₂(y₃–y₁) + x₃(y₁–y₂) ] (twice the signed area). The orthocenter H is the intersection of the altitudes. A convenient vector relation is H = 3G – 2O, which follows from the fact that G divides OH in the ratio 1:2. The incenter I uses side lengths a = BC, b = CA, c = AB: I = (a x₁ + b x₂ + c x₃)/(a+b+c) , (a y₁ + b y₂ + c y₃)/(a+b+c).

The nine‑point circle has centre N at the midpoint of OH and radius R/2 where R is the circumradius. Its equation can be written as (x – Nₓ)² + (y – Nᵧ)² = (R/2)². The Euler line is the line through O, G, H (and N). Its equation can be obtained from any two of these points. A useful property: the reflection of H across any side lies on the circumcircle. Also, the distance OH² = 9R² – (a²+b²+c²). These relations allow rapid solution of problems that ask for the locus of the orthocenter when a vertex moves on a line, or the condition for a triangle to be right‑angled (then O is the midpoint of the hypotenuse and H coincides with the right‑angle vertex).

Translation of Axes and Reduction of the General Second‑Degree Equation

The general second‑degree equation in two variables is A x² + 2H x y + B y² + 2G x + 2F y + C = 0. A translation of axes x = X + h , y = Y + k shifts the origin to (h , k). Substituting and collecting the first‑degree terms in X, Y gives the conditions for their elimination:

A h + H k + G = 0

H h + B k + F = 0

Solving this linear system yields the centre (h , k) of the conic (provided Δ = AB – H² ≠ 0). The transformed equation becomes A X² + 2H X Y + B Y² + C' = 0 where C' = A h² + 2H h k + B k² + 2G h + 2F k + C. The constant C' can be expressed in terms of the discriminant Δ₃ = A B C + 2 F G H – A F² – B G² – C H² as C' = Δ₃ / Δ.

Important invariants under translation (and also under rotation) are: the discriminant Δ = AB – H² (determines the type: Δ > 0 ellipse, Δ = 0 parabola, Δ < 0 hyperbola), the trace S = A + B, and the determinant of the 3×3 matrix Δ₃. The eccentricity of a central conic can be found from the eigenvalues of the quadratic part matrix [[A, H], [H, B]]. For a parabola (Δ = 0) the translation reduces the equation to the standard form Y² = 4a X or X² = 4a Y after a suitable rotation. The centre of a central conic is the unique point where the gradient of the quadratic form vanishes; it is also the pole of the line at infinity.

Family of Planes and Plane Through the Intersection of Two Planes

Two non‑parallel planes P₁: a₁x + b₁y + c₁z + d₁ = 0 and P₂: a₂x + b₂y + c₂z + d₂ = 0 intersect in a straight line. Every plane containing this line belongs to the one‑parameter family P₁ + λ P₂ = 0 (or equivalently μ P₁ + P₂ = 0). The parameter λ = –1 reproduces P₂; λ = 0 gives P₁. To find a particular plane of the family that satisfies an extra condition (passes through a given point, is parallel to a given line, or is perpendicular to another plane), substitute the condition into the family equation and solve for λ.

The distance from a point P(x₀ , y₀ , z₀) to a plane ax + by + cz + d = 0 is |a x₀ + b y₀ + c z₀ + d| / √(a² + b² + c²). The angle θ between a line with direction ratios (l , m , n) and a plane ax + by + cz + d = 0 satisfies sin θ = |a l + b m + c n| / ( √(a²+b²+c²) √(l²+m²+n²) ). The angle between two planes is the angle between their normals: cos φ = |a₁a₂ + b₁b₂ + c₁c₂| / ( √(a₁²+b₁²+c₁²) √(a₂²+b₂²+c₂²) ).

The intersection of a line (x – x₁)/l = (y – y₁)/m = (z – z₁)/n = t with a plane is found by substituting the parametric coordinates into the plane equation and solving for t. The shortest distance between two parallel planes ax+by+cz+d₁=0 and ax+by+cz+d₂=0 is |d₁ – d₂| / √(a²+b²+c²). These formulas are routinely combined with the family‑of‑planes technique to solve problems such as “find the plane through the line of intersection of P₁ and P₂ that is at a given distance from the origin” or “find the plane through the intersection line that makes a given angle with a third plane”.

  • Confusing the eccentric angle θ of an ellipse with the rational parameter t used for the parabola; the chord formulas differ.
  • Forgetting that the chord joining t₁ and t₂ on the parabola y² = 4ax is y(t₁+t₂) = 2x + 2a t₁ t₂, not y = (t₁+t₂)x + …
  • Assuming the confocal family x²/(a²+λ) + y²/(b²+λ) = 1 yields both ellipse and hyperbola for all λ; the sign of the denominators changes at λ = –b² and λ = –a².
  • Misapplying the translation centre equations when H ≠ 0; the correct system is Ah + Hk + G = 0 and Hh + Bk + F = 0.
  • Using the family of planes P₁ + λP₂ = 0 but treating λ = –1 as a new plane; it simply returns P₂.
  • Mixing the point‑to‑plane distance formula with the point‑to‑line distance formula in three dimensions.
  • Overlooking that the nine‑point circle radius is exactly half the circumradius, not half the distance between orthocenter and circumcenter.

Pair of Straight Lines: Homogeneous Equation and Angle Between Them

The homogeneous second‑degree equation a x² + 2h x y + b y² = 0 always represents a pair of straight lines passing through the origin. The nature of the pair is decided by the discriminant Δ = h² – a b. If Δ > 0 the lines are real and distinct; if Δ = 0 they are coincident (a double line); if Δ < 0 they are imaginary. The angle θ between the two lines is given by tan θ = 2√(h² – a b) / (a + b) provided a + b ≠ 0. When a + b = 0 the lines are perpendicular (θ = 90°). The condition for perpendicular lines can also be written as a + b = 0, and for parallel lines (coincident in the homogeneous case) as h² = a b.

A powerful technique is homogenisation. Suppose a line l x + m y + n = 0 cuts a curve F(x, y) = 0 (where F is a second‑degree polynomial) at two points. The combined equation of the lines joining the origin to these intersection points is obtained by making the equation of the curve homogeneous of degree two using the line equation. Replace the constant term in F by –(l x + m y)² / n² (or equivalently multiply the linear terms by (l x + m y)/n and the constant term by (l x + m y)² / n²). The resulting homogeneous equation represents the required pair of lines. This method is indispensable for problems asking for the joint equation of lines joining the origin to the points of intersection of a line and a conic.

The general second‑degree equation A x² + 2H x y + B y² + 2G x + 2F y + C = 0 represents a pair of straight lines (not necessarily through the origin) iff the determinant of the 3×3 matrix

| A H G |
| H B F |
| G F C |

is zero. When this condition holds, the equation can be factorised into two linear factors. The point of intersection of the two lines is the centre of the conic, obtained by solving A x + H y + G = 0 and H x + B y + F = 0. The angle between the lines is still given by the homogeneous quadratic part A x² + 2H x y + B y² = 0 using the same tan θ formula. This connection between the full equation and its quadratic part is a frequent source of examination questions.

Another useful result: if the pair of lines are l₁ x + m₁ y + n₁ = 0 and l₂ x + m₂ y + n₂ = 0, then the combined equation is (l₁ x + m₁ y + n₁)(l₂ x + m₂ y + n₂) = 0. Expanding and comparing coefficients yields relations such as l₁ l₂ = A, l₁ m₂ + l₂ m₁ = 2H, m₁ m₂ = B, etc. These relations allow one to reconstruct the individual lines when the combined equation and one extra condition (e.g., one line passes through a given point) are known.

Radical Axis, Power of a Point, and Coaxial System of Circles

The power of a point P(x₁, y₁) with respect to the circle S ≡ x² + y² + 2g x + 2f y + c = 0 is defined as S₁ = x₁² + y₁² + 2g x₁ + 2f y₁ + c. Geometrically, if P lies outside the circle, the power equals the square of the length of the tangent from P to the circle; if P lies on the circle, the power is zero; if P lies inside, the power is negative and its absolute value equals the product of the segments of any chord through P.

Given two circles S₁ = 0 and S₂ = 0, their radical axis is the line S₁ – S₂ = 0. This line is the locus of points having equal power with respect to both circles. It is always a straight line perpendicular to the line joining the centres of the two circles. If the circles intersect, the radical axis coincides with their common chord. If they touch, it becomes the common tangent at the point of contact. If they are non‑intersecting, the radical axis still exists as a real line, but it does not meet either circle.

A coaxial system (or pencil) of circles is a family of circles sharing the same radical axis. The general equation of a coaxial system determined by two base circles S₁ = 0 and S₂ = 0 is S₁ + λ S₂ = 0 (λ ≠ –1). Every circle in this family has its centre on the line of centres of S₁ and S₂, and all circles share the same radical axis. Two special circles in a coaxial system are the limiting points — point circles (radius zero) that belong to the system. They are the points from which the tangents to all circles of the system have zero length. The limiting points are the intersections of the radical axis with the line of centres, and they are real only for non‑intersecting type coaxial systems.

The condition for two circles S₁ ≡ x² + y² + 2g₁ x + 2f₁ y + c₁ = 0 and S₂ ≡ x² + y² + 2g₂ x + 2f₂ y + c₂ = 0 to cut orthogonally is 2 g₁ g₂ + 2 f₁ f₂ = c₁ + c₂. This follows from the Pythagorean relation between the radii and the distance between centres. Orthogonal circles appear frequently in problems involving coaxial systems because the radical axis of two orthogonal circles passes through the centre of each circle.

An important property: the radical axes of three circles taken in pairs are concurrent at a point called the radical centre. This point has equal power with respect to all three circles. If the three circles are coaxial, their radical axes coincide, and the radical centre is not uniquely defined (any point on the common radical axis qualifies). The radical centre is a powerful tool for solving problems that ask for a circle orthogonal to three given circles, or for finding the circle through the intersection points of two circles that also satisfies an orthogonality condition.

Technique: Radical Axis by Subtraction
Find the equation of the radical axis of the circles x² + y² – 4x + 6y – 12 = 0 and x² + y² + 2x – 8y + 5 = 0.
Subtract the second equation from the first: (x² + y² – 4x + 6y – 12) – (x² + y² + 2x – 8y + 5) = 0 ⇒ –6x + 14y – 17 = 0. Multiply by –1 to obtain the standard form: 6x – 14y + 17 = 0. This line is the radical axis. It is perpendicular to the line joining the centres (2, –3) and (–1, 4), as can be verified by checking the dot product of direction ratios (6, –14) and (3, –7) which is zero.
Exam‑Day Strategy
When a problem asks for the radical axis, always subtract the circle equations directly; do not complete squares. The result is linear and gives the axis instantly. Remember that the radical axis is perpendicular to the line of centres — use this as a quick check.

Equation of a Circle Through the Intersection of Two Circles and Orthogonal Circles

The family of circles passing through the intersection points of two given circles S₁ = 0 and S₂ = 0 is S₁ + λ S₂ = 0, where λ is a real parameter and λ ≠ –1 (λ = –1 reproduces S₂). This one‑parameter family contains every circle that goes through the two intersection points (real or imaginary). To find a particular circle of the family that satisfies an extra condition — for example, passing through a given point (x₀, y₀), touching a given line, or cutting a third circle orthogonally — substitute the condition into the family equation and solve for λ.

If the two base circles intersect in real points, the family represents all circles through those two points. If they do not intersect, the family still consists of circles that share the same radical axis; the parameter λ then controls the radius and centre position along the line of centres. The limiting points of the coaxial system correspond to the values of λ for which the radius becomes zero; they are obtained by solving the quadratic in λ that results from setting the radius squared to zero.

The condition for a circle S ≡ x² + y² + 2g x + 2f y + c = 0 to cut another circle S' ≡ x² + y² + 2g' x + 2f' y + c' = 0 orthogonally is 2 g g' + 2 f f' = c + c'. When a circle from the family S₁ + λ S₂ = 0 is required to be orthogonal to a fixed circle S₃ = 0, substitute the expressions for g, f, c from the family into the orthogonality condition. This yields a linear equation in λ (because the quadratic terms in λ cancel), giving a unique circle of the family that is orthogonal to S₃.

A related concept is the circle described on the line segment joining two points as diameter. If the endpoints are (x₁, y₁) and (x₂, y₂), the equation is (x – x₁)(x – x₂) + (y – y₁)(y – y₂) = 0. This form is useful when the intersection points of two circles are known explicitly, but more often the family S₁ + λ S₂ = 0 is preferred because it avoids computing the intersection coordinates.

Problems frequently combine these ideas: “Find the circle through the intersection of S₁ and S₂ that touches the line L = 0.” The tangency condition translates to the perpendicular distance from the centre of the variable circle to L being equal to its radius. This gives an equation in λ that is usually quadratic, yielding up to two circles satisfying the condition. Another common variant: “Find the circle through the intersection of S₁ and S₂ that cuts S₃ orthogonally.” As noted, this gives a linear equation in λ and a unique solution.

Three‑Dimensional Geometry: Direction Cosines, Direction Ratios, and Equation of a Line

In three dimensions, the orientation of a line is described by its direction ratios (l, m, n) — any three numbers proportional to the direction cosines. The direction cosines (cos α, cos β, cos γ) are the cosines of the angles that the line makes with the positive x, y, and z axes. They satisfy the fundamental relation cos² α + cos² β + cos² γ = 1. If (l, m, n) are direction ratios, the corresponding direction cosines are l/√(l²+m²+n²), m/√(l²+m²+n²), n/√(l²+m²+n²).

The symmetric (Cartesian) form of the equation of a line passing through a point P(x₁, y₁, z₁) with direction ratios (l, m, n) is (x – x₁)/l = (y – y₁)/m = (z – z₁)/n. The parametric form uses a parameter t: x = x₁ + l t, y = y₁ + m t, z = z₁ + n t. Both forms are interchangeable; the parameter t represents the signed distance from P only when (l, m, n) are direction cosines.

The angle between two lines with direction cosines (l₁, m₁, n₁) and (l₂, m₂, n₂) is given by cos θ = |l₁ l₂ + m₁ m₂ + n₁ n₂|. If direction ratios are used, the formula becomes cos θ = |l₁ l₂ + m₁ m₂ + n₁ n₂| / (√(l₁²+m₁²+n₁²) √(l₂²+m₂²+n₂²)). Two lines are perpendicular iff l₁ l₂ + m₁ m₂ + n₁ n₂ = 0. They are parallel iff their direction ratios are proportional.

To find the intersection of two lines given in symmetric form, equate the parametric coordinates of each line using different parameters (say t and s) and solve the resulting three equations for t and s. If a consistent solution exists, the lines intersect; otherwise they are skew or parallel. The shortest distance between two skew lines (already covered in a previous section) can also be derived using the scalar triple product of the direction vectors and the vector joining a point on each line.

A line can also be defined as the intersection of two planes. If the planes are a₁ x + b₁ y + c₁ z + d₁ = 0 and a₂ x + b₂ y + c₂ z + d₂ = 0, their line of intersection has direction ratios given by the cross product of the normals: (b₁ c₂ – b₂ c₁, c₁ a₂ – c₂ a₁, a₁ b₂ – a₂ b₁). A point on the line can be found by setting one coordinate (e.g., z = 0) and solving the two plane equations for x and y, provided the line is not parallel to the chosen coordinate plane.

Volume of a Tetrahedron and Scalar Triple Product in Coordinate Geometry

The volume V of a tetrahedron with vertices A(x₁, y₁, z₁), B(x₂, y₂, z₂), C(x₃, y₃, z₃), D(x₄, y₄, z₄) is given by one sixth of the absolute value of the scalar triple product of the vectors AB, AC, AD. In determinant form:

V = 1/6 | det | x₂–x₁ y₂–y₁ z₂–z₁ |
| x₃–x₁ y₃–y₁ z₃–z₁ |
| x₄–x₁ y₄–y₁ z₄–z₁ | |

Equivalently, using the coordinates directly,

V = 1/6 | det | x₁ y₁ z₁ 1 |
| x₂ y₂ z₂ 1 |
| x₃ y₃ z₃ 1 |
| x₄ y₄ z₄ 1 | |

The scalar triple product [AB AC AD] = AB · (AC × AD) gives the signed volume of the parallelepiped spanned by the three vectors; the tetrahedron occupies one sixth of that parallelepiped. If the scalar triple product is zero, the four points are coplanar, and the tetrahedron degenerates to zero volume.

This formula is extremely useful for problems that ask for the volume of a tetrahedron formed by a plane and the coordinate axes. For a plane x/a + y/b + z/c = 1 intersecting the axes at (a,0,0), (0,b,0), (0,0,c), the volume of the tetrahedron with the origin is V = |a b c| / 6. More generally, if a plane l x + m y + n z = p cuts the axes at (p/l,0,0), (0,p/m,0), (0,0,p/n), the volume is |p³ / (6 l m n)|.

The scalar triple product also appears in the formula for the distance from a point to a plane and the distance between two parallel planes. For a plane r · n = d (where n is a normal vector) and a point with position vector a, the perpendicular distance is |a · n – d| / |n|. This is a direct consequence of projecting the vector from a point on the plane to the given point onto the unit normal.

Another application: the volume of a parallelepiped formed by three vectors u, v, w is |u · (v × w)|. If the vectors are given in component form, the determinant of the 3×3 matrix with rows u, v, w gives the scalar triple product. This determinant is invariant under cyclic permutations and changes sign under a swap of two rows, reflecting the orientation of the triad.

  • Forgetting that the radical axis is obtained by simple subtraction of circle equations, not by eliminating the quadratic terms.

  • Mixing direction ratios with direction cosines in the angle formula without normalising; the denominator must contain the magnitudes of the direction‑ratio vectors.
  • Using the scalar triple product for volume but omitting the factor 1/6, leading to the parallelepiped volume instead of the tetrahedron volume.
