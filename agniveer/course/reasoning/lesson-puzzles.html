Key Concepts

Puzzles & Arrangements for CLAT

CLAT Logical Reasoning puzzles include seating arrangements (linear/circular), sequencing, blood relations, directions, and grouping/distribution. You must use given conditions to deduce positions/relationships and answer questions.

  • Seating arrangements:
    • Linear: Row — left/right, immediate neighbor, ends, between.
    • Circular: Round table — facing center (left/right = clockwise/anticlockwise), facing outside (left/right reversed), immediate neighbors.
    • Double row: Two rows facing each other.
  • Solving method:
    • Read all conditions; mark definite/fixed positions first.
    • Use relative positions (A is second to left of B, C is between D and E).
    • Use negative conditions (A is not at an end; B is not next to C).
    • Draw possible cases; eliminate contradictions as you place more people.
    • Answer each question from the final arrangement(s).
  • Sequencing: Order events by time/priority using clues (before, after, between, first, last).
  • Blood relations: Mother/father, son/daughter, brother/sister, husband/wife, uncle/aunt, nephew/niece, cousin, grandfather/grandmother, great-grandparents. Draw family tree; 'P is the son of Q's father's only daughter' → Q's father's only daughter = Q's sister (or Q if male? only daughter → Q's sister if Q male... careful).
  • Directions: North/South/East/West, turns (left/right = 90°), shadows (sunrise = east, shadow west), distance (Pythagoras for straight-line distance).
  • Grouping/distribution: Assign attributes (color, profession, city, subject) to persons using clues — elimination table method.
Technique: Linear arrangement
Five persons A,B,C,D,E sit in a row. A is at an end. B is second to left of D. C is between A and D. E is not at an end. Arrange.
Answer: A _ _ _ _. D must have B second to left: positions 4=D, 2=B. C between A(1) and D(4) → C can be 2 or 3, but 2=B, so C=3. E not at end → E=5. Arrangement: A B C D E.
Technique: Circular facing
Six persons around a circular table, all facing center. P is opposite Q. R is immediate left of P. S is immediate right of Q. Who is opposite R?
Answer: Place P at top, Q at bottom (opposite). R = immediate left of P (anticlockwise from P). The person opposite R = immediate right of Q (clockwise from Q) = S. So S is opposite R.
Technique: Blood relation decode
'P is the son of Q's father's only daughter.' How is P related to Q?
Answer: Q's father's only daughter = Q's sister (assuming Q male) or Q herself (if Q female — 'only daughter' of father = Q if Q is daughter). Standard convention: Q's father's only daughter = Q's sister if Q is male. P = son of Q's sister = Q's nephew. If Q female: Q's father's only daughter = Q herself → P = Q's son. Typically answer: nephew (Q male). Ambiguity noted — exams usually intend nephew.

Common Traps

  • Circular arrangement: forgetting left/right reverses when facing outside.
  • 'Immediate left/right' vs 'second to left/right' — count positions carefully.
  • Blood relations: gender of 'only daughter/son' creates ambiguity — read wording precisely.
  • Direction: shadow points west at sunrise, east at sunset (sun rises east, sets west).
  • Assuming more information than given — use only stated clues.

Memory Tricks

  • Circular facing center: Left = anticlockwise, Right = clockwise. Facing outside reverses.
  • Opposite in circle of 6: +3 positions; circle of 8: +4 positions.
  • Blood relation: Father's only daughter = sister; Mother's only son = brother (self if you).
  • Direction shadow: Morning sun (east) → shadow west; evening sun (west) → shadow east.
CLAT puzzles exam strategy
Draw diagrams for arrangements; use a table for distribution questions. Start with definite positions. If two cases remain, test each against remaining conditions and eliminate contradictions. Don't guess — every answer must follow from stated clues.
