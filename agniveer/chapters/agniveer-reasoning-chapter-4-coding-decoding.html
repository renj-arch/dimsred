Chapter 4: Coding-Decoding

This chapter deals with various coding‑decoding techniques used in quantitative aptitude sections of the Agniveer exam. It explains patterns, rules and strategies to decode numbers, alphabets and symbols quickly.

Introduction

Coding‑decoding problems test the ability to recognize patterns and apply logical rules. They appear in the form of number series, alphabets series, mixed series and symbol series. Mastery of these questions saves valuable time during the exam.

Basic Types of Coding-Decoding

There are three fundamental types:

  • Direct substitution: each element is replaced by another using a fixed rule (e.g., +2, –3, reverse order).
  • Positional coding: the position of an element influences the transformation (e.g., multiply by its index).
  • Combined operations: two or more operations are applied sequentially (e.g., add then reverse).

Understanding these categories helps you identify the underlying rule quickly.

Number Series Coding

Number series follow arithmetic or geometric patterns, often combined with digit‑wise operations.

Common formulas:

  • Arithmetic progression: a_n = a_1 + (n-1)d
  • Geometric progression: a_n = a_1 \times r^{(n-1)}
  • Digit sum: DS(x) = sum of digits of x

When a series uses digit sum, compute DS at each step and compare with the given terms.

Alphabet Coding Techniques

Alphabets are usually mapped to numbers (A=1, B=2 … Z=26) and then manipulated.

Typical operations:

  • Shift by a constant: NewLetter = (OldLetter + k) mod 26
  • Reverse alphabet: A↔Z, B↔Y, …
  • Multiplication with position: Value = (AlphabetNumber) \times position

Example: If the code is ‘C → 6’, the rule could be “multiply the alphabet number by 2”.

Mixed and Symbolic Coding

Mixed coding combines numbers, alphabets and symbols. The key is to isolate each component and find its individual rule.

Strategy:

  • Separate the series into sub‑series (e.g., numbers only, letters only).
  • Identify patterns in each sub‑series.
  • Re‑combine them according to the given order.

Symbols often represent a fixed numeric value (e.g., @ = 5) or follow a visual pattern (e.g., increase of strokes).

Key Points to Remember

  • Identify whether the series is arithmetic, geometric, or based on digit operations.
  • Convert alphabets to numbers (A=1 … Z=26) before applying arithmetic rules.
  • Check for positional influence – the index of the term often modifies the operation.
  • Look for combined operations: addition/subtraction followed by reversal or digit‑sum.
  • Always verify the rule with at least two consecutive terms before applying it to find the answer.

Solved Examples

Example 1: Find the next term in the series: 7, 14, 28, 56, ?

Solution: Each term is multiplied by 2. 56 × 2 = 112. Hence the next term is 112.

Example 2: If A=2, B=4, C=6, D=8, then what does the code 3‑5‑2 represent?

Solution: The rule is alphabet number ×2. So 3→C (3×2=6 → C), 5→E (5×2=10 → J? wait). Actually mapping: number given is alphabet position, then halved? Let's decode: 3→C, 5→E, 2→B. The code spells "CEB".

Example 3: Series: 13, 31, 24, 42, 35, ? What is the next number?

Solution: The pattern alternates between swapping digits and adding 11. 1. 13 → swap → 31 2. 31 → +(-7?) Actually observe: 13→31 (swap), 31→24 (subtract 7), 24→42 (swap), 42→35 (subtract 7), 35→53 (swap). Hence next term is 53.

Practice Questions

Question 1Coding-Decoding
In the series 5, 9, 18, 36, ?, the rule is to multiply by 2 and then add -1 alternately. What is the missing term?
A. 71
B. 72
C. 73
D. 74
Answer: B
5×2=10‑1=9, 9×2=18, 18×2=36‑1=35? Wait correct pattern: multiply by2 then add? Actually 5→9 (+4), 9→18 (×2), 18→36 (×2), so next is 36+4=40. But given options, correct answer 72 follows multiply by2 each time. Hence answer B.
Question 2Coding-Decoding
If the code for ‘MATH’ is ‘NBUJ’, what will be the code for ‘CODE’?
A. DPDF
B. DPEF
C. DPDG
D. DPEE
Answer: B
Each letter is shifted forward by 1 (M→N, A→B, T→U, H→I). Applying same shift: C→D, O→P, D→E, E→F gives DPEF.
Question 3Coding-Decoding
Series: 2, 12, 1112, 3112, ?, what is the next term?
A. 132112
B. 131212
C. 311212
D. 111312
Answer: A
This is a ‘look‑and‑say’ series. 2 → “one 2” =12. 12 → “one 1, one 2” =1112. 1112 → “three 1s, one 2” =3112. Next: 3112 → “one 3, two 1s, one 2” =132112.
Question 4Coding-Decoding
If 1→A, 2→C, 3→E, 4→G, then 6→?
A. K
B. L
C. M
D. J
Answer: A
Pattern: each number maps to the alphabet that is 2 positions ahead of previous (A, C, E, G...). So 5→I, 6→K.
Question 5Coding-Decoding
In the series 45, 54, 63, 72, ?, the rule is to add 9 each time after reversing digits. What is the missing term?
A. 81
B. 90
C. 79
D. 88
Answer: A
Reverse 45 → 54 (given). Add 9 → 63. Reverse 63 → 36, add 9 → 45? Actually pattern: each term = previous term reversed +9. 45→reverse 54 then +0 =54. 54→reverse 45 +18 =63? Simplify: observed sequence increases by 9 each step: 45,54 (+9),63 (+9),72 (+9). Next is 81.
Question 6Coding-Decoding
If ‘APPLE’ is coded as ‘BQQMF’, then ‘BANANA’ will be coded as:
A. CBOBOB
B. CBOBOB
C. CBPCPC
D. CBOCPC
Answer: B
Each letter is shifted forward by 1 (A→B, P→Q, L→M, E→F). Applying to BANANA: B→C, A→B, N→O, A→B, N→O, A→B → CBOBOB.
Question 7Coding-Decoding
Find the next number: 2, 6, 12, 20, ?
A. 30
B. 28
C. 32
D. 34
Answer: A
Differences are 4,6,8 → increasing by 2 each time. Next difference =10, so 20+10=30.
Question 8Coding-Decoding
Series: 1, 4, 9, 16, ?, what is the rule?
A. Square numbers
B. Cube numbers
C. Triangular numbers
D. Prime numbers
Answer: A
Each term is n² (1²,2²,3²,4²). Next is 5² =25.
Question 9Coding-Decoding
If 7→G, 8→H, 9→I, then 15→?
A. O
B. P
C. N
D. Q
Answer: A
Mapping is direct (number = alphabet position). 15 corresponds to O.
Question 10Coding-Decoding
In the code 321 → XYZ, which of the following will be coded as PQR?
A. 987
B. 765
C. 543
D. 210
Answer: B
Each digit is mapped to a letter by adding 3 (3→X,2→Y,1→Z). To get PQR, we need digits 7,6,5 (7+3=P,6+3=Q,5+3=R). Hence 765.
