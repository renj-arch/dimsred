Five books arranged on a shelf. Math is above English. Science is below History but above Geography. English is above Science. Which is at the bottom?
A. GeographyB. ScienceC. EnglishD. History
Answer: A
Direct Elimination~3sshortcut

Remove non-bottoms first

  1. List positions: Top to Bottom.
  2. Identify Math > English > Science > Geography.
  3. Note History is above Science.
  4. Eliminate anything not below all others.
  5. Geography is the only item with no one below it.
  6. Final: Geography (Option A)

Situation: 'Exams have been postponed due to a natural calamity.' Course I: The education board should announce revised dates immediately. Course II: The board should reduce the syllabus to reduce student burden.
A. Only I followsB. Only II followsC. Both followD. Neither follows
Answer: A
Keyword Link~3sshortcut

Map 'postponed' to 'announcement'

  1. Identify situation: Exams postponed.
  2. Link consequence: Board must announce new dates immediately.
  3. Ignore irrelevant Course II about syllabus reduction.
  4. Select option matching the logical link.
More methods (2)
Direct Deduction~4sinvariant

Follow the immediate obligation

  1. Read Course I: Postponement requires revised dates.
  2. Verify validity: Immediate announcement is standard procedure.
  3. Read Course II: Syllabus reduction is not a direct result of postponement.
  4. Conclude only Course I follows logically.
Elimination Filter~5sshortcut

Remove non-mandatory actions

  1. Check if syllabus cut (II) is forced by delay.
  2. Deduce II is optional, not mandatory.
  3. Keep I as the necessary administrative step.
  4. Reject options B, C, D; select A.

Statement: 'The HR department has launched a skill development program for employees.' Assumption I: Employees currently lack some required skills. Assumption II: The program will improve employee productivity.
A. Only I is implicitB. Only II is implicitC. Both are implicitD. Neither is implicit
Answer: A · paper key: C

The lab answer differs from the answer key in the paper; kept for review.

Keyword Match~3sshortcut

link action to cause

  1. Identify program purpose: skill development implies current lack of skills (I).
  2. Note 'productivity' is a possible outcome, not a guaranteed immediate fact (II).
More methods (2)
Logic Filter~4sinvariant

separate certainty from hope

  1. Assumption I connects directly to the existence of the program (valid cause).
  2. Assumption II treats a potential benefit as an implicit certainty (invalid leap).
  3. Select option where only the first assumption holds true.
Direct Deduction~5smnemonic

validate each claim strictly

  1. Check I: Does 'skill development' imply missing skills? Yes, so I is implicit.
  2. Check II: Does it guarantee productivity improvement? No, that is an assumption, not a fact.
  3. Conclusion: Only I is implicit.
