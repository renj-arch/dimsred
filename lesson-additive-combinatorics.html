Additive Combinatorics — Sumsets, the Cauchy-Davenport Theorem & Freiman's Theorem

Additive combinatorics is the study of additive structures in sets of integers (or more generally, abelian groups). A central object is the sumset A+B = {a+b : a∈A, b∈B}. The fundamental question: what can the size of A+B tell us about the structure of A and B? The Cauchy-Davenport theorem gives the sharp lower bound |A+B| ≥ min(p, |A|+|B|−1) for subsets of ℤ/pℤ with p prime. The Plünnecke–Ruzsa inequalities provide sumset estimates via the Ruzsa triangle inequality and doubling constants. Freiman's theorem classifies sets with small doubling: if |A+A| ≤ K|A|, then A is contained in a generalized arithmetic progression of bounded rank and size. The Balog–Szemerédi–Gowers theorem links large additive energy to small sumset. The capset problem — finding large subsets of 𝔽₃ⁿ with no three-term arithmetic progression — saw a breakthrough via the Croot–Lev–Pach polynomial method and the Ellenberg–Gijswijt theorem.

"Additive combinatorics is number theory through the lens of finite groups."
— Terence Tao
Part 1

📏 Sumsets and the Cauchy-Davenport Theorem

Sumsets
Sumsets, the Cauchy-Davenport Theorem, and the Kneser Theorem
Let A,B be non-empty finite subsets of an abelian group G. The sumset is A+B = {a+b : a∈A, b∈B}. The doubling constant σ[A] = |A+A|/|A| measures how "close" A is to an arithmetic progression. The Cauchy-Davenport theorem (Cauchy 1813, Davenport 1935): if A,B ⊆ ℤ/pℤ with p prime, then |A+B| ≥ min(p, |A|+|B|−1). This is sharp: take A,B as arithmetic progressions with the same difference. The Kneser theorem generalizes Cauchy-Davenport to arbitrary abelian groups: if A,B are non-empty subsets of an abelian group G, then |A+B| ≥ |A+H| + |B+H| − |H| where H = Stab(A+B) = {g ∈ G : g + A + B = A + B} is the stabilizer of the sumset. The inverse theorem: if |A+B| = |A|+|B|−1 in ℤ/pℤ, then A and B are arithmetic progressions with the same common difference. The Erdős–Ginzburg–Ziv theorem: any 2n−1 integers contain n whose sum is divisible by n — a classic application of the Cauchy-Davenport principle.
The size of a sumset is at least the sum of the sizes minus one in ℤ/pℤ; when equality holds, the sets are arithmetic progressions — a perfect inverse theorem.
Part 2

🌍 The Plünnecke–Ruzsa Inequalities

Ruzsa Calculus
Plünnecke–Ruzsa Inequalities, the Ruzsa Triangle Inequality, and the Sum-Product Phenomenon
The Ruzsa triangle inequality: for non-empty finite sets A,B,C in an abelian group, |A−C| ≤ |A−B|·|B−C|/|B|. This is the foundation of "Ruzsa calculus" — it allows transferring sumset information between different sets. The Plünnecke–Ruzsa theorem (Ruzsa, 1996): if |A+A| ≤ K|A|, then for all integers m,n ≥ 1, |mA − nA| ≤ K^{m+n}·|A| where kA = A+⋯+A (k times). Petridis (2012) gave a short proof using the Plünnecke graph and a commutativity argument. The Ruzsa covering lemma: A ⊆ B−B + X for some set X of size at most |A+B|/|B|. The sum-product phenomenon (Bourgain, 2003): for a sufficiently small set A ⊂ 𝔽_p, max(|A+A|, |A·A|) ≥ c·|A|^{1+δ} for some δ > 0 — a set cannot be simultaneously closed under addition and multiplication unless it is the whole field.
The Plünnecke–Ruzsa inequalities control the growth of iterated sumsets purely in terms of the doubling constant — a powerful amplification tool.
Part 3

🧮 The Balog–Szemerédi–Gowers Theorem

Energy
Additive Energy, the Balog–Szemerédi–Gowers Theorem, and Fourier Analysis
The additive energy of a set A is E(A) = |{(a₁,a₂,a₃,a₄)∈A⁴ : a₁+a₂ = a₃+a₄}| — it counts the number of additive quadruples. By Cauchy-Schwarz, |A|⁴ ≤ E(A)·|A+A|, so large sumset forces small energy. The Balog–Szemerédi–Gowers theorem (the BSG theorem) is the converse: if E(A) ≥ |A|³/K, then there exists a subset A'⊂A of size |A'| ≥ c·|A|/K^{C} such that |A'+A'| ≤ C'·K⁴·|A'|. This is the inverse theorem for additive energy: large additive energy implies a large subset has small sumset. The Gowers U²-norm provides a Fourier-analytic proof: E(A) = Σ_{r∈Ĝ} |̂1_A(r)|⁴, where ̂1_A are Fourier coefficients. The BSG theorem is the key ingredient in Gowers's proof of Szemerédi's theorem (the inverse U²-theorem for arithmetic progressions of length 3).
Large additive energy is equivalent to having a large subset with small sumset — the BSG theorem bridges energy and structure.
Part 4

🔥 The Capset Problem and Recent Breakthroughs

Capset
The Capset Problem, the Croot–Lev–Pach Polynomial Method, and the Ellenberg–Gijswijt Theorem
The capset problem: find the largest subset A ⊆ 𝔽₃ⁿ containing no three-term arithmetic progression (x, x+d, x+2d with d ≠ 0). The trivial bound: |A| ≤ 2·3ⁿ (by taking two residues). Meshulam (1995) proved |A| ≤ 3·3ⁿ/n using Fourier analysis. The breakthrough came in 2017: Croot, Lev, and Pach solved the analogous problem in ℤ₄ⁿ, showing that cap sets have size at most c^n for c < 4. Ellenberg and Gijswijt immediately adapted the method to 𝔽₃ⁿ, proving |A| ≤ c·2.756ⁿ. The method: for a capset A, define the polynomial P(x,y,z) = ∏_{i=1}^{n} (1−x_i−y_i−z_i) and bound the rank of the matrix M_{a,b} = P(a,b,a+b) using the slice rank (a generalization of the polynomial method). The Green–Tao theorem (2008): the primes contain arbitrarily long arithmetic progressions — a landmark in additive combinatorics using Szemerédi's theorem and the transference principle. The Bogolyubov–Ruzsa analog: in ℤ, continuous Fourier analysis modulo 1 shows that A+A−A−A contains a large Bohr set. The polynomial Freiman–Ruzsa conjecture (still open): if |A+A| ≤ K|A| in ℤ, then A can be covered by K^{O(1)} cosets of a finite subgroup of size ≤ |A|. Sanders (2012) gave the best known effective Freiman bound for ℤ.
The polynomial method — particularly the slice rank technique — revolutionized additive combinatorics, solving the capset problem and opening new frontiers.
