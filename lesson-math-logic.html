Mathematical Logic — Gödel's Theorems, Computability & the Limits of Formal Systems

Deep dive into Mathematical Logic — propositional logic (truth tables, logical equivalence, the deduction theorem), first-order logic (predicates, quantifiers, terms, formulas, the satisfaction relation ⊧), the completeness theorem (Gödel 1929, every logically valid formula has a finite proof), the compactness theorem (a set of sentences has a model iff every finite subset has one), the Löwenheim–Skolem theorems (the existence of countable models for countable theories and uncountable models of arbitrarily large cardinality), Gödel's incompleteness theorems (1931, any consistent recursively axiomatizable theory extending Robinson arithmetic Q is incomplete and cannot prove its own consistency), the Entscheidungsproblem (Hilbert's decision problem, solved negatively by Turing and Church), the Church–Turing thesis, the halting problem (the undecidability of whether a Turing machine halts), and the arithmetic hierarchy (the classification of definable sets by quantifier complexity).

"The true significance of Gödel's incompleteness theorems lies in the insight that the structure of truth is more complex than the structure of provability."
— Kurt Gödel
Part 1

📜 Propositional and First-Order Logic

Foundations
Syntax, Semantics, Natural Deduction, and the Completeness Theorem
Propositional logic begins with atomic propositions p, q, r, … and connectives ¬, ∧, ∨, →, ↔. A truth assignment v maps each atom to {T, F}; the truth value of a formula is computed recursively. A formula φ is a tautology (⊧ φ) if v(φ) = T for all assignments. The deduction theorem: if Γ ∪ {φ} ⊢ ψ then Γ ⊢ φ → ψ. The soundness theorem: if Γ ⊢ φ then Γ ⊧ φ. The completeness theorem: if Γ ⊧ φ then Γ ⊢ φ — provability coincides with logical consequence. First-order logic extends propositional logic with quantifiers ∀ and ∃, variables x, y, z, …, relation symbols R, P, …, function symbols f, g, …, and constant symbols c, d, …. A structure 𝔄 = (A, R^𝔄, f^𝔄, c^𝔄) consists of a domain A and interpretations. The satisfaction relation 𝔄 ⊧ φ[s] (with assignment s) is defined by Tarski's truth definition. A sentence φ is valid (⊧ φ) if true in all structures. Gödel's completeness theorem for first-order logic: a sentence φ is provable in a standard deductive system iff it is valid (⊧ φ ⇔ ⊢ φ). The compactness theorem (an immediate corollary): a set of sentences Σ has a model iff every finite subset Σ₀ ⊆ Σ has a model. The Löwenheim–Skolem theorem: if a countable theory T has an infinite model, it has models of every infinite cardinality. The downward Löwenheim–Skolem: any infinite structure has a countable elementary substructure. The Skolem paradox: ZFC set theory has a countable model, yet inside it proves uncountable sets exist — a phenomenon of relative cardinality.
First-order logic admits a complete deductive system: syntactic provability exactly captures semantic logical consequence, a foundational result due to Gödel.
Part 2

🧩 Gödel's Incompleteness Theorems

Incompleteness
Gödel Numbering, Self-Reference, and the Limits of Formal Provability
Gödel's first incompleteness theorem (1931): any consistent recursively axiomatizable theory T that interprets Robinson arithmetic Q is incomplete — there exists a sentence G_T (the Gödel sentence) such that T ⊬ G_T and T ⊬ ¬G_T. The proof uses Gödel numbering: assign a natural number ⌜φ⌝ to each formula φ via prime factorization (the Gödel code). The provability predicate Bew(x) = ∃y Proof(y, x) expresses "x is the code of a theorem." The diagonal lemma (self-reference): for any formula φ(x), there exists a sentence ψ such that T ⊢ ψ ↔ φ(⌜ψ⌝). Apply this to ¬Bew(x) to obtain the Gödel sentence G. The second incompleteness theorem: if T is consistent, T cannot prove its own consistency statement Con(T) = ¬Bew(⌜0=1⌝). This shattered Hilbert's program (the hope to prove the consistency of mathematics using finitary methods). Rosser's improvement: the Gödel–Rosser theorem eliminates the ω-consistency requirement. The arithmetic hierarchy classifies arithmetical formulas by quantifier alternations: Σ₀ = Π₀ = Δ₀ formulas have only bounded quantifiers. Σ_{n+1} = ∃x₁…∃x_k φ where φ ∈ Π_n. Π_{n+1} = ∀x₁…∀x_k φ where φ ∈ Σ_n. The Tarski undefinability theorem: truth in the standard model ℕ is not arithmetically definable (no formula True(x) such that ℕ ⊧ True(⌜φ⌝) ⇔ ℕ ⊧ φ). Gentzen's consistency proof for PA uses transfinite induction up to ε₀.
Any sufficiently strong consistent formal system is incomplete — there are true statements it cannot prove, and its own consistency is beyond its reach.
Part 3

⚙️ Computability Theory and the Entscheidungsproblem

Computation
Turing Machines, the Halting Problem, and the Church–Turing Thesis
Turing machines (Turing, 1936): an infinite tape divided into cells, a head that reads/writes symbols, a finite set of states, and a transition function δ: Q × Γ → Q × Γ × {L, R}. A configuration is (state, tape content, head position). A machine halts when it enters a designated halting state. The halting problem H = {⟨M, w⟩ | Turing machine M halts on input w} is undecidable (Turing's proof by diagonalization: assume a decider Halt exists, construct a machine D that does the opposite, leading to contradiction). The Church–Turing thesis: any effectively computable function can be computed by a Turing machine. Church's theorem (1936): first-order logic is undecidable — there is no algorithm to decide whether a given first-order sentence is valid (the Entscheidungsproblem has a negative solution). The Rice theorem: any non-trivial semantic property of Turing machines is undecidable. The recursion theorem (Kleene): for any computable function f, there exists e such that φ_e = φ_{f(e)} (the fixed point theorem). The arithmetic hierarchy classifies decision problems: Σ₁ are recursively enumerable (r.e.) sets, Π₁ are co-r.e., Δ₁ are recursive. The jump operator K = ∅' (the halting set) is Σ₁-complete. Higher jumps ∅^(n) give a hierarchy of increasingly undecidable problems. Post's problem: are there r.e. sets of intermediate Turing degree between 0 and 0'? Solved positively by Friedberg and Muchnik (1956) via priority arguments. The polynomial hierarchy PH and the P vs NP problem are the complexity-theoretic analogues.
The halting problem is the canonical undecidable problem: no algorithm can determine whether an arbitrary program terminates, establishing fundamental limits of computation.
Part 4

🌐 Model Theory and the Limits of Formal Systems

Model Theory
Type Theory, Ultraproducts, Saturation, and the Löwenheim–Skolem Theorems
Model theory is the study of the relationship between formal theories and their models. A type p(x₁, …, x_n) over a set A ⊆ M is a maximal consistent set of formulas with parameters from A. The compactness theorem implies any finitely realizable type is realized in an elementary extension. The omitting types theorem: if a type p is non-principal (isolated by no formula), there is a model of T omitting p. Ultraproducts (Łoś's theorem, 1955): given structures 𝔄_i (i ∈ I) and an ultrafilter U on I, the ultraproduct ∏_U 𝔄_i satisfies Łoś's theorem: ∏_U 𝔄_i ⊧ φ(⟨a_i⟩) iff {i | 𝔄_i ⊧ φ(a_i)} ∈ U. This proves the compactness theorem elegantly. Nonstandard analysis (Robinson, 1960s): the ultraproduct ∏_U ℝ gives the hyperreals *ℝ, an ordered field with infinitesimals. A model is κ-saturated if every type over a set of size < κ is realized. Saturated models are universal and homogeneous. A categorical theory in power κ has exactly one model of cardinality κ up to isomorphism. The Morley categoricity theorem (1965): if a countable first-order theory T is categorical in some uncountable power, it is categorical in all uncountable powers. Stability theory (Shelah): a theory T is λ-stable if for any model M of size λ, there are at most λ complete types over M. The classification program aims to classify theories as "classifiable" (admitting a structure theory like Shelah's main gap) or "non-classifiable." The ZFC axioms and the continuum hypothesis (Cohen's independence proof via forcing, 1963). Large cardinals and their consistency strength hierarchy.
Model theory studies the landscapes of mathematical structures that satisfy given axioms, revealing deep connections between syntax and semantics through ultraproducts, types, and saturation.
