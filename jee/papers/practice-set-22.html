ΔH (kJ/mol)ΔS (J/mol·K)
-50-100

B. T > 500 K

Correct Answer: A

Q2. Mathematics
Evaluate the limit: lim_{x→0} (e^x - 1 - x)/x^2.
A. 1/2
B. 0
C. 1
D. 2
Correct Answer: A
Shortcut: Use the Maclaurin expansion e^x = 1 + x + x^2/2 + x^3/6 + ... Then numerator ≈ x^2/2, so limit = 1/2. Full solution: Apply L'Hospital's rule twice: first derivative gives (e^x -1)/(2x), still 0/0; second derivative gives e^x/2 → 1/2 as x→0.
Q3. Physics
Light of wavelength λ is incident on a photosensitive metal surface with work function φ₀. The stopping potential is measured to be V₀. If the wavelength of the incident light is changed to λ/2 (assuming λ < hc/φ₀), the new stopping potential becomes:
A. 2V₀
B. V₀ + hc/(eλ)
C. 2V₀ + hc/(eλ)
D. 4V₀
Correct Answer: B
Shortcut: Use Einstein's photoelectric equation eV₀ = hc/λ - φ₀. For λ/2, eV₀' = 2hc/λ - φ₀ = (hc/λ - φ₀) + hc/λ = eV₀ + hc/λ. Thus V₀' = V₀ + hc/(eλ). Full Solution: For first case, eV₀ = hc/λ - φ₀. For second case (λ' = λ/2), eV₀' = hc/(λ/2) - φ₀ = 2hc/λ - φ₀. Substitute φ₀ = hc/λ - eV₀ from first equation: eV₀' = 2hc/λ - (hc/λ - eV₀) = hc/λ + eV₀. Therefore V₀' = V₀ + hc/(eλ).
Q4. Physics
In a Young's double slit experiment (YDSE), the fringe width is β. A transparent glass slab of thickness t and refractive index μ is introduced in the path of one of the beams. The central bright fringe shifts to a position originally occupied by the n-th bright fringe. The value of n is:
A. μt/λ
B. (μ - 1)t/β
C. (μ - 1)t/λ
D. (μ - 1)tλ/β
Correct Answer: C
Shortcut: Optical path difference introduced by slab = (μ - 1)t. Number of fringes shifted n = (Path difference) / λ = (μ - 1)t/λ. Full Solution: Introduction of a slab of thickness t and refractive index μ in one path increases the optical path length by (μ - 1)t compared to air. For the central bright fringe (zero path difference) to appear at the new position, the geometrical path difference must compensate this. The shift corresponds to n fringes where nλ = (μ - 1)t. Hence n = (μ - 1)t/λ. Note: Fringe width β = λD/d is not needed for n.

Q6. Mathematics
If ω is a complex cube root of unity, then the value of (1 - ω + ω²)⁵ + (1 - ω² + ω)⁵ is:
A. 32
B. -32
C. 64
D. -64
Correct Answer: A
Shortcut: Use 1+ω+ω²=0 ⇒ 1-ω+ω² = -2ω and 1-ω²+ω = -2ω². The expression becomes (-2ω)⁵ + (-2ω²)⁵ = -32(ω⁵+ω¹⁰) = -32(ω²+ω) = -32(-1) = 32. Full: Since ω³=1 and ω≠1, we have 1+ω+ω²=0. Thus 1-ω+ω² = -2ω and 1+ω-ω² = -2ω². Raising to power 5 and summing gives -32(ω⁵+ω¹⁰) = -32(ω²+ω) = 32.

Defect TypeDescription

Q10. Physics
A solid sphere, a hollow sphere, and a uniform disc, all having identical mass Mand radius R, are released from rest at the top of an identical rough inclined plane. Which object reaches the bottom first?
A. Solid Sphere
B. Hollow Sphere
C. Disc
D. All reach simultaneously
Correct Answer: A
Shortcut: Acceleration a = g sinθ / (1 + I/MR²). Smaller I/MR² gives larger 'a'. Ratios: Solid (2/5=0.4), Disc (1/2=0.5), Hollow (2/3≈0.67). Solid sphere has smallest ratio, hence highest acceleration. Full Solution: For rolling without slipping, a = g sinθ / (1 + k²/R²) where k is radius of gyration. Solid sphere: k²/R² = 2/5 ⇒ a = 5/7 g sinθ. Disc: k²/R² = 1/2 ⇒ a = 2/3 g sinθ. Hollow sphere: k²/R² = 2/3 ⇒ a = 3/5 g sinθ. Since 5/7 > 2/3 > 3/5, the solid sphere accelerates fastest and reaches first.

Q12. Physics
A parallel plate capacitor of capacitance C₀ is charged to charge Q₀ and disconnected from the battery. A dielectric slab of dielectric constant K is slowly inserted between the plates completely filling the gap. The work done by the external agent during this process is:
A. Q₀²/(2C₀) (1/K - 1)
B. Q₀²/(2C₀) (1 - 1/K)
C. Q₀²/(2KC₀) (K - 1)
D. Q₀²/(2C₀) (K - 1)
Correct Answer: A
Shortcut: For an isolated capacitor (Q constant), energy U = Q²/(2C). Initial Uᵢ = Q₀²/(2C₀). Final U_f = Q₀²/(2KC₀). Work done by external agent W_ext = ΔU = U_f - Uᵢ = Q₀²/(2C₀)(1/K - 1). The negative sign indicates the agent works against the attractive force. Full Solution: Since the battery is disconnected, charge Q₀ remains constant. Capacitance becomes KC₀. Initial energy Uᵢ = Q₀²/(2C₀). Final energy U_f = Q₀²/(2KC₀). By work-energy theorem, work done by external agent equals change in stored energy: W_ext = U_f - Uᵢ = Q₀²/(2C₀)(1/K - 1).
Q13. Mathematics
If sinθ + cosθ = 1/2, then the value of sin2θ is:
A. -1/2
B. 1/4
C. -3/4
D. 3/4
Correct Answer: C
Shortcut: Square both sides: (sinθ+cosθ)^2 = sin^2θ+cos^2θ+2sinθcosθ = 1+sin2θ = 1/4 → sin2θ = -3/4. Full solution: (1/2)^2 = 1/4 = 1 + sin2θ ⇒ sin2θ = 1/4 - 1 = -3/4.
Q14. Physics
An on-conducting thin ring of radius R carries a total charge q uniformly distributed over its circumference. The ring is rotated about its axis with a constant angular velocity ω. The magnetic moment of the rotating ring is:
A. qωR²/4
B. qωR²/2
C. qωR²
D. qωR/2
Correct Answer: B
Shortcut: Equivalent current I = Charge / Time Period = q / (2π/ω) = qω/(2π). Magnetic moment μ = I × Area = (qω/(2π)) × πR² = qωR²/2. Full Solution: The rotating charge constitutes a current loop. Current I = q/T = qω/(2π). Area of the loop A = πR². Magnetic moment M = I × A = (qω/(2π)) × πR² = ½ qωR². Direction is along the axis given by right-hand rule.
Q15. Mathematics
If ω is an on-real cube root of unity, then the value of (1 - ω + ω²)⁴ + (1 + ω - ω²)⁴ is:
A. -16
B. 16
C. 0
D. 8
Correct Answer: A
Shortcut: Use 1+ω+ω²=0 ⇒ 1+ω²=-ω and 1+ω=-ω². Then (1-ω+ω²)=-2ω and (1+ω-ω²)=-2ω². The expression becomes 16ω⁴+16ω⁸=16(ω+ω²)=16(-1)=-16. Full Solution: Since ω³=1 and 1+ω+ω²=0, we have 1+ω²=-ω and 1+ω=-ω². First bracket: (1+ω²)-ω = -ω-ω = -2ω. Second bracket: (1+ω)-ω² = -ω²-ω² = -2ω². Raising to power 4: (-2ω)⁴ + (-2ω²)⁴ = 16ω⁴ + 16ω⁸ = 16ω + 16ω² = 16(ω+ω²) = -16.
