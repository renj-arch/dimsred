Let ω be a complex cube root of unity (ω ≠ 1). The value of (1 - ω + ω^2)(1 + ω - ω^2) is:
A. 0
B. 1
C. 2
D. 4
Correct Answer: D
Shortcut: Use 1+ω+ω^2=0 ⇒ 1+ω^2 = -ω and 1+ω = -ω^2. Then first factor = -2ω, second = -2ω^2. Product = 4ω^3 = 4. Full: Since ω^3=1 and 1+ω+ω^2=0, we have 1-ω+ω^2 = -2ω and 1+ω-ω^2 = -2ω^2. Multiplying gives 4ω^3 = 4.

The line y = 2x + c is a tangent to the ellipse x^2/9 + y^2/4 = 1. The value of c^2 is:
A. 36
B. 20
C. 40
D. 16
Correct Answer: C
Shortcut: For ellipse x^2/a^2 + y^2/b^2 = 1, the line y = mx + c is tangent iff c^2 = a^2 m^2 + b^2. Here a^2=9, b^2=4, m=2 ⇒ c^2 = 9·4 + 4 = 40. Full: Substitute y=2x+c into ellipse equation, set discriminant of resulting quadratic in x to zero. This yields c^2 = a^2 m^2 + b^2 = 40.

An aqueous solution of a weak binary electrolyte AB (concentration 0.1 mol L⁻¹) exhibits an osmotic pressure of 3.0 atm at 300 K. Assuming the gas constant R = 0.0821 L atm K⁻¹ mol⁻¹, the degree of dissociation of AB is approximately:
A. 0.10
B. 0.22
C. 0.35
D. 0.45
Correct Answer: B
Shortcut: Calculate van't Hoff factor i = Π/CRT. CRT = 0.1 × 0.0821 × 300 ≈ 2.463. i = 3.0/2.463 ≈ 1.22. For AB ⇌ A⁺ + B⁻ (n=2), α = (i−1)/(n−1) = 0.22. Worked: Osmotic pressure Π = iCRT ⇒ i = Π/CRT = 3.0 / (0.1 × 0.0821 × 300) = 1.218. Degree of dissociation α = (i−1)/(ν−1) where ν=2 (ions produced). α = 0.218 ≈ 0.22.

A. C/2
B. 3C/2
C. 2C
D. 5C/2
Correct Answer: B
Shortcut: Two capacitors in series give C/2; adding a third in parallel adds C, yielding C/2 + C = 3C/2. Full solution: Series equivalent C_s = (C×C)/(C+C) = C/2. Parallel with C gives C_eq = C_s + C = C/2 + C = 3C/2.

The value of the definite integral ∫_{-π/2}^{π/2} sin^3 x cos^2 x dx is:
A. 0
B. π/4
C. 1/2
D. 2/3
Correct Answer: A
Shortcut: The integrand f(x)=sin^3 x cos^2 x is an odd function because sin^3 x is odd and cos^2 x is even. Integral of an odd function over symmetric interval [-a,a] is zero. Full: Since f(-x) = -f(x), ∫_{-a}^{a} f(x) dx = 0. Here a=π/2, so the integral equals 0.

A. 53.6
B. 76.4
C. 107.2
D. 121.8
Correct Answer: C
Shortcut: Near 300 K, a 10 K rise doubles the rate for Eₐ ≈ 53.6 kJ mol⁻¹ (using ln2 = Eₐ/R × 10/300²). Since rate increases 4-fold (doubles twice), Eₐ ≈ 2 × 53.6 = 107.2 kJ mol⁻¹.
