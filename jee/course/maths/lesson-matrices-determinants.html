Introduction to Matrices and Basic Operations

1.1 Definition and Notation

A matrix is a rectangular array of numbers arranged in rows and columns, and it serves as a compact way to represent linear transformations and systems of linear equations. The size of a matrix is described by its order m × n, where m denotes the number of rows and n the number of columns; for example, a 3 × 2 matrix has three rows and two columns. Individual entries are denoted by aij, where the first subscript indicates the row and the second the column. Two matrices are equal only when they have the same order and each corresponding entry is identical, a fact that underpins every algebraic manipulation that follows.

1.2 Addition, Subtraction and Scalar Multiplication

Matrix addition and subtraction are defined entry‑wise and therefore require the operands to share the same order; the result is a matrix of that order whose each element is the sum or difference of the corresponding elements. Scalar multiplication multiplies every entry of a matrix by a constant k, producing a matrix of the same order. These operations satisfy the familiar commutative, associative and distributive laws, which means that the set of all m × n matrices over a field forms a vector space. The zero matrix, whose every entry is zero, acts as the additive identity, and the additive inverse of a matrix A is simply –A, obtained by multiplying each entry by –1.

1.3 Matrix Multiplication

Unlike addition, matrix multiplication is not defined entry‑wise; the product AB of an m × p matrix A and a p × n matrix B is an m × n matrix whose (i, j) entry equals the sum over k = 1 to p of aik bkj. This definition captures the composition of linear maps, which explains why multiplication is associative but generally not commutative; AB ≠ BA in most cases, and the order of factors matters critically when solving equations. The identity matrix In of order n has ones on the main diagonal and zeros elsewhere, and it satisfies AI = IA = A for any compatible square matrix A. The transpose of a matrix A, denoted AT, interchanges rows and columns, and it obeys (AB)T = BTAT, a property frequently used in proofs involving symmetric and orthogonal matrices.

Determinants and Their Properties

2.1 Definition of the Determinant

The determinant is a scalar value associated with a square matrix that encodes important geometric and algebraic information, such as whether the matrix is invertible and the volume scaling factor of the linear transformation it represents. For a 1 × 1 matrix [a] the determinant is simply a. For a 2 × 2 matrix [[a, b], [c, d]] the determinant is ad – bc. For higher orders the determinant can be defined recursively by cofactor expansion along any row or column: det(A) = Σj=1n (–1)i+j aij det(Mij), where Mij is the (n–1) × (n–1) submatrix obtained by deleting row i and column j. This Laplace expansion shows that the determinant is a multilinear alternating function of the rows (or columns).

2.2 Elementary Row Operations and Determinant Behaviour

Elementary row operations affect the determinant in predictable ways: swapping two rows multiplies the determinant by –1; multiplying a row by a non‑zero scalar k multiplies the determinant by k; adding a multiple of one row to another leaves the determinant unchanged. These rules allow the determinant to be computed efficiently by reducing the matrix to upper triangular form, where the determinant equals the product of the diagonal entries. Because the determinant of a triangular matrix is the product of its diagonal elements, the computation becomes straightforward once the matrix is in echelon form, and the sign changes from row swaps are tracked separately.

2.3 Important Properties and Theorems

Several fundamental theorems govern determinants. The determinant of a product equals the product of the determinants: det(AB) = det(A) det(B). Consequently, a square matrix is invertible if and only if its determinant is non‑zero. The determinant of the transpose equals the determinant of the original matrix: det(AT) = det(A). For a scalar k and an n × n matrix A, det(kA) = kn det(A). The adjugate matrix, denoted adj(A), satisfies A adj(A) = adj(A) A = det(A) I, linking determinants directly to inverses. Cramer's rule expresses the solution of a linear system AX = B in terms of determinants, provided det(A) ≠ 0, giving xi = det(Ai) / det(A) where Ai is A with its i‑th column replaced by B.

Example 1
Find the determinant of the 3 × 3 matrix A = [[2, –1, 3], [0, 4, 5], [1, 0, –2]] and use Cramer's rule to solve the system AX = [7, –3, 4]T.
First compute det(A) by expanding along the first row: det(A) = 2·det[[4,5],[0,–2]] – (–1)·det[[0,5],[1,–2]] + 3·det[[0,4],[1,0]] = 2·(4·(–2) – 5·0) + 1·(0·(–2) – 5·1) + 3·(0·0 – 4·1) = 2·(–8) + 1·(–5) + 3·(–4) = –16 –5 –12 = –33. Since det(A) ≠ 0, the system has a unique solution. Form A1 by replacing column 1 with the constant vector: [[7, –1, 3], [–3, 4, 5], [4, 0, –2]]. Its determinant is 7·det[[4,5],[0,–2]] – (–1)·det[[–3,5],[4,–2]] + 3·det[[–3,4],[4,0]] = 7·(–8) + 1·(6 – 20) + 3·(0 – 16) = –56 –14 –48 = –118. Thus x1 = (–118)/(–33) = 118/33. Similarly, A2 = [[2,7,3],[0,–3,5],[1,4,–2]] gives det = 2·det[[–3,5],[4,–2]] – 7·det[[0,5],[1,–2]] + 3·det[[0,–3],[1,4]] = 2·(6 –20) –7·(0 –5) +3·(0+3) = 2·(–14) +35 +9 = –28+44 = 16, so x2 = 16/(–33) = –16/33. Finally A3 = [[2,–1,7],[0,4,–3],[1,0,4]] yields det = 2·det[[4,–3],[0,4]] – (–1)·det[[0,–3],[1,4]] + 7·det[[0,4],[1,0]] = 2·(16 –0) +1·(0+3) +7·(0–4) = 32 +3 –28 = 7, so x3 = 7/(–33) = –7/33. The solution vector is X = [118/33, –16/33, –7/33]T.
Exam Insight
When a determinant question asks for the value of a parameter that makes a matrix singular, set the determinant expression to zero and solve for the parameter; this is faster than attempting row reduction with an unknown.

Adjoint, Inverse and Rank of a Matrix

3.1 Adjoint and the Formula for the Inverse

The adjoint (or adjugate) of a square matrix A is the transpose of its cofactor matrix; each cofactor Cij equals (–1)i+j det(Mij). The defining relation A adj(A) = adj(A) A = det(A) I holds for every square matrix. If det(A) ≠ 0, the inverse exists and is given by A–1 = (1/det(A)) adj(A). This formula is theoretically important because it expresses the inverse entirely in terms of determinants, but for numerical computation it is usually less efficient than Gaussian elimination, especially for large matrices.

3.2 Properties of the Inverse

The inverse of a product reverses the order: (AB)–1 = B–1A–1. The inverse of the transpose is the transpose of the inverse: (AT)–1 = (A–1)T. If A is invertible, then (A–1)–1 = A. For a non‑zero scalar k, (kA)–1 = (1/k) A–1. These identities are frequently used to simplify expressions involving multiple inverses and transposes, and they also underlie the proof that the set of invertible n × n matrices forms the general linear group GL(n).

3.3 Rank and Its Determination

The rank of a matrix is the maximum number of linearly independent rows (or columns); it equals the order of the largest non‑zero minor. Row‑equivalence preserves rank, so the rank can be found by reducing the matrix to row‑echelon form and counting the non‑zero rows. The rank–nullity theorem states that for an m × n matrix A, rank(A) + nullity(A) = n, where nullity is the dimension of the solution space of AX = 0. A square matrix is invertible precisely when its rank equals its order, which is equivalent to having a non‑zero determinant. Rank also determines the consistency of a linear system: the system AX = B is consistent iff rank(A) = rank([A|B]), where [A|B] is the augmented matrix.

Solution of Systems of Linear Equations

4.1 Gaussian Elimination and Row‑Echelon Form

Gaussian elimination systematically applies elementary row operations to transform the augmented matrix [A|B] into row‑echelon form, from which the solutions can be read by back‑substitution. The process proceeds column by column, selecting a pivot (a non‑zero entry) and using it to eliminate entries below. If a column lacks a pivot, the corresponding variable is free, leading to infinitely many solutions parameterised by the free variables. The algorithm terminates when all rows are processed; the resulting triangular system is straightforward to solve. The method works for any rectangular system and reveals the rank of the coefficient matrix simultaneously.

4.2 Gauss‑Jordan Elimination and Reduced Row‑Echelon Form

Gauss‑Jordan elimination continues the reduction until the matrix reaches reduced row‑echelon form, where each pivot is 1 and is the only non‑zero entry in its column. This form yields the solution directly without back‑substitution and also provides a basis for the null space of A. The reduced form is unique for a given matrix, which makes it a canonical representation useful for theoretical arguments. While Gauss‑Jordan requires more arithmetic operations than Gaussian elimination, it is often preferred when the inverse of a matrix is needed, because augmenting A with the identity and reducing to [I|A–1] produces the inverse in one pass.

4.3 Cramer's Rule, Matrix Inversion and Comparative Efficiency

Cramer's rule gives an explicit formula for each variable as a ratio of determinants, but it requires the computation of n+1 determinants of order n, which is computationally prohibitive for n > 3. Matrix inversion solves AX = B by computing X = A–1B, which is efficient when the same coefficient matrix is used with many different right‑hand sides, because the inverse (or an LU factorisation) can be reused. For a single system, Gaussian elimination is generally the method of choice due to its O(n³) complexity with a smaller constant factor. Understanding the trade‑offs among these methods is essential for selecting the appropriate technique in both theoretical problems and numerical implementations.

Applications and Special Types of Matrices

5.1 Symmetric, Skew‑Symmetric and Orthogonal Matrices

A symmetric matrix satisfies A = AT; its eigenvalues are real and it can be orthogonally diagonalised by the spectral theorem. A skew‑symmetric matrix satisfies A = –AT; its diagonal entries are zero and its non‑zero eigenvalues occur in pure imaginary conjugate pairs. An orthogonal matrix Q fulfills QTQ = QQT = I, so its inverse equals its transpose; orthogonal matrices preserve lengths and angles, making them central to rotations and reflections in Euclidean space. The determinant of an orthogonal matrix is either +1 (proper rotation) or –1 (improper rotation including a reflection).

5.2 Diagonal, Triangular and Block Matrices

A diagonal matrix has non‑zero entries only on the main diagonal; its determinant is the product of the diagonal entries, and its inverse (when it exists) is obtained by inverting each diagonal entry. Upper (or lower) triangular matrices have zeros below (or above) the diagonal; their determinants are likewise the product of diagonal entries, and they are easily inverted by forward or backward substitution. Block matrices partition a large matrix into submatrices; operations such as multiplication and inversion can sometimes be performed block‑wise, provided the blocks are conformable and certain submatrices are invertible. The Schur complement arises naturally in block inversion and is a powerful tool in numerical linear algebra and statistics.

5.3 Eigenvalues, Eigenvectors and Diagonalisation

An eigenvalue λ of a square matrix A is a scalar for which there exists a non‑zero vector v (the eigenvector) satisfying Av = λv. The characteristic polynomial det(A – λI) = 0 yields the eigenvalues; its degree equals the order of the matrix. A matrix is diagonalisable if it possesses a basis of eigenvectors, which is guaranteed when it has n distinct eigenvalues or, more generally, when the algebraic multiplicity of each eigenvalue equals its geometric multiplicity. Diagonalisation simplifies many computations: powers of A become Ak = PDkP–1, where D is the diagonal matrix of eigenvalues and P the matrix of eigenvectors. This property underlies the solution of linear differential equations, Markov chains, and principal component analysis.

LU Decomposition and Its Variants

LU decomposition factorises a square matrix A into the product of a lower‑triangular matrix L (with unit diagonal) and an upper‑triangular matrix U, i.e. A = LU. The factorisation exists uniquely when all leading principal minors of A are non‑zero; otherwise row permutations are required, giving the PA = LU form where P is a permutation matrix. The algorithm proceeds by Gaussian elimination without back‑substitution, storing the multipliers in L and the resulting upper triangle in U. Computational cost is O(n³) with a smaller constant than full Gauss‑Jordan, making LU the workhorse for solving multiple right‑hand sides AX = B.

Doolittle, Crout and Cholesky Variants

In the Doolittle scheme L has unit diagonal; in Crout the diagonal resides in U. Both are algebraically equivalent but differ in numerical stability when pivoting is omitted. For symmetric positive‑definite matrices the Cholesky factorisation A = LLᵀ (or A = UᵀU) halves the arithmetic and guarantees stability without pivoting because all pivots are positive. The Cholesky factor L is obtained by the recurrence lii = √(aii − Σk<i lik²) and lji = (aji − Σk<i ljklik) / lii for j > i.

Block LU and Sparse Implementations

Large sparse systems exploit block LU where the matrix is partitioned into sub‑blocks; the Schur complement of the leading block appears naturally and can be factorised recursively. Modern sparse direct solvers (e.g. multifrontal methods) combine symbolic analysis to predict fill‑in with numerical factorisation, preserving sparsity patterns. Incomplete LU (ILU) preconditioners drop small entries during factorisation to keep the factors sparse, trading exactness for memory efficiency in iterative solvers.

QR Decomposition and Least Squares

The QR decomposition writes an m × n matrix A (with m ≥ n) as A = QR, where Q is m × m orthogonal (QᵀQ = I) and R is m × n upper‑triangular (the bottom m−n rows are zero). Two numerically stable constructions dominate: Householder reflections and Givens rotations. Householder reduces a column to a multiple of the first basis vector by reflecting across a hyperplane; the product of n such reflectors yields Q. Givens rotates a pair of rows to zero a single entry, useful for sparse or banded matrices.

Solving Linear Least Squares

For an overdetermined system Ax ≈ b, the normal equations AᵀAx = Aᵀb square the condition number. QR avoids this: substitute A = QR to obtain Rx = Qᵀb (using the first n rows of Qᵀb). Since R is triangular, back‑substitution gives the minimum‑norm solution in O(mn²) operations with excellent stability. If A is rank‑deficient, the rank‑revealing QR (with column pivoting) produces AP = QR where the diagonal of R decays, allowing a truncated solution.

Economy‑Size QR and Updating

When only the first n columns of Q are needed, the economy QR stores Q₁ (m × n) and R (n × n), reducing memory. Rank‑one updates (adding a row or column) can be performed in O(n²) using Givens rotations on the existing factors, a key ingredient in recursive least squares and Kalman filtering.

Worked Example: QR via Householder and Least Squares
Find the QR decomposition of A = [[1, 2], [3, 4], [5, 6]] and solve the least‑squares problem min ||Ax − b||₂ for b = [7, 8, 9]ᵀ.

Step 1: First column a₁ = [1,3,5]ᵀ. Compute v = a₁ − ||a₁|| e₁ = [1,3,5]ᵀ − √35 [1,0,0]ᵀ = [1−√35, 3, 5]ᵀ. Normalise u = v/||v||. Householder H₁ = I − 2uuᵀ. Apply H₁A → first column becomes [√35, 0, 0]ᵀ, second column becomes some vector c.

Step 2: Work on submatrix rows 2‑3, column 2. Let c₂ be the 2‑vector from rows 2‑3 of column 2. Build 2×2 Householder H₂' to zero its second entry. Embed into 3×3 as H₂ = diag(1, H₂'). Then Q = H₁H₂, R = H₂H₁A.

Numerically: ||a₁|| = √35 ≈ 5.91608. v = [−4.91608, 3, 5]ᵀ, ||v|| ≈ 7.54983. u ≈ [−0.651, 0.397, 0.662]ᵀ. H₁A yields R₁₁ = 5.91608, R₁₂ ≈ 10.141. Submatrix column 2 rows 2‑3 ≈ [−0.828, −1.656]ᵀ. Its norm ≈ 1.851. Householder gives R₂₂ ≈ 1.851, R₂₃ = 0. Thus R = [[5.916, 10.141], [0, 1.851], [0, 0]].

Compute Qᵀb: Qᵀ = H₂H₁. Applying to b = [7,8,9]ᵀ gives y = Qᵀb ≈ [15.652, −0.540, 0.0]ᵀ. Solve Rx = y₁:₂ → 5.916 x₁ + 10.141 x₂ = 15.652; 1.851 x₂ = −0.540 → x₂ ≈ −0.292, x₁ ≈ (15.652 − 10.141(−0.292))/5.916 ≈ 3.148. Least‑squares solution x ≈ [3.148, −0.292]ᵀ.

Exam‑Day Strategy
When a question asks for a least‑squares solution, first check whether the matrix is tall (m > n) and full rank. If so, write the normal equations only if explicitly required; otherwise state that QR (or SVD) is numerically preferred and outline the steps: compute QR, form Qᵀb, back‑substitute. For rank‑deficient cases, mention column‑pivoted QR or SVD truncation. In multiple‑choice, the presence of “condition number” or “normal equations” often signals a trap — prefer the QR‑based answer.

Singular Value Decomposition and Applications

The singular value decomposition (SVD) factorises any real m × n matrix A as A = UΣVᵀ, where U (m × m) and V (n × n) are orthogonal, and Σ (m × n) is diagonal with non‑negative singular values σ₁ ≥ σ₂ ≥ … ≥ σr > 0 (r = rank(A)). The columns of U are left singular vectors (eigenvectors of AAᵀ), columns of V are right singular vectors (eigenvectors of AᵀA), and σi² are the common non‑zero eigenvalues. SVD exists for every matrix, unlike eigendecomposition which requires square and diagonalizable matrices.

Low‑Rank Approximation and Eckart‑Young Theorem

The best rank‑k approximation (in both Frobenius and spectral norms) is obtained by truncating Σ to its first k singular values and corresponding singular vectors: Ak = UkΣkVkᵀ. The approximation error equals σk+1 (spectral) or √(Σi>k σi²) (Frobenius). This underpins principal component analysis (PCA), image compression, and latent semantic indexing.

Pseudoinverse and Least Squares via SVD

The Moore‑Penrose pseudoinverse A⁺ = VΣ⁺Uᵀ, where Σ⁺ replaces each non‑zero σi by 1/σi and transposes the shape. The minimum‑norm least‑squares solution of Ax = b is x = A⁺b. SVD reveals the condition number κ = σ₁/σr; a large κ warns of numerical sensitivity. Regularised solutions (Tikhonov) replace 1/σi by σi/(σi²+λ²).

Computational Aspects

Full SVD costs O(mn²) (or O(n³) for square) via bidiagonalisation followed by QR iteration on the bidiagonal matrix. For large sparse matrices, randomised SVD or Lanczos bidiagonalisation compute only the leading singular triplets in O(mn log k) time.

Positive Definite Matrices, Cholesky Decomposition and Quadratic Forms

A symmetric matrix A is positive definite (PD) iff xᵀAx > 0 for all non‑zero x. Equivalent characterisations: all eigenvalues > 0; all leading principal minors > 0 (Sylvester’s criterion); there exists a non‑singular B with A = BᵀB. Positive semidefinite (PSD) relaxes strict inequality to ≥ 0, allowing zero eigenvalues.

Cholesky Factorisation

For PD A, the unique Cholesky factor L (lower‑triangular with positive diagonal) satisfies A = LLᵀ. The algorithm computes lii = √(aii − Σk<i lik²) and lji = (aji − Σk<i ljklik) / lii. Cost is ⅓ n³ flops, half of LU. Cholesky fails (square‑root of negative) if A is not PD, providing a practical test.

Quadratic Forms and Sylvester’s Law of Inertia

A quadratic form q(x) = xᵀAx can be diagonalised by an orthogonal change of variables x = Py giving q = Σ λi yi². Sylvester’s law states that the numbers of positive, negative, and zero eigenvalues (the inertia) are invariant under any non‑singular congruence transformation A → CᵀAC. This classifies conics and quadrics: PD → ellipsoid, indefinite → hyperboloid, PSD → paraboloid/cylinder.

Applications in Optimisation and Statistics

In Newton’s method, the Hessian must be PD for a descent direction; if indefinite, a modified Cholesky (adding a multiple of identity) yields a PD approximation. In statistics, covariance matrices are PSD; their Cholesky factors generate correlated random vectors via x = Lz with z ∼ N(0,I). The Mahalanobis distance d² = (x−μ)ᵀΣ⁻¹(x−μ) uses the inverse covariance, efficiently computed via Cholesky solves.

Matrix Exponential and Linear Differential Equations

The matrix exponential is defined by the convergent power series eA = Σk=0∞ Ak/k! for any square A. It satisfies d/dt etA = A etA = etA A and e0 = I. For a constant‑coefficient linear system dx/dt = Ax, the solution is x(t) = etA x(0). If A is diagonalizable (A = PDP⁻¹), then eA = P eD P⁻¹ where eD is diagonal with entries eλi.

Computing the Exponential

Direct series summation is rarely used. For small matrices, scaling and squaring combined with Padé approximants (the “expm” algorithm) is standard. For large sparse systems, Krylov subspace methods (Arnoldi) approximate etAv without forming the full exponential. When A is nilpotent (Ak=0), the series terminates after k terms.

General Solution of Inhomogeneous Systems

For dx/dt = Ax + f(t), variation of parameters gives x(t) = etA x(0) + ∫0t e(t−s)A f(s) ds. If f(t) is a polynomial, exponential, or sinusoid, the integral can be evaluated analytically using the matrix exponential or by augmenting the system.

Stability and Lyapunov Exponents

The zero solution of dx/dt = Ax is asymptotically stable iff all eigenvalues of A have negative real parts. The matrix exponential norm ‖etA‖ decays exponentially at rate equal to the spectral abscissa max Re(λi). For discrete‑time xk+1 = Axk, stability requires ρ(A) < 1 (spectral radius). These criteria are central in control theory and numerical analysis of stiff ODEs.

  • Confusing LU with Cholesky: Cholesky requires symmetric positive‑definite matrices; applying it to indefinite matrices produces a square‑root of a negative pivot.
  • Assuming QR always yields a square Q: economy QR returns Q₁ (m×n) and R (n×n); the full Q is m×m and often unnecessary.
  • Treating singular values as eigenvalues: singular values are square roots of eigenvalues of AᵀA (or AAᵀ) and are always non‑negative, whereas eigenvalues can be negative or complex.
  • Using normal equations for least squares without checking condition number: squaring the condition number amplifies rounding errors; QR or SVD is safer.
  • Believing every matrix has a matrix logarithm: only non‑singular matrices with no eigenvalues on the negative real axis (principal logarithm) admit a real logarithm; otherwise complex branches appear.
  • Neglecting the inertia when classifying quadratic forms: congruence transformations preserve the numbers of positive, negative, and zero eigenvalues, not the eigenvalues themselves.
  • Overlooking that the matrix exponential of a non‑diagonalizable matrix involves Jordan blocks and polynomial factors in t, not just exponentials of eigenvalues.

These advanced topics extend the core toolkit and appear frequently in higher‑level problem papers and research‑oriented examinations.

Jordan Canonical Form and Generalized Eigenvectors

When a square matrix A is not diagonalizable, its eigenvectors fail to span the space. The Jordan canonical form gives a block‑diagonal representation capturing the defective structure. For each eigenvalue λ, the Jordan blocks Jk(λ) are k×k matrices with λ on the diagonal, 1 on the super‑diagonal, and 0 elsewhere. The size of the largest block for λ equals the index of λ, i.e. the smallest integer m such that (A−λI)mv = 0 for some non‑zero v. Vectors satisfying (A−λI)mv = 0 but (A−λI)m−1v ≠ 0 are called generalized eigenvectors of rank m. Chains of generalized eigenvectors v1, v2, …, vk with (A−λI)v1 = 0 and (A−λI)vi = vi−1 for i>1 form the columns of the transformation matrix P such that P−1AP = J. The number of Jordan blocks for λ equals the geometric multiplicity (dimension of the eigenspace), while the sum of their sizes equals the algebraic multiplicity. Computing J numerically is ill‑conditioned; in practice the Schur form or rational canonical form is used for stability. Nevertheless, the Jordan form is indispensable for analytic work: it yields closed formulas for matrix functions f(A) via f(J) = diag(f(J1), …), where f(Jk(λ)) is an upper‑triangular Toeplitz matrix whose entries are derivatives f(j)(λ)/j!. This underpins the theory of matrix exponentials for non‑diagonalizable systems and the solution of linear differential equations with repeated eigenvalues.

Construction Algorithm

  1. Find all eigenvalues and their algebraic multiplicities.
  2. For each λ, compute the sequence of nullities nm = dim ker(A−λI)m until nm stabilises at the algebraic multiplicity.
  3. The differences nm−nm−1 give the number of Jordan blocks of size at least m.
  4. Build chains by selecting vectors in ker(A−λI)m ker(A−λI)m−1 and applying (A−λI) repeatedly.

The resulting P is non‑singular and the similarity transformation is exact over the algebraic closure of the field.

Matrix Functions: Logarithm, Square Root, and Fractional Powers

Beyond the exponential, many applications require the matrix logarithm log(A), the principal square root A1/2, or general fractional powers Aα. For a non‑singular matrix with no eigenvalues on the closed negative real axis, the principal logarithm is the unique matrix X such that eX = A and the spectrum of X lies in the strip −π < Im(λ) < π. It is computed via inverse scaling-and-squaring: repeatedly take square roots until ||Y|| is small, evaluate the Padé approximant of log(I+Y), then square back. The principal square root A1/2 is the unique solution of X2 = A with eigenvalues in the open right half‑plane. The Denman‑Beavers iteration Xk+1 = ½(Xk + Yk−1), Yk+1 = ½(Yk + Xk−1) converges quadratically to (A1/2, A−1/2) when started with X0=A, Y0=I. For general α∈ℝ, Aα = eα log A using the principal logarithm. When A is diagonalizable, A = PDP−1, the function reduces to f(A) = P f(D) P−1. For defective matrices, the Jordan form gives f(Jk(λ)) as described above. These functions appear in control theory (Riccati equations), statistics (matrix geometric means), and quantum mechanics (density matrix roots). Care must be taken: a real matrix may have no real logarithm (e.g. a negative scalar), and the square root of a non‑symmetric matrix is not unique; the principal branch is selected by the spectral condition.

Worked Example: Principal Square Root of a 2×2 Matrix
Find the principal square root of A = [[5, 4], [4, 5]].

Step 1: Diagonalise A. The eigenvalues are λ₁ = 9, λ₂ = 1 with eigenvectors (1,1)ᵀ and (1,−1)ᵀ. Thus P = 1/√2 [[1, 1], [1, −1]], D = diag(9, 1).

Step 2: Compute D1/2 = diag(3, 1) (principal roots, both positive).

Step 3: Reconstruct X = P D1/2 P−1 = 1/2 [[1, 1], [1, −1]] [[3, 0], [0, 1]] [[1, 1], [1, −1]] = [[2, 1], [1, 2]].

Verification: X² = [[2,1],[1,2]]² = [[5,4],[4,5]] = A. The eigenvalues of X are 3 and 1, both in the right half‑plane, confirming the principal branch.

Exam‑Day Strategy
When a question asks for a matrix function, first check diagonalizability. If the matrix is symmetric or normal, orthogonal diagonalisation gives the answer instantly. For non‑diagonalizable cases, write the Jordan chains explicitly; the function of a Jordan block is an upper‑triangular Toeplitz matrix whose entries are derivatives of the scalar function at the eigenvalue. Memorise the pattern for the exponential, logarithm, and square root of a 2×2 Jordan block — it appears frequently in objective‑type papers.

Perturbation Theory for Eigenvalues and Eigenvectors

In practice, matrices are known only approximately. Perturbation theory quantifies changes in eigenvalues and eigenvectors under a small additive perturbation E. Let A be diagonalizable with A = XΛX−1 and consider Ã = A + E. Weyl's inequality states that for Hermitian matrices, the eigenvalues λi(Ã) and λi(A) satisfy |λi(Ã) − λi(A)| ≤ ‖E‖2. For non‑Hermitian matrices, the Bauer‑Fike theorem gives a bound in terms of the condition number κ(X) = ‖X‖2‖X−1‖2: every eigenvalue μ of Ã lies in a disc centred at some eigenvalue λ of A with radius κ(X)‖E‖2. Eigenvector perturbations are more delicate. If λ is a simple eigenvalue with right eigenvector x and left eigenvector y (y∗x = 1), the first‑order change is δx ≈ (λI − A)† E x, where † denotes the Moore‑Penrose inverse on the orthogonal complement of x. The sensitivity is governed by the gap to the nearest eigenvalue: the smaller the gap, the larger the rotation. For multiple eigenvalues, the invariant subspace rotates as a whole; the Davis‑Kahan sin θ theorem bounds the angle between the true and perturbed subspaces by ‖E‖2/gap. These results guide the choice of algorithms: for ill‑conditioned eigenproblems, one prefers backward‑stable methods (QR algorithm, divide‑and‑conquer) and avoids explicit inversion of (λI−A). In structural engineering, perturbation bounds certify that computed natural frequencies are within tolerance despite modelling errors.

Structured Matrices: Toeplitz, Circulant, and Vandermonde Systems

Many applications yield structured matrices, reducing storage from O(n²) to O(n) and solution cost from O(n³) to O(n²) or O(n log n). A Toeplitz matrix T has constant diagonals: Tij = ti−j. It arises in time‑series analysis and signal processing. The Levinson‑Durbin algorithm solves Tx = b in O(n²) operations and yields the Cholesky factor of a positive‑definite Toeplitz matrix. A circulant matrix C is a special Toeplitz matrix where each row is a cyclic shift of the previous one; it is diagonalised by the discrete Fourier transform (DFT) matrix F: C = F∗ diag(Fc) F, where c is the first column. Hence Cx = b is solved by three FFTs in O(n log n). Vandermonde matrices V with Vij = xij−1 appear in polynomial interpolation and Prony's method. They are notoriously ill‑conditioned for large n; the Björck‑Pereyra algorithm solves Vx = b in O(n²) with forward/backward substitution on a bidiagonal factorisation. The displacement rank concept unifies these structures: a matrix A has displacement rank r if ∇(A) = A − ZAZ∗ has rank r for suitable shift matrices Z. Low displacement rank enables fast matrix‑vector multiplication and structured inversion via the Gohberg‑Semencul formula. In practice, one must guard against numerical instability when the generating vectors are nearly linearly dependent; regularisation or pivoting is often required.

Kronecker Products, Vectorization, and Sylvester/Lyapunov Equations

The Kronecker product A ⊗ B of an m×n matrix A and a p×q matrix B is the mp×nq block matrix [aijB]. It satisfies (A ⊗ B)(C ⊗ D) = (AC) ⊗ (BD) when dimensions match, and vec(ABC) = (CT ⊗ A) vec(B), where vec stacks columns. These identities convert matrix equations into linear systems. The Sylvester equation AX + XB = C becomes (I ⊗ A + BT ⊗ I) vec(X) = vec(C). The Lyapunov equation AX + XAT = C is a special case with B = AT. If A and −B have disjoint spectra, the Sylvester equation has a unique solution. The Bartels‑Stewart algorithm solves it in O(n³) by reducing A and B to real Schur form, then back‑substitution. For large sparse A, the ADI method or Krylov projections (e.g., extended block Arnoldi) compute low-rank approximations X ≈ ZZT when C is low-rank. The discrete‑time algebraic Riccati equation X = ATXA − ATXB(R + BTXB)−1BTXA + Q arises in optimal control; its solution is the stabilising fixed point of the associated Hamiltonian matrix. Kronecker products also appear in tensor-train decompositions and quantum many-body physics, where the dimension grows exponentially but the state has low-rank tensor structure.

  • Assuming every matrix has a Jordan form over ℝ — complex eigenvalues require complex blocks; the real Jordan form uses 2×2 blocks for conjugate pairs.
  • Confusing the principal matrix logarithm with any logarithm — the principal branch is uniquely defined only when no eigenvalue lies on the negative real axis.
  • Applying Weyl's inequality to non‑Hermitian matrices — it holds only for Hermitian (or normal) matrices; use Bauer‑Fike instead.
  • Treating the square root of a non‑symmetric matrix as unique — there are 2n square roots in general; the principal one is selected by spectral condition.
  • Neglecting displacement rank when solving Toeplitz systems — ignoring structure leads to O(n³) cost instead of O(n²) or O(n log n).
  • Solving Sylvester equations by forming the Kronecker system explicitly — the mp×mp matrix is huge; always use Bartels‑Stewart or ADI for large problems.
  • Assuming Vandermonde matrices are well‑conditioned for any node set — they are exponentially ill‑conditioned for equispaced nodes; use Chebyshev nodes or orthogonal polynomials.

These advanced tools extend the core linear algebra toolkit and are essential for tackling research‑level problems and high‑difficulty examination questions.

Generalized Eigenvalue Problems and Deflating Subspaces

The standard eigenvalue problem A x = λ x is the special case B = I. In many applications — structural dynamics, control theory, and quantum chemistry — one encounters the generalized eigenvalue problem A x = λ B x where A and B are square matrices and B may be singular. The pair (A, B) is called a matrix pencil. If det(A − λ B) is not identically zero, the pencil is regular and there are exactly n eigenvalues counting multiplicities in the extended complex plane (including ∞ when B is singular). The eigenvalues are the roots of the characteristic polynomial det(A − λ B) = 0. A right eigenvector satisfies A x = λ B x; a left eigenvector satisfies yH A = λ yH B.

When B is Hermitian positive definite, the problem reduces to a standard Hermitian eigenvalue problem via the Cholesky factor B = L LH and the transformation L−1 A L−H. For general B, the QZ algorithm (generalized Schur decomposition) computes unitary matrices Q, Z such that QH A Z = S (upper triangular) and QH B Z = T (upper triangular). The eigenvalues are the ratios sii / tii. Deflating subspaces generalize invariant subspaces: a subspace 𝒱 is a deflating subspace if there exists a subspace 𝒲 with dim 𝒱 = dim 𝒲 such that A 𝒱 ⊆ 𝒲 and B 𝒱 ⊆ 𝒲. The columns of Z corresponding to a selected set of eigenvalues span a deflating subspace. This concept is crucial for model reduction and for computing stable invariant subspaces in the algebraic Riccati equation.

Perturbation theory for generalized eigenvalues uses the chordal distance to handle infinite eigenvalues. The Stewart–Sun bounds generalize the Bauer–Fike theorem: if (Ã, B̃) = (A+E, B+F) and the pencil is regular, then for each eigenvalue λ of (A, B) there is an eigenvalue λ̃ of (Ã, B̃) such that the chordal distance χ(λ, λ̃) ≤ ‖E‖2 + ‖F‖2 / sep, where sep is the separation of the selected deflating subspace from the rest of the spectrum. In practice, the QZ algorithm with aggressive early deflation (AED) is the workhorse for dense problems; for large sparse pencils, the rational Krylov method or the Jacobi–Davidson algorithm target interior eigenvalues without factorizing B.

Matrix Norms, Condition Numbers, and Backward Error Analysis

A matrix norm ‖·‖ assigns a non‑negative real number to each matrix and satisfies positivity, homogeneity, triangle inequality, and submultiplicativity ‖A B‖ ≤ ‖A‖ ‖B‖. The most common norms are the Frobenius norm ‖A‖F = √(∑|aij|²), the spectral norm ‖A‖2 = σmax(A) (largest singular value), and the induced p-norms ‖A‖p = sup‖x‖p=1 ‖A x‖p. The spectral norm equals the square root of the largest eigenvalue of AHA and is unitarily invariant. The condition number of a nonsingular matrix A with respect to inversion is κ(A) = ‖A‖ ‖A−1‖. For the spectral norm, κ2(A) = σmax/σmin. A large condition number indicates that small relative perturbations in A or the right‑hand side b can cause large relative changes in the solution x of A x = b.

Backward error analysis asks: given an approximate solution x̂, what is the smallest perturbation ΔA, Δb such that (A+ΔA) x̂ = b+Δb? The normwise backward error is η = min{ ε : ∃ ΔA, Δb with ‖ΔA‖ ≤ ε‖A‖, ‖Δb‖ ≤ ε‖b‖ }. For linear systems, η = ‖r‖ / (‖A‖ ‖x̂‖ + ‖b‖) where r = b − A x̂. A backward stable algorithm guarantees η = O(εmach) where εmach is machine precision. Forward error is bounded by ‖x̂−x‖/‖x‖ ≤ κ(A) η + O(η²). Thus even a backward stable method can produce large forward error if κ(A) is huge.

Componentwise condition numbers and backward errors give sharper bounds for structured problems. For example, if A is a diagonally dominant M‑matrix, the componentwise condition number can be much smaller than the normwise κ. Iterative refinement solves A x = b by repeatedly computing the residual in higher precision and correcting the solution; it reduces the forward error to the level of the componentwise backward error provided the solver is normwise backward stable. In eigenvalue problems, the condition number of a simple eigenvalue λ is 1/|yH x| where x, y are right and left eigenvectors normalized to unit length. For multiple eigenvalues, the condition number of the invariant subspace is governed by the separation sep(λ, Λ\λ) as in the Davis–Kahan sin Θ theorem. Understanding these measures guides the choice of algorithm: for ill‑conditioned systems one may use extra precision, regularization, or a more stable factorization such as QR with column pivoting instead of LU.

Worked Example: Condition Number and Backward Error
Let A = [[1, 1], [1, 1.0001]] and b = [2, 2.0001]ᵀ. Compute the spectral condition number κ₂(A). An approximate solution is x̂ = [1.00005, 0.99995]ᵀ. Compute the normwise backward error η and the forward error bound κ₂(A) η. Compare with the actual forward error ‖x̂ − x‖₂ / ‖x‖₂ where x = [1, 1]ᵀ is the exact solution.
First compute singular values of A. AᵀA = [[2, 2.0001], [2.0001, 2.00020001]]. Eigenvalues of AᵀA are λ₁ ≈ 4.00030001, λ₂ ≈ 9.999×10⁻⁹. Thus σ₁ = √λ₁ ≈ 2.000075, σ₂ = √λ₂ ≈ 0.0001. κ₂(A) = σ₁/σ₂ ≈ 2.000075 / 0.0001 = 20000.75. Residual r = b − A x̂ = [2, 2.0001]ᵀ − [[1,1],[1,1.0001]] [1.00005,0.99995]ᵀ = [2−2.00000, 2.0001−2.000100005]ᵀ ≈ [0, −5×10⁻⁹]ᵀ. ‖r‖₂ ≈ 5×10⁻⁹. ‖A‖₂ = σ₁ ≈ 2.000075. ‖x̂‖₂ ≈ √(1.00005²+0.99995²) ≈ 1.4142. ‖b‖₂ ≈ √(2²+2.0001²) ≈ 2.8285. η = ‖r‖₂ / (‖A‖₂‖x̂‖₂ + ‖b‖₂) ≈ 5×10⁻⁹ / (2.000075×1.4142 + 2.8285) ≈ 5×10⁻⁹ / 5.657 ≈ 8.84×10⁻¹⁰. Forward error bound = κ₂(A) η ≈ 20000.75 × 8.84×10⁻¹⁰ ≈ 1.77×10⁻⁵. Actual forward error: x̂ − x = [0.00005, −0.00005]ᵀ, ‖x̂−x‖₂ = √(2×(5×10⁻⁵)²) = 7.07×10⁻⁵. ‖x‖₂ = √2 ≈ 1.4142. Relative forward error = 7.07×10⁻⁵ / 1.4142 ≈ 5×10⁻⁵. The bound 1.77×10⁻⁵ is smaller than the actual error because the bound uses normwise η; componentwise analysis would give a tighter estimate. This illustrates that κ₂(A) ≈ 2×10⁴ amplifies the backward error by four orders of magnitude.
Exam‑Day Strategy
When a question asks for the condition number of a 2×2 matrix, compute the singular values via the eigenvalues of AᵀA rather than using the formula κ₂ = ‖A‖₂‖A⁻¹‖₂ directly; the latter requires the inverse which may be ill‑conditioned. For backward error, remember the formula η = ‖r‖ / (‖A‖‖x̂‖ + ‖b‖) and always state the norm used. If the problem gives a perturbed matrix, apply the Bauer–Fike bound for eigenvalues: |λ̃ − λ| ≤ κ₂(V) ‖E‖₂ where V diagonalizes A (if A is diagonalizable). For non‑diagonalizable matrices, cite the generalized bound using the Jordan form or the pseudospectrum definition.

Schur Complement, Block Matrix Inversion, and Determinantal Identities

Partition a square matrix M into blocks M = [[A, B], [C, D]] where A is k×k and D is ℓ×ℓ. If A is invertible, the Schur complement of A in M is S = D − C A−1 B. The determinant factorizes as det(M) = det(A) det(S). If D is invertible, the complementary Schur complement is A − B D−1 C and det(M) = det(D) det(A − B D−1 C). These identities are the basis for block Gaussian elimination and for the matrix inversion lemma (Woodbury formula): (A + U C V)−1 = A−1 − A−1 U (C−1 + V A−1 U)−1 V A−1, where A is n×n, U is n×k, C is k×k, V is k×n. The lemma reduces the cost of updating an inverse when a low‑rank correction is applied.

The block inverse of M when A and S are invertible is M−1 = [[A−1 + A−1 B S−1 C A−1, −A−1 B S−1], [−S−1 C A−1, S−1]]. If D and the complementary Schur complement are invertible, an analogous formula holds with roles swapped. These formulas are used in domain decomposition methods for PDEs, where A and D correspond to subdomains and S represents the interface problem. The Schur complement also appears in statistics: for a partitioned covariance matrix Σ = [[Σ11, Σ12], [Σ21, Σ22]], the conditional covariance of the first block given the second is the Schur complement Σ11 − Σ12 Σ22−1 Σ21.

Determinantal identities extend beyond the Schur complement. The Cauchy–Binet formula gives det(A B) for rectangular matrices: if A is m×n and B is n×m with m ≤ n, then det(A B) = ∑S det(AS) det(BS) where the sum runs over all m-element subsets S of {1,…,n} and AS, BS are the corresponding square submatrices. The matrix determinant lemma states det(A + u vT) = det(A) (1 + vT A−1 u) for invertible A. This is a special case of the Woodbury identity with C = 1. The Weinstein–Aronszajn identity det(I + A B) = det(I + B A) holds for any A (m×n) and B (n×m) and is useful in random matrix theory and in deriving the characteristic polynomial of a low‑rank perturbation.

Polar Decomposition and the Matrix Sign Function

Every square matrix A admits a polar decomposition A = U H where U is unitary (orthogonal if A is real) and H is Hermitian positive semidefinite.

Nonnegative Matrices and Perron–Frobenius Theory

A matrix is called nonnegative if every entry is greater than or equal to zero. When such a matrix is also irreducible — meaning its associated directed graph is strongly connected — the Perron–Frobenius theorem guarantees the existence of a positive real eigenvalue, called the Perron root, that equals the spectral radius. This eigenvalue is simple, and there exists a corresponding eigenvector with strictly positive components. For primitive matrices (irreducible and aperiodic), the Perron root is strictly larger in magnitude than any other eigenvalue, and powers of the matrix scaled by the Perron root converge to a rank‑one projector onto the positive eigenvector.

The theorem extends to nonnegative matrices that are not irreducible through the Frobenius normal form, which permutes the matrix into block upper‑triangular form with irreducible diagonal blocks. The spectral radius of the whole matrix is the maximum of the Perron roots of the diagonal blocks. This decomposition is essential for analyzing Markov chains, input‑output economic models, and population dynamics where the transition matrix is nonnegative.

Collatz–Wielandt formulas provide variational characterizations of the Perron root: for a nonnegative irreducible matrix A, the spectral radius ρ(A) equals the maximum over all positive vectors x of the minimum ratio (Ax)_i / x_i, and also equals the minimum over all positive vectors x of the maximum ratio. These formulas yield practical bounds: ρ(A) lies between the minimum and maximum row sums, and also between the minimum and maximum column sums. For stochastic matrices, the Perron root is exactly 1, and the positive eigenvector gives the stationary distribution.

Applications include Google’s PageRank algorithm, where the web graph’s adjacency matrix is made stochastic and the dominant eigenvector ranks pages. In Leslie population models, the dominant eigenvalue determines the long‑term growth rate, and the associated eigenvector gives the stable age distribution. The theory also underpins the convergence analysis of iterative methods for nonnegative linear systems, such as the power method and its variants.

Matrix Polynomials and Linearizations

A matrix polynomial of degree m is an expression P(λ) = A_m λ^m + Am-1 λm-1 + … + A1 λ + A0, where each A_k is an n×n matrix and A_m is nonzero. The eigenvalues of P are the scalars λ for which det P(λ) = 0; the corresponding eigenvectors satisfy P(λ)v = 0. Direct solution of high‑degree matrix polynomials is numerically unstable, so one constructs a linearization — a larger pencil L(λ) = λX + Y whose eigenvalues coincide with those of P(λ) and whose eigenvectors can be mapped back to those of P.

The first companion form is the block matrix
L(λ) = λ [ I 0 … 0; 0 I … 0; … ; 0 0 … I ] + [ 0 I … 0; 0 0 … 0; … ; -A0 -A1 … -Am-1 ]
where the identity blocks are n×n. This pencil has size mn×mn and its finite eigenvalues are exactly the eigenvalues of P(λ). The second companion form places the coefficient matrices in the first block row. Both forms are linearizations provided A_m is nonsingular; if A_m is singular, the polynomial has eigenvalues at infinity, and the linearization captures them as infinite eigenvalues of the pencil.

Structure‑preserving linearizations exploit symmetries such as palindromic (A_k = Am-k^T) or alternating (A_k = -Am-k^T) coefficient patterns. For example, a palindromic quadratic Q(λ) = λ2 A + λ B + A^T arises in vibration analysis of gyroscopic systems. A structure‑preserving linearization keeps the pencil palindromic, ensuring that eigenvalues occur in reciprocal pairs (λ, 1/λ), which is physically meaningful. Such linearizations can be built as block‑symmetric pencils that maintain a smaller condition number than the companion forms.

Numerical solution proceeds by applying the QZ algorithm to the linearized pencil. Backward error analysis shows that the computed eigenvalues are exact eigenvalues of a slightly perturbed polynomial, provided the linearization is well‑conditioned. Scaling the polynomial coefficients (e.g., by balancing the norms of A_k) before linearization improves accuracy. Software packages such as NLEIGS and the Matrix Polynomial Toolbox implement these ideas for large‑scale problems.

Perron–Frobenius Eigenvalue Bound
Let A = [[2, 1, 0], [1, 3, 1], [0, 1, 2]]. Using only row sums, give lower and upper bounds for the spectral radius ρ(A). Then compute the exact Perron root to verify the bounds.
Row sums are 3, 5, 3. For any nonnegative matrix, ρ(A) lies between the minimum and maximum row sums, so 3 ≤ ρ(A) ≤ 5. The characteristic polynomial is det(A - λI) = -λ3 + 7λ2 - 14λ + 8 = -(λ-1)(λ-2)(λ-4). The eigenvalues are 1, 2, 4. The Perron root is 4, which indeed satisfies 3 ≤ 4 ≤ 5.
Exam‑Day Strategy for Perron–Frobenius
When a question asks for bounds on the spectral radius of a nonnegative matrix, immediately write the Collatz–Wielandt row‑sum bounds. If the matrix is irreducible, state that the Perron root is simple and has a positive eigenvector. For stochastic matrices, recall that ρ = 1 and the stationary distribution is the normalized positive eigenvector. Avoid computing the full characteristic polynomial unless explicitly required; the bounds often suffice for multiple‑choice questions.

Matrix Inequalities: Weyl, Courant–Fischer, and Majorization

Eigenvalue inequalities for Hermitian matrices form a cornerstone of matrix analysis. Weyl’s inequalities state that for Hermitian matrices A and B of the same size, the eigenvalues λ_i(A+B) satisfy λ_i(A) + λ_n(B) ≤ λ_i(A+B) ≤ λ_i(A) + λ1(B) for each i, where eigenvalues are ordered nondecreasingly. These bounds are sharp and follow from the Courant–Fischer min‑max principle, which characterizes the i‑th eigenvalue as λ_i(A) = mindim S = i maxx∈S, ‖x‖=1 x^* A x = maxdim S = n-i+1 minx∈S, ‖x‖=1 x^* A x.

The Courant–Fischer theorem also yields the interlacing property: if B is a principal submatrix of A obtained by deleting k rows and columns, then λ_i(A) ≤ λ_i(B) ≤ λi+k(A). This is crucial for domain decomposition and for bounding eigenvalues of large matrices by those of smaller submatrices. A related result is Cauchy’s interlacing theorem for bordered matrices, which adds one row and column.

Majorization provides a partial order on vectors that captures the collective behavior of eigenvalues. For Hermitian A and B, the vector of eigenvalues of A+B is majorized by the sum of the eigenvalue vectors of A and B. In particular, the Ky Fan norms ‖A‖(k) = sumi=1^k σ_i(A) (sum of k largest singular values) satisfy ‖A+B‖(k) ≤ ‖A‖(k) + ‖B‖(k). These inequalities underpin the analysis of low‑rank approximations and the stability of eigenvalue computations under perturbations.

Applications include the Hoffman–Wielandt theorem, which bounds the distance between eigenvalue sets of two normal matrices by the Frobenius norm of their difference. In quantum information, majorization characterizes the convertibility of entangled states under local operations. In numerical linear algebra, Weyl’s inequalities guarantee that the eigenvalues of a symmetric matrix computed in floating‑point arithmetic are the exact eigenvalues of a matrix within a backward error of order machine precision times the norm.

Graph Laplacians and Spectral Graph Theory

The Laplacian matrix L of an undirected graph with n vertices is defined as L = D - A, where D is the diagonal degree matrix and A is the adjacency matrix. L is symmetric positive semidefinite; its smallest eigenvalue is 0 with eigenvector 1 (the all‑ones vector). The multiplicity of the zero eigenvalue equals the number of connected components. The second smallest eigenvalue, λ2(L), is called the algebraic connectivity or Fiedler value; it quantifies how well‑connected the graph is. For the normalized Laplacian Lsym = D-1/2 L D-1/2, Cheeger’s inequality relates λ2 to the edge expansion (conductance) h(G): λ2/2 ≤ h(G) ≤ √(2λ2). This provides a spectral certificate for graph partitioning.

The eigenvectors of L, especially the Fiedler vector (eigenvector for λ2), are used in spectral clustering: vertices are embedded into ℝ^k using the first k nontrivial eigenvectors, then a standard clustering algorithm (e.g., k‑means) is applied. For bipartite graphs, the sign pattern of the Fiedler vector yields a near‑optimal bipartition. The normalized Laplacian Lsym has eigenvalues in [0,2] and is preferred for graphs with widely varying degrees because it eliminates degree bias.

Effective resistance between vertices i and j is defined as Rij = (e_i - e_j)^T L^† (e_i - e_j), where L^† is the Moore–Penrose pseudoinverse. This metric satisfies the triangle inequality and equals the commute time of a random walk divided by twice the number of edges. Kirchhoff’s matrix‑tree theorem states that any cofactor of L equals the number of spanning trees of the graph, linking spectral data to combinatorial enumeration.

In machine learning, graph Laplacians appear in semi‑supervised learning (label propagation), manifold regularization, and graph neural networks where the Laplacian defines the convolution operator. The spectrum of L also controls the mixing time of random walks: the spectral gap 1 - λ2(P) for the transition matrix P = D-1A determines the rate of convergence to the stationary distribution.

Matrix Calculus: Derivatives of Determinants, Traces, and Inverses

Matrix calculus extends scalar differential calculus to functions whose arguments are matrices. The differential of a scalar function f(X) is expressed as df = tr( G^T dX ), where G is the gradient matrix ∂f/∂X. For the determinant, d det(X) = det(X) tr( X-1 dX ), so ∂ det(X) / ∂X = det(X) X-T. For the trace, d tr(X) = tr(dX), giving ∂ tr(X) / ∂X = I. The derivative of the inverse follows from d(X-1) = -X-1 dX X-1, yielding ∂ (X-1)ij / ∂Xkl = - (X-1)ik (X-1)lj.

These identities are indispensable in maximum‑likelihood estimation for Gaussian models, where the log‑likelihood involves log det(Σ) and tr(Σ-1 S). The gradient with respect to the covariance matrix Σ is ∂ℓ/∂Σ = -½ Σ-1 + ½ Σ-1 S Σ-1. In optimization, the Hessian of log det(X) is the linear operator H[U] = -X-1 U X-1, which is negative definite on the cone of positive definite matrices, confirming concavity.

For a matrix function f(X) = tr( X^T A X B ), the differential is df = tr( (A X B + A^T X B^T)^T dX ), so the gradient is A X B + A^T X B^T. When A and B are symmetric, this simplifies to 2 A X B. The chain rule for matrix functions uses the vec operator and Kronecker products: vec( d f(X) ) = J_f(X) vec(dX), where J_f is the Jacobian matrix. For the matrix exponential, d exp(X) = ∫01 exp((1-s)X) dX exp(sX) ds, a formula used in sensitivity analysis of linear differential equations.

Practical computation often avoids explicit Jacobians by using directional derivatives: the derivative of f at X in direction V is limt→0 (f(X+tV)-f(X))/t. Automatic differentiation frameworks (e.g., JAX, PyTorch) implement reverse‑mode differentiation for matrix operations, enabling gradient‑based optimization of objectives involving determinants, traces, and inverses without manual derivation.

  • Confusing the Perron root with the spectral radius for reducible matrices; the spectral radius is the maximum of the Perron roots of irreducible diagonal blocks.
  • Assuming every linearization of a matrix polynomial preserves structure; companion forms destroy palindromic or alternating symmetry unless a structure‑preserving linearization is used.
  • Applying Weyl’s inequalities to non‑Hermitian matrices; they hold only for Hermitian (or real symmetric) matrices.
  • Using the unnormalized Laplacian for graphs with highly skewed degree distributions; the normalized Laplacian gives meaningful spectral clustering in that regime.
  • Forgetting the transpose in the gradient of the determinant: ∂ det(X)/∂X = det(X) X-T, not det(X) X-1.
  • Neglecting to verify irreducibility before invoking the simplicity of the Perron root; a reducible nonnegative matrix can have a multiple eigenvalue equal to the spectral radius.
