Key Concepts

What is Coordinate Geometry?

Coordinate geometry (or analytic geometry) uses algebraic equations to describe geometric shapes. For JEE, this topic covers straight lines, circles, and conic sections (parabola, ellipse, hyperbola). It carries approximately 12-15% weightage in JEE Main and Advanced.

Key Concepts

1. Straight Lines: Slope m = tanθ = (y₂-y₁)/(x₂-x₁). Forms: y = mx + c (slope-intercept), y - y₁ = m(x - x₁) (point-slope), (y-y₁)/(y₂-y₁) = (x-x₁)/(x₂-x₁) (two-point), x/a + y/b = 1 (intercept). Angle between two lines: tanθ = |(m₁-m₂)/(1+m₁m₂)|. Condition for perpendicular: m₁m₂ = -1. Condition for parallel: m₁ = m₂. Distance from point (x₁,y₁) to line ax+by+c=0: d = |ax₁+by₁+c|/√(a²+b²).

2. Circles: Standard form: (x-h)² + (y-k)² = r². General form: x² + y² + 2gx + 2fy + c = 0, centre (-g,-f), radius r = √(g²+f²-c). Tangent at (x₁,y₁): xx₁ + yy₁ + g(x+x₁) + f(y+y₁) + c = 0. Condition for tangency: distance from centre to line = radius.

3. Parabola: Standard y² = 4ax. Focus: (a,0), directrix: x = -a, vertex: (0,0), latus rectum: x = a (length = 4a). Parametric: (at², 2at). Tangent at t: yt = x + at². Condition: y = mx + a/m touches parabola y² = 4ax.

4. Ellipse: x²/a² + y²/b² = 1 (a > b). Foci: (±ae,0), eccentricity e = √(1-b²/a²). Directrices: x = ±a/e. Latus rectum: x = ±ae (length = 2b²/a). Parametric: (a cosθ, b sinθ).

5. Hyperbola: x²/a² - y²/b² = 1. Foci: (±ae,0), eccentricity e = √(1+b²/a²). Directrices: x = ±a/e. Asymptotes: y = ±(b/a)x. Rectangular hyperbola: xy = c².

Solved Examples

Example 1 (Straight Line — Foot of Perpendicular)
Find the foot of the perpendicular from point P(3,2) to the line 2x + 3y - 4 = 0.

a) (5/13, 22/13) b) (25/13, 14/13) c) (2/13, 20/13) d) (1/13, 18/13)
Solution: b) (25/13, 14/13). Foot of perpendicular: (x - x₁)/a = (y - y₁)/b = -(ax₁+by₁+c)/(a²+b²). Here a=2, b=3, c=-4. x₁=3, y₁=2. Value = -(2·3+3·2-4)/(4+9) = -(6+6-4)/13 = -8/13. So x = 3 + (-8/13)·2 = 3 - 16/13 = 25/13. y = 2 + (-8/13)·3 = 2 - 24/13 = 14/13.
Example 2 (Circle — Tangent Condition)
Find the values of p for which the line y = px + 1 is a tangent to the circle x² + y² - 2x + 4y = 0.

a) 2, -1/2 b) 1, -2 c) 3, -1 d) 0, 1
Solution: a) 2, -1/2. Circle centre: (1,-2), radius r = √(1+4) = √5. Distance from centre to line: line: px - y + 1 = 0. d = |p(1) - (-2) + 1|/√(p²+1) = |p+3|/√(p²+1) = √5. Squaring: (p+3)² = 5(p²+1) → p² + 6p + 9 = 5p² + 5 → 4p² - 6p - 4 = 0 → 2p² - 3p - 2 = 0 → (2p+1)(p-2) = 0 → p = 2 or p = -1/2.

Shortcut Techniques

  • For conic sections, learn the standard forms thoroughly — most JEE problems reduce to identifying the conic and applying standard formulas.
  • Parametric forms are powerful: use parametric coordinates for tangents, normals, and chord problems to avoid messy algebra.
  • For circle and line tangency, use the condition perpendicular distance from centre = radius rather than solving the quadratic.
  • Family of circles: through intersection of two circles S=0 and S'=0 → S + λS' = 0. Through intersection of circle and line → S + λL = 0.
  • For ellipse and hyperbola, the auxiliary circle equation is x²+y²=a², and eccentricity relationships help find foci/directrices quickly.
Pro Tip
Coordinate geometry in JEE Advanced often combines with calculus (e.g., finding tangents using derivatives, or area bounded by curves). Always sketch the figure before solving — a rough graph helps identify intersection points and the correct integration limits.
