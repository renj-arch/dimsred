📐 Part 1: Tangents & Normals — The Derivative as Slope

The Derivative Is the Slope of the Tangent Line. Period.

You learned in the Calculus lesson that f'(a) gives the instantaneous rate of change at x = a. Geometrically, that's the slope of the tangent line to the curve y = f(x) at the point (a, f(a)).

📐 The Core Idea
Tangent = The line that "just touches" the curve. Normal = The line perpendicular to the tangent.
Imagine driving a car around a curve. At any instant, your direction of travel is the tangent at that point. The normal is the line perpendicular to your direction — like the direction a skid mark would point if you hit the brakes.

Equation of tangent at (x₀, y₀): y − y₀ = f'(x₀)(x − x₀)
Equation of normal at (x₀, y₀): y − y₀ = −1/f'(x₀)(x − x₀) (if f'(x₀) ≠ 0)

If f'(x₀) = 0, the tangent is horizontal (y = y₀), and the normal is vertical (x = x₀).
💡 Tangent = derivative as slope. Normal = negative reciprocal slope. Two lines, one derivative.
📐 Tangent & Normal — Visualized
The tangent (amber, dashed) touches the curve at exactly one point. The normal (green, dotted) is perpendicular to the tangent. Together they form a crosshair at the point of interest.

Worked Example: Tangent & Normal

Find the equations of the tangent and normal to y = x² at the point (2, 4).

1 Find the derivative ▶
f(x) = x²
f'(x) = 2x
At x = 2: f'(2) = 2(2) = 4.

The slope of the tangent at (2, 4) is 4.
2 Equation of tangent ▶
Point-slope form: y − y₀ = m(x − x₀)
y − 4 = 4(x − 2)
y − 4 = 4x − 8
y = 4x − 4 (Tangent)
3 Equation of normal ▶
Slope of normal = −1/m = −1/4.
y − 4 = (−1/4)(x − 2)
y − 4 = −x/4 + 1/2
y = −x/4 + 9/2 (Normal)

Angle Between Two Curves

The angle between two curves at their intersection point is the angle between their tangents at that point.

📐 Angle Between Curves
tan(θ) = |(m₁ − m₂)/(1 + m₁m₂)|
To find the angle between curves y₁ = f(x) and y₂ = g(x) at their intersection:

1. Find the intersection point(s) by solving f(x) = g(x).
2. Find m₁ = f'(x₀) and m₂ = g'(x₀) at the intersection.
3. Use the formula: tan(θ) = |(m₁ − m₂)/(1 + m₁m₂)|.

If m₁m₂ = −1, the curves intersect orthogonally (at 90°).
If m₁ = m₂, the curves touch each other (angle = 0°).
💡 The angle between curves = the angle between their tangents. Same formula as angle between two lines!
🌟 Tangent & Normal Checklist
1. Find f'(x) → 2. Plug in x₀ for slope → 3. Use point-slope line equation
Normal slope = negative reciprocal. Horizontal tangent → vertical normal (and vice versa).
📈 Part 2: Increasing & Decreasing — The Derivative Tells You Where the Function Goes

If f'(x) > 0, the Function Is Rising. If f'(x) < 0, It's Falling.

The derivative is like a thermometer for direction. Positive derivative = function going up. Negative derivative = function going down. Zero derivative = flat (possibly a peak or valley).

📈 Increasing vs Decreasing — Read the Slope
Increasing: The curve rises as x increases (tangent slopes upward). Decreasing: The curve falls as x increases (tangent slopes downward). The critical points where f'(x) = 0 are where the function changes direction (local max/min).

How to Find Intervals of Increase/Decrease

📈 The Method
4 Steps to Find Where a Function Is Increasing or Decreasing
1. Find f'(x).
2. Set f'(x) = 0 and solve for critical points (where f' = 0 or f' is undefined).
3. Plot these critical points on a number line to divide the domain into intervals.
4. Test ONE point in each interval: if f'(test) > 0, the function is increasing there. If f'(test) < 0, it's decreasing.

Example: f(x) = x³ − 3x. f'(x) = 3x² − 3 = 3(x − 1)(x + 1).
Critical points: x = −1, x = 1.
Test x = −2: f'(−2) = 3(4 − 1) = 9 > 0 → increasing on (−∞, −1).
Test x = 0: f'(0) = −3 < 0 → decreasing on (−1, 1).
Test x = 2: f'(2) = 3(4 − 1) = 9 > 0 → increasing on (1, ∞).
💡 The sign of f'(x) tells you the direction. Positive = climbing. Negative = descending. Zero = possibly flat (critical point).

Worked Example: Monotonicity

Find the intervals where f(x) = 2x³ − 9x² + 12x − 5 is increasing or decreasing.

1 Find the derivative and factor ▶
f'(x) = 6x² − 18x + 12 = 6(x² − 3x + 2) = 6(x − 1)(x − 2).

Critical points: x = 1 and x = 2 (where f'(x) = 0).
Domain is ℝ, so the number line is: (−∞, 1), (1, 2), (2, ∞).
2 Test each interval ▶
Interval (−∞, 1): Test x = 0. f'(0) = 6(−1)(−2) = 12 > 0 → Increasing.
Interval (1, 2): Test x = 1.5. f'(1.5) = 6(0.5)(−0.5) = −1.5 < 0 → Decreasing.
Interval (2, ∞): Test x = 3. f'(3) = 6(2)(1) = 12 > 0 → Increasing.

Result: f is increasing on (−∞, 1) ∪ (2, ∞), and decreasing on (1, 2).
At x = 1: f goes from ↑ to ↓ → local maximum.
At x = 2: f goes from ↓ to ↑ → local minimum.
🌟 Direction Change = Extreme Point
↑ to ↓ at critical point → local maximum. ↓ to ↑ at critical point → local minimum.
This is the First Derivative Test — the simplest way to classify critical points.
🏔️ Part 3: Maxima & Minima — Finding the Peaks and Valleys

The Derivative Finds Where Things Peak and Where They Bottom Out

In real life, we're always optimizing: maximizing profit, minimizing cost, finding the shortest path. The derivative is our optimization superpower.

🏔️ Local vs Absolute Extrema — Peaks and Valleys
Local maximum: Higher than all nearby points. Local minimum: Lower than all nearby points. Absolute (global) maximum: The highest point overall. Every peak has a horizontal tangent (f' = 0).

First Derivative Test vs Second Derivative Test

🏔️ Two Tests for Classifying Critical Points
First Derivative Test (check sign change) vs Second Derivative Test (check concavity)
First Derivative Test:
• f' changes from + to − at c → local maximum (peak)
• f' changes from − to + at c → local minimum (valley)
• f' does NOT change sign → point of inflection (neither)

Second Derivative Test (faster when f'' exists):
• If f'(c) = 0 and f''(c) < 0 → local maximum (curve is ∩-shaped)
• If f'(c) = 0 and f''(c) > 0 → local minimum (curve is ∪-shaped)
• If f''(c) = 0 → test is inconclusive (use first derivative test)
💡 f'' < 0 → concave down → maximum. f'' > 0 → concave up → minimum. f'' = 0 → need more investigation.

Worked Example: Maxima & Minima

Find all local maxima and minima of f(x) = x³ − 3x + 1, and determine their nature.

1 Find critical points ▶
f'(x) = 3x² − 3 = 3(x² − 1) = 3(x − 1)(x + 1).
Set f'(x) = 0: x = −1 or x = 1.
Critical points: x = −1 and x = 1.
2 Apply the second derivative test ▶
f''(x) = 6x.

At x = −1: f''(−1) = −6 < 0 → Local maximum. f(−1) = −1 + 3 + 1 = 3. So local max at (−1, 3).

At x = 1: f''(1) = 6 > 0 → Local minimum. f(1) = 1 − 3 + 1 = −1. So local min at (1, −1).

(−1, 3) 🏔️
Local Max (f'' < 0)
(1, −1) 🪷
Local Min (f'' > 0)

Worked Example: Maxima on a Closed Interval

Find the absolute maximum and minimum of f(x) = x³ − 3x + 1 on [−2, 3].

1 Check critical points AND endpoints ▶
Critical points from above: x = −1, x = 1 (both in [−2, 3]).
Endpoints: x = −2, x = 3.

Evaluate f at all four:
f(−2) = −8 + 6 + 1 = −1
f(−1) = −1 + 3 + 1 = 3
f(1) = 1 − 3 + 1 = −1
f(3) = 27 − 9 + 1 = 19

Absolute maximum: f(3) = 19 (at the right endpoint!)
Absolute minimum: f(−2) = −1 and f(1) = −1 (tied at two points).
🌟 Closed Interval Method
To find absolute extrema on [a, b]: evaluate f at ALL critical points in (a, b) AND at both endpoints. The largest value wins.
Don't forget the endpoints! The absolute max/min can be at an endpoint, not necessarily at a critical point.
⏱️ Part 4: Rate of Change — Derivatives in the Real World

The Derivative Measures HOW FAST Something Changes

In the real world, quantities change with time. The derivative dy/dt tells you the rate at which y changes. This is the most practical application of derivatives — from physics to economics.

⏱️ Rate of Change
dy/dt = The Speedometer of Any Quantity
If y = f(t) describes a quantity at time t, then dy/dt is its rate of change.

Examples:
• Position s(t) → velocity = ds/dt → acceleration = d²s/dt²
• Area A(r) = πr² → dA/dt = 2πr·dr/dt (chain rule!)
• Profit P(q) → marginal profit = dP/dq

Related rates: When two quantities are linked by an equation, you can find how fast one changes by knowing how fast the other changes. Differentiate both sides with respect to time (t) using the chain rule.
💡 dy/dt = "how fast y changes per unit time." For related rates: differentiate the relationship, plug in known values, solve for the unknown rate.

Worked Example: Related Rates — Expanding Balloon

Air is being pumped into a spherical balloon at 5 cm³/s. Find the rate at which the radius is increasing when the radius is 10 cm. (Volume of sphere: V = 4πr³/3)

1 Set up the relationship ▶
Given: dV/dt = 5 cm³/s (rate of volume increase).
Need: dr/dt when r = 10 cm.

Relationship: V = 4πr³/3.
Differentiate both sides with respect to t: dV/dt = 4πr²·dr/dt.
2 Plug in known values ▶
dV/dt = 4πr²·dr/dt
5 = 4π(10)²·dr/dt
5 = 400π·dr/dt
dr/dt = 5/(400π) = 1/(80π) cm/s.

dr/dt ≈ 0.00398 cm/s (about 0.004 cm per second)
The radius increases very slowly because a sphere with r = 10 has a large surface area (400π cm²), so new air spreads thin.

Worked Example: Motion Along a Line

A particle moves along a line such that s(t) = t³ − 6t² + 9t + 1 (s in meters, t in seconds). Find velocity and acceleration at t = 2.

1 Velocity = ds/dt, Acceleration = dv/dt ▶
v(t) = ds/dt = 3t² − 12t + 9
a(t) = dv/dt = 6t − 12

At t = 2:
v(2) = 3(4) − 24 + 9 = 12 − 24 + 9 = −3 m/s (moving backward/left)
a(2) = 12 − 12 = 0 m/s² (momentarily not accelerating)

The negative velocity at t = 2 means the particle is moving in the negative direction. Zero acceleration means the velocity is at a turning point (minimum velocity).
🌟 Related Rates Strategy
1. Write the relationship. 2. Differentiate with respect to t. 3. Substitute known values. 4. Solve for unknown rate.
The chain rule is your friend: dr/dt, dV/dt, dA/dt — everything changes with time, so every variable gets a dt derivative.
⚠️ Common Mistakes (Don't Fall For These!)

These Traps Trip Up Even Top Students

⚠️ Mistake 1
Forgetting That f'(c) = 0 Is NECESSARY But Not SUFFICIENT for Extrema
Wrong: f'(c) = 0 means c is a local max or min ❌
Right: f'(c) = 0 only means c is a critical point. It could be a max, a min, or a point of inflection.

Example: f(x) = x³. f'(0) = 0, but (0, 0) is a point of inflection (the function is increasing through x = 0). The first derivative doesn't change sign!

Always check the sign change (first derivative test) or concavity (second derivative test) to classify critical points.
⚠️ f'(c) = 0 is a clue, not a verdict. Always verify whether it's a max, min, or inflection point.
⚠️ Mistake 2
Forgetting to Check Endpoints for Absolute Extrema
Wrong: Finding f'(x) = 0 gives the absolute max and min on [a, b] ❌
Right: The absolute max/min can occur at endpoints of the interval, not just at critical points!

Example: f(x) = x² on [−2, 3]. f'(x) = 2x = 0 → x = 0. f(0) = 0. But f(3) = 9 is the absolute maximum. The critical point gave the minimum, not the maximum!

Always evaluate the function at endpoints when finding absolute extrema on a closed interval.
⚠️ On a closed interval, absolute extrema live at EITHER critical points OR endpoints. Check both!
⚠️ Mistake 3
Confusing Increasing/Decreasing with Positive/Negative Function Values
Wrong: f(x) > 0 means f is increasing ❌
Right: f(x) > 0 means the function's VALUE is positive. f'(x) > 0 means the function is increasing.

A function can be positive and decreasing (like f(x) = e⁻ˣ for x > 0).
A function can be negative and increasing (like f(x) = ln(x) for 0 < x < 1).

f'(x) is about DIRECTION, not VALUE. Don't mix them up!
⚠️ f'(x) > 0 → function going UP (increasing). f(x) > 0 → function is ABOVE the x-axis. These are completely different things!
🧠 Application of Derivatives Toolkit

4 Strategies That Crack Almost Any Problem

🧠 Strategy 1
"Tangent = Derivative at the Point"
Every tangent problem boils down to: find f'(x₀), then use point-slope form. No matter how complex the function looks, the tangent is always:

y − f(a) = f'(a)(x − a)
For the normal, just flip the slope to its negative reciprocal. If the slope is 0 (horizontal tangent), the normal is vertical (x = a). If the slope is infinite (vertical tangent), the normal is horizontal (y = f(a)).
💡 One formula for all tangents: y − y₀ = m(x − x₀) where m = f'(x₀). Don't overthink it!
🧠 Strategy 2
"Sign Chart for Monotonicity"
To find intervals of increase/decrease:

1. Find f'(x) and factor it.
2. Find all x where f'(x) = 0 or f'(x) DNE.
3. Draw a number line with these points marked.
4. Pick a test point in each interval and evaluate f' there.
5. Mark each interval as + (increasing) or − (decreasing).

Pro tip: Use the factored form of f'(x) to quickly determine signs. A factor like (x − a) changes sign at a. A squared factor like (x − a)² never changes sign.
💡 The sign chart is your best friend for monotonicity. One test value per interval is enough — f' can only change sign at critical points!
🧠 Strategy 3
"Second Derivative Test for Quick Classification"
When you already have f''(x) and finding it isn't too messy, use the second derivative test:

• f'(c) = 0 AND f''(c) < 0 → local maximum (concave down ∩)
• f'(c) = 0 AND f''(c) > 0 → local minimum (concave up ∪)
• f''(c) = 0 → test fails. Use the first derivative test instead.

When to use which: The second derivative test is faster but can fail (when f'' = 0). The first derivative test always works but requires more work (checking sign on both sides).
💡 f'' < 0 = ∩ = max. f'' > 0 = ∪ = min. If f'' = 0, fall back to the first derivative test.
🧠 Strategy 4
"Chain Rule for Related Rates"
Related rates problems always follow the same pattern:

1. Write an equation linking the quantities.
2. Differentiate BOTH sides with respect to t (time). Every variable gets a dt derivative via chain rule.
3. Plug in the known values (be careful with signs — "increasing" means positive rate, "decreasing" means negative).
4. Solve for the unknown rate.

Example: A ladder sliding down a wall. x² + y² = L². Differentiate: 2x·dx/dt + 2y·dy/dt = 0. So dy/dt = −(x/y)·dx/dt.
💡 Differentiate the relationship, then substitute. The chain rule automatically handles the rates — just let d/dt flow through every variable.
🔥 Advanced Worked Examples (JEE Level)

Multi-Step Problems That Combine Multiple Concepts

Example 1: Tangent + Monotonicity + Optimization

A curve y = ax² + bx + c passes through (1, 3) and has a tangent with slope 5 at x = 2. The function has a local minimum at x = 1. Find a, b, c.

1 Set up equations from the conditions ▶
y = ax² + bx + c
y' = 2ax + b

Condition 1: Passes through (1, 3): a(1)² + b(1) + c = 3 → a + b + c = 3
Condition 2: Tangent slope = 5 at x = 2: y'(2) = 4a + b = 5
Condition 3: Local minimum at x = 1: y'(1) = 2a + b = 0
2 Solve the system ▶
From condition 3: b = −2a.
Substitute into condition 2: 4a + (−2a) = 5 → 2a = 5 → a = 5/2 = 2.5
b = −2(5/2) = −5.
From condition 1: 5/2 − 5 + c = 3 → c = 3 + 5 − 5/2 = 8 − 2.5 = 11/2 = 5.5

y = 2.5x² − 5x + 5.5
Verify: y'(1) = 5 − 5 = 0 ✅. y''(1) = 5 > 0 → local minimum ✅.

Example 2: Optimization — Maximizing Area

A farmer has 100 meters of fencing. He wants to enclose a rectangular field against an existing wall (no fence needed on the wall side). Find the dimensions that maximize the area.

1 Set up the equations ▶
Let the side parallel to the wall be L, and the other two sides (perpendicular to the wall) be W each.

Fencing used: L + 2W = 100 → L = 100 − 2W.
Area: A = L × W = (100 − 2W)W = 100W − 2W².

Domain: W > 0 and L = 100 − 2W > 0 → W ∈ (0, 50).
2 Maximize using derivatives ▶
A(W) = 100W − 2W²
A'(W) = 100 − 4W
Set A'(W) = 0: 100 − 4W = 0 → W = 25.

A''(W) = −4 < 0 → local maximum (and the only critical point in the domain, so global max).

L = 100 − 2(25) = 50.

Dimensions: 50m × 25m. Max area = 1250 m².

Example 3: Rate of Change — Radius of a Cylinder

The radius of a cylinder is increasing at 0.5 cm/s while its height is constant at 10 cm. Find the rate of change of volume when r = 4 cm. (V = πr²h)

1 Differentiate the volume formula ▶
V = πr²h = πr²(10) = 10πr²

dV/dt = 10π·2r·dr/dt = 20πr·dr/dt

Given: dr/dt = 0.5 cm/s, r = 4 cm.

dV/dt = 20π(4)(0.5) = 20π(2) = 40π cm³/s.

At r = 4 cm, the volume is increasing at about 125.7 cm³ per second.
