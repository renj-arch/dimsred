🔄 Part 1: Indefinite Integration — The Anti-Derivative

Integration Asks: "What Function Did This Come From?"

If differentiation tells you the rate of change, integration tells you the original quantity. It's like knowing someone's speed at every moment and asking: where did they start?

🔄 The Core Idea
Integration = Reverse Differentiation — Like Watching a Movie Backward
If f(x) = x², then f'(x) = 2x. Integration goes the other way: ∫ 2x dx = x² + C.

The integral sign ∫ means "find the anti-derivative." The dx tells you the variable. The + C is the constant of integration — because the derivative of a constant is zero, we can never know the exact constant from just the derivative.

Analogy: If you know a car's speed at every moment (derivative), you can figure out where it went (integral), but you won't know exactly where it started (the + C).
💡 ∫ f'(x) dx = f(x) + C. The integral undoes the derivative, but the + C represents lost information.

The Basic Integrals — The Building Blocks

Every integration problem ultimately breaks down into these basic forms. Learn the PATTERN, not the formula.

📊 Basic Integral Patterns — The Building Blocks
The 10 basic integrals form the foundation of ALL integration. Every complex integral is a combination of these patterns using substitution, parts, or partial fractions.

Worked Example: Basic Integration

Find ∫ (3x² + 2x − 5) dx.

1 Integrate term by term using linearity ▶
∫ 3x² dx = 3·x³/3 = x³
∫ 2x dx = 2·x²/2 = x²
∫ −5 dx = −5x

∫ (3x² + 2x − 5) dx = x³ + x² − 5x + C
Check by differentiating: d/dx(x³ + x² − 5x + C) = 3x² + 2x − 5 ✅

Integration by Substitution — The Chain Rule in Reverse

The chain rule says: d/dx f(g(x)) = f'(g(x))·g'(x). Substitution reverses this: if you spot a function AND its derivative in the integrand, substitute.

🔄 Substitution
If You See f(g(x))·g'(x), Let u = g(x)
Example: ∫ 2x·cos(x²) dx

Notice: the derivative of x² is 2x, which appears right next to cos(x²). Let u = x², then du/dx = 2x, so du = 2x dx.

The integral becomes: ∫ cos(u) du = sin(u) + C = sin(x²) + C.

The pattern: Look for a function (the "inner" function) whose derivative is also present (up to a constant factor). Substitute u = inner function, replace dx with du/derivative.
💡 Substitution = "spot the chain rule in reverse." If a function and its neighbor look like a chain, let u = the inner function.

Integration by Parts — The Product Rule in Reverse

The product rule: (uv)' = u'v + uv'. Rearranging: ∫ uv' dx = uv − ∫ u'v dx.

⚡ Integration by Parts
∫ u dv = uv − ∫ v du — The Product Rule in Reverse
Choose u as the function that simplifies when differentiated, and dv as the function that doesn't get more complicated when integrated.

ILATE priority for choosing u:
I — Inverse trig (e.g., sin⁻¹(x))
L — Logarithmic (e.g., ln(x))
A — Algebraic (e.g., x, x²)
T — Trigonometric (e.g., sin(x), cos(x))
E — Exponential (e.g., eˣ)

Example: ∫ x·eˣ dx. u = x (algebraic), dv = eˣ dx (exponential).
du = dx, v = eˣ. Formula: uv − ∫ v du = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x − 1) + C.
💡 ILATE tells you which function to set as u. The other function becomes dv. Then: ∫ u dv = uv − ∫ v du.
🌟 Indefinite Integration Cheat Sheet
Power rule: ∫ xⁿ = xⁿ⁺¹/(n+1).  |  Substitution: ∫ f(g(x))g'(x) dx = ∫ f(u) du

📏 Part 2: Definite Integration — Adding Up the Slices

The Definite Integral = The Area Under the Curve

While indefinite integration gives a family of functions, definite integration gives a NUMBER — the net area under the curve between two x-values.

📏 The Definite Integral = Area of Infinitely Thin Rectangles
The Riemann sum: The definite integral ∫ₐᵇ f(x) dx is the limit of the sum of rectangle areas as the width → 0. Each rectangle has height f(xᵢ) and width Δx. As Δx → 0, the approximation becomes exact.

The Fundamental Theorem of Calculus (FTC)

The FTC connects differentiation and integration — it says that integration (adding up slices) is the opposite of differentiation (finding slopes).

📏 The FTC
∫ₐᵇ f(x) dx = F(b) − F(a), where F'(x) = f(x)
This is THE most important theorem in calculus. It says:

1. Find the anti-derivative F(x) of f(x).
2. Evaluate F at the upper limit b.
3. Evaluate F at the lower limit a.
4. Subtract: F(b) − F(a).

Example: ∫₀² x² dx = [x³/3]₀² = (8/3) − (0/3) = 8/3.

Properties:
• ∫ₐᵇ f(x) dx = −∫ᵇₐ f(x) dx (reversing limits flips the sign)
• ∫ₐᵇ f(x) dx + ∫ᵇᶜ f(x) dx = ∫ₐᶜ f(x) dx (splitting intervals)
• ∫ₐᵃ f(x) dx = 0 (zero-width interval)
💡 FTC = "Find the anti-derivative, plug in the bounds, subtract." That's all definite integration is!

The King's Property — ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b − x) dx

This property is a JEE favorite because it simplifies integrals that look impossible. The idea: replace x with (a + b − x) — the integral stays the same.

👑 King's Property
∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b − x) dx — The Reflection Trick
Why it works: As x goes from a to b, (a + b − x) goes from b to a. The integral over the same interval of the reflected function equals the original integral.

Example: ∫₀^{π/2} sin(x)/(sin(x) + cos(x)) dx.
Let I = ∫₀^{π/2} sin(x)/(sin(x) + cos(x)) dx.
Using King's: I = ∫₀^{π/2} sin(π/2 − x)/(sin(π/2 − x) + cos(π/2 − x)) dx
= ∫₀^{π/2} cos(x)/(cos(x) + sin(x)) dx.
Adding: 2I = ∫₀^{π/2} (sin + cos)/(sin + cos) dx = ∫₀^{π/2} 1 dx = π/2.
Therefore: I = π/4. Magic! 🎩
💡 King's property: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx. In JEE, this turns impossible-looking trig integrals into trivial ones.

Even & Odd Function Integration

For symmetric intervals [−a, a], the parity of the function simplifies things dramatically.

📊 Even & Odd — Half the Work
Even functions: Symmetric about the y-axis → integrate from 0 to a and double it. Odd functions: Symmetric about the origin → the integral over [−a, a] is always zero because the left and right halves cancel.
🌟 Definite Integration: Key Properties
FTC: ∫ₐᵇ f(x) dx = F(b) − F(a)  |  King's: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx
Even: ∫₋ₐᵃ = 2∫₀ᵃ  |  Odd: ∫₋ₐᵃ = 0  |  Splitting: ∫ₐᵇ + ∫ᵇᶜ = ∫ₐᶜ
📐 Part 3: Area Under Curves — Integration in Action

The Definite Integral = The Net Area (Above − Below the x-axis)

This is the most visual application of integration: finding the area bounded by curves.

📐 Area Between Curves
Area = ∫ (Top Curve − Bottom Curve) dx
Area between y = f(x) and y = g(x) from x = a to x = b:

Area = ∫ₐᵇ |f(x) − g(x)| dx
Where f(x) is the upper curve and g(x) is the lower curve on the interval.

Steps:
1. Find the intersection points of the curves (where f(x) = g(x)).
2. Determine which curve is on top in each interval.
3. Integrate (top − bottom) over each interval.
4. Add the absolute values.

Area between curve and x-axis: ∫ₐᵇ |f(x)| dx. If f(x) is always positive on the interval, it's just ∫ₐᵇ f(x) dx.
💡 Area = ∫ (top − bottom). If curves cross, split the interval at the intersection points and handle each piece separately.
⚡ Part 4: Advanced Techniques — When Basic Methods Aren't Enough

Partial Fractions, Special Integrals, and Reduction Formulas

These techniques appear frequently in JEE Advanced. Here's a conceptual overview — the formulas are in your toolkit.

Partial Fractions — Breaking Rational Functions into Simple Pieces

When integrating rational functions (polynomial/polynomial), you decompose them into simpler fractions that you know how to integrate.

⚡ Partial Fractions
1/(x² − 1) = ½·1/(x−1) − ½·1/(x+1)
Example: ∫ 1/(x² − 1) dx.
Step 1: Factor denominator: x² − 1 = (x − 1)(x + 1).
Step 2: Write 1/((x−1)(x+1)) = A/(x−1) + B/(x+1).
Step 3: Solve: A(x+1) + B(x−1) = 1. Put x=1: 2A = 1 → A = ½. Put x=−1: −2B = 1 → B = −½.
Step 4: Integrate: ∫ ½·1/(x−1) − ½·1/(x+1) dx = ½ ln|x−1| − ½ ln|x+1| + C = ½ ln|(x−1)/(x+1)| + C.

Partial fractions turns division into addition — then you just integrate ln terms!
💡 Partial fractions = "split a complicated fraction into simple ones you know how to integrate." Always factor the denominator first!

Special Integral Forms

These three forms appear constantly in JEE. Derive them once, then use them as formulas.

📊 Three Special Integral Forms
These three special forms (and their variants) cover most JEE integration problems involving √ and quadratic denominators. The key trick: complete the square in the quadratic to express it as a² ± x² or x² ± a².
🌟 Integration Strategy
1. Basic form? → Power rule / trig / exponential. 2. Chain rule pattern? → Substitution. 3. Product? → By parts (ILATE). 4. Rational? → Partial fractions. 5. √ or (a²+x²)? → Special forms.
Always check the form FIRST, then pick the method. Most JEE problems test your ability to CHOOSE the right technique.
⚠️ Common Mistakes (Don't Fall For These!)

These Traps Trip Up Even Top Students

⚠️ Mistake 1
Forgetting the + C in Indefinite Integration
Wrong: ∫ 2x dx = x² ❌
Right: ∫ 2x dx = x² + C ✅

The + C is NOT optional! Since d/dx(constant) = 0, any constant could have been in the original function. The integral represents a family of functions, not just one.

In definite integration, the + C cancels out: F(b) + C − (F(a) + C) = F(b) − F(a). So you don't need + C in definite integrals, but it's a must for indefinite.
⚠️ Never forget the + C in indefinite integrals. Without it, your answer is incomplete — you've only found ONE of infinitely many anti-derivatives!
⚠️ Mistake 2
Confusing ∫ 1/x dx with ln(x) Instead of ln|x|
Wrong: ∫ 1/x dx = ln(x) + C ❌
Right: ∫ 1/x dx = ln|x| + C ✅

The absolute value matters because 1/x is defined for negative x too! ln(x) is only defined for x > 0, but ln|x| works for all x ≠ 0.

Example: ∫₋₂⁻¹ 1/x dx = [ln|x|]₋₂⁻¹ = ln(1) − ln(2) = −ln(2). Without the absolute value, you'd get ln(−1) which doesn't exist!
⚠️ ∫ 1/x dx = ln|x| + C, not ln(x) + C. The absolute value handles negative x correctly.
⚠️ Mistake 3
Forgetting to Change Limits When Substituting in Definite Integrals
Wrong: ∫₀² 2x·cos(x²) dx. Let u = x². Then ∫ cos(u) du = sin(u). Then evaluate sin(u) from 0 to 2. ❌
Right: When x = 0 → u = 0. When x = 2 → u = 4. So the integral is ∫₀⁴ cos(u) du = [sin(u)]₀⁴ = sin(4). ✅

When you substitute in a definite integral, you MUST change the limits to the new variable. Alternatively, substitute back to x at the end and use the original limits.
⚠️ Substitution in definite integrals: change the limits TO the new variable. Forgetting this is the most common definite integration error!
🧠 Integration Toolkit

4 Strategies That Crack Almost Any Problem

🧠 Strategy 1
"Identify the Form First" — The Integration Flowchart
Before doing ANY algebra, look at the integrand and ask:

• Is it a basic form (power, trig, exponential)? → Use the basic rules.
• Does it look like f(g(x))·g'(x)? → Substitute u = g(x).
• Is it a product of two different kinds of functions? → Integration by parts (ILATE).
• Is it a rational function (polynomial/polynomial)? → Partial fractions.
• Does it have √(a²−x²) or 1/(a²+x²)? → Special forms.

Most JEE problems test your ability to recognize which technique to use. Practice identifying the form at a glance.
💡 Don't just start computing. First: what kind of integral is this? The form determines the method.
🧠 Strategy 2
"Properties First" for Definite Integrals
Before evaluating a definite integral, check if properties can simplify it:

• Is the interval symmetric [−a, a]? → Check if the function is even or odd.
• Does the integrand look like it could use King's property (especially with trig functions and limits 0 to π/2)?
• Can you split the integral at a point where the function changes form (like |x|)?

Pro tip: If the integral looks impossibly hard, try King's property. If it still looks hard, add the original integral to the King's-transformed version — the sum often simplifies dramatically.
💡 Properties of definite integrals are NOT optional shortcuts — they're the main method for JEE. King's property alone solves 30% of JEE definite integral problems.
🧠 Strategy 3
"Complete the Square" for Quadratic Denominators
When integrating rational functions with quadratic denominators that don't factor nicely:

Complete the square to turn it into one of the special forms.

Example: ∫ 1/(x² + 2x + 5) dx.
Complete the square: x² + 2x + 5 = (x + 1)² + 4.
Now: ∫ 1/((x+1)² + 2²) dx = (1/2)·tan⁻¹((x+1)/2) + C.

This technique works for ANY quadratic — just rewrite x² + bx + c as (x + b/2)² + (c − b²/4).
💡 Completing the square turns ANY quadratic into (something)² + (constant)². Then it's just the tan⁻¹ formula.
🧠 Strategy 4
"Check the Derivative" After Integrating
The fastest way to verify an integration is to differentiate your answer. If you get back the original integrand, you're correct.

This catches:
• Sign errors (e.g., ∫ sin(x) dx = −cos(x) + C, not cos(x) + C)
• Coefficient errors (e.g., was it ∫ 2x dx = x² + C or 2x² + C?)
• ln vs ln||absolute value issues

For definite integrals, after finding the anti-derivative, quickly verify by differentiating. Then plug in the bounds.
💡 Differentiation is the best integration checker. If your answer differentiates to the original function, it's correct. Period.

Multi-Step Problems That Combine Multiple Concepts

Example 1: King's Property + Substitution

Evaluate I = ∫₀^{π/2} √(tan(x)) dx.

1 Apply King's property ▶
I = ∫₀^{π/2} √(tan(x)) dx.
By King's property (replace x with π/2 − x):
I = ∫₀^{π/2} √(tan(π/2 − x)) dx = ∫₀^{π/2} √(cot(x)) dx.

Add: 2I = ∫₀^{π/2} [√(tan(x)) + √(cot(x))] dx.
2 Simplify the integrand ▶
√(tan(x)) + √(cot(x)) = √(tan(x)) + 1/√(tan(x))
= (tan(x) + 1)/√(tan(x)) = (sin(x)/cos(x) + 1)/√(tan(x))
= (sin(x) + cos(x))/√(sin(x)cos(x)).

So 2I = ∫₀^{π/2} (sin(x) + cos(x))/√(sin(x)cos(x)) dx.
3 Substitute t = sin(x) − cos(x) ▶
Let t = sin(x) − cos(x). Then dt = (cos(x) + sin(x)) dx.
t² = sin²(x) + cos²(x) − 2sin(x)cos(x) = 1 − 2sin(x)cos(x).
So sin(x)cos(x) = (1 − t²)/2.

When x = 0: t = 0 − 1 = −1. When x = π/2: t = 1 − 0 = 1.

2I = ∫₋₁¹ dt / √((1 − t²)/2) = √2 ∫₋₁¹ dt/√(1 − t²)
= √2 [sin⁻¹(t)]₋₁¹ = √2(π/2 − (−π/2)) = √2·π.

I = π/√2

Example 2: Area Between Curves

Find the area bounded by y = x² and y = √x.

1 Find intersection points ▶
Set x² = √x → x⁴ = x → x⁴ − x = 0 → x(x³ − 1) = 0.
Solutions: x = 0, x = 1.
Intersection points: (0, 0) and (1, 1).

At x = ½: x² = 0.25, √x = 0.707. So √x is above x² on (0, 1).
2 Integrate (top − bottom) ▶
Area = ∫₀¹ (√x − x²) dx
= ∫₀¹ (x¹/² − x²) dx
= [2x³/²/3 − x³/3]₀¹
= (2/3 − 1/3) − (0 − 0)
= 1/3 square units.

Area = 1/3 (approximately 0.333 square units)
The region between y = x² and y = √x from x = 0 to x = 1 has area 1/3.

Example 3: Integration by Parts (JEE Advanced Style)

Evaluate ∫₀^π eˣ·cos(x) dx.

1 Apply integration by parts ▶
Let u = cos(x), dv = eˣ dx.
du = −sin(x) dx, v = eˣ.

I = [eˣ·cos(x)]₀^π − ∫₀^π eˣ·(−sin(x)) dx
= [eˣ·cos(x)]₀^π + ∫₀^π eˣ·sin(x) dx
= (e^π·cos(π) − e⁰·cos(0)) + ∫₀^π eˣ·sin(x) dx
= (e^π·(−1) − 1·1) + ∫₀^π eˣ·sin(x) dx
= −e^π − 1 + ∫₀^π eˣ·sin(x) dx.
2 Apply integration by parts again ▶
Let J = ∫₀^π eˣ·sin(x) dx.
u = sin(x), dv = eˣ dx. du = cos(x) dx, v = eˣ.
J = [eˣ·sin(x)]₀^π − ∫₀^π eˣ·cos(x) dx
= (e^π·0 − e⁰·0) − I = −I.

So I = −e^π − 1 − I
2I = −(e^π + 1)
I = −(e^π + 1)/2
🌟 Cyclic Integration
When integrating eˣ·cos(x) or eˣ·sin(x), integration by parts creates a CYCLE. Solve for I algebraically: I = expression − I → 2I = expression → I = expression/2.
This technique is called "cyclic integration" or "solving for the integral." It works whenever the second integration by parts brings back the original integral.

Weierstrass Substitution for Rational Trigonometric Integrals

The substitution t = tan(x/2) converts any rational function of sin x and cos x into a rational function of t. The identities are sin x = 2t/(1+t²), cos x = (1−t²)/(1+t²), and dx = 2 dt/(1+t²). This transformation is universal for integrals of the form ∫ R(sin x, cos x) dx where R is a rational function. After substitution the integral becomes ∫ R(2t/(1+t²), (1−t²)/(1+t²)) · 2/(1+t²) dt, which can be tackled by partial fractions or standard rational integration techniques.

The method shines when the integrand contains mixtures like (sin x)/(1+cos x) or (1)/(a+b sin x). For example, ∫ dx/(1+sin x) becomes ∫ 2/(1+t²) · 1/(1+2t/(1+t²)) dt = ∫ 2/(1+t²+2t) dt = ∫ 2/(t+1)² dt = −2/(t+1)+C = −2/(tan(x/2)+1)+C. The substitution also handles definite integrals with limits 0 to π by mapping them to 0 to ∞, but care is needed when the interval crosses π because tan(x/2) has a discontinuity at x=π. In such cases split the integral at the discontinuity.

Compared with the standard trigonometric substitutions (sin x = 2t/(1+t²) etc.), Weierstrass is systematic and avoids casework. However, it often produces higher‑degree polynomials in t, so partial‑fraction decomposition can become algebraically heavy. A practical rule: if the integrand is a simple rational function of sin x and cos x with low‑degree numerator and denominator, Weierstrass is efficient; if the integrand already suggests a simpler substitution (e.g., u = sin x for ∫ cos x f(sin x) dx), prefer the simpler route.

When to Avoid Weierstrass

Integrals containing √(a+b sin x) or √(a+b cos x) are not rationalised by t = tan(x/2); they require Euler substitutions or other techniques. Also, integrals over symmetric intervals [−π, π] where the integrand is even or odd can be simplified using parity before any substitution.

Leibniz Integral Rule — Differentiation Under the Integral Sign

The Leibniz rule states that for an integral with parameter α, I(α) = ∫a(α)b(α) f(x,α) dx, the derivative is dI/dα = f(b(α),α)·b'(α) − f(a(α),α)·a'(α) + ∫a(α)b(α) ∂f/∂α dx. This allows one to evaluate difficult integrals by introducing a parameter, differentiating with respect to it, solving the resulting simpler integral, and then integrating back with respect to the parameter.

A classic application is the Dirichlet integral ∫0^∞ sin x/x dx. Define I(α) = ∫0^∞ e−αx sin x/x dx for α>0. Differentiating under the integral sign gives I'(α) = −∫0^∞ e−αx sin x dx = −1/(α²+1). Integrating back, I(α) = −tan⁻¹α + C. As α→∞, I(α)→0, so C = π/2. Hence I(0) = π/2, yielding the value of the original integral.

The rule requires that f and ∂f/∂α be continuous on the region of integration and that the limits a(α), b(α) be differentiable. If the limits are constant, the boundary terms vanish. In many JEE‑style problems the parameter appears only in the integrand, not in the limits, simplifying the formula to d/dα ∫_a^b f(x,α) dx = ∫_a^b ∂f/∂α dx.

Typical Parameter Choices

Common parameterisations include inserting an exponential factor e−αx to tame oscillatory integrands, or replacing a power x^n by xα to use Beta/Gamma functions. Another trick is to set I(α) = ∫0^π/2 ln(1+α sin²x) dx, differentiate to get a rational trigonometric integral, evaluate, then integrate back. The key is to recognise when the derivative eliminates a troublesome denominator or logarithm.

Leibniz Rule Application
Evaluate d/dα ∫0π/2 sin(α x)/x dx at α = 1.
Let I(α) = ∫0π/2 sin(α x)/x dx. The limits are constant, so dI/dα = ∫0π/2 ∂/∂α [sin(α x)/x] dx = ∫0π/2 cos(α x) dx = [sin(α x)/α]0π/2 = sin(απ/2)/α. At α = 1, dI/dα = sin(π/2)/1 = 1.
Exam‑Day Strategy for Leibniz Rule
When you see an integral with a parameter that looks impossible to integrate directly, try differentiating with respect to that parameter. If the derivative simplifies to a standard integral, compute it, then integrate the result with respect to the parameter. Always check the boundary terms if the limits depend on the parameter. This technique often turns a 10‑minute problem into a 2‑minute one.

Reduction Formulas for Powers of Sine and Cosine

Reduction formulas express ∫ sin^m x dx or ∫ cos^n x dx in terms of integrals with lower powers. For m,n ≥ 2, integration by parts yields ∫ sin^m x dx = −(1/m) sinm−1x cos x + (m−1)/m ∫ sinm−2x dx, and similarly ∫ cos^n x dx = (1/n) cosn−1x sin x + (n−1)/n ∫ cosn−2x dx. These recurrences reduce the power by two each step until reaching ∫ sin x dx = −cos x + C or ∫ cos x dx = sin x + C (odd powers) or ∫ dx = x + C (even powers).

For definite integrals over [0, π/2], the boundary terms vanish because sin 0 = 0, cos π/2 = 0, etc. This gives the Wallis formulas: ∫0π/2 sin2kx dx = ∫0π/2 cos2kx dx = (2k−1)!!/(2k)!! · π/2, and ∫0π/2 sin2k+1x dx = ∫0π/2 cos2k+1x dx = (2k)!!/(2k+1)!!. These closed forms are invaluable for evaluating integrals like ∫0π/2 sin4 x cos6 x dx without repeated integration by parts.

Mixed powers ∫ sin^m x cos^n x dx can be handled by reducing the even power using the identity sin²x = 1−cos²x or cos²x = 1−sin²x, then applying the single‑power reduction. If both m and n are odd, factor out one sin x cos x and substitute u = sin x or u = cos x. If one is even and the other odd, factor out the odd one and substitute.

Derivation of the Reduction Formula

Let I_m = ∫ sin^m x dx. Write sin^m x = sinm−1x · sin x. Set u = sinm−1x, dv = sin x dx. Then du = (m−1) sinm−2x cos x dx, v = −cos x. Integration by parts gives I_m = −sinm−1x cos x + (m−1)∫ sinm−2x cos²x dx. Replace cos²x = 1−sin²x to get I_m = −sinm−1x cos x + (m−1)Im−2 − (m−1)I_m. Solving for I_m yields the formula above.

Improper Integrals and Convergence Criteria

An improper integral occurs when the interval is infinite (∫_a^∞ f(x) dx) or the integrand has a vertical asymptote within the interval (∫_a^b f(x) dx with f unbounded). The integral is defined as a limit: ∫_a^∞ f(x) dx = limt→∞ ∫_a^t f(x) dx, and similarly for singularities. Convergence means the limit exists and is finite.

The p‑test is the primary tool: ∫1^∞ 1/x^p dx converges iff p > 1. For singularities at 0, ∫01 1/x^p dx converges iff p < 1. Comparison test: if 0 ≤ f(x) ≤ g(x) and ∫ g converges, then ∫ f converges; if ∫ f diverges, then ∫ g diverges. Limit comparison: if limx→∞ f(x)/g(x) = L with 0 < L < ∞, then ∫ f and ∫ g share convergence behaviour.

Absolute vs conditional convergence: ∫ f converges absolutely if ∫ |f| converges. If ∫ f converges but ∫ |f| diverges, the convergence is conditional. For example, ∫1^∞ sin x/x dx converges conditionally (Dirichlet test), while ∫1^∞ |sin x|/x dx diverges. The Dirichlet test states that if F(x) = ∫_a^x f(t) dt is bounded and g(x) decreases to 0, then ∫ f(x)g(x) dx converges. This is the standard proof for ∫1^∞ sin x/x dx.

Common Improper Integrals in Exams

∫0^∞ e−x2 dx = √π/2 (Gaussian integral). ∫0^∞ xn e−ax dx = n!/an+1 (Gamma function). ∫01 ln x dx = −1. ∫0^∞ sin x/x dx = π/2. Recognising these standard values saves time; they are often used as building blocks for more complex integrals via substitution or differentiation under the integral sign.

Euler Substitutions for Integrals Involving √(ax²+bx+c)

When the integrand contains √(ax²+bx+c) with a quadratic that does not factor nicely, three Euler substitutions rationalise the square root. First Euler substitution (a > 0): √(ax²+bx+c) = t − √a x. Second (c > 0): √(ax²+bx+c) = xt + √c. Third (real roots α, β): √(a(x−α)(x−β)) = t(x−α). Each transforms the integral into a rational function of t, which can then be integrated by partial fractions.

For example, ∫ dx/√(x²+4x+5). Complete the square: (x+2)²+1. Here a=1>0, so use first substitution: √(x²+4x+5) = t − x. Squaring gives x²+4x+5 = t² − 2tx + x² ⇒ 4x+5 = t² − 2tx ⇒ x(4+2t) = t²−5 ⇒ x = (t²−5)/(2t+4). Then dx = derivative, and √(...) = t − x = rational in t. The integral becomes ∫ rational(t) dt.

The choice of substitution depends on the signs of a and c and whether the quadratic has real roots. If a>0, the first substitution is usually simplest. If c>0, the second avoids fractions. If the quadratic factors over reals, the third is efficient. In practice, completing the square and then using a trigonometric or hyperbolic substitution (x+2 = tan θ or sinh θ) is often faster than Euler substitutions, but Euler's method is purely algebraic and guarantees rationalisation without trigonometric identities.

When Euler Substitutions Are Preferred

They are useful when the integrand is a rational function of x and √(ax²+bx+c) and the quadratic has no simple trigonometric substitution (e.g., when a<0 and c<0). They also appear in problems where the answer is expected in logarithmic or inverse hyperbolic form, because the rational integration naturally yields such expressions.

Beta and Gamma Functions — The Factorial Generalisation

The Gamma function Γ(z) extends the factorial to complex numbers (except non‑positive integers) via the Euler integral of the second kind: Γ(z) = ∫₀^∞ tz−1 e−t dt, valid for Re(z) > 0. The functional equation Γ(z+1) = z Γ(z) follows directly from integration by parts, giving Γ(n+1) = n! for n ∈ ℕ. The Beta function B(p,q) = ∫₀¹ tp−1 (1−t)q−1 dt (Re(p), Re(q) > 0) is symmetric: B(p,q) = B(q,p). The fundamental relation B(p,q) = Γ(p)Γ(q)/Γ(p+q) is proved by writing Γ(p)Γ(q) as a double integral over the first quadrant, changing to polar‑like coordinates u = t, v = s/(t+s), and recognising the Beta integral. This identity converts many rational‑power definite integrals into products of Gamma values. For example, ∫₀π/2 sinm−1θ cosn−1θ dθ = ½ B(m/2, n/2) = ½ Γ(m/2)Γ(n/2)/Γ((m+n)/2). Wallis' formulas for even/odd powers of sine and cosine are immediate corollaries. The duplication formula Γ(z)Γ(z+½) = 21−2z√π Γ(2z) and the reflection formula Γ(z)Γ(1−z) = π/sin(πz) allow evaluation of Gamma at half‑integers and rational arguments. In JEE‑level problems, the Beta‑Gamma machinery is the standard tool for integrals of the form ∫₀^∞ xm−1/(1+x)m+n dx, ∫₀¹ xp−1(1−x)q−1 dx, and trigonometric powers over [0, π/2]. Recognising the Beta kernel and converting to Gamma often reduces a messy algebraic integral to a one‑line answer involving factorials or √π.

Frullani Integrals and the Logarithmic Kernel

The Frullani integral ∫₀^∞ (f(ax) − f(bx))/x dx = (f(0) − f(∞)) ln(b/a) holds under mild conditions: f continuous on [0,∞), the limit f(∞) = limx→∞ f(x) exists and is finite, and the integral converges (typically guaranteed if f' is absolutely integrable). The proof writes the integral as ∫₀^A (f(ax)−f(bx))/x dx + ∫_A^∞ …, changes variables u = ax, v = bx in the first part, and uses the existence of f(∞) to control the tail. The most common kernel in exams is f(x) = e−x, giving ∫₀^∞ (e−ax − e−bx)/x dx = ln(b/a). Variants with f(x) = arctan x, f(x) = 1/(1+x), f(x) = sin x (where f(∞) does not exist but the integral converges conditionally via Dirichlet test) appear frequently. A powerful generalisation: if f is differentiable and f' is integrable, then ∫₀^∞ (f(ax)−f(bx))/x dx = ∫₀^∞ f'(x) ln(b/a) dx? No — the correct generalisation uses the identity ∫₀^∞ (f(ax)−f(bx))/x dx = ∫₀^∞ (f(u)/u) du evaluated between limits, but the standard Frullani form is the one to memorise. Examiners often hide the Frullani structure inside integrals like ∫₀^∞ (tan−1(3x) − tan−1(x))/x dx = (π/2) ln 3, or ∫₀^∞ (e−x − e−2x)/x dx = ln 2. The key recognition step: the integrand is a difference of the same function at scaled arguments, divided by x. If the limits at 0 and ∞ exist, the answer is their difference times ln(scale ratio). When f(∞) does not exist (e.g., sin x), the integral may still converge but the Frullani formula does not apply directly; one must use Dirichlet or known sine‑integral values.

Ostrogradsky's Method for Rational Functions with Repeated Factors

When a rational function has a denominator with repeated irreducible quadratic factors, the standard partial‑fraction decomposition becomes algebraically heavy. Ostrogradsky's method (also called the Hermite‑Ostrogradsky method) separates the integral into a rational part and a remaining integral with a simpler denominator. Given a proper rational function P(x)/Q(x) where Q(x) has repeated factors, write Q(x) = Q₁(x) Q₂(x) with Q₁(x) containing each factor to the highest power and Q₂(x) the product of the same factors each to the first power. Then there exist polynomials A(x) and B(x) with deg A < deg Q₁ and deg B < deg Q₂ such that

∫ P(x)/Q(x) dx = A(x)/Q₁(x) + ∫ B(x)/Q₂(x) dx.

The derivative of the rational part yields a rational function whose denominator is Q₁(x)². Equating numerators after differentiating A(x)/Q₁(x) and adding B(x)/Q₂(x) gives a system of linear equations for the coefficients of A and B. This avoids the lengthy decomposition into many simple fractions. The method is especially powerful when Q(x) contains powers of irreducible quadratics, e.g. ∫ (x³+2x)/((x²+1)³) dx. Here Q₁ = (x²+1)³, Q₂ = x²+1. Let A(x) = ax²+bx+c, B(x) = dx+e. Differentiate A/Q₁, combine with B/Q₂, match numerator to x³+2x, solve for a,b,c,d,e. The result is a rational term plus an arctangent integral. Ostrogradsky's method reduces the algebraic load and is a favourite in time‑pressured examinations because it produces the rational part directly.

To apply the method systematically: (1) Factor Q(x) completely over reals. (2) Form Q₁ as the product of each distinct factor raised to its multiplicity, and Q₂ as the product of each distinct factor to the first power. (3) Write unknown polynomials A(x), B(x) with degrees one less than Q₁, Q₂ respectively. (4) Differentiate A/Q₁ using the quotient rule, add B/Q₂, set equal to P/Q, clear denominators, and equate coefficients of like powers of x. (5) Solve the linear system. (6) The integral equals A/Q₁ + ∫ B/Q₂ dx. The remaining integral ∫ B/Q₂ dx is handled by standard partial fractions or trigonometric substitutions. This technique also extends to improper rational functions after polynomial long division.

Feynman's Technique: Introducing a Parameter to Evaluate Definite Integrals

Feynman's technique, or differentiation under the integral sign, exploits the Leibniz rule to evaluate definite integrals that resist elementary antiderivatives. The idea is to embed the original integral into a family I(α) = ∫ₐᵇ f(x,α) dx where α is a parameter, differentiate with respect to α, and hope the resulting integral is simpler. After integrating the derivative, the constant of integration is fixed by evaluating I(α) at a convenient α value. A classic example is ∫₀^∞ (e-ax - e-bx)/x dx for a,b > 0. Define I(α) = ∫₀^∞ (e-αx - e-bx)/x dx. Then dI/dα = -∫₀^∞ e-αx dx = -1/α. Integrating gives I(α) = -ln α + C. Setting α = b yields I(b) = 0, so C = ln b. Hence I(a) = ln(b/a). This recovers the Frullani integral without invoking its theorem directly.

The technique shines when the integrand contains a logarithm or an inverse trigonometric function that can be generated by differentiation. For instance, ∫₀¹ (x^a - 1)/ln x dx. Let I(a) = ∫₀¹ (x^a - 1)/ln x dx. Then dI/da = ∫₀¹ x^a dx = 1/(a+1). Integrate: I(a) = ln(a+1) + C. Since I(0) = 0, C = 0, so I(a) = ln(a+1). Another powerful use is ∫₀π/2 ln(sin x) dx. Introduce I(α) = ∫₀π/2 ln(1 + α sin x) dx, differentiate, evaluate the resulting rational trigonometric integral, then integrate back. The choice of parameter is an art: it should simplify the derivative integral, often by removing a logarithm or producing a rational function. The method also works for integrals over infinite intervals, provided uniform convergence justifies differentiation under the integral sign. In examinations, look for integrands with a parameter‑like structure (e.g., a power, an exponential coefficient, or a logarithmic argument) that can be turned into a differentiable family.

Term-by-Term Integration of Power Series and Fourier Series

Integrating a function represented by a power series or Fourier series term by term is justified by uniform convergence on compact subintervals of the interval of convergence. For a power series ∑n=0^∞ a_n (x - c)^n with radius of convergence R, the integrated series ∑ a_n (x - c)n+1/(n+1) has the same radius R and converges to ∫ f(x) dx on |x - c| < R. This allows evaluation of integrals like ∫₀¹ ln(1+x)/x dx by expanding ln(1+x) = ∑n=1^∞ (-1)n-1 x^n/n, dividing by x, and integrating termwise to obtain ∑ (-1)n-1/n² = π²/12. The same principle applies to Fourier series: if f(x) = a₀/2 + ∑n=1^∞ [a_n cos(nx) + b_n sin(nx)] converges piecewise smoothly, then ∫ f(x) dx = a₀ x/2 + ∑ [a_n sin(nx)/n - b_n cos(nx)/n] + C, with the series converging uniformly on any closed interval not containing discontinuities. This technique is invaluable for evaluating definite integrals of periodic functions, e.g., ∫₀^π x(π - x) sin(nx) dx appears in Fourier coefficient calculations. Termwise integration also provides a route to derive series for constants: integrating the geometric series ∑ x^n = 1/(1-x) from 0 to 1 gives ∑ 1/(n+1) which diverges, but integrating ∑ (-1)^n x^n = 1/(1+x) yields the alternating harmonic series ln 2. In examinations, you may be asked to evaluate an integral by recognizing it as the termwise integral of a known series, or to find the sum of a series by integrating a known series expansion. Always state the convergence theorem used (Weierstrass M‑test for uniform convergence) to justify the interchange of sum and integral.

Integrals Involving the Signum Function and Absolute Value Products

The signum function sgn(x) = 1 for x > 0, 0 for x = 0, -1 for x < 0, and the absolute value |x| = x sgn(x) appear in integrals that model piecewise‑defined physical quantities. Integrals of products like ∫-a^a |x|^m sgn(x)^n dx simplify by splitting at zero. Since sgn(x)^n = sgn(x) for odd n and 1 for even n, the integrand becomes either an even or odd function. For example, ∫-π^π |sin x| sgn(cos x) dx splits into intervals where cos x changes sign. On [0, π/2] and [3π/2, 2π] cos x ≥ 0 so sgn(cos x) = 1; on [π/2, 3π/2] sgn(cos x) = -1. The absolute value of sin x is symmetric, so the integral reduces to a sum of standard trigonometric integrals. A systematic approach: (1) Identify all points where the arguments of absolute values or signum functions change sign. (2) Partition the integration interval at those points. (3) On each subinterval replace |f(x)| by ±f(x) and sgn(g(x)) by ±1 according to the sign of f and g. (4) Integrate the resulting elementary expression. (5) Sum the contributions. This method also handles nested absolute values, e.g., ∫₀² | |x-1| - 1 | dx. The inner absolute value changes at x = 1, the outer at points where |x-1| = 1, i.e., x = 0, 2. Partition [0,2] into [0,1] and [1,2], evaluate each piece. In examinations, such integrals test the ability to manage piecewise definitions without graphing. A common shortcut: for ∫-a^a f(|x|) sgn(x) dx, the integrand is odd, so the integral is zero provided f is integrable. For ∫-a^a f(|x|) dx, the integral equals 2∫₀^a f(x) dx.

Rationalizing Substitutions for Binomial Differentials

Integrals of the form ∫ x^m (a + b x^n)^p dx, where m, n, p are rational numbers, are called binomial differentials. Chebyshev's theorem states that such an integral is expressible in elementary functions if and only if at least one of (m+1)/n, p, or (m+1)/n + p is an integer. When this condition holds, a rationalizing substitution reduces the integral to a rational function. The standard substitution is x^n = t^q where q is the denominator of p (when p is rational) or the denominator of (m+1)/n. More generally, set a + b x^n = t^q x^n, or x = t^r, choosing r to clear all fractional exponents. For example, ∫ x1/2 (1 + x1/3)-2 dx. Here m = 1/2, n = 1/3, p = -2. Compute (m+1)/n = (3/2)/(1/3) = 9/2, not integer; p = -2 integer, so condition satisfied. Substitute x = t6 (LCM of denominators 2 and 3). Then dx = 6 t5 dt, x1/2 = t3, x1/3 = t2. The integral becomes ∫ t3 (1 + t2)-2 · 6 t5 dt = 6 ∫ t8/(1+t2)2 dt, a rational function integrable by partial fractions or Ostrogradsky's method. Another example: ∫ dx/√(x + √x). Let x = t4, then √x = t2, √(x+√x) = √(t4+t2) = t√(t2+1). The integral becomes ∫ 4 t3/(t√(t2+1)) dt = 4 ∫ t2/√(t2+1) dt, which is handled by trigonometric substitution t = tan θ. The key is to find the least common multiple of the denominators of all fractional exponents appearing in the integrand after writing each radical as a power. This substitution rationalizes the integrand completely, converting the problem into integration of a rational function, which is algorithmic. In examinations, binomial differentials often appear disguised as nested radicals; recognizing the pattern and applying the LCM substitution is a high‑yield skill.

  • Forgetting to check Chebyshev's condition before attempting a rationalizing substitution — the integral may not have an elementary antiderivative.
  • Choosing the wrong LCM for the substitution exponent, leaving fractional powers in the transformed integrand.
  • Neglecting to adjust the differential dx correctly when substituting x = t^r.
  • Misapplying Ostrogradsky's method when the denominator has no repeated factors — standard partial fractions are simpler.
  • Overlooking the need to verify uniform convergence before integrating a series term by term.
  • Incorrectly splitting the interval for signum or absolute value functions at points where the argument is zero but the function does not change sign.
  • Review these traps before the exam to avoid losing marks.

Integration of Inverse Functions and the Area Formula

The integral of an inverse function admits a geometric interpretation that converts a difficult antiderivative into a simple algebraic expression. If f is continuous and strictly monotonic on an interval, with inverse f⁻¹, then for any a, b in the domain of f⁻¹,

∫ f⁻¹(x) dx = x f⁻¹(x) − F(f⁻¹(x)) + C,

where F is any antiderivative of f. This follows from integration by parts with u = f⁻¹(x), dv = dx, giving du = dx / f'(f⁻¹(x)) and v = x. The definite version is even more powerful: the area under y = f⁻¹(x) from x = c to x = d equals d f⁻¹(d) − c f⁻¹(c) − ∫f⁻¹(c)f⁻¹(d) f(t) dt. Geometrically, this is the area of the bounding rectangle minus the area under the original curve, reflected across y = x.

For example, ∫ arcsin x dx = x arcsin x + √(1 − x²) + C because f(t) = sin t, F(t) = −cos t, and cos(arcsin x) = √(1 − x²). Similarly, ∫ ln x dx = x ln x − x + C (inverse of et). The formula extends to integrals like ∫ arctan(x²) dx by setting u = x², though the resulting integral ∫ u⁻¹ᐟ² arctan u du may still require series or special functions. In examinations, this technique is most valuable when the inverse function is elementary but its direct antiderivative is not obvious — arcsin, arccos, arctan, arcsec, and logarithmic forms. A common variant: evaluate ∫01 arcsin x dx using the area formula. Here f(t) = sin t, f⁻¹(0) = 0, f⁻¹(1) = π/2. The integral equals 1·(π/2) − 0 − ∫0π/2 sin t dt = π/2 − 1. This avoids integration by parts entirely.

Gaussian Integrals and Their Generalizations

The Gaussian integral ∫−∞∞ e−x² dx = √π is the cornerstone of a family of integrals evaluated by squaring and converting to polar coordinates. The standard proof: let I = ∫−∞∞ e−x² dx. Then I² = ∫−∞∞ ∫−∞∞ e−(x²+y²) dx dy = ∫02π ∫0∞ e−r² r dr dθ = 2π · ½ = π, so I = √π. This method generalizes to ∫−∞∞ e−a x² dx = √(π/a) for a > 0 by substitution u = √a x. The moments ∫−∞∞ x2n e−a x² dx are obtained by differentiating with respect to a: d/da ∫ e−a x² dx = −∫ x² e−a x² dx. Since ∫ e−a x² dx = √(π/a), we get ∫ x² e−a x² dx = ½ √(π/a³). Repeating gives ∫ x4 e−a x² dx = ¾ √(π/a⁵), and generally ∫−∞∞ x2n e−a x² dx = (2n−1)!! / (2n an) √(π/a). Odd moments vanish by symmetry.

Integrals of the form ∫−∞∞ e−a x² + b x dx are handled by completing the square: −a x² + b x = −a(x − b/2a)² + b²/4a. The integral becomes eb²/4a √(π/a). This is the generating function for Hermite polynomials and appears in quantum mechanics and probability. A frequent examination variant: ∫0∞ xn e−a x² dx. Substitute u = a x², dx = du / (2√a u), yielding ½ a−(n+1)/2 ∫0∞ u(n−1)/2 e−u du = ½ a−(n+1)/2 Γ((n+1)/2). This connects Gaussian integrals to the Gamma function. For n = 1, ∫0∞ x e−a x² dx = 1/(2a). For n = 2, ∫0∞ x² e−a x² dx = ¼ √(π/a³). The error function erf(x) = 2/√π ∫0x e−t² dt is the antiderivative of the Gaussian; it is non-elementary but tabulated. In definite integrals with finite limits, expressing the answer in terms of erf is acceptable and often expected.

Integrals with Parameter-Dependent Limits and the Generalized Leibniz Rule

The standard Leibniz rule d/dx ∫a(x)b(x) f(t, x) dt = f(b(x), x) b'(x) − f(a(x), x) a'(x) + ∫a(x)b(x) ∂f/∂x dt assumes f is continuously differentiable and the limits are differentiable. In examinations, the rule is often applied in reverse: given a derivative, recover the integral. For instance, if F'(x) = f(x, x) + ∫0x ∂f/∂x(t, x) dt, then F(x) = ∫0x f(t, x) dt + C. This is the basis for solving integral equations of Volterra type.

A powerful extension handles integrals where the integrand has a singularity at the limit, e.g., ∫0x (x−t)−½ f(t) dt. The derivative involves a fractional integral. More generally, for α > 0, the Riemann–Liouville fractional integral Iαf(x) = 1/Γ(α) ∫0x (x−t)α−1 f(t) dt satisfies d/dx Iαf = Iα−1f for α > 1. While fractional calculus is beyond the standard syllabus, the case α = ½ appears in Abel's integral equation: given g(x) = ∫0x f(t)/√(x−t) dt, find f. The solution is f(x) = 1/π d/dx ∫0x g(t)/√(x−t) dt. This is solved by applying the Leibniz rule carefully, noting the singularity.

Another examination favorite: differentiate under the integral sign when the parameter appears in the limit AND the integrand. Example: I(a) = ∫0a e−a t sin t dt. Then I'(a) = e−a² sin a + ∫0a (−t) e−a t sin t dt. This creates a differential equation for I(a). Solving it yields the value of the original integral. A classic problem: I(a) = ∫0a (sin x)/x dx. Then I'(a) = (sin a)/a, so I(a) = ∫0a (sin t)/t dt = Si(a), the sine integral. The limit a → ∞ gives π/2. The generalized rule also applies when the integrand depends on a parameter α and the limits are constants: d/dα ∫ab f(x, α) dx = ∫ab ∂f/∂α dx. This is the Feynman technique already discussed, but the full Leibniz rule with variable limits is a distinct tool for problems where the domain of integration changes with the parameter.

Integrals Involving Periodic Functions and the Mean Value Property

If f is periodic with period T, then ∫aa+T f(x) dx is independent of a. This is the mean value property: the average value of f over one period is (1/T) ∫0T f(x) dx. For definite integrals over multiple periods, ∫0nT f(x) dx = n ∫0T f(x) dx. This simplifies integrals like ∫0100π |sin x| dx = 100 ∫0π sin x dx = 200. A more subtle property: if f is periodic with period T and g is any integrable function, then limn→∞ ∫ab f(n x) g(x) dx = (1/T) ∫0T f(t) dt · ∫ab g(x) dx. This is the Riemann–Lebesgue lemma for periodic functions and appears in problems asking for the limit of an oscillatory integral.

Another technique: for ∫0T f(sin x, cos x) dx where f is rational, the substitution t = tan(x/2) (Weierstrass) works, but symmetry often gives a faster route. For example, ∫02π x sin x / (1 + cos² x) dx. The integrand is not periodic, but split ∫0π + ∫π2π. In the second, let u = x − π. The integral becomes ∫0π (u+π) sin u / (1+cos² u) du. Adding to the first part gives ∫0π (2<u>+π) sin u / (1+cos² u) du. The u sin u part is odd about π/2 (since sin(π−u) = sin u, but u → π−u changes sign), so it vanishes. The remainder is π ∫0π sin u / (1+cos² u) du = π [−arctan(cos u)]0π = π (π/4 − (−π/4)) = π²/2.

Integrals of the form ∫02π R(cos x, sin x) dx where R is rational can be evaluated by the complex substitution z = ei x, dx = dz/(i z), cos x = (z+z⁻¹)/2, sin x = (z−z⁻¹)/(2i). The integral becomes a contour integral around the unit circle: ∮ R((z+z⁻¹)/2, (z−z⁻¹)/(2i)) dz/(i z). This is evaluated by the residue theorem. While contour integration is not in the standard syllabus, the algebraic substitution z = ei x converts the trigonometric integral into a rational function integral in z, which can be handled by partial fractions if the poles are simple. For instance, ∫02π dx/(a + b cos x) = 2π/√(a²−b²) for a > |b|. This is derived by z-substitution and is a standard result worth memorizing.

Cauchy Principal Value and Singular Integrals

When an integrand has a non-integrable singularity inside the interval, the definite integral diverges in the Riemann sense. The Cauchy principal value (PV) assigns a finite value by symmetrically approaching the singularity: PV ∫ab f(x) dx = limε→0⁺ [∫ac−ε f(x) dx + ∫c+εb f(x) dx] where c ∈ (a, b) is the singular point. For example, PV ∫−11 dx/x = 0 because the two halves cancel. However, ∫−11 dx/x diverges (both ∫01 dx/x and ∫−10 dx/x diverge). The principal value exists only when the singularity is of odd order (like 1/x) and the limits are taken symmetrically. If the singularity is of even order (like 1/x²), the PV diverges to +∞.

In examinations, principal value integrals appear in two contexts: (1) integrals of rational functions with simple poles on the real axis, evaluated by contour integration with indented contours; (2) integrals like ∫0∞ sin x/x dx = π/2, where the singularity at 0 is removable (sin x/x → 1), but the integral is conditionally convergent. The Dirichlet integral ∫0∞ sin x/x dx is evaluated by Feynman's technique: I(a) = ∫0∞ e−a x sin x/x dx, I'(a) = −∫0∞ e−a x sin x dx = −1/(a²+1), so I(a) = −arctan a + π/2, and I(0) = π/2.

Another class: integrals with singularities at endpoints, e.g., ∫01 ln x / (1−x) dx. The singularity at x = 1 is logarithmic. Expand 1/(1−x) = ∑ xn, integrate termwise: ∑ ∫01 xn ln x dx = −∑ 1/(n+1)² = −π²/6. This is a standard evaluation. The Hilbert transform Hf(x) = (1/π) PV ∫−∞∞ f(t)/(x−t) dt appears in signal processing; its discrete analogue is the harmonic conjugate. In examinations, you may encounter PV ∫−∞∞ f(x)/(x−a) dx where f is rational and decays sufficiently. The value is πi times the sum of residues in the upper half-plane plus πi times the residue at the pole on the real axis (if indented above). Without complex analysis, such integrals are evaluated by splitting into partial fractions and using known PVs: PV ∫−∞∞ dx/(x−a) = 0, PV ∫−∞∞ x dx/(x²−a²) = 0, etc.

  • Applying the inverse function formula to integrands that are not strictly monotonic on the integration interval — the formula requires a well-defined inverse.
  • Forgetting the Jacobian factor when completing the square in Gaussian integrals with linear terms — the shift does not change dx, but the constant factor eb²/4a must be included.
  • Using the standard Leibniz rule when the integrand has a singularity at the variable limit — the derivative formula acquires an extra term involving the singularity.
  • Assuming periodicity allows termwise integration of a series without checking uniform convergence — the Riemann–Lebesgue lemma requires f ∈ L¹ and g continuous.
  • Confusing Cauchy principal value with the actual convergent integral — if the integral converges absolutely, PV equals the integral; if it converges conditionally, PV may exist while the integral diverges.
  • Neglecting to verify that the singularity in a principal value integral is of odd order — even-order singularities (1/x², 1/|x|) yield divergent PVs.
  • Misapplying the Weierstrass substitution to integrals over [0, 2π] when the integrand has a singularity at π — the substitution t = tan(x/2) is not bijective at x = π; split the interval first.
