Operations Research — Linear Programming, Duality & the Simplex Method

Operations Research (OR) is the discipline of applying mathematical methods to make optimal decisions in complex systems. At its core lies linear programming (LP): minimize c^T x subject to Ax ≤ b, x ≥ 0. The simplex method (Dantzig, 1947) navigates the vertices of the feasible polyhedron to find the optimum, while duality theory provides a powerful economic interpretation via shadow prices. Beyond LP, OR encompasses network flows, integer programming, convex optimization, interior point methods (Karmarkar, 1984), and dynamic programming (Bellman). Together these tools underpin modern logistics, finance, manufacturing, and artificial intelligence.

"Operations research is the art of making bad decisions with good mathematics."
— George Dantzig
Part 1

📏 Linear Programming and the Simplex Method

Foundations
Standard LP, Polyhedra, Extreme Points, and the Simplex Algorithm
The standard form LP is: minimize c^T x subject to Ax = b, x ≥ 0, where A ∈ ℝ^{m×n} with rank(A) = m and n ≥ m. The feasible set {x ≥ 0: Ax = b} is a convex polyhedron. A point x is an extreme point (vertex) iff the columns of A corresponding to positive entries are linearly independent — equivalently, x is a basic feasible solution (BFS): n−m variables (non-basic) are zero, and the m basic variables satisfy A_B x_B = b, x_B ≥ 0. The Fundamental Theorem of Linear Programming: if an LP has an optimal solution, it has an optimal BFS (extreme point). The simplex method (Dantzig, 1947) starts at a BFS and moves along an edge by increasing one non-basic variable until a constraint becomes tight. The pricing step selects the entering variable with the most negative reduced cost: c̄_j = c_j − c_B^T A_B^{-1} A_j. The ratio test determines the leaving variable: min over i with (A_B^{-1} A_j)_i > 0 of (x_B)_i / (A_B^{-1} A_j)_i. The tableau representation maintains the canonical form: the objective row expresses z = c_B^T A_B^{-1} b + Σ_{j∈N} c̄_j x_j. Degeneracy occurs when a BFS has fewer than m positive variables; cycling is possible but avoided by Bland's rule (the smallest-index rule for entering and leaving variables). Although the simplex method is exponential in worst-case (Klee-Minty cube), it is polynomial in practice and remains the workhorse of LP solvers.
Linear programming optimizes a linear objective over a convex polyhedron; the simplex method efficiently explores extreme points to find the optimum.
Part 2

🌍 Duality Theory

Duality
Dual LP, Weak and Strong Duality, Complementary Slackness, Sensitivity
Given the primal LP (P): minimize c^T x subject to Ax ≥ b, x ≥ 0, the dual LP (D) is: maximize b^T y subject to A^T y ≤ c, y ≥ 0. The pair is symmetric: the dual of the dual is the primal. Weak duality: for any feasible primal x and dual y, we have c^T x ≥ b^T y — the primal objective is always at least the dual objective. Strong duality: if (P) has an optimal solution x*, then (D) has an optimal solution y* with c^T x* = b^T y* (provided either (P) or (D) is feasible and bounded). This holds under a constraint qualification (e.g., Slater's condition). Complementary slackness: for optimal x* and y*, we have (c_j − a_j^T y*) x*_j = 0 for all j, and y*_i (a_i^T x* − b_i) = 0 for all i — a variable is positive only if its corresponding dual constraint is tight. Economic interpretation: y*_i is the shadow price of constraint i — the marginal increase in the optimal objective value when the right-hand side b_i is increased. The dual simplex method maintains dual feasibility and drives toward primal feasibility; it is especially useful for re-optimizing after adding constraints. Sensitivity analysis studies the range of coefficients (c_j, b_i, a_{ij}) for which the optimal basis remains optimal: the allowable increase/decrease for each cost coefficient c_j (without changing the optimal basis), the shadow prices and their ranges, and the right-hand side ranging. Farkas' lemma: Ax ≤ b, x ≥ 0 is infeasible iff there exists y ≥ 0 such that A^T y ≥ 0 and b^T y < 0 — a certificate of infeasibility dual to the original system.
Duality pairs every LP with a mirror problem; strong duality ensures their optimal values coincide, and shadow prices give marginal economic value to each constraint.
Part 3

🧮 Network Flow and Integer Programming

Networks & IP
Transportation Problem, Max Flow, Branch and Bound, Cutting Planes
The transportation problem minimizes Σ_i Σ_j c_{ij} x_{ij} subject to Σ_j x_{ij} = s_i (supply), Σ_i x_{ij} = d_j (demand), x_{ij} ≥ 0 — a classic network-structured LP that can be solved efficiently via specialized algorithms (the transportation simplex). The assignment problem (a special case where s_i = d_j = 1) is solved by the Hungarian algorithm (Kuhn-Munkres) in O(n³) time. The maximum flow problem: given a directed graph with capacities, find the maximum flow from source s to sink t. The Ford-Fulkerson algorithm repeatedly finds augmenting paths; the max-flow-min-cut theorem states the maximum flow equals the capacity of the minimum s-t cut. The minimum cost flow problem generalizes both transportation and max flow; the network simplex exploits the graph structure for efficiency. Moving to discrete decisions, integer programming (IP) adds integrality constraints: minimize c^T x subject to Ax ≤ b, x ∈ ℤ₊ⁿ. The branch and bound method: solve the LP relaxation, branch on a fractional variable x_j = v into two subproblems (x_j ≤ ⌊v⌋ and x_j ≥ ⌈v⌉), compute bounds to prune. Cutting planes tighten the LP relaxation: a Gomory cut is derived from a fractional row of the optimal simplex tableau — if x_B_i + Σ_j ā_{ij} x_{N_j} = b̄_i with b̄_i fractional, then x_B_i + Σ_j ⌊ā_{ij}⌋ x_{N_j} ≤ ⌊b̄_i⌋ is valid. The Chvátal-Gomory closure is the set of points satisfying all Gomory cuts — it is a polyhedron (the Chvátal rank is finite). Lagrangian relaxation dualizes complicating constraints, yielding a problem that decomposes into tractable subproblems; the subgradient method iteratively solves the dual. Stochastic programming handles uncertainty via two-stage formulation: here-and-now decisions x followed by wait-and-see recourse decisions y(ω) that depend on the realized scenario ω.
Network flow problems exploit graph structure for efficiency; integer programming extends LP to discrete decisions via branch-and-bound and cutting planes.
Part 4

🔥 Interior Point Methods and Convex Optimization

Advanced
Karmarkar's Algorithm, Primal-Dual Path-Following, SDP, and Beyond
Karmarkar's projective algorithm (1984) was the first interior point method for LP with polynomial complexity O(n^{3.5} L), igniting a revolution. Modern solvers use the primal-dual path-following framework: solve the KKT conditions via Newton's method applied to the perturbed system. For the LP: minimize c^T x subject to Ax = b, x ≥ 0, the KKT conditions are: A^T y + s = c, Ax = b, X·s·e = 0 with (x, s) ≥ 0. The perturbed system replaces complementarity with X·s·e = μ·e, where μ > 0 is the barrier parameter. The central path is the set of solutions (x(μ), y(μ), s(μ)) parameterized by μ → 0. The duality gap c^T x(μ) − b^T y(μ) = n·μ, so driving μ → 0 converges to optimality. The predictor-corrector method (Mehrotra) uses an affine predictor step to estimate μ, then a corrector step for centrality. The complexity is O(√n·log(1/ε)) iterations for μ → ε. Self-concordant barriers (Nesterov-Nemirovskii, 1994) generalize the logarithmic barrier x ↦ −Σ ln x_j to arbitrary convex cones, providing a universal theory of polynomial-time interior point methods for all convex optimization problems: linear, quadratic, second-order cone, semidefinite, and conic programming. Semidefinite programming (SDP): minimize C·X subject to A_i·X = b_i, X ⪰ 0 (X is symmetric positive semidefinite). SDP duality: max b^T y subject to Σ y_i A_i ⪯ C. The complementarity condition: X·Z = 0 for optimal primal-dual pair (X, Z = C − Σ y_i A_i). A landmark application is the MAX CUT approximation (Goemans-Williamson, 1995): relax MAX CUT to an SDP, then use randomized rounding to achieve a 0.878 approximation ratio — a dramatic improvement over naive methods. Beyond these, dynamic programming (Bellman's principle of optimality) solves sequential decision problems via the Hamiltonian-Jacobi-Bellman equation, linking OR to optimal control and reinforcement learning.
Interior point methods traverse the interior of the feasible region via Newton's method; their polynomial complexity extends to all convex optimization through self-concordant barriers.
